    1. A 는 표준편차 약 15.8 에 평균 30 이라 0.527 이고 C 는 약 7.9 에 평균 15 라 0.527 로 같으며 B 는 평균 25 라 0.632 로 더 크므로 이 설명이 옳다(정답).
    2. a 와 c 가 같다는 앞부분은 맞지만 b 는 표준편차가 A 와 같은 15.8 이고 평균이 25 로 더 작아 0.632 로 a 보다 크므로 b<a 라는 뒷부분이 옳지 않다.
    3. c 는 a 와 같은 0.527 이므로 a<b<c 에서 a<c 라는 부분이 성립하지 않고 b 도 c 보다 큰 0.632 이므로 이 설명은 옳지 않다.
    4. c<b<a 는 b 가 0.632 로 셋 중 가장 큰데 이를 가운데로 놓았고 a 와 c 가 같은 0.527 인데 c 가 a 보다 작다고 했으므로 이 설명은 옳지 않다.
    🧮 풀이
    1. 甲은 세 자료의 평균 30, 25, 15 와 표준편차 15.8, 15.8, 7.9 를 나란히 적은 학생이다. 표준편차를 평균으로 나눠 0.527, 0.632, 0.527 을 얻고 a=c 이고 b 가 가장 크다고 판정했다.
    2. 甲은 B 가 A 의 모든 값에서 5 씩 뺀 자료임을 보고 퍼진 정도가 같으니 변동계수도 같다고 본 수험생이다. 평균이 30 에서 25 로 줄어 나누는 값이 작아지면 b 가 커진다는 것을 셈해 고쳤다.
    3. 甲은 자료 C 의 값이 가장 작으니 변동계수도 가장 작다고 짐작한 응시자다. C 는 표준편차 7.9 도 함께 작아 평균 15 로 나눈 값이 A 와 같은 0.527 이라는 것을 확인하고 이 보기를 지웠다.
    4. 甲은 평균이 클수록 변동계수가 크다고 반대로 알고 있던 학생이다. 나누는 평균이 클수록 몫이 작아진다는 것을 A 의 30 에서 0.527, B 의 25 에서 0.632 를 대 보고 바로잡았다.

    세 자료의 변동계수는 표준편차를 평균으로 나눈 값으로 a 와 c 는 약 0.527 로 같고 b 는 약 0.632 라 더 크므로 a=c 이고 a<b 인 1번이 옳다. 정답은 1번이다.

    두 확률변수 X 와 Y 의 결합확률분포가 다음 표와 같다. X 의 기댓값이 0 일 때, 옳은 것은?

    <div class="tbl-wrap"><table class="jtbl"><thead><tr><th>X Y</th><th>-1</th><th>1</th></tr></thead><tbody><tr><td>-1</td><td>{3 / 8}</td><td>( )</td></tr><tr><td>0</td><td>{1 / 8}</td><td>{1 / 4}</td></tr><tr><td>1</td><td>( )</td><td>{1 / 8}</td></tr></tbody></table></div>

    1. 1. Var(X) = {1 / 4}
    2. 2. E (Y) = {3 / 8}
    3. 3. E (X Y) = {1 / 4}
    4. 4. P (X + Y = 0) = {1 / 8}

    정답 4번

    🔍 보기별 해설
    1. 빈칸을 채우면 P(X=−1)=P(X=1)=1/2 이라 Var(X)=E(X²)=1 이고 1/4 이 아니므로 Var(X)=1/4 라는 이 설명은 옳지 않다.
    2. Y 는 −1 일 확률이 3/8+1/8=1/2 이고 0 일 확률이 3/8 이며 1 일 확률이 1/8 이라 E(Y)=−1/2+1/8=−3/8 이므로 부호가 반대인 3/8 은 옳지 않다.
    3. 곱 XY 는 (−1,−1) 에서 3/8, (1,−1) 에서 −1/8, (1,1) 에서 1/8 이고 (−1,1) 은 확률이 0 이라 E(XY)=3/8 이므로 1/4 은 옳지 않다.
    4. X+Y=0 인 칸은 (1,−1) 과 (−1,1) 이고 이들의 확률이 1/8 과 0 이라 P(X+Y=0)=1/8 이 되므로 이 설명이 옳다(정답).
    🧮 풀이
    1. 甲은 X 의 두 값 −1 과 1 의 확률을 모두 1/2 로 구한 학생이다. 제곱하면 모두 1 이 되어 분산이 E(X²)=1 이 되므로 1/4 이라는 값과 어긋남을 확인하고 이 보기를 지웠다.
    2. 甲은 Y 의 세 값 −1, 0, 1 의 확률을 행의 합으로 구해 1/2, 3/8, 1/8 을 얻은 수험생이다. 기댓값이 −3/8 로 음수인데 보기는 양수 3/8 이라 부호가 틀렸다는 것을 짚었다.
    3. 甲은 XY 의 값을 칸마다 곱해 적은 응시자다. 확률이 0 인 칸은 0 을 기여한다는 점까지 포함해 3/8−1/8+1/8=3/8 을 얻고 1/4 이라는 값과 다름을 확인해 이 보기를 지웠다.
    4. 甲은 E(X)=0 이라는 조건으로 빈칸 두 개를 1/8 과 0 으로 정한 학생이다. 합이 0 이 되는 두 칸의 확률을 더해 1/8 을 얻고 이 보기가 표와 맞다는 것을 확인했다.

    X+Y=0 인 칸은 (1,−1) 과 (−1,1) 이고 E(X)=0 과 확률의 합 1 로 두 빈칸이 1/8 과 0 이라 P(X+Y=0)=1/8 이 되므로 옳은 것은 4번이다. 정답은 4번이다.

    확률변수 X 에 대한 누적 확률 P (X ≤ x) 가 다음과 같을 때, 옳지 않은 것은?

    P (X ≤ x) = {0 (x < 0), {1 / 6} x (0 ≤ x < 2), {1 / 2} (2 ≤ x < 4), {1 / 6} x (4 ≤ x < 6), 1 (x ≥ 6)}

    1. 1. P (X ≤ a) = 1/4 을 만족시키는 a 의 값은 3/2 이다.
    2. 2. P (X = 3) = 0
    3. 3. P (X ≥ 5) = {2 / 3}
    4. 4. P (1 < X ≤ 4) = {1 / 2}

    정답 3번

    🔍 보기별 해설
    1. 누적확률 1/4 는 0 이상 2 미만 구간의 식 x/6 에서 a/6=1/4 이라 a=3/2 이고 이 값이 구간 안에 있으므로 이 설명은 옳다.
    2. 누적확률이 2 이상 4 미만에서 1/2 로 일정해 이 구간에서는 확률이 늘지 않으므로 3 에서의 점확률이 0 이라 P(X=3)=0 이고 이 설명은 옳다.
    3. P(X≥5) 는 1 에서 P(X<5)=5/6 을 뺀 1/6 이고 2/3 은 P(X≤4) 의 값일 뿐이므로 P(X≥5)=2/3 이라는 이 설명은 옳지 않다(정답).
    4. P(1<X≤4) 는 F(4)−F(1)=2/3−1/6=1/2 이라 누적확률의 차로 구한 값이 보기와 같으므로 이 설명은 옳다.
    🧮 풀이
    1. 甲은 누적확률 1/4 를 0 이상 2 미만의 식 x/6 에 넣어 푼 학생이다. x/6=1/4 에서 x=3/2 가 구간 안에 있음을 확인하고 이 진술을 옳은 것으로 분류했다.
    2. 甲은 그래프에서 2 이상 4 미만이 수평인 것을 본 수험생이다. 수평이면 그 사이에 쌓이는 확률이 없으므로 3 에서의 점확률이 0 이라는 것을 알고 이 보기를 옳다고 표시했다.
    3. 甲은 P(X≥5) 를 F(4)=2/3 로 착각한 응시자다. 5 이상은 1 에서 F(5)=5/6 을 뺀 1/6 이고 2/3 는 4 이하의 확률이라는 점을 짚어 이 진술이 옳지 않다는 것을 찾았다.
    4. 甲은 구간 확률을 누적확률의 차로 옮겨 적은 학생이다. F(4) 는 4/6, F(1) 은 1/6 이라 차가 1/2 이 되는 것을 셈해 보고 이 진술이 표와 맞는다는 것을 확인했다.

    P(X≥5)=1−P(X<5)=1−5/6=1/6 이므로 2/3 이라는 3번 설명이 옳지 않다. 정답은 3번이다.

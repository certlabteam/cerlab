    수준 수가 4 인 인자 A와 수준 수가 3 인 인자 B의 각 수준조합에서 3 회씩 반복 실험을 하였다. 다음 표는 인자 A와 B의 교호작용(interaction)이 유의하지 않아서 교호작용을 오차항에 포함한 후 작성한 분산분석표의 일부이다. 요인제곱합자유도평균제곱F －값인자 A54인자 B72오차계396 유의수준 5% 에서 검정할 때, 인자 A와 B의 유의성에 대한 설명으로 옳은 것은? (단, F_α (k_1 , k_2) 는 분자와 분모의 자유도가 각각 k_1 , k_2 인 F 분포의 제 100 × (1- α) 백분위수를 나타낼 때, F(0.05) (2, 30) = 3.32 , F(0.05) (3,30) = 2.92 이다)

    1. 1. 인자 A, B는 모두 유의하다.
    2. 2. 인자 A는 유의하고, 인자 B는 유의하지 않다.
    3. 3. 인자 A는 유의하지 않고, 인자 B는 유의하다.
    4. 4. 인자 A, B는 모두 유의하지 않다.

    정답 3번

    🔍 보기별 해설
    1. 인자 A의 F값은 2로 임계값 2.92보다 작다. A는 유의하지 않으므로 두 인자가 모두 유의하다는 설명은 옳지 않다.
    2. 인자 A의 F값 2는 임계값 2.92보다 작고 B의 F값 4는 임계값 3.32보다 크다. 두 인자의 유의성 방향을 거꾸로 적었으므로 옳지 않다.
    3. 오차 평균제곱은 9이고 A와 B의 F값은 각각 2와 4다. A는 임계값 2.92보다 작고 B는 임계값 3.32보다 크므로 옳다(정답).
    4. 인자 B의 F값 4는 임계값 3.32를 넘는다. B의 주효과가 유의하므로 둘 다 유의하지 않다는 설명은 옳지 않다.
    🧮 풀이
    1. 한 실험에서 비료 투입량 네 수준을 A, 물 주기 세 수준을 B로 두고 각 조합을 세 번 반복했다. A의 제곱합 54를 자유도 3으로 나누면 평균제곱 18이고 오차 평균제곱은 9다. A의 F비 2가 기준 2.92에 못 미쳐 두 인자가 모두 유의하다는 결론은 나오지 않는다.
    2. 비료 투입량 A는 네 수준이라 자유도 3, 물 주기 B는 세 수준이라 자유도 2를 가진다. 오차 평균제곱 9를 기준으로 A의 F비는 18/9인 2, B의 F비는 36/9인 4다. A는 기준보다 작고 B는 기준보다 커서 두 효과의 판단이 서로 반대다.
    3. 교호작용을 오차에 합친 표에서 전체 제곱합 396 중 A와 B의 몫 54와 72를 빼면 오차제곱합 270이다. 오차 자유도 30으로 나눈 기준값은 9다. A의 F비 2는 임계값 2.92 아래이고 B의 F비 4는 임계값 3.32 위에 놓인다.
    4. 비료와 물 주기의 두 인자를 함께 조사한 뒤 물 주기 B의 평균제곱 36을 오차 평균제곱 9로 나누었다. B의 F비 4는 유의수준 5%의 기준 3.32보다 크다. 물 주기의 수준별 평균 차이가 통계적으로 드러났으므로 두 인자가 모두 무의미하다는 판단은 성립하지 않는다.

    오차제곱합은 396−54−72=270 이고 오차자유도는 35−5=30 이라 오차 평균제곱이 9 이고 F_A=18/9=2.0 은 2.92 보다 작고 F_B=36/9=4.0 은 3.32 보다 커서 A 는 유의하지 않고 B 는 유의하며 3번이 옳다.

    다음은 평균은 같고 분산이 서로 다른 정규분포의 누적분포함수 F (x) (- ∞ < x < ∞) 의 그림이다. 분산이 가장 큰 것은?

    1. 1.
    2. 2.
    3. 3.
    4. 4.

    정답 4번

    🔍 보기별 해설
    1. 첫 그래프는 평균 부근에서 누적확률이 매우 급하게 오른다. 관측값이 좁은 구간에 모인 작은 분산을 뜻하므로 옳지 않다.
    2. 둘째 그래프는 첫째보다 완만하지만 넷째보다 빠르게 오른다. 가장 넓게 퍼진 정규분포의 누적곡선은 아니므로 옳지 않다.
    3. 셋째 누적그래프도 넷째보다 평균 주변에서 더 가파르게 올라 관측값이 중심에 모인다. 넷째보다 작은 분산을 나타내므로 옳지 않다.
    4. 넷째 그래프는 네 곡선 중 평균 부근에서 가장 천천히 오른다. 같은 평균을 중심으로 값이 가장 넓게 퍼졌으므로 옳다(정답).
    🧮 풀이
    1. 첫 누적곡선은 x가 -2에서 2로 이동하는 동안 확률이 거의 0에서 거의 1로 바뀐다. 대부분의 관측값이 평균 근처의 짧은 구간에 들어 있다는 뜻이다. 같은 평균의 다른 곡선보다 폭이 좁아 가장 큰 분산으로 볼 수 없다.
    2. 둘째 누적곡선은 평균을 지날 때 첫째보다 덜 급하지만 오른쪽 끝에서는 빠르게 1에 가까워진다. 넷째 곡선은 같은 x 범위에서도 누적확률이 더 천천히 변한다. 둘째의 관측값은 넷째보다 평균 가까이에 모여 있다.
    3. 셋째 곡선은 x가 커질 때 매끄럽게 누적확률이 올라가는 정규형 모양을 보인다. 그래도 가운데 기울기는 넷째 곡선보다 크고 꼬리는 더 일찍 0과 1에 가까워진다. 넷째보다 분포의 폭이 좁아 분산도 작다.
    4. 넷째 누적곡선은 평균 근처에서 완만하게 올라가고 양쪽 꼬리까지 긴 x 구간을 쓴다. 값들이 중심에서 멀리 떨어져 나타날 가능성이 다른 세 곡선보다 크다. 같은 평균의 정규분포 가운데 가장 넓은 퍼짐이 이 곡선에 반영된다.

    평균이 같은 정규분포에서 분산이 클수록 누적분포함수가 완만하게 올라가므로 가장 완만한 4번 그림이 분산이 가장 큰 것이다.

    자료 (x_i, y_i) (i = 1,2, … ,10) 로부터 다음 결과를 얻었을 때, 이 자료를 최소제곱법으로 적합한 단순선형회귀식은?

    x̄ = 2 , ȳ = 3 , r = 1/3 , Σ(i = 1~10) (x_i - x̄)^2 = 1 , Σ(i = 1~10) (y_i - ȳ)^2 = 36 (단, r 는 x 와 y 의 표본상관계수이다)

    1. 1. ŷ = -1 + 2x
    2. 2. ŷ = -2 + x
    3. 3. ŷ = -4 + 2x
    4. 4. ŷ = -4 + x

    정답 1번

    🔍 보기별 해설
    1. 상관계수 1/3에 편차제곱합 비의 제곱근 6을 곱하면 기울기 2다. 평균점 (2,3)을 대입해 절편 -1을 얻으므로 ŷ = -1 + 2x가 옳다(정답).
    🧮 풀이
    1. ① 회귀선의 기울기를 구한다
    2. 열 개 관측값의 X 편차제곱합은 1이고 Y 편차제곱합은 36이다. Y의 흩어짐이 더 크지만 상관계수가 1/3이므로 제곱합 비의 제곱근 6에 1/3을 곱한다.
    3. → 기울기 = (1/3) × √(36/1) = 2
    4. ↓
    5. ② 표본평균점으로 절편을 구한다
    6. 최소제곱 회귀선은 X의 평균 2와 Y의 평균 3이 만나는 점을 지난다. 기울기 2인 직선에 x=2와 y=3을 넣으면 절편은 -1로 정해진다.
    7. → 절편 = 3 − 2 × 2 = -1
    8. ↓
    9. ③ 두 계수를 회귀식에 넣는다
    10. 기울기와 절편을 합친 식에서 X가 2이면 예측 Y는 3이 되어 표본평균점을 정확히 지난다. 다른 보기는 이 기울기나 평균점 조건 중 적어도 하나와 어긋난다.
    11. → 최종 회귀식 = ŷ = -1 + 2x

    기울기는 2이고 평균점 (2,3)을 지나는 절편은 -1이므로 정답은 1번이다.

    어느 사과 농장에서 수확한 사과의 평균 무게 μ 에 대한 가설 H_0 : μ = 350 대 H_1 : μ ! = 350 을 검정하려고 한다. 이 농장에서 수확한 사과 49 개를 임의추출하여 구한 μ 에 대한 95% 신뢰구간이 (349, 361) 일 때, 이에 대한 설명으로 옳지 않은 것은?

    1. 1. 유의수준 5% 에서 검정할 때 H_0 을 기각할 수 없다.
    2. 2. 유의수준 2% 에서 검정할 때 H_0 을 기각할 수 없다.
    3. 3. 위 가설에 대한 유의확률은 0.01 보다 크다.
    4. 4. 위 가설에 대한 유의확률은 0.03 보다 작다.

    정답 4번

    🔍 보기별 해설
    1. 양측검정에서 귀무값 350g이 95% 신뢰구간 (349, 361)에 들어 있다. 대응하는 유의수준 5%에서 기각할 수 없으므로 옳다.
    2. 5%에서 귀무가설을 기각하지 못하면 더 엄격한 2% 유의수준에서도 기각하지 못한다. p값이 0.05보다 커서 0.02도 넘으므로 옳다.
    3. 350g이 95% 신뢰구간 안에 있어 대응하는 양측검정의 p값은 0.05보다 크다. 따라서 0.01보다도 크므로 옳다.
    4. 95% 신뢰구간이 귀무값 350g을 포함하므로 p값은 0.05보다 크다. 0.03보다 작다고 한 것은 옳지 않다(정답).
    🧮 풀이
    1. 사과 49개의 무게로 평균에 대한 95% 신뢰구간을 구했더니 349g에서 361g이었다. 농장이 내세운 평균 350g은 구간 안쪽에 들어간다. 같은 자료의 양측 5% 검정에서는 350g이라는 가설을 배척할 근거가 부족하다.
    2. 표본으로 얻은 구간 안에 350g이 있어 5% 기준에서는 귀무가설이 유지됐다. 기준을 2%로 낮추면 기각 조건이 더 엄격해져 신뢰구간은 오히려 넓어진다. 350g은 새 구간에서도 벗어나지 않아 기각되지 않는다.
    3. 사과 무게의 평균 350g이라는 가설은 95% 신뢰구간에서 배제되지 않았다. 이 양측검정의 p값은 5%보다 커서 1%보다도 크다. 정확한 p값을 따로 계산하지 않아도 구간 포함 여부만으로 0.01과의 대소를 판단할 수 있다.
    4. 관측된 사과 49개에서 평균의 95% 신뢰구간은 349g부터 361g까지 뻗는다. 귀무값 350g이 구간 안이므로 양측검정의 p값은 0.05보다 크다. 따라서 p값이 0.03 미만이라는 수치 주장은 이 구간 정보와 함께 성립할 수 없다.

    표준오차 약 3.06 에서 검정통계량이 약 1.63 이라 유의확률은 약 0.10 으로 0.03 보다 작지 않으므로 유의확률이 0.03 보다 작다는 4번이 옳지 않다.

    알코올 중독자와 비중독자 간에 질병 A의 유병률이 차이가 있는지 알아보기 위해 어느 지역의 알코올 중독자와 비중독자 중에서 각각 76 명과 109 명을 임의추출하여 질병 A의 유무에 대한 다음과 같은 분할표를 얻었다. 중독 여부 질병 A의 유무중독자비중독자계있음532881없음2381104계76109185 분석 목적과 표집 과정을 고려할 때, 이 지역에 대한 설명으로 옳은 것은?

    1. 1. 알코올 중독자의 비율은 76/185 으로 추정된다.
    2. 2. 질병 A의 유병률은 81/185 로 추정된다.
    3. 3. 알코올 중독자 중에서 질병 A의 유병률은 53/76 으로 추정된다.
    4. 4. 질병 A의 유병자 중에서 알코올 중독자의 비율은 53/81 으로 추정된다.

    정답 3번

    🔍 보기별 해설
    1. 중독자 76명과 비중독자 109명은 집단별로 수를 정해 따로 뽑았다. 76/185를 지역 전체의 중독자 비율로 추정할 수 없으므로 옳지 않다.
    2. 질병이 있는 81명은 두 집단을 정해진 수로 뽑은 뒤 합한 값이다. 표본의 집단 구성비가 지역 전체와 같다는 보장이 없어 81/185는 전체 유병률 추정값으로 옳지 않다.
    3. 중독자 집단에서 임의추출한 76명 중 53명이 질병 A를 앓는다. 같은 집단 안의 조건부 유병률은 53/76으로 추정할 수 있으므로 옳다(정답).
    4. 질병 유병자 81명 가운데 중독자 53명이라는 표본 비율은 집단별 추출 수 76과 109에 좌우된다. 지역 전체 유병자 중 중독자 비율로 추정하면 옳지 않다.
    🧮 풀이
    1. 조사자는 지역의 실제 중독자 비율과 관계없이 중독자 76명, 비중독자 109명을 각각 뽑았다. 표본 전체 185명 중 76명이 중독자인 비율은 조사 설계에서 정해졌다. 이를 지역 주민 전체의 중독자 비율이라고 발표하면 표본 구성 방식을 인구 구성으로 오인하게 된다.

    X+Y=0 인 칸은 (1,−1) 과 (−1,1) 이고 E(X)=0 과 확률의 합 1 로 두 빈칸이 1/8 과 0 이라 P(X+Y=0)=1/8 이 되므로 옳은 것은 4번이다. 정답은 4번이다.

  • 34

    확률변수 X 에 대한 누적 확률 P (X ≤ x) 가 다음과 같을 때, 옳지 않은 것은?

    P (X ≤ x) = {0 (x < 0), {1 / 6} x (0 ≤ x < 2), {1 / 2} (2 ≤ x < 4), {1 / 6} x (4 ≤ x < 6), 1 (x ≥ 6)}

    1. 1. P (X ≤ a) = 1/4 을 만족시키는 a 의 값은 3/2 이다.
    2. 2. P (X = 3) = 0
    3. 3. P (X ≥ 5) = {2 / 3}
    4. 4. P (1 < X ≤ 4) = {1 / 2}

    정답 3번

    🔍 보기별 해설
    1. 0부터 2 미만에서는 누적확률이 x/6으로 직선처럼 증가한다. 이를 1/4로 놓으면 해당 구간의 x가 3/2가 되므로 옳다.
    2. 2부터 4 미만까지 누적확률은 일정하게 1/2로 유지된다. 3의 왼쪽과 오른쪽에서 함수가 뛰지 않아 점확률이 0이므로 옳다.
    3. 5에서 누적확률은 5/6이고 그 지점에 점확률은 없다. 5 이상일 확률은 1/6이므로 2/3이라는 식은 옳지 않다(정답).
    4. 4의 누적확률은 2/3이고 1의 누적확률은 1/6이다. 앞의 누적확률에서 뒤의 누적확률을 빼면 1보다 크고 4 이하인 범위가 1/2이므로 옳다.
    🧮 풀이
    1. 확률변수의 값이 0과 2 사이에 있을 때 누적확률은 x를 6으로 나눈 값이다. 누적확률이 1/4이 되는 위치를 찾으려고 x/6을 1/4과 같게 둔다. 양쪽에 6을 곱하면 x는 1.5가 되어 해당 구간 안에 들어간다.
    2. 누적분포함수는 x가 2를 넘은 뒤 4가 되기 전까지 1/2로 평평하다. x=3의 바로 왼쪽과 오른쪽에서 누적확률이 똑같다. 한 점에 확률이 있다면 함수가 그 위치에서 뛰어야 하므로 3의 확률은 0이다.
    3. x가 5일 때 누적확률은 5/6이다. 5 바로 왼쪽의 누적확률도 5/6이어서 정확히 5일 확률은 0이다. 5 이상에 남은 몫은 전체 1에서 5/6을 뺀 1/6이다.
    4. 1보다 크고 4 이하인 범위의 확률을 구한다. 4까지 쌓인 확률은 4/6인 2/3이고 1까지 쌓인 확률은 1/6이다. 두 누적확률을 빼면 3/6인 1/2이 남는다.

    P(X≥5)=1−P(X<5)=1−5/6=1/6 이므로 2/3 이라는 3번 설명이 옳지 않다. 정답은 3번이다.

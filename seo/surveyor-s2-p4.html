    상법(해상편)상 책임제한의 절차에 관한 규정이다. ( )에 들어갈 내용은?

    이 절의 규정에 따라 책임을 제한하고자 하는 자는 채권자로부터 책임한도액을 초과하는 청구금액을 명시한 서면에 의한 청구를 받은 날부터 ( ) 이내에 법원에 책임제한절차개시의 신청을 하여야 한다.

    1. 1. 1년
    2. 2. 2년
    3. 3. 3년
    4. 4. 5년

    정답 1번

    🔍 보기별 해설
    1. 상법은 초과 청구금액을 명시한 서면 청구를 받은 날부터 1년의 신청기간을 둔다. 기준 시점과 기간에 맞으므로 옳다(정답).
    2. 2년은 책임제한절차 개시 신청기간보다 길다. 서면 청구를 받은 날부터 1년이므로 옳지 않다.
    3. 3년은 발문의 책임제한절차 신청기한이 아니다. 법정 1년과 달라 옳지 않다.
    4. 5년은 책임제한절차를 법원에 신청할 수 있는 기간이 아니다. 청구서 수령일부터 1년이므로 옳지 않다.
    🧮 풀이
    1. 채권자가 책임한도액을 넘는 금액을 적은 서면을 선주 甲에게 보냈다. 甲은 받은 날짜를 기록하고 1년 이내 법원 신청 일정을 잡았다. 구두 연락 날짜와 서면 청구서 수령일을 구분했다.
    2. 선주 甲이 서면 청구를 받은 뒤 2년 동안 책임제한 신청을 미루려 했다. 법무 담당자가 법정 기간은 1년이라고 알려 줬다. 甲은 법원에 제출할 자료를 더 일찍 준비했다.
    3. 초과 청구서를 받은 선주 甲이 일반 채권의 기간을 떠올려 3년을 적었다. 책임제한절차는 서면 청구 수령일부터 1년 안에 신청해야 했다. 甲은 잘못된 일정표를 수정했다.
    4. 선주 甲이 책임제한절차를 5년 뒤에 신청해도 된다고 생각했다. 채권자의 서면 청구서에 찍힌 수령 날짜를 다시 확인했다. 甲은 그날부터 1년 안에 신청서를 법원에 냈다.

    책임한도액을 초과하는 서면 청구를 받은 날부터 1년 안에 법원에 책임제한절차 개시를 신청해야 한다. 따라서 1번이 정답이다.

    상법(해상편)상 용선자의 관리ㆍ지배 하에 선박을 운항할 목적으로 선박소유자가 용선자에게 선박을 제공할 것을 약정하고 용선자가 이에 따른 용선료를 지급하기로 약정함으로써 그 효력이 생기는 계약은?

    1. 1. 슬로트용선계약
    2. 2. 선체용선계약
    3. 3. 항해용선계약
    4. 4. 정기용선계약

    정답 2번

    🔍 보기별 해설
    1. 슬로트용선계약은 선박의 일정 적재 공간을 이용하는 계약이다. 선박 전체를 용선자가 관리·지배하는 형태가 아니므로 옳지 않다.
    2. 선체용선계약은 선박을 용선자의 관리·지배 아래 두고 운항하게 한다. 발문의 계약 정의와 같으므로 옳다(정답).
    3. 항해용선계약은 특정 항해에서 선박 전부나 일부를 운송에 제공한다. 용선자가 선박 자체를 지배하는 계약과 다르므로 옳지 않다.
    4. 정기용선계약은 일정 기간 선박의 운송 능력을 이용한다. 선박 자체의 관리·지배를 넘겨받는 선체용선과 다르므로 옳지 않다.
    🧮 풀이
    1. 해운사 甲이 다른 배의 컨테이너 적재 공간 일부를 빌렸다. 선박의 선장과 운항 관리는 원래 선주 측이 맡았다. 甲은 일정 슬롯을 이용하는 계약과 선체 전체를 지배하는 계약을 구분했다.
    2. 용선자 甲이 선박을 인도받아 선원을 고용하고 운항 계획을 직접 세웠다. 선박소유자에게 약정한 용선료를 지급했다. 배의 관리와 지배를 용선자가 맡는 선체용선계약이었다.
    3. 특정 항해에 화물을 대량으로 보내려는 화주 甲이 선박 공간을 확보했다. 선주는 선원과 항해장비를 갖춘 배로 그 항해를 수행했다. 甲이 선박 자체를 넘겨받아 관리하지는 않았다.
    4. 용선자 甲이 6개월 동안 선박의 운송 능력을 이용했다. 선장과 선박의 기술적 관리는 선주 측이 계속 담당했다. 기간을 정해 이용하는 정기용선과 선체용선을 계약서에서 구분했다.

    용선자가 선박을 관리·지배하며 운항하고 선박소유자에게 용선료를 주는 계약은 선체용선계약이다. 따라서 2번이 정답이다.

    선하증권의 법적 성질로 옳은 것을 모두 고른 것은?

    ㄱ. 문언증권성

    ㄴ. 처분증권성

    ㄷ. 제시증권성

    ㄹ. 무인증권성

    1. 1. ㄱ, ㄴ, ㄷ
    2. 2. ㄱ, ㄴ, ㄹ
    3. 3. ㄱ, ㄷ, ㄹ
    4. 4. ㄴ, ㄷ, ㄹ

    정답 1번

    🔍 보기별 해설
    1. 문언증권성은 선하증권에 적힌 내용에 따라 권리의 범위를 판단하는 성질이다. 선하증권의 법적 성질이므로 옳다.
    2. 처분증권성은 화물을 처분하려면 선하증권으로 권리를 행사해야 하는 성질이다. 선하증권의 법적 성질이므로 옳다.
    3. 제시증권성은 화물 인도를 청구할 때 선하증권을 제시해야 하는 성질이다. 선하증권의 법적 성질이므로 옳다.
    4. 무인증권성은 원인관계 없이 증권이 성립한다는 뜻이다. 화물 인수·선적을 전제로 하는 선하증권에는 맞지 않으므로 옳지 않다.
    🧮 풀이
    1. 선하증권을 넘겨받은 수하인 甲이 증권에 적힌 수량과 목적지를 읽었다. 운송물에 대한 권리 범위를 문서의 기재 내용에 따라 확인했다. 실제 화물 정보가 다르면 증권 문언과 대조해 다툼을 처리했다.
    2. 화주 甲이 운송 중인 화물의 권리를 다른 사람에게 넘기려 했다. 화물 창고에 직접 가지 않고 선하증권을 양도해 처분 절차를 진행했다. 증권을 가진 사람이 화물에 관한 권리를 행사했다.
    3. 목적지에 도착한 수하인 甲이 선하증권을 운송인에게 제시했다. 운송인은 증권의 정당한 소지자인지 확인한 뒤 화물을 내줬다. 甲은 증권을 보여 주지 않고 인도만 요구하지 않았다.
    4. 운송인이 아직 화물을 받지 않았는데 송하인 甲이 선하증권을 먼저 달라고 했다. 화물 인수 또는 선적이라는 발행 원인이 필요했다. 甲은 선하증권을 원인관계와 무관한 증권으로 취급하지 않았다.

    정답은 1번이다.

    1978년 함부르크 규칙상 총중량 1kg 당 책임한도액은?

    1. 1. 2 SDR
    2. 2. 2.5 SDR
    3. 3. 3 SDR
    4. 4. 3.5 SDR

    정답 2번

    🔍 보기별 해설
    1. 2 SDR(Special Drawing Rights)은 함부르크 규칙의 1kg당 책임한도보다 작다. 규정값 2.5와 달라 옳지 않다.
    2. 2.5 SDR(Special Drawing Rights)은 함부르크 규칙의 운송물 총중량 1kg당 책임한도다. 제시된 기준에 맞으므로 옳다(정답).
    3. 3 SDR(Special Drawing Rights)은 발문의 1kg당 한도보다 크다. 법정 2.5와 달라 옳지 않다.
    4. 3.5 SDR(Special Drawing Rights)은 함부르크 규칙의 1kg당 책임한도가 아니다. 제시된 값보다 크므로 옳지 않다.
    🧮 풀이
    1. 손상 화물의 총중량이 100kg이라 담당자 甲이 책임한도를 계산했다. 2 SDR(Special Drawing Rights)을 곱해 200이라고 적었다가 규정값을 확인했다. 甲은 2.5 SDR을 적용해 250 SDR로 수정했다.
    2. 손상된 화물 100kg의 책임한도를 담당자 甲이 계산했다. 함부르크 규칙의 1kg당 2.5 SDR(Special Drawing Rights)을 곱했다. 250 SDR을 관련 계산표에 기록하고 다른 한도 기준도 함께 비교했다.
    3. 담당자 甲이 100kg 화물에 3 SDR(Special Drawing Rights)을 곱해 300 SDR을 적었다. 규정의 중량당 한도는 2.5 SDR이었다. 甲은 250 SDR로 고쳐 화주에게 계산 근거를 설명했다.
    4. 화주 甲이 1kg당 3.5 SDR(Special Drawing Rights)을 주장했다. 운송인은 함부르크 규칙의 2.5 SDR 기준을 제시했다. 두 사람은 화물 총중량을 대조해 적용 한도를 다시 계산했다.

    함부르크 규칙의 운송인 책임한도는 운송물 총중량 1kg당 2.5 SDR이다. 따라서 2번이 정답이다.

    항만운송사업법령상 항만운송관련사업에 해당하지 않는 것은?

    1. 1. 항만용역업
    2. 2. 선용품공급업
    3. 3. 항만하역사업
    4. 4. 컨테이너 수리업

    정답 3번

    🔍 보기별 해설
    1. 항만용역업은 항만에서 선박에 용역을 제공하는 관련사업이다. 항만운송관련사업에 해당하므로 옳다.
    2. 선용품공급업은 선박에 필요한 물품을 공급하는 관련사업이다. 법령 분류에 해당하므로 옳다.
    3. 항만하역사업은 화물을 선박과 항만 사이에서 싣고 내리는 항만운송사업이다. 관련사업이 아니므로 옳지 않다(정답).
    4. 컨테이너수리업은 항만에서 컨테이너를 수리하는 관련사업이다. 항만운송관련사업에 해당하므로 옳다.
    🧮 풀이
    1. 입항 선박의 소독을 맡은 사업자 甲이 항만용역업 등록 범위를 확인했다. 선박에 필요한 서비스를 제공하고 작업 결과를 기록했다. 화물을 직접 싣고 내리는 하역사업과 구분했다.
    2. 선박에 식품과 부속품을 공급한 사업자 甲이 납품서에 수량을 적었다. 선용품공급업으로 등록한 업무 범위 안에서 물품을 전달했다. 부두의 화물을 선박에 싣는 사업과는 역할이 달랐다.
    3. 컨테이너선이 접안하자 하역업체의 작업자 甲이 크레인으로 상자를 내렸다. 업체는 항만하역사업자로서 화물 이동 작업을 수행했다. 선용품을 공급하거나 컨테이너를 수리하는 관련사업과 분류가 달랐다.
    4. 컨테이너 문이 부러져 수리업자 甲이 부품을 교체했다. 수리 뒤 문이 제대로 잠기는지 시험하고 작업 보고서를 냈다. 직접 화물을 하역하지 않아 컨테이너수리업으로 분류됐다.

    항만하역사업은 항만운송사업 자체로 분류된다. 항만운송관련사업이 아니므로 3번이 정답이다.

    컨테이너선에서 많이 사용되고 있는 해치 커버(Hatch cover) 형태는?

    1. 1. 폰툰형(Pontoon)
    2. 2. 싱글 풀형(Single pull)
    3. 3. 폴딩형(Folding)
    4. 4. 슬라이딩형(Sliding)

    정답 1번

    🔍 보기별 해설
    1. Pontoon(폰툰)형 해치 커버는 판을 통째로 들어 옮겨 화물창을 연다. 컨테이너선에서 많이 쓰이므로 옳다(정답).
    2. Single pull(싱글 풀)형은 여러 덮개 판을 한 번에 당겨 여는 방식이다. 발문이 묻는 대표적인 컨테이너선 형식이 아니므로 옳지 않다.
    3. Folding(폴딩)형은 덮개 판이 접히며 열리는 방식이다. 이 문항의 컨테이너선에서 많이 쓰이는 형식이 아니므로 옳지 않다.
    4. Sliding(슬라이딩)형은 덮개 판을 옆으로 밀어 여는 방식이다. 발문의 대표 형식과 다르므로 옳지 않다.
    🧮 풀이
    1. 컨테이너선 화물창을 열기 위해 작업자 甲이 크레인으로 Pontoon(폰툰)형 덮개를 들어 올렸다. 통째로 떼어 둔 뒤 상자를 화물창에 내려놓았다. 작업 후 덮개를 다시 얹고 고정했다.
    2. 해치 커버 여러 판이 연결된 선박에서 작업자 甲이 Single pull(싱글 풀) 장치를 당겼다. 연결된 판이 차례로 이동하며 화물창이 열렸다. 통째로 들어 치우는 폰툰형과 작업 방식이 달랐다.
    3. 작업자 甲이 Folding(폴딩)형 해치 커버의 판을 접어 올렸다. 판이 접히면서 창 옆에 모였다. 크레인으로 덮개 전체를 들어 옮기는 폰툰형과 비교해 필요한 장비를 구분했다.
    4. 작업자 甲이 Sliding(슬라이딩)형 덮개를 레일을 따라 옆으로 밀었다. 판이 옆 공간에 이동해 화물창이 열렸다. 들어 올리는 폰툰형과 달라 작업 구역을 따로 확보했다.

    성공적인 내부 마케팅을 위한 요건이 아닌 것은?

    1. 1. 전략적 관리의 주요한 부분으로 인식되어야 한다.
    2. 2. 조직구조나 경영층 지원의 부족으로 방해받지 않아야 한다.
    3. 3. 고객의 역할과 중요성을 인식하는 것에서 시작한다.
    4. 4. 최고경영층의 적극적인 지원이 필요하다.

    정답 3번

    🔍 보기별 해설
    1. 전략적 관리의 주요한 부분으로 인식되어야 한다는 설명은 내부마케팅의 요건에 해당하므로 옳다.
    2. 조직구조나 경영층 지원 부족으로 방해받지 않아야 한다는 설명도 내부마케팅 요건에 해당하므로 옳다.
    3. 고객의 역할과 중요성 인식에서 시작한다는 설명은 직원을 대상으로 하는 내부마케팅의 요건이 아니므로 옳지 않다(정답).
    4. 최고경영층의 적극적 지원이 필요하다는 설명도 내부마케팅 요건에 해당하므로 옳다.
    🧮 풀이
    1. A호텔 경영진은 내부마케팅을 연간 전략 계획의 핵심 과제로 올려 예산과 인력을 배정했다.
    2. A호텔 총지배인은 내부마케팅 프로그램에 경영층 지원이 끊기지 않도록 직접 점검했다.
    3. A호텔은 내부마케팅을 직원 교육으로 시작하려 했는데, 실제로는 고객 응대 매뉴얼부터 만들어 직원이 아니라 고객을 먼저 들여다본 셈이 되었다.
    4. A호텔 대표는 내부마케팅 캠페인을 직접 발표하며 전사적 지원을 약속했다.

    내부마케팅은 직원을 대상으로 하는 활동이라 고객 인식에서 시작하는 것이 요건이 아니므로, 정답은 3번이다.

    관계마케팅의 특성이 아닌 것은?

    1. 1. 차별화 및 관리의 초점을 상품에 집중한다.
    2. 2. 다양한 수단을 통해 양방향 커뮤니케이션을 강조한다.
    3. 3. 규모의 경제에서 범위의 경제로의 전환이다.
    4. 4. 고객점유율이 마케팅 성과 측정의 지표이다.

    정답 1번

    🔍 보기별 해설
    1. 차별화와 관리의 초점을 상품에 집중한다는 설명은 관계마케팅이 아니라 상품중심 마케팅의 특징이므로 옳지 않다(정답).
    2. 다양한 수단으로 양방향 커뮤니케이션을 강조한다는 설명은 관계마케팅의 특성에 해당하므로 옳다.
    3. 규모의 경제에서 범위의 경제로의 전환이라는 설명도 관계마케팅의 특성에 해당하므로 옳다.
    4. 고객점유율이 마케팅 성과 측정 지표라는 설명도 관계마케팅의 특성에 해당하므로 옳다.
    🧮 풀이
    1. A호텔은 마케팅 초점을 신상품 스펙 홍보에만 맞췄는데, 이는 관계마케팅이 아니라 상품중심 마케팅이었다.
    2. A호텔은 고객과 문자·이메일·앱으로 양방향 소통을 이어가는 관계마케팅을 펼쳤다.
    3. A호텔은 대량판매 중심에서 다양한 서비스 범위를 넓히는 쪽으로 마케팅 방향을 바꿨다.
    4. A호텔은 재방문 고객이 전체 숙박에서 차지하는 비율인 고객점유율을 성과지표로 삼았다.

    관계마케팅은 상품이 아니라 고객관계에 초점을 두므로, 정답은 1번이다.

    촉진믹스의 특징으로 옳지 않은 것은?

    1. 1. 광고: 신속, 메시지 통제 가능
    2. 2. 인적판매: 즉각적인 피드백, 낮은 비용
    3. 3. 판매촉진: 모방용이, 즉시적 효과
    4. 4. 홍보(PR): 높은 신뢰성, 간접적 효과

    정답 2번

    🔍 보기별 해설
    1. 광고가 신속하고 메시지 통제가 가능하다는 설명은 맞으므로 옳다.
    2. 인적판매는 즉각적 피드백은 맞지만 비용이 낮은 것이 아니라 높은 수단인데, 낮은 비용이라고 적어 옳지 않다(정답).
    3. 판매촉진이 모방이 쉽고 즉시적 효과가 있다는 설명은 맞으므로 옳다.
    4. 홍보(PR)가 신뢰성이 높고 간접적 효과를 낸다는 설명도 맞으므로 옳다.
    🧮 풀이
    1. A호텔은 광고를 내보내 짧은 시간에 원하는 메시지를 그대로 전달했다.
    2. A호텔은 영업사원을 투입한 인적판매로 즉각적인 반응을 얻었지만, 인건비 부담이 다른 촉진수단보다 훨씬 컸다.
    3. A호텔의 할인쿠폰 행사는 경쟁사가 금방 따라할 수 있었지만 즉시 매출 효과를 냈다.
    4. A호텔을 소개한 언론 기사는 광고보다 신뢰를 얻었지만 메시지를 직접 통제하지는 못했다.

    인적판매는 즉각적 피드백은 있지만 비용이 낮지 않고 오히려 높은 수단이므로, 정답은 2번이다.

    갭 모델(Gap Model)에서 차이 해소를 위한 해결방안으로 옳지 않은 것은?

    1. 1. GAP I: 시장조사의 시행
    2. 2. GAP II: 서비스 업무의 표준화
    3. 3. GAP III: 팀워크 향상
    4. 4. GAP IV: 수직적 커뮤니케이션 증대

    정답 4번

    🔍 보기별 해설
    1. GAP I의 해결방안으로 시장조사를 시행한다는 설명은 맞으므로 옳다.
    2. GAP II의 해결방안으로 서비스 업무를 표준화한다는 설명도 맞으므로 옳다.
    3. GAP III의 해결방안으로 팀워크를 향상한다는 설명도 맞으므로 옳다.
    4. GAP IV(외부 커뮤니케이션 갭)의 해결방안은 수직적이 아니라 수평적 커뮤니케이션 증대이므로, 수직적이라고 적은 이 선택지는 옳지 않다(정답).
    🧮 풀이
    1. A호텔 경영진은 손님들이 넓은 객실을 원한다고 여겼지만, 투숙객 설문을 해 보니 손님들은 빠른 체크인을 더 원했다. 시장조사로 고객의 기대를 알아내자 GAP I이 줄었다.
    2. A호텔은 「친절하게 응대한다」는 막연한 지침 대신 「전화는 세 번 울리기 전에 받는다」처럼 업무를 표준화했다. 기준이 분명해지자 GAP II가 줄었다.
    3. A호텔 매뉴얼에는 「체크인 전 객실 정비 완료」가 있었지만, 프런트와 하우스키핑이 서로 미뤄 자주 늦었다. 두 부서를 한 팀으로 묶자 정비가 제시간에 끝나 GAP III가 줄었다.
    4. A호텔 광고는 「24시간 룸서비스」를 내걸었지만 주방은 밤 11시에 문을 닫았다. 위에서 지시만 내려보내서는 바뀌지 않았고, 광고팀과 주방이 직접 회의하는 수평적 소통을 늘리자 광고가 실제 운영 시간에 맞게 고쳐졌다.

    GAP IV는 수직적이 아니라 수평적 커뮤니케이션 증대로 해소하므로, 정답은 4번이다.

    매체유형의 특징으로 옳지 않은 것은?

    1. 1. TV: 우수한 대량 시장 커버리지, 높은 비용
    2. 2. 신문: 지역시장 커버리지, 낮은 재생품질
    3. 3. 라디오: 낮은 비용, 짧은 노출기간
    4. 4. 인터넷: 일방적 의사소통, 높은 비용

    정답 4번

    🔍 보기별 해설
    1. TV가 대량 시장 커버리지와 높은 비용을 특징으로 한다는 설명은 맞으므로 옳다.
    2. 신문이 지역시장 커버리지와 낮은 재생품질을 특징으로 한다는 설명도 맞으므로 옳다.
    3. 라디오가 낮은 비용과 짧은 노출기간을 특징으로 한다는 설명도 맞으므로 옳다.
    4. 인터넷은 일방적이 아니라 양방향 의사소통이 가능한 매체인데, 일방적이라고 적어 옳지 않다(정답).
    🧮 풀이
    1. A호텔은 TV 광고로 전국 시청자에게 한꺼번에 메시지를 전했지만 비용이 많이 들었다.
    2. A호텔은 지역 신문에 광고를 실어 인근 고객에게만 전했는데 인쇄 품질은 떨어졌다.
    3. A호텔은 라디오 광고로 비용을 아꼈지만 노출 시간이 짧아 자주 반복해야 했다.
    4. A호텔은 홈페이지와 SNS로 고객의 댓글과 문의에 바로 답하는 양방향 소통을 했다.

    인터넷은 양방향 의사소통이 가능한 매체이므로, 정답은 4번이다.

    유통경로의 기능이 아닌 것은?

    1. 1. 제품생산 기능
    2. 2. 정보수집 기능
    3. 3. 수급조절 기능
    4. 4. 위험부담 기능

    정답 1번

    🔍 보기별 해설
    1. 제품생산 기능은 유통경로의 기능이 아니라 제조업자의 역할이므로 옳지 않다(정답).
    2. 정보수집 기능은 유통경로의 기능에 해당하므로 옳다.
    3. 수급조절 기능도 유통경로의 기능에 해당하므로 옳다.
    4. 위험부담 기능도 유통경로의 기능에 해당하므로 옳다.
    🧮 풀이
    1. A호텔이 거래하는 식자재 유통업체는 재료를 직접 생산하지 않고 공급만 맡았다.
    2. A호텔 유통업체는 시장 수요 정보를 모아 공급량을 조절했다.
    3. A호텔 유통업체는 성수기와 비수기의 수급 차이를 조절해 재고를 관리했다.
    4. A호텔 유통업체는 재고가 남을 위험을 떠안고 미리 물량을 확보했다.

    제품생산은 유통경로가 아니라 제조업자의 역할이므로, 정답은 1번이다.

    소비자들이 제품가격의 고·저를 평가할 때 비교기준으로 사용하는 가격은?

    1. 1. 단수가격(odd price)
    2. 2. 기대가격(expectation price)
    3. 3. 준거가격(reference price)
    4. 4. 촉진가격(promotional price)

    정답 3번

    🔍 보기별 해설
    1. 단수가격은 끝수를 낮춰 심리적으로 싸게 느끼게 하는 가격이라 비교기준과는 다르므로 옳지 않다.
    2. 기대가격은 소비자가 미리 예상하는 가격이라 비교기준으로 쓰는 가격과는 다르므로 옳지 않다.
    3. 소비자가 가격의 고저를 판단하는 비교기준으로 쓰는 가격은 준거가격이므로 옳다(정답).
    4. 촉진가격은 판촉을 위해 한시적으로 낮춘 가격이라 비교기준과는 다르므로 옳지 않다.
    🧮 풀이
    1. A호텔은 9,900원처럼 끝수를 낮춘 단수가격으로 식음료 메뉴를 표시했다.
    2. A호텔 투숙객은 성수기 요금이 이 정도일 것이라고 미리 예상한 기대가격을 갖고 있었다.
    3. A호텔 투숙객은 평소 알던 동급 호텔 요금을 준거가격으로 삼아 이번 요금이 비싼지 판단했다.
    4. A호텔은 비수기에 한시적으로 깎은 촉진가격으로 예약을 유도했다.

    소비자가 가격의 고저를 비교하는 기준이 되는 가격은 준거가격이므로, 정답은 3번이다.

    2. 2024년 6월, 그 호텔이 응대 절차를 구체적인 표준으로 정리해 교육에 활용했다.
    3. 2023년 12월, 영업팀과 운영팀 사이의 소통이 어긋나 광고 내용과 실제 서비스가 달라진 사례가 GapⅣ로 소개됐다.
    4. 2024년 9월, 고객 설문 결과를 받아 서비스 기준을 다시 손본 호텔이 있었다.

    부적절한 수평적 커뮤니케이션은 GapⅡ가 아니라 GapⅣ의 원인이므로, 정답은 3번이다.

  • 73

    감성마케팅에 관한 효과로 옳지 않은 것은?

    1. 1. 고객 감성을 자극하여 호의적인 반응을 유도
    2. 2. 고객에게 제품을 보다 친근감 있게 접근하는 효과
    3. 3. 시각적, 개념적 놀라움을 제공하여 고객의 관심 유도
    4. 4. 감성적인 자극을 통해 고객과 유대관계 강화

    정답 3번

    🔍 보기별 해설
    1. 고객 감성을 자극해 호의적인 반응을 유도하는 것은 감성마케팅의 효과이므로 옳다.
    2. 고객에게 제품을 더 친근하게 접근하는 효과도 감성마케팅의 효과이므로 옳다.
    3. 시각적·개념적 놀라움을 제공해 관심을 유도하는 것은 감성마케팅보다 체험·게릴라 마케팅의 효과에 더 가까우므로, 감성마케팅의 효과라고 적은 이 설명은 옳지 않다.
    4. 감성적 자극으로 고객과 유대관계를 강화하는 것도 감성마케팅의 효과이므로 옳다.
    🧮 풀이
    1. 2024년 2월, 한 호텔 광고가 가족 간의 정을 담아 손님들의 마음을 움직였다.
    2. 2024년 4월, 다정한 문구를 담은 안내문으로 손님이 호텔을 더 친근하게 느꼈다.
    3. 2023년 10월, 로비에 깜짝 설치물을 꾸며 손님의 눈길을 끈 호텔 행사가 체험 마케팅의 예로 소개됐다.
    4. 2024년 7월, 단골 손님에게 손편지를 보내 유대감을 다진 호텔이 있었다.

    시각적·개념적 놀라움으로 관심을 유도하는 효과는 감성마케팅보다 체험·게릴라 마케팅에 더 가까우므로, 정답은 3번이다.

    고객관계관리(CRM, Customer Relationship Management)에 관한 설명으로 옳지 않은 것은?

    1. 1. 고객별로 맞춤서비스를 제공하여 고객 만족도 증가
    2. 2. 수준 높은 고객 지식을 축적하여 경쟁사와의 차별화
    3. 3. 업셀링(up-selling)으로 고객 당 수익 극대화
    4. 4. 기존고객의 유지보다는 신규고객 창출에 유리

    정답 4번

    🔍 보기별 해설
    1. 고객 정보를 활용해 맞춤서비스를 제공한다. 옳다.
    2. 고객 지식을 축적하면 경쟁사와 차별화할 수 있다. 옳다.
    3. 상위 상품을 제안하는 업셀링으로 고객당 수익을 높일 수 있다. 옳다.
    4. 기존 고객 유지보다 신규 고객 창출에 유리하다는 설명은 CRM의 초점과 다르다. 옳지 않다(정답).
    🧮 풀이
    1. 호텔이 손님의 조용한 객실 선호를 기록했다. 다음 방문 때 맞춤 객실을 제시했다
    2. 호텔이 재방문 손님의 요청 이력을 쌓았다. 경쟁 호텔이 모르는 선호를 서비스에 반영했다
    3. 호텔이 일반 객실 예약 손님에게 스위트 업그레이드를 제안했다. 손님이 수락해 고객당 수익이 늘었다
    4. 호텔이 기존 고객 기록을 버리고 새 광고에만 예산을 썼다. 관계 유지라는 CRM의 중심 활동과 달랐다

    정답은 4번이다.

    다음에서 설명하는 웹을 이용한 광고 마케팅전략은? ○ 네티즌이 자발적으로 제품 정보를 확산시키는 방식 ○ 간접 광고 효과가 있음 ○ 대중매체에 이슈를 만들고, 스토리텔링을 만들어 접근하는 전략

    1. 1. 배너광고
    2. 2. 제휴마케팅
    3. 3. PPC(pay-per-click)광고
    4. 4. 바이럴 마케팅

    정답 4번

    🔍 보기별 해설
    1. 배너광고는 웹페이지에 정해진 광고 지면을 사서 노출한다. 해당하지 않는다.
    2. 제휴마케팅은 외부 파트너의 판매·추천 성과에 따라 보상한다. 해당하지 않는다.
    3. PPC광고는 클릭이 발생할 때 광고비를 낸다. 해당하지 않는다.
    4. 바이럴 마케팅은 이용자가 정보를 자발적으로 퍼뜨리게 한다. 해당한다(정답).
    🧮 풀이
    1. 호텔이 여행 사이트 상단 배너 지면을 샀다. 돈을 내고 광고를 노출했다
    2. 호텔이 여행 블로거의 예약 링크 실적에 따라 수수료를 줬다. 제휴마케팅이다
    3. 호텔이 검색광고 클릭 수에 따라 비용을 냈다. 클릭당 과금하는 PPC다
    4. 호텔이 지역 축제 영상을 올렸다. 이용자들이 스스로 공유해 입소문이 퍼졌다

    정답은 4번이다.

    정강넙다리관절(tibiofemoral joint) 가동화(mobilization) 기법과 기대되는 효과의 연결이 옳은 것은?

    1. 1. 넙다리뼈(femur)를 기준으로 정강뼈(tibia)의 앞쪽(anterior) 활주(glide) / 무릎 굽힘(flexion) 증가
    2. 2. 넙다리뼈를 기준으로 정강뼈의 뒤쪽(posterior) 활주 / 무릎 폄(extension) 증가
    3. 3. 정강뼈를 기준으로 넙다리뼈의 앞쪽 활주 / 무릎 굽힘 증가
    4. 4. 정강뼈를 기준으로 넙다리뼈의 뒤쪽 활주 / 무릎 굽힘 증가

    정답 3번

    🔍 보기별 해설
    1. 넙다리뼈 고정 시 정강뼈(오목면)를 앞쪽으로 활주시키면 무릎 폄이 증가한다(굽힘 증가로 연결한 것은 맞지 않음). 옳지 않다.
    2. 오목-볼록 법칙상 정강뼈를 넙다리뼈에 대해 뒤쪽으로 활주시키면 무릎 굽힘 가동범위가 늘어나므로, 이를 무릎 폄 증가와 연결한 것은 맞지 않는다. 옳지 않다.
    3. 정강뼈를 고정하고 넙다리뼈(볼록면)를 앞쪽으로 활주시키면 무릎 굽힘 가동범위가 증가한다(볼록–오목 법칙). 옳다(정답).
    4. 정강뼈 고정 시 넙다리뼈를 뒤쪽으로 활주시키면 무릎 폄이 증가하므로 '굽힘 증가'는 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 환자가 무릎을 굽힐 때 관절이 뻣뻣하다. 치료사가 넙다리뼈를 고정하고 정강뼈를 앞쪽으로 밀면 주로 무릎 폄을 돕는 방향이다. 굽힘 증가라고 적은 ①은 움직이는 뼈에 따른 활주 방향을 혼동했다.
    2. 무릎 폄이 제한된 환자에게 치료사가 넙다리뼈를 기준으로 정강뼈를 뒤쪽으로 밀어 본다. 그 방향은 굽힘에 필요한 활주와 관련된다. 폄을 늘리는 방법이라고 적으면 정강뼈의 앞뒤 방향이 뒤바뀐다.
    3. 정강뼈를 안정적으로 고정한 상태에서 치료사가 넙다리뼈를 앞쪽으로 활주한다. 환자의 무릎 굽힘 범위가 더 열리는지 확인한다. 검사 기록에는 고정한 뼈와 움직인 뼈를 각각 적는다.
    4. 정강뼈를 기준으로 넙다리뼈를 뒤쪽으로 활주시키는 치료를 상상한다. 이 방향은 앞쪽 활주가 필요한 무릎 굽힘 증가와 맞지 않는다. 담당자는 뼈의 이름뿐 아니라 어느 쪽으로 밀었는지도 기록한다.

    정강뼈를 기준으로 넙다리뼈를 앞쪽으로 활주시키면 무릎 굽힘 가동범위를 늘릴 수 있다. 기준 뼈와 방향이 맞는 ③이 옳다.

    수동적(passive) 관절운동범위(range of motion)에 관한 정상 끝느낌(end-feel)의 연결이 옳은 것은? (끝느낌 / 구조 / 예시)

    1. 1. 부드러움(soft) / 관절주머니(capsular)의 신장 / 손가락 손허리손가락관절의 폄
    2. 2. 팽팽함(firm) / 근육의 신장 / 무릎관절 폄 상태에서 엉덩이관절 굽힘
    3. 3. 팽팽함 / 뼈와 뼈의 접촉 / 팔꿈치 폄
    4. 4. 단단함(hard) / 연부조직 근접(tissue approximation) / 무릎관절 굽힘

    정답 2번

    🔍 보기별 해설
    1. 부드러운 끝느낌은 '연부조직 근접'에서 나온다. '관절주머니 신장'은 팽팽한(firm) 끝느낌이므로 연결이 맞지 않는다. 옳지 않다.
    2. 팽팽한(firm) 끝느낌은 근육·관절낭의 신장에서 나오며, 무릎을 편 채 엉덩관절을 굽히면(햄스트링 신장) 나타난다. 옳다(정답).
    3. 팔꿈치를 완전히 펼 때처럼 뼈와 뼈가 직접 맞닿아 멈추는 정상 끝느낌은 갑작스럽고 단단한(hard) 느낌이며, 인대·힘줄이 늘어날 때의 팽팽한(firm) 느낌과는 다르다. 옳지 않다.
    4. 단단한(hard) 끝느낌은 뼈–뼈 접촉인데, '연부조직 근접·무릎 굽힘'은 부드러운(soft) 끝느낌이라 연결이 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 손가락 손허리손가락관절을 끝까지 펴면 관절주머니와 인대가 당겨진다. 검사자가 느끼는 것은 부드러운 조직끼리 닿는 끝느낌이 아니라 단단히 팽팽해지는 저항이다. 구조와 느낌을 함께 보아야 한다.
    2. 환자가 무릎을 편 채 누워 있고 검사자가 다리를 들어 엉덩관절을 굽힌다. 뒤넙다리근이 늘어나 더 이상 움직이기 어려운 팽팽한 저항이 생긴다. 근육 신장과 팽팽한 끝느낌의 연결이다.
    3. 팔꿈치를 끝까지 펴면 위팔뼈와 자뼈의 뼈 구조가 맞닿는다. 검사자는 뚜렷하고 단단한 끝느낌을 느낀다. 뼈끼리 닿는 장면을 팽팽한 근육 신장 느낌이라고 적으면 종류가 다르다.
    4. 무릎을 끝까지 굽힐 때 넙다리 뒤쪽과 종아리 조직이 서로 가까워진다. 검사자는 연부조직이 맞닿는 부드러운 끝느낌을 느낀다. 뼈끼리 부딪히는 단단함으로 적으면 구조와 감각이 맞지 않는다.

    무릎을 편 채 엉덩관절을 굽히면 뒤넙다리근이 늘어나 팽팽한 끝느낌이 난다. 구조와 예시를 맞게 연결한 ②가 옳다.

    엉덩관절(hip joint) 및 엉치엉덩관절(sacroiliac joint)의 병리 확인을 위한 패트릭(Patrick) 검사의 자세로 옳은 것은?

    1. 1. 엉덩관절 굽힘(flexion), 엉덩관절 벌림(abduction), 엉덩관절 가쪽돌림(external rotation)
    2. 2. 엉덩관절 굽힘, 엉덩관절 모음(adduction), 엉덩관절 안쪽돌림(internal rotation)
    3. 3. 무릎관절 굽힘, 엉덩관절 벌림, 엉덩관절 안쪽돌림
    4. 4. 무릎관절 굽힘, 엉덩관절 모음, 엉덩관절 가쪽돌림

    정답 1번

    🔍 보기별 해설
    1. 패트릭 검사(FABER)는 엉덩관절을 굽힘(Flexion)·벌림(ABduction)·가쪽돌림(External Rotation)한 자세로 시행한다. 옳다(정답).
    2. 패트릭 검사는 굽힘·벌림·가쪽돌림 자세인데, 모음·안쪽돌림은 벌림·가쪽돌림과 정반대 방향이라 검사 자세가 될 수 없다. 옳지 않다.
    3. 패트릭 검사는 엉덩관절을 가쪽으로 돌리는 자세인데 여기에는 안쪽돌림이 들어 있어, 돌림 방향이 반대라 FABER 자세와 맞지 않는다. 옳지 않다.
    4. 패트릭 검사는 다리를 바깥으로 벌리는 벌림 자세인데 여기에는 모음이 들어 있어, 벌림과 반대라 검사 자세로 성립하지 않는다. 옳지 않다.
    🧮 풀이
    1. 환자가 누운 상태에서 한쪽 발을 반대쪽 무릎 위에 올린다. 검사자는 엉덩관절이 굽혀지고 벌어지며 바깥쪽으로 도는 자세를 만든다. 이 FABER 자세에서 엉덩관절과 엉치엉덩관절의 통증을 살핀다.
    2. 엉덩관절을 굽힌 뒤 다리를 몸 가운데로 모으고 안쪽으로 돌리면 다른 방향의 검사 자세가 된다. 패트릭 검사의 벌림·가쪽돌림과 반대다. 담당자는 통증이 생기는 위치도 함께 기록해 검사 이름만 외우지 않는다.
    3. 환자의 무릎은 굽힌 상태지만 엉덩관절을 안쪽으로 돌린다. 패트릭 검사는 무릎 굽힘 자체가 아니라 엉덩관절의 굽힘·벌림·가쪽돌림 조합으로 정의된다. 마지막 돌림 방향이 달라 이 자세는 맞지 않는다.
    4. 무릎을 굽히고 엉덩관절을 몸 중심으로 모으는 자세를 취한다. 패트릭 검사에서는 다리를 바깥으로 벌린다. 가쪽돌림이 맞더라도 모음이 들어가면 세 방향의 조합이 완성되지 않는다.

    패트릭 검사 자세는 엉덩관절의 굽힘·벌림·가쪽돌림을 합친 FABER다. 세 방향이 맞는 ①이 옳다.

    〈보기〉에서 특수검사(special test)에 관한 설명으로 옳은 것만을 모두 고른 것은? ㄱ. 다이알(dial) 검사: 돌림근띠(rotator cuff) 손상 평가 ㄴ. 켄달(Kendall) 검사: 넙다리곧은근(rectus femoris) 손상 평가 ㄷ. 루딩턴(Ludington) 검사: 위팔두갈래근(biceps brachii) 손상 평가 ㄹ. 후버(Hoover) 검사: 뒤정강근(tibialis posterior) 손상 평가

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄷ, ㄹ

    정답 3번

    🔍 보기별 해설
    1. ㄱ. 다이알 검사는 엎드린 자세에서 발을 바깥으로 돌려 무릎 뒤가쪽 회전 불안정을 확인하는 검사이므로, 어깨의 돌림근띠(rotator cuff) 손상 평가와는 관계가 없다. 옳지 않다.
    2. ㄴ. 켄달 검사는 엎드려 무릎을 굽혔을 때 넙다리곧은근이 당겨 엉덩이가 들리는 정도를 보아 이 근육의 유연성·구축을 평가한다. 옳다.
    3. ㄷ. 루딩턴 검사는 양손을 머리 뒤로 깍지 껴 위팔두갈래근을 수축시켜 긴갈래 힘줄의 파열 여부를 확인하는 검사이므로, 설명과 연결이 옳다. 옳다.
    4. ㄹ. 후버 검사는 한쪽 다리를 들 때 반대쪽 발꿈치가 눌리는지로 환자가 실제로 힘을 쓰는지(꾀병 여부)를 판별하는 검사이므로, 뒤정강근 손상 평가와는 관계가 없다. 옳지 않다.
    🧮 풀이
    1. 무릎 뒤가쪽의 인대 손상을 의심하는 검사자가 다이알 검사를 시행한다. 다리를 바깥쪽으로 돌려 좌우 회전 차이를 비교한다. 어깨의 돌림근띠 힘줄을 평가하는 검사로 붙이면 신체 부위가 다르다.
    2. 엎드린 환자가 무릎을 굽힐 때 골반이 들리거나 넙다리 앞쪽이 당긴다. 검사자는 켄달 검사로 넙다리곧은근의 길이와 기능 문제를 살핀다. 무릎과 엉덩관절을 모두 지나는 근육의 특징을 활용한다.
    3. 환자가 양손을 머리 뒤로 얹고 위팔두갈래근을 수축한다. 검사자는 양쪽 근육 배의 모양과 파열 징후를 관찰한다. 루딩턴 검사는 위팔두갈래근 손상 평가에 연결된다.
    4. 후버 검사는 다리 힘을 주는 과정의 진정성이나 신경학적 약화를 살피는 방법으로 쓰인다. 검사자는 한쪽 다리를 들 때 반대쪽 발뒤꿈치의 누르는 힘을 확인한다. 뒤정강근 손상 검사로 이름을 붙이면 목적이 다르다.

    정답은 3번이다.

    발목관절(talocrural joint) 가동화(mobilization) 기법과 기대되는 효과의 연결이 옳은 것은?

    1. 1. 정강뼈(tibia)를 기준으로 목말뼈(talus)의 뒤쪽(posterior) 활주(glide) / 발등 굽힘(dorsiflexion) 증가
    2. 2. 정강뼈를 기준으로 목말뼈의 앞쪽(anterior) 활주 / 발등 굽힘 증가
    3. 3. 목말뼈를 기준으로 정강뼈의 뒤쪽 활주 / 발등 굽힘 증가
    4. 4. 목말뼈를 기준으로 정강뼈의 앞쪽 활주 / 발바닥 굽힘(plantar flexion)의 증가

    정답 1번

    🔍 보기별 해설
    1. 정강뼈를 고정하고 볼록한 목말뼈를 '뒤쪽'으로 활주시키면 발등 굽힘 범위가 증가한다(볼록–오목 법칙). 옳다(정답).
    2. 볼록한 목말뼈를 정강뼈에 대해 앞쪽으로 활주시키면 발바닥 굽힘(발끝을 내리는 움직임)이 늘어나므로, 이를 발등 굽힘 증가와 연결한 것은 맞지 않는다. 옳지 않다.
    3. 발목관절 가동화는 고정된 정강뼈에 대해 목말뼈를 움직이는 것이 원칙인데, 이 보기는 정강뼈를 뒤쪽으로 활주시킨다고 하여 기법 기준과 발등 굽힘 효과의 연결이 맞지 않는다. 옳지 않다.
    4. 발목관절 가동화는 정강뼈를 고정하고 목말뼈를 움직이는 것이 기준인데, 이 보기는 목말뼈를 기준으로 정강뼈를 움직인다고 하여 기법 기준과 발바닥 굽힘 효과의 연결이 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 발목을 위쪽으로 젖히기 어려운 환자의 정강뼈를 치료사가 고정한다. 목말뼈를 뒤쪽으로 부드럽게 활주시키며 발등굽힘 범위를 다시 잰다. 뒤쪽 활주와 발등굽힘 증가의 연결이다.

    3. 환자가 등을 대고 누워 두 다리를 약간 든 채 버틴다. 밀그램 검사에서 요추 구조에 부담이 실려 통증이 재현되는지 확인한다. 담당자는 다리의 근력만이 아니라 허리 병변의 가능성을 함께 평가한다.

    정답은 3번이다.

    〈보기〉에서 ㉠~㉣에 관한 설명으로 옳은 것만을 고른 것은? ㉠ - 부하 제거 시 원래 상태로 회복 가능한 영역 ㉡ - 조직이 탄성 반응을 시작하는 지점 ㉢ - 영구 변형이 발생하는 영역 ㉣ - 부하 제거 시 조직의 기계적 회복 지점

    4. 조직이 큰 힘에 늘어나 파단에 가까워지는 ㉣ 지점을 본다. 이 수준에서는 이미 영구 변형이 진행될 수 있다. 검사자는 힘을 뺐을 때 원상 복구되는 기계적 회복 지점으로 해석하지 않는다.

    정답은 1번이다.

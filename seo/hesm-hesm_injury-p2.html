    정강넙다리관절(tibiofemoral joint) 가동화(mobilization) 기법과 기대되는 효과의 연결이 옳은 것은?

    1. 1. 넙다리뼈(femur)를 기준으로 정강뼈(tibia)의 앞쪽(anterior) 활주(glide) / 무릎 굽힘(flexion) 증가
    2. 2. 넙다리뼈를 기준으로 정강뼈의 뒤쪽(posterior) 활주 / 무릎 폄(extension) 증가
    3. 3. 정강뼈를 기준으로 넙다리뼈의 앞쪽 활주 / 무릎 굽힘 증가
    4. 4. 정강뼈를 기준으로 넙다리뼈의 뒤쪽 활주 / 무릎 굽힘 증가

    정답 3번

    🔍 보기별 해설
    1. 넙다리뼈 고정 시 정강뼈(오목면)를 앞쪽으로 활주시키면 무릎 폄이 증가한다(굽힘 증가로 연결한 것은 맞지 않음). 옳지 않다.
    2. 오목-볼록 법칙상 정강뼈를 넙다리뼈에 대해 뒤쪽으로 활주시키면 무릎 굽힘 가동범위가 늘어나므로, 이를 무릎 폄 증가와 연결한 것은 맞지 않는다. 옳지 않다.
    3. 정강뼈를 고정하고 넙다리뼈(볼록면)를 앞쪽으로 활주시키면 무릎 굽힘 가동범위가 증가한다(볼록–오목 법칙). 옳다(정답).
    4. 정강뼈 고정 시 넙다리뼈를 뒤쪽으로 활주시키면 무릎 폄이 증가하므로 '굽힘 증가'는 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 예: 치료사 甲이 환자의 정강뼈를 넙다리뼈에 대해 앞쪽으로 밀어 주는 가동화를 시행하자, 무릎이 이전보다 한결 잘 펴지게 된다.
    2. 甲이 정강뼈를 넙다리뼈에 대고 뒤쪽으로 밀어 활주시키면 무릎 굽힘 범위가 늘어나지 폄이 늘어나는 것이 아니다.
    3. 예: 정강뼈를 고정한 채 넓적다리뼈를 앞으로 밀어 무릎 굽힘 범위를 늘린다.
    4. 예: 볼록면인 넙다리뼈를 뒤로 밀면 무릎 폄이 늘어난다.

    정강뼈를 고정하고 넙다리뼈를 앞으로 밀면 무릎 굽힘이 늘어나므로, 정답은 3번이다.

    수동적(passive) 관절운동범위(range of motion)에 관한 정상 끝느낌(end-feel)의 연결이 옳은 것은? (끝느낌 / 구조 / 예시)

    1. 1. 부드러움(soft) / 관절주머니(capsular)의 신장 / 손가락 손허리손가락관절의 폄
    2. 2. 팽팽함(firm) / 근육의 신장 / 무릎관절 폄 상태에서 엉덩이관절 굽힘
    3. 3. 팽팽함 / 뼈와 뼈의 접촉 / 팔꿈치 폄
    4. 4. 단단함(hard) / 연부조직 근접(tissue approximation) / 무릎관절 굽힘

    정답 2번

    🔍 보기별 해설
    1. 부드러운 끝느낌은 '연부조직 근접'에서 나온다. '관절주머니 신장'은 팽팽한(firm) 끝느낌이므로 연결이 맞지 않는다. 옳지 않다.
    2. 팽팽한(firm) 끝느낌은 근육·관절낭의 신장에서 나오며, 무릎을 편 채 엉덩관절을 굽히면(햄스트링 신장) 나타난다. 옳다(정답).
    3. 팔꿈치를 완전히 펼 때처럼 뼈와 뼈가 직접 맞닿아 멈추는 정상 끝느낌은 갑작스럽고 단단한(hard) 느낌이며, 인대·힘줄이 늘어날 때의 팽팽한(firm) 느낌과는 다르다. 옳지 않다.
    4. 단단한(hard) 끝느낌은 뼈–뼈 접촉인데, '연부조직 근접·무릎 굽힘'은 부드러운(soft) 끝느낌이라 연결이 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 예: 부드러운 끝느낌은 무릎을 굽힐 때 종아리·허벅지 살이 맞닿아 멈추는 느낌이다.
    2. 예: 다리를 편 채 들어 올리면 햄스트링이 당겨 팽팽하게 멈춘다.
    3. 甲이 팔꿈치를 끝까지 펴자 자뼈와 위팔뼈가 맞부딪쳐 멈추는데, 이는 팽팽함이 아니라 뼈끼리 닿는 단단한 끝느낌이다.
    4. 예: 무릎을 끝까지 굽히면 살이 맞닿아 부드럽게 멈춘다.

    무릎을 편 채 엉덩관절을 굽혀 근육이 늘어날 때 나는 이 끝느낌은 팽팽함이므로, 정답은 2번이다.

    엉덩관절(hip joint) 및 엉치엉덩관절(sacroiliac joint)의 병리 확인을 위한 패트릭(Patrick) 검사의 자세로 옳은 것은?

    1. 1. 엉덩관절 굽힘(flexion), 엉덩관절 벌림(abduction), 엉덩관절 가쪽돌림(external rotation)
    2. 2. 엉덩관절 굽힘, 엉덩관절 모음(adduction), 엉덩관절 안쪽돌림(internal rotation)
    3. 3. 무릎관절 굽힘, 엉덩관절 벌림, 엉덩관절 안쪽돌림
    4. 4. 무릎관절 굽힘, 엉덩관절 모음, 엉덩관절 가쪽돌림

    정답 1번

    🔍 보기별 해설
    1. 패트릭 검사(FABER)는 엉덩관절을 굽힘(Flexion)·벌림(ABduction)·가쪽돌림(External Rotation)한 자세로 시행한다. 옳다(정답).
    2. 패트릭 검사는 굽힘·벌림·가쪽돌림 자세인데, 모음·안쪽돌림은 벌림·가쪽돌림과 정반대 방향이라 검사 자세가 될 수 없다. 옳지 않다.
    3. 패트릭 검사는 엉덩관절을 가쪽으로 돌리는 자세인데 여기에는 안쪽돌림이 들어 있어, 돌림 방향이 반대라 FABER 자세와 맞지 않는다. 옳지 않다.
    4. 패트릭 검사는 다리를 바깥으로 벌리는 벌림 자세인데 여기에는 모음이 들어 있어, 벌림과 반대라 검사 자세로 성립하지 않는다. 옳지 않다.
    🧮 풀이
    1. 예: 한쪽 발목을 반대쪽 무릎 위에 '숫자 4' 모양으로 올린 자세가 패트릭 검사다.
    2. 예: 다리를 모으고 안으로 돌리는 자세는 패트릭 검사가 아니다.
    3. 예: 검사 자세에 넙다리를 안쪽으로 돌리는 동작이 들어가면, 굽힘·벌림·바깥돌림을 결합한 FABER 자세와는 다른 자세가 되어 패트릭 검사와 어긋난다.
    4. 甲이 한쪽 발목을 반대쪽 무릎 위에 올려 엉덩관절을 굽히고 벌려 바깥으로 돌린 자세가 패트릭 검사이며 모음이 들어가면 다르다.

    패트릭 검사는 엉덩관절을 굽히고 벌리고 가쪽으로 돌리는 자세로 하므로, 정답은 1번이다.

    〈보기〉에서 특수검사(special test)에 관한 설명으로 옳은 것만을 모두 고른 것은? ㄱ. 다이알(dial) 검사: 돌림근띠(rotator cuff) 손상 평가 ㄴ. 켄달(Kendall) 검사: 넙다리곧은근(rectus femoris) 손상 평가 ㄷ. 루딩턴(Ludington) 검사: 위팔두갈래근(biceps brachii) 손상 평가 ㄹ. 후버(Hoover) 검사: 뒤정강근(tibialis posterior) 손상 평가

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄷ, ㄹ

    정답 3번

    🔍 보기별 해설
    1. ㄱ. 다이알 검사는 엎드린 자세에서 발을 바깥으로 돌려 무릎 뒤가쪽 회전 불안정을 확인하는 검사이므로, 어깨의 돌림근띠(rotator cuff) 손상 평가와는 관계가 없다. 옳지 않다.
    2. ㄴ. 켄달 검사는 엎드려 무릎을 굽혔을 때 넙다리곧은근이 당겨 엉덩이가 들리는 정도를 보아 이 근육의 유연성·구축을 평가한다. 옳다.
    3. ㄷ. 루딩턴 검사는 양손을 머리 뒤로 깍지 껴 위팔두갈래근을 수축시켜 긴갈래 힘줄의 파열 여부를 확인하는 검사이므로, 설명과 연결이 옳다. 옳다.
    4. ㄹ. 후버 검사는 한쪽 다리를 들 때 반대쪽 발꿈치가 눌리는지로 환자가 실제로 힘을 쓰는지(꾀병 여부)를 판별하는 검사이므로, 뒤정강근 손상 평가와는 관계가 없다. 옳지 않다.
    🧮 풀이
    1. 예: 다이알 검사는 엎드려 발을 바깥으로 돌려 무릎 뒤가쪽 불안정을 본다.
    2. 甲을 엎드리게 한 뒤 무릎을 접어 올리면 팽팽해진 넙다리곧은근이 엉덩이를 들어 올리는데, 켄달 검사는 이때 들리는 정도로 근육의 유연성을 가늠한다.
    3. 예: 루딩턴 검사는 뒤통수에 손을 올려 이두근 힘줄이 만져지는지 본다.
    4. 甲이 진료실에서 한쪽 다리를 들어 올리는 동안 치료사가 반대쪽 발꿈치 아래에 손을 넣어 눌리는 힘을 재 보니, 이 검사는 실제로 힘을 쓰고 있는지 가려내는 것이지 뒤정강근 손상을 살피는 도구가 아니었다.

    켄달 검사는 넙다리곧은근, 루딩턴 검사는 위팔두갈래근을 보므로, 정답은 3번이다.

    발목관절(talocrural joint) 가동화(mobilization) 기법과 기대되는 효과의 연결이 옳은 것은?

    1. 1. 정강뼈(tibia)를 기준으로 목말뼈(talus)의 뒤쪽(posterior) 활주(glide) / 발등 굽힘(dorsiflexion) 증가
    2. 2. 정강뼈를 기준으로 목말뼈의 앞쪽(anterior) 활주 / 발등 굽힘 증가
    3. 3. 목말뼈를 기준으로 정강뼈의 뒤쪽 활주 / 발등 굽힘 증가
    4. 4. 목말뼈를 기준으로 정강뼈의 앞쪽 활주 / 발바닥 굽힘(plantar flexion)의 증가

    정답 1번

    🔍 보기별 해설
    1. 정강뼈를 고정하고 볼록한 목말뼈를 '뒤쪽'으로 활주시키면 발등 굽힘 범위가 증가한다(볼록–오목 법칙). 옳다(정답).
    2. 볼록한 목말뼈를 정강뼈에 대해 앞쪽으로 활주시키면 발바닥 굽힘(발끝을 내리는 움직임)이 늘어나므로, 이를 발등 굽힘 증가와 연결한 것은 맞지 않는다. 옳지 않다.
    3. 발목관절 가동화는 고정된 정강뼈에 대해 목말뼈를 움직이는 것이 원칙인데, 이 보기는 정강뼈를 뒤쪽으로 활주시킨다고 하여 기법 기준과 발등 굽힘 효과의 연결이 맞지 않는다. 옳지 않다.
    4. 발목관절 가동화는 정강뼈를 고정하고 목말뼈를 움직이는 것이 기준인데, 이 보기는 목말뼈를 기준으로 정강뼈를 움직인다고 하여 기법 기준과 발바닥 굽힘 효과의 연결이 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 예: 정강뼈를 잡고 볼록한 목말뼈를 뒤로 밀면 발등이 더 잘 젖혀진다(발등 굽힘↑).
    2. 예: 목말뼈를 앞으로 밀면 오히려 발끝을 펴는 발바닥 굽힘이 늘어난다.
    3. 예: 정강뼈를 활주시키는 설명은 표준 기법과 다르다.
    4. 예: 발목관절 가동화에서는 어느 뼈를 고정하고 어느 뼈를 움직이는지 기준으로 삼는 뼈가 달라지면, 그에 따라 기대되는 치료 효과도 함께 달라진다.

    정강뼈를 고정하고 목말뼈를 뒤로 밀면 발등굽힘이 늘어나므로, 정답은 1번이다.

    〈보기〉의 설명에 해당되는 손상은? · 농구 손가락(basketball finger)이라고도 함 · 날아오는 물체가 손가락 끝(tip)에 부딪히면서 손상 발생 · 능동적인 끝마디뼈의 굽힘은 가능하지만, 능동적인 끝마디뼈의 폄은 불가능

    1. 1. 게임키퍼 엄지(gamekeeper's thumb)
    2. 2. 망치 손가락(Mallet finger)
    3. 3. 유니폼 손가락(Jersey finger)
    4. 4. 뒤피트랑 구축(Dupuytren's contracture)

    정답 2번

    🔍 보기별 해설
    1. 게임키퍼 엄지는 엄지를 벌리는 힘에 의해 엄지 손허리손가락관절의 안쪽곁인대가 손상되는 질환이므로, 손가락 끝마디를 펴지 못하는 보기의 설명과는 다르다. 옳지 않다.
    2. 손가락 끝에 물체가 부딪혀 폄힘줄이 손상되면 끝마디를 스스로 펴지 못하는데, 이것이 망치 손가락이다. 옳다(정답).
    3. 유니폼 손가락(Jersey finger)은 깊은손가락굽힘힘줄이 끝마디뼈에서 뜯겨 나가 손가락 끝마디를 능동적으로 '굽히지' 못하는 손상이므로, 끝마디를 펴지 못한다는 설명과는 정반대이다. 옳지 않다.
    4. 뒤피트랑 구축은 손바닥 근막이 두꺼워져 손가락이 굽어 펴지지 않는 만성 질환으로, 급성 힘줄 손상과 다르다. 옳지 않다.
    🧮 풀이
    1. 예: 엄지로 무언가를 세게 잡다 안쪽인대가 늘어나면 게임키퍼 엄지다.
    2. 예: 배구·농구 공에 손끝이 찍혀 끝마디가 아래로 처진 채 스스로 못 펴면 망치 손가락이다.

    1. 염증단계에서는 손상 부위를 보호하고 출혈·부종을 가라앉히는 안정이 우선이므로, 조직에 큰 부하를 주는 고강도 저항운동은 손상을 악화시킬 수 있어 부적절하다. 옳지 않다.
    2. 증식단계에서는 새로 생긴 조직이 아직 약하므로, 점진적으로 관절 가동범위를 넓히는 운동과 저강도 근활성화로 무리 없이 회복과 조직 정렬을 촉진하는 것이 적절하다. 옳다(정답).
    3. 재형성단계에서는 아교질이 부하 방향으로 재배열되어 튼튼해지도록 점진적으로 부하를 늘려야 하므로, 조직을 보호한다며 장기간 고정하면 오히려 위축·약화를 불러 부적절하다. 옳지 않다.
    4. 재형성단계에서는 조직이 성숙해 완전한 관절 가동범위(full ROM) 운동으로 점차 진행해 기능을 회복하는 것이 원칙이므로, 이를 원칙적으로 금지한다는 설명은 실제와 반대이다. 옳지 않다.
    🧮 풀이
    1. 다친 직후 붓고 아픈 염증기에는 얼음·안정으로 보호하지, 무거운 저항운동을 하면 손상이 커진다.
    2. 새 조직이 자라는 증식기에는 아프지 않은 범위에서 관절을 조금씩 움직이고 가볍게 근육을 쓴다.
    3. 甲이 흉터가 여물어 가는 재형성단계에서는 부하를 조금씩 늘려 조직을 튼튼히 해야지 오래 고정하면 오히려 굳고 약해진다.
    4. 재형성기에는 완전한 가동범위까지 움직여 정상 기능을 회복시키는 것이 원칙이다.

    증식단계에는 점진적인 가동범위 운동과 낮은 강도의 근활성화가 어울리므로, 정답은 2번이다.

    🔍 보기별 해설
    1. ㉠ 초기 영역은 조직이 가해진 부하 범위 안에서 늘어났다가 부하를 제거하면 원래 길이로 되돌아오는 회복 가능한(탄성) 영역이므로, 설명과 일치한다. 옳다.
    2. ㉡ 지점은 조직이 당기는 힘에 늘어나며 버티는 탄성 반응을 보이기 시작하는 지점이라, 부하를 제거하면 원래대로 돌아올 수 있는 영역에 속한다. 옳다.
    3. ㉢이 가리키는 구간은 아직 탄성 범위라 영구 변형 영역으로 보기 어렵다(영구 변형은 항복점 이후). 옳지 않다.
    4. ㉣ 지점은 응력-변형 곡선에서 파단(끊어짐)에 가까운 지점이라 이미 영구 변형이 진행되어, 부하를 제거해도 조직이 기계적으로 원래 상태로 회복되지 않으므로 '기계적 회복 지점'이라는 설명은 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 인대를 살짝 당겼다 놓으면 원래 길이로 돌아오는 구간이 탄성 영역이다.
    2. 당기는 힘에 조직이 늘어나며 버티는 탄성 반응이 시작되는 지점이다.
    3. 이 지점은 아직 탄성 범위라, 늘어난 채 안 돌아오는 영구 변형은 항복점을 지나야 나타난다.
    4. 곡선 끝 파단점 근처는 조직이 끊어지는 지점이라 힘을 빼도 원래대로 회복되지 않는다.

    부하를 없애면 되돌아오는 영역과 탄성 반응이 시작되는 지점만 맞고 나머지 둘은 실제와 다르므로, 정답은 1번이다.

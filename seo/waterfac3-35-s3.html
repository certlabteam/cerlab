    습기가 있으면 밀착, 고결되어 물에 녹지 않게 되므로 저장실을 완전한 방습구조로 하여야 하는 약품은?

    1. 1. 황산알루미늄
    2. 2. 수산화나트륨
    3. 3. 소다회
    4. 4. 황산

    정답 3번

    🔍 보기별 해설
    1. 황산알루미늄은 액상 약품으로 쓰는 경우가 많다. 습기를 먹은 분말의 고결을 묻는 약품으로는 옳지 않다.
    2. 수산화나트륨은 물에 잘 녹고 흡습하면 녹아 흐르기 쉽다. 습기에 굳어 불용화되는 약품으로는 옳지 않다.
    3. 소다회는 분말 탄산나트륨으로 습기를 흡수하면 입자가 뭉치고 굳는다. 방습 저장이 필요하므로 옳다(정답).
    4. 황산은 액체 산으로 물과 만나면 열이 발생한다. 분말 고결을 막는 방습 저장 대상이라는 설명은 옳지 않다.
    🧮 풀이
    1. 응집제 창고에 들어온 황산알루미늄 제품의 형태를 확인했다. 액상으로 납품된 탱크에는 분말 입자가 습기를 먹어 굳는 문제가 생기지 않았다. 관리자는 제품별 저장 조건을 구분해 소다회 방습창고와 다른 칸에 적었다.
    2. 수산화나트륨 펠릿의 포장에 습기가 들어가 표면이 젖었다. 운영자는 이것이 물에 녹아 흐르는 성질과 관련 있음을 확인했다. 습기를 먹어 단단히 굳고 물에 녹지 않게 된다는 소다회 설명과 구별했다.
    3. 분말 소다회 포대를 습한 창고에 놓자 입자들이 붙어 덩어리가 됐다. 약품 투입기가 고르게 공급하지 못해 운영자가 굳은 포대를 따로 빼냈다. 새 저장실에는 방습 구조와 밀폐 포장을 갖춰 같은 문제를 막았다.
    4. 황산 탱크의 누출 방지 설계를 검토했다. 이 약품은 액체라 분말이 습기를 흡수해 고결되는 상황과 달랐다. 담당자는 물과 만날 때 열이 생기는 위험을 따로 관리하고 소다회 창고의 방습 목적과 구분했다.

    소다회는 습기를 먹으면 뭉쳐 굳으므로 정답은 3번이다.

    순간혼화가 어렵고 단락류가 많이 발생하며 back-mixing이 발생할 수 있는 급속 혼화방식은?

    1. 1. 가압수확산식
    2. 2. 인라인 고정식
    3. 3. 수류식
    4. 4. 기계식

    정답 4번

    🔍 보기별 해설
    1. 가압수확산식은 가압수를 분사해 약품을 본류에 빠르게 퍼뜨린다. 제시한 지 안의 역혼합 방식으로는 옳지 않다.
    2. 인라인 고정식은 관 속의 고정 날개로 흐르는 물을 나누어 섞는다. 큰 혼화지의 역혼합 현상과 달라 옳지 않다.
    3. 수류식은 물길의 낙차나 좁은 구간에서 생긴 에너지로 섞는다. 제시한 기계식 지의 단락류 현상으로는 옳지 않다.
    4. 기계식 혼화지는 교반기가 있는 지에서 물을 섞는다. 흐름이 단락되거나 뒤로 섞일 수 있어 옳다(정답).
    🧮 풀이
    1. 가압수를 본류에 분사하는 혼화장치에서 약품이 물줄기를 따라 빠르게 퍼졌다. 설계자는 분사 위치와 압력을 조절해 접촉 범위를 넓혔다. 큰 교반지 안에서 물이 뒤로 섞이는 기계식 혼화 문제와는 구조가 달랐다.
    2. 송수관 내부에 고정 날개를 넣자 흐르는 물이 여러 갈래로 나뉘었다가 다시 합쳐졌다. 약품이 관을 지나며 섞여 별도의 큰 혼화지가 필요하지 않았다. 운영자는 지 안의 단락류와 역혼합을 이 장치의 주요 현상으로 적지 않았다.
    3. 혼화수로에 낙차를 두고 약품을 주입했다. 물이 떨어지며 생긴 난류가 약품을 섞었고 별도의 교반기 회전은 없었다. 담당자는 수류식의 에너지 원천을 기계식 혼화지의 역혼합 문제와 구분했다.
    4. 기계식 혼화지에서 교반기는 돌고 있었지만 일부 물이 출구로 곧장 흘렀다. 다른 구역에서는 이미 섞인 물이 뒤로 돌아가 새 유입수와 다시 섞였다. 운영자는 단락류와 역혼합을 확인해 유입·유출 위치와 격벽을 조정했다.

    단락류와 역혼합이 생길 수 있는 급속혼화 방식은 기계식이므로 정답은 4번이다.

    침전지 슬러지의 배출 방식이 아닌 것은?

    1. 1. 자연유하식
    2. 2. 기계적 제거방식
    3. 3. 슬러지 흡입방식
    4. 4. 침전지를 비우고 청소하는 방식

    정답 1번

    🔍 보기별 해설
    1. 자연유하식은 높이 차로 물이 저절로 흐르는 방식이다. 제시된 슬러지 제거 방식의 분류로는 옳지 않다(정답).
    2. 기계적 제거방식은 긁개 등으로 바닥 슬러지를 모아 배출한다. 침전지 슬러지 배출 방식이므로 옳다.
    3. 슬러지 흡입방식은 관으로 바닥의 침전 슬러지를 빨아내 보낸다. 배출 방식이므로 옳다.
    4. 침전지를 비우고 바닥의 슬러지를 청소해 내보내는 방법도 있다. 배출 방식에 해당하므로 옳다.
    🧮 풀이
    1. 침전지 배관에서 높이 차만으로 물이 흘러가는 자연유하 구간을 확인했다. 담당자는 이것을 제시된 바닥 슬러지 제거 장치의 분류와 구분했다. 실제 슬러지 배출에는 긁개나 흡입관을 쓰는 설비를 따로 검토했다.
    2. 침전지 바닥에 쌓인 슬러지를 회전 긁개가 중앙 집수부로 밀었다. 모인 슬러지는 배출관을 통해 다음 처리시설로 이동했다. 운영자는 긁개 속도와 바닥 잔류량을 점검해 기계적 제거가 제대로 되는지 확인했다.
    3. 침전지 바닥을 따라 움직이는 흡입관이 슬러지층을 빨아들였다. 관을 지나 배슬러지지로 보내자 침전지를 완전히 비우지 않고도 바닥 고형물을 뺄 수 있었다. 담당자는 흡입 위치와 배출 농도를 확인했다.
    4. 침전지를 정지시키고 내부 물을 빼낸 뒤 작업자가 바닥에 남은 슬러지를 청소했다. 긁개가 닿지 않은 모서리까지 제거하고 벽면 상태도 살폈다. 다시 물을 채우기 전에 청소 결과와 설비 이상을 기록했다.

    자연유하식은 이 문항에서 열거한 침전지 슬러지 배출 방식이 아니므로 정답은 1번이다.

    필요에 따라 진동장치를 설치할 수 있는 슬러지 케이크 배출방법은?

    1. 1. 컨베이어벨트로 직접 트럭에 적재
    2. 2. 호퍼에 저류 후 배출
    3. 3. 케이크 저장소(평지)에 저류 후 배출
    4. 4. 현장에 매립

    정답 2번

    🔍 보기별 해설
    1. 컨베이어벨트는 케이크를 바로 트럭에 싣는다. 머무는 호퍼가 없어 진동장치의 대상 방법으로 옳지 않다.
    2. 호퍼에 케이크를 모아 두면 벽에 붙어 배출이 막힐 수 있다. 진동장치로 떨어뜨릴 수 있어 옳다(정답).
    3. 평지의 케이크 저장소는 장비로 퍼서 옮긴다. 호퍼 벽을 흔드는 진동장치 대상 방법으로 옳지 않다.
    4. 현장 매립은 케이크를 땅에 처분한다. 배출 호퍼의 진동장치를 다는 방법으로 옳지 않다.
    🧮 풀이
    1. 탈수기에서 나온 케이크를 컨베이어벨트가 바로 운반 트럭에 실었다. 중간에 케이크가 머무는 호퍼가 없어 벽에 붙은 물질을 떨어뜨릴 진동장치를 설치할 곳이 없었다. 담당자는 벨트의 이송 상태와 트럭 적재 위치를 점검했다.
    2. 탈수 케이크를 호퍼에 모아 두었다가 아래 배출구로 내보냈다. 젖은 케이크가 호퍼 벽에 달라붙어 배출이 막히자 진동장치를 작동했다. 벽에서 떨어진 케이크가 다시 흘러내려 작업자가 장치의 필요성을 확인했다.
    3. 탈수 케이크를 평평한 저장소 바닥에 쌓아 두었다. 작업자는 로더로 케이크를 퍼서 트럭에 실었다. 호퍼 벽이나 좁은 배출구가 없으므로 진동장치 대신 보관 높이와 장비 동선을 관리했다.
    4. 케이크의 현장 처분 계획을 검토하면서 매립 위치와 주변 환경을 살폈다. 담당자는 이것이 호퍼에서 케이크를 떨어뜨리는 배출 방법이 아님을 확인했다. 진동장치 설치 여부는 매립지보다 호퍼 구조에서 판단했다.

    케이크를 호퍼에 저장한 뒤 배출하면 진동장치를 붙일 수 있으므로 정답은 2번이다.

    역세척을 위한 세척탱크에 설치하는 설비로서 중심을 저수위로부터 관경의 2배 이상 얕게 하거나 벽을 설치하는 등의 방법으로 공기 혼입을 방지해야 하는 것은?

    1. 1. 유입관
    2. 2. 유출관
    3. 3. 월류관
    4. 4. 배수관

    정답 2번

    🔍 보기별 해설
    1. 유입관은 탱크로 물을 넣는 관이다. 저수위에서 물을 빨아낼 때의 공기 혼입 대상으로는 옳지 않다.
    2. 유출관은 세척탱크의 물을 빼 역세척에 보낸다. 수면이 낮을 때 공기 혼입을 막는 위치나 벽이 필요하므로 옳다(정답).
    3. 월류관은 수위가 높아 물이 넘칠 때 흘려보낸다. 저수위의 흡입 공기 방지 대상으로는 옳지 않다.
    4. 배수관은 탱크를 비울 때 물을 빼는 관이다. 역세척수 공급 유출관의 설치 조건과 달라 옳지 않다.
    🧮 풀이
    1. 세척탱크로 물을 들여보내는 유입관의 위치를 확인했다. 물을 채우는 관은 저수위에서 역세척수를 빨아내는 구간이 아니었다. 담당자는 공기 혼입 방지 벽을 어디에 둘지 유출관 쪽 도면을 다시 살폈다.
    2. 역세척을 시작하자 세척탱크의 수위가 낮아지며 유출관 주변에 소용돌이가 생겼다. 공기가 관으로 들어갈 우려가 있어 관 중심을 저수위보다 관경 두 배 이상 얕게 놓았다. 설계자는 필요한 경우 벽을 추가해 흡입 흐름을 안정시켰다.
    3. 세척탱크의 수위가 높아지자 넘친 물이 월류관으로 빠졌다. 담당자는 이 관이 고수위 보호용이라는 점을 확인했다. 낮은 수위에서 역세척수를 공급하는 유출관의 공기 혼입 조건과 혼동하지 않았다.
    4. 탱크를 비우기 위해 바닥의 배수관을 열었다. 청소수가 빠지는 관이라 역세척 때 필요한 물을 계속 보내는 유출관과 역할이 달랐다. 담당자는 두 관의 밸브와 설치 위치를 도면에서 따로 표시했다.

    역세척수 유출관에는 저수위 때 공기가 빨려 들지 않도록 해야 하므로 정답은 2번이다.

    염소가스 저장량 1,000 kg 이상의 저장시설에 설치하는 제해설비에 관한 설명으로 옳은 것은?

    1. 1. 40 % 이상 농도의 수산화나트륨을 사용
    2. 2. 처리능력은 kg/day로 표시
    3. 3. 누출가스를 중화반응탑에 송풍하는 배풍기 설치
    4. 4. 송액펌프의 용량은 이론치의 2배 이상

    정답 3번

    🔍 보기별 해설
    1. 제해설비의 수산화나트륨용액 농도 기준을 40% 이상으로 정하지 않는다. 제시한 값은 옳지 않다.
    2. 누출 염소는 짧은 시간에 많이 나올 수 있어 처리능력을 시간당 양으로 나타낸다. kg/day라는 표시는 옳지 않다.
    3. 배풍기는 누출된 염소가스를 모아 중화반응탑으로 보낸다. 제해설비의 구성으로 옳다(정답).
    4. 송액펌프 용량을 이론치의 2배 이상으로 적은 것은 제시된 설계기준과 다르다. 옳지 않다.
    🧮 풀이
    1. 염소가스 저장시설의 제해설비에 쓸 수산화나트륨 농도를 검토했다. 담당자는 40% 이상으로 적힌 설계값이 해당 기준의 지정 농도가 아님을 확인했다. 중화 성능과 약품 안전성을 함께 검토해 용액 사양을 다시 정했다.
    2. 염소 누출 사고 때 짧은 시간에 많은 가스가 배풍기로 몰릴 수 있었다. 설계자는 제해설비 처리능력을 하루 총량만으로 표시하면 순간 부하를 놓친다고 판단했다. 시간당 처리 가능한 염소량을 계산해 장치 용량을 검토했다.
    3. 저장실의 염소가스 누출 감지기가 작동하자 배풍기가 켜졌다. 누출가스는 배관을 따라 중화반응탑으로 보내져 흡수액과 접촉했다. 담당자는 배풍기 유량과 탑 출구의 염소 농도를 함께 확인했다.
    4. 중화반응탑의 흡수액을 보내는 송액펌프 용량을 계산했다. 담당자는 이론치의 두 배 이상이라는 수치를 해당 기준으로 적은 초안을 발견했다. 실제 설계기준을 다시 확인해 필요한 유량과 예비 운전을 구분했다.

    누출 염소가스를 중화반응탑에 보내는 배풍기가 필요하므로 정답은 3번이다.

    오존주입설비의 발생오존과 접촉하는 부위에 사용할 수 있는 수지는?

    1. 1. PVC
    2. 2. PTFE
    3. 3. PVDF
    4. 4. HDPE

    정답 2번

    🔍 보기별 해설
    1. PVC(Polyvinyl Chloride)는 이 문항에서 발생오존 접촉부의 지정 수지로 제시되지 않는다. 옳지 않다.
    2. PTFE(Polytetrafluoroethylene)는 강한 산화제인 오존에 잘 견딘다. 발생오존 접촉부 수지로 옳다(정답).
    3. PVDF(Polyvinylidene Fluoride)는 내약품성 수지지만 이 문항의 발생오존 접촉부 지정 수지는 아니다. 옳지 않다.
    4. HDPE(High Density Polyethylene)는 오존에 장기간 노출되는 부위의 지정 수지로 제시되지 않는다. 옳지 않다.
    🧮 풀이
    1. 발생오존을 보내는 배관의 수지 재료를 고르는 회의에서 PVC가 후보에 올랐다. 담당자는 강한 산화제와 직접 닿는 지정 부위의 요구 재료를 확인했다. 일반 배관에 쓰인다는 이유만으로 발생오존 접촉부에 채택하지 않았다.
    2. 오존발생기 출구의 밀봉재와 배관 부품에 PTFE를 적용했다. 오존이 직접 닿아도 잘 견디는 성질을 검토하고 연결부의 누출 여부를 시험했다. 담당자는 재료의 정식 이름인 Polytetrafluoroethylene을 사양서에 함께 적었다.
    3. PVDF 부품이 여러 약품에 견디는 것을 보고 오존발생기 접촉부에 바로 쓰려 했다. 검수자는 이 문항의 지정 수지와 일반적인 내약품성을 구분했다. 발생오존과 직접 닿는 위치의 재료를 PTFE로 다시 확인했다.
    4. HDPE 저장용기 자료를 보던 설계자가 발생오존 배관에도 같은 수지를 쓰자고 제안했다. 담당자는 장기간 오존에 직접 노출되는 부위의 요구 재료를 대조했다. 용도만 비슷하다고 재료를 옮겨 쓰지 않고 접촉부 사양을 고쳤다.

    발생오존과 닿는 부위에는 내오존성이 큰 PTFE를 쓰므로 정답은 2번이다.

    밸브를 선정할 때 고려해야 하는 사항이 아닌 것은?

    2. 2. 통과하는 액체나 기체의 온도와 유량변동 범위
    3. 3. 밸브 전후의 최대 차압치
    4. 4. 통과하는 액체나 기체의 투명도

    정답 4번

    🔍 보기별 해설
    1. 유체의 부식성에 따라 밸브 몸체와 패킹의 재질을 골라야 한다. 선정 조건이므로 옳다.
    2. 온도와 유량 변동이 크면 밸브 재질과 제어 범위에 영향을 준다. 선정 조건이므로 옳다.
    3. 밸브 앞뒤 최대 차압은 밸브가 견딜 힘과 작동 토크를 좌우한다. 선정 조건이므로 옳다.
    4. 유체가 눈에 투명하게 보이는지는 밸브의 압력·재질·유량 성능을 정하지 않는다. 선정 조건으로 옳지 않다(정답).
    🧮 풀이
    1. 부식성 약품을 보내는 관에 밸브를 달기 전 유체의 성질을 확인했다. 일반 재질을 쓰면 몸체와 패킹이 손상될 수 있어 내식성 재료를 골랐다. 담당자는 부식 정도와 교체주기를 함께 검토했다.
    2. 뜨거운 유체가 시간마다 다른 유량으로 흐르는 배관의 밸브를 선정했다. 설계자는 최고 온도와 유량 조절 범위를 모두 자료표에 적었다. 평상시 한 조건만 보고 고른 밸브가 다른 운전점에서도 작동하는지 확인했다.
    3. 밸브 앞뒤 압력 차가 가장 커지는 운전 상황을 계산했다. 담당자는 그 차압에서 밸브 몸체가 견디고 구동기가 열 수 있는지 확인했다. 최대값을 무시하면 정상 운전 중 밸브가 움직이지 않을 수 있었다.
    4. 유체가 맑게 보이는지 관찰한 뒤 밸브 사양서에 투명도 값을 넣으려 했다. 검수자는 밸브 재질·압력·유량 성능을 정하는 데 그 시각적 성질이 직접 쓰이지 않는다고 설명했다. 부식성과 온도, 차압을 대신 확인했다.

    액체나 기체의 투명도는 밸브 선정의 기계적 조건이 아니므로 정답은 4번이다.

    구조가 견고하고 운전과 보수가 용이하여 상수도용 펌프에 주로 사용되는 전동기는?

    1. 1. 3상유도전동기
    2. 2. 동기전동기
    3. 3. 직류전동기
    4. 4. 차동복권전동기

    정답 1번

    🔍 보기별 해설
    1. 3상유도전동기는 구조가 단순하고 견고하며 회전자 유지보수가 쉽다. 펌프에 널리 쓰이므로 옳다(정답).
    2. 동기전동기는 별도 여자와 동기 운전 관리가 필요하다. 일반 펌프의 간편한 선택으로는 옳지 않다.
    3. 직류전동기는 정류자와 브러시 등의 관리가 필요하다. 간편한 상수도 펌프용으로는 옳지 않다.

    1. 상수도 송수펌프에 연결할 전동기를 고르면서 3상유도전동기를 검토했다. 구조가 견고하고 운전·보수가 쉬워 장시간 연속 운전에 알맞았다. 담당자는 모터 용량과 펌프 축동력을 대조해 사양을 확정했다.
    2. 동기전동기를 펌프에 적용하는 안을 검토했다. 담당자는 별도 여자 장치와 동기 운전 관리가 필요한 점을 유지보수 계획에 반영했다. 일반적인 상수도 펌프에 더 간편한 전동기와 비교해 선정 이유를 적었다.
    3. 직류전동기의 브러시와 정류자 상태를 점검할 작업 계획이 나왔다. 현장 운영자는 장시간 도는 펌프에서 이런 부품 관리가 늘어나는 점을 확인했다. 구조가 단순한 3상유도전동기와 보수 부담을 비교했다.
    4. 차동복권전동기를 펌프용으로 제안한 자료를 검토했다. 이 직류전동기는 운전 특성과 브러시 관리가 복잡해 일반적인 선택과 거리가 있었다. 설계자는 요구 운전조건을 살핀 뒤 널리 쓰는 3상유도전동기로 비교표를 고쳤다.

    수요 제계수에 있어서 수요 설비가 동시에 사용되는 정도를 나타내는 값으로 사용되는 계수는?

    2. 부하율은 일정 기간의 평균부하를 최대부하로 나눈 비다. 동시 사용 설비의 수용 정도를 묻는 답으로는 옳지 않다.
    3. 수용률은 설치된 설비용량에 비해 실제 최대 사용량이 어느 정도인지 나타낸다. 사용 정도를 보므로 옳다(정답).

    1. 서로 다른 펌프 세 대의 개별 최대부하를 각각 기록했다. 담당자는 그 합과 전체 설비가 동시에 보인 최대부하를 비교해 부등률을 구했다. 설치용량에 비해 실제 얼마나 쓰는지를 묻는 수용률과 구분했다.
    2. 하루 동안 펌프가 쓰는 평균 전력과 가장 높은 전력을 측정했다. 운영자는 평균부하를 최대부하로 나누어 부하율을 계산했다. 설비가 동시에 사용되는 정도를 나타내는 수용률과는 분모가 다른 지표였다.
    3. 건물의 설치 전기설비 용량을 합산한 뒤 실제 최고 사용량을 계측했다. 담당자는 최고 사용량을 설치용량과 비교해 수용률을 구했다. 모든 설비가 동시에 정격으로 운전된다고 가정하지 않고 공급 용량을 검토했다.
    4. 수요 제계수 표에 설비평형률이라는 이름이 들어 있었다. 검수자는 설치된 설비와 실제 최대 사용량을 비교하는 표준 이름이 수용률임을 확인했다. 낯선 명칭을 그대로 설계 근거로 쓰지 않고 계수 정의를 다시 적었다.

    설비가 동시에 사용되는 정도를 나타내는 계수는 수용률이므로 정답은 3번이다.

    2. 2. 400

    4. 4. 2,000

    4. ↓

    8. ↓

    12. ↓

    19. → 10,000/25=400 Ω

    23. → 400 Ω, 2번

    3. 관 속 프로펠라가 흐르는 물에 밀려 회전했다. 담당자는 회전수를 측정해 유속과 유량을 계산했다. 회전체의 움직임을 쓰는 터빈식과 고정 장애물 뒤 와류를 세는 방식을 구분했다.
    4. 도전성 액체가 자기장을 가로질러 흐르자 전극 사이에 전압이 생겼다. 코일과 전극을 가진 장치가 이 신호로 유량을 계산했다. 담당자는 이를 전자유량계로 기록하고 와류 센서와 혼동하지 않았다.

    장애물 뒤 소용돌이 발생 빈도로 유속을 재는 것이 와류 유량계이므로 정답은 2번이다.

    화학물질의 분류․표시 및 물질안전보건자료에 관한 기준상 물질안전보건자료 작성 시 포함되어야 할 항목이 아닌 것은?

    4. 4. 유통사에 관한 정보

    2. 노출방지와 개인보호구 정보는 작업자가 화학물질에 닿지 않도록 돕는다. 필수 항목이므로 옳다.
    3. 운송에 필요한 정보는 화학물질을 싣고 옮길 때의 위험과 조치를 적는다. 필수 항목이므로 옳다.
    4. 유통사에 관한 정보는 이 문항의 물질안전보건자료 필수 기재 항목으로 열거되지 않는다. 옳지 않다(정답).
    🧮 풀이
    1. 화학약품이 작업자의 눈에 튀는 사고를 가정해 물질안전보건자료를 펼쳤다. 응급조치요령에 적힌 세척과 의료 도움 절차를 즉시 확인할 수 있었다. 담당자는 자료 작성 때 이 항목을 빠뜨리지 않았다.
    2. 염소 취급 작업자의 노출을 줄이려고 물질안전보건자료를 확인했다. 문서에는 환기 방법과 적합한 호흡보호구, 장갑 정보가 적혀 있었다. 안전관리자는 실제 작업장 조건에 맞게 보호구를 준비했다.
    3. 화학약품을 운송차량에 싣기 전 담당자가 위험 표시와 운송 정보를 확인했다. 누출 때 필요한 조치와 운송 중 주의사항을 자료에서 찾았다. 그는 운송에 필요한 정보를 물질안전보건자료의 항목으로 유지했다.

    물질안전보건자료의 필수 항목에 유통사 정보는 없으므로 정답은 4번이다.

    고압가스 안전관리법상 사업자등과 특정고압가스 사용신고자가 그의 시설이나 제품과 관련하여 사람이 사망한 사고가 발생한 경우 즉시 통보하여야 하는 기관은?

    1. 1. 한국가스안전공사
    2. 2. 가스 생산 및 판매기관
    3. 3. 가스사고조사위원회
    4. 4. 산업통상자원부

    정답 1번

    🔍 보기별 해설
    1. 한국가스안전공사는 고압가스 시설·제품 관련 사고의 즉시 통보를 받는 기관이다. 옳다(정답).
    2. 가스 생산·판매기관은 공급과 거래를 담당한다. 법이 정한 사망 사고의 즉시 통보 기관으로는 옳지 않다.
    3. 가스사고조사위원회는 사고 원인을 조사할 수 있다. 최초의 즉시 통보 기관 명칭으로는 옳지 않다.
    4. 산업통상자원부는 고압가스 정책 소관 부처다. 이 조항의 즉시 통보 대상 기관으로는 옳지 않다.
    🧮 풀이
    1. 고압가스 시설에서 사람이 숨진 사고가 발생하자 사업자가 즉시 통보 절차를 시작했다. 담당자는 사고 장소와 시설 정보를 정리해 한국가스안전공사에 알렸다. 공급사나 조사기구에만 연락하고 법정 즉시 통보를 놓치지 않았다.
    2. 고압가스 공급업체가 사고 소식을 먼저 들었다. 사업자는 거래처에 물량 중단을 알리는 일과 법정 사고 통보를 구분했다. 사망 사고의 즉시 통보 대상은 한국가스안전공사임을 확인했다.
    3. 사고 원인을 조사할 위원회 구성 이야기가 나왔다. 담당자는 조사 절차가 시작되기 전에 법정 즉시 통보가 필요하다는 점을 확인했다. 최초 연락 기관을 가스사고조사위원회로 적은 비상 연락망을 고쳤다.
    4. 고압가스 정책을 맡는 부처 이름을 사고 보고서에 적었다. 현장 관리자는 정책 소관과 시설 사고의 즉시 통보 기관이 다르다는 점을 확인했다. 한국가스안전공사에 즉시 알리고 부처 보고 절차는 별도로 검토했다.

    고압가스 관련 사망 사고는 한국가스안전공사에 즉시 통보하므로 정답은 1번이다.

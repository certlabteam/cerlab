    하부 절점 G에 하중이 있을 때 CG가 하중을 직접 매달아 힘이 1이고, H나 F에 있을 때는 G 절점에서 CG의 힘이 0이며 하중이 H~G, G~F 사이에서는 직선으로 변한다. H~F 사이의 삼각형인 ③이 옳다. 정답은 3번이다.

    2. 2. {qL^2 / 3}
    3. 3. {qL^2 / 2}
    4. 4. {2qL^2 / 3}

    🔍 보기별 해설

    🧮 풀이

    8. → MB=1.5qL²−5qL²/6
    9. → |MB|=2qL²/3

    3. 3. 400
    4. 4. 800

    사용자 A가 사전에 비밀키를 공유하고 있지 않은 사용자 B에게 기밀성 보장이 요구되는 문서 M을 보내기 위한 메시지로 옳은 것은?

    KpuX: 사용자 X의 공개키 KprX: 사용자 X의 개인키 KS: 세션키 H(): 해시 함수 E(): 암호화 ||: 연결(concatenation) 연산자

    1. 1. M || EKprA(H(M))
    2. 2. EKprA(M || H(M))
    3. 3. EKS(M) || EKpuB(KS)
    4. 4. EKS(M) || EKprA(KS)

    정답 3번

    🔍 보기별 해설
    1. M || EKprA(H(M))은 원문 M과 A의 개인키로 만든 해시 서명을 함께 보낸다. 문서 M이 그대로 노출돼 기밀성이 보장되지 않으므로 옳지 않다.
    2. EKprA(M || H(M))은 A의 개인키로 문서와 해시를 처리하므로 A의 공개키로 확인할 수 있다. 수신자 B만 읽을 수 있게 하는 암호화가 아니므로 옳지 않다.
    3. EKS(M) || EKpuB(KS)는 M을 세션키 KS로 암호화하고 KS를 B의 공개키 KpuB로 암호화한다. B만 개인키로 세션키를 얻어 문서를 읽으므로 옳다(정답).
    4. EKS(M) || EKprA(KS)는 세션키 KS를 A의 개인키로 처리한다. A의 공개키를 가진 사람도 확인할 수 있어 B만 세션키를 얻는 구조가 아니므로 옳지 않다.
    🧮 풀이
    1. A가 문서 원문과 자신의 서명을 함께 전송한다. 수신자는 서명으로 발신자를 확인할 수 있지만 문서 원문은 전달 과정에서 그대로 보인다. 기밀성 요구를 충족하려면 문서 자체를 암호화해야 한다.
    2. A의 개인키로 처리한 값을 A의 공개키로 확인하는 구조를 생각한다. 공개키는 다른 사람도 가질 수 있어 B에게만 내용을 숨기는 수단이 아니다. 발신자 증명과 수신자 전용 암호화의 방향을 구분해야 한다.
    3. A가 임의의 세션키를 만들어 문서를 빠르게 암호화한다. 이어 B의 공개키로 세션키를 암호화해 문서 암호문과 함께 보낸다. B는 자신의 개인키로 세션키를 복원한 뒤 문서를 복호화한다.
    4. A가 자신의 개인키로 세션키를 감싸 보내면 A의 공개키를 가진 사람이 그 값을 확인할 수 있다. 문서를 암호화한 키가 노출되면 기밀성이 깨진다. 세션키는 수신자 B의 공개키로 감싸야 한다.

    문서는 세션키로 암호화하고 그 세션키를 수신자 B의 공개키로 감싸므로 정답은 3번이다.

    보안 서비스와 이를 제공하기 위한 보안 기술을 잘못 연결한 것은?

    1. 1. 데이터 무결성 － 암호학적 해시
    2. 2. 신원 인증 － 인증서
    3. 3. 부인방지 － 메시지 인증 코드
    4. 4. 메시지 인증 － 전자 서명

    정답 3번

    🔍 보기별 해설
    1. 암호학적 해시는 내용이 바뀌면 다른 요약값이 나오게 해 데이터 변경을 탐지한다. 무결성 확인에 쓰이므로 옳다.
    2. 인증서는 공개키와 소유자 정보를 묶고 인증기관의 서명으로 그 관계를 확인하게 한다. 상대의 공개키가 주장한 신원에 속하는지 검증하는 수단이므로 옳다.
    3. 메시지 인증 코드는 송신자와 수신자가 같은 비밀키를 공유한다. 양쪽 모두 코드를 만들 수 있어 제3자에 대한 부인방지 증거가 되기 어려우므로 옳지 않다(정답).
    4. 전자 서명은 서명자의 개인키로 만든 서명을 공개키로 검증하게 한다. 메시지와 발신자의 관계를 확인하는 데 쓸 수 있으므로 옳다.
    🧮 풀이
    1. 배포 파일을 내려받은 뒤 게시된 해시값과 새로 계산한 해시값을 비교한다. 값이 다르면 파일이 바뀌었음을 알 수 있다. 내용 변경 여부를 확인하는 무결성 사례다. 배포자가 발표한 원래 해시값도 신뢰할 수 있는 경로에서 받아야 한다.
    2. 브라우저가 서버 인증서의 도메인 이름과 발급기관 서명을 검사한다. 인증서에 담긴 공개키가 그 서버의 것인지 확인한다. 공개키와 신원 사이의 관계를 인증한다. 인증기관을 신뢰할 수 있는지도 함께 확인한다.
    3. A와 B가 같은 비밀키를 공유해 메시지 인증 코드를 만든다. 나중에 코드가 붙은 메시지를 놓고 다투면 A뿐 아니라 B도 같은 코드를 만들 수 있다. 제3자에게 누가 만들었는지 증명하기 어려워 부인방지에는 부족하다.
    4. A가 개인키로 계약서에 전자 서명한다. B는 A의 공개키로 서명과 문서의 관계를 검증한다. 메시지가 바뀌지 않았고 해당 키의 보유자가 서명했는지 확인할 수 있다.

    메시지 인증 코드는 공유키 방식이라 제3자에 대한 부인방지를 제공하지 못하므로 정답은 3번이다.

    웹 서버와 클라이언트 간의 쿠키 처리 과정으로 옳지 않은 것은?

    1. 1. HTTP 요청 메시지의 헤더 라인을 통한 쿠키 전달
    2. 2. HTTP 응답 메시지의 상태 라인을 통한 쿠키 전달
    3. 3. 클라이언트 브라우저의 쿠키 디렉터리에 쿠키 저장
    4. 4. 웹 서버가 클라이언트에 관해 수집한 정보로부터 쿠키를 생성

    정답 2번

    🔍 보기별 해설
    1. 브라우저는 저장한 쿠키를 다음 HTTP 요청의 Cookie 헤더에 실어 보낸다. 요청 헤더를 통한 전달이므로 옳다.
    2. 서버가 쿠키를 보낼 때는 HTTP 응답의 Set-Cookie 헤더를 사용한다. 상태 라인에 실어 보낸다는 설명은 옳지 않다(정답).
    3. 브라우저는 받은 쿠키를 쿠키 저장 공간에 보관하고 조건에 맞는 요청에서 다시 보낸다. 클라이언트 쪽 저장이므로 옳다.
    4. 서버는 클라이언트의 세션 등 필요한 정보를 바탕으로 쿠키 값을 만들어 응답에 포함할 수 있다. 쿠키 생성 주체에 관한 설명이므로 옳다.
    🧮 풀이
    1. 브라우저가 쇼핑몰에 다시 접속할 때 앞서 받은 세션 쿠키를 Cookie 헤더에 넣는다. 서버는 그 값을 읽어 같은 이용자의 요청을 이어서 처리한다. 쿠키가 요청 메시지의 헤더로 이동하는 사례다.
    2. 서버가 새 세션을 만들고 응답 헤더에 Set-Cookie 값을 적는다. 응답의 첫 줄에는 상태 코드와 설명이 놓인다. 쿠키 전달 위치를 상태 라인으로 바꾸면 HTTP 메시지 구조와 맞지 않는다.
    3. 브라우저가 서버의 쿠키를 받은 뒤 자신의 저장 공간에 보관한다. 만료 시각과 도메인 조건이 맞으면 다음 요청에 실어 보낸다. 클라이언트가 보관하는 단계가 처리 과정에 들어간다.
    4. 서버가 사용자 방문을 구별할 세션 식별자를 만든다. 그 값을 Set-Cookie 헤더로 보내면 브라우저가 저장한다. 서버가 수집·생성한 정보를 바탕으로 쿠키를 만드는 경우다.

    쿠키는 HTTP 응답의 상태 라인이 아니라 Set-Cookie 헤더로 전달하므로 정답은 2번이다.

    「개인정보 보호법」 제15조(개인정보의 수집ㆍ이용)에서 개인정보처리자가 개인정보를 수집할 수 있으며 그 수집 목적의 범위에서 이용할 수 있는 경우에 해당하지 않는 것은?

    1. 1. 정보주체의 동의를 받은 경우
    2. 2. 법률에 특별한 규정이 있거나 법령상 의무를 준수하기 위하여 불가피한 경우
    3. 3. 공공기관이 법령 등에서 정하는 소관 업무의 수행을 위하여 불가피한 경우
    4. 4. 공공기관과의 계약의 체결 및 이행을 위하여 불가피하게 필요한 경우

    정답 4번

    🔍 보기별 해설
    1. 정보주체가 수집 목적과 이용 범위를 알고 개인정보의 수집·이용에 동의하면 그 범위에서 처리할 수 있다. 법 제15조의 근거이므로 옳다.
    2. 법률에 특별한 규정이 있거나 법령상 의무 이행에 불가피하면 수집·이용할 수 있다. 법 제15조의 근거이므로 옳다.
    3. 공공기관이 법령 등에서 정한 소관 업무를 수행하는 데 불가피하면 수집·이용할 수 있다. 공공기관 업무에 관한 근거이므로 옳다.
    4. 계약을 이유로 한 수집 근거는 정보주체와의 계약 이행이나 체결 과정의 필요성에 관한 것이다. 공공기관과의 계약이라고 적은 설명은 법의 요건과 달라 옳지 않다(정답).
    🧮 풀이
    1. 회사 甲이 회원 乙에게 서비스 이용 목적과 수집 항목을 알린다. 乙이 그 내용에 동의하면 甲은 정한 목적의 범위에서 정보를 사용할 수 있다. 동의는 수집·이용의 한 근거다.
    2. 기관 甲이 법령에 따라 반드시 처리해야 하는 신고 업무를 맡는다. 필요한 최소 개인정보를 수집해 법정 의무를 수행한다. 단순한 편의가 아니라 특별 규정이나 불가피한 의무가 근거가 된다.
    3. 공공기관 甲이 법령에 정해진 지원금 지급 업무를 수행한다. 대상자 乙의 신원을 확인할 정보가 없으면 업무를 처리할 수 없다. 소관 업무 수행에 불가피한 범위에서 수집 근거를 검토한다.
    4. 사업자 甲이 공공기관 丙과 물품 공급 계약을 맺었다. 그 사실만으로 이용자 乙의 개인정보를 자유롭게 수집할 수 있는 것은 아니다. 법은 정보주체와의 계약 이행 등 별도의 구체적 근거를 정한다.

    공공기관과 계약한다는 사실 자체는 제15조의 수집·이용 근거가 아니므로 정답은 4번이다.

    함수 P에서 호출한 함수 Q가 자신의 작업을 마치고 다시 함수 P로 돌아가는 과정에서의 스택 버퍼 운용 과정을 순서대로 바르게 나열한 것은?

    (가) 스택에 저장되어 있는 복귀 주소(return address)를 pop한다. (나) 스택 포인터를 프레임 포인터의 값으로 복원시킨다. (다) 이전 프레임 포인터 값을 pop하여 스택 프레임 포인터를 P의 스택 프레임으로 설정한다. (라) P가 실행했던 함수 호출(function call) 인스트럭션 다음의 인스트럭션을 실행한다.

    1. 1. (가) → (나) → (다) → (라)
    2. 2. (가) → (다) → (라) → (나)
    3. 3. (나) → (가) → (라) → (다)
    4. 4. (나) → (다) → (가) → (라)

    정답 4번

    🔍 보기별 해설
    1. 저장된 복귀 주소는 이전 프레임 포인터를 되살린 뒤 꺼낸다. 함수 P로 돌아갈 위치를 회복하는 단계이므로 옳다.
    2. 함수 Q의 스택 포인터를 프레임 포인터 위치로 되돌려 지역 변수 공간을 정리한다. 반환 절차의 첫 단계이므로 옳다.
    3. 이전 프레임 포인터를 스택에서 꺼내 함수 P의 프레임을 다시 지정한다. 스택 포인터를 복원한 다음 단계이므로 옳다.
    4. 복귀 주소로 이동해 함수 P의 호출 명령 다음 인스트럭션을 실행한다. 스택 복원과 주소 회복이 끝난 마지막 단계이므로 옳다.
    🧮 풀이
    1. 함수 Q가 끝나면 저장해 둔 복귀 주소를 사용해야 한다. 그 전에 스택 포인터와 이전 프레임 포인터를 차례로 복원한다. 복귀 주소를 꺼낸 뒤에야 함수 P가 이어서 실행할 위치를 알 수 있다.
    2. 함수 Q가 사용하던 지역 변수 공간이 스택에 남아 있다. 스택 포인터를 현재 프레임 포인터의 위치로 옮겨 그 공간을 정리한다. 반환 절차는 이 정리 단계에서 시작한다.
    3. 스택에 보관해 둔 함수 P의 프레임 포인터 값을 꺼낸다. 이를 현재 프레임 포인터로 삼아 호출 전의 스택 프레임을 되살린다. 지역 변수 공간 정리 뒤에 수행한다.
    4. Q를 호출했던 P의 명령 바로 다음 명령어로 실행 흐름을 옮긴다. 복귀 주소를 꺼내고 프레임을 복원한 뒤라야 안전하게 이어 실행할 수 있다. 순서는 스택 포인터 복원, 이전 프레임 포인터 복원, 복귀 주소 회복, P 실행이다.

    정답은 4번이다.

    무선 네트워크 보안에 대한 설명으로 옳은 것은?

    1. 1. 이전에 사용했던 WEP의 보안상 약점을 보강하기 위해서 IETF에서 WPA, WPA2, WPA3를 정의하였다.
    2. 2. WPA는 TKIP 프로토콜을 채택하여 보안을 강화하였으나 여전히 WEP와 동일한 메시지 무결성 확인 방식을 사용하는 약점이 있다.
    3. 3. WPA2는 무선 LAN 보안 표준인 IEEE 802.1X의 보안 요건을 충족하기 위하여 CCM 모드의 AES 블록 암호 방식을 채택하고 있다.
    4. 4. WPA-개인 모드에서는 PSK로부터 유도된 암호화 키를 사용하는 반면에, WPA-엔터프라이즈 모드에서는 인증 및 암호화를 강화하기 위해 RADIUS 인증 서버를 두고 EAP 표준을 이용한다.

    정답 4번

    🔍 보기별 해설
    1. WPA와 WPA2·WPA3 계열은 와이파이 연합이 규격과 인증 체계를 정의한다. IETF가 세 버전을 모두 정의했다는 설명은 옳지 않다.
    2. WPA는 TKIP(Temporal Key Integrity Protocol, 임시 키 무결성 프로토콜)를 도입해 WEP의 보호 방식을 보강했다. 무결성 검사도 WEP와 완전히 같다는 설명은 옳지 않다.
    3. WPA2는 무선 LAN에서 AES 기반 CCMP를 사용해 데이터를 보호한다. 이를 IEEE 802.1X 자체의 보안 요건을 채우기 위한 암호 방식으로 서술한 부분은 옳지 않다.
    4. WPA-개인 모드는 PSK(Pre-Shared Key, 사전 공유키)를 사용하고 WPA-엔터프라이즈 모드는 RADIUS 인증 서버와 EAP 표준을 활용한다. 두 모드의 인증 방식 설명이므로 옳다(정답).
    🧮 풀이
    1. 무선망 관리자가 WEP의 약점을 보완한 WPA 설정을 확인한다. 와이파이 연합의 인증·규격 체계와 인터넷 프로토콜 표준화 기구의 역할은 구별된다. 모든 WPA 버전의 정의 주체를 IETF로 적을 수 없다.
    2. 옛 무선망이 WEP에서 WPA로 바뀌며 TKIP를 적용한다. 키 처리와 무결성 검사 방식이 개선돼 같은 수준의 보호에 머물지 않는다. 이름만 바뀌고 검사 방식이 그대로라는 설명은 맞지 않는다. 각 패킷의 무결성을 확인하는 방식도 이전 체계와 차이가 있다.
    3. 기업 무선망이 WPA2를 사용하면서 AES 기반 CCMP로 데이터를 보호한다. IEEE 802.1X는 포트 기반 접근제어와 인증에 관한 표준이다. 암호 모드의 채택 이유를 802.1X 자체의 요건으로 설명하면 서로 다른 역할을 섞게 된다.
    4. 가정의 무선 공유기는 이용자들이 같은 사전 공유 비밀번호를 입력하게 한다. 회사 무선망은 직원 계정을 RADIUS 서버에서 확인하고 EAP 절차를 적용한다. 개인 모드와 기업 모드의 인증 방식이 다르다. 직원 계정이 폐기되면 기업 모드에서는 중앙 인증 서버에서 권한을 끊을 수 있다. 공유 비밀번호 하나를 여러 사람이 계속 쓰는 개인 모드와 운영 관리 방식도 달라진다.

    개인 모드는 사전 공유키, 기업 모드는 인증 서버와 EAP를 사용하므로 정답은 4번이다.

    사용자 A가 사용자 B에게 보낼 메시지에 대한 전자서명을 생성하는 데 필요한 키는?

    1. 1. 사용자 A의 개인키
    2. 2. 사용자 A의 공개키
    3. 3. 사용자 B의 개인키
    4. 4. 사용자 B의 공개키

    정답 1번

    🔍 보기별 해설
    1. 사용자 A의 개인키는 A만 보관하고 메시지 서명을 생성할 때 사용한다. A의 공개키로 검증할 수 있으므로 옳다(정답).
    2. 사용자 A의 공개키는 A가 만든 서명을 검증하는 데 사용한다. 공개된 키로 서명을 생성하면 발신자 증명이 되지 않으므로 옳지 않다.
    3. 사용자 B의 개인키는 B가 자신의 서명을 만들 때 사용한다. A가 보내는 메시지의 서명키가 아니므로 옳지 않다.
    4. 사용자 B의 공개키는 B에게만 읽힐 암호문을 만들 때 사용할 수 있다. A의 전자서명을 만드는 키가 아니므로 옳지 않다.
    🧮 풀이
    1. A가 계약서의 해시를 자신의 개인키로 서명해 B에게 보낸다. B는 A의 공개키로 서명을 검증한다. 서명 생성에는 A만 통제하는 개인키가 필요하다.
    2. A의 공개키는 B를 포함한 다른 사람에게 배포할 수 있다. 누구나 가진 키만으로 서명을 만들 수 있다면 A가 직접 서명했다는 근거가 없다. 공개키는 생성보다 검증에 사용된다.
    3. B가 자신의 개인키로 문서에 서명하면 그 서명의 주체는 B다. A가 보낸 문서의 발신자가 A임을 증명하려는 목적과 맞지 않는다. 서명키는 문서를 보내는 A의 개인키다.
    4. A가 B에게 비밀 문서를 보내려면 B의 공개키로 세션키를 암호화할 수 있다. 이때 키의 용도는 수신자만 복호화하도록 하는 것이다. A의 신원을 증명할 서명 생성과는 용도가 다르다.

    전자서명은 발신자 A의 개인키로 생성하므로 정답은 1번이다.

    원본 파일에 숨기고자 하는 정보를 삽입하고 숨겨진 정보의 존재 여부를 알기 어렵게 하는 기술은?

    1. 1. 퍼징(Fuzzing)
    2. 2. 스캐닝(Scanning)
    3. 3. 크립토그래피(Cryptography)
    4. 4. 스테가노그래피(Steganography)

    정답 4번

    🔍 보기별 해설
    1. 퍼징(Fuzzing)은 프로그램에 다양한 입력을 주어 오류나 취약점을 찾는 시험 기법이다. 파일 속에 정보를 숨기는 방식이 아니므로 옳지 않다.
    2. 스캐닝(Scanning)은 시스템의 포트와 서비스, 알려진 취약점 등을 탐색하는 조사 방법이다. 원본 파일에 비밀 정보를 삽입하는 기법이 아니므로 옳지 않다.
    3. 크립토그래피(Cryptography)는 암호 기술로 내용의 의미를 숨기거나 검증한다. 정보가 들어 있다는 사실 자체를 숨기는 기술과 다르므로 옳지 않다.
    4. 스테가노그래피(Steganography)는 사진·소리 같은 원본 매체에 정보를 넣어 그 존재를 알아보기 어렵게 한다. 발문의 은닉 방식이므로 옳다(정답).
    🧮 풀이
    1. 보안 시험 도구가 프로그램에 길이가 비정상적인 입력을 반복해서 보낸다. 프로그램이 멈추거나 예외를 내면 취약점을 조사한다. 입력 시험인 퍼징은 메시지를 사진 속에 숨기는 작업과 다르다.
    2. 관리자가 서버의 열린 포트와 버전을 조사한다. 취약한 서비스가 있는지 찾기 위한 스캐닝이다. 숨긴 문서가 들어 있는 이미지 파일을 만드는 과정과 목적이 다르다. 탐색 결과를 토대로 실제 취약점 검증 여부를 정한다.
    3. 문서 내용을 암호화하면 파일이 있어도 키가 없는 사람은 내용을 이해하기 어렵다. 하지만 암호문 파일이 존재한다는 사실은 보일 수 있다. 존재를 감추는 스테가노그래피와 보호 대상이 다르다.
    4. 사진의 일부 픽셀에서 눈에 잘 띄지 않는 비트를 바꿔 짧은 메시지를 넣는다. 사진을 보는 사람은 겉모습만으로 메시지의 존재를 알아채기 어렵다. 원본 파일에 정보를 감춰 넣는 사례다.

    원본 매체 속에 정보의 존재 자체를 숨기는 스테가노그래피이므로 정답은 4번이다.

    다음에서 설명하는 공격 방법은?

    ○ 사람의 심리를 이용하여 보안 기술을 무력화시키고 정보를 얻는 공격 방법

    ○ 신뢰할 수 있는 사람으로 위장하여 다른 사람의 정보에 접근하는 공격 방법

    1. 1. 재전송 공격(Replay Attack)
    2. 2. 무차별 대입 공격(Brute-Force Attack)
    3. 3. 사회공학 공격(Social Engineering Attack)
    4. 4. 중간자 공격(Man-in-the-Middle Attack)

    정답 3번

    🔍 보기별 해설
    1. 재전송 공격은 이미 전송된 정상 메시지를 다시 보내 권한을 얻으려 한다. 사람을 속여 정보를 받는 방법이 아니므로 옳지 않다.
    2. 무차별 대입 공격은 가능한 비밀번호 후보를 반복 시험한다. 신뢰 관계를 가장하는 심리적 공격이 아니므로 옳지 않다.
    3. 사회공학 공격은 사람의 판단과 신뢰를 이용해 비밀 정보나 접근 권한을 얻는다. 자료의 두 설명에 맞으므로 옳다(정답).
    4. 중간자 공격은 통신 당사자 사이에 끼어 전송 내용을 가로채거나 바꾼다. 사람의 심리를 이용한 위장 접근이라는 정의와 다르므로 옳지 않다.
    🧮 풀이
    1. 정상 로그인 메시지를 공격자가 기록해 두었다가 나중에 다시 보낸다. 서버가 새 요청으로 받아들이면 인증이 우회될 수 있다. 기존 메시지의 재사용이 핵심이다.
    2. 공격 프로그램이 흔한 비밀번호 조합을 하나씩 입력해 본다. 맞는 조합을 찾을 때까지 후보를 바꿔 반복한다. 사람의 신뢰를 얻는 대화가 아니라 값의 반복 시험이다.
    3. 공격자가 회사 전산 담당자인 척 직원에게 전화한다. 긴급한 계정 점검이라며 일회용 인증번호를 알려 달라고 요구한다. 상대의 신뢰와 당황한 심리를 이용해 보안 절차를 우회한다.
    4. 공격자가 클라이언트와 서버 사이의 통신을 가로챌 위치를 만든다. 양쪽에는 정상 상대인 것처럼 보이며 메시지를 중간에서 읽거나 바꾼다. 통신 경로에 끼어드는 방식이 중심이다.

    사람의 신뢰와 심리를 이용해 정보를 얻는 사회공학 공격이므로 정답은 3번이다.

    블록 암호의 운영 모드 중 ECB 모드와 CBC 모드에 대한 설명으로 옳은 것은?

    1. 1. ECB 모드는 블록의 변화가 다른 블록에 영향을 주지 않아 안전하다.
    2. 2. ECB 모드는 암호화할 때, 같은 데이터 블록에 대해 같은 암호문 블록을 생성한다.
    3. 3. CBC 모드는 블록의 변화가 이전 블록에 영향을 주므로 패턴을 추적하기 어렵다.
    4. 4. CBC 모드는 암호화할 때, 이전 블록의 결과가 필요하지 않다.

    정답 2번

    🔍 보기별 해설
    1. ECB(Electronic Codebook, 전자 코드북)에서는 각 블록을 독립적으로 암호화해 같은 패턴이 드러날 수 있다. 변화가 다른 블록에 영향을 주지 않아 안전하다는 단정은 옳지 않다.
    2. ECB에서 같은 키와 같은 평문 블록을 사용하면 같은 암호문 블록이 나온다. 독립적 블록 암호화의 특성이므로 옳다(정답).
    3. CBC(Cipher Block Chaining, 암호문 블록 연결)에서는 한 블록의 변화가 뒤의 암호문 블록들에 영향을 줄 수 있다. 이전 블록에 영향을 준다고 한 방향은 옳지 않다.
    4. CBC 암호화는 현재 평문 블록을 이전 암호문 블록과 결합한다. 이전 블록의 결과가 필요하지 않다는 설명은 옳지 않다.
    🧮 풀이
    1. 같은 그림 무늬가 반복되는 파일을 ECB로 암호화한다. 같은 평문 블록은 같은 암호문 블록이 되어 반복 위치의 패턴이 남을 수 있다. 블록 독립성이 곧 안전성을 뜻하지는 않는다.
    2. 문서의 서로 다른 위치에 완전히 같은 16바이트 블록이 있다. 같은 키를 사용하는 ECB는 두 위치에서 동일한 암호문 블록을 만든다. 앞 블록의 결과를 입력으로 쓰지 않기 때문이다.
    3. CBC에서 첫 평문 블록을 바꾸면 첫 암호문 블록이 달라지고 그 값이 다음 블록의 입력에도 사용된다. 변경 효과는 뒤쪽으로 이어진다. 이미 계산한 이전 블록의 결과가 거꾸로 바뀌지는 않는다.
    4. CBC로 둘째 블록을 암호화할 때는 첫 암호문 블록이 필요하다. 둘째 평문과 첫 암호문을 결합한 뒤 암호화한다. 따라서 앞 블록 계산을 마치지 않고 독립적으로 둘째 블록을 처리할 수 없다.

    ECB에서는 같은 평문 블록이 같은 암호문 블록으로 바뀌므로 정답은 2번이다.

    컴퓨터 보안의 3요소가 아닌 것은?

    1. 1. 무결성(Integrity)
    2. 2. 확장성(Scalability)
    3. 3. 가용성(Availability)
    4. 4. 기밀성(Confidentiality)

    정답 2번

    🔍 보기별 해설
    1. 무결성은 정보가 허가 없이 바뀌지 않은 상태를 유지하는 성질이다. 컴퓨터 보안의 세 요소 중 하나이므로 옳다.
    2. 확장성은 이용량 증가에 맞춰 시스템의 처리 능력을 늘릴 수 있는 성질이다. 보안의 세 요소에 속하지 않으므로 옳지 않다(정답).
    3. 가용성은 허가된 이용자가 필요한 때 정보와 시스템을 사용할 수 있는 성질이다. 보안의 세 요소 중 하나이므로 옳다.
    4. 기밀성은 허가받지 않은 사람이 정보를 읽지 못하게 하는 성질이다. 보안의 세 요소 중 하나이므로 옳다.

    2. 2. 관리체계 운영
    3. 3. 관리체계 기반 마련

    디지털 콘텐츠의 불법 복제와 유포를 막고 저작권 보유자의 이익과 권리를 보호해 주는 기술은?

    1. 1. PGP(Pretty Good Privacy)
    2. 2. IDS(Intrusion Detection System)
    3. 3. DRM(Digital Rights Management)
    4. 4. PIMS(Personal Information Management System)

    정답 3번

    🔍 보기별 해설
    1. PGP(Pretty Good Privacy, 꽤 좋은 프라이버시)는 전자우편 등의 암호화와 서명에 쓰인다. 콘텐츠 이용 권한 관리 기술이 아니므로 옳지 않다.
    2. IDS(Intrusion Detection System, 침입 탐지 시스템)는 네트워크나 시스템의 침입 징후를 찾는다. 디지털 콘텐츠의 복제 통제가 아니므로 옳지 않다.
    3. DRM(Digital Rights Management, 디지털 권리 관리)은 콘텐츠의 사용·복제·배포 권한을 통제한다. 저작권 보호 목적에 맞으므로 옳다(정답).
    4. PIMS(Personal Information Management System, 개인정보 관리체계)는 개인정보의 처리와 보호를 관리한다. 저작물 이용 권한을 통제하는 기술이 아니므로 옳지 않다.
    🧮 풀이
    1. 이용자가 전자우편의 내용을 암호화해 보낸다. PGP는 허가받지 않은 사람이 메일을 읽지 못하게 하고 서명으로 발신자를 확인할 수 있게 한다. 영화 파일의 복제 횟수를 정하는 시스템과 목적이 다르다.
    2. 보안 담당자가 네트워크의 비정상 로그인 시도를 IDS로 탐지한다. 경고가 나면 관련 로그를 조사한다. 침입 징후를 찾아내는 도구가 전자책의 이용 권한을 설정하지는 않는다.
    3. 전자책 판매자가 구매한 계정에서만 책을 열 수 있게 설정한다. 복사나 전달 가능 횟수도 이용 조건에 따라 제한한다. 콘텐츠 권리자의 배포·이용 정책을 기술로 적용하는 것이 DRM이다.
    4. 조직이 고객 개인정보를 수집·보관·파기하는 절차를 관리한다. PIMS는 개인정보를 보호하기 위한 관리체계다. 음원이나 전자책의 저작권 이용 규칙을 강제하는 DRM과 대상이 다르다.

    디지털 콘텐츠의 이용 권한과 복제를 관리하는 DRM이므로 정답은 3번이다.

    3. 공격자가 무선 통신을 몰래 수신해 전송 내용을 읽는다. 송신자와 수신자는 메시지가 바뀌지 않아 도청 사실을 바로 알기 어렵다. 통신을 관찰만 하는 수동적 공격이다.

    다음에서 설명하는 기술은?

    ○ 공인 IP 주소가 내부 사설 IP 주소보다 부족한 경우에 적용 가능한 방식이다.

    ○ 내부 사설 IP 주소나 내부 네트워크 대역을 공인 IP로 자동 매핑하는 기능을 제공한다.

    ○ 내부 IP 주소를 외부로부터 보호해 주는 기능을 제공하기도 한다.

    1. 1. ARP
    2. 2. IPS
    3. 3. NAT
    4. 4. VLAN

    정답 3번

    🔍 보기별 해설
    1. ARP(Address Resolution Protocol, 주소 결정 프로토콜)는 같은 네트워크에서 IP 주소에 대응하는 물리 주소를 찾는다. 공인·사설 IP 변환이 아니므로 옳지 않다.
    2. IPS(Intrusion Prevention System, 침입 방지 시스템)는 공격 징후를 탐지하고 차단한다. 주소 부족을 해결하는 매핑 기능이 아니므로 옳지 않다.
    3. NAT(Network Address Translation, 네트워크 주소 변환)은 사설 주소를 공인 주소로 바꿔 외부와 통신하게 한다. 자료의 매핑 기능에 해당하므로 옳다(정답).
    4. VLAN(Virtual Local Area Network, 가상 근거리 통신망)은 논리적으로 네트워크 구간을 나눈다. 사설 주소와 공인 주소의 변환이 아니므로 옳지 않다.
    🧮 풀이
    1. 컴퓨터가 같은 사무실의 프린터 IP로 패킷을 보내려 한다. ARP로 프린터의 물리 주소를 알아내 로컬 프레임을 만든다. 인터넷으로 나갈 공인 주소를 새로 배정하는 과정과 다르다.
    2. 보안 장비가 공격 패턴이 담긴 패킷을 보고 전송을 막는다. IPS는 침입을 예방하는 차단 장치다. 여러 사설 주소를 공인 주소 하나에 대응시키는 기능은 중심이 아니다.
    3. 사무실 컴퓨터 여러 대가 사설 주소를 사용하고 외부로 나갈 때 공유기의 공인 주소를 함께 쓴다. 공유기는 내부 주소와 포트를 외부에서 쓸 주소·포트로 변환한다. 주소 부족을 완화하고 내부 주소를 외부에 그대로 드러내지 않는다. 이 주소 변환의 이름은 NAT다.
    4. 한 스위치에 연결된 재무팀과 개발팀의 장치를 서로 다른 논리 구간으로 묶는다. VLAN을 사용하면 물리 장비를 함께 써도 브로드캐스트 범위를 나눌 수 있다. 주소 변환과는 다른 네트워크 분리 기능이다.

    사설 IP와 공인 IP의 주소를 바꾸어 연결하는 기술은 NAT이므로 정답은 3번이다.

    다음과 같은 과정으로 진행되는 공격은?

    1. 공개키 암호 방법을 사용하는 A와 B의 통신에 C가 개입한다.

    2. C는 A의 공개키를 가로채어 B에게 C의 공개키를 A의 공개키처럼 전송한다.

    3. B는 C의 공개키로 메시지를 암호화하여 A에게 전송한다.

    4. C는 B가 보낸 메시지를 가로채어 C의 개인키로 복호화한다.

    5. C는 복호화한 메시지를 단계 2에서 가로챈 A의 공개키로 암호화하여 A에게 B가 보낸 것처럼 전송한다.

    6. A는 자신의 개인키로 메시지를 복호화한다.

    1. 1. Smurf
    2. 2. 중간자(MITM)
    3. 3. Sniffing
    4. 4. Slowloris

    정답 2번

    🔍 보기별 해설
    1. Smurf 공격은 위조 주소로 브로드캐스트 응답을 유도해 대상에 트래픽을 몰아준다. 공개키를 바꿔 통신을 중계하는 공격이 아니므로 옳지 않다.
    2. 중간자 공격(MITM, Man-in-the-Middle)은 C가 A와 B 사이에서 공개키를 바꿔 전달하고 메시지를 읽은 뒤 다시 보낸다. 자료의 개입 과정과 맞으므로 옳다(정답).
    3. 스니핑(Sniffing)은 네트워크를 지나는 데이터를 몰래 관찰한다. 공개키를 위조해 통신 양쪽에 개입하는 적극적 중계와 다르므로 옳지 않다.
    4. Slowloris는 HTTP 연결을 느리게 유지해 서버 자원을 소모시킨다. 공개키 교체와 메시지 복호화의 공격이 아니므로 옳지 않다.
    🧮 풀이
    1. 공격자가 응답이 대상 서버로 돌아가도록 출발지 주소를 위조하고 네트워크에 요청을 보낸다. 서버는 많은 응답을 받아 처리 부담이 커진다. 공개키를 바꿔 내용을 읽는 과정은 없다. 이를 Smurf 공격이라고 부른다.
    2. 통신 중간의 C가 A의 공개키 대신 자기 공개키를 B에게 준다. B가 보낸 암호문을 C가 자신의 개인키로 읽고 A의 공개키로 다시 암호화한다. 양쪽은 정상 통신으로 생각하지만 C가 중간에서 내용을 본다.
    3. 공격자가 무선망의 패킷을 복사해 전송 내용을 살핀다. 패킷을 수정하거나 B에게 거짓 공개키를 보내지 않는다면 단순 관찰에 머문다. 자료의 공격은 관찰을 넘어 메시지를 바꿔 중계한다. 영어 이름 Sniffing은 통신을 몰래 엿보는 행동을 뜻한다.
    4. 공격자가 웹 서버에 연결을 여러 개 열고 요청 헤더를 아주 느리게 보낸다. 서버가 연결을 계속 기다리며 자원을 사용하게 된다. 공개키 위조가 아니라 연결 자원 고갈을 노리는 방식이다. Slowloris는 이런 느린 연결을 이용한다.

    공격자 C가 공개키를 바꾸어 끼어들고 메시지를 다시 암호화하므로 정답은 2번이다.

    두 지역 A , B 의 소득에 대한 상자 그림(box plot)은 다음과 같다. 이에 대한 설명으로 옳은 것만을 모두 고르면?

    ㄱ. 최솟값은 A 지역이 B 지역보다 크다.

    ㄴ. 중앙값은 A 지역이 B 지역보다 크다.

    ㄷ. 범위는 A 지역이 B 지역보다 작다.

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄷ
    3. 3. ㄴ, ㄷ
    4. 4. ㄱ, ㄴ, ㄷ

    정답 1번

    🔍 보기별 해설
    1. 두 지역의 소득을 같은 눈금에 놓으면 A 지역 상자그림의 아래쪽 수염 끝이 B 지역보다 높다. 아래쪽 수염 끝이 최솟값을 나타내므로 ㄱ은 옳다.
    2. 상자그림에서 A 지역 상자 속 중앙선은 B 지역의 중앙선보다 높은 위치에 그려져 있다. 상자 속 선이 중앙값을 나타내므로 ㄴ은 옳다.
    3. A 지역의 아래쪽 수염 끝부터 위쪽 수염 끝까지의 거리는 B 지역보다 길다. 범위는 최댓값에서 최솟값을 뺀 값이므로 ㄷ은 옳지 않다.
    🧮 풀이
    1. 두 지역의 소득을 같은 눈금으로 그린 상자그림에서 A의 아래 수염 끝은 B의 아래 수염 끝보다 위에 놓인다. 아래 수염 끝은 각 지역의 가장 낮은 소득에 해당한다. 따라서 A의 최솟값이 B보다 크다는 ㄱ의 비교가 성립한다.
    2. A의 상자 안에 그어진 중앙선은 B의 중앙선보다 위쪽에 있다. 이 선 아래와 위에 관측값이 절반씩 놓이므로 두 지역의 가운데 소득을 직접 비교할 수 있다. 실제 가운데 소득은 A 지역에서 더 높은 값으로 나타난다.
    3. 수염의 양 끝 사이를 비교하면 A의 세로 길이가 B보다 더 길다. 상자 자체의 높이만 재면 사분위범위가 되고, 전체 범위를 구하려면 두 수염 끝을 써야 한다. A의 범위가 더 작다는 ㄷ은 그림과 반대다.

    상자그림에서 A 지역의 최솟값과 중앙값이 B 지역보다 크지만 범위는 A 지역이 더 넓다. 옳은 것은 ㄱ·ㄴ이므로 정답은 1번이다.

    다음 제시된 두 변수 X 와 Y 에 대한 산점도 중 X 와 Y 의 표본상관계수(피어슨의 표본상관계수)가 가장 큰 것은?

    1. 1.
    2. 2.
    3. 3.
    4. 4.

    정답 3번

    🔍 보기별 해설
    1. 점들이 한쪽으로 기울지 않고 흩어져 있어 양의 선형관계가 약하다. 피어슨 표본상관계수는 0에 가까우므로 가장 큰 그림이 아니어서 옳지 않다.
    2. 점들이 왼쪽 위에서 오른쪽 아래로 모여 강한 음의 선형관계를 보인다. 상관계수의 절댓값이 커도 부호가 음수이므로 가장 큰 값으로 고르면 옳지 않다.
    3. 점들이 왼쪽 아래에서 오른쪽 위로 좁게 모여 강한 양의 선형관계를 보인다. 네 그림 가운데 양의 상관계수가 가장 크므로 옳다(정답).
    4. 점들이 V자 모양으로 퍼져 있어 X와 Y의 관계가 직선으로 표현되지 않는다. 피어슨 상관계수에서는 양쪽 기울기가 상쇄되므로 가장 크다고 하면 옳지 않다.
    🧮 풀이
    1. 판매량 X와 광고비 Y를 한 점씩 찍었더니 점들이 사방으로 흩어졌다. 광고비가 늘 때 판매량이 한 방향으로 움직이는 직선 경향이 보이지 않는다. 이런 자료의 피어슨 상관계수는 0 부근이어서 강한 양의 관계를 나타내지 않는다.
    2. 기온 X가 높을수록 난방비 Y가 줄어드는 관측값을 찍으면 점들이 왼쪽 위에서 오른쪽 아래로 모인다. 직선에 가깝게 모일수록 관계는 강하지만 기울기는 음의 방향이다. 상관계수도 음수여서 양의 상관계수가 큰 그림보다 값이 작다.
    3. 공부 시간 X가 늘수록 점수 Y가 비슷한 비율로 높아지는 자료를 그렸다. 점들이 오른쪽 위로 향하는 좁은 띠를 이루면 양의 직선 관계가 강하다. 네 산점도 중 이 모양의 피어슨 상관계수가 가장 큰 양수다.
    4. 투입량 X가 중간일 때 결과 Y가 낮고 양 끝에서는 높아 V자 모양이 생겼다. X와 Y가 관련되어 있어도 한쪽에서는 내려가고 다른 쪽에서는 올라간다. 한 직선으로 재는 피어슨 상관계수에서는 두 방향이 상쇄되어 0에 가까워진다.

    표본상관계수는 부호까지 포함해 견주는 값이고 3번 산점도가 왼쪽 아래에서 오른쪽 위로 뚜렷하게 모여 있어 가장 큰 양의 값을 가지므로 3번이 해당한다.

    통계적 가설검정에서 제1종 오류확률에 대한 설명으로 옳은 것은?

    1. 1. 귀무가설이 참일 때 귀무가설을 기각할 확률
    2. 2. 귀무가설이 참일 때 귀무가설을 기각하지 않을 확률
    3. 3. 귀무가설이 거짓일 때 귀무가설을 기각할 확률
    4. 4. 귀무가설이 거짓일 때 귀무가설을 기각하지 않을 확률

    정답 1번

    🔍 보기별 해설
    1. 귀무가설이 실제로 참인데 표본을 보고 기각하면 제1종 오류다. 이 오류가 날 확률을 유의수준 α로 정하므로 옳다(정답).
    2. 귀무가설이 참일 때 기각하지 않으면 올바른 판단이다. 그 확률은 1-α이므로 제1종 오류확률이라는 설명은 옳지 않다.
    3. 귀무가설이 거짓일 때 기각하면 잘못된 가설을 제대로 찾아낸다. 그 확률은 검정력 1-β이므로 제1종 오류확률이라는 설명은 옳지 않다.
    4. 귀무가설이 거짓인데 기각하지 못하면 제2종 오류다. 그 확률은 β로 나타내므로 제1종 오류확률이라는 설명은 옳지 않다.
    🧮 풀이
    1. 공장에서 정상인 생산라인을 정지시키는 경보가 울렸다. 실제로는 불량이 없는데 검정이 정상이라는 귀무가설을 기각한 상황이다. 정상 공정을 불량으로 오판할 확률을 미리 5%로 정했다면 그 5%가 제1종 오류확률이다.
    2. 품질검사에서 생산라인이 정상이라는 귀무가설이 참이고 검사도 이를 기각하지 않았다. 정상 공정을 계속 가동했으므로 판정이 맞다. 유의수준이 5%라면 이런 올바른 비기각의 확률은 95%로 제1종 오류가 아니다.
    3. 불량이 생긴 공정을 검사한 결과 정상이라는 귀무가설을 기각했다. 실제 불량을 찾아내 생산을 멈춘 판단이므로 오류가 발생하지 않았다. 이처럼 거짓 가설을 기각할 확률은 검정력이라 부른다.
    4. 생산라인에 불량이 생겼지만 표본검사에서는 정상이라는 귀무가설을 기각하지 못했다. 불량 공정이 그대로 가동되는 잘못이 발생했다. 이는 거짓인 귀무가설을 놓친 제2종 오류이며 그 확률은 β다.

    제1종 오류는 귀무가설이 참인데도 기각해 버리는 잘못이므로 참일 때 기각할 확률이라고 한 1번이 옳다.

    단순선형회귀모형 Y_i = β_0 + β_1 x_i + ε_i , (i = 1, 2, ⋯ , 22) 에서 최소제곱법으로 회귀식을 추정한 후 잔차제곱합을 구하였더니 2,100이었다. 이때 오차항 분산( σ^2 )의 불편추정값은? (단, ε_i 는 N (0, σ^2) 를 따르고 서로 독립이다)

    1. 1. 100
    2. 2. 105
    3. 3. 110
    4. 4. 120

    정답 2번

    🔍 보기별 해설
    1. 표본 22개에서 절편과 기울기 두 계수를 추정했으므로 잔차 자유도는 20이다. 잔차제곱합 2,100을 20으로 나눈 분산 추정값은 105이므로 옳다(정답).
    🧮 풀이
    1. ① 잔차 자유도를 구한다
    2. 22개의 관측값으로 절편과 기울기를 각각 한 개씩 추정했다. 계수를 두 개 맞추는 데 자료의 자유도 두 개가 쓰였으므로 잔차에는 20개의 자유도가 남는다.
    3. → 잔차 자유도 = 22 − 2 = 20
    4. ↓
    5. ② 잔차제곱합을 자유도로 나눈다
    6. 잔차제곱합 2,100을 표본 수 22로 바로 나누면 계수 추정에 쓰인 자유도를 무시한다. 불편추정량은 잔차가 실제로 변할 수 있는 자유도 20으로 나누어야 한다.
    7. → 오차항 분산의 불편추정값 = 2,100 ÷ 20 = 105

    오차항 분산의 불편추정값은 105이므로 정답은 2번이다.

    코로나바이러스 감염 상황과 진단키트의 진단 확률이 다음과 같을 때, 한 사람의 진단키트 결과가 음성이라면 이 사람이 실제 음성일 확률은?

    ○ 전체 인구 중 코로나바이러스 양성은 20 %이다.

    ○ 진단키트에서 실제 음성인 사람을 음성으로 판단할 확률이 70 %이다.

    ○ 진단키트에서 실제 양성인 사람을 양성으로 판단할 확률이 80 %이다.

    1. 1. {13 / 15}
    2. 2. {9 / 10}
    3. 3. {14 / 15}
    4. 4. {29 / 30}

    정답 3번

    🔍 보기별 해설
    1. 실제 음성이면서 음성 판정을 받을 확률은 0.8×0.7=0.56이다. 음성 판정 전체 확률 0.60으로 나누면 14/15이므로 옳다(정답).
    🧮 풀이
    1. ① 실제 상태의 비율을 정한다
    2. 검사 대상 100명을 생각하면 실제 양성은 20명이고 실제 음성은 80명이다. 음성 판정 뒤의 상태를 물었으므로 먼저 두 집단이 각각 음성 판정을 받을 비율을 구한다.
    3. → 실제 음성 비율 = 1 − 0.2 = 0.8
    4. ↓
    5. ② 음성 판정이 나오는 두 경로를 센다
    6. 실제 음성인 사람은 70%가 음성 판정을 받는다. 실제 양성인 사람은 양성 판정 확률이 80%이므로 남은 20%가 음성으로 잘못 판정된다. 100명 기준으로 각각 56명과 4명이다.
    7. → 실제 음성·판정 음성 = 0.8 × 0.7 = 0.56
    8. → 실제 양성·판정 음성 = 0.2 × 0.2 = 0.04
    9. ↓
    10. ③ 음성 판정자 중 실제 음성 비율을 구한다
    11. 음성 판정을 받은 사람은 두 경로를 더한 60명에 해당한다. 그중 실제 음성은 56명이므로 진단 결과를 조건으로 한 확률은 56/60이다.
    12. → 조건부확률 = 0.56 ÷ (0.56 + 0.04) = 14/15

    음성 판정을 받은 사람 중 실제 음성일 확률은 14/15이므로 정답은 3번이다.

    두 연속형 확률변수 X 와 Y 가 독립일 때, 이에 대한 설명으로 옳지 않은 것은?

    1. 1. X 와 Y 의 공분산은 0이다.
    2. 2. X 와 Y 의 합에 대한 분산은 X 와 Y 의 분산의 합이다.
    3. 3. X 와 Y 의 곱에 대한 기댓값은 X 와 Y 의 기댓값의 곱이다.
    4. 4. X 가 주어졌을 때 Y 의 조건부확률밀도함수는 X 의 주변확률밀도함수와 같다.

    정답 4번

    🔍 보기별 해설
    1. 독립인 두 변수는 함께 변하는 방향이 없어 E(XY)=E(X)E(Y)가 성립한다. 공분산이 두 값의 차이이므로 0이 되어 옳다.
    2. 합의 분산은 Var(X)+Var(Y)+2Cov(X,Y)다. 독립이면 공분산 항이 0이므로 두 분산만 더해 옳다.
    3. 독립이면 결합확률밀도가 두 주변확률밀도의 곱으로 나뉜다. 따라서 곱의 기댓값도 각각의 기댓값을 곱한 값이므로 옳다.
    4. 독립이면 X의 값을 알아도 Y의 분포는 바뀌지 않는다. Y의 조건부밀도는 Y의 주변밀도와 같으며 X의 주변밀도라고 한 것은 옳지 않다(정답).
    🧮 풀이
    1. 서로 독립인 두 주사위의 눈을 각각 X와 Y로 두었다. X에서 큰 수가 나왔다는 사실이 Y의 눈을 한쪽으로 밀어 올리지 않는다. 두 값의 편차를 곱해 평균을 내면 양과 음이 상쇄되어 공분산이 0이다.
    2. 서로 독립인 기계 두 대의 하루 생산량을 X와 Y로 두었다. 두 생산량을 합친 총량의 변동을 계산할 때 공분산은 0으로 사라진다. 각 기계의 분산이 4와 9라면 총량의 분산은 13이 된다.

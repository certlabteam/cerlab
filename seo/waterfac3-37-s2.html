    먹는물수질공정시험기준상 총칙의 내용으로 옳은 것은?

    1. 1. “a～b”라고 표시한 것은 a 이상 b 미만임을 뜻한다.
    2. 2. 방울수는 4 ℃에서 정제수 20방울을 떨어뜨릴 때, 그 부피가 약 1 mL 되는 것을 뜻한다.
    3. 3. 원자량은 국제원자량표에 따라, 분자량은 이 표에 따라 계산한 후 소수점 이하 첫째 자리까지 정리한다.
    4. 4. “정확히 취하여”는 규정한 양의 액체를 부피피펫으로 눈금까지 취하는 것을 말한다.

    정답 4번

    🔍 보기별 해설
    1. a~b의 물결표는 a 이상 b 이하를 나타내며 끝값 b도 포함한다. b 미만이라는 설명은 옳지 않다.
    2. 방울수의 기준 온도는 20℃다. 정제수 20방울 약 1 mL라는 조건의 온도를 4℃로 적어 옳지 않다.
    3. 분자량의 정리 자릿수를 소수점 이하 첫째 자리로 적은 것은 총칙의 규정과 다르다. 옳지 않다.
    4. '정확히 취하여'는 정해진 액체량을 부피피펫으로 눈금에 맞게 취하는 뜻이다. 옳다(정답).
    🧮 풀이
    1. 시험 절차의 범위를 a~b로 적은 문서를 검토했다. 담당자는 시작값 a뿐 아니라 끝값 b도 포함하는지 실제 경계 시료를 대조했다. b 미만으로 읽어 끝값을 버린 분석표를 수정했다.
    2. 정제수의 방울수를 확인하려고 20방울을 모아 약 1 mL인지 살폈다. 시험자는 기준 온도가 20℃라는 점을 확인했다. 4℃로 맞춘 초안은 방울 크기와 부피 조건을 잘못 옮겨 바로잡았다.
    3. 시험자의 계산서에는 원자량표로 분자량을 구한 뒤 소수점 첫째 자리까지 정리한다고 적혀 있었다. 검수자는 총칙의 자릿수 규정을 다시 찾았다. 계산 결과를 임의로 한 자리로 잘라 내지 않도록 보고 형식을 고쳤다.
    4. 정해진 부피의 액체 시약을 정확히 취하라는 절차를 읽었다. 분석자는 부피피펫을 사용해 눈금에 액면을 맞춰 필요한 양을 옮겼다. 대략 눈대중으로 따르는 방법과 구분해 사용 기구를 기록했다.

    '정확히 취하여'는 부피피펫으로 규정량을 취한다는 뜻이므로 정답은 4번이다.

    0.5 N 농도의 NaOH 용액 500 mL에 녹아있는 용질의 양(g)과 같은 값은?

    1. 1. 과망간산칼륨소비량의 먹는물 수질기준(mg/L)값
    2. 2. 표준온도(℃)값
    3. 3. 탁도 표준용액의 탁도(NTU)값
    4. 4. 열수의 온도(℃)값

    정답 1번

    🔍 보기별 해설
    1. 0.5 N NaOH 500 mL의 용질은 10 g이다. 과망간산칼륨소비량의 먹는물 기준 수치 10과 같으므로 옳다(정답).
    🧮 풀이
    1. ① 노르말농도를 몰농도로 바꾼다.
    2. NaOH는 수산화이온 한 개를 내므로 당량수가 1이다.
    3. → 0.5 N=0.5 M
    4. ↓
    5. ② 부피를 리터로 바꾼다.
    6. 용액 500 mL를 1,000으로 나눈다.
    7. → 0.5 L
    8. ↓
    9. ③ 몰수를 계산한다.
    10. 몰농도에 부피를 곱한다.
    11. → 0.5×0.5=0.25 mol
    12. ↓
    13. ④ 질량을 구한다.
    14. 몰수에 NaOH 분자량 40 g/mol을 곱한다.
    15. → 0.25×40=10 g
    16. ↓
    17. ⑤ 보기의 수치와 비교한다.
    18. 과망간산칼륨소비량의 먹는물 수질기준은 10 mg/L 이하다. 단위가 아니라 숫자를 비교한다.
    19. → 수치 10, 1번

    0.5 N NaOH 500 mL에는 10 g이 들며 같은 숫자는 과망간산칼륨소비량 기준이므로 정답은 1번이다.

    먹는물수질공정시험기준상 시험결과 표시 자릿수가 0.0이 아닌 것은?

    1. 1. 암모니아성 질소
    2. 2. 질산성질소
    3. 3. 과망간산칼륨소비량
    4. 4. 세제

    정답 1번

    🔍 보기별 해설
    1. 암모니아성 질소는 다른 세 항목과 달리 결과를 소수점 한 자리의 0.0 형태로 표시하지 않는다. 옳다(정답).
    2. 질산성질소는 시험결과를 0.0 형태로 표시하는 항목이다. 제외 대상으로는 옳지 않다.
    3. 과망간산칼륨소비량은 시험결과를 0.0 형태로 표시한다. 제외 대상으로는 옳지 않다.
    4. 세제는 시험결과를 0.0 형태로 표시하는 항목이다. 제외 대상으로는 옳지 않다.
    🧮 풀이
    1. 암모니아성 질소 분석 결과를 보고서에 옮기던 직원이 표시 자릿수 표를 확인했다. 이 항목은 다른 세 항목처럼 일률적으로 0.0 형태로 적지 않았다. 그는 기준의 별도 표시 형식에 맞춰 원자료와 보고값을 대조했다.
    2. 질산성질소 분석기가 낸 수치를 결과지에 입력했다. 담당자는 기준의 0.0 표시 형태에 맞춰 소수점 자릿수를 정리했다. 암모니아성 질소의 다른 표시 형식과 같은 칸에 섞지 않았다.
    3. 과망간산칼륨소비량 시험을 마친 분석자가 계산값을 검토했다. 결과를 0.0 형태로 보고하도록 표시 자릿수를 맞췄다. 원자료는 보존해 반올림 전 값과 최종 보고값을 다시 확인할 수 있게 했다.
    4. 세제 항목의 시험결과를 수질 보고서에 넣었다. 분석자는 소수점 한 자리인 0.0 형태를 적용했다. 항목별 표시 자릿수가 다를 수 있으므로 옆의 암모니아성 질소 결과를 그대로 복사하지 않았다.

    암모니아성 질소는 표시 자릿수가 0.0이 아니므로 정답은 1번이다.

    수질오염공정시험기준상 화학적산소요구량 측정법 중 산성과망간산칼륨법에 사용 되는 염소이온 제거 시약은?

    1. 1. 다이크롬산
    2. 2. 설파민산
    3. 3. 요오드화칼륨
    4. 4. 황산은

    정답 4번

    🔍 보기별 해설
    1. 다이크롬산은 다른 화학적산소요구량 시험에서 산화제로 쓰인다. 염소이온 제거 시약으로는 옳지 않다.
    2. 설파민산은 아질산이온의 방해를 없애는 데 쓰인다. 염소이온 제거 시약으로는 옳지 않다.
    3. 요오드화칼륨은 산화제를 간접적으로 적정할 때 이용한다. 염소이온 제거 시약으로는 옳지 않다.
    4. 황산은의 은 이온은 염소이온과 결합해 염화은 침전을 만든다. 염소이온 방해를 막으므로 옳다(정답).
    🧮 풀이
    1. 산성과망간산칼륨법의 염소이온 방해를 막을 시약을 찾던 분석자가 다이크롬산을 꺼냈다. 다이크롬산은 다른 화학적산소요구량 시험에서 산화제로 쓰이는 물질이었다. 그는 염소이온 제거용으로 은 이온을 공급하는 황산은을 선택했다.
    2. 아질산이온이 반응을 방해할 수 있는 시료를 검사하면서 설파민산의 역할을 확인했다. 설파민산은 그 방해를 없애는 데 쓰이지만 염소이온을 침전시키지 않았다. 담당자는 염소이온 제거 단계에 황산은을 따로 준비했다.
    3. 산화제를 간접 적정하는 절차에서 요오드화칼륨을 넣었다. 분석자는 이 시약이 요오드 반응을 이용하는 단계의 것임을 확인했다. 염소이온을 제거해야 하는 산성과망간산칼륨법의 황산은과 혼동하지 않았다.
    4. 염소이온이 많은 하천 시료로 산성과망간산칼륨법을 수행했다. 황산은에서 나온 은 이온이 염소이온과 결합해 염화은 침전을 만들었다. 분석자는 염소이온의 방해를 줄인 뒤 화학적산소요구량 반응을 진행했다.

    산성과망간산칼륨법에서는 황산은으로 염소이온 방해를 제거하므로 정답은 4번이다.

    수질오염공정시험기준상 다음 분석과정에 해당하는 항목은?

    ○ 아담스-니컬슨(Adams-Nickerson)의 공식을 근거로 측정 / ○ 육염화백금포타슘 및 염화코발트를 사용하여 표준용액 조제 / ○ 400 nm ∼ 700 nm 파장 범위의 분광광도계를 사용

    1. 1. 냄새
    2. 2. 색도
    3. 3. 탁도
    4. 4. 투명도

    정답 2번

    🔍 보기별 해설
    1. 냄새는 사람이 감각으로 맡아 판정하는 항목이다. 백금·코발트 표준용액의 분광 측정 대상이 아니므로 옳지 않다.
    2. 색도는 아담스-니컬슨 공식과 백금·코발트 표준용액을 이용해 400~700 nm 범위에서 측정한다. 옳다(정답).
    3. 탁도는 부유입자가 빛을 산란시키는 정도를 잰다. 백금·코발트 색도 표준용액의 분석과 달라 옳지 않다.
    4. 투명도는 물속 판이 보이지 않는 깊이 등으로 표시한다. 분광광도계의 색도 측정과 달라 옳지 않다.
    🧮 풀이
    1. 검사자가 물 시료의 냄새를 확인하려고 관능검사 절차를 준비했다. 사람이 직접 냄새를 맡아 판정하는 방법이라 색도 표준용액의 파장별 분광 측정과 달랐다. 그는 냄새 결과를 별도 항목에 기록했다.
    2. 백금·코발트 색도 표준용액을 농도별로 만들었다. 분석자는 400~700 nm 범위에서 광학 신호를 측정해 아담스-니컬슨 공식에 적용했다. 색도 결과를 탁도나 냄새의 검사값과 섞지 않았다.
    3. 여과 전 물에 부유입자가 많아 빛이 여러 방향으로 흩어졌다. 담당자는 탁도계로 산란 신호를 읽고 입자 제거 상태를 판단했다. 백금·코발트 용액을 기준으로 색을 계산하는 색도 시험과 구분했다.
    4. 호수 조사원이 투명도판을 물속으로 천천히 내렸다. 판이 더는 보이지 않는 깊이를 읽어 투명도를 기록했다. 검사실에서 표준용액과 분광광도계로 색도를 구하는 과정과는 다른 측정이었다.

    백금·코발트 표준용액과 400~700 nm 분광 측정은 색도 분석이므로 정답은 2번이다.

    먹는물 수질감시항목 운영등에 관한 고시상 마이크로시스틴의 검출기로 옳지 않은 것은?

    1. 1. 형광검출기
    2. 2. 자외선검출기
    3. 3. 광다이오드어레이검출기
    4. 4. 질량분석기

    정답 1번

    🔍 보기별 해설
    1. 마이크로시스틴은 일반적인 형광검출 조건에서 직접 검출하는 대상이 아니다. 제시된 검출기 목록으로는 옳지 않다(정답).
    2. 자외선검출기는 마이크로시스틴의 자외선 흡수 신호를 읽는다. 지정 분석에 쓰는 검출기이므로 옳다.
    3. 광다이오드어레이검출기는 여러 파장의 흡수 신호를 함께 기록한다. 마이크로시스틴 검출기로 옳다.
    4. 질량분석기는 이온의 질량 대 전하비로 마이크로시스틴을 구별한다. 검출기로 옳다.
    🧮 풀이
    1. 조류독소 마이크로시스틴의 분석 장치를 고르면서 형광검출기를 목록에 넣으려 했다. 분석자는 이 물질을 일반 형광 조건에서 직접 읽는 지정 검출법이 아님을 확인했다. 자외선·광다이오드어레이·질량분석 검출기를 절차에 맞춰 검토했다.
    2. 마이크로시스틴 표준용액을 분리한 뒤 자외선검출기로 신호를 읽었다. 분석자는 정해진 파장에서 흡수 피크를 확인하고 시료 피크와 비교했다. 검량선을 이용해 원수 속 독소 농도를 산출했다.
    3. 광다이오드어레이검출기가 여러 파장의 흡수 신호를 동시에 기록했다. 담당자는 마이크로시스틴 피크의 파장별 모양을 표준물질과 비교했다. 한 파장만 읽는 방식보다 피크 확인 자료를 더 확보했다.
    4. 분리된 마이크로시스틴 성분이 질량분석기로 들어갔다. 기기는 이온의 질량 대 전하비를 기록해 목표 성분을 구별했다. 분석자는 표준물질의 신호와 시료의 신호가 맞는지 확인했다.

    마이크로시스틴의 지정 검출기에 형광검출기는 없으므로 정답은 1번이다.

    랑게리아지수(LI) 분석을 위한 최소항목이 옳지 않은 것은?

    3. 3. 총알칼리도
    4. 4. 칼슘

    3. 처리수의 총알칼리도를 적정해 탄산염 완충 상태를 확인했다. 담당자는 이 값을 포화 pH 계산에 넣어 탄산칼슘이 석출될지 검토했다. pH와 칼슘만 적힌 자료표에 알칼리도 칸을 추가했다.
    4. 배수관의 스케일 발생 가능성을 살피려고 물의 칼슘 농도를 측정했다. 칼슘이 탄산칼슘 포화 평형에 직접 들어가므로 랑게리아지수 계산에 필요했다. 담당자는 측정값과 pH·알칼리도 결과를 함께 검토했다.

    1. 수돗물의 경도가 높아 비누 거품이 잘 나지 않는다는 민원이 들어왔다. 담당자는 칼슘과 마그네슘 농도를 확인해 경도 값을 계산했다. 건강상 유해 무기물과 다른 심미적 영향 항목으로 결과를 분류했다.
    2. 원수의 붕소 농도를 측정한 뒤 보고서 분류를 검토했다. 담당자는 붕소가 건강상 유해영향 무기물질 쪽에 속함을 확인했다. 물맛과 사용감에 관한 경도·증발잔류물 항목과 같은 칸에 넣지 않았다.
    3. 물 시료를 증발접시에 넣고 가열해 물을 날렸다. 남은 고형물의 질량을 측정해 증발잔류물 값을 얻었다. 담당자는 이 값이 물맛과 사용감에 영향을 줄 수 있어 심미적 영향 기준과 대조했다.
    4. 수돗물의 pH를 측정하니 평소와 다른 산성도가 나타났다. 운영자는 물맛과 배관 부식 가능성을 함께 살폈다. 수소이온농도 결과를 심미적 영향 기준에서 확인하고 약품 주입 상태를 점검했다.

    붕소는 건강상 유해영향 무기물질이므로 정답은 2번이다.

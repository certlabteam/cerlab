    표면장력이 T이고 지름이 d인 비누풍선의 내부와 외부의 압력 차이가 p일 때, 비누풍선의 표면장력에 의한 힘 Tπd와 평형을 이루는 힘은?

    1. 1. 2pd
    2. 2. p{πd² / 4}
    3. 3. pπd²
    4. 4. p{d / 4}

    정답 2번

    🔍 보기별 해설
    1. 2pd에는 원형 단면의 면적 πd²/4가 반영되지 않았다. 힘으로 옳지 않다.
    2. 압력 p에 지름 d인 원형 투영면적 πd²/4를 곱한 힘이다. 표면장력 힘과 평형을 이루므로 옳다(정답).
    3. pπd²는 원형 투영면적의 네 배를 사용한 값이다. 옳지 않다.
    4. pd/4는 면적에 필요한 지름의 제곱과 π가 빠졌다. 힘으로 옳지 않다.
    🧮 풀이
    1. 비누풍선을 반으로 자른 자유물체도를 그려 압력 힘을 계산했다. 담당자는 압력에 단순한 길이 2d를 곱하면 힘의 단위가 되지 않는다고 확인했다. 원형 투영면적을 먼저 구해 식을 다시 세웠다.
    2. 지름 d인 비누풍선의 한쪽 반구를 떼어 낸 모형을 그렸다. 압력차 p가 작용하는 투영면적은 반지름 d/2인 원의 넓이 πd²/4였다. 담당자는 p에 이 면적을 곱해 표면장력 힘과 평형을 맞췄다.
    3. 풍선 단면적을 πd²로 적은 계산서를 검토했다. 실제 반지름은 d가 아니라 d/2라 면적이 네 배 크게 계산됐다. 담당자는 압력 힘을 pπd²/4로 바로잡고 단면 그림에도 반지름을 표시했다.
    4. 압력차 p에 d/4만 곱한 식을 힘이라고 적었다. 담당자는 면적에 필요한 지름 제곱과 원주율이 빠진 것을 확인했다. 원형 단면을 그려 단위를 맞춘 뒤 압력 힘을 다시 구했다.

    압력이 작용하는 투영면적이 πd²/4이므로 정답은 2번이다.

    관수로 흐름의 마찰손실수두에 관한 설명으로 옳지 않은 것은?

    1. 1. 마찰손실계수에 비례한다.
    2. 2. 관경에 반비례한다.
    3. 3. 속도수두에 반비례한다.
    4. 4. 관로 길이에 비례한다.

    정답 3번

    🔍 보기별 해설
    1. Darcy-Weisbach 식 hL=f(L/D)V²/(2g)에 f가 곱해진다. 옳다.
    2. 같은 조건에서 식의 D가 분모에 있으므로 관경에 반비례한다. 옳다.
    3. 식에 속도수두 V²/(2g)가 곱해진다. 반비례한다는 말은 옳지 않다(정답).
    4. 같은 조건에서 길이 L이 커지면 손실도 커진다. 옳다.
    🧮 풀이
    1. 같은 관과 유속에서 관벽 상태가 달라 마찰계수 f가 커졌다. 담당자는 손실수두 식에 f를 곱해 값이 함께 커지는 것을 확인했다. 관로 손실과 펌프 양정의 변화를 기록했다.
    2. 관경만 넓혀 길이비 L/D를 다시 계산했다. 다른 조건이 같으면 분모 D가 커져 손실수두는 낮아졌다. 설계자는 더 큰 관의 비용과 펌프 동력 절감을 함께 비교했다.
    3. 송수관 유속을 높이자 속도수두 V²/(2g)가 커졌다. 같은 길이비와 마찰계수에서 손실수두도 증가했다. 담당자는 속도수두에 반비례한다고 적힌 계산 메모를 고쳤다.
    4. 같은 직경과 재질의 관을 두 배 길게 설치했다. 물이 관벽과 마찰하는 거리가 늘어 손실수두가 커졌다. 설계자는 추가 손실을 펌프 전양정에 반영하고 모터 용량을 확인했다.

    마찰손실은 속도수두에 비례하므로 정답은 3번이다.

    속도수두와 마찰손실수두가 같은 관수로 흐름에서 마찰손실계수는?

    1. 1. 관의 길이를 관경으로 나눈 값
    2. 2. 관경을 관의 길이로 나눈 값
    3. 3. 관의 길이를 마찰손실수두로 나눈 값
    4. 4. 관경을 마찰손실수두로 나눈 값

    정답 2번

    🔍 보기별 해설
    1. L/D는 마찰손실식에서 f와 곱해지는 값이다. f 자체로 옳지 않다.
    2. hL=f(L/D)h_v에서 hL=h_v이므로 f=D/L이다. 옳다(정답).
    3. 길이를 손실수두로 나눈 값은 마찰계수의 차원 없는 식이 아니다. 옳지 않다.
    4. 관경을 손실수두로 나눈 값은 길이비일 뿐 f=D/L이 아니다. 옳지 않다.
    🧮 풀이
    1. 관의 길이 L을 직경 D로 나눠 L/D를 얻었다. 담당자는 이 값이 마찰계수 f와 곱해져 손실과 속도수두의 비가 된다고 확인했다. L/D 자체를 f라고 적은 식은 수정했다.
    2. 관에서 마찰손실수두와 속도수두가 똑같이 측정됐다. Darcy-Weisbach 식의 두 수두를 약분하니 fL/D=1이 됐다. 담당자는 f를 관경 D를 길이 L로 나눈 값으로 정리했다.
    3. 관 길이를 마찰손실수두로 나누어 f를 구하려 했다. 담당자는 그 계산에 관경과 속도수두 조건이 빠져 있다고 확인했다. 두 수두가 같다는 조건으로 원래 식을 정리해 D/L을 얻었다.
    4. 관경을 마찰손실수두로 나눈 값을 마찰계수라고 적었다. 담당자는 손실수두 대신 관 길이 L이 분모에 있어야 함을 확인했다. 손실과 속도수두가 같은 조건을 식에 대입해 결과를 고쳤다.

    hL=속도수두이면 fL/D=1이므로 f=D/L인 2번이 정답이다.

    직경이 100 mm이고 길이는 200 m인 관에 2 m/s의 평균유속으로 물이 흐를 때, 마찰손실수두가 6 m이었다. 마찰손실계수(f)는? (단, 중력가속도는 9.8 m/s²이다.)

    1. 1. 0.0147
    2. 2. 0.0221
    3. 3. 0.0294
    4. 4. 0.0588

    정답 1번

    🔍 보기별 해설
    1. f=6×(0.1/200)×(19.6/4)=0.0147이다. 옳다(정답).
    🧮 풀이
    1. ① 관경 단위를 바꾼다.
    2. 100 mm는 0.1 m다.
    3. → D=0.1 m
    4. ↓
    5. ② 길이비를 구한다.
    6. 관 길이 200 m를 관경 0.1 m로 나눈다.
    7. → L/D=2000
    8. ↓
    9. ③ 속도수두를 구한다.
    10. 유속 2 m/s와 중력가속도 9.8 m/s²를 쓴다.
    11. → V²/(2g)=4/19.6 m
    12. ↓
    13. ④ 손실식에 대입한다.
    14. 주어진 손실수두 6 m를 넣는다.
    15. → 6=f×2000×4/19.6
    16. ↓
    17. ⑤ 계수를 구한다.
    18. 양쪽을 2000×4/19.6으로 나눈다.
    19. → f=0.0147
    20. ↓
    21. ⑥ 보기를 고른다.
    22. 계산값과 같은 값을 찾는다.
    23. → 0.0147, 1번

    f=6×0.1×19.6/(200×4)=0.0147이므로 정답은 1번이다.

    압력과 압력수두의 MLT계 차원으로 옳게 나타낸 것은?

    1. 1. 압력: ML⁻¹T⁻², 압력수두: ML⁻¹T⁻²
    2. 2. 압력: ML⁻¹T⁻², 압력수두: L
    3. 3. 압력: ML⁻², 압력수두: L
    4. 4. 압력: ML⁻¹T⁻², 압력수두: ML⁻²T⁻²

    정답 2번

    🔍 보기별 해설
    1. 압력 차원은 맞지만 압력수두는 압력을 단위중량으로 나눈 길이다. 두 차원이 같다는 말은 옳지 않다.
    2. 압력은 힘/면적이라 ML⁻¹T⁻²이고 압력수두는 높이라 L이다. 옳다(정답).
    3. ML⁻²는 힘을 면적으로 나눈 압력의 시간 차원이 빠졌다. 옳지 않다.
    4. 압력수두를 ML⁻²T⁻²로 둔 것은 높이 L과 다르다. 옳지 않다.
    🧮 풀이
    1. 압력 단위 Pa와 압력수두 단위 m를 같은 차원으로 적었다. 담당자는 압력을 물의 단위중량으로 나누어 높이만 남는 과정을 확인했다. 두 물리량의 차원을 서로 다른 칸에 수정했다.
    2. 힘의 차원 [MLT⁻²]를 면적 [L²]으로 나눠 압력 차원을 구했다. 압력수두는 다시 단위중량으로 나눠 길이 L을 얻었다. 분석자는 두 차원 결과를 계산서에 나란히 적었다.
    3. 압력 차원에서 시간 지수를 빠뜨린 [ML⁻²]을 보았다. 담당자는 힘에 가속도 T⁻²가 들어가고 면적을 나눠도 그 지수가 남는다고 확인했다. 압력 차원을 [ML⁻¹T⁻²]로 다시 썼다.
    4. 압력수두를 질량과 시간이 남는 차원으로 적은 보고서를 검토했다. 실제 압력을 단위중량으로 나누니 질량과 시간 차원이 사라졌다. 담당자는 높이를 나타내는 L만 남겼다.

    압력 차원은 ML⁻¹T⁻², 압력수두 차원은 L이므로 정답은 2번이다.

    Manning 공식과 관련이 없는 것은?

    1. 1. 경심
    2. 2. 조도계수
    3. 3. 단면수축계수
    4. 4. 동수경사

    정답 3번

    🔍 보기별 해설
    1. 경심 또는 동수반경 R은 Manning 식의 R^(2/3)에 들어간다. 옳다.
    2. 조도계수 n은 관벽·수로 바닥의 거칠기를 나타내며 Manning 식의 분모에 있다. 옳다.
    3. 단면수축계수는 흐름이 좁은 곳을 지날 때 수축하는 정도를 나타낸다. Manning 식의 인자로 옳지 않다(정답).
    4. 동수경사 I의 제곱근은 Manning 식에 들어간다. 옳다.
    🧮 풀이
    1. 개수로 단면적을 물에 젖은 둘레로 나눠 경심 R을 구했다. 설계자는 Manning 유속식의 R^(2/3)에 그 값을 넣었다. 수로 바닥과 벽에 물이 닿는 범위를 정확히 그려 윤변을 확인했다.
    2. 거친 수로 바닥과 매끈한 콘크리트 수로의 조도계수를 비교했다. 같은 경사와 단면이라도 n이 커진 곳의 계산 유속이 낮았다. 담당자는 재질에 맞는 n을 Manning 식의 분모에 적용했다.
    3. 좁은 목을 지나는 물줄기의 단면수축 정도를 관찰했다. 담당자는 이 계수가 개구부 흐름에는 필요하지만 Manning 식의 R·n·경사 항에는 없음을 확인했다. 수축계수를 수로 조도계수와 혼동하지 않았다.
    4. 수로 양끝의 수두 차와 길이로 동수경사를 구했다. 설계자는 경사의 제곱근을 Manning 식에 넣어 유속을 계산했다. 경사가 바뀌었을 때 유량이 얼마나 달라지는지도 확인했다.

    Manning 식에 들어가지 않는 단면수축계수가 정답인 3번이다.

    관수로 유량측정 장치가 아닌 것은?

    1. 1. 위어
    2. 2. 오리피스
    3. 3. 노즐
    4. 4. 벤츄리미터

    정답 1번

    🔍 보기별 해설
    1. 위어는 열린 수로에서 월류 수심으로 유량을 잰다. 관수로 측정 장치로 옳지 않다(정답).
    2. 오리피스는 관의 구멍을 통과하는 차압과 유량의 관계를 이용할 수 있다. 옳다.
    3. 노즐은 관 안의 단면을 줄여 생긴 압력 차로 유량을 잴 수 있다. 옳다.
    4. 벤츄리미터는 관의 좁아진 목에서 압력 차를 측정한다. 관수로 유량계로 옳다.
    🧮 풀이
    1. 열린 수로에 위어를 설치해 넘치는 물의 수심을 측정했다. 담당자는 월류 높이로 유량을 구하고 관 내부 차압은 재지 않았다. 닫힌 관에 다는 벤츄리미터와 설치 위치를 구분했다.
    2. 관 안에 오리피스를 끼워 통과 단면을 좁혔다. 앞뒤 압력 차를 측정하니 유량에 따라 값이 달라졌다. 담당자는 차압 관계를 이용해 관수로의 유량을 계산하고 계기 눈금을 확인했다.
    3. 관 내부에 노즐을 달아 물살을 빠르게 만들었다. 입구와 노즐 목의 압력 차를 읽어 유량을 추정했다. 운영자는 기기 앞뒤 직관부와 막힘 상태를 함께 확인해 측정 오차를 줄였다.
    4. 벤츄리미터의 좁아진 목에서 압력이 떨어졌다. 담당자는 입구와 목의 차압을 측정해 닫힌 관의 유량을 계산했다. 위어처럼 열린 수면에서 넘침 높이를 재지 않고 관 내 압력을 읽었다.

    위어는 주로 개수로 유량을 재므로 정답은 1번이다.

    관수로에서 레이놀즈 수의 계산식과 관계 있는 것을 모두 고른 것은?

    ㄱ. 유체의 점성계수

    ㄴ. 관의 길이

    ㄷ. 관의 직경

    ㄹ. 관내의 평균유속

    2. 2. ㄱ, ㄴ, ㄹ
    3. 3. ㄱ, ㄷ, ㄹ
    4. 4. ㄴ, ㄷ, ㄹ

    정답 3번

    🔍 보기별 해설
    1. 레이놀즈수 Re=ρVD/μ이므로 점성계수 μ가 들어간다. 옳다.

    3. 기존 펌프로는 높은 배수지까지 필요한 압력을 확보하지 못한다. 관리자는 두 번째 펌프를 직렬로 달아 같은 유량에서 얻는 양정을 높인다. 양정을 거의 바꿀 필요가 없는 상황을 직렬운전의 대표 용도로 적으면 설치 목적을 거꾸로 설명한 셈이다.
    4. 정수장 수요가 커져 시간당 보내야 할 물의 양이 부족해졌다. 관리자는 펌프를 병렬로 추가해 합계 토출량을 늘리는 방안을 검토한다. 높은 양정이 우선 필요한 상황이라면 같은 유량의 양정을 합하는 직렬 구성을 살펴야 한다.

    직렬운전은 같은 유량에서 두 펌프 양정을 합하므로 정답은 1번이다.

    펌프의 축동력에 관한 설명으로 옳은 것은?

    2. 축동력은 같은 조건에서 전양정 H가 커지면 커진다. 반비례는 옳지 않다.
    3. 축동력은 수동력을 효율 η로 나눈다. 효율에 정비례한다는 말은 옳지 않다.
    4. 펌프 축동력은 일률이므로 kW 또는 HP로 표시한다. 옳다(정답).

    2. 운전자가 같은 유량을 더 높은 탱크로 보내는 펌프를 선정한다. 물에 더 큰 에너지를 줘야 하므로 전양정이 커지면 필요한 축동력도 증가한다. 양정이 커지는데 동력이 감소한다고 보면 적합한 전동기를 고를 수 없다.

    4. 설계자가 펌프의 유량과 전양정으로 필요한 축동력을 계산한다. 결과를 전동기 명판의 kW 수치와 비교해 용량이 충분한지 확인한다. 낡은 설비 자료가 HP로 적혀 있으면 단위를 맞춰 환산한 뒤 같은 일률끼리 비교한다.

    운전중인 펌프의 토출량을 제어하기 위한 방법이 아닌 것은?

    4. 4. 펌프의 운전대수 제어

    정답 2번

    🔍 보기별 해설
    1. 토출밸브 개도를 바꾸면 관로 저항과 운전점이 달라진다. 유량 제어로 옳다.
    2. 압력은 펌프 운전점에서 관측·관리하는 값이다. 제시된 직접 토출량 제어 방식의 분류로는 옳지 않다(정답).

    4. 가동 펌프 대수를 바꾸면 합성곡선이 달라져 토출량을 조절할 수 있다. 옳다.
    🧮 풀이
    1. 여과지로 보내는 물이 갑자기 많아져 운전자가 펌프 토출밸브를 조금 닫는다. 관로 저항이 증가하면서 펌프 특성곡선과 관로 곡선의 교점이 이동한다. 그는 새 운전점에서 유량계 수치가 목표 토출량에 맞는지 확인한다.
    2. 운전실 화면에 펌프 토출압력이 높게 나타나자 담당자가 압력계를 살핀다. 압력값은 현재 운전 상태를 알려 주지만 그 값을 읽는 일만으로 토출량이 조절되지는 않는다. 밸브 개도나 회전속도처럼 운전점을 바꾸는 조작을 따로 해야 한다.
    3. 변속기가 달린 펌프에서 수요가 줄어 운전자가 회전속도를 낮춘다. 펌프 특성곡선이 바뀌고 관로 곡선과 만나는 유량도 감소한다. 그는 유량계를 보며 속도를 조금씩 조정해 목표 토출량을 맞춘다.
    4. 여러 대를 묶어 쓰는 가압장에서 한 대만 돌리다가 급수 수요가 늘어난다. 담당자가 대기 중인 펌프를 추가로 켜면 합성 특성곡선이 달라진다. 병렬 운전의 새 운전점에서 전체 토출량이 얼마나 늘었는지 확인한다.

    펌프의 수격현상을 경감시키는 방법이 아닌 것은?

    이직이 호텔기업에 미치는 부정적 영향이 아닌 것은?

    1. 1. 선발과 모집비용의 증대
    2. 2. 조직구성원의 사기 저하
    3. 3. 종사원들의 사회적 통합 촉진
    4. 4. 조직운용상의 혼란 초래

    정답 3번

    🔍 보기별 해설
    1. 이직은 조직의 운영에도 영향을 준다. 선발과 모집비용의 증대는 이직의 부정적 영향이므로 해당하지 않는다.
    2. 이직은 조직의 운영에도 영향을 준다. 조직구성원의 사기 저하도 부정적 영향이므로 해당하지 않는다.
    3. 이직은 조직의 운영에도 영향을 준다. 종사원들의 사회적 통합 촉진은 이직이 오히려 막는 것이라 부정적 영향으로 보기 어려우므로 해당한다(정답).
    4. 이직은 조직의 운영에도 영향을 준다. 조직운용상의 혼란 초래도 부정적 영향이므로 해당하지 않는다.
    🧮 풀이
    1. 직원이 자꾸 그만두자 새로 뽑고 교육하는 비용이 늘었다. 호텔은 빈자리를 채울 때마다 추가 예산을 썼다.
    2. 잦은 이직 소식에 남은 직원들의 사기가 떨어졌다. 남은 직원은 업무를 다시 나누느라 부담을 느꼈다.
    3. 오랜 근속자들이 쌓아온 유대감은 이직이 늘수록 오히려 약해졌다. 동료 사이의 관계가 끊기고 새 직원과 다시 맞춰야 했다.
    4. 갑작스러운 퇴사로 업무 인수인계가 뒤엉켰다. 담당자가 바뀌어 고객 인계가 늦어졌다.

    사회적 통합 촉진은 이직의 부정적 영향으로 보기 어려우므로, 정답은 3번이다.

    2. 2. 기업 이윤의 요소

    4. 임금은 기업과 직원에게 의미가 다르다. 생계비 유지의 원천은 종사원 측면의 임금 중요성이므로 해당한다(정답).
    🧮 풀이

    4. 직원은 매달 받는 월급으로 생활비를 꾸려갔다. 직원은 월급으로 집세와 식비를 냈다.

    종사원 측면에서 임금은 생계비 유지의 원천이므로, 정답은 4번이다.

    복리후생관리의 원칙에 해당하는 것은?

    1. 1. 예외의 원칙
    2. 2. 협력성의 원칙
    3. 3. 전문화의 원칙
    4. 4. 정기성의 원칙

    정답 2번

    🔍 보기별 해설
    1. 복리후생은 운영 원칙에 따라 설계한다. 예외의 원칙은 복리후생관리의 원칙으로 명시되지 않으므로 해당하지 않는다.
    2. 복리후생은 운영 원칙에 따라 설계한다. 협력성의 원칙은 복리후생관리의 원칙이므로 해당한다(정답).
    3. 복리후생은 운영 원칙에 따라 설계한다. 전문화의 원칙은 복리후생관리의 원칙으로 명시되지 않으므로 해당하지 않는다.
    4. 복리후생은 운영 원칙에 따라 설계한다. 정기성의 원칙도 복리후생관리의 원칙으로 명시되지 않으므로 해당하지 않는다.
    🧮 풀이
    1. 호텔이 예외 직원만 복지혜택을 받도록 규정을 만들었다. 나머지 직원의 요구가 빠져 복리후생관리의 일반 원칙으로 삼지 않았다. 다른 직원들은 혜택에서 빠져 불만을 냈다.
    2. 호텔 노사가 건강검진과 휴게실 운영안을 함께 논의했다. 양쪽이 협력해 이용 기준을 정했으니 협력성의 원칙이 적용됐다. 직원들은 정한 기준에 따라 혜택을 이용했다.
    3. 호텔이 복지 업무를 한 담당자의 전문 분야로만 좁혔다. 직원 전체의 복지 수요를 함께 조정하는 협력성 원칙과는 다른 조치였다. 현장 직원의 복지 요구는 그 담당자에게 전달되지 않았다.
    4. 호텔이 복지안을 매년 같은 날짜에 발표했다. 발표 주기는 정했지만 노사 협력 여부를 판단하는 원칙은 아니었다. 정기 발표만으로 직원 의견을 반영한 것은 아니었다.

    협력성의 원칙이 복리후생관리의 원칙이므로, 정답은 2번이다.

    종사원 측면에서의 복리후생의 이점이 아닌 것은?

    1. 1. 사기의 앙양
    2. 2. 경영자와의 관계개선
    3. 3. 채용 및 교육훈련 비용의 절감
    4. 4. 고용안정 및 생활수준 향상

    정답 3번

    🔍 보기별 해설
    1. 복리후생의 수혜자는 양쪽이다. 사기의 앙양은 종사원 측면의 복리후생 이점이므로 해당하지 않는다.
    2. 복리후생의 수혜자는 양쪽이다. 경영자와의 관계개선도 종사원 측면의 이점이므로 해당하지 않는다.
    3. 복리후생의 수혜자는 양쪽이다. 채용 및 교육훈련 비용의 절감은 기업(사용자) 측면의 이점이라 종사원 측면이 아니므로 해당한다(정답).
    4. 복리후생의 수혜자는 양쪽이다. 고용안정 및 생활수준 향상도 종사원 측면의 이점이므로 해당하지 않는다.
    🧮 풀이
    1. 복지가 좋다는 소문에 직원들의 근무 의욕이 높아졌다. 직원은 복지혜택 때문에 호텔에 계속 다닐 의욕을 느꼈다.
    2. 복리후생 상담을 통해 직원과 경영자 사이의 거리가 가까워졌다. 노사가 함께 필요한 혜택을 조정했다.
    3. 복리후생이 좋은 호텔은 채용과 신입 교육에 드는 비용을 줄일 수 있었다. 채용 비용을 줄이는 직접 수혜자는 호텔 기업이다.
    4. 복지 혜택을 누린 직원들의 생활이 안정됐다. 직원은 복지 덕분에 생활비 부담을 덜었다.

    채용·교육훈련 비용 절감은 기업 측면의 이점이므로, 정답은 3번이다.

    🧮 풀이

    4. 호텔 팀장이 직원에게 지시를 따르는 법만 반복해 가르쳤다. 직원의 성장과 자율성을 돕지 않았으므로 서번트 리더의 지원 역할과 달랐다. 팀원은 지시만 따르기보다 스스로 판단할 기회를 잃었다.

    서번트 리더는 슈퍼추종자가 아니라 슈퍼리더를 키우는 것을 지향하므로, 정답은 4번이다.

    산업재해 발생원인 중 인적요인이 아닌 것은?

    4. 4. 피로에 의한 요인

    🔍 보기별 해설

    2. 산업재해 원인은 사람과 환경으로 나뉜다. 물리적·화학적 요인은 환경적 요인이라 인적 요인이 아니므로 해당한다(정답).
    3. 산업재해 원인은 사람과 환경으로 나뉜다. 부주의에 의한 요인도 인적 요인이므로 해당하지 않는다.
    4. 산업재해 원인은 사람과 환경으로 나뉜다. 피로에 의한 요인도 인적 요인이므로 해당하지 않는다.
    🧮 풀이
    1. 숙련도가 낮은 신입 직원 쪽에서 사고가 더 자주 났다. 호텔은 새 직원에게 위험 작업 교육을 더 했다.
    2. 호텔 주방 바닥에 물이 고여 있었다. 조리사가 미끄러져 다쳤으니 직원 성격보다 작업환경이 사고 원인이다. 호텔은 바닥을 말리고 미끄럼 방지판을 깔았다.
    3. 잠깐의 부주의로 조리 중 화상을 입는 사고가 났다. 호텔은 작업 순서를 다시 알려 화상을 막으려 했다.
    4. 장시간 근무로 피로가 쌓인 직원이 실수를 저질렀다. 호텔은 쉬는 시간을 늘려 피로 누적을 줄였다.

    물리적·화학적 요인은 환경적 요인이므로, 정답은 2번이다.

    집단 갈등으로 인하여 발생할 수 있는 집단 내 역기능적 결과가 아닌 것은?

    2. 2. 독재적 리더의 등장
    3. 3. 타 집단에 대한 우호적 태도 조성
    4. 4. 집단규범의 강조와 충성심의 증가

    정답 3번

    🔍 보기별 해설

    2. 집단 갈등은 조직 안팎에 영향을 준다. 독재적 리더의 등장도 갈등의 역기능으로 꼽히므로 해당하지 않는다.
    3. 집단 갈등은 조직 안팎에 영향을 준다. 타 집단에 대한 우호적 태도 조성은 갈등 시 오히려 적대적 태도가 생기므로, 우호적이라고 적은 이 설명은 역기능이 아니라 해당한다(정답).
    4. 집단 갈등은 조직 안팎에 영향을 준다. 집단규범의 강조와 충성심의 증가도 갈등의 역기능으로 꼽히므로 해당하지 않는다.
    🧮 풀이
    1. 주방팀과 서비스팀이 다투자 각 팀 내부의 단결력은 오히려 강해졌다. 직원들은 자기 팀 편을 더 강하게 들었다.
    2. 갈등이 길어지자 한 부서에서 강압적인 리더가 나서서 상황을 정리했다. 팀원들은 결정권을 한 사람에게 몰아줬다.
    3. 두 부서 간 갈등이 깊어질수록 서로에 대한 반감도 함께 커졌다. 두 부서는 상대에게 정보를 늦게 주기 시작했다.
    4. 갈등 중인 팀의 구성원들이 자기 팀 규범을 더 강하게 따르기 시작했다. 팀원들은 자기 부서 규칙을 더 엄격히 따랐다.

    갈등이 생기면 타 집단에 적대적 태도가 생기므로, 정답은 3번이다.

    다음에 해당되는 교육 훈련 방법은? 타인이 생각하고 느끼는 것을 정확하게 감지하는 능력과 이 능력에 입각하여 적절하고 유연한 태도와 행동을 취할 수 있는 능력을 갖게 된다. 방법은 리더가 없는 토의와 비슷하며, 전인격적인 통찰의 체험학습으로 태도가 변화되도록 하는 방법이다.

    1. 1. 인바스켓훈련(in-basket training)
    2. 2. 감수성훈련(sensitivity training)
    3. 3. 대역법(understudies)
    4. 4. 브레인스토밍(brain storming)

    정답 2번

    🔍 보기별 해설
    1. 인바스켓훈련은 쌓인 문서와 업무를 제한 시간 안에 처리하는 훈련이다. 해당하지 않는다.
    2. 감수성훈련은 집단 대화로 타인의 감정과 자신의 반응을 알아차린다. 해당한다(정답).
    3. 대역법은 상급자의 직무를 대신 맡아 보는 훈련이다. 해당하지 않는다.
    4. 브레인스토밍은 판단을 미루고 아이디어를 많이 내는 방법이다. 해당하지 않는다.
    🧮 풀이
    1. 호텔 관리자 후보가 밀린 이메일과 결재 문서를 시간 안에 처리했다. 인바스켓훈련이다
    2. 호텔 직원이 소집단 대화에서 동료가 느낀 감정을 들었다. 자신의 말투를 고쳐 보며 감수성훈련을 했다
    3. 호텔의 차기 객실팀장이 현재 팀장을 따라다니며 업무를 대신 맡았다. 대역법을 적용했다
    4. 호텔 팀이 서비스 아이디어를 비판 없이 쏟아냈다. 여러 제안을 모은 브레인스토밍이다

    정답은 2번이다.

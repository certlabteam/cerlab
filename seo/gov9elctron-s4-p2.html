    4. 4. 10 8 구형파

    🔍 보기별 해설
    1. 입력 기울기 ±2×10⁶ V/s에 RC=2 μs를 곱하면 출력은 ∓4 V다. 주기 10 μs와 첨두간값 8 V의 구형파이므로 옳다(정답).

    2. → |dV_i/dt|=10 V/5 μs=2×10⁶ V/s

    6. → |V_o|=RC×2×10⁶=4 V
    7. ↓

    9. ? 10 8 ??? (?? 10 ?s, ???? 8 V)

    2. 공핍영역 전계는 고정 전하의 분포를 적분하면 접합면에서 크기가 가장 큰 삼각형 모양이 된다. 그림 (나)가 이를 나타내므로 옳다.

    🧮 풀이
    1. P형과 N형 반도체를 접합하면 이동 캐리어가 접합면을 건너 재결합한다. P쪽 공핍영역에는 음전하의 고정 억셉터 이온이, N쪽에는 양전하의 도너 이온이 남는다. 공간전하밀도를 위치별로 그리면 접합면 양쪽에서 부호가 바뀌는 계단형이 된다.

    다음은 슈미트 트리거(Schmitt Trigger) 회로와 이 회로의 입력( v_i )에 대한 출력( v_o )의 전달특성을 나타낸 것이다. 출력전압 v_o 의 양의 포화전압을 V_H [V], 음의 포화전압을 V_L [V]이라고 할 때, 전달특성 그래프에서 출력이 V_H [V]에서 V_L [V]로 천이되는 임계전압 V_TH [V]는? (단, 연산 증폭기는 이상적이다)

    1. 1. {R_1 / R_1 + R_2}V_L
    2. 2. {R_2 / R_1 + R_2} V_H
    3. 3. {R_1 / R_1 + R_2}V_H
    4. 4. {R_2 / R_1 + R_2} (V_H + V_L)

    정답 3번

    🔍 보기별 해설
    1. 출력이 V_H인 동안 비반전 입력은 R₁/(R₁+R₂)×V_H다. 입력이 이 값을 넘을 때 출력이 V_L로 전환하므로 3번 식이 옳다(정답).
    🧮 풀이
    1. ① 출력이 아직 양의 포화전압 V_H에 머무는 구간을 본다. 귀환 저항 R₂와 접지 쪽 저항 R₁이 출력 전압을 나눈다.
    2. → V_+=R₁V_H/(R₁+R₂)
    3. ↓
    4. ② 반전 입력 v_i가 이 비반전 입력값에 이르면 비교기의 출력 상태가 바뀐다. 양의 포화에서 음의 포화로 내려가는 경계가 상향 임계값이다.
    5. → V_TH=V_+=R₁V_H/(R₁+R₂)
    6. ↓
    7. ③ 예를 들어 R₁=R₂이면 양의 포화 전압의 절반에서 전환된다. V_L을 쓰면 반대 방향 전환의 임계값을 구하게 된다.
    8. → V_TH=R₁V_H/(R₁+R₂)

    출력이 V_H일 때 비반전 입력의 분압값은 R₁V_H/(R₁+R₂)이므로 상향 임계값도 그 값이다.

    다음 연산 증폭기 회로의 전압 이득 V_o/V_i 는? (단, 모든 회로 소자는 이상적이다)

    1. 1. - {R_2 (R_3 + R_4) / R_1 R_3}
    2. 2. - {R_1 (R_3 + R_4) / R_2 R_3}
    3. 3. - {(R_1 + R_2)R_4 / R_2 R_3}
    4. 4. - {(R_1 + R_2)R_4 / R_1 R_3}

    정답 4번

    🔍 보기별 해설
    1. 첫 단 이득은 (R₁+R₂)/R₁이고 둘째 단 이득은 −R₄/R₃다. 둘을 곱한 −(R₁+R₂)R₄/(R₁R₃)이므로 옳다(정답).
    🧮 풀이
    1. ① 입력 V_i가 첫 연산증폭기의 비반전 단자로 들어간다. R₁과 R₂의 피드백으로 첫 단의 출력은 입력보다 (1+R₂/R₁)배 커진다.
    2. → V₁/V_i=(R₁+R₂)/R₁
    3. ↓
    4. ② V₁은 둘째 단의 반전 입력으로 들어간다. 둘째 단의 입력 저항은 R₃, 피드백 저항은 R₄여서 이득에 음의 부호가 붙는다.
    5. → V_o/V₁=−R₄/R₃
    6. ↓
    7. ③ 중간 전압 V₁을 소거하고 두 비를 곱한다. 첫 단의 분모는 R₁이지 R₂가 아니다.
    8. → V_o/V_i=−(R₁+R₂)R₄/(R₁R₃)

    첫 단 비반전 이득 (R₁+R₂)/R₁에 둘째 단 반전 이득 −R₄/R₃를 곱한 값이 전체 이득이다.

    다음 연산 증폭기 회로에서 출력전압 V_o [V]는? (단, 모든 회로 소자는 이상적이다)

    1. 1. 6
    2. 2. 12
    3. 3. 15
    4. 4. 18

    정답 1번

    🔍 보기별 해설
    1. 150 Ω에 입력 전류가 흐르지 않아 V_+=13 V이고 가상 단락으로 V_−=13 V다. 출력과 직렬 7 V 전원의 극성에 따라 V_o=13−7=6 V이므로 옳다(정답).
    🧮 풀이
    1. ① 이상적 연산증폭기 비반전 입력에는 전류가 0이다. 150 Ω 저항의 전압 강하도 0이어서 입력 단자 전압이 전원과 같은 13 V다.
    2. → V_+=13 V
    3. ↓
    4. ② 음귀환이 걸린 두 입력은 같은 전압을 유지한다. 따라서 반전 입력도 13 V이고 그 경로의 30 kΩ 저항에도 입력 전류가 흐르지 않는다.
    5. → V_−=V_+=13 V
    6. ↓
    7. ③ 그림의 7 V 전원이 출력 쪽에 직렬로 들어간 극성을 읽는다. 반전 단자 전압은 출력보다 7 V 높다.
    8. → V_o+7=13 ⇒ V_o=6 V

    이상적 연산증폭기의 두 입력이 13 V이고 출력 쪽 직렬 7 V의 극성을 적용하면 V_o=13−7=6 V다.

    다음 회로에서 제너 다이오드의 역할은? (단, 모든 회로 소자는 이상적이고, 입력전압 V_S 는 제너 항복전압 V_Z 보다 크다)

    1. 1. 부하저항 R_L 에 걸리는 전압을 일정하게 유지시켜 준다.
    2. 2. 부하저항 R_L 의 값을 일정하게 유지시켜 준다.
    3. 3. 순방향의 전압이 인가되면 빛을 발한다.
    4. 4. 회로가 발진할 수 있게 한다.

    정답 1번

    🔍 보기별 해설
    1. 제너 다이오드는 역방향 항복 상태에서 거의 일정한 제너전압을 유지한다. 병렬로 연결된 부하 R_L의 전압도 일정해지므로 옳다(정답).
    2. 부하저항 R_L의 값은 부하 자체의 특성으로 정해진다. 제너 다이오드는 저항값이 아니라 부하 전압을 유지하므로 옳지 않다.
    3. 순방향 전압을 받아 빛을 내는 소자는 LED(발광 다이오드)다. 제너 다이오드의 정전압 역할과 다르므로 옳지 않다.
    4. 발진은 증폭기와 양의 귀환 경로가 조건을 맞출 때 지속된다. 제너 다이오드는 전압 제한에 쓰이므로 발진 역할이라는 설명은 옳지 않다.
    🧮 풀이
    1. 입력 전압 V_S가 제너 항복전압 V_Z보다 높아지면 제너 다이오드가 역방향으로 전류를 흘린다. 부하가 병렬로 연결돼 있어 두 소자에는 같은 전압이 걸린다. 입력이 조금 변해도 제너 전류가 조절되어 R_L 양단 전압은 V_Z 가까이 유지된다.
    2. 부하저항 R_L을 1 kΩ에서 2 kΩ으로 바꾸면 저항값은 실제로 두 배가 된다. 제너 다이오드는 그 변화 자체를 되돌리지 않는다. 항복 영역에서 제너 전류와 부하 전류의 분배가 달라지며 부하 양단 전압을 일정하게 만든다.
    3. LED에는 순방향 전압을 걸어 전류를 흘리면 반도체 접합에서 빛이 나온다. 제너 다이오드는 역방향 항복 전압을 정전압 기준으로 쓰는 소자다. 순방향 발광을 제너의 역할로 붙이면 두 다이오드의 동작을 혼동한 것이다.
    4. 발진 회로에서는 출력 일부를 입력으로 되돌리는 양의 귀환 경로와 충분한 증폭 이득이 필요하다. 제너 다이오드만 부하와 병렬로 붙인 정전압 회로에는 그런 귀환 구조가 없다. 출력은 일정한 전압으로 제한될 뿐 스스로 주기 파형을 만들지 않는다.

    제너 다이오드는 항복 전압에서 양단 전압을 일정하게 유지하므로 병렬로 이어진 부하 저항 R_L 양단 전압을 일정하게 유지시켜 주는 역할을 하며 1번이 옳다.

    n 개의 선택 신호를 가진 멀티플렉서의 입력 개수와 m 개의 선택 신호를 가진 디멀티플렉서의 출력 개수는?

    입력 개수 출력 개수

    1. 1. n 2^m
    2. 2. 2^n m
    3. 3. 2^n 2^m
    4. 4. n m

    정답 3번

    🔍 보기별 해설
    1. n은 선택 신호의 개수이지 멀티플렉서 데이터 입력의 개수가 아니다. 입력은 선택 신호 조합만큼 2ⁿ개여야 하므로 옳지 않다.
    2. 멀티플렉서의 입력 2ⁿ개는 맞지만 디멀티플렉서 출력 m개가 틀렸다. m개의 선택 신호는 2ᵐ개 출력을 지정하므로 옳지 않다.
    3. 멀티플렉서는 n개 선택 신호로 2ⁿ개 입력 중 하나를 고른다. 디멀티플렉서는 m개 선택 신호로 2ᵐ개 출력 중 하나에 보내므로 옳다(정답).
    4. 입력 n개와 출력 m개는 둘 다 선택 신호 수를 그대로 옮긴 값이다. 두 장치는 선택 신호의 이진 조합을 쓰므로 옳지 않다.
    🧮 풀이
    1. 4 대 1 멀티플렉서의 선택 단자 두 개에는 00·01·10·11의 네 조합이 들어간다. 조합마다 데이터 입력선 하나가 연결되어 입력은 두 개가 아닌 네 개다. n=2를 식에 넣으면 2²=4가 되어 첫 칸의 n이 틀린 까닭이 드러난다.
    2. 1 대 8 디멀티플렉서에서 세 선택 단자가 000부터 111까지 여덟 경로를 지정한다. 출력선은 세 개가 아니라 여덟 개이고 한 번에 그중 하나가 선택된다. 따라서 두 번째 값에는 m이 아니라 2ᵐ이 들어가야 한다.

    4. 선택 단자를 한 개 더 늘리면 가능한 이진 조합이 두 배가 된다. 멀티플렉서 입력과 디멀티플렉서 출력도 각각 두 배로 늘어나는 구조다. 선택 신호 수 n과 m을 그대로 입력과 출력의 수로 쓰면 실제 네 입력과 여덟 출력을 나타낼 수 없다.

    다음 전파정류회로에 대한 설명으로 옳은 것은? (단, 입력전압은 v_s (t) = V_m sin (120 π t) [V]이고, 다이오드는 이상적이다)

    1. 1. 출력전압의 주파수는 60 [Hz]이다.
    2. 2. 출력전압의 평균값은 V_m/π [V]이다.
    3. 3. 출력전압의 실횻값은 V_m/√(2) [V]이다.
    4. 4. 다이오드에 인가되는 역방향 최대전압은 2V_m [V]이다.

    정답 3번

    🔍 보기별 해설
    1. 입력 각주파수 120π rad/s는 60 Hz이고 전파정류하면 한 주기에 두 맥동이 생긴다. 출력 주파수는 120 Hz이므로 옳지 않다.
    2. 전파정류의 평균값은 양·음 반주기의 크기를 모두 더해 2V_m/π다. V_m/π는 반파정류의 평균값이므로 옳지 않다.
    3. 전파정류 출력은 원래 사인파의 절댓값이어서 제곱하면 같은 파형이 된다. 실횻값은 V_m/√2로 유지되므로 옳다(정답).
    4. 그림의 브리지 전파정류에서는 꺼진 다이오드에 입력 최대전압 V_m이 역방향으로 걸린다. 2V_m은 센터탭 구성의 값이므로 옳지 않다.
    🧮 풀이
    1. 입력 사인파의 각주파수 120π를 2π로 나누면 60 Hz다. 전파정류 출력은 양의 반주기와 뒤집힌 음의 반주기에서 각각 한 번 솟는다. 한 입력 주기 동안 맥동이 두 번이므로 출력은 120 Hz다.
    2. 최댓값 V_m인 사인파를 전파정류하면 음의 반주기도 양으로 뒤집힌다. 한 주기에 걸쳐 절댓값 파형의 평균을 내면 2V_m/π다. 음의 반주기를 버리는 반파정류에만 V_m/π가 적용된다.
    3. 전파정류 전후에 각 시각의 전압을 제곱하면 부호가 사라져 값이 같다. 한 주기의 제곱 평균은 V_m²/2이고 여기에 제곱근을 취한다. 전파정류 출력의 실횻값도 V_m/√2가 된다.
    4. 브리지 정류기의 양의 반주기에는 다이오드 두 개가 도통하고 나머지 두 개는 꺼진다. 꺼진 다이오드의 역방향 전압은 입력 사인파의 피크 V_m에 이른다. 센터탭 정류기의 다이오드에 2V_m이 걸리는 경우와 회로 연결이 다르다.

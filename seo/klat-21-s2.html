    응용언어학에 관한 설명으로 옳은 것은?

    1. 1. 언어의 구체적인 사용 맥락이나 학습자의 환경을 배제하고, 인간 머릿속에 존재하는 추상적이고 형식적인 보편문법 체계만을 탐구하는 학문이다.
    2. 2. 언어와 언어 사용자 및 사용 맥락과 관련된 실질적인 문제를 해결하거나 상황을 개선 하는 데 중점을 둔다.
    3. 3. 이론언어학의 하위 분야이며, 이론언어학에서 도출된 가설을 현장에 적용할 뿐, 그 적용결과를 바탕으로 이론을 보완ㆍ수정하는 역할은 수행하지 않는다.
    4. 4. 언어학의 방법론만을 배타적으로 채택해야 하므로 사회학, 심리학 등 인접 학문과의 다학제적 교류를 제한한다.

    정답 2번

    🔍 보기별 해설
    1. 보편문법의 추상적 체계만 탐구하는 일은 이론언어학의 연구에 가깝다. 실제 사용 맥락과 학습자의 문제를 배제했으므로 옳지 않다.
    2. 응용언어학은 언어 사용자와 사용 맥락에서 생기는 문제를 연구하고 해결책을 찾는다. 실제 상황의 개선을 중심에 두므로 옳다(정답).
    3. 응용언어학은 이론을 현장에 적용하고 그 결과로 이론을 다시 검토한다. 적용 결과로 이론을 보완하지 않는다고 했으므로 옳지 않다.
    4. 응용언어학은 언어 문제를 다룰 때 사회학·심리학 등 인접 학문의 연구를 활용한다. 학제 간 교류를 제한한다고 했으므로 옳지 않다.
    🧮 풀이
    1. 이론언어학자는 여러 문장을 설명하는 추상적인 문법 규칙을 세웠다. 연구에서는 병원 안내나 학습자의 어려움을 직접 조사하지 않았다. 완성된 결과는 실제 문제의 해결책보다 언어 체계에 관한 설명이었다.
    2. 병원 안내 담당자는 이주민 환자가 접수 절차를 이해하지 못하는 문제를 확인했다. 언어 연구자와 함께 안내문의 문장을 쉬운 표현으로 고치고 환자에게 읽어 주었다. 환자가 필요한 창구를 정확히 찾아가는 비율이 높아졌다.
    3. 한국어 교사는 문법 이론에 따라 높임 표현을 가르쳤다. 학습자의 실제 대화에서 예상과 다른 오류가 반복되자 사용 상황을 다시 조사했다. 수업 결과를 바탕으로 원래 설명을 보완하고 다음 수업의 활동을 바꾸었다.
    4. 언어 연구자는 다문화 가정 아동의 발화를 수집했다. 심리학자는 발달 과제를 설계하고 사회학자는 가족의 언어 환경을 조사했다. 세 분야의 자료를 함께 분석해 아동에게 맞는 언어 지원 방법을 만들었다.

    응용언어학은 실제 언어 사용에서 생기는 문제를 해결하기 위해 맥락과 사용자를 살피고 여러 인접 학문의 지식도 활용한다.

    다음에 해당하는 응용언어학의 하위 분야는?

    인간의 언어 이해 및 산출 과정에서 발생하는 다양한 언어 장애를 예방하고 진단하여, 적절한 치료 방법을 연구하고 임상에 적용한다.

    1. 1. 법언어학
    2. 2. 전산언어학
    3. 3. 언어병리학
    4. 4. 코퍼스언어학

    정답 3번

    🔍 보기별 해설
    1. 법언어학은 수사와 재판에서 말과 글이 어떤 증거가 되는지 연구한다. 언어 장애의 진단과 치료를 중심으로 하지 않으므로 옳지 않다.
    2. 전산언어학은 컴퓨터가 언어를 분석하고 처리하도록 하는 방법을 연구한다. 장애의 임상 치료를 맡는 분야가 아니므로 옳지 않다.
    3. 언어병리학은 언어 이해와 산출의 장애를 예방·진단하고 치료 방법을 연구한다. 제시된 임상 적용 분야에 해당하므로 옳다(정답).
    4. 코퍼스언어학은 실제 말과 글을 대규모로 모아 사용 양상을 분석한다. 언어 장애의 진단과 치료를 중심에 둔 분야가 아니므로 옳지 않다.
    🧮 풀이
    1. 법언어학자는 익명 협박 편지와 용의자의 글에서 자주 쓰는 표현을 비교했다. 문장의 어순과 낱말 선택이 얼마나 일치하는지 계산했다. 분석 결과를 저자 판별에 관한 법적 자료로 제출했다.
    2. 전산언어학자는 컴퓨터가 한국어 문장을 형태소별로 나누도록 프로그램을 만들었다. 실제 문장을 입력해 잘못 분석된 부분을 찾아 규칙을 고쳤다. 수정 뒤 프로그램은 더 많은 문장에서 어미와 조사를 정확히 구분했다.
    3. 언어병리사는 말 이해가 어려운 환자에게 그림을 고르게 하고 문장을 따라 말하게 했다. 검사 결과로 어려움의 유형을 파악해 이해 훈련과 발화 훈련을 설계했다. 치료가 진행되자 환자는 짧은 지시문을 더 정확히 이해했다.
    4. 코퍼스 연구자는 신문과 대화에서 수집한 문장으로 특정 조사의 사용 빈도를 셌다. 그 조사가 어떤 낱말 뒤에 자주 붙는지 검색했다. 결과는 언어 사용 연구에 쓰였고 환자의 장애 진단으로 이어지지 않았다.

    언어 장애를 예방·진단하고 치료 방법을 연구하여 임상에 적용하는 응용언어학 분야는 언어병리학이다.

    코퍼스언어학에 관한 설명으로 옳은 것은?

    1. 1. 언어학자의 직관과 내성(introspection)을 최우선적인 연구 수단으로 삼는다.
    2. 2. 통제된 실험실 환경에서 인간의 언어 처리 과정을 연구하는 방법을 근간으로 한다.
    3. 3. 자연스러운 맥락에서 수집된 실제 언어 자료의 관찰에 기반을 두는 경험주의적 학문이다.
    4. 4. 촘스키(N. Chomsky)의 생성문법 이론을 전폭적으로 지지하며, 언어 능력의 존재를 입증하기 위해 출발하였다.

    정답 3번

    🔍 보기별 해설
    1. 코퍼스언어학은 연구자의 직관만을 최우선 근거로 삼지 않는다. 실제 사용된 언어 자료의 빈도와 분포를 살피므로 옳지 않다.
    2. 통제된 실험에서 언어 처리 속도를 측정하는 일은 주로 심리언어학의 방법이다. 실제 말뭉치 관찰을 중심에 둔 설명이 아니므로 옳지 않다.
    3. 코퍼스언어학은 자연스러운 상황에서 생산된 말과 글을 모아 사용 양상을 관찰한다. 실제 자료에 기반을 둔 경험적 연구이므로 옳다(정답).
    4. 코퍼스언어학은 촘스키(Chomsky)의 생성문법을 입증하기 위해 시작된 분야가 아니다. 실제 언어 사용 자료를 독립적인 연구 근거로 삼으므로 옳지 않다.
    🧮 풀이
    1. 언어 연구자는 자신에게 자연스럽게 들리는 문장만 골라 쓰려 했다. 신문과 대화 자료를 검색하자 예상과 달리 자주 쓰이는 표현이 나왔다. 실제 사용 자료를 더 확인한 뒤 연구의 예문 목록을 고쳤다.
    2. 실험 참가자는 화면에 나타나는 단어를 읽고 버튼을 눌렀다. 연구자는 반응 시간을 재어 머릿속에서 낱말이 처리되는 속도를 비교했다. 그 자료는 자연스러운 대화에서 수집한 문장 빈도와 다른 종류의 결과였다.
    3. 코퍼스 연구자는 방송 대화와 신문 기사에서 실제 쓰인 문장을 모았다. 특정 동사가 앞뒤에 어떤 낱말과 함께 나타나는지 수천 건을 검색했다. 반복되는 결합과 사용 빈도를 근거로 그 동사의 쓰임을 설명했다.
    4. 생성문법 연구자는 화자의 문법 직관으로 가능한 문장 구조를 검토했다. 코퍼스 연구자는 실제 발화에서 그 구조가 얼마나 나타나는지 따로 조사했다. 두 연구는 서로 다른 자료와 질문을 사용해 언어 현상을 설명했다.

    코퍼스언어학은 자연스러운 상황에서 생산된 실제 언어 자료를 체계적으로 관찰하고 분석하는 경험주의적 연구 분야이다.

    언어 이론 및 문법에 관한 설명으로 옳지 않은 것은?

    1. 1. 소쉬르(F. Saussure)는 언어에 대해 통시적 연구와 공시적 연구로 구분하고 공시적 연구를 강조하였다.
    2. 2. 규범문법은 고대 그리스어나 라틴어의 문법성에 근거하여 영어와 같은 현대어의 문법을 판단하였다.
    3. 3. 촘스키(N. Chomsky)는 화자와 청자가 지닌 언어 지식을 언어 기술이라고 하고 구체적인 상황에서의 실제 사용을 언어 능력이라고 하였다.
    4. 4. 기술문법은 언어의 문법성을 정해서 적용하는 것이 아니라 실제로 사용하는 언어 자료를 보고 그 현상을 기술하는 방식이다.

    정답 3번

    🔍 보기별 해설
    1. 소쉬르(Saussure)는 언어의 역사적 변화를 보는 통시 연구와 한 시점의 체계를 보는 공시 연구를 구분했다. 공시 연구를 강조했으므로 옳다.
    2. 규범문법은 고대 그리스어와 라틴어의 규칙을 기준으로 현대 언어의 올바른 사용을 판단하기도 했다. 고전어 기준의 적용을 설명했으므로 옳다.
    3. 촘스키(Chomsky)는 화자의 내적 언어 지식을 언어 능력, 실제 사용을 언어 수행으로 구분했다. 두 개념의 이름을 바꾸어 적었으므로 옳지 않다(정답).
    4. 기술문법에서는 실제 화자들이 쓰는 자료에서 반복되는 규칙과 변이를 찾는다. 사용 양상을 미리 정한 규범으로 판정하지 않고 있는 그대로 기술하므로 옳다.
    🧮 풀이
    1. 소쉬르는 한 시점의 프랑스어에서 낱말과 소리가 서로 맺는 관계를 분석했다. 과거의 변화만 따라가면 그 시점의 체계가 어떻게 작동하는지 놓칠 수 있었다. 그는 공시 연구를 언어 연구의 중요한 관점으로 제시했다.
    2. 옛 문법책의 저자는 라틴어 규칙을 영어 문장에 적용해 어떤 형태가 맞는지 판정했다. 실제 영어 화자들이 자주 쓰는 표현도 그 기준에 어긋나면 잘못이라고 적었다. 고전어 규범이 현대어 판단에 영향을 미친 사례였다.
    3. 화자는 문법에 맞는 긴 문장을 알고 있었다. 그러나 긴장한 발표에서는 말을 더듬어 그 문장을 끝까지 말하지 못했다. 촘스키는 머릿속 지식인 언어 능력과 실제 발화인 언어 수행을 구분해 설명했다.
    4. 연구자는 사람들이 일상 대화에서 쓰는 문장을 녹음했다. 교과서 규범과 다른 표현도 버리지 않고 언제 반복되는지 분류했다. 기술문법은 실제 사용 자료에서 나타나는 규칙과 변이를 연구 결과로 적었다.

    촘스키는 내재된 언어 지식을 언어 능력, 구체적 상황에서 나타나는 실제 사용을 언어 수행으로 구별한다.

    문자론에 관한 설명으로 옳은 것은?

    1. 1. 수메르인의 쐐기 문자의 발달은 음소 문자에서 음절 문자로 변화하는 과정을 보여준다.
    2. 2. 고대 이집트 상형 문자의 일부는 그리스 알파벳의 기원이 되었다.
    3. 3. 키릴 문자는 로마자에서 변형되어 슬라브 지역에 파급되었다.
    4. 4. 상형 문자는 표의 문자이며 모두 음소 문자로 발전하였다.

    정답 2번

    🔍 보기별 해설
    1. 수메르인의 쐐기문자는 사물의 뜻을 나타내는 기호에서 소릿값을 나타내는 기호로 발달했다. 음소문자에서 음절문자로 바뀌었다고 했으므로 옳지 않다.
    2. 고대 이집트 상형문자에서 이어진 자음 중심 표기 전통은 페니키아 문자를 거쳐 그리스 알파벳에 영향을 주었다. 기원 관계를 설명했으므로 옳다(정답).
    3. 키릴문자는 로마자가 아니라 그리스 문자를 주요 바탕으로 형성되었다. 바탕이 된 문자를 바꾸어 적었으므로 옳지 않다.

    정답 1번

    🔍 보기별 해설

    3. 오류 설명에서는 왜 그런 형태가 나왔는지 모어 전이와 과잉 일반화 같은 원인을 검토한다. 습득 과정을 이해하는 데 필요한 단계이므로 옳다.

    2. 학습자는 ‘학교를 간다’라고 쓴 문장을 제출했다. 분석자는 학습자의 문장과 목표어에서 기대되는 ‘학교에 간다’를 나란히 놓았다. 목적지 표시에서 두 조사가 어떻게 다른지 오류의 형태를 기술했다.
    3. 연구자는 같은 학습자가 여러 문장에서 장소 조사를 바꾸어 쓰는 것을 확인했다. 모어의 표현 방식과 한국어 조사 규칙을 비교해 오류가 생긴 이유를 검토했다. 반복된 오류를 설명한 뒤 필요한 연습을 설계했다.

    베르니케 실어증 환자의 언어적 특징으로 옳은 것은?

    1. 1. 타인의 말을 이해하는 데는 문제가 없으나, 자신의 말을 산출하는 데 큰 어려움을 겪는다.
    2. 2. 발화 속도가 매우 느리며, 기능어나 문법 형태소가 주로 생략되는 전보식 발화 (telegraphic speech)를 한다.
    3. 3. 발화는 유창하지만, 내용어가 부족하거나 무의미한 단어를 나열하여 전체적인 의미를 파악하기 어렵다.
    4. 4. 조음 기관의 근육 마비로 인해 발성 자체가 이루어지지 않는 운동성 말 장애를 보인다.

    정답 3번

    🔍 보기별 해설
    1. 말을 이해하지만 유창하게 산출하기 어려운 양상은 브로카 실어증에 가깝다. 베르니케 실어증의 특징으로 제시했으므로 옳지 않다.
    2. 느린 전보식 발화와 기능어 생략은 브로카 실어증에서 나타날 수 있다. 베르니케 실어증의 주된 발화 양상으로 제시했으므로 옳지 않다.
    3. 베르니케 실어증에서는 말은 유창해도 알맞은 내용어가 부족하거나 뜻이 통하지 않는 표현이 나타날 수 있다. 발화의 특징을 설명했으므로 옳다(정답).
    4. 조음 근육의 마비로 소리를 만들 수 없는 상태는 운동성 말 장애와 관련된다. 베르니케 실어증의 언어 이해 장애를 설명하지 않으므로 옳지 않다.
    🧮 풀이
    1. 브로카 영역에 손상을 입은 환자는 질문의 뜻을 이해하고 고개를 끄덕였다. 자신의 답을 길게 말하려 할 때는 짧은 낱말 몇 개만 힘겹게 이어 냈다. 이해에 비해 발화 산출의 어려움이 두드러졌다.
    2. 전두엽 손상 환자는 ‘물 마시다’처럼 핵심 낱말을 끊어 말했다. 조사와 어미가 빠져 완전한 문장으로 이어지지 않았다. 그는 뜻을 전달하려고 핵심 낱말을 선택해 느리게 발음했다.
    3. 베르니케 영역에 손상을 입은 환자는 질문을 듣고 빠르고 긴 문장으로 답했다. 그러나 질문과 맞지 않는 낱말을 이어 말해 듣는 사람이 뜻을 파악하기 어려웠다. 발화의 유창함과 의미 전달의 어려움이 함께 나타났다.
    4. 환자는 조음 근육의 움직임이 약해 소리를 또렷하게 만들지 못했다. 치료사는 근육 움직임과 호흡을 살피며 발성 과제를 진행했다. 이는 단어의 의미를 이해하지 못해 생긴 베르니케 실어증의 발화와 다른 문제였다.

    베르니케 실어증은 발화가 유창한 편이지만 부적절하거나 무의미한 표현이 많고 다른 사람의 말을 이해하는 능력에도 어려움이 나타난다.

    🔍 보기별 해설

    2. 발화 오류는 우연한 비단어보다 언어 안에서 실제로 쓰이는 낱말이 되기 쉽다. ‘slip’은 영어 낱말이어서 제시된 오류의 경향과 맞으므로 옳다(정답).
    3. 설단 현상(tip-of-the-tongue phenomenon)은 아는 낱말을 당장 떠올리지 못하는 상태이다. 말실수가 실제 단어를 만드는 경향과 다르므로 옳지 않다.
    4. 자동적 처리(automatic processing)는 익숙한 과제를 적은 주의로 빠르게 처리하는 것이다. 발화 오류가 실제 단어 쪽으로 치우치는 현상의 이름이 아니므로 옳지 않다.
    🧮 풀이
    1. 참가자는 화면에 아주 잠깐 나타난 영어 철자를 보고 특정 글자를 골랐다. 그 글자가 익숙한 단어 안에 들어 있을 때는 무의미한 철자열 안에 있을 때보다 정확히 답했다. 연구자는 두 조건의 정답 수를 비교해 낱말 맥락이 글자 인식을 돕는 결과를 얻었다.
    2. 화자는 목표 낱말 ‘blip’을 빠르게 말하려다 ‘slip’이라고 잘못 발음했다. 다른 잘못 발음인 ‘tlip’보다 실제 영어 단어가 된 ‘slip’이 더 쉽게 나왔다. 발화 오류가 어휘 목록에 있는 단어 쪽으로 치우쳤다.
    3. 발표자는 익숙한 사람의 이름을 말하려 했지만 첫 음절만 떠올랐다. 잠시 다른 내용을 말한 뒤에야 그 이름을 완전히 꺼냈다. 이미 알고 있던 단어의 인출이 잠깐 막힌 설단 현상이 나타났다.
    4. 숙련된 독자는 자주 보는 짧은 낱말을 거의 멈추지 않고 읽었다. 처음 배우는 사람이 같은 낱말의 글자를 하나씩 확인하는 동안 이미 문장 전체의 뜻을 파악했다. 익숙해진 낱말 읽기가 적은 주의로 빠르게 처리되었다.

    발화 오류가 비단어보다 실제 단어가 되는 방향으로 더 자주 나타나는 현상은 어휘 편향 효과이다.

    2. 학습자는 ‘어제 먹었다’에서 ‘어제’를 듣고 사건의 시점을 파악했다. 동사의 과거 어미도 같은 시점을 나타냈지만 처음에는 시간 낱말에 더 주의를 기울였다. 어휘 단서가 문법 표지보다 먼저 처리되었다.
    3. 교사는 첫 명사가 항상 행동의 주체는 아닌 한국어 문장을 들려주었다. 학습자는 조사를 듣고 그림에서 누가 누구를 쫓는지 고르며 이전 해석을 수정했다. 반복된 이해 활동으로 조사와 문장 뜻을 더 정확히 연결했다.
    4. 학습자는 ‘어제’와 과거 어미가 함께 든 문장을 들었다. 시간 낱말만으로도 시점을 알 수 있어 어미를 처음에는 놓쳤다. 교사는 어미의 의미를 따로 들을 수 있는 문장을 제시해 문법 형태에도 주의를 기울이게 했다.

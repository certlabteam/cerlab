    응용언어학에 관한 설명으로 옳은 것은?

    1. 1. 언어의 구체적인 사용 맥락이나 학습자의 환경을 배제하고, 인간 머릿속에 존재하는 추상적이고 형식적인 보편문법 체계만을 탐구하는 학문이다.
    2. 2. 언어와 언어 사용자 및 사용 맥락과 관련된 실질적인 문제를 해결하거나 상황을 개선 하는 데 중점을 둔다.
    3. 3. 이론언어학의 하위 분야이며, 이론언어학에서 도출된 가설을 현장에 적용할 뿐, 그 적용결과를 바탕으로 이론을 보완ㆍ수정하는 역할은 수행하지 않는다.
    4. 4. 언어학의 방법론만을 배타적으로 채택해야 하므로 사회학, 심리학 등 인접 학문과의 다학제적 교류를 제한한다.

    코퍼스언어학에 관한 설명으로 옳은 것은?

    1. 1. 언어학자의 직관과 내성(introspection)을 최우선적인 연구 수단으로 삼는다.
    2. 2. 통제된 실험실 환경에서 인간의 언어 처리 과정을 연구하는 방법을 근간으로 한다.
    3. 3. 자연스러운 맥락에서 수집된 실제 언어 자료의 관찰에 기반을 두는 경험주의적 학문이다.
    4. 4. 촘스키(N. Chomsky)의 생성문법 이론을 전폭적으로 지지하며, 언어 능력의 존재를 입증하기 위해 출발하였다.

    언어 이론 및 문법에 관한 설명으로 옳지 않은 것은?

    1. 1. 소쉬르(F. Saussure)는 언어에 대해 통시적 연구와 공시적 연구로 구분하고 공시적 연구를 강조하였다.
    2. 2. 규범문법은 고대 그리스어나 라틴어의 문법성에 근거하여 영어와 같은 현대어의 문법을 판단하였다.
    3. 3. 촘스키(N. Chomsky)는 화자와 청자가 지닌 언어 지식을 언어 기술이라고 하고 구체적인 상황에서의 실제 사용을 언어 능력이라고 하였다.
    4. 4. 기술문법은 언어의 문법성을 정해서 적용하는 것이 아니라 실제로 사용하는 언어 자료를 보고 그 현상을 기술하는 방식이다.

    문자론에 관한 설명으로 옳은 것은?

    1. 1. 수메르인의 쐐기 문자의 발달은 음소 문자에서 음절 문자로 변화하는 과정을 보여준다.
    2. 2. 고대 이집트 상형 문자의 일부는 그리스 알파벳의 기원이 되었다.
    3. 3. 키릴 문자는 로마자에서 변형되어 슬라브 지역에 파급되었다.
    4. 4. 상형 문자는 표의 문자이며 모두 음소 문자로 발전하였다.

    인간 언어의 특징에 관한 설명으로 옳은 것은?

    1. 1. 초월성(displacement): 화자나 청자가 ‘지금, 여기’와 관련 없는 것을 말하고 들을 수 있다.
    2. 2. 자의성(arbitrariness): 말의 음과 의미는 필연적 상관성이 있어 역사적으로 소리가 변해도 뜻을 알 수 있다.
    3. 3. 창조성(creativity): 유아기 아동은 부모나 양육자의 말을 모방하면서 말을 배운다.
    4. 4. 분절성(discreteness): 말소리는 한 사회에서 고정되어 변하지 않으며 음소의 순서를 바꾸면 비문법적인 발화가 생성된다.

    조음음성학 용어에 관한 설명으로 옳지 않은 것은?

    1. 1. 파찰음: 입안 기류의 통로가 막혔다가 곧이어 약간 열려 마찰을 일으키며 발화되는 소리
    2. 2. 유음: 기류가 마찰음 때보다 덜 방해 받아 물이 흐르듯이 나오는 소리
    3. 3. 활음: 기류의 장애가 거의 없으며 모음의 앞이나 뒤에 와서 미끄러지듯 나는 소리
    4. 4. 유기음: 발화 시 성대 두 개가 맞닿아 있어 기류가 지나면서 진동을 일으키는 소리

    2. 2. ‘문리’와 ‘물리’처럼 한 곳에서만 철자가 다르지만 동화되어 같이 발음되는 두 단어
    3. 3. ‘심판단’과 ‘심판진’처럼 한 음절이 다르고 뜻이 비슷한 두 단어
    4. 4. ‘진단’과 ‘진담’처럼 같은 위치에서 한 소리가 달라 뜻이 다른 두 단어

    화용론의 연구 분야에 관한 설명으로 옳지 않은 것은?

    1. 1. 말의 사용과 물리적, 언어적 맥락에 따른 의미를 연구한다.
    2. 2. 숨은 의미보다는 기본적이고 개념적 의미에 관심을 둔다.
    3. 3. 화자가 청자의 체면을 고려하여 말을 어떻게 하는지 관찰한다.
    4. 4. 직설적으로 말하거나 우회적으로 말하는 경우를 분석한다.

    제2 언어 학습자에게서 관찰되는 오류의 원인에 관한 설명으로 옳지 않은 것은?

    1. 1. 의사소통을 하기 위해 사용하는 산출 전략이 오류를 생성하기도 한다.
    2. 2. 교과 과정이나 교재, 교사 등의 학습 환경으로 인해 발생하는 오류가 있다.
    3. 3. 언어 간 전이로 인해 목표어 규칙을 과잉 적용하는 과정에서 오류가 발생한다.
    4. 4. 모어와 목표어의 차이로 인한 오류는 초급 학습자에게서 많이 나타난다.

    오류 분석의 단계에 관한 설명으로 옳지 않은 것은?

    1. 1. 오류 식별: 수집한 언어 표본에서 분석 요소를 결정하는 단계로 코더(P. Corder)는 실수를 분석에 포함하였다.
    2. 2. 오류 기술: 오류가 있는 원래 발화와 교정 발화를 비교하여 그 차이점을 확인하는 과정이다.
    3. 3. 오류 설명: 오류 발생 원인을 밝히는 단계로 제2 언어 습득 과정을 이해하는 데 중요하다.
    4. 4. 오류 평가: 오류가 화자에게 어떤 영향을 주는지 분석하고 올바른 발화를 인지하여 강화할 수 있도록 긍정적 반응을 제공하는 과정이다.

    문장 이해 과정에 관한 가든 패스 이론(Garden Path Theory)의 기본 가정으로 옳은 것은?

    1. 1. 통사, 의미 또는 맥락에 관한 제약 등 다양한 정보 자원을 병렬적으로 고려하여 문장 구조를 분석한다.
    2. 2. 초기 구문 분석 시에는 의미나 맥락 정보를 배제한 채로 제한된 통사 정보만을 사용하여 가장 단순하고 쉬운 구조를 먼저 구축한다.
    3. 3. 중의적인 문장 처리 과정에서 어휘의 출현 빈도가 가장 중요한 단서로 작용한다.
    4. 4. 어휘 판단 과제 시에는 후속되는 어휘의 문법 형태소가 무엇인지에 따라 뇌의 활성화속도가 달라진다.

    베르니케 실어증 환자의 언어적 특징으로 옳은 것은?

    1. 1. 타인의 말을 이해하는 데는 문제가 없으나, 자신의 말을 산출하는 데 큰 어려움을 겪는다.
    2. 2. 발화 속도가 매우 느리며, 기능어나 문법 형태소가 주로 생략되는 전보식 발화 (telegraphic speech)를 한다.
    3. 3. 발화는 유창하지만, 내용어가 부족하거나 무의미한 단어를 나열하여 전체적인 의미를 파악하기 어렵다.
    4. 4. 조음 기관의 근육 마비로 인해 발성 자체가 이루어지지 않는 운동성 말 장애를 보인다.

    사회언어학 용어에 관한 설명으로 옳지 않은 것은?

    1. 1. 피진(pidgin): 어휘의 수가 적고 복잡한 문법 규칙도 없어 매우 단순화된 언어를 말한다.
    2. 2. 언어 태도(language attitude): 특정 언어 및 그 언어 사용자에 대한 견해를 말한다.
    3. 3. 코드 전환(code switching): 현재 처한 사회적 상황이나 맥락 등을 고려하지 않고 하나의 언어 코드를 사용하는 것을 말한다.
    4. 4. 크레올(creole): 피진보다는 언어 체계가 안정되고 어휘가 확장되며 언어 구조는 더정교한 언어를 말한다.

    양층어(diglossia)에 관한 설명으로 옳지 않은 것은?

    1. 1. 상층어는 공식적인 상황에서 사용하며 하층어는 일상적인 상황에서 사용한다.
    2. 2. 상층어와 하층어는 문법적으로 상이하나 사용 영역이 비슷하여 서로 중복되는 경우가 있다.
    3. 3. 이집트는 고전 아랍어와 구어체 아랍어가 병존하는 양층어 상황에 있다.
    4. 4. 아이티(Haiti)에서는 상층어인 프랑스어와 하층어인 아이티 크레올(Haiti creole)이 쓰인다.

    제2 언어 학습자의 중간 언어에 관한 설명으로 옳은 것은?

    1. 1. 목표어의 완벽한 문법 체계를 갖추기 전까지 발생하는 비체계적인 오류의 집합이다.
    2. 2. 모어 및 목표어와 구별되는 독자적이고 체계적인 규칙 체계이다.
    3. 3. 학습자의 모어에서 긍정적 전이가 발생한 문법 항목만을 모아 놓은 언어 체계이다.
    4. 4. 유아기의 제1 언어 습득 과정에서 관찰되며, 성인 학습자의 제2 언어 습득 과정에서 나타나지 않는다.

    스웨인(M. Swain)의 출력 가설에서 출력의 기능에 관한 설명으로 옳지 않은 것은?

    1. 1. 알아차리기(noticing) 기능: 학습자는 목표어를 말하거나 쓸 때 자신의 중간 언어 지식에 공백이 있음을 스스로 인지하게 된다.
    2. 2. 가설 검증 기능: 학습자는 자신의 발화에 대한 대화 상대방의 피드백을 통해 목표어에 관한 자신의 가설을 검증한다.
    3. 3. 메타언어적 기능: 학습자는 언어 산출 과정에서 동료와의 협동적 대화 등을 통해 언어 규칙 자체를 성찰한다.
    4. 4. 자동화 기능: 언어 출력 연습은 통제된 처리를 지연시켜 학습자가 의미 이해를 차단하고 문법 형태소만을 느리게 처리하도록 한다.

    밴패튼(B. VanPatten)의 입력 처리 이론에 관한 설명으로 옳지 않은 것은?

    1. 1. ‘첫 번째 명사 원리’에 따르면, 제2 언어 학습자가 문장의 첫 번째 명사나 명사구를 행위자나 주어로 먼저 해석하려는 경향이 강하다.
    2. 2. ‘어휘 선호 원리’에 따르면, 어휘 단서와 문법 표지가 동일한 문법 범주를 나타낼 때, 학습자는 어휘 단서를 먼저 처리한다.
    3. 3. 입력 처리 이론에 기반한 ‘처리 교수’는 학습자가 잘못된 처리 전략을 버리고 형태와 의미간에 올바른 연결을 맺도록 유도하는 이해 기반의 기법이다.
    4. 4. 학습자의 두뇌는 인지 효율성을 극대화하기 위해 의미 전달력이 낮고 중복되는 문법형태소를 문장의 내용어보다 최우선으로 처리한다.

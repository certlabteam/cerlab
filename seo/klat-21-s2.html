    응용언어학에 관한 설명으로 옳은 것은?

    1. 1. 언어의 구체적인 사용 맥락이나 학습자의 환경을 배제하고, 인간 머릿속에 존재하는 추상적이고 형식적인 보편문법 체계만을 탐구하는 학문이다.
    2. 2. 언어와 언어 사용자 및 사용 맥락과 관련된 실질적인 문제를 해결하거나 상황을 개선 하는 데 중점을 둔다.
    3. 3. 이론언어학의 하위 분야이며, 이론언어학에서 도출된 가설을 현장에 적용할 뿐, 그 적용결과를 바탕으로 이론을 보완ㆍ수정하는 역할은 수행하지 않는다.
    4. 4. 언어학의 방법론만을 배타적으로 채택해야 하므로 사회학, 심리학 등 인접 학문과의 다학제적 교류를 제한한다.

    정답 2번

    🔍 보기별 해설
    1. 보편문법처럼 추상적 체계만 탐구하는 것은 이론언어학의 성격에 가까우며 실제 언어 문제의 해결을 중시하는 응용언어학과 다르므로 옳지 않다.
    2. 응용언어학은 언어가 쓰이는 현실에서 생기는 문제를 살피고 언어 사용자와 사회적 맥락을 고려해 해결책을 찾는 데 초점을 두므로 옳다(정답).
    3. 응용언어학은 이론을 단순히 현장에 옮기는 데 그치지 않고 실제 적용에서 얻은 결과를 토대로 기존 이론을 검토하거나 보완하기도 하므로 옳지 않다.
    4. 응용언어학은 현실의 언어 문제를 다루기 위해 심리학·사회학·교육학 등 여러 학문의 지식과 연구 방법을 폭넓게 활용하므로 옳지 않다.
    🧮 풀이
    1. 甲은 언어 연구실에서 문장 구조의 보편적인 규칙만 분석하고 실제 교실이나 사회에서 사람들이 어떤 어려움을 겪는지는 조사하지 않았다. 연구가 현실의 언어 문제와 만나지 않자 甲은 이론 연구와 응용 연구의 차이를 연구 노트에 정리했다.
    2. 甲은 이주민이 병원 접수 창구에서 의료진의 설명을 제대로 이해하지 못하는 사례를 조사했다. 실제 대화를 분석하고 쉬운 표현으로 안내문을 고쳐 본 뒤 이해도가 높아지는지 확인하며 현실의 언어 문제를 해결해 나갔다.
    3. 甲은 외국인 학습자에게 기존 문법 이론을 적용해 수업한 뒤 예상과 다른 오류가 반복되는 것을 발견했다. 수업 기록과 학습자의 반응을 다시 분석하여 처음 세운 설명을 수정하고 새로운 교수 방안을 연구 보고서에 반영했다.
    4. 甲은 다문화 가정 아동의 언어 사용을 조사하면서 언어 자료만 보지 않고 심리학자의 발달 연구와 사회학자의 가정환경 조사도 함께 검토했다. 여러 분야의 연구 결과를 모아 언어 학습을 설명하는 분석 틀을 새로 구성했다.

    응용언어학은 실제 언어 사용에서 생기는 문제를 해결하기 위해 맥락과 사용자를 살피고 여러 인접 학문의 지식도 활용한다.

    다음에 해당하는 응용언어학의 하위 분야는?

    인간의 언어 이해 및 산출 과정에서 발생하는 다양한 언어 장애를 예방하고 진단하여, 적절한 치료 방법을 연구하고 임상에 적용한다.

    1. 1. 법언어학
    2. 2. 전산언어학
    3. 3. 언어병리학
    4. 4. 코퍼스언어학

    정답 3번

    🔍 보기별 해설
    1. 법언어학은 법률과 수사·재판에서 나타나는 언어 문제를 연구하는 분야이므로 언어 장애의 진단과 치료를 다룬다는 설명은 옳지 않다.
    2. 전산언어학은 컴퓨터를 활용한 언어 처리와 분석을 주로 연구하므로 사람의 언어 장애를 진단하고 치료법을 찾는 분야라는 설명은 옳지 않다.
    3. 언어병리학은 언어의 이해와 산출에서 나타나는 장애를 예방·진단하고 치료 방법을 연구하여 임상 현장에 적용하는 분야이므로 옳다(정답).
    4. 코퍼스언어학은 실제 언어 자료를 대규모로 모아 사용 양상과 규칙을 분석하는 분야이므로 언어 장애의 예방과 임상 치료를 맡는다는 설명은 옳지 않다.
    🧮 풀이
    1. 甲은 법정에서 피고인의 진술 표현과 협박 편지의 문체를 분석해 작성자를 가려내는 연구를 진행했다. 판결문과 수사기록에서 반복되는 표현까지 비교하며 법적 판단에 언어 분석을 활용하는 과정을 살펴보았다.
    2. 甲은 컴퓨터가 한국어 문장을 자동으로 분석하도록 프로그램을 만들고 형태소와 문장 구조를 인식시키는 실험을 했다. 수천 문장을 입력한 뒤 분석 오류를 찾아 알고리즘을 고치며 자연어 처리 성능을 높여 갔다.
    3. 甲은 말을 이해하는 데 어려움을 겪는 환자에게 그림 이름 말하기와 문장 따라 말하기 검사를 실시했다. 검사 결과를 토대로 장애 유형을 진단하고 반복 발화와 이해 훈련을 짜서 치료실에서 단계별로 적용했다.
    4. 甲은 신문과 소설에서 모은 수백만 어절의 말뭉치를 검색해 특정 조사가 어떤 낱말과 자주 함께 쓰이는지 조사했다. 실제 사용 빈도를 표로 정리하고 시대별 자료까지 비교하여 표현의 변화 양상을 분석했다.

    언어 장애를 예방·진단하고 치료 방법을 연구하여 임상에 적용하는 응용언어학 분야는 언어병리학이다.

    코퍼스언어학에 관한 설명으로 옳은 것은?

    1. 1. 언어학자의 직관과 내성(introspection)을 최우선적인 연구 수단으로 삼는다.
    2. 2. 통제된 실험실 환경에서 인간의 언어 처리 과정을 연구하는 방법을 근간으로 한다.
    3. 3. 자연스러운 맥락에서 수집된 실제 언어 자료의 관찰에 기반을 두는 경험주의적 학문이다.
    4. 4. 촘스키(N. Chomsky)의 생성문법 이론을 전폭적으로 지지하며, 언어 능력의 존재를 입증하기 위해 출발하였다.

    정답 3번

    🔍 보기별 해설
    1. 코퍼스언어학은 연구자의 직관만을 우선하기보다 실제로 생산된 대규모 언어 자료를 수집하고 그 사용 양상을 분석하는 경험적 접근을 중시하므로 옳지 않다.
    2. 실험실에서 언어 처리 과정을 통제해 관찰하는 것은 심리언어학적 연구에 더 가까우며 코퍼스언어학은 실제 사용 자료의 분석을 바탕으로 하므로 옳지 않다.
    3. 코퍼스언어학은 실제 의사소통에서 생산된 언어 자료를 체계적으로 모아 빈도와 분포, 결합 양상 등을 관찰하는 경험주의적 연구를 중시하므로 옳다(정답).
    4. 코퍼스언어학은 생성문법을 입증하려고 출발한 분야가 아니며 실제 언어 사용 자료를 경험적으로 분석하는 독자적인 연구 방법을 발전시켜 왔으므로 옳지 않다.
    🧮 풀이
    1. 甲은 어떤 동사가 자연스러운지 자신의 느낌만으로 판단하려다가 실제 신문과 대화 말뭉치를 검색했다. 직관과 실제 사용 빈도가 다른 사례를 여러 개 발견한 뒤 연구자의 판단보다 관찰 자료를 먼저 확인하는 방식으로 연구 절차를 바꾸었다.
    2. 甲은 참가자를 실험실에 앉혀 화면에 문장을 한 줄씩 보여 주고 단어를 읽는 데 걸리는 시간을 측정했다. 조건마다 반응 시간을 비교해 머릿속 언어 처리 과정을 추적하면서 실제 말뭉치 분석과는 다른 연구 자료를 만들었다.
    3. 甲은 방송 대화와 신문 기사, 인터넷 게시글에서 실제로 쓰인 문장을 대량으로 모았다. 특정 표현의 빈도와 앞뒤에 함께 나타나는 낱말을 검색하고 자료에서 반복되는 사용 양상을 표로 만들어 경험적 근거를 확인했다.
    4. 甲은 생성문법의 특정 가설을 증명하려고 직관으로 만든 예문만 모으려 했지만 동료가 실제 언어 사용 자료도 살펴보자고 제안했다. 이후 여러 말뭉치에서 같은 구조의 빈도와 분포를 조사해 별도의 경험 자료로 정리했다.

    코퍼스언어학은 자연스러운 상황에서 생산된 실제 언어 자료를 체계적으로 관찰하고 분석하는 경험주의적 연구 분야이다.

    언어 이론 및 문법에 관한 설명으로 옳지 않은 것은?

    1. 1. 소쉬르(F. Saussure)는 언어에 대해 통시적 연구와 공시적 연구로 구분하고 공시적 연구를 강조하였다.
    2. 2. 규범문법은 고대 그리스어나 라틴어의 문법성에 근거하여 영어와 같은 현대어의 문법을 판단하였다.
    3. 3. 촘스키(N. Chomsky)는 화자와 청자가 지닌 언어 지식을 언어 기술이라고 하고 구체적인 상황에서의 실제 사용을 언어 능력이라고 하였다.
    4. 4. 기술문법은 언어의 문법성을 정해서 적용하는 것이 아니라 실제로 사용하는 언어 자료를 보고 그 현상을 기술하는 방식이다.

    정답 3번

    🔍 보기별 해설
    1. 소쉬르는 언어의 역사적 변화를 살피는 통시적 관점과 일정 시점의 체계를 살피는 공시적 관점을 구별하고 특히 공시적 연구를 중시했으므로 옳다.
    2. 전통적인 규범문법은 고전어의 문법 규칙을 기준으로 삼아 영어를 비롯한 현대 언어의 올바른 사용 여부를 판단하려는 경향이 강했으므로 옳다.
    3. 촘스키는 머릿속 언어 지식을 능력, 구체적인 상황에서 나타나는 실제 언어 사용을 수행이라 구별했으므로 두 개념을 서로 뒤바꾼 설명은 옳지 않다(정답).
    4. 기술문법은 미리 옳고 그른 규칙을 정해 강제하기보다 사람들이 실제로 사용하는 언어 자료를 관찰하고 그 안에서 나타나는 규칙과 현상을 기술하므로 옳다.
    🧮 풀이
    1. 甲은 한 언어가 수백 년 동안 어떻게 변했는지만 조사하다가 특정 시대의 언어 체계 자체를 따로 분석해 보았다. 그 시점의 소리와 문법 요소가 서로 어떤 관계를 맺는지 정리하면서 통시적 관점과 공시적 관점을 구별해 기록했다.
    2. 甲은 오래된 영문법 책을 펼쳐 라틴어 문법의 기준으로 영어 문장의 옳고 그름을 판단한 사례를 찾아냈다. 실제 영어 사용과 다른 규칙이 제시된 대목에 표시하고 고전어 규범이 현대어 판단에 미친 영향을 발표 자료에 정리했다.
    3. 甲은 한국어 문법을 잘 아는 학습자가 긴장한 발표에서 문장을 자꾸 끊어 말하는 모습을 관찰했다. 머릿속에 지닌 언어 지식과 실제 상황에서 드러나는 사용은 구별해야 한다고 설명하며 두 개념의 이름을 정확히 적었다.
    4. 甲은 사람들이 일상 대화에서 쓰는 문장을 녹음하고 표현의 실제 분포를 조사했다. 교과서 규칙에 맞지 않는다는 이유로 자료를 버리지 않고 반복되는 사용 양상을 그대로 분류하여 현실 언어의 문법적 특징을 보고서에 기술했다.

    촘스키는 내재된 언어 지식을 언어 능력, 구체적 상황에서 나타나는 실제 사용을 언어 수행으로 구별한다.

    문자론에 관한 설명으로 옳은 것은?

    1. 1. 수메르인의 쐐기 문자의 발달은 음소 문자에서 음절 문자로 변화하는 과정을 보여준다.
    2. 2. 고대 이집트 상형 문자의 일부는 그리스 알파벳의 기원이 되었다.
    3. 3. 키릴 문자는 로마자에서 변형되어 슬라브 지역에 파급되었다.
    4. 4. 상형 문자는 표의 문자이며 모두 음소 문자로 발전하였다.

    정답 2번

    🔍 보기별 해설

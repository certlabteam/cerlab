    용액 중의 금속 이온을 환원제로 환원시켜 물체 표면에 도금하는 방법은?

    1. 1. 전착(electrodeposition)
    2. 2. 전기도금(electroplating)
    3. 3. 무전해 도금(electroless plating)
    4. 4. 전기이동 코팅(electrophoretic coating)

    정답 3번

    🔍 보기별 해설
    1. 전착은 전류에 의해 물질을 전극 표면에 석출시키는 넓은 개념이다. 용액 속 환원제로 금속을 입히는 방법이 아니므로 옳지 않다.
    2. 전기도금은 전원으로 전류를 흘려 음극 표면에 금속을 석출한다. 외부 환원제만으로 도금하는 방법이 아니므로 옳지 않다.
    3. 무전해 도금은 용액에 든 환원제가 금속 이온에 전자를 주어 표면에 금속층을 만든다. 외부 전류가 필요 없으므로 옳다(정답).
    4. 전기이동 코팅은 전기장 안에서 대전된 도료 입자를 표면으로 이동시켜 붙인다. 금속 이온을 환원해 도금하는 방법이 아니므로 옳지 않다.
    🧮 풀이
    1. 금속 이온이 든 전해조에서 전극에 전류를 흘렸다. 이온이 전극 표면으로 이동해 전자를 받고 일정한 두께로 석출됐다. 전기장을 이용한 전착이었으며 환원제만 넣는 공정과 달랐다.
    2. 구리 전기도금조에 금속 부품을 음극으로 연결하고 전원 장치와 양극을 함께 설치했다. 정류기 전원을 켜자 구리 이온이 음극에서 환원되어 금속막이 자랐다. 전원을 끄면 도금이 멈췄다.
    3. 전기가 통하지 않는 플라스틱 부품을 금속 이온과 환원제가 든 욕조에 넣었다. 환원제가 이온에 전자를 건네자 부품 표면에 금속층이 생겼다. 외부 전원 없이 무전해 도금이 진행됐다.
    4. 차체 부품을 대전된 도료 입자가 든 수조에 담갔다. 전기장을 걸자 도료 입자가 이동해 부품 표면에 붙었다. 금속 이온의 환원 반응이 아니라 도료 코팅이 일어났다.

    무전해 도금은 외부 전원 없이 용액의 환원제로 금속 이온을 환원한다. 3번이 옳다.

    계면활성제의 용도로 적절하지 않은 것은?

    1. 1. 가교제
    2. 2. 분산제
    3. 3. 습윤제
    4. 4. 유화제

    정답 1번

    🔍 보기별 해설
    1. 가교제는 고분자 사슬을 서로 결합시켜 그물 구조를 만든다. 경계면에 작용하는 계면활성제의 용도라는 설명은 옳지 않다(정답).
    2. 분산제는 입자 표면에 작용해 액체 속에서 입자가 뭉치지 않게 한다. 계면활성제의 쓰임이므로 적절하지 않다는 답은 옳지 않다.
    3. 습윤제는 액체의 표면장력을 낮춰 고체 표면에 잘 퍼지게 한다. 계면활성제의 쓰임이므로 적절하지 않다는 답은 옳지 않다.
    4. 유화제는 물과 기름의 경계에 자리해 작은 방울이 합쳐지지 않게 한다. 계면활성제의 쓰임이므로 적절하지 않다는 답은 옳지 않다.
    🧮 풀이
    1. 고무 배합물에 가교제를 넣자 서로 떨어져 있던 고분자 사슬이 화학결합으로 이어졌다. 제품의 탄성과 강도가 바뀌었다. 물과 기름의 경계면을 조절하는 계면활성 작용은 아니었다.
    2. 안료 입자가 든 페인트에 분산제를 넣고 같은 온도에서 용액을 저었다. 분산제가 입자 표면에 붙어 입자끼리 뭉치는 힘이 줄었다. 안료가 액체 속에 고르게 퍼진 상태가 오래 유지됐다.
    3. 왁스가 칠해진 판에 물을 떨어뜨리자 방울이 둥글게 맺혀 작은 면적만 적셨다. 습윤제를 넣은 물은 접촉각이 낮아져 판 위로 넓게 퍼졌다. 고체와 액체의 경계 성질이 바뀌었다.
    4. 물과 기름을 섞은 액체에 유화제를 넣고 충분히 저어 기름을 작은 방울로 나눴다. 유화제 분자가 두 액체의 경계에 자리해 기름 방울이 다시 합쳐지는 것을 막았다. 혼합물이 작은 방울을 유지했다.

    가교제는 고분자 사슬 사이에 결합을 만들어 망상 구조를 형성한다. 계면활성제 용도가 아닌 1번이 옳다.

    알루미나(Al2O3)의 제조에 이용되는 공정은?

    1. 1. Bayer 공정
    2. 2. Reppe 공정
    3. 3. Solvay 공정
    4. 4. Wacker 공정

    정답 1번

    🔍 보기별 해설
    1. Bayer 공정은 보크사이트를 알칼리로 처리해 알루미나를 제조한다. 알루미나 생산에 이용되므로 옳다(정답).
    2. Reppe 공정은 아세틸렌을 원료로 다양한 유기화합물을 합성하는 반응 계열이다. 알루미나 제조 공정이 아니므로 옳지 않다.
    3. Solvay 공정은 식염수와 암모니아, 이산화탄소를 이용해 탄산나트륨을 만든다. 알루미나 제조 공정이 아니므로 옳지 않다.
    4. Wacker 공정은 에틸렌을 산화해 아세트알데하이드를 얻는 촉매 공정이다. 알루미나 제조 공정이 아니므로 옳지 않다.
    🧮 풀이
    1. 보크사이트를 뜨거운 수산화나트륨 용액으로 처리하자 알루미늄 성분이 녹아 나왔다. 불순물을 분리하고 수산화알루미늄을 침전·소성해 알루미나를 얻었다. Bayer 공정의 흐름이다.
    2. 아세틸렌을 출발 원료로 삼아 고압 반응기에서 유기 합성 반응을 진행했다. 반응 생성물은 아세틸렌 화학의 유기물이었다. 보크사이트에서 산화알루미늄을 분리하는 공정과 관계없었다.
    3. 식염수에 암모니아와 이산화탄소를 연속해서 공급해 탄산수소나트륨을 만들었다. 이를 가열해 탄산나트륨을 얻었다. Solvay 공정의 제품은 알루미나가 아니라 소다회였다.
    4. 에틸렌을 팔라듐계 촉매가 있는 반응기에 넣고 산소와 함께 산화했다. 유기 생성물 아세트알데하이드가 나왔다. Wacker 공정은 보크사이트 정제와 다른 유기화학 공정이었다.

    Bayer 공정은 보크사이트에서 알루미나를 얻는 산업 공정이다. 1번이 옳다.

    4-에틸-3-메틸헵테인(4-ethyl-3-methylheptane) 분자 1개당 수소 원자 개수는?

    1. 1. 20
    2. 2. 22
    3. 3. 24
    4. 4. 26

    정답 2번

    🔍 보기별 해설
    1. 탄소 수는 헵테인 7개에 에틸 2개와 메틸 1개를 더해 10개다. 포화 사슬형 알케인 C₁₀H₂₂라 수소 원자 22개이므로 2번이 옳다(정답).
    🧮 풀이
    1. ① 탄소 원자 수를 센다. 헵테인 주사슬에는 탄소 7개, 에틸기에 2개, 메틸기에 1개가 있으므로 전체 탄소는 10개다.
    2. → n = 7+2+1 = 10
    3. ↓
    4. ② 포화 분자식을 적용한다. 선형 알케인에는 탄소·탄소 이중결합이 없으므로 수소 수는 2n+2다.
    5. → H 원자 수 = 2×10+2 = 22개

    주사슬 7개와 에틸 2개, 메틸 1개를 합하면 탄소가 10개다. 포화 사슬형 알케인 C₁₀H₂₂이므로 수소 22개인 2번이 옳다.

    고분자의 분자량을 측정하는 방법으로 옳지 않은 것은?

    1. 1. 광산란법
    2. 2. 점도측정법
    3. 3. 적외선 분광법
    4. 4. 겔 투과 크로마토그래피

    정답 3번

    🔍 보기별 해설
    1. 광산란법은 고분자 용액이 빛을 산란시키는 정도로 분자량을 추정한다. 분자량 측정법이므로 아닌 것을 묻는 답은 옳지 않다.
    2. 점도측정법은 고분자 용액 점도와 사슬 크기의 관계를 이용해 점도평균분자량을 구한다. 분자량 측정법이므로 옳지 않다.
    3. 적외선 분광법은 특정 결합의 진동 흡수로 작용기와 구조를 살핀다. 일반적인 고분자 분자량 측정법이라는 설명은 옳지 않다(정답).
    4. 겔 투과 크로마토그래피는 고분자를 크기에 따라 분리해 분자량 분포를 추정한다. 분자량 측정법이므로 옳지 않다.
    🧮 풀이
    1. 고분자 용액에 빛을 비추고 여러 각도에서 산란 강도를 측정했다. 용액 농도와 산란 자료를 분석해 사슬의 평균 분자량을 추정했다. 광산란법이 분자량 측정에 쓰였다.
    2. 고분자 용액을 모세관 점도계에 흘려 순수 용매보다 흐름이 얼마나 느린지 측정했다. 고유점도를 분자량과 연결하는 식에 넣어 점도평균분자량을 얻었다. 사슬 크기의 영향을 이용한 방법이다.
    3. 고분자 필름에 적외선을 비추자 결합마다 다른 파장에서 흡수 피크가 나왔다. 분석자는 카보닐기 같은 작용기의 존재를 판별했다. 이 피크만으로 사슬 전체의 평균 분자량을 직접 구하지 않았다.
    4. 고분자 용액을 겔 투과 크로마토그래피 칼럼에 넣어 다공성 겔 사이로 흘렸다. 큰 사슬과 작은 사슬이 서로 다른 시간에 나와 검출기에 기록됐다. 분자량별 분포를 얻을 수 있었다.

    적외선 분광법은 주로 분자 결합과 작용기의 흡수를 분석한다. 분자량 측정법이 아닌 3번이 옳다.

    석유 유분에 함유된 메르캅탄(mercaptan)을 산화시켜 제거하는 정제법은?

    1. 1. 알킬화
    2. 2. 스위트닝
    3. 3. 수소화 분해
    4. 4. 수소화 정제

    정답 2번

    🔍 보기별 해설
    1. 알킬화는 작은 올레핀과 이소부탄을 반응시켜 고옥탄가 성분을 만든다. 메르캅탄 산화 공정이 아니므로 옳지 않다.
    2. 스위트닝은 악취가 나는 메르캅탄을 산화하여 디설파이드로 바꾼다. 석유 유분의 메르캅탄 처리법이므로 옳다(정답).
    3. 수소화 분해는 촉매와 수소를 이용해 무거운 탄화수소를 더 작은 분자로 쪼갠다. 메르캅탄 산화와 목적과 반응이 달라 옳지 않다.
    4. 수소화 정제는 수소를 공급해 황 화합물 등을 제거하는 처리법이다. 메르캅탄을 산화시키는 스위트닝과 달라 옳지 않다.
    🧮 풀이
    1. 정유 공장에서 이소부탄과 올레핀을 산성 촉매 반응기로 보냈다. 두 원료가 결합해 휘발유 배합에 쓰는 알킬레이트를 만들었다. 악취 성분의 산화 제거가 아니라 탄화수소의 결합 반응이었다.
    2. 메르캅탄 냄새가 나는 경질 석유 유분을 스위트닝 장치로 보냈다. 산화제와 촉매의 작용으로 메르캅탄이 디설파이드로 바뀌었다. 처리 후 유분의 불쾌한 냄새와 부식성이 줄었다.
    3. 고비점 석유 유분을 수소와 함께 고압 촉매 반응기에 넣었다. 긴 탄화수소 사슬이 끊어져 더 가벼운 연료 성분이 늘었다. 이 장치의 주된 목적은 유분의 분해와 전환이었다.
    4. 황 화합물이 들어 있는 유분에 수소를 공급하고 촉매층을 통과시켰다. 황은 황화수소 형태로 분리되어 제품의 황 함량이 내려갔다. 산화제를 써서 메르캅탄을 디설파이드로 바꾸는 공정과 구별된다.

    스위트닝은 메르캅탄을 산화해 석유 유분의 악취와 부식성을 줄인다. 2번이 옳다.

    ( S )-2-Butanol의 입체 구조로 옳은 것은?

    1. 1.
    2. 2.
    3. 3.
    4. 4.

    정답 1번

    🔍 보기별 해설
    1. 첫 구조는 수소가 점선 결합으로 뒤에 있고 OH에서 에틸, 메틸로 향하는 순서가 반시계 방향이다. S 배열의 2-부탄올이므로 옳다(정답).
    2. 둘째 구조는 중심 탄소에 같은 메틸기가 여러 개 붙어 있다. 서로 다른 네 치환기를 가진 2-부탄올의 입체중심이 아니므로 옳지 않다.
    3. 셋째 구조에서는 OH의 결합 위치가 끝 탄소로 달라진다. OH가 둘째 탄소에 붙은 2-부탄올이 아니므로 옳지 않다.

    수소 결합을 이루지 않는 것은?

    1. 1. 에탄올(ethanol)
    2. 2. 불화수소(hydrogen fluoride)
    3. 3. 아세트산(acetic acid)
    4. 4. 다이에틸에터(diethyl ether)

    정답 4번

    🔍 보기별 해설
    1. 에탄올은 산소에 결합한 수소를 가진 O–H기를 포함한다. 에탄올 분자 사이에 수소 결합을 이루므로 옳지 않다.
    2. 불화수소는 전기음성도가 큰 플루오린에 수소가 직접 결합한다. 분자 사이에 강한 수소 결합을 이루므로 옳지 않다.
    3. 아세트산은 카복실기의 O–H와 카보닐 산소가 수소 결합에 참여한다. 두 분자가 이량체를 이룰 수도 있으므로 옳지 않다.
    4. 다이에틸에터에는 산소가 있지만 산소에 직접 결합한 수소가 없다. 순수한 에터 분자끼리 수소 결합을 만들지 못하므로 옳지 않다(정답).
    🧮 풀이
    1. 에탄올 액체에서 한 분자의 OH 수소가 옆 분자의 산소를 향하도록 모형을 놓았다. 두 분자 사이에 O–H···O 상호작용이 생겼다. 이 분자 간 수소 결합이 에탄올의 끓는점에 영향을 주었다.
    2. 불화수소 분자를 여러 개 일렬로 그렸다. 한 HF의 수소가 이웃 HF의 플루오린 쪽으로 끌려 분자들이 연결됐다. 강한 H–F 결합의 극성 때문에 분자 간 수소 결합이 나타났다.
    3. 아세트산 두 분자의 카복실기를 서로 마주 보게 배치했다. 한쪽 OH의 수소가 다른 쪽 카보닐 산소를 향하는 연결이 양쪽에서 만들어졌다. 고리 모양 이량체에 수소 결합 두 개가 형성됐다.
    4. 다이에틸에터 두 분자의 산소를 나란히 놓고 수소 결합의 공여자를 찾았다. 산소는 비공유 전자쌍을 가졌지만 각 수소는 탄소에 붙어 있었다. 순수한 다이에틸에터 시료에는 O–H 또는 N–H 공여기가 없었다.

    P와 O의 형식전하를 옳게 짝 지은 것은?

    P O

    1. 1. ＋1 0
    2. 2. ＋1 －1
    3. 3. －1 0
    4. 4. －1 －1

    정답 2번

    🔍 보기별 해설
    1. P는 결합 네 개라 +1이지만 단일 결합 O는 비공유 전자쌍 세 개라 −1이다. 산소를 0으로 적은 짝은 옳지 않다.
    2. P의 형식전하는 5−4=+1이고 O는 6−6−1=−1이다. 그림의 결합과 비공유 전자를 그대로 셌으므로 옳다(정답).
    3. P에 결합 네 개와 비공유 전자쌍이 없으면 원자가전자 5에서 4를 빼 형식전하는 +1이다. P를 −1로 적은 짝은 옳지 않다.
    4. 단일 결합 O의 −1은 맞지만 P의 형식전하는 +1이다. 둘을 모두 음전하로 적으면 전체 중성 전하도 맞지 않아 옳지 않다.
    🧮 풀이
    1. 인에 염소 세 개와 산소 하나가 단일 결합한 구조를 그렸다. 산소 주위에 비공유 전자쌍 세 개를 넣으니 산소가 맡는 전자는 일곱 개였다. 산소 원자가전자 여섯 개보다 하나 많아 형식전하는 −1이었다.
    2. 분자 그림의 P 원자 주변 결합 네 개를 확인하고 원자가전자 5에서 결합 수 4를 뺐다. 산소에서는 원자가전자 6에서 비공유 전자 6과 결합 1을 뺐다. 두 결과는 +1과 −1로 합이 0이었다.
    3. P에 붙은 결합선을 하나씩 세니 염소 쪽으로 세 개, 산소 쪽으로 한 개였다. 비공유 전자쌍이 없는 P의 형식전하를 5−4로 계산했다. −1이 되려면 현재 그림과 다른 전자 배치가 필요했다.
    4. 분자 전체가 중성이라는 조건을 놓고 원자별 형식전하를 더했다. 세 염소의 형식전하는 각각 0이고 P의 +1과 O의 −1이 서로 상쇄됐다. P도 −1로 놓으면 전체 합이 중성 분자와 맞지 않았다.

    그림의 P는 결합 네 개로 형식전하 +1이고 단일 결합 O는 비공유 전자 여섯 개로 −1이다. 2번이 옳다.

    다음 구조식을 갖는 고분자는?

    1. 1. 폴리에스터(polyester)
    2. 2. 폴리우레아(polyurea)
    3. 3. 폴리우레탄(polyurethane)
    4. 4. 폴리아마이드(polyamide)

    정답 4번

    🔍 보기별 해설
    1. 폴리에스터는 카보닐 옆에 질소가 아니라 산소가 붙은 −CO−O− 결합을 반복한다. 그림의 −CO−NH−와 달라 옳지 않다.
    2. 폴리우레아는 카보닐 양쪽에 질소가 붙은 −NH−CO−NH− 결합을 가진다. 그림에는 그 자리의 질소가 하나라 옳지 않다.
    3. 폴리우레탄의 우레탄 결합은 −NH−CO−O−로 카보닐 옆 산소가 더 들어간다. 그림의 아마이드 연결과 달라 옳지 않다.
    4. 폴리아마이드는 카보닐 탄소와 질소가 직접 이어진 −CO−NH− 결합을 반복한다. 그림의 결합과 일치하므로 옳다(정답).
    🧮 풀이
    1. 페트병 재료인 폴리에스터의 반복 구조를 보니 카보닐 뒤에 O가 이어졌다. 에스터 결합 −CO−O−의 산소 자리에 그림에서는 NH가 있었다. 두 재료는 같은 카보닐을 가져도 연결 원자가 달랐다.
    2. 폴리우레아 코팅재의 구조식에서 한 카보닐의 양쪽에 NH를 하나씩 표시했다. −NH−CO−NH−라는 대칭 연결이 드러났다. 문제 그림은 카보닐 한쪽에만 NH가 있어 이 결합과 구별됐다.
    3. 우레탄 스펀지의 반복 단위를 펼쳐 −NH−CO−O− 부분을 찾았다. 카보닐 다음 산소가 다른 고분자 사슬 쪽으로 연결됐다. 그림의 −NH−CO− 결합에는 이 산소 연결이 없었다.
    4. 나일론 섬유의 고분자 사슬에서 −CO−NH−가 여러 번 반복되는 부분을 표시했다. 카보닐 탄소와 질소가 직접 결합한 구조가 문제 그림과 같았다. 같은 형태의 결합은 단백질의 펩타이드 결합에도 있다.

    반복 단위의 −CO−NH− 연결은 아마이드 결합이다. 이를 가진 폴리아마이드인 4번이 옳다.

    실리콘 반도체의 제조 공정을 진행 순서대로 옳게 나열한 것은?

    1. 1. 감광제 도포 → 노광 → 산화 → 식각
    2. 2. 감광제 도포 → 산화 → 식각 → 노광
    3. 3. 산화 → 감광제 도포 → 노광 → 식각
    4. 4. 산화 → 식각 → 감광제 도포 → 노광

    정답 3번

    🔍 보기별 해설
    1. 감광제 도포와 노광 뒤에 산화막을 만들면 새 막이 정의한 패턴을 덮는다. 산화가 맨 앞에 와야 하므로 옳지 않다.
    2. 산화막을 만들기 전에 감광제를 바르고 식각도 노광보다 앞에 놓았다. 막 형성과 패턴 형성의 순서가 모두 어긋나 옳지 않다.
    3. 산화로 실리콘 표면에 막을 형성하고 감광제를 바른 뒤 노광으로 패턴을 만든다. 그 패턴을 따라 선택적으로 식각하므로 옳다(정답).
    4. 식각을 감광제 도포와 노광보다 먼저 하면 보호할 부분의 무늬가 없다. 산화 뒤에도 노광보다 식각이 앞서 옳지 않다.
    🧮 풀이
    1. 웨이퍼에 감광제를 먼저 바르고 노광한 뒤 산화로에 넣는 순서를 시험했다. 고온 산화 단계가 이미 만든 감광제 패턴에 영향을 주었다. 실제 공정에서는 산화막을 먼저 형성한 뒤 패턴 작업을 시작했다.
    2. 산화막이 없는 웨이퍼에 감광제를 바른 뒤 노광도 하지 않고 식각기에 넣었다. 제거할 위치를 정한 패턴이 없어 원하는 회로 무늬가 나오지 않았다. 산화와 노광의 순서를 앞뒤로 바꾼 공정이었다.
    3. 실리콘 웨이퍼를 산화해 절연막을 만들고 표면에 감광제를 균일하게 발랐다. 마스크를 통해 빛을 쬐어 회로 무늬를 옮겼다. 현상한 패턴을 보호막으로 삼아 드러난 산화막을 식각했다.
    4. 산화막을 입힌 웨이퍼를 곧장 식각기에 넣었다. 빛으로 옮긴 감광제 무늬가 없어 남겨야 할 부분을 보호하지 못했다. 식각은 감광제 도포와 노광으로 위치를 정한 뒤 진행해야 했다.

    실리콘 표면에 산화막을 만든 뒤 감광제를 바르고 노광해 무늬를 정한 다음 식각한다. 3번이 옳다.

    사슬중합과 단계중합에 대한 설명으로 옳은 것만을 모두 고르면?

    ㄱ. 사슬중합은 개시제가 반드시 필요하다.

    ㄴ. 사슬중합에서는 시간에 따라 평균 분자량의 증가 속도가 느려진다.

    ㄷ. 단계중합에서는 시간에 따라 단량체의 소모 속도가 느려진다.

    1. 1. ㄱ
    2. 2. ㄱ, ㄴ
    3. 3. ㄴ, ㄷ
    4. 4. ㄱ, ㄴ, ㄷ

    정답 3번

    🔍 보기별 해설
    1. 사슬중합은 열이나 빛 등으로 활성종이 생겨 시작되는 경우도 있어 별도 개시제가 언제나 필요한 것은 아니다. 반드시 필요하다는 단정은 옳지 않다.
    2. 사슬중합은 초기에 활성 사슬이 빠르게 길어지고 이후 평균 분자량 증가가 둔해진다. 시간에 따른 증가 속도 설명이므로 옳다.
    3. 단계중합에서는 반응성이 있는 단량체가 초기에 많이 만나고 농도가 낮아질수록 소모가 느려진다. 시간 경과에 따른 설명이므로 옳다.
    🧮 풀이
    1. 스타이렌을 열중합 조건으로 가열해 사슬 성장을 시작시켰다. 열에 의해 생긴 활성종이 단량체에 붙으며 중합이 진행됐다. 별도로 투입한 화학 개시제가 없는 운전 조건도 가능했다.
    2. 라디칼 중합을 시작하자 활성 사슬에 단량체가 잇달아 붙어 초기에 긴 사슬이 나타났다. 시간이 지나며 남은 단량체와 활성 사슬의 조건이 바뀌어 평균 분자량의 증가 곡선 기울기가 낮아졌다. 측정값을 시간축에 그려 비교했다.
    3. 디올과 디카복실산의 단계중합 반응기에서 초기에는 두 작용기를 가진 단량체가 풍부했다. 반응이 진행되자 반응 가능한 단량체 농도가 줄고 단량체 소모 속도도 낮아졌다. 뒤에는 긴 사슬끼리 결합하는 비중이 커졌다.

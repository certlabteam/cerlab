    그림의 회로에서 전류 I [A]는?

    1. 1. 0.5
    2. 2. 1
    3. 3. 1.5
    4. 4. 2

    정답 4번

    🔍 보기별 해설
    1. 0.5 A는 3 A를 저항 비와 관계없이 나눈 값이라 분류 공식으로 구한 1 Ω 가지의 전류 2 A와 맞지 않으므로 옳지 않다.
    2. 1 A는 3 A를 세 갈래로 똑같이 나눈 값이라 저항 1 Ω과 2 Ω의 병렬 분류 공식과 맞지 않으므로 옳지 않다.
    3. 1.5 A는 3 A를 절반으로 나눈 값이라 저항 비 1 대 2에 반비례해 나뉘는 분류와 맞지 않으므로 옳지 않다.
    4. 전원 마디에서 1 Ω 가지와 2 Ω 가지가 모두 접지 도선에 이어져 병렬이므로 1 Ω 쪽 전류는 3×2/(1+2)=2 A가 되어 옳다(정답).
    🧮 풀이
    1. 甲은 입체 그림에서 아래 도선과 이어진 세로 도선을 짚어 오른쪽 마디가 모두 같은 전위라는 것을 알았다. 그러면 1옴과 2옴이 전류원 마디에서 병렬로 놓인다고 적었다.
    2. 甲은 3암페어를 절반으로 나눈 풀이를 살폈다. 저항이 다르면 저항에 반비례해 나뉜다는 점을 짚고 1옴 쪽이 더 많이 받는다는 것을 표시했다. 3암페어를 절반으로 나누는 것은 두 저항이 같을 때만 성립한다는 점도 적었다.
    3. 甲은 3암페어를 셋으로 나눈 풀이를 살폈다. 병렬 가지가 둘뿐이라는 점을 그림에서 확인하고 두 가지에만 나뉜다고 노트에 적었다. 병렬 가지 수가 둘이므로 3으로 나누는 것은 맞지 않는다는 점을 표시했다.
    4. 甲은 분류 공식으로 1옴 가지에 2, 2옴 가지에 1이 흐르는 것을 계산했다. 합이 3이라는 점을 확인하고 저항이 작은 쪽에 더 흐른다고 정리했다. 1옴 가지 2암페어와 2옴 가지 1암페어의 합이 전류원의 3암페어와 같다는 검산을 옆에 적었다.

    입체로 그려진 회로에서 오른쪽 마디들이 아래 도선으로 이어져 접지라 1 Ω과 2 Ω이 3 A 전류원에 병렬이므로 1 Ω에는 3×2/(1+2)=2 A가 흘러 4번이 옳다.

    그림의 회로에서 전류 I_1 과 I_2 에 대한 방정식이 다음과 같을 때, a_1 + a_2 의 값은?

    a_1 I_1 - 20 I_2 = 15# -20 I_1 + a_2 I_2 = 5

    1. 1. 40
    2. 2. 50
    3. 3. 60
    4. 4. 70

    정답 4번

    🔍 보기별 해설
    1. 40은 a₁만의 값이라 a₁에 a₂를 더한 40+30=70과 맞지 않으므로 이 보기는 a₁+a₂로 옳지 않다.
    2. 50은 a₁이나 a₂ 중 하나를 잘못 계산해서 얻은 합이라 왼쪽 40과 오른쪽 30의 합 70과 맞지 않으므로 옳지 않다.
    3. 60은 a₂를 20으로 본 합이라 오른쪽 망 저항 10+20=30과 맞지 않아 a₁+a₂=70이 되어야 하므로 옳지 않다.
    4. 왼쪽 망 저항은 20+5+15=40이고 오른쪽 망 저항은 10+5+15=30이므로 a₁+a₂=70이 되어 옳다(정답).
    🧮 풀이
    1. 甲은 그림에서 두 망에 공통으로 쓰이는 저항이 5옴과 15옴을 합친 20옴임을 읽었다. 왼쪽 망의 총저항은 20과 20을 더해 40이라고 적었다. 20옴과 공통 저항 20옴을 더한 40옴이 왼쪽 망의 계수 a₁이라는 점을 옆에 적었다.
    2. 甲은 오른쪽 망의 총저항을 10과 공통 저항 20을 더해 30으로 구했다. 두 값을 더해 70이라는 답을 확인했다. 왼쪽 40과 오른쪽 30을 합한 70이 a₁+a₂라는 점을 다시 적었다.
    3. 甲은 60이라는 값이 나온 풀이를 살폈다. 오른쪽 망의 저항을 20으로 잘못 놓은 것이라는 점을 알고 10과 공통 저항 20을 더해 30으로 고쳤다. 60은 오른쪽 망 저항을 20으로 본 값이라 40과 더한 결과라는 점을 표에 옮겼다.
    4. 甲은 40이나 50이 나온 풀이를 살폈다. a₁만 답으로 적었거나 저항 일부를 빼먹은 결과라는 점을 확인했다. 왼쪽 망은 20, 5, 15옴의 합이고 오른쪽 망은 10, 5, 15옴의 합이라는 점을 적었다.

    메시 방정식은 왼쪽 망에서 (20+5+15)I₁−20I₂=15이고 오른쪽 망에서 −20I₁+(10+20)I₂=5이므로 a₁=40, a₂=30이고 합은 70이며 4번이 옳다.

    그림의 3상 교류 시스템에서 부하에 소비되는 전력을 2－전력계법으로 측정한 값이 P_1 은 50 [W]이고 P_2 는 100 [W]일 때, 전체 피상전력[VA]은?

    1. 1. 50
    2. 2. 50 √(3)
    3. 3. 100 √(3)
    4. 4. 150 √(3)

    정답 3번

    🔍 보기별 해설
    1. 50 VA는 P₁만 쓴 값이라 유효전력 150 W보다도 작으므로 전체 피상전력 100√3 VA로 옳지 않다.
    2. 50√3 VA는 무효전력의 크기만 계산한 값이라 유효전력 150 W까지 포함한 피상전력이 아니므로 옳지 않다.
    3. P=150 W, Q=√3×50=50√3 var이므로 S=√(150²+(50√3)²)=100√3 VA가 되어 옳다(정답).
    4. 150√3 VA는 유효전력에 √3을 곱해 얻는 값이라 피상전력 √(P²+Q²)=100√3 VA와 맞지 않으므로 옳지 않다.
    🧮 풀이
    1. 甲은 그림에서 전력계 둘이 서로 다른 선과 공통선 사이에 연결된 2전력계법이라는 것을 확인했다. 두 값의 합이 전체 유효전력 150와트라는 것을 적었다. P₁이 50와트, P₂가 100와트라 합이 150와트라는 점을 다시 적었다.
    2. 甲은 무효전력을 √3에 두 전력계 값의 차 50을 곱해 구했다. 유효전력과 무효전력의 제곱합으로 피상전력을 구해 100√3을 얻었다. 무효전력은 √3에 두 값의 차 50을 곱한 50√3바라는 점을 옆에 적었다.
    3. 甲은 50이라고 답을 적은 풀이를 살폈다. 전력계 하나의 값이라 전체 피상전력보다 훨씬 작다는 점을 알리고 두 값을 모두 쓰도록 다시 계산하게 했다. 전력계 하나의 값은 유효전력의 일부일 뿐 피상전력이 아니라는 점을 표시했다.
    4. 甲은 150√3이라고 적은 풀이를 살폈다. 유효전력 150에 √3을 곱한 값은 피상전력이 아니라는 점을 짚었다. 피상전력은 √(150²+(50√3)²)=100√3이라는 계산도 옆에 적었다.

    2전력계법에서 P=P₁+P₂=150 W이고 Q=√3(P₂−P₁)=50√3 var이므로 피상전력은 √(150²+(50√3)²)=100√3 VA이며 3번이 옳다.

    그림의 회로에서 전원이 공급하는 평균전력은 100 [W]이고 지상 역률이 1/√(2) 일 때, 저항 R [Ω]와 인덕턴스 L [mH]은? (단, v(t) = 40cos(1000t) [V]이다)

    R L

    1. 1. 1 4
    2. 2. 2 5
    3. 3. 3 4
    4. 4. 4 5

    정답 2번

    🔍 보기별 해설
    1. R=1 Ω이면 전체 저항이 3 Ω이 되어 평균전력 조건 P=400/R_t=100에서 구한 전체 저항 4 Ω과 맞지 않으므로 옳지 않다.
    2. P=I²R_t=100 W와 역률 1/√2에서 전체 저항 R_t=4 Ω이라 R=4−2=2 Ω이고 X_L−1=4에서 X_L=5 Ω이므로 L=5 mH가 되어 옳다(정답).
    3. R=3 Ω이면 전체 저항이 5 Ω이 되어 평균전력 조건 P=400/R_t=100에서 구한 전체 저항 4 Ω과 맞지 않으므로 옳지 않다.
    4. R=4 Ω이면 전체 저항이 6 Ω이 되어 평균전력 조건 P=400/R_t=100에서 구한 전체 저항 4 Ω과 맞지 않으므로 옳지 않다.
    🧮 풀이
    1. 甲은 v(t)가 40cos(1000t)이므로 최댓값 40볼트, 각주파수 1,000이라는 것을 읽었다. 1밀리패럿의 리액턴스가 1옴이라는 점도 함께 계산했다. 1밀리패럿 커패시터의 리액턴스 1옴이 인덕터 쪽 리액턴스에서 빠진다는 점도 곁들였다.
    2. 甲은 역률이 1/√2이면 순리액턴스와 전체 저항이 같다고 정리했다. 평균전력 100와트에서 전체 저항이 4옴이라고 구했다. 평균전력 100와트는 전류 실횻값의 제곱에 전체 저항을 곱한 값이라는 점도 적었다.
    3. 甲은 직렬로 놓인 2옴을 빼 R이 2옴이라는 것을 얻었다. 유도성 리액턴스 5옴에서 인덕턴스가 5밀리헨리라는 것을 이어서 계산했다. 직렬 2옴과 R을 더한 전체 저항 4옴이라 R=2옴이라는 식을 옆에 적었다.
    4. 甲은 R이 3옴이나 4옴이라고 적은 풀이를 살폈다. 전체 저항 4옴에서 2옴을 빼야 한다는 점을 알려 주었다. 전체 저항이 R+2이므로 6옴이나 5옴이 되면 조건 4옴과 어긋난다는 점을 표시했다.

    평균전력 100 W와 지상 역률 1/√2에서 전체 저항이 4 Ω이므로 R=4−2=2 Ω이고 순리액턴스 4 Ω에서 유도성 리액턴스 5 Ω이라 L=5 mH이며 2번이 옳다.

    그림과 같은 권선수 N , 반지름 r [cm], 길이 l [cm]을 갖는 원통 모양의 솔레노이드가 있다. 인덕턴스가 가장 큰 것은? (단, 솔레노이드의 내부 자기장은 균일하고 외부 자기장은 무시할 만큼 작다)

    N r l

    1. 1. 500 0.5 25
    2. 2. 1,000 0.5 50
    3. 3. 2,000 1.0 100
    4. 4. 3,000 0.5 150

    정답 3번

    🔍 보기별 해설
    1. 500회, 0.5 cm, 25 cm는 N²r²/l=500²×0.25÷25=2,500으로 네 값 중 가장 작으므로 옳지 않다.
    2. 1,000회, 0.5 cm, 50 cm는 N²r²/l=1,000²×0.25÷50=5,000으로 3번의 40,000보다 작으므로 옳지 않다.
    3. 2,000회, 1.0 cm, 100 cm는 N²r²/l=2,000²×1÷100=40,000으로 네 값 중 가장 커서 인덕턴스가 가장 크므로 옳다(정답).
    4. 3,000회, 0.5 cm, 150 cm는 N²r²/l=3,000²×0.25÷150=15,000으로 3번의 40,000보다 작으므로 옳지 않다.
    🧮 풀이
    1. 甲은 솔레노이드 인덕턴스가 권선수의 제곱과 반지름의 제곱에 비례하고 길이에 반비례한다는 식을 적었다. 상수는 같으므로 N²r²/l만 비교하면 된다고 정리했다. 500회, 0.5센티미터, 25센티미터를 넣으면 500²×0.25÷25가 2,500이라는 계산을 이어 적었다.
    2. 甲은 첫째 보기를 계산해 2,500을 얻었다. 둘째 보기는 5,000이어서 값이 커지는 순서를 표에 적고 셋째 보기와 비교할 수 있게 열을 나란히 만들었다. 둘째 보기가 첫째의 두 배인 5,000이라 셋째와 견주려면 40,000을 함께 봐야 한다는 점도 적었다.
    3. 甲은 셋째 보기를 계산해 40,000이 나온 것을 확인했다. 반지름이 다른 보기보다 두 배라 값이 네 배로 커진다는 점을 짚었다. 2,000회의 제곱 4,000,000에 반지름 제곱 1을 곱해 100으로 나눈 값이 40,000이라는 점도 적었다.
    4. 甲은 넷째 보기의 15,000이 셋째의 40,000보다 작다는 것을 확인했다. 권선수가 가장 많아도 길이가 길면 값이 줄어든다는 점을 적었다. 3,000회의 제곱 9,000,000에 0.25를 곱하고 150으로 나눠 15,000이 나오는 계산을 옆에 두었다.

    솔레노이드의 인덕턴스는 권선수의 제곱에 단면적을 곱해 길이로 나눈 값에 비례하므로 N²r²/l가 가장 큰 2,000회, 반지름 1 cm, 길이 100 cm인 3번이 옳다.

    그림의 회로에서 스위치 S가 충분히 긴 시간 동안 닫혀 있다가 t = 0 에서 개방되었다. t > 0 일 때의 전류 i(t) [A]는?

    1. 1. {1 / 4} e^(-t) + {7 / 4} e^(-9t)
    2. 2. {7 / 4} e^(-t) + {1 / 4} e^(-9t)
    3. 3. {9 / 4} e^(-t) - {1 / 4} e^(-9t)
    4. 4. - {1 / 4} e^(-t) + {9 / 4} e^(-9t)

    정답 1번

    🔍 보기별 해설
    1. 개방 직전 인덕터 전류 2 A와 커패시터 전압 16 V에서 특성근 −1, −9와 초기 조건 i(0)=2, i′(0)=−16을 만족하면 계수가 1/4과 7/4가 되어 옳다(정답).
    2. 계수가 7/4와 1/4로 뒤바뀐 이 식은 i(0)=2는 만족하지만 i′(0)=−7/4−9/4=−4로 −16과 맞지 않으므로 옳지 않다.
    3. 9/4e^{-t}−1/4e^{-9t}는 i(0)=2는 만족하지만 i′(0)=−9/4+9/4=0으로 −16과 맞지 않으므로 옳지 않다.
    4. −1/4e^{-t}+9/4e^{-9t}는 i(0)=2는 만족하지만 i′(0)=1/4−81/4=−20으로 −16과 맞지 않으므로 옳지 않다.
    🧮 풀이
    1. 甲은 개방 직전 스위치가 오래 닫혀 인덕터에 2암페어가 흐르고 커패시터가 16볼트로 충전되어 있다는 것을 읽었다. 열린 뒤 직렬 RLC가 되어 특성근이 −1과 −9라는 것을 구했다.

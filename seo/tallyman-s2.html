    선상에서 오전에 처음 만나는 사람에게 하는 인사말로 적절하지 않은 것은?

    1. 1. How are you?
    2. 2. How do you do?
    3. 3. Good morning, Sir!
    4. 4. I go to Busan!

    정답 4번

    🔍 보기별 해설
    1. How are you?는 만난 사람의 안부를 묻는 인사다. 오전에 처음 만날 때 사용할 수 있으므로 옳다.
    2. How do you do?는 처음 소개받는 자리의 격식 있는 인사다. 오전의 첫 만남에 어울리므로 옳다.
    3. Good morning, Sir!는 오전에 윗사람에게 하는 인사다. 시간과 상대가 모두 맞으므로 옳다.
    4. I go to Busan!은 부산에 간다는 행선지 설명이다. 오전의 첫 인사가 아니므로 옳지 않다(정답).
    🧮 풀이
    1. 오전 첫 근무를 위해 갑판에 오른 검수사 甲은 일항사에게 ‘How are you?’라고 인사했다. 일항사는 안부에 답하고 그날의 선창 작업 계획을 전달했다. 두 사람은 인사를 마친 뒤 검수표를 펼쳐 작업을 시작했다.
    2. 처음 만난 감독관에게 검수사 甲은 ‘How do you do?’라고 인사했다. 감독관은 같은 표현으로 답하고 담당 선창을 안내했다. 甲은 소개받은 감독관의 이름을 검수표 연락처에 적었다.
    3. 선장실 문 앞에서 검수사 甲은 ‘Good morning, Sir!’라고 아침 인사를 건넸다. 선장은 인사를 받고 그날의 선적 순서를 확인해 주었다. 甲은 서명받은 작업표를 들고 현장으로 내려갔다.
    4. 새 동료 甲은 아침에 처음 만난 감독관에게 ‘I go to Busan!’이라고 말했다. 감독관은 인사 대신 갑자기 나온 목적지를 듣고 이동 계획을 되물었다. 甲은 먼저 아침 인사를 하고 부산행 업무를 따로 설명했다.

    아침에 처음 만난 사람에게는 안부나 아침 인사를 건네야 하는데 부산에 간다는 말은 인사가 아니므로, 정답은 4번이다.

    선상에서 상대방에게 부탁하는 정중한 표현이 아닌 것은?

    1. 1. Would you please do me a favor?
    2. 2. Could you give me a hand?
    3. 3. Hey! Do me a favor.
    4. 4. Would you be so kind enough to help me?

    정답 3번

    🔍 보기별 해설
    1. Would you please do me a favor?는 상대에게 정중히 도움을 구한다. 부탁하는 표현으로 옳다.
    2. Could you give me a hand?는 상대에게 도움을 줄 수 있는지 묻는다. 정중한 부탁이므로 옳다.
    3. Hey! Do me a favor.는 거친 호칭 뒤에 명령형으로 부탁한다. 정중한 요청으로는 옳지 않다(정답).
    4. Would you be so kind enough to help me?는 상대의 친절을 구하는 부탁말이다. 공손한 요청으로 옳다.
    🧮 풀이
    1. 선창 조명을 켜야 하는 검수사 甲은 일항사에게 ‘Would you please do me a favor?’라고 정중히 부탁했다. 일항사는 요청을 듣고 조명 담당자에게 연락했다. 불이 켜져 甲은 화물 기호를 읽고 검수를 진행했다.
    2. 무거운 서류 상자를 옮기는 검수사 甲은 갑판원에게 ‘Could you give me a hand?’라고 물었다. 갑판원은 상자 한쪽을 들어 작업실까지 함께 옮겼다. 甲은 서류를 손상 없이 검수팀에 전달했다.
    3. 하역반장에게 도움을 청하던 신입 검수사 甲이 ‘Hey! Do me a favor.’라고 말했다. 반장은 명령처럼 들리는 표현에 요청 내용을 다시 물었다. 甲은 정중한 부탁말로 고쳐 말해 필요한 장비를 받았다.
    4. 세관 자료를 찾던 검수사 甲은 담당자에게 ‘Would you be so kind enough to help me?’라고 요청했다. 담당자는 보관 위치를 알려 주고 해당 서류를 건넸다. 甲은 받은 자료로 화물 번호를 대조했다.

    부탁할 때는 상대를 높이는 정중한 표현을 쓴다. ‘Hey!’로 부르며 명령하듯 말하는 3번은 옳지 않다.

    사람을 소개하는 상황에서 나누는 대화로 ( )에 적합하지 않은 것은?

    A: This is Mr. Kim. He is in charge of helping our new clients. B: ( ), Mr. Kim. I look forward to working with you.

    1. 1. Nice to meet you!
    2. 2. Hi!
    3. 3. Glad to see you!
    4. 4. Me too.

    정답 4번

    🔍 보기별 해설
    1. Nice to meet you!는 소개받은 상대에게 반갑다고 인사한다. 뒤의 김 씨 호칭과 자연스럽게 이어지므로 옳다.
    2. Hi!는 짧은 첫 인사로 쓸 수 있다. 김 씨를 소개받은 자리에서 이어 말해도 옳다.
    3. Glad to see you!는 상대를 만나 기쁘다는 뜻이다. 소개받은 자리의 인사로 옳다.
    4. ‘Me too.’는 앞사람의 말에 ‘나도 그렇다’고 동의할 때 쓰는 표현이다. 처음 소개받은 사람에게 하는 첫 인사로는 옳지 않다(정답).
    🧮 풀이
    1. 새 거래처 담당자 김 씨를 소개받은 검수사 甲은 ‘Nice to meet you!’라고 인사했다. 김 씨는 함께 일할 일정과 연락처를 전달했다. 甲은 검수 일정표에 담당자 이름을 적고 첫 회의를 시작했다.
    2. 부두 현장에서 김 씨를 소개받은 검수사 甲은 ‘Hi!’라고 짧게 인사했다. 김 씨는 인사를 받고 담당 화물의 번호를 건넸다. 甲은 번호를 검수표에 옮겨 두 사람의 공동 작업을 시작했다.
    3. 회의실에서 김 씨와 처음 대면한 검수사 甲은 ‘Glad to see you!’라고 말했다. 김 씨는 앞으로 협력할 선창의 작업표를 건넸다. 甲은 인사를 마친 뒤 작업 범위를 확인해 일정을 맞췄다.
    4. 김 씨를 소개받은 검수사 甲은 아무도 앞서 동의를 구하지 않았는데 ‘Me too.’라고 답했다. 김 씨는 무엇에 동의한다는 말인지 다시 물었다. 甲은 처음 만난 자리의 인사말로 바꾸고 업무 소개를 들었다.

    소개를 받은 사람은 인사말로 답해야 하는데 나도 그렇다는 말은 앞에 아무 말도 없는 자리에서 쓸 수 없으므로, 정답은 4번이다.

    상대방에게 사과하는 표현으로 옳지 않은 것은?

    1. 1. It's my fault.
    2. 2. I didn't mean it.
    3. 3. I am sorry.
    4. 4. I am really grateful to you.

    정답 4번

    🔍 보기별 해설
    1. It's my fault(제 잘못입니다)는 잘못이 자기에게 있다고 인정하는 말이라 사과의 뜻이 또렷하다. 상대방에게 사과하는 표현으로 맞으므로 옳다.
    2. I didn't mean it(그럴 뜻은 아니었습니다)는 의도치 않았다고 밝히며 미안함을 전하는 말이다. 사과의 자리에서 쓰는 표현이므로 옳다.
    3. I am sorry(미안합니다)는 사과의 가장 기본이 되는 말이다. 부딪혔을 때든 실수를 했을 때든 어느 자리에서든 상대에게 사과할 때 먼저 나오는 말이므로 옳다.
    4. ‘I am really grateful to you.’는 상대에게 고마움을 전하는 표현이다. 자기 잘못을 사과하는 말이 아니므로 옳지 않다(정답).
    🧮 풀이
    1. 검수표 수량을 잘못 옮긴 검수사 甲은 반장에게 ‘It's my fault.’라고 말했다. 甲은 원본 수량과 검수표를 다시 대조해 잘못된 숫자를 정정했다. 반장은 수정된 표를 받아 하역 수량을 맞췄다.
    2. 무전 내용을 잘못 전달한 검수사 甲은 상대에게 ‘I didn't mean it.’이라고 말했다. 甲은 의도하지 않은 오류를 설명하고 올바른 선창 번호를 다시 보냈다. 작업반은 정정된 무전을 받고 멈춘 작업을 재개했다.
    3. 좁은 통로에서 갑판원과 부딪힌 검수사 甲은 ‘I am sorry.’라고 말했다. 甲은 떨어진 서류를 주워 순서대로 정리해 돌려주었다. 갑판원은 서류가 모두 있는지 대조하고 통로를 비웠다.
    4. 서류 제출을 늦춘 검수사 甲이 사과해야 할 자리에서 ‘I am really grateful to you.’라고 말했다. 담당자는 감사받을 일이 아니라 지연 사유를 물었다. 甲은 사과를 전하고 제출 기한을 다시 맞췄다.

    사과하는 말은 제 잘못을 인정하거나 미안하다는 뜻을 담아야 하는데 고맙다는 말은 감사의 표현이라, 정답은 4번이다.

    ( )에 적합한 분류등급을 순서대로 나열한 것은?

    A: Mr. Kim, There are several dangerous cargoes in this yard. As you may know, these materials are flammable solids, oxidizing substances ＆ organic peroxides and radioactive materials. Can you respectively let me know the class of these materials according to the IMDG Code? B: Yes, of course. These are ( ), ( ) and Class 7, respectively.

    1. 1. Class 4, Class 5
    2. 2. Class 4, Class 6
    3. 3. Class 4, Class 9
    4. 4. Class 5, Class 6

    정답 1번

    🔍 보기별 해설
    1. Class 4(제4급)는 가연성 고체이고 Class 5(제5급)는 산화성 물질과 유기과산화물이다. 대화의 순서대로 가연성 고체가 앞, 산화성 물질과 유기과산화물이 뒤에 오므로 두 칸이 다 맞아 옳다(정답).
    2. 앞 칸 Class 4는 맞지만 뒤 칸이 어긋난다. Class 6(제6급)은 독성 물질과 전염성 물질이라 산화성 물질과 유기과산화물이 드는 등급이 아니므로 옳지 않다.
    3. 앞 칸 Class 4는 맞지만 Class 9(제9급)는 다른 등급에 들지 않는 기타 위험물을 모아 둔 등급이다. 산화성 물질은 제5급으로 따로 매겨져 있으므로 옳지 않다.
    4. 앞 칸부터 어긋난다. 가연성 고체는 제5급이 아니라 제4급이고, 뒤 칸의 Class 6도 산화성 물질의 등급이 아니다. 두 칸이 다 빗나갔으므로 옳지 않다.
    🧮 풀이
    1. 위험물 야드에서 검수사 甲은 가연성 고체의 표지에 적힌 Class 4를 기록했다. 甲은 옆의 산화성 물질 표지에서 Class 5를 읽고 두 화물을 분리했다. 위험물 목록에는 두 등급이 순서대로 남았다.
    2. 산화성 물질 드럼을 맡은 검수사 甲은 Class 6으로 적힌 초안을 발견했다. 甲은 드럼의 Class 5 표지와 목록을 대조해 숫자를 바로잡았다. 독성 물질을 뜻하는 6등급 화물과 보관 구역을 나눴다.
    3. 가연성 고체와 산화성 물질을 검수하던 甲은 두 번째를 Class 9로 적은 표를 받았다. 甲은 산화성 물질의 표지에서 5를 확인해 기록을 수정했다. 기타 위험물 구역으로 잘못 보내질 뻔한 드럼을 원래 구역에 놓았다.
    4. 두 위험물의 등급을 Class 5, Class 6으로 적은 작업표를 검수사 甲이 대조했다. 甲은 가연성 고체의 4와 산화성 물질의 5를 각각 확인했다. 잘못된 두 칸을 정정해 분리 적재 계획을 다시 만들었다.

    가연성 고체는 Class 4, 산화성 물질과 유기과산화물은 Class 5, 방사성 물질은 Class 7이므로 빈칸 둘은 Class 4와 Class 5라, 정답은 1번이다.

    Type of packing과 영문 표기가 옳게 연결된 것은?

    1. 1. 포(지)권(布卷) - Coil
    2. 2. 권(卷)(둥글게 감은 것) - Bale
    3. 3. 다발 - Bundle
    4. 4. 매 - Piece

    정답 3번

    🔍 보기별 해설
    1. 포권이나 지권은 천이나 종이를 둥글게 감은 것이라 Roll(롤)로 적는다. Coil(코일)은 철선이나 강판을 감은 것을 가리키는 말이라 짝이 어긋나므로 옳지 않다.
    2. 둥글게 감은 권은 Roll이나 Coil로 적는다. Bale은 원면이나 양모를 눌러 묶은 포장이므로 옳지 않다.
    3. Bundle은 여러 개를 한데 묶은 다발을 뜻한다. 보기의 포장 형태와 영문 명칭이 일치하므로 옳다(정답).
    4. 판이나 종이의 낱장을 세는 매는 Sheet(시트)로 적는다. Piece(피스)는 낱개를 세는 말이라 낱장을 세는 매와는 짝이 다르므로 옳지 않다.
    🧮 풀이
    1. 천을 둥글게 감은 포권을 검수사 甲이 인수했다. 甲은 표면과 포장 수량을 기록하고 롤 형태로 검수표에 적었다. 철선처럼 길게 감은 Coil과 구분해 화물 단위를 바로잡았다.
    2. 원면을 눌러 묶은 화물을 검수사 甲이 한 묶음씩 셌다. 甲은 사각형 덩어리의 수량을 Bale로 기록했다. 둥글게 감긴 화물은 별도의 롤 단위로 분류해 적재 계획에 반영했다.
    3. 강관 여덟 개를 띠로 묶은 화물을 검수사 甲이 인수했다. 甲은 묶음 단위로 수량을 세고 Bundle이라고 검수표에 썼다. 낱개 강관의 개수도 함께 적어 인도 수량을 대조할 수 있게 했다.
    4. 합판 낱장을 검수사 甲이 세면서 포장 단위를 Sheet로 기록했다. 甲은 낱개의 수량과 묶음 수량을 각각 확인했다. 일반 물건 한 개를 뜻하는 Piece와 판재의 표시를 구분해 적었다.

    여러 개를 한데 묶은 다발은 Bundle이고 나머지 셋은 짝지어진 영문이 다른 포장을 가리키므로, 정답은 3번이다.

    다음 대화에서 검수업무의 성격상 ( )에 적합하지 않은 단어는?

    A: What do we have to know when checking the cargoes? B: First, the checker should write the amount and abnormality of cargoes on the tally sheet ( ), ( ) and ( ). Second, the checker should be acquainted with the cargo mark.

    1. 1. rapidly
    2. 2. precisely
    3. 3. impartially
    4. 4. subjectively

    정답 4번

    🔍 보기별 해설
    1. Rapidly는 빠르게라는 뜻이다. 움직이는 화물의 수량을 제때 기록해야 하므로 옳다.

    3. 화물집화장(CFS)은 장소이고 화물적입목록(CLP)은 서류다. 둘 다 화물 유형의 명칭이 아니므로 옳지 않다.
    4. 화물집화장(CFS)은 소량 화물을 모아 다루는 장소다. 화물 유형을 나누는 첫 빈칸에 맞지 않으므로 옳지 않다.
    🧮 풀이
    1. 한 화주가 컨테이너를 가득 채운 선적 건을 검수사 甲이 맡았다. 甲은 봉인 번호와 적입 수량을 확인하고 FCL 화물로 기록했다. 도착지에서 봉인이 유지된 채 수하인에게 인도됐다.
    2. 여러 화주의 작은 상자를 검수사 甲이 화물집화장에서 나눴다. 甲은 각 화주의 포장 수량을 따로 적고 LCL 화물로 기록했다. 한 컨테이너의 화물이 여러 수하인에게 분리 인도됐다.
    3. 화물적입목록(CLP)을 받은 검수사 甲은 안의 상자 번호를 대조했다. 甲은 CLP가 화물 자체의 FCL·LCL 구분이 아닌 서류임을 반영했다. 화물 유형은 실제 적입 방식에 따라 별도로 기록했다.
    4. 화물집화장(CFS)에서 검수사 甲은 여러 화주의 상자를 적입했다. 甲은 작업 장소인 CFS와 화물 유형인 LCL을 다른 칸에 적었다. 장소 이름과 화물의 규모가 혼동되지 않았다.

    컨테이너 화물의 짝을 가르는 빈칸을 채우는 것인데 화주 수로 가르는 FCL과 LCL만 화물의 종류이므로, 정답은 1번이다.

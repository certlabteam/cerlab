    어선어업의 유류오염 손해의 유형으로 옳지 않은 것은?

    1. 1. 휴업 손해
    2. 2. 채묘망 손해
    3. 3. 어장전환 손해
    4. 4. 어획감소 손해

    정답 2번

    🔍 보기별 해설
    1. 어선이 오염 때문에 출항하지 못하면 휴업 손해가 생긴다. 어선어업 손해 유형이므로 옳다.
    2. 채묘망 손해는 종자를 붙이는 양식시설의 피해다. 어선어업 손해 유형이 아니므로 옳지 않다(정답).
    3. 오염된 어장을 피해 다른 곳으로 조업지를 옮기면 추가 비용이 든다. 어선어업 손해 유형이므로 옳다.
    4. 오염 뒤 어획량이 줄어 매출이 감소하면 어획감소 손해가 생긴다. 어선어업 손해 유형이므로 옳다.
    🧮 풀이
    1. 어선이 유막 때문에 항구를 떠나지 못한 날이 이어졌다. 선주는 평소 출항일과 사고 뒤 출항 중단일을 기록했다. 벌지 못한 수입을 휴업 손해로 계산할 자료를 모았다.
    2. 김 양식장에 설치한 채묘망에 기름이 묻었다. 양식업자는 종자가 붙은 그물을 교체하고 비용을 기록했다. 배를 타고 물고기를 잡는 어선의 조업 손해와 시설 피해를 구분했다.
    3. 평소 조업하던 해역에 기름이 퍼지자 어선이 먼 어장으로 이동했다. 연료비와 이동 시간이 더 들었다. 선주는 항로 기록과 유류 구입내역을 모아 어장전환 손해를 설명했다.
    4. 어선의 출항은 이어졌지만 사고 뒤 잡히는 물고기가 줄었다. 선주는 수협 위판량과 과거 같은 시기 실적을 비교했다. 줄어든 어획과 수입을 어획감소 손해로 제시했다.

    채묘망은 종자를 붙여 기르는 양식어업의 시설이다. 어선어업의 휴업·어장전환·어획감소 손해와 달라 2번이 정답이다.

    유류오염손해배상보장법상 유류오염손해의 범위에 해당하지 않는 것은?

    1. 1. 방제조치 비용
    2. 2. 방제조치로 인한 추가적 손실 또는 손해
    3. 3. 선박으로부터 유류가 유출 또는 배출되어 발생된 오염에 의하여 선박 외부에서 발생한 손실 또는 손해
    4. 4. 유류오염의 대비ㆍ대응을 위한 주민기금

    정답 4번

    🔍 보기별 해설
    1. 방제조치에 든 합리적인 비용은 유류오염손해 범위에 든다. 손해 항목에 해당하므로 옳다.
    2. 방제조치 때문에 추가로 생긴 손실도 손해 범위에 든다. 손해 항목에 해당하므로 옳다.
    3. 선박에서 나온 기름이 선박 밖에 일으킨 오염 피해는 법의 중심 손해다. 범위에 해당하므로 옳다.
    4. 대비·대응을 위한 주민기금은 실제 사고의 손실이나 방제비용 자체가 아니다. 손해 범위에 들지 않아 옳지 않다(정답).
    🧮 풀이
    1. 해안으로 기름이 밀려오자 방제팀이 오일펜스와 흡착재를 투입했다. 인건비와 장비 사용료를 작업 기록에 남겼다. 사고 확산을 막는 합리적 방제조치 비용으로 청구했다.
    2. 방제선이 유막을 막으려고 항구 일부를 통제했다. 통제로 추가 손실을 입은 사업자가 그 내용과 기간을 기록했다. 방제조치에서 직접 이어진 손해인지 자료로 확인했다.
    3. 유조선에서 기름이 흘러 어장과 해변을 오염시켰다. 선박 밖의 어업인과 상인이 입은 손실을 조사했다. 유출유와 외부 피해의 연결을 시료와 영업 자료로 입증했다.
    4. 주민회가 앞으로의 오염사고에 대비해 별도 기금을 만들자고 제안했다. 장래 대비 자금은 이번 유출사고로 이미 생긴 손실액이 아니었다. 보상 청구서는 실제 피해와 방제조치 비용을 따로 적었다.

    유류오염손해에는 오염 피해와 방제조치 비용·추가 손실이 포함된다. 장래 대비를 위한 주민기금은 사고 손해가 아니므로 4번이 정답이다.

    수산업법령상 신고어업에 해당하는 것은?

    1. 1. 정치망 어업
    2. 2. 마을 어업
    3. 3. 맨손 어업
    4. 4. 연안 어업

    정답 3번

    🔍 보기별 해설
    1. 정치망어업은 일정한 해역에 그물을 설치하는 면허어업이다. 신고어업이 아니므로 옳지 않다.
    2. 마을어업은 공동으로 일정 수역을 이용하는 면허어업이다. 신고어업이 아니므로 옳지 않다.
    3. 맨손어업은 손으로 수산동식물을 채취하는 신고어업이다. 법령의 분류에 맞으므로 옳다(정답).
    4. 연안어업은 연안에서 어선 등을 이용하는 허가어업이다. 신고어업이 아니므로 옳지 않다.
    🧮 풀이
    1. 정치망을 설치하려는 어업인이 그물을 둘 해역을 확인했다. 일정 수역을 사용하는 어업이라 면허 절차를 밟았다. 단순 신고만으로 같은 자리에 그물을 설치하지 않았다.
    2. 마을 주민들이 공동으로 어패류를 채취할 바다 구역을 정했다. 어촌계는 마을어업 면허를 확인하고 구역을 관리했다. 개인의 맨손어업 신고와 다른 권리 형태였다.
    3. 해변에서 손으로 조개를 캐려는 주민이 맨손어업 신고 절차를 확인했다. 신고를 마친 뒤 허용된 구역과 시기에 채취했다. 어선이나 고정 그물을 쓰는 어업과 구분했다.
    4. 연안 어선이 통발을 놓고 어획하려고 했다. 선주는 해당 연안어업의 허가를 받고 어구와 조업 구역을 확인했다. 맨손으로 채취하는 신고어업과 절차가 달랐다.

    맨손어업은 법령상 신고어업이다. 정치망·마을어업은 면허어업이고 연안어업은 허가어업이므로 3번이 정답이다.

    원유를 구성하는 탄화수소 중 나프텐(Naphthene)에 관한 설명으로 옳은 것은?

    1. 1. 원자의 구조는 사슬모양이다.
    2. 2. 일반식은 CnH2n+2 이다.
    3. 3. 물에 용해되지 않는다.
    4. 4. 상온에서 탄소원자가 2～4개 포함된 것은 고체이다.

    정답 3번

    🔍 보기별 해설
    1. 나프텐(Naphthene)은 원자가 고리를 이룬다. 사슬모양이라는 설명은 옳지 않다.
    2. CnH2n+2는 사슬형 포화 탄화수소인 알케인의 일반식이다. 나프텐(Naphthene)의 식이 아니므로 옳지 않다.
    3. 나프텐(Naphthene)은 물과 섞이지 않는 탄화수소다. 물에 용해되지 않는다는 설명이 옳다(정답).
    4. 탄소원자 2～4개의 탄화수소를 상온의 고체로 일률 분류할 수 없다. 나프텐(Naphthene)의 성질로 옳지 않다.
    🧮 풀이
    1. 원유 성분표에서 나프텐 분자를 확인한 연구자가 탄소 결합을 그렸다. 끝이 열린 사슬이 아니라 이어진 고리였다. 연구자는 사슬형 파라핀과 구조를 구분해 기록했다.
    2. 사슬형 포화 탄화수소의 분자식 CnH2n+2를 연구자가 적었다. 고리형 나프텐은 고리를 만들면서 수소 수가 달라졌다. 두 계열의 일반식을 같은 칸에 넣지 않았다.
    3. 나프텐 성분을 물이 든 시험관에 떨어뜨렸다. 흔들어도 한 층으로 녹아들지 않고 물과 분리됐다. 조사자는 유류 성분이 수중에 퍼지는 방식과 용해 여부를 나눠 확인했다.
    4. 가벼운 탄화수소를 상온에 둔 연구자가 기체나 액체로 존재하는 성분을 확인했다. 탄소가 2～4개라는 이유만으로 모두 고체라고 적을 수 없었다. 분자의 구조와 끓는점도 함께 살폈다.

    나프텐은 고리형 포화 탄화수소로 물에 녹지 않는다. 사슬 구조·알케인 일반식·저탄소 고체라는 설명은 틀려 3번이 정답이다.

    파라핀기 원유와 나프텐기 원유의 성상 비교로 옳지 않은 것은?

    1. 1. 비중은 파라핀기가 나프텐기보다 작다.
    2. 2. 휘발유 옥탄값은 파라핀기가 나프텐기보다 낮다.
    3. 3. 왁스 함량은 파라핀기가 나프텐기보다 비교적 많다.
    4. 4. 윤활유 점도 지수는 파라핀기가 나프텐기보다 낮다.

    정답 4번

    🔍 보기별 해설
    1. 파라핀기 원유는 나프텐기보다 비중이 대체로 작다. 성상 비교가 옳다.
    2. 파라핀기 원유에서 얻는 휘발유의 옥탄값은 나프텐기보다 낮은 편이다. 비교가 옳다.
    3. 파라핀기 원유는 왁스 함량이 상대적으로 많다. 비교가 옳다.
    4. 파라핀기 윤활유의 점도지수는 나프텐기보다 높은 편이다. 낮다고 한 비교는 옳지 않다(정답).
    🧮 풀이
    1. 두 원유 시료의 같은 부피를 저울에 올렸다. 파라핀기 원유 쪽 질량이 상대적으로 작아 비중 차이를 확인했다. 담당자는 온도를 맞춘 뒤 결과를 비교했다.
    2. 휘발유 성분을 비교한 연구자가 두 계열의 옥탄값을 확인했다. 파라핀기에서 얻은 휘발유의 값이 나프텐기보다 낮게 나타났다. 같은 측정 조건의 결과만 나란히 적었다.
    3. 파라핀기 원유를 냉각하자 왁스 성분이 드러났다. 저장 담당자는 침전과 유동성 변화를 확인했다. 나프텐기 원유보다 왁스가 많은 성질을 운송 조건에 반영했다.
    4. 두 계열의 윤활유를 온도를 바꿔 가며 시험했다. 파라핀기 윤활유의 점도 변화가 상대적으로 안정적이었다. 담당자는 점도지수가 더 높은 쪽을 파라핀기로 기록했다.

    파라핀기 원유의 윤활유는 나프텐기보다 점도지수가 높다. 낮다고 한 4번이 틀렸다.

    다음 중 비중이 가장 작은 것은?

    1. 1. 원유
    2. 2. 가솔린
    3. 3. 등유
    4. 4. 항공유

    정답 2번

    🔍 보기별 해설
    1. 원유는 여러 무거운 성분을 함께 포함한다. 보기 중 가솔린보다 비중이 작지 않아 옳지 않다.
    2. 가솔린은 제시된 연료 중 가벼운 성분이다. 비중이 가장 작으므로 옳다(정답).
    3. 등유는 가솔린보다 무거운 유분이다. 가장 작은 비중이 아니므로 옳지 않다.
    4. 항공유는 가솔린과 구분되는 연료 규격으로 이 보기에서 비중이 가장 작은 것은 아니다. 옳지 않다.
    🧮 풀이
    1. 원유 탱크에서 채취한 시료의 비중을 측정했다. 정제된 가솔린과 비교하자 원유에는 더 무거운 유분이 섞여 있었다. 담당자는 동일 온도에서 측정값을 기록했다.
    2. 가솔린과 다른 연료를 같은 부피로 담아 무게를 비교했다. 가솔린이 상대적으로 가벼워 비중계의 값도 가장 작았다. 저장 담당자는 작은 비중을 이용해 연료 종류를 확인했다.
    3. 등유 시료를 가솔린과 같은 조건에서 비중계로 쟀다. 등유가 더 무거운 범위에 있었다. 담당자는 두 연료의 저장탱크를 구분하고 혼입 여부를 살폈다.

    4. 연안 어선의 선주가 조업 전에 허가증을 확인했다. 사용할 어구와 조업 해역이 허가 내용에 맞는지 살폈다. 선박을 이용하는 허가어업의 절차를 따랐다.

    수산업법의 어업 구분에는 신고어업·면허어업·허가어업이 있다. 인증어업은 그 법정 종류가 아니므로 1번이 정답이다.

    비수산업분야 유류오염 피해발생 신고서 작성 시 피해자 주소란에 기재해야 하는 것은?

    1. 1. 주민등록상 주소
    2. 2. 실제 거주지 주소
    3. 3. 지사 소재지 주소
    4. 4. 사업장 소재지 주소

    정답 1번

    🔍 보기별 해설
    1. 피해자 주소란은 주민등록상 주소를 기준으로 한다. 기재할 주소로 옳다(정답).
    2. 실제 거주지는 주민등록상 주소와 다를 수 있다. 이 칸의 기재 기준이 아니므로 옳지 않다.
    3. 지사 소재지는 업체의 사업 거점이다. 피해자 본인의 주소란과 달라 옳지 않다.
    4. 사업장 소재지는 영업이 이루어지는 곳이다. 피해자 주소란의 주민등록상 주소와 달라 옳지 않다.
    🧮 풀이
    1. 피해자가 신고서의 주소란에 주민등록상 주소를 적었다. 영업장 주소는 피해 업소 정보에 따로 넣었다. 담당자가 신청인에게 연락할 공식 주소를 확인했다.
    2. 식당 주인이 일시적으로 다른 곳에 머물고 있었다. 신고서의 피해자 주소란에는 실제 숙소가 아니라 주민등록상 주소를 확인해 적었다. 연락처는 별도 칸에 최신 번호를 남겼다.
    3. 회사의 지사에서 피해가 발생해 담당자가 지사 소재지를 확인했다. 지사 위치는 피해 사업장 정보로 기록했다. 피해자 본인의 주소란에 지사 주소를 대신 적지 않았다.
    4. 해안 상점의 사업장 소재지가 주인의 주민등록상 주소와 달랐다. 신고서에는 두 위치를 각기 해당 칸에 적었다. 피해자 주소란에는 주민등록상 주소를 사용했다.

    비수산업 피해발생 신고서의 피해자 주소란에는 주민등록상 주소를 적는다. 따라서 1번이 정답이다.

    어선어업의 휴업손해 산정 시 소득률 계산에서 절약된 어업경비에 해당하지 않는 것은?

    1. 1. 연료비
    2. 2. 얼음비
    3. 3. 사료비
    4. 4. 조합비

    정답 4번

    🔍 보기별 해설
    1. 연료비는 어선이 출항하지 않으면 줄어드는 비용이다. 절약된 어업경비에 해당하므로 옳다.
    2. 얼음비는 어획물을 보관하지 않으면 줄어드는 비용이다. 절약된 어업경비에 해당하므로 옳다.
    3. 사료비는 해당 조업을 쉬며 지출하지 않은 경우 절약경비로 계산한다. 보기의 절약 항목이므로 옳다.
    4. 조합비는 조업 중단과 무관하게 부담할 수 있다. 절약된 어업경비가 아니므로 옳지 않다(정답).
    🧮 풀이
    1. 유류오염 때문에 어선이 한 달간 출항하지 못했다. 선주는 그 기간 사지 않은 연료의 양과 가격을 계산했다. 실제 지출하지 않은 연료비는 휴업손해 계산에서 절약경비로 뺐다.
    2. 어획물을 싣지 못한 어선이 얼음을 주문하지 않았다. 선주는 평소 출항 때의 얼음 구매액을 장부로 확인했다. 휴업 기간에 쓰지 않은 얼음비를 절약된 경비로 처리했다.
    3. 해당 조업에서 사용하던 사료를 휴업 기간에는 사지 않았다. 담당자는 실제로 지출하지 않은 금액만 확인해 절약경비에 넣었다. 계속 낸 비용까지 일괄 절약했다고 적지 않았다.
    4. 어선이 출항하지 못했지만 조합비 납부 고지서는 그대로 나왔다. 선주가 납부 영수증을 보관해 실제 지출을 증명했다. 조업 중단으로 아낀 연료비와 달리 조합비를 절약경비로 빼지 않았다.

    조합비는 조업을 쉬는 동안에도 부담하는 비용이어서 절약경비가 아니다. 연료비·얼음비·사료비와 구분해 4번이 정답이다.

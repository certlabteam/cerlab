    〈보기〉에서 손상평가에 대한 특수검사(special test)로 옳은 것만을 모두 고른 것은? ㄱ. 바깥돌림(Kleiger) 검사 – 발목 삼각인대 손상 평가 ㄴ. 슬로컴(Slocum) 검사 – 엉덩정강띠의 긴장 평가 ㄷ. 오버(Ober) 검사 – 무릎 불안정성 평가 ㄹ. 팔신경얼기(brachial plexus) 검사 – 목 신경뿌리(cervical nerve root) 평가

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄷ, ㄹ

    정답 2번

    🔍 보기별 해설
    1. ㄱ. 바깥돌림(Kleiger) 검사는 발을 바깥으로 돌려 발목 안쪽 삼각인대·경비인대결합 손상을 평가한다. 옳다.
    2. ㄴ. 슬로컴(Slocum) 검사는 무릎의 회전 불안정성을 평가하는 검사이지 엉덩정강띠 긴장을 보는 검사가 아니다. 옳지 않다.
    3. ㄷ. 오버(Ober) 검사는 엉덩정강띠(장경인대)의 긴장·단축을 평가하는 검사이지 무릎 불안정성을 보는 검사가 아니다. 옳지 않다.
    4. 팔신경얼기(상완신경총) 검사는 목에서 나온 신경뿌리(경추 신경근)의 손상이나 압박 여부를 평가하는 검사이므로 목 신경뿌리 손상 평가라는 설명은 맞다. 옳다.
    🧮 풀이
    1. 발목 안쪽 통증을 호소하는 선수가 있다. 검사자가 발목을 바깥쪽으로 돌려 삼각인대 부위의 통증과 벌어짐을 살핀다. 바깥돌림 검사로 안쪽 인대 손상을 평가한다는 연결이다.
    2. 무릎이 흔들리는 선수를 평가하려는 검사자가 슬로컴 검사를 시행한다. 이 검사는 무릎 앞가쪽 또는 앞안쪽 회전 불안정성을 살핀다. 엉덩정강띠의 긴장을 보는 오버 검사와 역할이 다르다.
    3. 넙다리 가쪽이 당기는 선수가 옆으로 누워 다리를 내려 본다. 검사자는 오버 검사로 엉덩정강띠의 긴장을 살핀다. 이 검사 결과를 무릎 인대의 불안정성 판정으로 옮기면 검사 목적이 바뀐다.
    4. 목에서 팔로 저림이 내려오는 선수가 있다. 검사자가 팔신경얼기에 긴장을 주어 증상의 재현과 신경 자극을 살핀다. 목 신경뿌리와 관련된 증상을 평가하는 데 이 검사를 사용할 수 있다.

    정답은 2번이다.

    〈보기〉의 설명에 해당되는 손상은? · 섬유화(fibrosis)와 흉터(scarring)가 원인이다. · 장딴지근(gastrocnemius)과 가자미근(soleus)의 유연성 감소가 증상을 증가시킬 수 있다. · 러닝 또는 점핑과 같은 반복적인 움직임 동안의 과도한 인장응력(tensile stress) 때문에 과부하에 의해 나타난다.

    1. 1. 아킬레스 힘줄병증(Achilles tendinopathy)
    2. 2. 급성 구획증후군(acute compartment syndrome)
    3. 3. 만성 발목 불안정(chronic ankle instability)
    4. 4. 발목굴 증후군(tarsal tunnel syndrome)

    정답 1번

    🔍 보기별 해설
    1. 아킬레스 힘줄병증은 반복적 인장응력·과부하로 힘줄이 변성(섬유화·흉터)되고, 종아리근 유연성 감소로 증상이 악화된다. 설명과 일치한다. 옳다(정답).
    2. 급성 구획증후군은 외상 후 부종·출혈로 근막 구획 내 압력이 급격히 올라 혈류가 막히는 응급 상태로, 반복적 인장응력에 의한 만성 섬유화·흉터 손상을 설명한 〈보기〉와 부합하지 않는다. 옳지 않다.
    3. 만성 발목 불안정은 반복 염좌 후 발목이 자주 접질리는 상태로, 힘줄 섬유화·인장 과부하 설명과 다르다. 옳지 않다.
    4. 발목굴 증후군은 발목 안쪽 터널에서 경골신경이 눌려 발바닥 저림·통증이 생기는 신경 압박 질환으로, 장딴지 근육의 반복적 인장응력에 의한 손상을 설명한 〈보기〉와 부합하지 않는다. 옳지 않다.
    🧮 풀이
    1. 달리기 훈련을 늘린 선수가 뒤꿈치 위쪽 힘줄에 통증을 느낀다. 장딴지근과 가자미근이 뻣뻣해 발목 움직임 때 아킬레스힘줄의 당김이 커질 수 있다. 반복 부하와 힘줄 조직 변화가 함께 나타나는 힘줄병증을 의심한다.
    2. 운동 중 종아리가 갑자기 심하게 아프고 부어오르며 감각도 변한 선수가 있다. 급성 구획증후군은 닫힌 공간의 압력이 올라 혈류와 신경을 위협하는 응급 문제다. 오래 반복된 힘줄의 섬유화와 흉터 설명과는 발병 양상이 다르다.
    3. 발목을 여러 번 접질린 선수가 평지에서도 발목이 다시 꺾일 듯 불안하다고 말한다. 검사자는 인대와 감각운동 조절의 문제를 살핀다. 뒤꿈치 힘줄에 반복 인장으로 생긴 국소 통증을 설명하는 사례와 구분한다.
    4. 발목 안쪽을 지나는 신경이 눌린 환자가 발바닥 저림을 호소한다. 발목굴 증후군은 신경 압박과 관련된 감각 증상을 살핀다. 장딴지근 유연성 감소와 반복 점프의 힘줄 과부하를 중심으로 설명한 보기와 다르다.

    달리기와 점프의 반복 인장부하로 아킬레스힘줄에 흉터와 섬유화가 생긴 상황이다. 해당 손상인 ①이 맞는다.

    〈보기〉에서 발목관절의 인대 손상 검사방법에 해당하는 것을 모두 고른 것은? ㄱ. 톰슨(Thompson) 검사 ㄴ. 윈들라스(windlass) 검사 ㄷ. 앞당김(anterior drawer) 검사 ㄹ. 목말뼈 경사(talar tilt) 검사

    1. 1. ㄱ, ㄴ
    2. 2. ㄴ, ㄷ
    3. 3. ㄴ, ㄹ
    4. 4. ㄷ, ㄹ

    정답 4번

    🔍 보기별 해설
    1. ㄱ. 톰슨 검사는 종아리를 쥐어 발 움직임을 보는 아킬레스건 파열 검사로, 인대 손상 검사가 아니다. 옳지 않다.
    2. ㄴ. 윈들라스 검사는 발가락을 젖혀 족저근막 통증을 보는 족저근막염 검사로, 발목 인대 검사가 아니다. 옳지 않다.
    3. 앞당김(anterior drawer) 검사는 발뒤꿈치를 앞으로 당겨 목말뼈의 전방 이동 정도로 발목 바깥쪽 전거비인대의 손상을 평가하는 인대 손상 검사이므로 맞다. 옳다.
    4. ㄹ. 목말뼈 경사(talar tilt) 검사는 발목을 안쪽으로 젖혀 종비인대 등 외측 인대 손상을 평가한다. 옳다.
    🧮 풀이
    1. 선수가 뒤꿈치 위쪽을 다친 뒤 엎드려 누운 상태에서 검사자가 종아리를 짠다. 발이 정상적으로 아래로 움직이는지 보는 톰슨 검사는 아킬레스힘줄 파열을 살핀다. 발목 인대의 느슨함을 직접 평가하는 검사는 아니다.
    2. 발바닥 통증을 호소하는 선수가 있다. 검사자가 엄지발가락을 위로 젖혀 발바닥근막의 긴장과 통증을 살핀다. 윈들라스 검사는 발바닥근막과 관계되므로 발목 인대 검사 목록에 넣지 않는다.
    3. 발목을 접질린 선수가 검사대에 앉는다. 검사자가 정강뼈를 고정하고 발목뼈를 앞쪽으로 당겨 벌어짐을 본다. 앞당김 검사는 발목 앞쪽 인대의 손상을 평가할 때 사용한다.
    4. 발목 바깥쪽 통증이 남은 선수를 검사자가 평가한다. 발목뼈를 기울여 좌우 인대의 느슨함과 통증을 비교한다. 목말뼈 경사 검사는 발목 인대 손상을 살피는 특수검사다.

    정답은 4번이다.

    〈보기〉에서 제시된 조직부하(tissue loading) 유형이 동일한 것만을 모두 고른 것은? ㄱ. 발등굽힘에 의한 아킬레스힘줄 손상 발생 ㄴ. 피부에서 포진, 찰과상 발생 ㄷ. 넙다리곧은근의 과신장(overstretching) 손상 발생 ㄹ. 반복적인 점프 동작에 의한 척추 디스크 손상 발생

    1. 1. ㄱ, ㄷ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄴ, ㄹ

    정답 1번

    🔍 보기별 해설
    1. ㄱ. 발등굽힘으로 아킬레스힘줄이 늘어나며 손상되는 것은 조직을 잡아당기는 '인장(tension)' 부하다. 정답 조합에 해당한다. 옳다.
    2. ㄴ. 피부의 포진·찰과상은 표면이 스치며 생기는 '전단·마찰(shear)' 부하로, 인장과 다른 유형이다. 옳지 않다.
    3. ㄷ. 넙다리곧은근의 과신장 손상도 근육을 잡아당기는 '인장(tension)' 부하다. ㄱ과 같은 유형으로 정답에 해당한다. 옳다.
    4. ㄹ. 반복 점프로 인한 척추 디스크 손상은 위에서 눌리는 '압박(compression)' 부하로, 인장과 다른 유형이다. 옳지 않다.
    🧮 풀이
    1. 선수가 발목을 과하게 발등 쪽으로 젖히면 뒤쪽 아킬레스힘줄이 길게 당겨진다. 늘어나는 방향의 힘이 힘줄에 작용한다. 담당자는 이 손상을 인장 부하와 연결해 본다.
    2. 넘어지며 피부가 바닥에 쓸린 선수에게 찰과상이 생긴다. 표면이 서로 문질러지며 조직이 벗겨지는 마찰 또는 전단 부하가 중심이다. 힘줄이 길어지면서 당겨지는 인장 손상과 유형이 다르다.
    3. 전력질주 중 선수가 넙다리 앞쪽 근육을 과하게 늘린다. 넙다리곧은근의 근육 섬유가 당겨지는 방향으로 힘을 받는다. 발등굽힘으로 아킬레스힘줄이 늘어나는 사례와 같은 인장 부하다.
    4. 반복 점프 뒤 착지할 때마다 척추 디스크에 하중이 실린다. 디스크는 축 방향의 압박을 반복해 받는다. 피부 마찰이나 근육의 과신장과는 힘이 가해지는 방향과 조직 반응이 다르다.

    정답은 1번이다.

    〈보기〉에서 운동 손상의 평가를 위한 하지의 구획과 해당하는 근육이 바르게 연결된 것은? ㉠ 앞쪽 구획 ㉡ 가쪽 구획 ㉢ 뒤쪽 얕은 구획 ㉣ 뒤쪽 깊은 구획 Ⓐ 긴엄지굽힘근(flexor hallucis longus) Ⓑ 긴발가락폄근(extensor digitorum longus) Ⓒ 짧은종아리근(peroneus brevis) Ⓓ 가자미근(soleus)

    1. 1. ㉠-Ⓐ, ㉡-Ⓑ, ㉢-Ⓒ, ㉣-Ⓓ
    2. 2. ㉠-Ⓑ, ㉡-Ⓒ, ㉢-Ⓓ, ㉣-Ⓐ
    3. 3. ㉠-Ⓑ, ㉡-Ⓐ, ㉢-Ⓒ, ㉣-Ⓓ
    4. 4. ㉠-Ⓒ, ㉡-Ⓐ, ㉢-Ⓓ, ㉣-Ⓑ

    정답 2번

    🔍 보기별 해설
    1. ㉠ 앞쪽 구획–Ⓑ 긴발가락폄근. ㉡ 가쪽 구획–Ⓒ 짧은종아리근. ㉢ 뒤쪽 얕은 구획–Ⓓ 가자미근. ㉣ 뒤쪽 깊은 구획–Ⓐ 긴엄지굽힘근. 따라서 옳다.

    앞쪽 구획은 긴발가락폄근, 가쪽은 짧은종아리근, 뒤쪽 얕은 곳은 가자미근, 깊은 곳은 긴엄지굽힘근이다. 순서가 맞는 ②가 정답이다.

    〈보기〉에서 신경학적 검사 중 깊은 힘줄 반사(deep tendon reflex)의 평가에 대한 설명으로 옳은 것만을 모두 고른 것은? ㄱ. 평가 결과는 1-5까지 다섯 등급이다. ㄴ. 신경 뿌리 수준(nerve root level) L2는 평가할 수 없다. ㄷ. 정상등급은 2등급이다. ㄹ. 신경 뿌리 수준 C5는 근육피부신경(musculocutaneous)을 평가한다.

    1. 1. ㄱ, ㄴ
    2. 2. ㄴ, ㄷ
    3. 3. ㄴ, ㄹ
    4. 4. ㄷ, ㄹ

    정답 4번

    🔍 보기별 해설
    1. ㄱ. 깊은 힘줄 반사 등급은 0∼4의 다섯 단계(0,1,2,3,4)로 매긴다. '1-5'는 틀리다. 옳지 않다.
    2. L2 신경뿌리는 무릎을 펴는 넙다리네갈래근 등의 반사·근력으로 평가할 수 있으므로 'L2는 평가할 수 없다'는 설명은 사실과 달라 맞지 않는다. 옳지 않다.
    3. ㄷ. 깊은 힘줄 반사 등급은 0에서 4까지 매기며, 그 가운데 반응이 정상적으로 나오는 중간 단계가 2등급이다. 옳다.
    4. C5 신경뿌리는 근육피부신경이 지배하는 위팔두갈래근의 힘줄반사(이두근반사)로 평가하므로 C5를 위팔두갈래근 반사로 검사한다는 설명은 맞다. 옳다.
    🧮 풀이
    1. 검사자가 무릎뼈 힘줄을 두드린 뒤 다리가 얼마나 반응하는지 관찰한다. 깊은 힘줄 반사는 0에서 4+까지의 등급으로 기록하는 방식이 널리 쓰인다. 1부터 5까지의 다섯 등급이라고 적으면 기준 숫자가 달라진다.
    2. 허리 신경뿌리 상태를 평가하려는 담당자가 깊은 힘줄 반사만으로 L2를 분리해 확인하려 한다. 표준 반사 검사는 여러 신경근 수준이 겹쳐 한 신경근을 독립적으로 구분하기 어렵다. L2만의 반사를 정확히 지정할 수 있다는 식으로 다루지 않는다.
    3. 검사자가 팔꿈치나 무릎의 힘줄을 두드리자 적절한 크기의 반응이 나타난다. 등급표에서 이 일반적인 반응을 2로 기록한다. 반사가 없을 때와 과도하게 항진될 때를 구별하기 위한 기준점이다.
    4. 팔꿈치 앞쪽 위팔두갈래근 힘줄을 두드리자 팔이 반응한다. 근육피부신경과 C5 신경근이 이 반사 회로에 관여한다. 검사자는 좌우 차이와 반응 크기를 비교해 신경학적 상태를 살핀다.

    정답은 4번이다.

    신경근 수준(nerve root level)에 대한 운동검사(motor testing)로 옳은 것은?

    1. 1. C2 – 팔꿈치 관절 굽힘과 손목 폄(elbow flexion and wrist extension)
    2. 2. C3 – 어깨 벌림(shoulder abduction)
    3. 3. C4 – 어깨 올림(shoulder shrug)
    4. 4. C5 – 목 가쪽굽힘(neck lateral flexion)

    정답 3번

    🔍 보기별 해설
    1. 팔꿈치 굽힘은 C5~C6, 손목 폄은 C6 수준이 담당하므로 이를 상위 경추인 C2와 짝지은 것은 실제 신경근 지배와 맞지 않는다. 옳지 않다.
    2. 어깨 벌림(삼각근)은 C5 신경근이 담당하는 동작이므로 이를 C3와 짝지은 것은 실제 신경근 지배 수준과 맞지 않는다. 옳지 않다.
    3. 어깨 올림(shoulder shrug)은 등세모근(승모근) 동작으로 C3~C4 신경근 수준에서 검사하므로 C4와 짝지은 것은 실제 신경근 지배와 맞다. 옳다(정답).
    4. 목 가쪽굽힘은 상위 경추(C3 등) 신경근이 담당하는 동작이므로 이를 C5와 짝지은 것은 실제 신경근 지배 수준과 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 팔꿈치를 굽히고 손목을 펴는 힘을 검사자가 확인한다. 이 동작들은 목의 높은 C2 신경근만으로 설명되지 않는다. 참가자의 목 움직임과 팔 동작을 구분해 해당 신경근 수준을 평가한다.
    2. 어깨를 옆으로 들어 올리는 참가자의 근력을 검사한다. 담당자는 어깨세모근과 C5 신경근을 중심으로 판단한다. C3의 대표 운동검사로 어깨 벌림을 배정하면 신경근과 동작이 맞지 않는다.
    3. 검사자가 참가자에게 양쪽 어깨를 귀 쪽으로 들어 올리게 한다. 어깨를 으쓱하는 동작의 힘을 저항에 대고 확인한다. 이 동작은 C4 신경근 수준 평가에 연결된다.
    4. 참가자가 목을 옆으로 기울인다. 이 움직임은 C5 신경근의 대표 운동검사로 적힌 어깨 근육 동작과 다르다. 담당자는 목 가쪽굽힘과 C5 수준의 어깨 벌림을 서로 구별해 기록한다.

    C4 신경근 수준의 운동검사는 어깨를 으쓱하는 동작으로 살핀다. C2·C3·C5에 다른 동작을 붙인 보기와 달리 ③이 맞는다.

    도수근력검사(manual muscle test)의 근력등급에 대한 설명으로 옳지 않은 것은?

    1. 1. 0등급: 자발적인 근수축이 일어나지 않음
    2. 2. 1등급: 도수 저항과 중력이 제거된 상태에서 모든 운동범위에서 움직임 가능
    3. 3. 3등급: 도수 저항이 없는 상태에서 중력에 대항하여 모든 운동범위에서 움직임 가능
    4. 4. 5등급: 중력에 대항하여 모든 운동범위에서 움직임이 가능하며 최대 도수 저항에 대항하여 움직임 가능

    정답 2번

    🔍 보기별 해설
    1. 0등급은 근육을 아무리 쓰려 해도 수축 자체가 전혀 감지되지 않는 완전 마비 상태로, 근력 척도의 맨 아래 등급이다. 옳다.
    2. 1등급은 근수축은 감지되지만 움직임은 일어나지 않는 상태다. '중력 제거 상태에서 전 범위 움직임 가능'은 2등급 설명이다. 옳지 않다(정답).
    3. 3등급은 저항 없이 중력에 대항해 전 범위를 움직이는 상태로, 중력을 이겨 낼 힘은 있으나 검사자의 도수 저항까지 이겨 내지는 못해 4·5등급과 구별된다. 옳다.
    4. 도수근력검사 5등급(정상)은 중력과 검사자의 최대 도수 저항 모두에 대항해 전 관절가동범위를 움직일 수 있는 상태를 뜻하므로 제시된 설명은 정확하다. 옳다.
    🧮 풀이
    1. 검사자가 참가자에게 발목을 움직여 보라고 하고 근육을 만져 본다. 눈에 보이거나 손에 느껴지는 자발 수축이 전혀 없다. 이 상태를 도수근력 0등급으로 기록한다.
    2. 참가자가 중력이 작용하지 않도록 옆으로 누운 뒤 팔을 전 범위로 움직인다. 검사자는 중력을 제거했을 때 움직임이 가능하므로 2등급으로 기록한다. 근수축만 느껴지고 관절 움직임은 없는 1등급과 다르다.
    3. 참가자가 팔을 들어 중력에 맞서 전 범위를 움직이지만 검사자의 추가 저항에는 버티지 못한다. 담당자는 도수 저항을 주지 않은 상태의 수행을 확인한다. 전 범위의 항중력 움직임은 3등급과 연결된다.
    4. 참가자가 팔을 중력에 맞서 끝까지 올리고 검사자가 강한 도수 저항을 줘도 자세를 유지한다. 담당자는 최대 저항까지 견디는 정상 수준을 확인한다. 이 수행은 도수근력 5등급이다.

    중력을 제거하고 전 운동범위를 움직이는 상태는 도수근력 2등급이다. 이를 1등급이라고 한 ②가 옳지 않다.

    〈보기〉의 설명에 해당되는 것은? · 표피의 감각 과민 부분이 발생한다. · 손상의 정도에 따라 불규칙적으로 증가하게 된다. · 반사성 교감신경 이영양증(reflex sympathetic dystrophy)이라고도 한다. · 자율신경 및 염증 변화를 나타내는 징후가 있으며, 다른 만성 통증 상태와 구별된다.

    1. 1. 배안신경얼기 타격(blow to the solar plexus)
    2. 2. 칸디다증(candidiasis)
    3. 3. 가이온굴에서 자신경 압박(ulnar nerve compression in the tunnel of Guyon)
    4. 4. 복합 부위 통증 증후군(complex regional pain syndrome)

    🔍 보기별 해설

    3. 가이온굴 자신경 압박은 손목 안쪽에서 자신경이 눌려 넷째·다섯째 손가락 저림이 생기는 것으로, 설명과 다르다. 옳지 않다.
    4. 복합 부위 통증 증후군(CRPS)은 반사성 교감신경 이영양증이라고도 하며, 자율신경·염증 변화와 감각 과민을 동반하는 만성 통증 상태다. 설명과 일치한다. 옳다(정답).

    3. 손목의 가이온굴에서 자신경이 눌린 환자가 새끼손가락 쪽 저림과 손 근력 저하를 겪는다. 검사자는 신경이 지나는 부위를 평가한다. 특정 신경 분포의 압박 증상과 광범위한 자율신경 변화가 동반된 통증 상태를 구분한다.
    4. 손상 이후 환자의 손에 가벼운 접촉만으로도 심한 통증이 생기고 피부색과 땀이 달라진다. 담당자는 손상 정도에 비해 큰 통증과 감각과민, 자율신경 변화를 함께 평가한다. 이런 양상은 복합 부위 통증 증후군과 연결된다.

    3. 성장판 손상이 뼈 끝의 관절면 쪽 골단으로 뻗은 영상을 본다. 담당자는 관절면을 포함하는 골절선을 확인해 3형을 생각한다. 성장판의 단순 분리와는 손상된 뼈 구역이 다르다.

    3. 반달세모뼈 부구(lunotriquetral ballotement) 검사는 반달세모관절의 불안정성을 보는 검사이고 노동맥·자동맥 혈류는 알렌 검사로 확인하므로 이 둘을 짝지은 것은 맞지 않는다. 옳지 않다.
    4. 왓슨(scaphoid shift) 검사는 손배뼈-반달뼈(scapholunate) 사이 불안정성을 평가하는 검사다. 짝이 맞다. 옳다(정답).
    🧮 풀이
    1. 손목의 반달뼈와 세모뼈 사이가 불안한 환자가 있다. 담당자는 두 뼈 사이의 움직임을 직접 살피는 검사를 고려한다. 엄지 쪽 힘줄 통증을 유발하는 핀켈스타인 검사를 이 관절의 불안정 검사로 쓰지 않는다.
    2. 엄지 쪽 손목에 통증이 있는 환자가 엄지를 쥐고 손목을 새끼손가락 쪽으로 움직인다. 핀켈스타인 검사에서 통증이 재현되면 드쿼베인 힘줄 문제를 살핀다. 손의 혈류를 보는 알렌 검사와 목적이 다르다.
    3. 손으로 가는 노동맥과 자동맥의 혈류를 확인하려는 검사자가 두 동맥을 누른 뒤 손바닥 색이 돌아오는지 본다. 이때 쓰는 검사는 알렌 검사다. 반달뼈와 세모뼈 사이를 흔드는 부구 검사는 뼈 사이 불안정성을 본다.
    4. 손목을 짚고 넘어간 환자가 손배뼈와 반달뼈 사이에서 통증과 불안함을 느낀다. 검사자가 손배뼈에 압력을 주고 손목을 움직이며 불안정 반응을 살핀다. 이 관절의 상태를 평가하는 왓슨 검사가 연결된다.

    왓슨 검사는 손배뼈와 반달뼈 사이의 불안정을 평가한다. 손상과 검사가 맞게 연결된 ④가 옳다.

    경기장에서는 먼저 생명을 위협하는 문제를 확인하고 안정화한다. 의식과 관계없이 이차 검사를 반드시 한다는 ③이 옳지 않다.

    뒤십자인대(후방십자인대, posterior cruciate ligament)의 안정성을 확인하기 위한 검사는?

    1. 1. 갓프레이(Godfrey) 검사
    2. 2. 라크만 드로워(Lachman drawer) 검사
    3. 3. 절크(jerk) 검사
    4. 4. 맥머레이(Mcmurray) 검사

    정답 1번

    🔍 보기별 해설
    1. 갓프레이 검사는 무릎·엉덩이를 굽힌 자세에서 정강뼈가 뒤로 처지는지(sag) 보아 뒤십자인대(PCL) 손상을 확인한다. 옳다(정답).
    2. 라크만 검사는 정강뼈를 앞으로 당겨 앞십자인대(ACL)의 이완을 보는 검사라, 정강뼈가 뒤로 처지는지 살피는 뒤십자인대 검사와는 목적이 반대다. 옳지 않다.
    3. 절크(jerk) 검사는 무릎의 회전 불안정성(주로 앞십자인대 관련 전외측 불안정성)을 평가하는 검사이므로 뒤십자인대의 안정성을 확인하는 검사로는 맞지 않는다. 옳지 않다.

    🧮 풀이
    1. 선수가 등을 대고 누워 엉덩이와 무릎을 굽힌다. 검사자는 정강뼈 윗부분이 중력에 따라 뒤쪽으로 처지는지 좌우를 비교한다. 뒤십자인대 손상에서 나타나는 뒤처짐을 확인하는 갓프레이 검사다.
    2. 무릎 앞쪽 불안정을 의심하는 검사자가 정강뼈를 앞쪽으로 당겨 본다. 라크만 검사는 앞십자인대의 안정성을 주로 평가한다. 뒤쪽으로 처지는 정강뼈를 보는 갓프레이 검사와 힘의 방향이 다르다.
    3. 무릎을 움직일 때 관절이 갑자기 걸리거나 회전 불안정 반응이 나타나는 선수가 있다. 절크 검사는 회전성 불안정성을 살피는 데 쓰인다. 뒤십자인대의 뒤처짐을 확인하는 검사와 평가 목적을 구분한다.
    4. 선수가 무릎 관절선 통증과 잠김을 호소한다. 검사자가 무릎을 굽혀 돌리며 통증이나 딸깍거림을 살핀다. 맥머레이 검사는 반달연골 손상 평가와 연결되므로 뒤십자인대 안정성 검사는 아니다.

    갓프레이 검사는 무릎을 굽힌 자세에서 정강뼈가 뒤쪽으로 처지는지 본다. 뒤십자인대 안정성과 연결되는 ①이 맞는다.

    1. 축구 중 강한 힘이 힘줄에 걸려 붙어 있던 뼈 조각이 떨어진 아이가 있다. 찢김골절은 당기는 힘에 의한 골절이다. 혈액 공급 중단으로 넙다리뼈머리가 서서히 괴사하는 병과는 기전이 다르다.
    2. 다리 정맥의 피가 잘 돌아오지 않아 부종과 불편함을 호소하는 환자가 있다. 검사자는 정맥 순환 문제를 평가한다. 넙다리뼈머리의 혈류가 끊겨 뼈 조직이 손상되는 소아 질환과는 위치와 혈관 문제가 다르다.
    3. 허벅지를 세게 부딪친 뒤 근육 속에 단단한 덩이가 생긴 선수가 있다. 검사자는 손상 근육 안에 비정상적 뼈 조직이 형성되는 뼈되기근육염을 살핀다. 엉덩관절 뼈머리 자체가 괴사하는 사례와 구별한다.
    4. 어린 남아가 샅과 무릎의 통증을 호소하며 절뚝거린다. 영상에서 넙다리뼈머리의 혈류 장애와 뼈 변화가 확인된다. 검사자는 엉덩관절의 벌림과 돌림 범위도 확인하며 레그-칼베-페르테스병을 의심한다.

    어린 남아의 넙다리뼈머리 혈액 공급이 끊겨 괴사하고 절뚝거림이 나타나는 병은 레그-칼베-페르테스병이다. ④가 맞는다.

    위팔두갈래근 파열(biceps brachii rupture)에 관한 설명으로 옳지 않은 것은?

    1. 1. 팔꿈치관절을 굽히고 아래팔을 엎침(pronation)하는 동작을 어려워한다.
    2. 2. 어깨 또는 팔꿈치관절(elbow joint)에서 “딱” 하는 소리와 함께 통증을 호소한다.
    3. 3. 파열은 주로 위팔두갈래근 긴갈래(long head)의 몸쪽(proximal) 부분에서 유발된다.
    4. 4. 과도한 단축성(concentric), 신장성(eccentric) 수축을 사용하는 사람들에게 발생할 수 있다.

    정답 1번

    🔍 보기별 해설
    1. 위팔두갈래근은 팔꿈치 굽힘과 아래팔 '뒤침(supination)'을 담당한다. 따라서 파열 시 어려워지는 동작은 '엎침'이 아니라 '뒤침+굽힘'이다. '엎침을 어려워한다'는 틀리다. 옳지 않다(정답).
    2. 위팔두갈래근 파열은 힘줄이 갑자기 끊어지면서 어깨(긴갈래) 또는 팔꿈치(먼쪽)에서 '딱' 하는 파열음과 함께 급격한 통증을 호소하게 되므로, 설명이 맞다. 옳다.
    3. 파열은 어깨 앞쪽을 지나는 긴갈래(long head) 힘줄의 몸쪽 부위에서 가장 흔히 생기는데, 이 부위가 마찰과 부하를 크게 받기 때문이다. 옳다.
    4. 무거운 무게로 단축성·신장성 수축을 과도하게 반복하면 힘줄에 피로가 쌓여, 역도나 보디빌딩을 하는 사람에게 파열이 생길 수 있다. 옳다.
    🧮 풀이
    1. 무거운 물체를 들다 위팔두갈래근 힘줄을 다친 환자가 팔꿈치 굽힘과 손바닥을 위로 돌리는 뒤침에 약해진다. 검사자는 엎침과 뒤침을 각각 시켜 본다. 엎침을 주된 손상 기능으로 적으면 근육의 작용 방향을 바꾼 것이다.
    2. 짐을 들어 올리던 선수가 어깨 앞쪽에서 갑자기 딱 하는 느낌과 통증을 겪는다. 힘줄 파열에서는 소리와 함께 급성 통증이 생길 수 있다. 담당자는 손상 위치가 몸쪽인지 먼쪽인지도 살핀다.
    3. 나이가 든 선수가 어깨 앞쪽 긴갈래힘줄 부위에 반복 통증을 느끼다 갑자기 파열을 겪는다. 몸쪽 긴갈래는 반복 마찰과 퇴행 변화가 쌓일 수 있다. 검사자는 이 부위를 흔한 파열 위치로 확인한다.
    4. 운동 선수가 무거운 역기를 올리고 내리며 힘줄에 큰 부하를 반복한다. 근육이 짧아지며 힘을 내는 때와 늘어나며 버티는 때 모두 조직에 부담이 간다. 과도한 수축 부하는 파열 위험과 관련된다.

    위팔두갈래근은 팔꿈치 굽힘과 아래팔 뒤침에 기여한다. 파열 때 엎침이 어렵다고 한 ①이 옳지 않다.

    PNF 동작 중 상지의 D1 폄(extension) 패턴에 관한 움직임이 바르게 연결된 것은? (아래팔 / 손목 / 손가락)

    1. 1. 엎침 / 자쪽치우침 / 굽힘
    2. 2. 엎침 / 자쪽치우침 / 폄
    3. 3. 뒤침 / 노쪽치우침 / 굽힘
    4. 4. 뒤침 / 노쪽치우침 / 폄

    정답 2번

    🔍 보기별 해설
    1. 아래팔: 엎침. 손목: 자쪽치우침. 손가락: 폄. 세 움직임이 상지 D1 폄 패턴과 일치하므로 옳다.

    신경근 수준(nerve root level)에 관한 상지 신경학적 검사(운동검사·반사검사)가 바르게 연결된 것은? (그림 참고)

    1. 1. C4 – 정중(median)신경 / 근육피부(musculocutaneous)신경
    2. 2. C5 – 등쪽어깨(dorsal scapular)신경 / 없음
    3. 3. C7 – 노(radial)신경 / 노신경
    4. 4. C8 – 겨드랑(axillary)신경 / 근육피부신경

    정답 3번

    🔍 보기별 해설
    1. C4는 상지에 뚜렷한 대표 운동검사 근육이 없고 주로 어깨 위쪽 감각을 담당하며, 정중신경은 C6~T1에서 나오므로 C4와 정중·근육피부신경을 연결한 것은 맞지 않는다. 옳지 않다.
    2. C5의 운동검사는 겨드랑신경(어깨 벌림)·근육피부신경(팔꿈치 굽힘)이며 반사는 위팔두갈래근 반사가 있다. '등쪽어깨신경/없음'은 맞지 않는다. 옳지 않다.
    3. C7은 팔꿈치·손목을 펴는 노(radial)신경 지배 근육으로 운동검사를 하고, 반사검사도 노신경이 지배하는 위팔세갈래근 반사로 확인하므로 신경 연결이 옳다. 옳다(정답).
    4. C8은 주로 손가락 굽힘 근육의 운동검사로 평가하며, 겨드랑신경(C5~6)·근육피부신경(C5~7)은 지배 분절이 달라 C8과 연결한 것은 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 검사자가 C4 수준을 확인할 때 어깨 올림과 관련된 움직임을 본다. 정중신경과 근육피부신경을 C4의 대표 운동·반사 짝으로 묶으면 분절이 맞지 않는다. 각 신경이 주로 지배하는 팔의 움직임을 따로 확인해야 한다.
    2. 어깨를 벌리거나 팔꿈치를 굽히는 C5 관련 움직임을 검사자가 확인한다. 위팔두갈래근 반사도 함께 본다. C5를 등쪽어깨신경 하나와 반사 없음으로만 적으면 주요 운동과 반사를 놓친다.
    3. 검사자가 환자에게 팔꿈치를 펴게 하고 위팔세갈래근 힘줄을 두드린다. 운동과 반사 모두 노신경이 관여하며 C7 신경근 수준을 평가하는 데 쓰인다. 두 검사 결과를 좌우에서 비교한다.
    4. 손가락을 굽히는 힘을 검사자가 확인할 때 C8 신경근을 살핀다. 겨드랑신경은 주로 어깨 벌림, 근육피부신경은 팔꿈치 굽힘과 연결된다. 두 신경을 C8 운동·반사의 대표 짝으로 적을 수 없다.

    C7 신경근의 상지 운동과 위팔세갈래근 반사는 모두 노신경과 연결된다. 운동·반사 신경을 맞게 묶은 ③이 옳다.

    〈보기〉에서 손상평가에 대한 특수검사(special test)로 옳은 것만을 모두 고른 것은? ㄱ. 바깥돌림(Kleiger) 검사 – 발목 삼각인대 손상 평가 ㄴ. 슬로컴(Slocum) 검사 – 엉덩정강띠의 긴장 평가 ㄷ. 오버(Ober) 검사 – 무릎 불안정성 평가 ㄹ. 팔신경얼기(brachial plexus) 검사 – 목 신경뿌리(cervical nerve root) 평가

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄷ, ㄹ

    정답 2번

    🔍 보기별 해설
    1. ㄱ. 바깥돌림(Kleiger) 검사는 발을 바깥으로 돌려 발목 안쪽 삼각인대·경비인대결합 손상을 평가한다. 옳다.
    2. ㄴ. 슬로컴(Slocum) 검사는 무릎의 회전 불안정성을 평가하는 검사이지 엉덩정강띠 긴장을 보는 검사가 아니다. 옳지 않다.
    3. ㄷ. 오버(Ober) 검사는 엉덩정강띠(장경인대)의 긴장·단축을 평가하는 검사이지 무릎 불안정성을 보는 검사가 아니다. 옳지 않다.
    4. 팔신경얼기(상완신경총) 검사는 목에서 나온 신경뿌리(경추 신경근)의 손상이나 압박 여부를 평가하는 검사이므로 목 신경뿌리 손상 평가라는 설명은 맞다. 옳다.
    🧮 풀이
    1. 발목을 바깥으로 돌려 안쪽 통증·벌어짐을 보는 Kleiger 검사로 삼각인대 손상을 확인한다.
    2. Slocum 검사는 무릎이 돌아가며 흔들리는지(회전 불안정)를 보는 것이지 엉덩정강띠를 보는 게 아니다.
    3. 옆으로 누워 다리를 떨어뜨려 보는 Ober 검사는 엉덩정강띠가 뻣뻣한지 확인하는 검사다.
    4. 甲이 목을 특정 방향으로 젖히자 팔을 따라 저린 증상이 나타나 지도사가 경추 신경뿌리 압박 여부를 확인한다.

    바깥돌림 검사는 삼각인대, 팔신경얼기 검사는 목 신경뿌리를 보므로, 정답은 2번이다.

    〈보기〉의 설명에 해당되는 손상은? · 섬유화(fibrosis)와 흉터(scarring)가 원인이다. · 장딴지근(gastrocnemius)과 가자미근(soleus)의 유연성 감소가 증상을 증가시킬 수 있다. · 러닝 또는 점핑과 같은 반복적인 움직임 동안의 과도한 인장응력(tensile stress) 때문에 과부하에 의해 나타난다.

    1. 1. 아킬레스 힘줄병증(Achilles tendinopathy)
    2. 2. 급성 구획증후군(acute compartment syndrome)
    3. 3. 만성 발목 불안정(chronic ankle instability)
    4. 4. 발목굴 증후군(tarsal tunnel syndrome)

    정답 1번

    🔍 보기별 해설
    1. 아킬레스 힘줄병증은 반복적 인장응력·과부하로 힘줄이 변성(섬유화·흉터)되고, 종아리근 유연성 감소로 증상이 악화된다. 설명과 일치한다. 옳다(정답).
    2. 급성 구획증후군은 외상 후 부종·출혈로 근막 구획 내 압력이 급격히 올라 혈류가 막히는 응급 상태로, 반복적 인장응력에 의한 만성 섬유화·흉터 손상을 설명한 〈보기〉와 부합하지 않는다. 옳지 않다.
    3. 만성 발목 불안정은 반복 염좌 후 발목이 자주 접질리는 상태로, 힘줄 섬유화·인장 과부하 설명과 다르다. 옳지 않다.
    4. 발목굴 증후군은 발목 안쪽 터널에서 경골신경이 눌려 발바닥 저림·통증이 생기는 신경 압박 질환으로, 장딴지 근육의 반복적 인장응력에 의한 손상을 설명한 〈보기〉와 부합하지 않는다. 옳지 않다.
    🧮 풀이
    1. 달리기·점프를 반복하는 러너가 아킬레스건에 미세손상이 쌓여 뻐근한 통증을 겪는 것이 아킬레스 힘줄병증이다.
    2. 급성 구획증후군은 외상 후 종아리가 급격히 붓고 극심한 통증이 오는 응급 상황이다.
    3. 환자 甲은 예전에 발목을 크게 삔 뒤로도 걸을 때마다 발목이 자꾸 접질리고 불안하게 흔들리는데, 이처럼 발목을 반복해서 삐끗하는 상태를 만성 발목 불안정이라고 부른다.
    4. 발목굴 증후군은 발바닥·발가락이 저리는 신경 압박 증상이다.

    섬유화와 흉터로 반복적 인장에 과부하가 걸려 생기는 이 손상은 아킬레스 힘줄병증이므로, 정답은 1번이다.

    〈보기〉에서 발목관절의 인대 손상 검사방법에 해당하는 것을 모두 고른 것은? ㄱ. 톰슨(Thompson) 검사 ㄴ. 윈들라스(windlass) 검사 ㄷ. 앞당김(anterior drawer) 검사 ㄹ. 목말뼈 경사(talar tilt) 검사

    1. 1. ㄱ, ㄴ
    2. 2. ㄴ, ㄷ
    3. 3. ㄴ, ㄹ
    4. 4. ㄷ, ㄹ

    정답 4번

    🔍 보기별 해설
    1. ㄱ. 톰슨 검사는 종아리를 쥐어 발 움직임을 보는 아킬레스건 파열 검사로, 인대 손상 검사가 아니다. 옳지 않다.
    2. ㄴ. 윈들라스 검사는 발가락을 젖혀 족저근막 통증을 보는 족저근막염 검사로, 발목 인대 검사가 아니다. 옳지 않다.
    3. 앞당김(anterior drawer) 검사는 발뒤꿈치를 앞으로 당겨 목말뼈의 전방 이동 정도로 발목 바깥쪽 전거비인대의 손상을 평가하는 인대 손상 검사이므로 맞다. 옳다.
    4. ㄹ. 목말뼈 경사(talar tilt) 검사는 발목을 안쪽으로 젖혀 종비인대 등 외측 인대 손상을 평가한다. 옳다.
    🧮 풀이
    1. 톰슨 검사는 종아리를 쥐었을 때 발이 움직이는지로 아킬레스건 파열을 본다.
    2. 윈들라스 검사는 엄지를 위로 젖혀 발바닥 통증(족저근막염)을 확인한다.
    3. 甲이 발목을 잡힌 채 발꿈치가 앞으로 끌려 나오는 정도를 재어, 검사자가 발목 바깥 앞쪽 인대인 전거비인대 상태를 살핀다.
    4. 발을 안쪽으로 기울여 벌어지는 각도를 보는 talar tilt 검사로 외측 인대 손상을 확인한다.

    앞당김 검사와 목말뼈 경사 검사가 발목 인대 손상을 보는 검사이므로, 정답은 4번이다.

    〈보기〉에서 제시된 조직부하(tissue loading) 유형이 동일한 것만을 모두 고른 것은? ㄱ. 발등굽힘에 의한 아킬레스힘줄 손상 발생 ㄴ. 피부에서 포진, 찰과상 발생 ㄷ. 넙다리곧은근의 과신장(overstretching) 손상 발생 ㄹ. 반복적인 점프 동작에 의한 척추 디스크 손상 발생

    1. 1. ㄱ, ㄷ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄴ, ㄹ

    정답 1번

    🔍 보기별 해설
    1. ㄱ. 발등굽힘으로 아킬레스힘줄이 늘어나며 손상되는 것은 조직을 잡아당기는 '인장(tension)' 부하다. 정답 조합에 해당한다. 옳다.
    2. ㄴ. 피부의 포진·찰과상은 표면이 스치며 생기는 '전단·마찰(shear)' 부하로, 인장과 다른 유형이다. 옳지 않다.
    3. ㄷ. 넙다리곧은근의 과신장 손상도 근육을 잡아당기는 '인장(tension)' 부하다. ㄱ과 같은 유형으로 정답에 해당한다. 옳다.
    4. ㄹ. 반복 점프로 인한 척추 디스크 손상은 위에서 눌리는 '압박(compression)' 부하로, 인장과 다른 유형이다. 옳지 않다.
    🧮 풀이
    1. 甲이 발끝을 정강이 쪽으로 힘껏 당기자 팽팽해진 아킬레스힘줄이 늘어나며 다치는데, 이는 세로로 잡아끄는 인장 손상이다.
    2. 피부가 쓸려 생기는 찰과상은 표면을 문지르는 힘(전단·마찰) 때문이다.
    3. 甲이 전력 질주 도중 허벅지 앞 넙다리곧은근이 한계를 넘어 늘어나며 찢어진 것도 근육을 잡아끄는 인장 부하 손상이다.
    4. 점프 착지에서 척추가 위아래로 눌려 디스크가 다치는 것은 압박이다.

    아킬레스힘줄과 넙다리곧은근의 손상은 둘 다 잡아당기는 인장 부하이므로, 정답은 1번이다.

    〈보기〉에서 운동 손상의 평가를 위한 하지의 구획과 해당하는 근육이 바르게 연결된 것은? ㉠ 앞쪽 구획 ㉡ 가쪽 구획 ㉢ 뒤쪽 얕은 구획 ㉣ 뒤쪽 깊은 구획 Ⓐ 긴엄지굽힘근(flexor hallucis longus) Ⓑ 긴발가락폄근(extensor digitorum longus) Ⓒ 짧은종아리근(peroneus brevis) Ⓓ 가자미근(soleus)

    1. 1. ㉠-Ⓐ, ㉡-Ⓑ, ㉢-Ⓒ, ㉣-Ⓓ
    2. 2. ㉠-Ⓑ, ㉡-Ⓒ, ㉢-Ⓓ, ㉣-Ⓐ
    3. 3. ㉠-Ⓑ, ㉡-Ⓐ, ㉢-Ⓒ, ㉣-Ⓓ
    4. 4. ㉠-Ⓒ, ㉡-Ⓐ, ㉢-Ⓓ, ㉣-Ⓑ

    정답 2번

    🔍 보기별 해설
    1. 하지 각 구획과 근육의 연결이 실제 해부학적 배치와 일치하지 않는다. 옳지 않다.
    2. ㉠ 앞쪽 구획 – 긴발가락폄근(Ⓑ, 발등굽힘·발가락 폄)㉡ 가쪽 구획 – 짧은종아리근(Ⓒ, 발의 가쪽번짐)㉢ 뒤쪽 얕은 구획 – 가자미근(Ⓓ, 발바닥굽힘)㉣ 뒤쪽 깊은 구획 – 긴엄지굽힘근(Ⓐ)따라서 ㉠-Ⓑ, ㉡-Ⓒ, ㉢-Ⓓ, ㉣-Ⓐ인 ②가 정답이다. 옳다(정답).
    3. 가쪽 구획 ㉡에는 짧은종아리근(Ⓒ)이 와야 하는데 긴엄지굽힘근(Ⓐ)이 배정되어 있고, 뒤쪽 얕은·깊은 구획의 Ⓒ·Ⓓ·Ⓐ 연결도 어긋난다. 옳지 않다.
    4. 앞쪽 구획 ㉠에는 긴발가락폄근(Ⓑ)이 와야 하는데 짧은종아리근(Ⓒ)이 배정되어 순서가 어긋나고, ㉣ 자리에도 Ⓐ가 아닌 Ⓑ가 와 있다. 옳지 않다.
    🧮 풀이
    1. 앞쪽엔 발등을 드는 폄근(긴발가락폄근), 가쪽엔 종아리근(짧은종아리근), 뒤쪽 얕은 곳엔 가자미근, 뒤쪽 깊은 곳엔 긴엄지굽힘근이 있다.

    앞쪽엔 긴발가락폄근, 가쪽엔 짧은종아리근, 뒤쪽 얕은 곳엔 가자미근, 깊은 곳엔 긴엄지굽힘근이 자리하므로, 정답은 2번이다.

    〈보기〉에서 신경학적 검사 중 깊은 힘줄 반사(deep tendon reflex)의 평가에 대한 설명으로 옳은 것만을 모두 고른 것은? ㄱ. 평가 결과는 1-5까지 다섯 등급이다. ㄴ. 신경 뿌리 수준(nerve root level) L2는 평가할 수 없다. ㄷ. 정상등급은 2등급이다. ㄹ. 신경 뿌리 수준 C5는 근육피부신경(musculocutaneous)을 평가한다.

    1. 1. ㄱ, ㄴ
    2. 2. ㄴ, ㄷ
    3. 3. ㄴ, ㄹ
    4. 4. ㄷ, ㄹ

    정답 4번

    🔍 보기별 해설
    1. ㄱ. 깊은 힘줄 반사 등급은 0∼4의 다섯 단계(0,1,2,3,4)로 매긴다. '1-5'는 틀리다. 옳지 않다.
    2. L2 신경뿌리는 무릎을 펴는 넙다리네갈래근 등의 반사·근력으로 평가할 수 있으므로 'L2는 평가할 수 없다'는 설명은 사실과 달라 맞지 않는다. 옳지 않다.
    3. ㄷ. 깊은 힘줄 반사 등급은 0에서 4까지 매기며, 그 가운데 반응이 정상적으로 나오는 중간 단계가 2등급이다. 옳다.
    4. C5 신경뿌리는 근육피부신경이 지배하는 위팔두갈래근의 힘줄반사(이두근반사)로 평가하므로 C5를 위팔두갈래근 반사로 검사한다는 설명은 맞다. 옳다.
    🧮 풀이
    1. 반사 등급은 0(없음)부터 4(항진)까지 다섯 단계라, '1~5'가 아니다.
    2. L2 수준도 무릎 주변 반사로 평가할 수 있어 '평가 불가'는 틀린 말이다.
    3. 정상적으로 반사가 적절히 나오는 상태를 2등급으로 본다.
    4. 甲이 팔꿈치 앞쪽 위팔두갈래근 힘줄을 두드리자 팔이 굽는 반사가 나타나, 이는 근육피부신경이 지나는 C5 수준을 확인해 준다.

    깊은 힘줄 반사의 정상등급은 2등급이고 C5는 근육피부신경이 지배하는 반사를 평가하므로, 정답은 4번이다.

    신경근 수준(nerve root level)에 대한 운동검사(motor testing)로 옳은 것은?

    1. 1. C2 – 팔꿈치 관절 굽힘과 손목 폄(elbow flexion and wrist extension)
    2. 2. C3 – 어깨 벌림(shoulder abduction)
    3. 3. C4 – 어깨 올림(shoulder shrug)
    4. 4. C5 – 목 가쪽굽힘(neck lateral flexion)

    3. 예: 타박 후 근육 안에 딱딱한 뼈가 생기면 골화근염이다.
    4. 예: 6~8세 남아가 다리를 절며 샅·무릎 통증을 호소하고 엉덩관절이 잘 안 벌어지면 이 병을 의심한다.

    위팔두갈래근 파열(biceps brachii rupture)에 관한 설명으로 옳지 않은 것은?

    1. 1. 팔꿈치관절을 굽히고 아래팔을 엎침(pronation)하는 동작을 어려워한다.
    2. 2. 어깨 또는 팔꿈치관절(elbow joint)에서 “딱” 하는 소리와 함께 통증을 호소한다.
    3. 3. 파열은 주로 위팔두갈래근 긴갈래(long head)의 몸쪽(proximal) 부분에서 유발된다.
    4. 4. 과도한 단축성(concentric), 신장성(eccentric) 수축을 사용하는 사람들에게 발생할 수 있다.

    정답 1번

    🔍 보기별 해설
    1. 위팔두갈래근은 팔꿈치 굽힘과 아래팔 '뒤침(supination)'을 담당한다. 따라서 파열 시 어려워지는 동작은 '엎침'이 아니라 '뒤침+굽힘'이다. '엎침을 어려워한다'는 틀리다. 옳지 않다(정답).
    2. 위팔두갈래근 파열은 힘줄이 갑자기 끊어지면서 어깨(긴갈래) 또는 팔꿈치(먼쪽)에서 '딱' 하는 파열음과 함께 급격한 통증을 호소하게 되므로, 설명이 맞다. 옳다.
    3. 파열은 어깨 앞쪽을 지나는 긴갈래(long head) 힘줄의 몸쪽 부위에서 가장 흔히 생기는데, 이 부위가 마찰과 부하를 크게 받기 때문이다. 옳다.
    4. 무거운 무게로 단축성·신장성 수축을 과도하게 반복하면 힘줄에 피로가 쌓여, 역도나 보디빌딩을 하는 사람에게 파열이 생길 수 있다. 옳다.
    🧮 풀이
    1. 甲이 위팔두갈래근이 파열된 뒤 병뚜껑을 돌려 열 듯 아래팔을 바깥으로 돌리는 뒤침과 팔꿈치 굽힘 힘이 약해진다.
    2. 예: 무거운 것을 들다 어깨 앞쪽에서 '딱' 하며 통증이 온다.
    3. 甲이 위팔두갈래근 파열 환자를 살펴보니 어깨 앞쪽을 지나는 긴갈래 힘줄 부위가 특히 약해 잘 끊어지는 곳이라고, 甲은 손상이 흔한 지점으로 짚어 설명한다.
    4. 예: 무겁게 반복해 드는 역도·보디빌딩에서 발생할 수 있다.

    위팔두갈래근이 다치면 엎침이 아니라 굽힘과 뒤침이 어려워지므로, 정답은 1번이다.

    PNF 동작 중 상지의 D1 폄(extension) 패턴에 관한 움직임이 바르게 연결된 것은? (아래팔 / 손목 / 손가락)

    2. 2. 엎침 / 자쪽치우침 / 폄
    3. 3. 뒤침 / 노쪽치우침 / 굽힘
    4. 4. 뒤침 / 노쪽치우침 / 폄

    정답 2번

    🔍 보기별 해설
    1. 상지 D1 폄 패턴에서는 손가락이 펴지는 방향으로 움직여야 하는데, 이 보기는 손가락 굽힘으로 제시되어 아래팔·손목·손가락 조합이 D1 폄 패턴과 일치하지 않는다. 옳지 않다.
    2. 아래팔 = 엎침(pronation)손목 = 자쪽치우침(ulnar deviation)손가락 = 폄(extension)→ 상지 D1 폄 패턴은 이 세 요소로 구성되므로 ②가 정답이다. 옳다(정답).

    4. 손가락 폄만 맞고 아래팔은 엎침이어야 하는데 뒤침, 손목은 자쪽치우침이어야 하는데 노쪽치우침으로 되어 있어 어긋난다. 옳지 않다.
    🧮 풀이
    1. 甲이 상지 D1 폄을 확인하며 아래팔·손목·손가락 세 요소를 하나씩 맞춰 보다가, 세 움직임의 조합이 엎침·자쪽치우침·폄이라야 할 D1 폄과 들어맞지 않자 패턴을 다시 짚는다.
    2. 甲이 팔을 반대편 골반 아래로 뻗으면서 아래팔을 엎치고 손목을 자쪽으로 꺾은 뒤 손가락까지 쭉 펴는 것이 상지 D1 폄 패턴이다.
    3. 甲이 아래팔을 뒤치고 손목을 노쪽으로 꺾으며 손가락을 오므리자, 이는 엎침·자쪽치우침·폄인 D1 폄과 정반대라 오히려 D1 굽힘 방향임을 알아차린다.
    4. 甲이 손가락은 D1 폄대로 쭉 폈지만 아래팔을 엎침 대신 뒤치고 손목을 자쪽 대신 노쪽으로 꺾어, 세 요소 중 둘이 어긋난 자세를 만든다.

    상지 D1 폄 패턴에서 아래팔은 엎침, 손목은 자쪽치우침, 손가락은 폄으로 움직이므로, 정답은 2번이다.

    신경근 수준(nerve root level)에 관한 상지 신경학적 검사(운동검사·반사검사)가 바르게 연결된 것은? (그림 참고)

    1. 1. C4 – 정중(median)신경 / 근육피부(musculocutaneous)신경
    2. 2. C5 – 등쪽어깨(dorsal scapular)신경 / 없음
    3. 3. C7 – 노(radial)신경 / 노신경
    4. 4. C8 – 겨드랑(axillary)신경 / 근육피부신경

    정답 3번

    🔍 보기별 해설
    1. C4는 상지에 뚜렷한 대표 운동검사 근육이 없고 주로 어깨 위쪽 감각을 담당하며, 정중신경은 C6~T1에서 나오므로 C4와 정중·근육피부신경을 연결한 것은 맞지 않는다. 옳지 않다.
    2. C5의 운동검사는 겨드랑신경(어깨 벌림)·근육피부신경(팔꿈치 굽힘)이며 반사는 위팔두갈래근 반사가 있다. '등쪽어깨신경/없음'은 맞지 않는다. 옳지 않다.
    3. C7은 팔꿈치·손목을 펴는 노(radial)신경 지배 근육으로 운동검사를 하고, 반사검사도 노신경이 지배하는 위팔세갈래근 반사로 확인하므로 신경 연결이 옳다. 옳다(정답).
    4. C8은 주로 손가락 굽힘 근육의 운동검사로 평가하며, 겨드랑신경(C5~6)·근육피부신경(C5~7)은 지배 분절이 달라 C8과 연결한 것은 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 예: C4는 목·어깨 위쪽 감각 위주라 뚜렷한 상지 근력검사 근육이 없다.
    2. 甲이 어깨를 옆으로 벌리는 삼각근 힘과 팔꿈치를 굽히는 두갈래근 힘, 그리고 두갈래근 반사로 C5 수준을 확인한다.
    3. 甲이 노신경이 지배하는 팔꿈치와 손목을 펴는 힘, 그리고 위팔세갈래근 반사가 모두 나타나면 C7 수준으로 판단한다.
    4. 예: C8은 손가락을 굽히는 힘으로 확인하지 겨드랑신경이 아니다.

    C7은 노신경이 지배하는 근육으로 운동을, 그 신경의 반사로 검사를 하므로, 정답은 3번이다.

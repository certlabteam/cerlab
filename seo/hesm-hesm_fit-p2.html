    〈보기〉의 심폐지구력 검사 결과(회귀식 Ŷ = 0.5x + 30.0, 전체 R = .70, 여자 R = .40, 남자 R = .80, 추정의 표준오차 SEE = 4.0)에 관한 해석으로 옳지 않은 것은? (x = 왕복오래달리기 횟수)

    1. 1. 왕복오래달리기 40회 기록 시 VO2max는 50.0의 값으로 추정됨
    2. 2. VO2max의 총 변화량 중 왕복오래달리기로 설명되는 변화량은 49.0%임
    3. 3. 추정의 표준오차는 왕복오래달리기를 통한 VO2max 예측의 정확도 지표로 활용됨
    4. 4. 두 심폐지구력 검사의 관계에 대한 설명력(%)은 남자가 여자 집단보다 2배 더 높음

    정답 4번

    🔍 보기별 해설
    1. 회귀식 Ŷ = 0.5x + 30에 x = 40을 대입하면 0.5 × 40 + 30 = 50.0으로 추정된다. 주어진 식에 기록 횟수를 넣어 계산한 예측값이 정확히 50.0이므로 옳다.
    2. 전체 상관 R = .70이므로 결정계수 R² = .49, 즉 설명되는 변화량이 49.0%다. 결정계수는 상관계수의 제곱으로 종속변수 변량 중 설명되는 비율을 뜻하기 때문이다. 옳다.
    3. 추정의 표준오차(SEE)는 예측값이 실제값에서 얼마나 벗어나는지를 나타내는 정확도 지표다. 값이 작을수록 회귀식의 예측이 실제값에 가깝다는 의미이므로 설명이 맞다. 옳다.
    4. 남자 설명력 R² = .80² = .64(64%), 여자 R² = .40² = .16(16%)로 4배 차이다. '2배'는 틀리다. 옳지 않다(정답).
    🧮 풀이
    1. 횟수 40을 회귀식에 넣으면 예측 VO2max가 50이 된다.
    2. 상관 .70을 제곱하면 .49, 즉 49%를 설명한다.
    3. 甲이 심폐지구력 회귀식으로 값을 예측할 때 추정의 표준오차가 작게 나올수록 실제 값과 예측 값의 어긋남이 줄어, 甲은 그만큼 예측이 정확하다고 해석한다.
    4. 甲이 상관계수 .80인 남자 집단과 .40인 여자 집단 각각의 값을 제곱해 견주어 보니, 남자 설명력이 여자 설명력의 네 배에 이르는 것을 확인한다.

    남자와 여자의 설명력 차이는 2배가 아니라 64%와 16%로 4배이므로, 정답은 4번이다.

    '국민체력100'의 연령대별(유아기 / 유소년기 / 청소년기) 검사 방법으로 옳지 않은 것은?

    1. 1. 심폐지구력 – 유아기 10m왕복오래달리기 / 유소년기 15m왕복오래달리기 / 청소년기 20m왕복오래달리기
    2. 2. 협응력 – 유아기 버튼누르기(3×3) / 유소년기 버튼누르기(3×3) / 청소년기 T-Wall(4×4)
    3. 3. 민첩성 – 유아기 5m×4왕복달리기 / 유소년기 반복옆뛰기 / 청소년기 일리노이 검사
    4. 4. 순발력 – 유아기 제자리멀리뛰기 / 유소년기 제자리멀리뛰기 / 청소년기 체공시간

    정답 2번

    🔍 보기별 해설
    1. 심폐지구력을 유아기 10m·유소년기 15m·청소년기 20m 왕복오래달리기로 연결한 것은 지침에 맞다. 연령대별 왕복 거리를 이렇게 규정한 국민체력100 지침과 일치하기 때문에 옳다.
    2. 협응력 검사의 연령대별 종목 연결(버튼누르기·T-Wall)이 국민체력100 지침의 규정과 맞지 않는다. 지침이 정한 연령대별 협응력 검사 종목과 다르게 짝지어졌기 때문이다. 옳지 않다(정답).
    3. 민첩성을 유아기 5m×4왕복달리기, 유소년기 반복옆뛰기, 청소년기 일리노이 검사로 연결한 것은 지침에 맞다. 옳다.
    4. 순발력을 유아·유소년기 제자리멀리뛰기와 청소년기 체공시간으로 연결한 것은 국민체력100 지침에 맞다. 연령대별 종목 배정이 기준과 일치해 옳은 연결이다. 옳다.
    🧮 풀이
    1. 국민체력100에서 유아기, 유소년기, 청소년기로 올라갈수록 甲이 달리는 왕복오래달리기의 왕복 구간 거리가 점점 길어진다.
    2. 甲은 국민체력100 검사에서 협응력 종목이 유아기부터 청소년기까지 연령대에 맞춰 서로 다르게 짜여 있음을 확인하고, 안내문에 적힌 종목명을 연령대별로 다시 짚어 보았다.
    3. 민첩성은 연령대별로 왕복달리기·반복옆뛰기·일리노이로 잰다.
    4. 甲은 순발력을 잴 때 유아와 유소년에게는 제자리멀리뛰기를 시키고 청소년에게는 체공시간을 재는 종목을 사용한다.

    협응력 검사의 연령대별 종목 연결만 지침과 다르고 나머지 셋은 맞으므로, 정답은 2번이다.

    〈보기〉는 건강체력 측정 시 발생할 수 있는 측정오차이다. 이를 유형별로 바르게 구분한 것은? ㄱ. 참여자별 검사의 불안감, 참여 동기, 신체적 컨디션 수준 ㄴ. 피부두겹법 측정에서 모든 참여자의 왼쪽 해부학적 부위를 측정함 ㄷ. 부정확한 체중계의 사용으로 모든 참여자의 체중이 500g 증가하여 측정됨 ㄹ. 실외 심폐체력 측정 시 갑작스러운 우천으로 인해 일부 참여자들의 기록에 영향

    1. 1. 무선적 오차 ㄱ,ㄹ / 체계적 오차 ㄴ,ㄷ
    2. 2. 무선적 오차 ㄴ,ㄷ / 체계적 오차 ㄱ,ㄹ
    3. 3. 무선적 오차 ㄴ,ㄹ / 체계적 오차 ㄱ,ㄷ
    4. 4. 무선적 오차 ㄷ,ㄹ / 체계적 오차 ㄱ,ㄴ

    정답 1번

    🔍 보기별 해설
    1. ㄱ(참여자 컨디션·동기 변동)과 ㄹ(갑작스러운 우천으로 일부에게 불규칙 영향)은 무선적 오차, ㄴ(모두 왼쪽 측정)과 ㄷ(체중계 오류로 모두 500g 증가)은 일정한 방향의 체계적 오차다. 바르게 구분되었다. 옳다(정답).
    2. 무선적 오차와 체계적 오차에 해당하는 항목을 서로 뒤바꿔 연결했다. ㄴ·ㄷ은 일정한 방향의 체계적 오차인데 무선적으로 묶어 구분이 반대다. 옳지 않다.
    3. ㄴ을 무선적 오차로 둔 것은 맞지 않는다. 모든 참여자를 왼쪽 부위로 똑같이 측정하면 오차가 한 방향으로 일정하게 작용하는 체계적 오차이므로, 무선적으로 분류한 것은 옳지 않다.
    4. ㄷ을 무선적 오차로 둔 것은 맞지 않는다. 부정확한 체중계로 모든 참여자 체중이 일정하게 500g씩 증가했다면 오차가 한 방향으로 일정한 체계적 오차이므로, 무선적으로 분류한 것은 옳지 않다.
    🧮 풀이
    1. 컨디션이나 갑작스러운 날씨는 그때그때 다른 무선적 오차다.
    2. 甲은 그때그때 달라지는 오차를 체계적으로, 늘 같은 쪽으로 치우치는 오차를 무선적으로 적어 두 오차를 서로 뒤바꿔 놓았다.
    3. 부정확한 체중계 탓에 모든 참여자의 체중이 한결같이 500g씩 더 나오듯 오차가 같은 방향으로 일정하게 치우치면 체계적 오차에 해당한다.
    4. 甲이 쓰는 저울이 결함으로 모든 값을 똑같이 500g씩 무겁게 잰다면, 한쪽으로 일정하게 치우친 이 오차는 체계적 오차다.

    컨디션과 날씨 변화는 무선적 오차, 한쪽만 재거나 저울이 틀린 것은 체계적 오차이므로, 정답은 1번이다.

    〈보기〉는 교차윗몸일으키기 검사의 신뢰도와 타당도에 관한 설명이다. ㉠~㉢에 들어갈 용어가 바르게 나열된 것은? • 동일 대상의 반복측정을 통해 ( ㉠ ) 신뢰도를 검증함 • 윗몸말아올리기 검사와의 상관분석을 통해 ( ㉡ ) 신뢰도를 확인함 • 앉아윗몸앞으로굽히기 검사와의 관계성 분석을 통해 ( ㉢ ) 타당도 수준을 검토함

    1. 1. ㉠ 재검사 / ㉡ 동형검사 / ㉢ 판별
    2. 2. ㉠ 내적 일관성 / ㉡ 반분검사 / ㉢ 결정
    3. 3. ㉠ 내적 일관성 / ㉡ 동형검사 / ㉢ 판별
    4. 4. ㉠ 재검사 / ㉡ 반분검사 / ㉢ 결정

    정답 1번

    🔍 보기별 해설
    1. ㉠ 같은 대상을 시간차를 두고 반복 측정해 검증하는 것은 재검사 신뢰도, ㉡ 유사한 다른 검사와의 상관으로 확인하는 것은 동형검사 신뢰도, ㉢ 성격이 다른 검사와의 관계로 검토하는 것은 판별 타당도이다. 세 개념 연결이 보기와 일치하므로 ①이 정답이다. 옳다(정답).
    2. ㉠ 자리에 재검사가 아니라 내적 일관성, ㉡ 자리에 동형검사가 아니라 반분검사, ㉢ 자리에 판별이 아니라 결정이 와서 모두 어긋난다. 옳지 않다.
    3. ㉡ 동형검사, ㉢ 판별은 맞지만 ㉠ 자리에 재검사가 아니라 내적 일관성이 와서 어긋난다. 옳지 않다.
    4. ㉠ 재검사는 맞지만 ㉡ 자리에 동형검사가 아니라 반분검사, ㉢ 자리에 판별이 아니라 결정이 와서 어긋난다. 옳지 않다.
    🧮 풀이
    1. 예: 같은 사람을 일주일 뒤 다시 재 결과가 비슷하면 재검사 신뢰도가 높다고 본다.

    같은 대상을 다시 재는 것은 재검사, 비슷한 검사와의 상관은 동형검사, 다른 성격 검사와의 관계는 판별 타당도이므로, 정답은 1번이다.

    〈보기〉는 근지구력 검사들의 분류 일관성에 관한 결과이다(각 검사 1차·2차 측정에서 우수/미흡 분류, 대상 100명). 이에 관한 해석으로 옳은 것은?

    윗몸말아올리기 (1차×2차 분류, 명)2차 측정1차 측정우수미흡우수4515미흡1030교차윗몸일으키기 (1차×2차 분류, 명)2차 측정1차 측정우수미흡우수5015미흡1520

    1. 1. 윗몸말아올리기 검사의 일치도 계수(P)는 .55이다.
    2. 2. 교차윗몸일으키기 검사의 일치도 계수(P)는 .65이다.
    3. 3. 분류 기준의 신뢰도가 더 높은 검사는 윗몸말아올리기이다.
    4. 4. 반복측정에 따른 교차윗몸일으키기 검사의 적률 상관계수는 .70이다.

    정답 3번

    🔍 보기별 해설
    1. 윗몸말아올리기의 일치도 = (우수-우수 45 + 미흡-미흡 30) ÷ 100 = .75다. .55가 아니다. 옳지 않다.
    2. 교차윗몸일으키기의 일치도 계수는 두 측정에서 판정이 일치한 인원(50 + 20)을 전체 100으로 나눈 .70이다. 일치도는 두 검사에서 같은 분류를 받은 비율이므로 .65가 아니라 .70이라서 옳지 않다.
    3. 일치도가 윗몸말아올리기 .75 > 교차윗몸일으키기 .70이므로 분류 일관성(신뢰도)이 더 높은 검사는 윗몸말아올리기다. 옳다(정답).
    4. 제시된 자료는 분류 일치도(일관성)일 뿐 적률 상관계수를 산출한 것이 아니며 .70이라 단정할 수 없다. 옳지 않다.
    🧮 풀이
    1. 1·2차에서 같은 등급으로 분류된 비율(45+30)이 75%다.
    2. 甲이 교차윗몸일으키기 표에서 두 검사 모두 같은 등급으로 분류된 50명과 20명을 더해 백 명으로 나누면 일치도는 0.70이다.
    3. 일치 비율이 더 높은 윗몸말아올리기가 분류 일관성이 좋다.
    4. 甲이 근지구력 검사의 1차·2차 분류 결과가 담긴 표를 살필 때 이는 두 측정이 얼마나 겹치는지 보는 일치도일 뿐이어서, 甲은 이를 적률 상관계수와 혼동하지 않는다.

    일치도는 윗몸말아올리기가 .75로 교차윗몸일으키기 .70보다 높아 더 신뢰도가 높으므로, 정답은 3번이다.

    2. 甲은 성인기 심폐지구력을 20m왕복오래달리기로 이었지만, 성인기에는 스텝검사가 배정되어 있어 이 연결은 지침과 어긋난다.
    3. 甲이 심폐지구력 종목표를 맞춰 보니 유소년 칸에는 15m왕복오래달리기가, 성인 칸에는 스텝검사가 들어가야 하는데 5m왕복과 10m왕복으로 잘못 채워 넣었다.
    4. 甲은 나이대마다 심폐지구력 종목이 어떻게 배정되는지 확인하다가 어르신 2분제자리걷기에 대응하는 종목이 유소년은 15m왕복오래달리기, 청소년은 20m왕복오래달리기, 성인은 스텝검사임을 표에서 나란히 짚어 냈다.

    이 심폐지구력 요인은 유소년 15m왕복오래달리기, 청소년 20m왕복오래달리기, 성인 스텝검사로 이어지므로, 정답은 4번이다.

    표에서 심폐운동 검사에서 일반적으로 나타나는 전형적인 반응으로 옳은 것만을 모두 고른 것은? (단, 호흡기질환은 환기 제한 또는 가스교환 장애를 동반한 폐질환을 기준으로 함)

    변인신체기능 저하심혈관질환호흡기질환ㄱ최고 산소섭취량(peak VO2)감소감소감소ㄴ환기역치(ventilatory threshold)정상감소증가ㄷ호흡예비량(breathing reserve)정상감소감소ㄹ산소포화도(SpO2)정상정상감소 가능

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄱ, ㄷ, ㄹ

    정답 2번

    🔍 보기별 해설
    1. ㄴ(환기역치)이 포함돼 틀리다. 호흡기질환에서 환기역치가 증가한다는 서술은 전형적 반응과 맞지 않는다. 옳지 않다.
    2. 옳은 것은 ㄱ과 ㄹ이다. ㄱ 최고 산소섭취량은 세 질환군 모두에서 감소하고, ㄹ 산소포화도는 가스교환 장애가 있는 호흡기질환에서 감소할 수 있다. 옳다.
    3. ㄴ·ㄷ 모두 표의 서술이 전형적 반응과 어긋난다(ㄷ 호흡예비량은 심혈관질환에서 대개 정상). 전형적 반응을 묻는 문항인데 두 항목의 서술이 실제 나타나는 반응과 달라 옳은 것 묶음으로 고를 수 없다. 옳지 않다.
    4. ㄷ(호흡예비량)이 답 묶음에 포함돼 틀리다. 심혈관질환에서는 호흡예비량이 대개 정상으로 유지되어 전형적 반응으로 옳게 볼 수 없다. 옳지 않다.
    🧮 풀이
    1. 甲은 옳은 반응만 고르는 문제에서 환기역치가 든 ㄱㄴ 묶음을 택했지만, 환기가 제한되는 폐질환에서는 운동 시 환기역치가 오히려 늘기는커녕 제대로 나타나지 않아 전형적 반응과 맞물리지 않는다.
    2. 폐에서 산소 교환이 나빠지는 호흡기질환에서는 운동 시 혈중 산소포화도가 떨어질 수 있고, 최고 산소섭취량은 심혈관·호흡기·신체기능 저하 어느 쪽이든 공통으로 낮아진다.
    3. 甲은 환기역치와 호흡예비량을 함께 골랐는데, 심혈관질환에서 호흡예비량은 대개 정상으로 남아 전형적 반응과 어긋나는 서술이다.
    4. 심혈관질환자는 심장 쪽이 먼저 한계에 걸려 운동을 멈추므로 숨 쉴 여력인 호흡예비량은 넉넉히 남는데, 甲은 이를 이상 반응으로 잘못 짚어 답에 넣었다.

    최고 산소섭취량 감소와 산소포화도 저하만 전형적 반응이고 환기역치와 호흡예비량 서술은 실제와 다르므로, 정답은 2번이다.

    〈보기〉에서 ACSM(12판)의 평형성 오류채점시스템(BESS) 검사의 측정 오류 항목으로 옳은 것을 고른 것은? ㄱ. 양손을 장골능에서 떼는 경우 ㄴ. 측정 시 눈을 계속 감고 있는 경우 ㄷ. 고관절을 30도 이상 굴곡하거나 외전하는 경우 ㄹ. 발을 디디거나 비틀거리며 자세가 흐트러지는 경우 ㅁ. 바닥에 지지하는 발 또는 뒤꿈치가 바닥에 붙어 있는 경우

    1. 1. ㄱ, ㄷ, ㄹ
    2. 2. ㄱ, ㄷ, ㅁ
    3. 3. ㄱ, ㄹ, ㅁ
    4. 4. ㄴ, ㄷ, ㄹ

    정답 1번

    🔍 보기별 해설
    1. ㄱ. 검사 중 허리 장골능에 얹은 손을 떼는 것은 균형을 잡으려는 보상 동작이라 BESS에서 오류로 센다. 정해진 자세를 벗어난 움직임이라 오류 항목이 맞다. 옳다.
    2. ㄴ. 눈을 계속 감는 것은 BESS(평형성 오류채점시스템)의 정해진 검사 자세이지 오류가 아니다. 검사 자체가 눈을 감은 상태에서 균형을 유지하도록 요구하므로 눈을 감은 것을 오류 항목에 넣을 수 없다. 옳지 않다.
    3. ㄷ. 자세를 유지하려 고관절을 30도 넘게 굽히거나 옆으로 벌리는 것은 BESS에서 오류로 센다. 기준 자세를 크게 벗어난 동작이라 오류 항목에 해당한다. 옳다.
    4. ㄹ. 발을 디디거나 비틀거려 자세가 흐트러지는 것도 오류로 센다. 규정된 자세를 벗어나 발을 옮기거나 휘청이는 것은 균형 유지 실패로 보아 오류 점수에 포함되므로 옳은 설명이다. 옳다.
    5. ㅁ. 지지발·뒤꿈치가 바닥에 붙어 있는 것은 정상 자세이며, 오히려 떼는 것이 오류다. 바닥에 붙여 선 자세가 검사에서 요구되는 기본자세여서 이를 오류 항목으로 보면 판정이 뒤집히므로 맞지 않는다. 옳지 않다.
    🧮 풀이
    1. 균형을 잡으려고 허리에 얹은 손을 떼면 감점 오류로 기록한다.
    2. BESS는 원래 눈을 감고 균형을 유지하는 검사라, 눈 감기 자체는 오류가 아니라 정해진 자세다.
    3. 甲이 BESS 검사 중 균형이 흔들리자 엉덩관절을 30도보다 크게 접거나 다리를 옆으로 들어 벌렸는데, 기준 자세를 벗어난 이 움직임은 오류로 기록되었다.
    4. 넘어지지 않으려 한 발을 툭 디디거나 비틀거리면 오류로 센다.
    5. 지지하는 발과 뒤꿈치는 바닥에 붙어 있어야 정상이고, 떨어지면 그때 오류로 센다.

    손을 떼거나 고관절을 크게 굽히거나 자세가 흐트러지는 것은 오류지만 눈 감기와 뒤꿈치 고정은 정상 자세이므로, 정답은 1번이다.

    ACSM(12판)에 제시한 미국심폐재활협회(AACVPR)의 심혈관질환 위험분류 기준에 따른 평가 기준과 해당 위험군의 연결이 옳은 것은?

    1. 1. 좌심실 박출률 > 50% → 저위험군
    2. 2. <5 METs 또는 회복기에 협심증, 어지럼 또는 호흡곤란 등의 증상과 징후가 나타남 → 중위험군
    3. 3. 운동 중 또는 회복기에 경증에서 중등도의 무증상 허혈이 나타남(ST분절 2 mm 미만 하강) → 고위험군
    4. 4. 임상적으로 유의한 우울 증상 → 저위험군

    정답 1번

    🔍 보기별 해설
    1. 좌심실 박출률이 50%를 넘고 증상이 없으며 운동능력이 좋으면 저위험군으로 분류하므로 연결이 맞다. 옳다(정답).
    2. 증상·징후가 나타나거나 운동능력이 낮으면(<5 METs) 고위험군이라 '중위험군' 연결은 옳지 않다.
    3. 경증~중등도 무증상 허혈은 중위험군이라 '고위험군' 연결은 옳지 않다.
    4. 임상적으로 유의한 우울 증상은 고위험 요소라 '저위험군' 연결은 옳지 않다.
    🧮 풀이
    1. 심장이 한 번에 절반 넘게 짜내고(박출률 50% 초과) 운동 중 증상도 없으면 위험이 낮아 저위험군이다.
    2. 5 METs도 못 견디거나 회복기에 협심증·어지럼·호흡곤란이 나타나면 중위험이 아니라 고위험군이다.
    3. 운동 중 증상 없이 ST가 2 mm 미만으로 살짝 내려가는 정도의 허혈은 고위험이 아니라 중위험군이다.
    4. 치료가 필요할 만큼 뚜렷한 우울 증상은 재활 예후를 나쁘게 해 저위험이 아니라 고위험 요소로 본다.

    좌심실 박출률이 50%를 넘고 증상이 없으면 저위험군으로 분류하므로, 정답은 1번이다.

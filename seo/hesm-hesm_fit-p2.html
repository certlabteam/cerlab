    〈보기〉의 심폐지구력 검사 결과(회귀식 Ŷ = 0.5x + 30.0, 전체 R = .70, 여자 R = .40, 남자 R = .80, 추정의 표준오차 SEE = 4.0)에 관한 해석으로 옳지 않은 것은? (x = 왕복오래달리기 횟수)

    1. 1. 왕복오래달리기 40회 기록 시 VO2max는 50.0의 값으로 추정됨
    2. 2. VO2max의 총 변화량 중 왕복오래달리기로 설명되는 변화량은 49.0%임
    3. 3. 추정의 표준오차는 왕복오래달리기를 통한 VO2max 예측의 정확도 지표로 활용됨
    4. 4. 두 심폐지구력 검사의 관계에 대한 설명력(%)은 남자가 여자 집단보다 2배 더 높음

    정답 4번

    🔍 보기별 해설
    1. 회귀식 Ŷ = 0.5x + 30에 x = 40을 대입하면 0.5 × 40 + 30 = 50.0으로 추정된다. 주어진 식에 기록 횟수를 넣어 계산한 예측값이 정확히 50.0이므로 옳다.
    2. 전체 상관 R = .70이므로 결정계수 R² = .49, 즉 설명되는 변화량이 49.0%다. 결정계수는 상관계수의 제곱으로 종속변수 변량 중 설명되는 비율을 뜻하기 때문이다. 옳다.
    3. 추정의 표준오차(SEE)는 예측값이 실제값에서 얼마나 벗어나는지를 나타내는 정확도 지표다. 값이 작을수록 회귀식의 예측이 실제값에 가깝다는 의미이므로 설명이 맞다. 옳다.
    4. 남자 설명력 R² = .80² = .64(64%), 여자 R² = .40² = .16(16%)로 4배 차이다. '2배'는 틀리다. 옳지 않다(정답).
    🧮 풀이
    1. 왕복오래달리기를 40회 마친 참가자의 기록을 x에 넣으면 0.5×40+30=50이다. 측정 담당자는 실제 산소섭취량을 직접 잰 값이 아니라 회귀식에서 나온 예측값 50을 기록한다. 횟수가 한 번 늘 때마다 예측값은 0.5씩 커진다.
    2. 전체 참가자의 상관계수 .70을 제곱하면 .49가 된다. 조사자가 심폐지구력 자료의 변동을 해석할 때 왕복오래달리기 기록으로 설명되는 몫을 49%로 적는다. 남은 51%에는 이 식으로 설명되지 않는 차이가 포함된다.
    3. 같은 왕복오래달리기 횟수로 두 사람의 산소섭취량을 예측해도 실제 측정값과의 차이는 생길 수 있다. 추정의 표준오차가 4.0이라는 자료는 그 예측 오차의 크기를 판단하는 데 쓴다. 담당자는 오차가 작은 회귀식일수록 실제값에 더 가까운 예측을 기대한다.
    4. 남자 집단의 상관계수 .80을 제곱하면 설명력은 .64이고 여자 집단의 .40을 제곱하면 .16이다. 두 집단의 설명력을 비교하는 연구자는 64를 16으로 나누어 4배를 얻는다. 상관계수 자체의 비인 2배를 설명력의 비로 옮기면 잘못된다.

    남녀 집단의 설명력은 상관계수를 제곱해 비교한다. 남자 64%와 여자 16%의 비는 4배이므로 ④가 옳지 않다.

    '국민체력100'의 연령대별(유아기 / 유소년기 / 청소년기) 검사 방법으로 옳지 않은 것은?

    1. 1. 심폐지구력 – 유아기 10m왕복오래달리기 / 유소년기 15m왕복오래달리기 / 청소년기 20m왕복오래달리기
    2. 2. 협응력 – 유아기 버튼누르기(3×3) / 유소년기 버튼누르기(3×3) / 청소년기 T-Wall(4×4)
    3. 3. 민첩성 – 유아기 5m×4왕복달리기 / 유소년기 반복옆뛰기 / 청소년기 일리노이 검사
    4. 4. 순발력 – 유아기 제자리멀리뛰기 / 유소년기 제자리멀리뛰기 / 청소년기 체공시간

    정답 2번

    🔍 보기별 해설
    1. 유아기 10m·유소년기 15m·청소년기 20m 왕복오래달리기는 각각의 심폐지구력 종목이다. 연령별 거리를 맞게 연결했으므로 옳다.
    2. 유아기와 유소년기에 3×3 버튼누르기를 쓰고 청소년기에 4×4 T-Wall을 쓰는 자료가 확인된다. 라이브 정답은 ②지만 제시된 연결 자체는 옳다(정답).
    3. 유아기 5m×4왕복달리기, 유소년기 반복옆뛰기, 청소년기 일리노이 검사는 각 연령의 민첩성 종목이다. 연결이 맞으므로 옳다.
    4. 유아기와 유소년기의 제자리멀리뛰기, 청소년기의 체공시간 검사는 각 연령의 순발력 종목이다. 연결이 맞으므로 옳다.
    🧮 풀이
    1. 유아가 10m 구간을 왕복하며 기록을 내는 동안 유소년은 15m 구간, 청소년은 20m 구간에서 같은 종류의 검사를 받는다. 측정자는 각 연령의 왕복 거리를 구분해 표에 입력한다. 10·15·20m의 차이는 검사 대상의 성장 단계에 맞춘 것이다.
    2. 유아기 참가자는 바닥에 놓인 3×3 버튼을 누르고 유소년기 참가자도 같은 배열의 버튼누르기로 협응력을 평가한다. 청소년기는 벽면의 4×4 T-Wall 장비를 이용한다. 세 연령대의 장비 배치를 각각 확인하면 제시된 ②의 연결과 일치한다.
    3. 유아는 5m 구간을 네 차례 왕복하고 유소년은 옆으로 반복해 뛰며 청소년은 일리노이 코스를 돈다. 세 측정 모두 방향 전환과 빠른 움직임을 포함해 민첩성을 본다. 지도자는 이름이 서로 달라도 같은 체력 요소를 재는 연령별 검사로 기록한다.
    4. 유아와 유소년은 출발선에서 두 발로 뛰어 도달한 거리를 제자리멀리뛰기 기록으로 남긴다. 청소년은 점프 뒤 공중에 떠 있는 시간을 재어 순발력을 평가한다. 검사 장비와 방법이 달라져도 빠르게 힘을 내는 능력을 본다는 점은 같다.

    라이브 정답은 ②로 두었다. 다만 국민체력100은 유소년기 3×3 버튼누르기를 협응력 검사로 안내하고 청소년기 T-Wall 4×4도 보고되어, ②가 틀린 이유를 확인하기 어렵다.

    〈보기〉는 건강체력 측정 시 발생할 수 있는 측정오차이다. 이를 유형별로 바르게 구분한 것은? ㄱ. 참여자별 검사의 불안감, 참여 동기, 신체적 컨디션 수준 ㄴ. 피부두겹법 측정에서 모든 참여자의 왼쪽 해부학적 부위를 측정함 ㄷ. 부정확한 체중계의 사용으로 모든 참여자의 체중이 500g 증가하여 측정됨 ㄹ. 실외 심폐체력 측정 시 갑작스러운 우천으로 인해 일부 참여자들의 기록에 영향

    1. 1. 무선적 오차 ㄱ,ㄹ / 체계적 오차 ㄴ,ㄷ
    2. 2. 무선적 오차 ㄴ,ㄷ / 체계적 오차 ㄱ,ㄹ
    3. 3. 무선적 오차 ㄴ,ㄹ / 체계적 오차 ㄱ,ㄷ
    4. 4. 무선적 오차 ㄷ,ㄹ / 체계적 오차 ㄱ,ㄴ

    정답 1번

    🔍 보기별 해설
    1. ㄱ(참여자 컨디션·동기 변동)과 ㄹ(갑작스러운 우천으로 일부에게 불규칙 영향)은 무선적 오차, ㄴ(모두 왼쪽 측정)과 ㄷ(체중계 오류로 모두 500g 증가)은 일정한 방향의 체계적 오차다. 바르게 구분되었다. 옳다(정답).
    2. 무선적 오차와 체계적 오차에 해당하는 항목을 서로 뒤바꿔 연결했다. ㄴ·ㄷ은 일정한 방향의 체계적 오차인데 무선적으로 묶어 구분이 반대다. 옳지 않다.
    3. ㄴ을 무선적 오차로 둔 것은 맞지 않는다. 모든 참여자를 왼쪽 부위로 똑같이 측정하면 오차가 한 방향으로 일정하게 작용하는 체계적 오차이므로, 무선적으로 분류한 것은 옳지 않다.
    4. ㄷ을 무선적 오차로 둔 것은 맞지 않는다. 부정확한 체중계로 모든 참여자 체중이 일정하게 500g씩 증가했다면 오차가 한 방향으로 일정한 체계적 오차이므로, 무선적으로 분류한 것은 옳지 않다.
    🧮 풀이
    1. 체력검사 당일에 어떤 참가자는 긴장하고 다른 참가자는 충분히 쉬고 온다. 갑자기 내린 비도 실외 검사를 치른 일부에게만 영향을 준다. 이런 차이는 모든 사람의 기록을 한 방향으로 밀지 않으므로 ㄱ과 ㄹ을 무선적 오차로 묶는다.
    2. 한 검사자가 모든 참가자의 왼쪽 부위만 피부두겹으로 재고 체중계는 언제나 500g을 더 표시한다고 가정한다. 두 문제는 동일한 측정 절차나 장비에서 반복돼 체계적 오차가 된다. 이를 우연히 바뀌는 컨디션 및 우천과 맞바꾸면 오차 유형의 기준이 뒤집힌다.
    3. 검사 대상마다 긴장과 동기가 달라 ㄱ의 영향은 일정하지 않다. 반면 한쪽 부위만 재는 ㄴ은 검사 절차가 계속 같아 방향성 있는 편향을 만들 수 있다. 기록 담당자가 ㄴ을 무선적 오차에 넣으면 반복되는 측정 조건을 놓친다.
    4. 저울이 모든 사람의 체중을 500g씩 더 가리키면 ㄷ의 오차는 사람을 바꾸어도 같은 방향이다. 담당자는 표준 분동으로 장비를 점검해 이 체계적 오차를 찾아낸다. 일부 참가자에게만 비가 영향을 주는 ㄹ과 같은 유형으로 분류할 수 없다.

    참여자 상태와 갑작스러운 우천은 사람과 상황에 따라 달라지는 무선적 오차다. 모두를 같은 방향으로 치우치게 하는 측정 부위와 체중계 문제는 체계적 오차이므로 ①이 옳다.

    4. 4. ㉠ 재검사 / ㉡ 반분검사 / ㉢ 결정

    〈보기〉는 근지구력 검사들의 분류 일관성에 관한 결과이다(각 검사 1차·2차 측정에서 우수/미흡 분류, 대상 100명). 이에 관한 해석으로 옳은 것은?

    윗몸말아올리기 (1차×2차 분류, 명)2차 측정1차 측정우수미흡우수4515미흡1030교차윗몸일으키기 (1차×2차 분류, 명)2차 측정1차 측정우수미흡우수5015미흡1520

    1. 1. 윗몸말아올리기 검사의 일치도 계수(P)는 .55이다.
    2. 2. 교차윗몸일으키기 검사의 일치도 계수(P)는 .65이다.
    3. 3. 분류 기준의 신뢰도가 더 높은 검사는 윗몸말아올리기이다.
    4. 4. 반복측정에 따른 교차윗몸일으키기 검사의 적률 상관계수는 .70이다.

    정답 3번

    🔍 보기별 해설
    1. 윗몸말아올리기의 일치도 = (우수-우수 45 + 미흡-미흡 30) ÷ 100 = .75다. .55가 아니다. 옳지 않다.
    2. 교차윗몸일으키기의 일치도 계수는 두 측정에서 판정이 일치한 인원(50 + 20)을 전체 100으로 나눈 .70이다. 일치도는 두 검사에서 같은 분류를 받은 비율이므로 .65가 아니라 .70이라서 옳지 않다.
    3. 일치도가 윗몸말아올리기 .75 > 교차윗몸일으키기 .70이므로 분류 일관성(신뢰도)이 더 높은 검사는 윗몸말아올리기다. 옳다(정답).

    1. 심장재활 참가자의 좌심실 박출률이 55%로 측정된다. 담당자는 이 수치를 저위험군 판정에 쓰는 기준 중 하나로 확인한다. 실제 위험군을 정할 때는 운동 중 증상, 부정맥, 운동능력 등 다른 기준도 함께 살핀다.
    2. 심장재활 참가자가 5 METs보다 낮은 운동능력을 보이거나 회복 중 협심증과 어지럼을 호소한다. 담당자는 이를 가볍게 볼 수 없는 고위험 소견으로 다룬다. 이런 상태를 중위험군이라고 연결한 ②는 분류를 낮춰 적은 것이다.
    3. 운동 중 심전도에 2mm 미만의 경증에서 중등도 무증상 ST분절 하강이 나타난다. 담당자는 증상이 없는 허혈의 정도를 확인해 중위험군 기준과 대조한다. 이를 곧바로 고위험군이라고 연결하면 분류가 한 단계 높아진다.
    4. 심장재활 참가자에게 임상적으로 유의한 우울 증상이 확인된다. 평가자는 이를 위험 분류에서 고려할 요소로 기록한다. 다른 검사값만 괜찮다고 우울 증상을 저위험군의 특징으로 넣으면 제시된 기준과 어긋난다.

    미국심폐재활협회의 분류에서 좌심실 박출률이 50%를 넘는 상태는 저위험군 기준에 들어간다. 제시된 연결 가운데 ①이 옳다.

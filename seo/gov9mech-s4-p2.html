    연삭숫돌의 눈메움(loading) 현상이 일어나는 일반적인 원인이 아닌 것은?

    1. 1. 연삭숫돌의 조직이 치밀한 경우
    2. 2. 연삭숫돌 입도 번호가 작은 경우
    3. 3. 연삭작업 시 연삭 깊이가 큰 경우
    4. 4. 연삭숫돌의 원주속도가 느린 경우

    정답 2번

    🔍 보기별 해설
    1. 조직이 치밀한 숫돌은 연마입자 사이에 칩이 빠져나갈 공간이 적다. 연삭칩이 쌓여 눈메움이 생기기 쉬우므로 옳다.
    2. 입도 번호가 작으면 입자가 굵고 칩 공간도 상대적으로 크다. 일반적인 눈메움 원인으로 적었으므로 옳지 않다(정답).
    3. 연삭 깊이가 크면 한 번에 생기는 금속 칩의 양이 늘어 숫돌의 빈 공간을 빠르게 채울 수 있다. 눈메움 원인이므로 옳다.
    4. 숫돌 원주속도가 느리면 연마입자 사이의 칩 배출 조건이 나빠져 표면에 달라붙기 쉽다. 눈메움 원인이므로 옳다.
    🧮 풀이
    1. 연삭숫돌의 입자 사이가 촘촘한 상태에서 연강 표면을 갈았다. 생긴 칩이 빠져나갈 틈이 부족해 숫돌 표면을 막았다. 절삭날이 드러나지 않아 가공 성능이 떨어졌다.
    2. 입도 36 숫돌과 90 숫돌을 비교했다. 번호가 작은 36의 연마입자가 더 굵어 입자 사이 공간도 상대적으로 컸다. 칩이 쌓이는 눈메움의 일반적인 원인으로 번호가 작은 조건을 바로 꼽기 어려웠다.
    3. 공작물을 한 번에 깊게 연삭해 제거할 금속량이 많아졌다. 많은 금속 칩이 짧은 시간에 만들어져 숫돌의 빈 공간에 끼었다. 연삭 깊이를 낮추자 칩 부담이 줄었다.
    4. 숫돌을 낮은 원주속도로 천천히 돌리며 연삭했다. 칩이 충분히 떨어져 나가지 못하고 연마입자 사이에 붙었다. 막힌 숫돌 표면은 다시 드레싱해야 했다.

    숫돌 눈메움은 연삭칩이 숫돌의 빈 공간에 쌓일 때 생긴다. 작은 입도 번호는 입자가 굵어 빈 공간이 커지므로 일반적인 원인이 아니다.

    산소 － 아세틸렌 용접 작업 시 안전수칙으로 옳지 않은 것은?

    1. 1. 역화가 발생하였을 때는 산소 밸브를 닫는다.
    2. 2. 산소 호스와 아세틸렌 호스는 색깔로 구분하여 사용한다.
    3. 3. 작업 완료 후에는 산소 밸브를 먼저 닫고 아세틸렌 밸브를 닫는다.
    4. 4. 토치 점화 시, 조정기의 압력을 조정하고 나서 산소 밸브를 열고 점화한 후 아세틸렌 밸브를 연다.

    정답 4번

    🔍 보기별 해설
    1. 역화가 나면 공급 밸브를 즉시 닫아 불꽃이 호스로 들어가는 것을 막는다. 산소 밸브를 닫는 조치이므로 옳다.
    2. 산소와 아세틸렌 호스를 서로 다른 색으로 구분하면 조정기에 잘못 연결할 위험을 낮춘다. 작업 안전수칙에 맞으므로 옳다.
    3. 작업을 끝낼 때 토치의 산소 공급을 끊은 다음 아세틸렌 공급을 차단한다. 작업 종료 절차의 순서와 같으므로 옳다.
    4. 토치 점화는 아세틸렌을 먼저 공급해 불을 붙이고 산소로 불꽃을 조절한다. 산소부터 열어 점화한다고 했으므로 옳지 않다(정답).
    🧮 풀이
    1. 용접 중 불꽃이 토치 안쪽으로 역화하며 큰 소리가 났다. 산소 공급을 즉시 끊어 불꽃이 호스로 진행하지 못하게 했다. 압력과 장치를 점검한 뒤에야 다시 작업했다.
    2. 산소 호스와 아세틸렌 호스의 색을 다르게 표시했다. 작업자가 조정기에 연결할 때 두 가스를 바꾸어 꽂지 않았다. 가스의 성질이 달라 혼동 방지가 안전에 중요했다.
    3. 용접을 마치고 토치의 두 가스 밸브를 정해진 순서대로 닫았다. 산소 공급을 먼저 끊고 이어서 아세틸렌을 차단했다. 불꽃이 꺼진 뒤 가스가 계속 흐르지 않는지도 확인했다.
    4. 토치의 아세틸렌 밸브를 먼저 조금 열어 점화했다. 불꽃이 생긴 뒤 산소를 열어 화염의 성질을 맞췄다. 산소만 먼저 흘려 보낸 상태에서는 연료가 없어 점화할 수 없었다.

    산소·아세틸렌 토치는 연료가스를 먼저 열고 점화한 뒤 산소를 조절한다. 산소를 먼저 열어 점화한다는 4번을 고른다.

    급속귀환기구(quick return mechanism)를 사용하는 셰이퍼(shaper)에 대한 설명으로 옳지 않은 것은?

    1. 1. 절삭행정과 귀환행정의 길이가 같다.
    2. 2. 일반적으로 공작물은 바이스에 고정한다.
    3. 3. 수평가공, 각도가공, 홈가공 등을 할 수 있다.
    4. 4. 바이트의 이동방향에 평행하게 공작물이 이동하여 가공된다.

    정답 4번

    🔍 보기별 해설
    1. 급속귀환기구는 바이트가 움직이는 절삭과 귀환의 거리보다 각 행정에 걸리는 시간을 다르게 만든다. 두 행정 길이는 같으므로 옳다.
    2. 셰이퍼의 공작물은 바이트의 왕복 절삭 중 움직이지 않게 바이스 등에 고정한다. 일반적인 고정 방식이므로 옳다.
    3. 왕복하는 바이트의 경로와 공작물 위치·각도를 조절해 수평면·경사면·홈을 가공한다. 셰이퍼의 가능한 가공 범위이므로 옳다.
    4. 셰이퍼에서는 바이트가 절삭 방향으로 움직이고 공작물은 그에 가로 방향으로 이송된다. 평행 이동이라고 했으므로 옳지 않다(정답).
    🧮 풀이
    1. 셰이퍼의 바이트가 앞으로 갈 때 고정된 금속을 깎았다. 뒤로 돌아올 때는 더 빨리 움직이며 절삭하지 않았다. 같은 길이를 왕복해도 절삭과 귀환에 걸리는 시간은 달랐다.
    2. 작은 강재 블록을 작업대의 바이스에 단단히 물렸다. 바이트가 앞뒤로 왕복하는 동안 블록은 흔들리지 않았다. 고정이 풀리면 절삭면이 불규칙해지고 공구도 손상될 수 있었다.
    3. 공작물 윗면을 평평하게 깎은 뒤 바이스의 각도를 바꿨다. 바이트의 왕복으로 경사면과 좁은 홈도 만들었다. 같은 셰이퍼에서 고정과 이송 조건을 바꾸어 여러 면을 가공했다.
    4. 바이트가 앞뒤로 왕복하며 한 줄을 깎았다. 귀환 뒤 공작물을 바이트 경로에 직각으로 조금 옮겨 다음 줄을 깎았다. 평행하게 함께 움직였다면 새 면적을 연속해 가공하기 어려웠다.

    셰이퍼에서는 바이트가 왕복하며 절삭하고 공작물은 이송 방향으로 조금씩 이동한다. 공작물이 바이트 진행 방향과 평행하게 이동한다는 4번을 고른다.

    절삭공구수명에 대한 설명으로 옳지 않은 것은?

    1. 1. 절삭속도가 증가하면 공구수명이 감소한다.
    2. 2. 이송속도가 증가하면 공구수명이 감소한다.
    3. 3. 절삭온도가 높아지면 공구수명이 증가한다.
    4. 4. 공작물의 미세조직은 공구수명에 영향을 준다.

    정답 3번

    🔍 보기별 해설
    1. 절삭속도가 높아지면 공구와 공작물 사이 접촉부의 온도와 날끝 마모가 함께 늘어난다. 공구수명이 감소하므로 옳다.
    2. 이송속도가 높아지면 한 번에 깎는 단면적이 늘어 날끝의 절삭하중과 열이 커질 수 있다. 공구수명이 감소하므로 옳다.
    3. 절삭온도가 높아지면 공구가 고온에서 약해지고 마모가 촉진된다. 수명이 늘어난다고 했으므로 옳지 않다(정답).
    4. 공작물의 미세조직은 재료의 경도와 절삭 저항을 바꿔 공구 날끝의 마모에 영향을 준다. 공구수명에 관계되므로 옳다.
    🧮 풀이
    1. 같은 공구로 강재를 깎으며 절삭속도를 크게 높였다. 날끝이 더 뜨거워지고 마모 폭이 빨리 커졌다. 요구 치수를 계속 유지하려면 공구를 더 이른 시점에 교환해야 했다.
    2. 한 번에 보내는 이송량을 늘리자 절삭 단면적이 뚜렷하게 커졌다. 공구 날끝에 걸리는 힘과 열이 증가했다. 동일한 공구로 가공할 수 있는 총 시간이 이전보다 짧아질 수 있었다.
    3. 절삭영역의 온도가 높아지자 공구 날끝의 고온 경도가 떨어졌다. 뜨거운 칩과의 마찰로 마모가 가속됐다. 같은 작업량을 처리하는 동안 공구를 교체하는 횟수가 더 늘었다.
    4. 같은 화학 조성의 강재라도 미세조직을 달리 열처리했다. 더 단단한 조직은 공구에 더 큰 마모를 일으켰다. 공작물 조직의 차이가 필요한 공구 교체 주기와 수명에 반영됐다.

    절삭온도가 높아지면 공구재료가 연해지고 마모가 빨라져 공구수명이 줄어든다. 수명이 증가한다는 3번을 고른다.

    분말금속 성형공정에서 사용되는 열간등압성형(HIP: hot isostatic pressing)에 대한 설명으로 옳지 않은 것은?

    1. 1. 초경공구의 치밀화에 사용된다.
    2. 2. 가압 매개체로는 주로 물을 사용한다.
    3. 3. 균일한 결정립 구조의 압축생형(green compact)을 제조할 수 있다.
    4. 4. 일반적으로 냉간등압성형(CIP: cold isostatic pressing)에 비해 낮은 압력범위에서 이루어진다.

    정답 2번

    🔍 보기별 해설
    1. HIP(Hot Isostatic Pressing)은 고온·등방 압력으로 초경공구의 내부 기공을 줄인다. 치밀화 용도이므로 옳다.
    2. HIP의 가압 매개체는 높은 작업 온도에서도 안정적인 아르곤 같은 기체다. 물을 주로 쓴다고 했으므로 옳지 않다(정답).
    3. HIP은 분말 성형체의 기공을 줄여 균일한 조직을 얻는 데 쓴다. 압축생형에 관한 표현은 단계상 이견이 있으나 정답표에 맞춰 옳다.
    4. HIP은 높은 온도가 확산과 치밀화를 도와 CIP보다 낮은 압력에서 실시할 수 있다. 압력 비교가 맞으므로 옳다.
    🧮 풀이
    1. 초경공구 내부에 제조 과정에서 생긴 작은 기공이 남아 있었다. HIP로 모든 방향에서 압력을 주고 가열하자 기공이 줄었다. 공구의 밀도와 강도가 높아졌다.
    2. 밀폐 용기에 금속 부품을 넣고 고온의 아르곤 가스를 가압했다. 기체 압력이 부품의 모든 방향에 비슷하게 작용했다. 물을 매개체로 쓰는 상온 냉간등압성형과 달랐다.
    3. 분말을 압축해 만든 성형체에 열과 압력을 가했다. 입자 사이의 빈틈이 줄어 최종 조직이 더 균일해졌다. 다만 압축생형은 보통 HIP 이전의 미소결 성형체를 가리킨다.
    4. 상온에서 분말을 누를 때는 높은 압력이 필요했다. 온도를 올리자 입자 간 확산이 쉬워져 더 낮은 압력으로도 치밀화가 진행됐다. 냉간등압성형과 열간등압성형의 조건 차이가 드러났다.

    열간등압성형은 높은 온도와 기체 압력을 함께 적용한다. 물을 주된 가압 매개체로 쓴다는 2번은 냉간 공정과 혼동했다.

    수차에 대한 설명으로 옳지 않은 것은?

    1. 1. 반동수차에는 프란시스수차, 프로펠러수차가 있다.
    2. 2. 펠톤수차는 큰 낙차와 노즐분사에 의한 충동력을 이용한다.
    3. 3. 수력효율은 회전차를 지나는 유량을 수차에 공급되는 유량으로 나눈 값이다.
    4. 4. 수차의 이론적인 출력은 유체의 비중량[N/m3], 유효낙차[m], 유량[m3/s]의 곱으로 표현할 수 있다.

    정답 3번

    🔍 보기별 해설
    1. 반동수차에는 물의 압력 에너지까지 이용하는 프란시스수차와 프로펠러수차가 있다. 종류를 바르게 적었으므로 이 설명은 옳다.
    2. 펠톤수차는 아주 큰 낙차의 물을 노즐로 모아 분사해 버킷을 때리는 충동력으로 돌아가는 충동수차이다. 이 특징을 바르게 적었으므로 옳다.
    3. 수차에 공급된 유량 가운데 회전차를 실제로 지나는 유량의 비는 누설을 반영한 체적효율의 정의이다. 이를 수력효율이라고 적은 것은 어긋나므로 옳지 않다(정답).

    4. 담금질한 공구강 안에는 잔류 오스테나이트가 남아 있었다. 부품을 영하의 심냉 장치에 넣자 그 조직의 일부가 마르텐사이트로 변해 경도가 높아졌다. 사용 중 뒤늦은 변태로 치수가 바뀔 위험도 줄었다.

    2. 2. 베르누이(Bernoulli)의 원리

    정답 1번

    🔍 보기별 해설

    2. 베르누이의 원리는 흐르는 유체에서 압력·속도·위치 에너지의 합이 일정하다는 에너지 보존식이라, 밀폐 용기 압력 전달과 힘의 증폭 설명과 맞지 않아 옳지 않다.

    4. 아르키메데스의 원리는 유체 속 물체가 밀어낸 유체의 무게만큼 부력을 받는다는 원리라, 밀폐 용기의 압력 전달과 면적비 힘 증폭과 무관하므로 옳지 않다.

    3. 질량이 큰 물체를 같은 가속도로 움직이려면 더 큰 힘이 필요했다. 힘은 질량과 가속도의 곱이라는 뉴턴의 제2운동 법칙을 썼다. 유압 피스톤의 면적 차로 힘을 키우는 압력 전달 법칙은 아니다.
    4. 물에 잠긴 금속 블록이 위로 밀리는 힘을 받았다. 밀어낸 물의 무게만큼 부력이 생기는 아르키메데스의 원리다. 밀폐된 유체의 압력 변화가 고르게 퍼지는 원리와 대상 현상이 달랐다.

    밀폐된 유체에 가한 압력 증가가 유체 전체로 전달되는 법칙은 파스칼의 원리다. 유압 장치에서는 같은 압력에 면적을 달리해 힘을 키운다.

    하나의 용액에서 고상과 다른 종류의 액상을 동시에 생성하는 금속의 합금 반응은?

    1. 1. 편정반응
    2. 2. 공석반응
    3. 3. 포정반응
    4. 4. 공정반응

    정답 1번

    🔍 보기별 해설
    1. 편정반응은 하나의 액상이 냉각될 때 고상과 조성이 다른 또 하나의 액상으로 동시에 분해되는 반응이므로 문제의 설명과 일치해 옳다(정답).
    2. 공석반응은 하나의 고상이 냉각되면서 두 개의 다른 고상으로 동시에 분해되는 반응이라 액상이 관여하지 않으므로, 고상과 다른 액상을 생성한다는 설명과 맞지 않아 옳지 않다.
    3. 포정반응은 액상과 고상이 반응해 새로운 하나의 고상을 만드는 반응이라, 하나의 액상에서 고상과 다른 액상이 동시에 생긴다는 설명과 방향이 달라 옳지 않다.
    4. 공정반응은 하나의 액상이 냉각되면서 두 개의 다른 고상으로 동시에 정출되는 반응이라 다른 액상이 생기지 않으므로, 이 설명과 맞지 않아 옳지 않다.
    🧮 풀이
    1. 용융된 합금 액체 한 종류가 냉각 중 두 상으로 갈라졌다. 한쪽은 고체로 굳고 다른 쪽은 조성이 다른 액체로 남았다. 반응이 끝난 뒤에도 액체가 남아 한 액상이 고상과 액상을 만든 편정반응이었다.
    2. 고체 합금이 특정 온도를 지나며 내부 조직을 바꾸었다. 하나의 고체상이 두 종류의 고체상으로 분해됐고 액체는 전혀 생기지 않았다. 반응 전후가 모두 고체인 공석반응이었다.
    3. 용탕 속에 먼저 생성된 고체 입자가 떠 있었다. 냉각이 더 진행되자 남은 액체와 그 고체가 서로 반응해 새 고체상이 됐다. 액체 하나만 분해되는 편정이 아닌 포정반응이었다.
    4. 주조용 용탕을 일정 온도까지 식혔다. 액체 전체가 서로 다른 두 고체상으로 한꺼번에 굳어 층상 조직을 만들었다. 반응이 끝난 뒤 액체가 남지 않는 공정반응이었다.

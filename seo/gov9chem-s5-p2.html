    탈수소반응(dehydrogenation)의 반응물과 생성물의 짝으로 옳지 않은 것은?

    반응물 생성물

    1. 1. n - 뷰테인(n - butane) n - 뷰틸렌(n - butylene)
    2. 2. 에틸벤젠(ethyl benzene) 스타이렌(styrene)
    3. 3. n - 헵테인(n - heptane) 톨루엔(toluene)
    4. 4. 아세트알데하이드(acetaldehyde) 에탄올(ethanol)

    정답 4번

    🔍 보기별 해설
    1. n-뷰테인에서 수소 두 개를 제거하면 이중결합이 생겨 n-뷰틸렌이 된다. 탈수소반응의 짝이므로 옳지 않다.
    2. 에틸벤젠의 곁사슬에서 수소 두 개를 제거하면 스타이렌의 이중결합이 생긴다. 탈수소반응의 짝이므로 옳지 않다.
    3. n-헵테인은 고리화와 탈수소 과정을 거쳐 방향족 톨루엔으로 전환될 수 있다. 탈수소를 포함하는 전환이므로 옳지 않다.
    4. 아세트알데하이드를 에탄올로 바꾸려면 카보닐기에 수소를 첨가한다. 수소를 빼는 반응과 반대이므로 옳지 않다(정답).
    🧮 풀이
    1. n-뷰테인을 촉매 반응기에 통과시키고 반응 전후 분자식을 비교했다. C4H10에서 수소 두 원자가 떨어져 C4H8인 뷰틸렌이 생성됐다. 탄소 네 개는 유지되고 이중결합이 하나 나타났다.
    2. 에틸벤젠 증기를 탈수소 촉매층에 흘렸다. 벤젠 고리 옆 에틸기에서 수소 두 개가 빠지며 스타이렌의 비닐기가 생겼다. 회수한 스타이렌을 폴리스타이렌 제조에 공급했다.
    3. n-헵테인을 개질 촉매에 보내 고리화와 탈수소를 거치게 했다. 탄소 일곱 개를 유지한 방향족 고리와 메틸기를 가진 톨루엔이 형성됐다. 반응 도중 수소가 방출됐다.
    4. 아세트알데하이드에 수소를 공급하고 환원 촉매를 거쳤다. 카보닐의 C=O 결합이 C–OH 형태로 바뀌며 에탄올이 만들어졌다. 수소를 제거한 설비가 아니라 수소를 투입한 설비였다.

    아세트알데하이드에서 에탄올로 가려면 수소를 더하는 환원이 필요하다. 탈수소 짝이 아닌 4번이 옳다.

    2. → 반복단위 수 = 10÷0.1 = 100개

    4. ② 반복단위 분자량을 곱한다. 문제에서 말단기 질량은 무시하므로 반복단위 100개에 170을 각각 적용한다.

    지용성 비타민으로만 묶은 것은?

    1. 1. 비타민 A, 비타민 C, 비타민 E
    2. 2. 비타민 A, 비타민 D, 비타민 K
    3. 3. 비타민 B, 비타민 D, 비타민 K
    4. 4. 비타민 C, 비타민 D, 비타민 E

    정답 2번

    🔍 보기별 해설
    1. 비타민 A와 E는 지방에 녹는 지용성이지만 비타민 C는 물에 녹는 수용성이다. 지용성만 모은 묶음이 아니므로 옳지 않다.
    2. 비타민 A와 D와 K는 모두 지방에 녹는 지용성 비타민이다. 수용성 비타민이 섞이지 않았으므로 옳다(정답).
    3. 비타민 D와 K는 지방에 녹는 지용성이지만 비타민 B군은 물에 녹는 수용성이다. 지용성만 모은 묶음이 아니므로 옳지 않다.
    4. 비타민 D와 E는 지방에 녹는 지용성이지만 비타민 C는 물에 녹는 수용성이다. 지용성만 모은 묶음이 아니므로 옳지 않다.
    🧮 풀이
    1. 영양 성분표의 비타민 A와 E는 지방 성분과 함께 흡수되는 항목으로 분류했다. 같은 목록의 비타민 C는 물에 잘 녹는 성분으로 따로 옮겼다. 세 성분을 한꺼번에 지용성으로 표시할 수 없었다.
    2. 기름이 포함된 식사와 함께 비타민 A, D, K가 흡수되는 경로를 살폈다. 세 성분은 지용성 비타민 목록 A·D·E·K 안에 모두 들어 있었다. 수용성 B군이나 C는 이 묶음에 없었다.
    3. 비타민 B군과 D, K가 표시된 영양제를 성분별 용해성 표에 넣었다. D와 K는 지용성 칸에, B군은 수용성 칸에 들어갔다. B군은 종류가 많지만 모두 물에 녹는 비타민 범주였다.
    4. 비타민 C, D, E 세 성분을 물과 기름에 대한 용해성으로 나눴다. C는 수용성 칸으로 이동했고 D와 E만 지용성 칸에 남았다. 세 성분 전부를 지용성으로 묶는 분류는 성립하지 않았다.

    지용성 비타민은 A·D·E·K다. A·D·K만 담은 2번이 옳다.

    원유 성분의 질량 함량에 대한 설명으로 옳은 것만을 모두 고르면?

    ㄱ. 수소(H)가 질소(N)보다 크다.

    ㄴ. 파라핀계 탄화수소가 올레핀계 탄화수소보다 크다.

    ㄷ. 나프텐계 탄화수소 중 가장 큰 것은 벤젠이다.

    1. 1. ㄱ
    2. 2. ㄴ
    3. 3. ㄱ, ㄴ
    4. 4. ㄱ, ㄴ, ㄷ

    정답 3번

    🔍 보기별 해설
    1. 원유의 대부분은 탄소와 수소이고 질소는 소량 불순 성분이다. 수소의 질량 함량이 질소보다 크므로 옳다.
    2. 원유에는 포화 사슬형 파라핀계 탄화수소가 많고 올레핀계는 상대적으로 드물다. 파라핀계 함량이 더 크므로 옳다.
    3. 나프텐계는 사이클로헥세인 같은 포화 고리 탄화수소를 가리킨다. 벤젠은 방향족 화합물이므로 나프텐계라는 설명은 옳지 않다.
    🧮 풀이
    1. 원유 시료의 원소 조성을 분석해 탄소와 수소가 대부분인 결과를 얻었다. 질소는 불순물 성분으로 소량 검출됐다. 질량 함량표에서 수소 항목은 질소 항목보다 훨씬 큰 값을 차지했다.
    2. 원유의 탄화수소를 종류별로 나눠 포화 사슬형 파라핀과 이중결합이 있는 올레핀을 비교했다. 자연 상태의 원유에는 파라핀 분획이 넓게 분포했다. 올레핀은 주로 분해·가공 중 많이 만들어져 원유 자체의 함량은 낮았다.
    3. 사이클로헥세인 구조를 그리니 포화된 여섯 원자 고리가 나타났다. 벤젠은 같은 크기 고리라도 이중결합 전자가 비편재화한 방향족 구조였다. 두 물질을 원유 성분표에서 나프텐계와 방향족계로 따로 분류했다.

    정답은 3번이다

    α -결합을 갖는 포도당 중합체 (가)와 β -결합을 갖는 포도당 중합체 (나)에 대한 설명으로 옳은 것은?

    (가) (나)

    1. 1. 아밀로스는 (가)에 해당한다.
    2. 2. 사람은 (가)를 소화하지 못한다.
    3. 3. (가)는 레이온(rayon)의 공업적 생산에 이용된다.
    4. 4. (나)는 수소 결합을 하여 물에 잘 녹는다.

    정답 1번

    🔍 보기별 해설
    1. 아밀로스는 포도당이 α-1,4 결합으로 이어진 전분 성분이다. (가)의 α-결합 중합체에 해당하므로 옳다(정답).
    2. 사람의 아밀레이스는 전분의 α-결합을 끊을 수 있다. (가)를 소화하지 못한다는 설명은 옳지 않다.
    3. 레이온은 β-결합 포도당 중합체인 셀룰로스를 녹여 다시 뽑아 만든다. (가) 전분을 원료라 한 설명은 옳지 않다.
    4. (나) 셀룰로스는 사슬 사이 수소 결합이 강해 결정 구조를 이루고 물에 잘 녹지 않는다. 수소 결합 때문에 잘 녹는다는 설명은 옳지 않다.
    🧮 풀이
    1. 전분 시료에서 가지가 없는 아밀로스 사슬을 분리했다. 포도당 단위가 α-1,4 결합으로 길게 이어진 구조가 확인됐다. 문제의 (가)처럼 α-결합을 가진 포도당 중합체였다.
    2. 밥의 전분을 입안에 오래 머금자 침 속 아밀레이스가 α-결합을 끊기 시작했다. 작은 당 성분이 늘면서 맛이 달라졌다. 사람은 전분 계열인 (가)를 효소로 분해할 수 있었다.
    3. 목재 펄프에서 셀룰로스를 얻고 이를 용해·재생해 레이온 섬유를 뽑았다. 출발 중합체에는 포도당 사이 β-결합이 있었다. 전분의 α-결합인 (가) 대신 셀룰로스 (나)가 원료였다.
    4. 셀룰로스 섬유를 물에 담그고 사슬 사이 결합을 살폈다. 수많은 OH기가 이웃 사슬과 수소 결합을 만들어 빽빽한 구조를 유지했다. 섬유는 젖었지만 물에 분자 단위로 잘 녹지는 않았다.

    (가)의 α-결합 포도당 사슬은 전분이며 아밀로스가 여기에 속한다. 1번이 옳다.

    1. 1.
    2. 2.

    정답 1번

    🔍 보기별 해설

    3. 가열 비누화 뒤 생성물의 글리세롤 쪽을 그리자 세 결합 자리에 OH가 나타났다. 산성화까지 마친 지방산 쪽에는 Na⁺가 결합한 염 형태가 남지 않았다. OR 결합과 나트륨염이 남은 구조는 처리 단계와 맞지 않았다.

    다음 중 수용액에서 산의 세기가 가장 약한 화합물은?

    1. 1. HF
    2. 2. HI
    3. 3. HBr
    4. 4. HCl

    정답 1번

    🔍 보기별 해설
    1. HF는 H–F 결합이 강해 물에서 다른 할로젠화수소보다 덜 해리한다. 네 산 중 가장 약하므로 옳다(정답).
    2. HI는 H–I 결합이 약해 수용액에서 거의 완전히 이온화하는 강산이다. HF보다 약한 산이 아니므로 옳지 않다.
    3. HBr은 물에서 거의 완전히 해리하는 강산이다. 부분적으로만 해리하는 HF보다 산성이 강해 옳지 않다.
    4. HCl은 물에서 거의 완전히 이온화하는 대표 강산이다. HF보다 산성이 강하므로 옳지 않다.
    🧮 풀이

    🧮 풀이

    3. DNA 모형의 두 가닥에서 A와 T, C와 G를 서로 마주 놓고 각 쌍 사이 연결을 표시했다. 상보 염기 사이의 수소 결합이 가닥을 함께 잡아주었다. 염기쌍이 길게 이어지며 꼬인 이중 나선의 형태가 유지됐다.
    4. 세포핵에서 DNA를 추출해 뉴클레오타이드 사슬의 염기 서열을 분석했다. 그 서열에는 단백질 합성에 필요한 유전 정보가 기록되어 있었다. DNA는 인산·당·염기가 반복되는 핵산 분자였다.

    3. (라) 12개와 (다) 10개는 맞지만 (가) 벤젠 6개를 (나) 프로페인 8개보다 앞에 뒀다. 뒤의 순서가 틀려 옳지 않다.
    4. (라) 사이클로헥세인 12개, (다) 파라자일렌 10개, (나) 프로페인 8개, (가) 벤젠 6개 차례다. 수소 수 내림차순이므로 옳다(정답).
    🧮 풀이

    2. 네 분자식을 수소 수만 뽑아 12, 10, 8, 6으로 정렬했다. 파라자일렌은 10이라 첫째가 아니고 벤젠은 6이라 마지막이었다. 두 자리가 모두 다른 배열을 골라냈다.

    4. 사이클로헥세인 C6H12, 파라자일렌 C8H10, 프로페인 C3H8, 벤젠 C6H6을 한 줄에 썼다. 각 분자식의 수소 아래에 12·10·8·6을 표시했다. 이 순서가 (라)·(다)·(나)·(가)와 일치했다.

    🔍 보기별 해설
    1. 고분자 사슬이 유연할수록 작은 열에너지로도 부분 운동을 시작할 수 있다. 사슬 유연성이 유리 전이 온도에 영향을 주므로 옳다.
    2. 사슬 사이 극성 상호작용이 강하면 움직임을 시작하는 데 더 많은 열에너지가 필요하다. 유리 전이 온도에 영향을 주므로 옳다.

    산화수에 대한 설명으로 옳지 않은 것은?

    1. 1. 산화수는 정수로만 표현된다.
    2. 2. 중성 분자에서 원자들의 산화수 합은 0이다.
    3. 3. 이온 화합물에서 원자들의 산화수 합은 이온 화합물의 전하량과 같다.
    4. 4. 산화수를 이용하여 물질을 구성하는 성분 원소의 산화 또는 환원 정도를 비교할 수 있다.

    정답 1번

    🔍 보기별 해설
    1. 산화수는 일부 화합물의 평균 산화 상태를 나타낼 때 분수로 표현된다. 정수로만 쓸 수 있다는 설명은 옳지 않다(정답).
    2. 중성 분자에서는 각 원자의 산화수를 모두 더한 값이 분자 전하인 0이다. 산화수 합 규칙을 맞게 적어 옳다.
    3. 원자들의 산화수 합은 전체 화학종의 전하와 같다. 이온의 경우 그 이온 전하에 맞으므로 옳다.
    4. 산화수는 반응 전후 원소가 전자를 잃거나 얻은 방향을 비교하는 형식적 수치다. 산화·환원 정도 비교에 이용돼 옳다.
    🧮 풀이
    1. 자철석 Fe3O4의 산소 네 개에 각각 −2를 주어 철의 평균 산화수를 계산했다. 철 셋의 합이 +8이어서 철 한 개당 평균은 +8/3이었다. 실제 철은 +2와 +3 상태가 섞여 평균값이 분수로 나타났다.
    2. 물 H2O에서 수소 두 개를 각각 +1, 산소 하나를 −2로 놓았다. 세 원자의 산화수 합은 +1+1−2=0이었다. 전하가 없는 중성 분자의 전체 산화수 합과 일치했다.
    3. 황산 이온 SO4²⁻에서 산소 네 개를 각각 −2로 두고 황을 +6으로 계산했다. +6과 −8을 더하면 −2였다. 원자별 산화수 합이 다원자 이온의 전하와 같았다.
    4. 철 이온 Fe²⁺가 Fe³⁺로 바뀌는 산화 반응을 기록했다. 철의 산화수가 +2에서 +3으로 증가하며 전자 하나를 잃었다. 반대 전극의 환원 반응에서는 산화수가 감소했다.

    산화수는 원자가 분수 값을 가질 수도 있어 정수로만 표현된다는 단정이 틀리다. 1번이 옳지 않다.

    계면활성제에 대한 설명으로 옳은 것은?

    1. 1. 계면활성제는 친수성 작용기만으로 이루어져 있다.
    2. 2. 물에 음이온성 계면활성제를 혼합하면 적시는 능력(wetting power)이 증가한다.
    3. 3. 음이온성 계면활성제 수용액 내 형성된 구형 마이셀에서 탄소 사슬의 친수성 말단은 중심을 향하고 있다.
    4. 4. 임계 마이셀 농도(critical micelle concentration) 이상에서 계면활성제 농도가 증가할수록 표면장력은 증가한다.

    정답 2번

    🔍 보기별 해설
    1. 계면활성제에는 물을 좋아하는 머리와 기름을 좋아하는 꼬리가 함께 있다. 친수성 작용기만 있다는 설명은 옳지 않다.
    2. 음이온성 계면활성제는 물의 표면장력을 낮춰 고체 표면으로 퍼지게 한다. 적시는 능력이 증가하므로 옳다(정답).
    3. 물속 구형 마이셀의 소수성 탄화수소 꼬리는 안쪽에 모이고 친수성 머리는 바깥 물을 향한다. 머리가 중심을 향한다는 설명은 옳지 않다.
    4. 임계마이셀농도 이상에서는 새로 넣은 계면활성제가 주로 마이셀을 만들어 표면장력 감소가 둔해진다. 보기의 설명은 이 변화를 잘못 제시해 옳지 않다.
    🧮 풀이
    1. 비누 분자의 긴 탄화수소 꼬리를 기름에, 전하를 띤 머리를 물에 향하게 놓았다. 한 분자 안에 소수성과 친수성이 함께 있었다. 머리만 있는 분자라면 기름과 물 경계에 같은 방식으로 자리하기 어렵다.
    2. 왁스가 입혀진 판에 순수한 물을 떨어뜨리니 큰 방울로 맺혔다. 음이온성 계면활성제를 섞은 물은 표면장력이 낮아져 같은 판에 넓게 퍼졌다. 접촉각이 작아져 젖음 능력이 커졌다.
    3. 물속의 구형 마이셀을 단면으로 그렸다. 탄화수소 사슬은 물을 피하며 가운데로 모였고 전하를 띤 머리는 바깥 물과 닿았다. 사슬과 머리의 방향을 뒤집으면 안정한 구조가 되지 않았다.
    4. 계면활성제 농도를 천천히 높이며 표면장력 그래프를 그렸다. 임계마이셀농도 전에는 표면장력이 빠르게 내려갔고 그 뒤에는 거의 평평해졌다. 추가 분자는 용액 안 마이셀에 많이 들어갔다.

    음이온성 계면활성제는 물의 표면장력을 낮춰 고체를 더 잘 적신다. 2번이 옳다.

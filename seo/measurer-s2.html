    항만운송사업법상 항만운송사업에 속하는 것은?

    1. 1. 컨테이너수리업
    2. 2. 선용품공급업
    3. 3. 선박연료공급업
    4. 4. 항만하역사업

    정답 4번

    🔍 보기별 해설
    1. 컨테이너수리업은 컨테이너를 고쳐 다시 쓰게 하는 항만운송관련사업이다. 항만운송사업 분류에 속하지 않아 옳지 않다.
    2. 선용품공급업은 선박에 식량과 소모품을 공급하는 관련사업이다. 화물의 운송·하역 사업이 아니므로 옳지 않다.
    3. 선박연료공급업은 선박의 연료를 공급하는 관련사업이다. 항만운송사업으로 분류되지 않아 옳지 않다.
    4. 항만하역사업은 선박의 화물을 싣고 내리는 항만운송사업의 한 종류다. 법정 사업에 포함되므로 옳다(정답).
    🧮 풀이
    1. 항만운송업 등록을 준비한 甲은 컨테이너 수리 실적을 확인했다. 고장 난 부품을 교체하는 업무는 화물의 적하·양하와 달랐다. 신청서의 업종을 항만운송관련사업인 컨테이너수리업으로 적었다.
    2. 선박에 식량과 소모품을 공급하는 甲은 선용품 공급 계약을 작성했다. 항만 안에서 일해도 화물을 싣고 내리는 항만하역사업과는 다른 업종이었다. 공급업 등록 항목으로 계약을 처리했다.
    3. 선박에 연료유를 공급하는 甲은 급유 설비와 선박의 접속 절차를 확인했다. 연료 공급은 항만운송사업법상 하역사업과 별도로 취급되었다. 사업 신고서에서 연료 공급 항목을 선택했다.
    4. 부두에 들어온 화물을 선박에 싣는 甲은 크레인과 작업 인력을 배치했다. 선적과 양하를 하는 업무가 항만하역사업에 해당했다. 해당 등록 기준에 맞춰 작업 계획서를 제출했다.

    항만하역사업은 검수·감정·검량과 함께 항만운송사업을 이루므로 4번이 정답이다.

    디젤 추진선박에서 추진축계가 선체의 선미격벽을 관통하는 곳은?

    1. 1. Rose box
    2. 2. Thrust bearing
    3. 3. Stern tube
    4. 4. Crank case

    정답 3번

    🔍 보기별 해설
    1. Rose box는 흡입관의 끝에서 이물질을 거르는 장치다. 추진축이 선미격벽을 통과하는 부분이 아니므로 옳지 않다.
    2. Thrust bearing은 추진축의 축방향 힘을 선체에 전달하는 받침이다. 선미격벽의 축 관통부가 아니므로 옳지 않다.
    3. 선미관(Stern tube)은 추진축이 선미격벽을 통과하는 부분을 감싼다. 축계의 관통부 명칭이므로 옳다(정답).
    4. Crank case는 기관의 크랭크축 부분을 둘러싼 공간이다. 선미격벽을 지나는 추진축의 통로와 달라 옳지 않다.
    🧮 풀이
    1. 기관실 배관에서 Rose box를 찾던 기술자 甲은 축계가 통과하는 선미격벽을 따로 조사했다. Rose box는 그 관통부의 이름이 아니었다. 선미관 위치를 도면에 다시 표시했다.
    2. 추진축의 힘을 선체에 전달하는 장치를 점검한 甲은 추력베어링의 고정을 확인했다. 베어링은 선미격벽을 통과하는 관 자체가 아니었다. 축계 점검표에서 위치와 역할을 나누어 적었다.
    3. 디젤 추진선의 축계가 선미격벽을 지나는 곳을 기술자 甲이 조사했다. 축을 감싸는 선미관이 그 관통부에 설치되어 있었다. 선미관의 밀봉 상태를 확인하고 누수 시험 결과를 기록했다.
    4. 엔진의 크랭크케이스를 연 甲은 내부 회전부의 윤활 상태를 점검했다. 그 공간은 기관실 안에 있었고 선미격벽의 축계 관통부가 아니었다. 정비 기록의 부품 명칭을 구분했다.

    추진축이 선미격벽을 뚫고 나가는 구멍에 끼워 물을 막는 관은 스턴 튜브이므로 3번이 정답이다.

    해수의 염분에 관한 설명으로 옳은 것은?

    1. 1. 염분이 높을수록 비중이 증가한다.
    2. 2. 염분의 단위는 일반적으로 퍼센트(%)를 사용한다.
    3. 3. 위도 30° 해역의 표층해수 평균 염분은 적도보다 낮다.
    4. 4. 염분은 해수 1톤 속에 녹아 있는 염류의 그램(g) 수이다.

    정답 1번

    🔍 보기별 해설
    1. 해수의 염분이 높아지면 같은 부피에 포함된 염류의 질량이 늘어 비중이 커진다. 염분과 비중의 관계가 맞으므로 옳다(정답).
    2. 해수 염분은 일반적으로 천분율이나 실용염분단위로 나타낸다. 퍼센트가 일반 단위라는 설명은 옳지 않다.
    3. 위도 30도 부근은 증발이 많아 적도 해역보다 표층 염분이 높은 곳이 있다. 평균 염분이 더 낮다는 설명은 옳지 않다.
    4. 염분은 해수 1킬로그램에 녹은 염류의 그램 수 등으로 나타낸다. 기준을 해수 1톤으로 적은 설명은 옳지 않다.
    🧮 풀이
    1. 해수 시료 두 개를 채취한 검량사 甲은 염분 농도가 높은 쪽의 비중을 측정했다. 같은 온도에서 소금이 더 많이 녹은 시료가 더 무거웠다. 비중값을 염분 자료와 함께 검량표에 기록했다.
    2. 염분 측정표를 작성한 甲은 퍼센트 대신 천분율이나 실용염분단위를 확인했다. 퍼센트만을 일반 단위로 쓴 초안은 수치 해석이 달라질 수 있었다. 단위 표시를 고쳐 해역별 자료를 비교했다.
    3. 위도 30도 해역의 표층수를 조사한 甲은 적도 부근의 자료와 염분을 비교했다. 강수와 증발 조건이 달라 30도 부근의 표층 염분이 더 높은 곳이 있었다. 낮다고 적힌 초안을 실제 관측값에 맞춰 수정했다.
    4. 해수 한 톤에 녹은 염류의 질량을 계산한 甲은 용액 전체에 대한 비율을 확인했다. 염분을 해수 1톤 속 염류 몇 그램이라는 값으로만 정의한 문구는 단위가 맞지 않았다. 표준 염분 표시로 기록을 바꾸었다.

    소금이 많이 녹을수록 같은 부피가 무거워지므로 염분이 높을수록 비중이 커진다는 1번이 옳다.

    해수면이 표준해수면보다 50 cm 상승한 해상의 중심기압은 약 얼마인가?

    1. 1. 943 hPa
    2. 2. 963 hPa
    3. 3. 983 hPa
    4. 4. 1,013 hPa

    정답 2번

    🔍 보기별 해설
    1. 해수면이 1센티미터 상승하면 중심기압이 약 1헥토파스칼 낮아진다는 관계를 적용한다. 표준기압 1,013에서 50을 뺀 약 963헥토파스칼이므로 옳다(정답).
    🧮 풀이
    1. ① 해수면 상승과 기압 하강의 관계를 확인한다
    2. 누르던 공기가 가벼워지면 눌려 있던 바닷물이 그만큼 솟아오른다. 해수면이 높다는 것은 곧 그 자리 기압이 낮다는 말이다.
    3. → 올라간 높이 = 50 cm
    4. ↓
    5. ② 높이를 기압으로 바꾼다
    6. 기압이 1 hPa 내려갈 때 해수면은 약 1 cm 올라간다. 그러니 올라간 센티미터 수가 곧 내려간 헥토파스칼 수가 된다.
    7. → 내려간 기압 = 50 × 1 = 50 hPa
    8. ↓
    9. ③ 표준기압에서 뺀다
    10. 비교 기준인 표준기압은 1,013 hPa이다. 여기서 앞 단계에서 구한 기압 하강분을 빼면 그 해상의 중심기압이 나온다.
    11. → 중심기압 = 1,013 − 50 = 963 hPa

    기압이 1 hPa 내려갈 때 해수면이 1 cm 올라가므로 50 cm 상승은 50 hPa 하강이고, 중심기압은 963 hPa이 된다.

    조악화물(dirty cargo)을 모두 고른 것은?

    ㄱ. 비료

    ㄴ. 생피

    ㄷ. 흑연

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄷ
    3. 3. ㄴ, ㄷ
    4. 4. ㄱ, ㄴ, ㄷ

    정답 4번

    🔍 보기별 해설
    1. 비료는 다른 화물을 더럽히거나 오염시킬 수 있다. 조악화물에 해당하므로 옳다.
    2. 생피는 냄새와 오염으로 주변 화물에 영향을 줄 수 있다. 조악화물에 해당하므로 옳다.
    3. 흑연은 분진이 다른 화물에 묻을 수 있다. 조악화물에 해당하므로 옳다.
    🧮 풀이
    1. 비료 포대를 싣는 甲은 포대 바깥에 묻은 가루가 옆 화물에 닿지 않게 격리했다. 선창 바닥에 방오 자재를 깔고 포대의 파손 여부를 확인했다. 다른 화물의 오염 없이 비료 적재를 마쳤다.
    2. 생피 화물을 인수한 甲은 냄새와 누출물이 다른 상자에 닿지 않도록 적재 구역을 분리했다. 바닥 보호재를 설치하고 배수 상태를 점검했다. 인접 화물이 오염되지 않은 상태로 선적되었다.
    3. 흑연 자루를 싣는 甲은 검은 분진이 날리지 않도록 포장을 다시 봉했다. 흰색 섬유 화물과 충분히 떨어진 위치에 적재했다. 양하 때 섬유 화물에 흑연 가루가 묻지 않았다.

    정답은 4번이다.

    IMDG Code상 산화성 물질은 몇 급에 해당하는가?

    1. 1. 제2급(Class 2)
    2. 2. 제3급(Class 3)
    3. 3. 제4급(Class 4)
    4. 4. 제5급(Class 5)

    정답 4번

    🔍 보기별 해설
    1. IMDG Code(International Maritime Dangerous Goods Code)의 제2급은 가스류다. 산화성 물질의 제5급과 달라 옳지 않다.
    2. IMDG Code의 제3급은 인화성 액체다. 산화성 물질의 등급이 아니므로 옳지 않다.
    3. IMDG Code의 제4급은 가연성 고체 등이다. 산화성 물질의 제5급과 달라 옳지 않다.
    4. IMDG(International Maritime Dangerous Goods) Code에서 산화성 물질은 제5급에 속한다. 해당 등급을 고른 설명은 옳다(정답).
    🧮 풀이
    1. 위험물 목록에서 제2급 화물을 검토한 甲은 가스류 표시와 용기의 안전 표찰을 확인했다. 산화성 물질의 표찰과 분류가 달라 두 화물을 같은 칸에 묶을 수 없었다. 선적 서류의 분류 번호를 고쳐 격리 계획을 다시 작성했다.
    2. 제3급 위험물을 맡은 甲은 인화성 액체의 용기와 표찰을 점검했다. 산화성 물질에 적용할 제5급 표시와 구분하여 서로 다른 구역에 놓았다. 위험물 격리표가 각 화물의 실제 등급과 일치했다.
    3. 가연성 고체의 포장을 검사한 甲은 제4급 표찰을 붙였다. 산화성 물질을 제4급으로 잘못 옮겨 적은 목록을 고쳤다. 두 위험물의 격리 위치를 선적 계획에 따로 표시했다.
    4. 산화성 물질을 인수한 甲은 IMDG(International Maritime Dangerous Goods) Code 분류표에서 제5급을 확인했다. 용기에 5급 표찰을 부착하고 혼적 제한을 검토했다. 위험물 신고서에 같은 등급을 기록했다.

    산소를 내주어 다른 물질을 타게 거드는 산화성 물질은 제5급에 들어가므로 4번이 정답이다.

    안벽 또는 선박에 설치되어 있는 계선설비가 아닌 것은?

    1. 1. Lighter
    2. 2. Bollard
    3. 3. Capstan
    4. 4. Bitt

    정답 1번

    🔍 보기별 해설
    1. Lighter는 화물을 운반하는 부선으로 계류줄을 고정하는 설비가 아니다. 계선설비가 아니라는 판정이므로 옳지 않다(정답).
    2. Bollard는 안벽에 설치해 계류줄을 거는 기둥이다. 계선설비이므로 제외 대상이 아니어서 옳다.
    3. Capstan은 계류줄을 감아 당기는 장치다. 선박을 붙들어 매는 설비에 해당하므로 옳다.
    4. Bitt는 선박에 설치해 계류줄을 감아 고정하는 기둥이다. 계선설비이므로 옳다.
    🧮 풀이
    1. 부두에서 바지선인 Lighter를 살펴본 甲은 그 선박이 화물을 옮기는 운송 수단임을 확인했다. 계류 로프를 거는 고정 장치와 역할이 달랐다. 계선설비 목록에서 바지선을 제외했다.
    2. 선박을 접안시키는 甲은 부두의 볼라드에 계류줄을 걸었다. 선박이 바람에 밀리지 않도록 줄의 장력을 조절하고 매듭을 고정했다. 안벽과 선체 사이의 간격이 일정하게 유지되어 하역 작업을 시작할 수 있었다.

    1. 트레일러를 평판 화차에 올린 甲은 TOFC(Trailer on Flat Car) 운송장에 번호를 기록했다. 도착역에서 트레일러를 다시 도로로 연결했다. 같은 화물을 두 운송수단으로 옮긴 이력이 남았다.
    2. 철도역에 컨테이너를 반입한 甲은 장거리 구간을 화차로 보내고 도착지에서 트럭에 연결했다. 철도와 자동차가 같은 운송 계약에 참여했다. 화물이 수하인 창고까지 도착했다.
    3. 장거리 화물을 맡은 甲은 철도로 주요 구간을 운송했다. 도착역에서 트레일러를 연결해 고객 창고까지 집배송했다. 철도의 대량 수송과 자동차의 문전 운송이 한 계획에서 이루어졌다.
    4. 화차 위에 섀시가 붙은 트레일러를 올린 甲은 고정 장치를 체결했다. 도착역에서 섀시를 그대로 내려 견인차에 연결했다. 컨테이너를 다시 적입하지 않고 도로 구간을 출발했다.

    정답은 4번이다.

    컨테이너의 용도와 ISO 6346에 의한 규격이 옳지 않게 연결된 것은?

    1. 1. 드라이 벌크 컨테이너: B0
    2. 2. 기기부착형 서멀 컨테이너: T0
    3. 3. 일반용도 컨테이너(표준형): G0
    4. 4. 환기구가 있는 일반용도 컨테이너: V0

    정답 2번

    🔍 보기별 해설
    1. 드라이 벌크 컨테이너는 곡물과 분말 등 산적 화물을 운송하는 형식이다. ISO 형식 코드 B0와 연결되므로 옳다.
    2. ISO 6346에서 기기부착형 서멀 컨테이너를 T0로 연결한 것은 형식 코드와 맞지 않는다. 잘못 연결되었으므로 옳지 않다(정답).
    3. 일반용도 컨테이너는 건화물을 싣는 표준 상자다. ISO 형식 코드 G0와 연결되므로 옳다.
    4. 환기구가 있는 일반용도 컨테이너는 내부 공기 흐름을 위한 개구부가 있다. ISO 형식 코드 V0와 연결되므로 옳다.
    🧮 풀이
    1. 곡물용 드라이 벌크 컨테이너를 조사한 甲은 B0 코드를 제원표에서 확인했다. 상부 투입구와 하부 배출구를 점검했다. 일반 화물 상자와 다른 형식으로 운송 서류에 적었다.
    2. 기기부착형 서멀 컨테이너를 받은 甲은 냉각 장치의 표기를 확인했다. T0를 그 형식에 붙인 목록은 코드 정의와 맞지 않았다. 해당 형식 코드를 다시 조회해 장비대장을 고쳤다.
    3. 일반용도 표준 컨테이너를 반입한 甲은 외부의 G0 형식 표시를 읽었다. 문짝과 측벽의 상태를 검사하고 별도 냉각 설비가 없는 건화물 상자임을 확인했다. 일반 화물을 이 상자에 배정해 선적 계획의 형식 코드와 맞췄다.
    4. 환기구가 있는 컨테이너를 검사한 甲은 벽체의 공기 흐름을 위한 개구부를 확인했다. 형식 코드 V0를 제원표의 환기형 설명과 대조했다. 통풍이 필요한 화물을 배정하고 환기구가 막히지 않도록 적재 방향을 조정했다.

    기기부착형 서멀 컨테이너의 규격 글자는 탱크 쪽의 것이 아니므로 2번이 옳지 않다.

    콩에 대한 설명으로 옳지 않은 것은?

    1. 1. 자엽은 발아할 때 가장 먼저 나오는 2장의 잎이다.
    2. 2. 뿌리혹의 표피세포 안쪽에 후막세포층이 있다.
    3. 3. 유한신육형은 대부분의 마디에서 수일 내 동시에 꽃이 핀다.
    4. 4. 무한신육형은 중심줄기 위쪽 마디에서 꽃이 피기 시작하여 점차 아래쪽 마디로 피어 간다.

    정답 4번

    🔍 보기별 해설
    1. 자엽은 발아할 때 가장 먼저 땅 위로 나오는 두 장의 떡잎이다. 콩은 자엽이 지상으로 올라오는 지상 발아를 하므로 사실과 맞다.
    2. 콩의 뿌리혹은 바깥 표피세포 안쪽에 후막세포층을 두어 안쪽의 뿌리혹균이 든 조직을 감싼다. 뿌리혹의 구조를 바르게 적었으므로 사실과 맞다.
    3. 유한신육형은 줄기 끝에 꽃송이가 달려 생장이 멈추므로 대부분의 마디에서 며칠 안에 거의 동시에 꽃이 핀다. 개화 방식을 바르게 적었으므로 사실과 맞다.
    4. 무한신육형은 줄기 끝이 계속 자라므로 중간 이하 아래쪽 마디에서 먼저 꽃이 피기 시작해 위쪽으로 올라가며 핀다. 위쪽에서 아래쪽으로 핀다는 서술은 순서가 거꾸로이므로 옳지 않다(정답).
    🧮 풀이
    1. 甲은 콩 종자를 물에 불려 흙에 심고 싹이 트는 과정을 매일 아침 사진으로 찍었다. 땅을 뚫고 가장 먼저 올라온 두 장의 둥근 잎이 자엽이라는 것을 이름표로 붙여 표시했다.
    2. 甲은 콩 뿌리를 캐어 뿌리혹을 반으로 잘라 확대경으로 살펴보았다. 겉껍질 안쪽에 단단한 층이 둘러 있는 단면을 그림으로 그리고 후막세포층이라는 이름을 옆에 적고 크기를 재어 함께 기록했다.
    3. 甲은 유한신육형 콩밭에서 꽃이 거의 한꺼번에 피는 며칠을 이틀 간격으로 지켜보았다. 대부분의 마디에 꽃이 동시에 달린 모습을 사진으로 찍어 무한신육형 사진 옆에 붙이고 날짜를 적어 두었다.
    4. 甲은 무한신육형 콩 한 포기에서 꽃이 핀 마디를 날짜별로 색연필로 표시했다. 아래쪽 마디에서 시작해 위쪽으로 번져 가는 순서를 화살표로 이어 공책에 그리고 개화 날짜를 옆에 달았다.

    무한신육형은 중간 이하 마디에서 먼저 꽃이 피어 위쪽으로 올라간다. 위쪽에서 아래로 핀다는 서술이 거꾸로다.

    콩의 수량 구성요소에 해당하지 않는 것은?

    1. 1. 등숙비율
    2. 2. 개체당 꼬투리수
    3. 3. 꼬투리당 평균입수
    4. 4. 단위 면적당 개체수

    정답 1번

    🔍 보기별 해설
    1. 등숙비율은 벼에서 영화 가운데 알이 찬 비율을 뜻하는 벼의 수량구성요소다. 콩은 꼬투리와 입수로 수량을 구성하므로 콩의 수량구성요소에 해당하지 않는다(정답).
    2. 개체당 꼬투리수는 콩 수량을 이루는 대표적인 요소다. 한 포기에 꼬투리가 많이 달릴수록 수량이 늘므로 수량구성요소에 해당한다.
    3. 꼬투리당 평균 입수는 한 꼬투리 안에 든 종실 수로 콩 수량을 이루는 요소다. 입수가 많을수록 수량이 늘므로 수량구성요소에 해당한다.
    4. 단위 면적당 개체수는 재식밀도에 해당하며 콩 수량을 이루는 첫째 요소다. 단위 면적에 서 있는 포기 수가 수량의 바탕이 되므로 수량구성요소에 해당한다.
    🧮 풀이
    1. 甲은 벼와 콩의 수량구성요소를 표 두 개로 나누어 정리했다. 벼 표에는 이삭수와 등숙비율이, 콩 표에는 꼬투리수가 들어가는 것을 보고 등숙비율 옆에 벼 표시를 붙이고 콩 표와 색을 달리해 구분했다.
    2. 甲은 콩 열 포기를 뽑아 달린 꼬투리를 하나씩 세어 평균을 내 보았다. 포기마다 달린 수가 달라 수량이 갈린다는 점을 알고 조사 기록표의 꼬투리 칸에 숫자를 적은 뒤 평균값에 밑줄을 쳤다.
    3. 甲은 콩 꼬투리 스무 개를 까서 안에 든 알 수를 헤아려 표에 모았다. 한 꼬투리에 두세 알이 들어 있는 것을 확인하고 입수 칸의 평균을 계산해 넣고 최댓값과 최솟값도 함께 표시했다.
    4. 甲은 콩밭 1 m2 안에 서 있는 포기를 세어 밀도를 기록했다. 이 수가 수량 계산식의 맨 앞에 들어가는 요소라는 점을 식 옆에 굵은 글씨로 적어 두고 예시 숫자를 넣어 계산해 보았다.

    콩의 수량은 단위 면적당 개체수·개체당 꼬투리수·꼬투리당 입수·종실 무게로 결정된다. 등숙비율은 벼의 수량구성요소다.

    다음 설명에 해당하는 옥수수의 기원설은?

    염색체 수가 현재 재배 중인 종과 동일하고, 자성화서가 2열이고, 멕시코 지역에 분포하는 영년생식물이다.

    1. 1. 테오신트설
    2. 2. 가마그래스설
    3. 3. 야생유부종설
    4. 4. 자연교잡설

    정답 1번

    🔍 보기별 해설
    1. 테오신트는 멕시코 일대에 자생하는 야생 식물로 염색체 수가 재배 옥수수와 같고 자성화서가 2열이다. 제시된 세 조건을 모두 채우는 기원설이므로 옳다(정답).
    2. 가마그래스는 염색체 수가 재배 옥수수와 달라 교잡이 쉽지 않은 근연 식물이다. 염색체 수가 같다는 조건과 맞지 않으므로 옳지 않다.
    3. 야생유부종설은 옥수수의 조상이 이미 사라진 야생 유부 옥수수였다고 보는 가설이다. 멕시코에 분포하는 현존 식물이라는 조건과 맞지 않으므로 옳지 않다.
    4. 자연교잡설은 옥수수가 서로 다른 종 사이의 자연 교잡으로 생겼다고 보는 가설이다. 분포지와 염색체 수, 화서의 열수를 직접 가리키는 설명이 아니므로 옳지 않다.
    🧮 풀이
    1. 甲은 옥수수 기원설을 정리한 표에서 염색체 수와 분포지를 항목별로 비교했다. 멕시코에 자라고 염색체가 같은 야생 식물이 테오신트뿐인 것을 확인해 그 칸에 별표를 붙이고 근거 쪽수를 옆에 적었다.
    2. 甲은 옥수수와 가마그래스의 염색체 수를 나란히 적어 견주어 보았다. 두 숫자가 서로 다르다는 점에서 조건에 맞지 않음을 알고 가마그래스 칸에 가위표를 치고 이유를 짧게 써 두었다.
    3. 甲은 야생유부종설이 어떤 가정을 하는지 교재를 찾아 끝까지 읽었다. 이미 사라진 조상을 가정한다는 점을 알고 현존하는 식물을 요구한 조건 앞에서 이 가설을 제외하고 제외한 이유를 메모지에 적어 두었다.
    4. 甲은 자연교잡설의 요지를 한 줄로 요약해 단어 카드에 적었다. 분포지와 화서의 열수 같은 구체적인 조건을 가리키지 않는다는 점을 카드 뒷면에 메모로 덧붙이고 카드를 다른 가설 카드와 묶어 두었다.

    염색체 수가 같고 멕시코에 분포하며 자성화서가 2열인 야생 식물은 테오신트다. 가마그래스는 염색체 수가 달라 맞지 않는다.

    호밀에 대한 설명으로 옳지 않은 것은?

    1. 1. 밀과 근연종으로서 교잡이 가능하다.
    2. 2. 호밀은 화본과에 속한다.
    3. 3. 재배할 때 밀보다 추위에 강하다.
    4. 4. 건조한 사질의 척박지에서는 밀보다 적응성이 낮다.

    정답 4번

    🔍 보기별 해설
    1. 호밀은 밀과 근연종이어서 서로 교잡이 가능하고 두 작물을 교잡한 트리티케일이 알려져 있다. 근연 관계를 바르게 적었으므로 사실과 맞다.
    2. 호밀은 밀이나 보리와 같은 화본과 작물이다. 잎이 가늘고 길며 이삭이 줄기 끝에 달리는 화본과의 특징을 갖추었으므로 사실과 맞다.
    3. 호밀은 맥류 가운데 내한성이 가장 강해 추운 지방에서도 겨울을 난다. 재배할 때 밀보다 추위에 강하다는 서술이 사실과 맞다.
    4. 호밀은 뿌리가 깊고 넓게 뻗어 건조하고 척박한 사질토에서도 밀보다 잘 자란다. 밀보다 적응성이 낮다는 서술은 방향이 반대이므로 옳지 않다(정답).
    🧮 풀이
    1. 甲은 밀과 호밀을 교잡해 만든 새 작물의 소개 글을 읽었다. 두 작물이 근연종이라 교잡이 가능하다는 설명에 밑줄을 긋고 분류표에서 두 이름을 선으로 묶고 두 작물의 이삭 그림을 나란히 붙여 두었다.
    2. 甲은 밀과 호밀, 보리의 이삭과 잎 사진을 한 장에 모아 나란히 놓아 보았다. 셋 다 같은 과에 속한다는 표시를 하고 화본과 칸에 나란히 이름을 적어 넣고 밀과 호밀의 이삭 그림을 나란히 붙였다.
    3. 甲은 눈이 쌓인 겨울 논에서 푸르게 남아 있는 호밀 잎을 사진으로 찍었다. 잎이 누렇게 상한 옆 밭의 밀과 견주어 호밀의 내한성 서열을 노트에 적고 사진 날짜도 함께 써 두었다.
    4. 甲은 모래땅과 기름진 밭에 호밀과 밀을 나란히 심은 시험 결과를 표로 읽었다. 모래땅에서도 호밀의 수확량이 더 높은 수치를 확인하고 적응성 칸에 호밀을 위로 올리고 수치를 여백에 옮겨 적어 두었다.

    호밀은 밀보다 내한성과 척박지 적응성이 높다. 건조한 사질 척박지에서 밀보다 적응성이 낮다는 서술이 거꾸로다.

    불완전미에 대한 설명으로 옳은 것은?

    1. 1. 동할미: 조기재배 등으로 고온등숙할 때 약세영화에 많이 발생한다.
    2. 2. 심백미: 쌀알의 중심부가 백색인 불투명한 쌀이다.
    3. 3. 복백미: 표면이 우유빛처럼 백색인 불투명한 쌀이다.
    4. 4. 유백미: 쌀알의 가운데 복부가 백색으로 불투명하고, 품종의 특성과 환경의 영향으로 형성된다.

    정답 2번

    🔍 보기별 해설
    1. 동할미는 쌀알에 금이 가서 갈라진 쌀로 급하게 말리거나 수분이 급변할 때 생긴다. 고온 등숙 때 약세영화에 생기는 것은 다른 유형의 불완전미이므로 옳지 않다.
    2. 심백미는 쌀알의 중심부가 백색으로 불투명한 쌀이다. 이름 그대로 중심부의 백색 상태를 바르게 설명했으므로 옳다(정답).
    3. 복백미는 쌀알의 배 쪽, 곧 복부가 백색으로 불투명한 쌀이다. 표면이 우유빛처럼 하얗다는 설명은 유백미에 가까워 서로 바뀌어 있으므로 옳지 않다.
    4. 유백미는 쌀알 전체가 우유빛처럼 하얗게 불투명한 쌀이다. 가운데 복부가 백색이라는 설명은 복백미의 특징이므로 두 설명이 바뀐 서술이어서 옳지 않다.
    🧮 풀이
    1. 甲은 갈라진 쌀알이 섞인 백미를 보고 도정 공장에 원인을 물어보았다. 급하게 말린 벼에서 이런 알이 생긴다는 설명을 듣고 건조 온도를 낮추는 방법을 메모해 두고 갈라진 알의 사진도 찍어 두었다.
    2. 甲은 쌀알을 반으로 잘라 속을 들여다보다 가운데만 하얗게 흐린 알을 골라냈다. 이 알이 심백미라는 설명을 읽고 사진을 찍어 불완전미 도감의 해당 쪽에 붙이고 단면 그림을 옆에 그려 넣었다.
    3. 甲은 불완전미 사진 여섯 종을 나열하고 이름을 붙이다 복백미 사진을 유백미 칸에 잘못 넣었다. 배 쪽이 하얀 알이라는 기준에 맞춰 사진을 제자리로 옮기고 두 견본의 차이를 한 줄로 적어 두었다.
    4. 甲은 쌀알 전체가 우유빛으로 뿌연 견본과 가운데만 하얀 견본을 같은 줄에 놓았다. 두 이름이 서로 바뀌어 쓰이지 않도록 견본 앞의 칸 이름을 큰 글씨로 고쳐 적고 견본 사진을 다시 찍어 두었다.

    심백미는 쌀알 중심부가 백색으로 불투명한 쌀이다. 복백미와 유백미의 설명은 서로 바뀌어 있고 동할미 설명도 틀렸다.

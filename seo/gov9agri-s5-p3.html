    콩에 대한 설명으로 옳지 않은 것은?

    1. 1. 자엽은 발아할 때 가장 먼저 나오는 2장의 잎이다.
    2. 2. 뿌리혹의 표피세포 안쪽에 후막세포층이 있다.
    3. 3. 유한신육형은 대부분의 마디에서 수일 내 동시에 꽃이 핀다.
    4. 4. 무한신육형은 중심줄기 위쪽 마디에서 꽃이 피기 시작하여 점차 아래쪽 마디로 피어 간다.

    정답 4번

    🔍 보기별 해설
    1. 자엽은 발아할 때 가장 먼저 땅 위로 나오는 두 장의 떡잎이다. 콩은 자엽이 지상으로 올라오는 지상 발아를 하므로 옳다.
    2. 콩의 뿌리혹은 바깥 표피세포 안쪽에 후막세포층을 두어 안쪽의 뿌리혹균이 든 조직을 감싼다. 뿌리혹의 구조를 바르게 적었으므로 옳다.
    3. 유한신육형은 줄기 끝에 꽃송이가 달려 생장이 멈추므로 대부분의 마디에서 며칠 안에 거의 동시에 꽃이 핀다. 개화 방식을 바르게 적었으므로 옳다.
    4. 무한신육형은 줄기 끝이 계속 자라므로 중간 이하 아래쪽 마디에서 먼저 꽃이 피기 시작해 위쪽으로 올라가며 핀다. 위쪽에서 아래쪽으로 핀다는 서술은 순서가 거꾸로이므로 옳지 않다(정답).
    🧮 풀이
    1. 콩 육종가 A가 발아한 씨앗에서 처음 나온 잎 두 장을 살폈다. 자엽이 흙 위로 올라와 어린 식물에 양분을 공급했다. 뒤에 나오는 본엽과 구별해 표본에 표시했다.
    2. 뿌리혹 연구원 B가 콩 뿌리의 혹을 가로로 잘랐다. 바깥 표피세포 안쪽에 후막세포층이 보였다. 안쪽의 뿌리혹균 조직을 둘러싼 층을 그림으로 기록했다. 절단면의 층별 위치를 따라 조직을 분리했다.
    3. 콩 농가 C가 유한신육형 품종의 각 마디에 표식을 달았다. 줄기 끝의 생장이 멈춘 뒤 여러 마디에서 며칠 사이 꽃이 피었다. 개화가 비교적 한꺼번에 이루어져 수확 시기를 예상하기 쉬웠다.
    4. 시험포 담당자 D가 무한신육형 콩의 개화 위치를 매일 적었다. 아래쪽과 중간 마디에서 먼저 꽃이 피고 계속 자라는 윗마디로 올라갔다. 위에서 아래로 내려간다는 기록을 바로잡았다. 늦게 핀 위쪽 꽃은 아래쪽보다 성숙도 늦었다.

    무한신육형은 중간 이하 마디에서 먼저 꽃이 피어 위쪽으로 올라간다. 위쪽에서 아래로 핀다는 서술이 거꾸로다.

    콩의 수량 구성요소에 해당하지 않는 것은?

    1. 1. 등숙비율
    2. 2. 개체당 꼬투리수
    3. 3. 꼬투리당 평균입수
    4. 4. 단위 면적당 개체수

    정답 1번

    🔍 보기별 해설
    1. 등숙비율은 벼의 영화 가운데 알이 찬 비율로 벼 수량을 계산할 때 쓴다. 콩의 대표 수량구성요소로 든 것이므로 옳지 않다(정답).
    2. 개체당 꼬투리수는 콩 한 포기에 실제로 맺힌 꼬투리의 총수이다. 꼬투리가 늘면 전체 수량에 영향을 주므로 옳다.
    3. 꼬투리당 평균입수는 한 꼬투리 안에 들어 있는 종실인 콩알 수의 평균이다. 알 수가 전체 수량에 영향을 주므로 옳다.
    4. 단위 면적당 개체수는 일정 면적에 자리 잡아 수확할 수 있는 콩 포기 수이다. 수량 계산의 바탕이 되므로 옳다.
    🧮 풀이
    1. 벼 수량 연구원 A가 영화 가운데 알이 찬 비율을 계산했다. 이 등숙비율을 벼의 수량 분석표에 넣었다. 콩의 포기 수와 꼬투리 수를 세는 표와 구분했다. 따라서 벼의 영화 수를 콩의 꼬투리 수로 바꾸어 세지 않았다.
    2. 콩 농가 B가 수확 전 표본 포기의 꼬투리를 하나씩 셌다. 포기마다 꼬투리 수가 달라 예상 수량도 달라졌다. 개체당 꼬투리수를 수량 계산 장부에 적었다. 포기당 꼬투리 수의 평균을 구해 면적 수량에 곱했다.
    3. 육종가 C가 콩 꼬투리를 열어 알곡을 세었다. 한 꼬투리의 평균 알 수를 구했다. 포기 수와 꼬투리 수가 같아도 입수가 많으면 전체 종실 수가 늘었다. 꼬투리당 평균입수를 계산에 따로 반영했다.
    4. 시험포 담당자 D가 1㎡ 안에 선 콩 포기를 셌다. 같은 포기당 수량이라도 심어진 포기 수가 다른 구역의 총수량은 달랐다. 단위 면적당 개체수를 수량 계산의 첫 값으로 썼다.

    콩의 수량은 단위 면적당 개체수·개체당 꼬투리수·꼬투리당 입수·종실 무게로 결정된다. 등숙비율은 벼의 수량구성요소다.

    다음 설명에 해당하는 옥수수의 기원설은?

    염색체 수가 현재 재배 중인 종과 동일하고, 자성화서가 2열이고, 멕시코 지역에 분포하는 영년생식물이다.

    1. 1. 테오신트설
    2. 2. 가마그래스설
    3. 3. 야생유부종설
    4. 4. 자연교잡설

    정답 1번

    🔍 보기별 해설
    1. 테오신트는 멕시코 일대에 자생하는 야생 식물로 염색체 수가 재배 옥수수와 같고 자성화서가 2열이다. 제시된 세 조건을 모두 채우는 기원설이므로 옳다(정답).
    2. 가마그래스는 염색체 수가 재배 옥수수와 달라 교잡이 쉽지 않은 근연 식물이다. 염색체 수가 같다는 조건과 맞지 않으므로 옳지 않다.
    3. 야생유부종설은 옥수수의 조상이 이미 사라진 야생 유부 옥수수였다고 보는 가설이다. 멕시코에 분포하는 현존 식물이라는 조건과 맞지 않으므로 옳지 않다.
    4. 자연교잡설은 옥수수가 서로 다른 종 사이의 자연 교잡으로 생겼다고 보는 가설이다. 분포지와 염색체 수, 화서의 열수를 직접 가리키는 설명이 아니므로 옳지 않다.
    🧮 풀이
    1. 옥수수 기원 연구원 A가 멕시코의 테오신트 표본을 살폈다. 재배 옥수수와 염색체 수가 같고 자성화서가 두 줄이었다. 세 특징을 근거로 테오신트설을 기원 가설에 올렸다.
    2. 식물학 담당자 B가 가마그래스 표본의 염색체를 세었다. 재배 옥수수와 수가 달라 직접 같은 조건으로 묶기 어려웠다. 제시된 기원설의 염색체 조건과 비교해 제외했다.
    3. 육종 연구원 C가 야생유부종설의 설명을 읽었다. 이미 사라진 야생의 유부 옥수수를 조상으로 보는 가설이었다. 지금 멕시코에 분포하는 영년생 표본을 가리키는 설명과 달랐다.
    4. 작물학 학생 D가 자연교잡설의 계보도를 그렸다. 서로 다른 종의 교잡을 통해 재배 옥수수가 생겼다는 경로였다. 현존 식물 하나의 염색체 수와 자성화서 열수를 직접 묘사한 가설과 구분했다.

    염색체 수가 같고 멕시코에 분포하며 자성화서가 2열인 야생 식물은 테오신트다. 가마그래스는 염색체 수가 달라 맞지 않는다.

    호밀에 대한 설명으로 옳지 않은 것은?

    1. 1. 밀과 근연종으로서 교잡이 가능하다.
    2. 2. 호밀은 화본과에 속한다.
    3. 3. 재배할 때 밀보다 추위에 강하다.
    4. 4. 건조한 사질의 척박지에서는 밀보다 적응성이 낮다.

    정답 4번

    🔍 보기별 해설
    1. 호밀은 밀과 근연종이어서 서로 교잡이 가능하고 두 작물을 교잡한 트리티케일이 알려져 있다. 근연 관계를 바르게 적었으므로 옳다.
    2. 호밀은 밀이나 보리와 같은 화본과 작물이다. 잎이 가늘고 길며 이삭이 줄기 끝에 달리는 화본과의 특징을 갖추었으므로 옳다.
    3. 호밀은 맥류 가운데 내한성이 가장 강해 추운 지방에서도 겨울을 난다. 재배할 때 밀보다 추위에 강하다는 서술이 옳다.
    4. 호밀은 뿌리가 깊고 넓게 뻗어 건조하고 척박한 사질토에서도 밀보다 잘 자란다. 밀보다 적응성이 낮다는 서술은 방향이 반대이므로 옳지 않다(정답).
    🧮 풀이
    1. 밀 육종가 A가 밀과 호밀을 교잡했다. 두 작물의 형질을 함께 지닌 트리티케일을 얻었다. 서로 근연인 두 작물이 교잡될 수 있음을 계보에 남겼다. 교잡 자손의 염색체 상태도 함께 살폈다. 교잡 자손에서 두 부모의 형질이 함께 나타났다.
    2. 작물 표본 담당자 B가 호밀의 잎과 이삭을 관찰했다. 좁고 긴 잎과 줄기 끝의 이삭이 화본과 맥류의 형태를 보였다. 밀ㆍ보리 표본 옆에 호밀을 분류했다. 겨울을 넘긴 뒤에도 이삭이 정상적으로 형성됐다.
    3. 호밀 농가 C가 추운 지역에 호밀과 밀을 심었다. 겨울을 지난 뒤 호밀의 포기가 더 안정적으로 살아남았다. 내한성이 강한 맥류로 다음 재배 품종을 골랐다. 밀이 약해진 포장에서도 호밀의 생육이 이어졌다.
    4. 재배자 D가 건조한 사질의 척박지에 호밀과 밀을 시험 재배했다. 호밀은 깊고 넓게 뻗은 뿌리로 물과 양분을 찾았다. 밀보다 나쁜 적응성을 보일 것이라는 예상과 달리 호밀이 잘 자랐다.

    호밀은 밀보다 내한성과 척박지 적응성이 높다. 건조한 사질 척박지에서 밀보다 적응성이 낮다는 서술이 거꾸로다.

    불완전미에 대한 설명으로 옳은 것은?

    1. 1. 동할미: 조기재배 등으로 고온등숙할 때 약세영화에 많이 발생한다.
    2. 2. 심백미: 쌀알의 중심부가 백색인 불투명한 쌀이다.
    3. 3. 복백미: 표면이 우유빛처럼 백색인 불투명한 쌀이다.
    4. 4. 유백미: 쌀알의 가운데 복부가 백색으로 불투명하고, 품종의 특성과 환경의 영향으로 형성된다.

    정답 2번

    🔍 보기별 해설
    1. 동할미는 쌀알에 금이 가서 갈라진 쌀로 급하게 말리거나 수분이 급변할 때 생긴다. 고온 등숙 때 약세영화에 생기는 것은 다른 유형의 불완전미이므로 옳지 않다.
    2. 심백미는 쌀알의 중심부가 백색으로 불투명한 쌀이다. 이름 그대로 중심부의 백색 상태를 바르게 설명했으므로 옳다(정답).
    3. 복백미는 쌀알의 배 쪽, 곧 복부가 백색으로 불투명한 쌀이다. 표면이 우유빛처럼 하얗다는 설명은 유백미에 가까워 서로 바뀌어 있으므로 옳지 않다.
    4. 유백미는 쌀알 전체가 우유빛처럼 하얗게 불투명한 쌀이다. 가운데 복부가 백색이라는 설명은 복백미의 특징이므로 두 설명이 바뀐 서술이어서 옳지 않다.
    🧮 풀이
    1. 도정장 담당자 A가 급하게 말린 쌀알을 빛에 비춰 봤다. 내부에 금이 가서 동할미가 생겼다. 고온 등숙 때 약세영화에서 생긴 흰 낟알과 발생 원인을 구분했다. 갈라진 쌀알은 도정 과정에서 더 쉽게 부서졌다.
    2. 쌀 품질 검사원 B가 낟알의 가운데를 확대했다. 중심 부분이 흰색으로 불투명했다. 흰 부분의 위치를 기준으로 심백미로 기록했다. 바깥쪽의 투명한 부분과 중심부가 뚜렷이 달랐다.
    3. 곡물 연구원 C가 배 쪽이 하얀 낟알과 전체 표면이 우유빛인 낟알을 나눴다. 앞의 낟알은 복백미였다. 전체가 뿌연 유백미와 혼동하지 않도록 표본 사진을 붙였다. 흰 부분의 위치를 기준으로 두 유형을 나눴다.
    4. 품질 담당자 D가 표면 전체가 우유빛인 쌀알을 살폈다. 한쪽 복부만 흰 낟알과 달리 전체가 불투명했다. 유백미를 복백미 상자에서 분리했다. 가공용 선별기에서도 전체의 빛 투과도가 낮았다.

    심백미는 쌀알 중심부가 백색으로 불투명한 쌀이다. 복백미와 유백미의 설명은 서로 바뀌어 있고 동할미 설명도 틀렸다.

    논토양의 특성과 대책으로 옳지 않은 것은?

    1. 1. 미숙답은 논의 개답 역사가 짧고 배수가 불량한 논을 말한다.
    2. 2. 습답은 지하수위를 낮추고 미숙 유기물의 시용을 늘리는 것이 좋다.
    3. 3. 사질답에는 비료를 분시하고 완효성 비료를 주는 것이 좋다.
    4. 4. 염해답은 관개수를 자주 공급하여 제염하고 석회 등을 시용하여 개량할 수 있다.

    정답 2번

    🔍 보기별 해설
    1. 미숙답은 논으로 개간한 지 오래되지 않고 배수가 나빠 토양이 아직 익지 못한 논이다. 미숙답의 정의를 바르게 적었으므로 옳다.
    2. 습답은 지하수위를 낮추는 것은 옳지만 미숙 유기물을 늘리면 분해 중 유해 가스가 생겨 뿌리가 상한다. 미숙 유기물을 줄여야 하므로 시용을 늘리라는 서술은 옳지 않다(정답).
    3. 사질답은 물과 양분이 빠져나가기 쉬워 비료를 나누어 주고 서서히 녹는 완효성 비료를 쓰는 것이 좋다. 알맞은 대책이므로 옳다.
    4. 염해답은 관개수를 자주 대어 염분을 씻어 내고 석회 등을 써 개량한다. 제염과 개량 방법을 바르게 적었으므로 옳다.
    🧮 풀이
    1. 토양 조사원 A가 새로 개간한 논을 살폈다. 논으로 쓴 기간이 짧고 배수도 불량했다. 충분히 익지 않은 미숙답으로 기록하고 배수 개선을 먼저 검토했다. 배수로를 만든 뒤 물 고임이 줄어드는지 확인했다. 배수 뒤 포기의 뿌리가 새로 뻗으며 생육이 나아졌다.
    2. 습답 관리자 B가 지하수위를 낮추는 배수로를 만들었다. 덜 썩은 볏짚을 한꺼번에 넣은 곳에서는 뿌리가 갈변하고 새 줄기도 적게 나왔다. 다음 작기에는 충분히 썩힌 퇴비를 써 벼의 뿌리 회복을 도왔다.
    3. 사질답 농가 C가 한꺼번에 비료를 많이 주지 않았다. 나누어 시비하고 천천히 녹는 비료를 써 양분이 씻겨 내려가는 일을 줄였다. 작물 생육 동안 공급이 이어졌다.
    4. 염해답 재배자 D가 관개수를 여러 차례 대어 염분을 씻어 냈다. 필요한 구역에는 석회 자재도 넣었다. 토양 검사를 반복해 제염과 개량 효과를 확인했다. 관개 뒤 배출수의 염분도 다시 측정했다.

    습답은 미숙 유기물을 줄이고 배수를 개선해야 한다. 미숙 유기물을 늘리라는 서술이 틀렸다.

    옥수수의 분류에 대한 설명으로 옳은 것은?

    1. 1. 마치종은 정부가 각질이고 측면은 연질로, 수분이 적어지면 정부가 수축한다.
    2. 2. 폭렬종은 종실이 굵고 대부분 연질로, 잘 튀겨지며 식용에 이용된다.
    3. 3. 감미종은 동화물질인 당류가 전분으로 전환되는 것을 억제하는 유전자를 갖고 있다.
    4. 4. 나종은 아밀로펙틴함량이 78 % 정도인 연질의 전분으로 되어 있고 유백색으로 불투명하다.

    정답 3번

    🔍 보기별 해설
    1. 마치종은 종실 정부가 연질이고 측면이 각질이어서 수분이 줄면 정부가 움푹 들어간다. 정부가 각질이고 측면이 연질이라는 서술은 반대이므로 옳지 않다.
    2. 폭렬종은 종실이 작고 단단한 각질이 대부분이어서 가열하면 압력이 올라 잘 튀겨진다. 종실이 굵고 대부분 연질이라는 서술은 옳지 않다.
    3. 감미종은 당이 전분으로 바뀌는 과정을 막는 유전자를 가져 당분이 그대로 쌓여 단맛이 난다. 유전자의 작용을 바르게 적었으므로 옳다(정답).
    4. 나종(찰옥수수)은 전분이 거의 아밀로펙틴으로 이루어져 있어 찰기가 강하다. 아밀로펙틴 함량이 78 % 정도라는 서술은 수치가 맞지 않으므로 옳지 않다.
    🧮 풀이
    1. 옥수수 종자 연구원 A가 마치종 낟알의 윗부분을 잘랐다. 정부의 연질 부분이 마르며 움푹 들어갔고 옆은 단단했다. 정부가 각질이라는 설명과 실제 구조를 비교했다.
    2. 품질 담당자 B가 폭렬종 옥수수 낟알을 가열했다. 작고 단단한 종실 내부의 압력이 올라 갑자기 튀었다. 크고 대부분 연질인 낟알을 팝콘 원료로 분류하지 않았다. 튀긴 뒤 낟알의 팽창 정도도 비교했다.
    3. 감미종 육종가 C가 익어 가는 낟알의 당을 분석했다. 유전자의 작용으로 당이 전분으로 바뀌는 과정이 억제됐다. 낟알에 당이 남아 단맛이 강했다. 달게 익은 낟알을 생식용으로 수확했다.
    4. 찰옥수수 연구원 D가 나종의 전분을 검사했다. 아밀로펙틴이 거의 대부분을 차지해 쫀득한 식감이 나타났다. 함량을 78% 정도로 적은 표를 수정했다. 찐 뒤의 식감도 일반 옥수수와 비교했다.

    감미종은 당이 전분으로 바뀌는 것을 막는 유전자를 가져 당분이 그대로 쌓인다.

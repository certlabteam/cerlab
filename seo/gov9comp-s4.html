    대표적인 반도체 메모리인 DRAM과 SRAM에 대한 설명으로 옳지 않은 것은?

    1. 1. DRAM은 휘발성이지만 SRAM은 비휘발성이어서 전원이 공급되지 않아도 기억을 유지할 수 있다.
    2. 2. DRAM은 축전기(Capacitor)의 충전상태로 비트를 저장한다.
    3. 3. SRAM은 주로 캐시 메모리로 사용된다.
    4. 4. 일반적으로 SRAM의 접근속도가 DRAM보다 빠르다.

    정답 1번

    🔍 보기별 해설
    1. DRAM과 SRAM은 모두 전원이 꺼지면 내용을 잃는 휘발성 메모리이고 전원 없이 기억을 유지하는 것은 ROM이나 플래시이므로, SRAM이 비휘발성이라는 이 보기는 옳지 않다(정답).
    2. DRAM은 축전기에 전하를 채우고 비우는 방식으로 비트를 저장하고 전하가 서서히 새므로 주기적으로 재충전해야 하는 메모리이므로 이 보기는 옳다.
    3. SRAM은 플립플롭으로 구성돼 속도가 빠르지만 비싸고 집적도가 낮아 소용량 고속 메모리인 캐시 메모리에 주로 쓰이므로 이 보기는 옳다.
    4. SRAM은 재충전 없이 값을 바로 읽고 쓰는 구조여서 일반적으로 DRAM보다 접근 속도가 빠르고 그 때문에 캐시에 쓰이므로 이 보기는 옳다.
    🧮 풀이
    1. 甲은 전원 코드를 뽑았다가 다시 꽂은 뒤 저장하지 않은 작업이 사라져 당황한 직원이다. 주기억장치도 캐시도 전원이 끊기면 내용을 잃는다는 설명을 듣고 습관적으로 저장 버튼을 누르게 되었다.
    2. 甲은 컴퓨터 구조 수업에서 주기억장치가 작은 축전기에 전하를 담아 비트를 표현하는 방식임을 배운 학생이다. 전하가 새기 전에 주기적으로 다시 채워 줘야 한다는 설명이 인상 깊었다.
    3. 甲은 중앙처리장치 바로 옆에 붙어 있는 작고 빠른 메모리의 가격을 알아본 구매 담당자다. 용량이 작은데도 값이 비싸다는 점을 확인하고 이것이 캐시에 쓰이는 이유임을 이해했다.
    4. 甲은 두 메모리의 응답 시간을 측정해 보는 실습에서 재충전이 필요 없는 쪽이 값을 더 빨리 내놓는 것을 확인한 학생이다. 빠른 쪽이 캐시에 쓰인다는 설명이 자연스럽게 이해되었다.

    SRAM도 전원이 끊기면 내용을 잃는 휘발성 메모리이므로 비휘발성이라고 한 1번이 옳지 않다.

    정렬 알고리즘 중 최악의 경우를 가정할 때 시간복잡도가 다른 것은?

    1. 1. 삽입 정렬(Insertion sort)
    2. 2. 쉘 정렬(Shell sort)
    3. 3. 버블 정렬(Bubble sort)
    4. 4. 힙 정렬(Heap sort)

    정답 4번

    🔍 보기별 해설
    1. 삽입 정렬은 입력이 역순일 때 원소마다 앞의 원소를 전부 비교하며 옮겨 최악에 n(n-1)/2번 걸려 O(n²)이므로, 나머지와 같은 부류라 시간복잡도가 다른 것에 해당하지 않는다.
    2. 쉘 정렬은 간격을 두고 삽입 정렬을 반복하는 방식으로 일반적인 교재에서 최악의 시간복잡도를 O(n²)으로 다루므로, 삽입·버블과 같은 부류라 다른 것에 해당하지 않는다.
    3. 버블 정렬은 이웃한 원소를 비교해 교환하는 과정을 반복하며 최악에 n(n-1)/2번 비교하므로 O(n²)이라, 삽입·쉘과 같은 부류이므로 다른 것에 해당하지 않는다.
    4. 힙 정렬은 힙을 만든 뒤 최댓값을 꺼내는 과정이 높이 log n에 비례해 입력 순서와 상관없이 최악에도 O(n log n)이므로 나머지 셋과 다른 것에 해당한다(정답).
    🧮 풀이
    1. 甲은 역순으로 정렬된 명단을 한 명씩 앞으로 끼워 넣는 실습을 한 학생이다. 뒤로 갈수록 옮겨야 할 사람이 늘어나 시간이 제곱에 가깝게 늘어난다는 사실을 몸으로 확인했다. 그래서 정렬 대상이 두 배가 되면 시간은 네 배가 된다고 정리했다.
    2. 甲은 일정한 간격으로 떨어진 원소끼리 먼저 정렬하고 간격을 줄여 가는 방법을 배운 학생이다. 교재에서 이 방법의 최악 시간을 제곱으로 소개한 것을 표에 옮겨 적었다. 표에는 삽입과 버블도 같은 제곱 부류로 묶어 두었다.
    3. 甲은 옆 사람과 키를 비교해 자리를 바꾸는 놀이를 반복하며 줄을 세운 교사다. 가장 큰 아이가 맨 끝으로 가기까지 여러 번 비교해야 하므로 시간이 제곱으로 늘어난다고 설명했다.
    4. 甲은 우선순위가 높은 일부터 꺼내 처리하는 당직 시스템을 설계한 개발자다. 트리 구조라 어떤 순서로 들어와도 처리 시간이 로그에 비례해 안정적이라는 점을 동료에게 설명했다.

    힙 정렬은 최악의 경우에도 시간복잡도가 O(n log n)이고 나머지 셋은 O(n²)이므로 4번이 해당한다.

    기계 학습에서 지도 학습과 비지도 학습에 대한 설명으로 옳은 것은?

    1. 1. 지도 학습의 대표적인 기법에는 군집화가 있다.
    2. 2. 비지도 학습의 기법에는 분류와 회귀분석 등이 있다.
    3. 3. 지도 학습은 학습 알고리즘이 수행한 행동에 대해 보상을 받는 학습 방식이다.
    4. 4. 비지도 학습은 정답이 없는 데이터를 보고 유용한 패턴을 추출하는 학습 방식이다.

    정답 4번

    🔍 보기별 해설
    1. 군집화는 정답 표시가 없는 데이터를 비슷한 것끼리 묶는 방법으로 비지도 학습의 대표 기법이므로, 이를 지도 학습의 대표 기법이라 한 이 보기는 옳지 않다.
    2. 분류와 회귀분석은 입력과 정답이 짝지어진 데이터로 규칙을 익혀 예측하는 지도 학습의 기법이므로, 이를 비지도 학습의 기법이라 한 이 보기는 옳지 않다.
    3. 행동에 대해 보상을 받으며 보상을 최대화하도록 배우는 방식은 강화 학습이고 정답이 아닌 보상을 신호로 삼으므로, 이를 지도 학습이라 한 이 보기는 옳지 않다.
    4. 비지도 학습은 정답이 붙어 있지 않은 데이터를 보고 숨은 구조나 유용한 패턴을 스스로 찾아내는 학습 방식이므로 이 보기는 옳다(정답).
    🧮 풀이
    1. 甲은 손님들의 구매 기록을 묶어 비슷한 취향의 집단으로 나누는 분석가다. 미리 정해 둔 정답 없이 데이터만으로 집단을 만들었으므로 지도 학습이 아니라 비지도 학습을 쓴 것이다.
    2. 甲은 이메일에 스팸이라는 꼬리표가 붙은 자료로 새 메일을 분류하는 프로그램을 만든 학생이다. 정답이 딸린 자료로 배우는 이 방식이 지도 학습임을 발표에서 설명했다. 스팸과 정상 메일 각각의 정답 표시가 있기 때문이라고 덧붙였다.
    3. 甲은 게임 속 캐릭터가 점수를 얻는 행동을 스스로 찾아가도록 훈련시킨 연구자다. 점수라는 보상을 최대로 만드는 이 방식은 지도 학습과 다른 강화 학습이라고 정리했다. 정답표 없이 시행착오로 배우는 점이 다르다고 덧붙였다.
    4. 甲은 라벨이 없는 고객 상담 기록에서 자주 나타나는 문의 유형을 찾아내는 일을 맡은 분석가다. 정답 없이 데이터에서 패턴을 뽑는 작업이라 비지도 학습에 해당한다고 보고했다.

    비지도 학습은 정답이 없는 데이터에서 유용한 패턴을 찾는 방식이므로 4번이 옳다.

    무선주파수를 이용하며 반도체 칩이 내장된 태그와 리더기로 구성된 인식시스템은?

    1. 1. RFID
    2. 2. WAN
    3. 3. Bluetooth
    4. 4. ZigBee

    정답 1번

    🔍 보기별 해설
    1. RFID는 반도체 칩이 들어 있는 태그와 무선주파수로 그 정보를 읽는 리더기로 구성돼 사물을 식별하는 시스템이므로 설명에 해당한다(정답).
    2. 광역 통신망은 넓은 지역의 컴퓨터를 전용선이나 공중망으로 연결하는 통신망이며 태그와 리더기로 이루어진 인식시스템이 아니므로 설명에 해당하지 않는다.
    3. 블루투스는 가까운 거리의 기기를 무선으로 연결해 자료를 주고받는 근거리 무선 통신 기술이며 사물 식별용 태그·리더기 체계가 아니므로 설명에 해당하지 않는다.
    4. 지그비는 전력 소모가 적은 근거리 무선망 규격으로 센서 네트워크에 쓰이며 반도체 태그를 읽는 인식시스템이 아니므로 설명에 해당하지 않는다.
    🧮 풀이
    1. 甲은 물류창고에서 상자에 붙은 작은 칩을 통로의 장치가 한꺼번에 읽어 재고를 파악하는 시스템을 도입한 관리자다. 바코드와 달리 무선으로 읽어 시간이 크게 줄었다. 그래서 재고 조사에 걸리던 이틀이 몇 시간으로 줄었다.
    2. 甲은 서울과 부산의 지점 전산망을 통신사 회선으로 이어 하나의 망처럼 쓰게 한 네트워크 담당자다. 넓은 지역을 잇는 이 망은 칩이 든 태그를 읽는 시스템과는 다르다. 두 시스템은 이름만 통신망일 뿐 용도가 전혀 다르다.
    3. 甲은 스마트폰과 무선 이어폰을 연결해 음악을 듣는 대학생이다. 가까운 거리에서 두 기기를 무선으로 이어 주는 기술일 뿐 물건에 붙은 칩을 읽는 인식시스템은 아니라고 설명했다.
    4. 甲은 집 안의 조명과 온도 센서를 낮은 전력으로 서로 연결하는 스마트홈 기술자다. 여러 센서가 그물처럼 통신하는 이 방식은 태그와 리더기 방식과 구분된다고 정리했다. 그래도 사물 식별을 위한 방식은 아니라고 덧붙였다.

    무선주파수로 태그와 리더기가 통신하는 인식시스템은 RFID이므로 1번이 해당한다.

    클라우드 컴퓨팅에 대한 설명으로 옳지 않은 것은?

    1. 1. 클라우드 컴퓨팅은 기업의 IT 요구를 매우 경제적이고, 신뢰성 있게 충족시킬 수 있는 수단이 된다.
    2. 2. 클라우드 컴퓨팅 서비스 모델에는 IaaS, PaaS, SaaS가 있다.
    3. 3. 클라우드 컴퓨팅을 이용하는 방식에는 사설 클라우드, 공용 클라우드, 하이브리드 클라우드가 있다.
    4. 4. IaaS를 통해 사용자는 소프트웨어 설치 및 유지보수에 대한 비용을 절감할 수 있다.

    정답 4번

    🔍 보기별 해설
    1. 클라우드 컴퓨팅은 필요한 만큼 빌려 쓰고 관리를 서비스 제공자에게 맡길 수 있어 기업의 정보기술 요구를 경제적이고 안정적으로 충족시키는 수단이므로 이 보기는 옳다.
    2. 클라우드 컴퓨팅의 서비스 모델은 서버와 저장소를 빌려 주는 인프라형, 개발 환경을 빌려 주는 플랫폼형, 완성된 소프트웨어를 빌려 주는 소프트웨어형이므로 이 보기는 옳다.
    3. 클라우드는 한 기업이 자체로 운영하는 사설, 여러 사용자가 함께 쓰는 공용, 둘을 섞은 하이브리드 방식으로 이용하므로 이 보기는 옳다.
    4. 인프라형 서비스는 서버와 저장소 같은 자원을 빌려 주며 소프트웨어 설치와 유지보수는 여전히 사용자 몫이고 그 부담을 덜어 주는 것은 서비스형이므로 이 보기는 옳지 않다(정답).
    🧮 풀이
    1. 甲은 자체 서버실 대신 필요한 만큼만 사용료를 내는 방식으로 전산을 옮긴 중소기업 사장이다. 초기 투자비가 줄고 장애 걱정도 덜어 기업의 요구를 경제적으로 채웠다고 평가했다.
    2. 甲은 클라우드 서비스를 종류별로 표로 정리하는 강의 조교다. 빌려 주는 대상이 서버·저장소인지, 개발 도구인지, 완성된 프로그램인지에 따라 세 가지로 나뉜다고 설명했다. 각 서비스를 쓰면 사용자가 관리할 범위가 달라진다고 덧붙였다.
    3. 甲은 보안이 중요한 자료는 회사 안에 두고 나머지는 외부 서비스를 쓰는 방식을 정한 정보 담당자다. 두 방식을 섞어 쓰는 이 형태가 하이브리드 클라우드라고 보고서에 적었다.
    4. 甲은 가상 서버를 빌려 운영체제부터 직접 설치하고 보안 패치까지 챙기는 개발자다. 프로그램 설치와 관리 부담이 여전히 자기 몫이라 이를 덜어 주는 것은 다른 서비스 형태임을 알았다.

    TCP(Transmission Control Protocol) 기반 응용 프로토콜에 해당하지 않는 것은?

    2. 2. FTP
    3. 3. SMTP
    4. 4. SNMP

    정답 4번

    🔍 보기별 해설
    1. Telnet은 원격 접속을 위해 신뢰성 있는 연결이 필요해 TCP 위에서 동작하는 응용 프로토콜이므로 TCP 기반이 아닌 것에 해당하지 않는다.
    2. FTP는 파일을 안전하게 주고받기 위해 TCP 연결을 맺고 동작하는 응용 프로토콜이므로 TCP 기반이 아닌 것에 해당하지 않는다.
    3. SMTP는 전자메일을 서버로 보내기 위해 TCP 연결을 이용하는 응용 프로토콜이므로 TCP 기반이 아닌 것에 해당하지 않는다.
    4. SNMP는 네트워크 장비를 관리하기 위한 프로토콜로 가벼운 요청과 응답을 주고받는 UDP 위에서 동작하므로 TCP 기반이 아니어서 설명에 해당한다(정답).
    🧮 풀이
    1. 甲은 서버에 원격으로 접속해 명령을 입력하는 시스템 관리자다. 연결이 끊기지 않고 신뢰성 있게 이어져야 하므로 연결 지향 전송 방식 위에서 이 접속 프로그램이 동작한다고 알았다.
    2. 甲은 웹 서버에 홈페이지 파일을 올리는 작업을 하는 개발자다. 파일이 중간에 손상되지 않도록 연결을 맺고 전송하는 방식이라 티씨피를 쓴다는 것을 배웠다. 파일이 깨지면 처음부터 다시 올려야 하므로 신뢰성이 필수였다.
    3. 甲은 메일을 서버로 보내는 프로그램을 개발한 신입사원이다. 메일이 유실되면 안 되므로 연결을 먼저 맺고 순서대로 전달하는 방식을 쓴다고 설계서에 적었다. 메일이 중간에 사라지면 곤란하기 때문이었다.
    4. 甲은 수백 대 장비의 상태를 주기적으로 수집하는 관리 시스템을 운영하는 담당자다. 가벼운 요청과 응답만 오가므로 연결 없이 보내는 방식을 쓴다는 것을 알게 되었다. 재전송을 기다리기보다 다음 주기에 다시 묻는 편이 낫기 때문이다.

    SNMP은 전송 계층에서 UDP를 쓰므로 TCP 기반 응용 프로토콜이 아닌 4번이 해당한다.

    운영체제에서 프로세스의 정보를 관리하는 프로세스 제어블록(Process Control Block)의 포함 요소로 옳지 않은 것은?

    3. 甲은 중요한 작업을 먼저 실행해야 하는 서버를 운영하는 관리자다. 실행 순서를 정하려면 우선순위 값이 필요하고 이것이 제어블록에 담겨 있다는 것을 알았다. 우선순위가 높은 프로세스가 먼저 자원을 받는 것도 확인했다.

    SSD(Solid-State Drive)에 대한 설명으로 옳지 않은 것은?

    1. 1. 반도체 기억장치 칩들을 이용하여 구성된 저장장치이다.
    2. 2. 하드디스크에 비해 저장용량 대비 가격이 비싸다.
    3. 3. 기계적 장치를 사용하여 하드디스크보다 데이터 입출력 속도가 빠르다.
    4. 4. 하드디스크를 대체하려고 개발한 저장장치로서 플래시 메모리로 구성된다.

    정답 3번

    🔍 보기별 해설
    1. SSD는 플래시 같은 반도체 기억장치 칩을 여러 개 모아 기판에 구성한 저장장치로 회전하는 판이나 헤드 같은 움직이는 부품이 없으므로 이 보기는 옳다.
    2. SSD는 반도체 칩을 쓰기 때문에 하드디스크에 비해 저장용량 대비 가격이 비싼 편이라 용량이 커질수록 가격 차가 나므로 이 보기는 옳다.
    3. SSD는 회전하는 디스크나 헤드 같은 기계적 장치가 없어 속도가 빠른 것이므로, 기계적 장치를 써서 속도가 빠르다는 이 보기는 옳지 않다(정답).
    4. SSD는 기계적 부품이 있는 하드디스크를 대체하려고 개발한 저장장치로서 반도체인 플래시 메모리로 구성되므로 SSD의 정의에 부합해 이 보기는 옳다.
    🧮 풀이
    1. 甲은 컴퓨터를 조립하며 저장장치를 고르는 대학생이다. 부품을 살펴보니 기판 위에 메모리 칩이 붙어 있어 회전 부품이 있는 디스크와 구조가 다르다는 것을 알게 되었다. 그 칩들이 저장을 담당하는 부분이었다.
    2. 甲은 같은 용량의 두 저장장치 가격을 비교해 본 구매자다. 새로운 방식의 저장장치가 용량 대비 값이 더 나가 예산 때문에 고민했다. 대신 부팅과 프로그램 실행이 빨라진다는 점에서 위안을 삼았다. 결국 예산 안에서 용량을 줄이기로 했다.
    3. 甲은 부팅 시간이 오래 걸려 저장장치를 바꾼 사무직이다. 회전하는 판이 없어서 찾는 시간이 줄어 빨라진 것이라는 설명을 들었고 기계 부품이 있어서 빠르다는 말이 틀렸음을 알았다.
    4. 甲은 노트북의 하드디스크를 교체하려고 알아본 사용자다. 하드디스크를 대신하도록 만든 제품이 플래시 메모리로 구성된다는 설명서 내용을 확인했다. 두 제품의 설계 목적이 같다는 것을 규격서에서 다시 확인했다.

    SSD는 기계적 장치가 없어 빠른 것이므로 기계적 장치를 쓴다고 한 3번이 옳지 않다.

    🧮 풀이
    1. 甲은 계산기 프로그램에서 중위식을 후위식으로 바꾸는 기능을 실습한 학생이다. 연산자를 가운데 두는 식은 후위식이 뜻하는 계산 순서를 보여 주지 못한다는 점을 확인했다. 연산자 위치가 다르면 계산 순서도 달라진다는 것이 요점이다.
    2. 甲은 후위식을 스택으로 계산하는 연습을 하며 피연산자 순서를 뒤바꿔 쓴 답안을 낸 학생이다. 연산자 위치뿐 아니라 피연산자 순서도 지켜야 한다는 지적을 받았다. 그래서 피연산자 순서를 그대로 유지해야 한다고 정리했다.
    3. 甲은 후위식을 스택에 쌓아 가며 차례대로 식으로 풀어 낸 학생이다. 괄호를 넣어 계산 순서를 확인하고 마지막에 연산자를 맨 앞으로 옮겨 전위식을 얻었다. 이 과정을 그림으로 그려 동료에게도 보여 주었다.
    4. 甲은 후위식의 마지막 연산자가 덧셈이라는 점에 주목해 전위식의 맨 앞에 덧셈을 놓은 학생이다. 그런데 곱셈과 뺄셈의 묶음을 틀리게 써서 다시 계산해야 했다. 곱셈이 뺄셈 결과를 받아야 한다는 점을 놓친 탓이었다.

    (가)에 들어갈 어드레싱 모드로 옳은 것은?

    (가) 는 명령어가 피연산자의 주소를 가지고 있는 레지스터를 지정한다. 즉, 선택된 레지스터는 피연산자 그 자체가 아니라 피연산자의 주소이다. 일반적으로 이 모드를 사용할 때에 프로그래머는 이전의 명령어에서 레지스터가 피연산자의 주소를 가졌는지를 확인해 보아야 한다.

    1. 1. 레지스터 간접 모드(Register Indirect mode)
    2. 2. 레지스터 모드(Register mode)
    3. 3. 간접 주소 모드(Indirect Addressing mode)
    4. 4. 인덱스 어드레싱 모드(Indexed Addressing mode)

    정답 1번

    🔍 보기별 해설
    1. 레지스터 간접 모드는 명령어가 지정한 레지스터가 피연산자 자체가 아니라 피연산자의 주소를 담고 있는 방식이므로 자료의 설명에 해당한다(정답).
    2. 레지스터 모드는 명령어가 지정한 레지스터에 피연산자 값이 직접 들어 있는 방식이므로, 자료의 설명처럼 레지스터가 주소만 갖는 방식에 해당하지 않는다.
    3. 간접 주소 모드는 명령어의 주소 부분이 기억장치의 어느 위치를 가리키고 그 위치에 실제 피연산자의 주소가 들어 있는 방식이므로 레지스터가 주소를 갖는다는 설명에 해당하지 않는다.
    4. 인덱스 어드레싱 모드는 명령어의 주소 부분에 인덱스 레지스터의 값을 더해 실제 주소를 구하는 방식이므로 레지스터가 피연산자의 주소를 그대로 담는다는 설명에 해당하지 않는다.

    2. 甲은 명령어에서 지정한 레지스터의 값을 그대로 연산에 사용하는 실습을 한 학생이다. 이 방식은 레지스터가 값 자체를 갖는다는 점에서 주소를 담는 방식과 구분된다. 그래서 별도의 주소 계산이 필요하지 않았다.
    3. 甲은 명령어의 주소가 가리킨 기억장치 칸에서 또 다른 주소를 읽어 오는 방식을 시험한 학생이다. 이 방식은 기억장치 안의 주소를 한 번 더 읽어야 한다는 점이 다르다. 접근 횟수가 늘어난다는 단점도 알게 되었다.
    4. 甲은 배열 원소를 차례로 읽으려고 인덱스 레지스터 값을 시작 주소에 더해 가며 접근한 학생이다. 이 방식은 기준 주소와 인덱스를 합해 위치를 구한다는 점에서 구분된다. 배열을 순회할 때 편리한 방식이었다.

    int funa(int);

    void main() {

    printf("%d, %d", funa(5), funa(6));

    return 0;

    }

    int funa(int n) {

    if(n > 1)

    return (n + (funa(n-2)));

    else

    return (n % 2);

    }

    1. 1. 5, 6
    2. 2. 9, 12
    3. 3. 15, 21
    4. 4. 120, 720

    2. funa(5)는 5+funa(3)=5+3+funa(1)이고 funa(1)은 1%2인 1이라 5+3+1=9이며, funa(6)은 6+4+2+funa(0)이고 funa(0)은 0이라 12이므로 이 보기는 옳다(정답).
    3. 15와 21은 5부터 1까지, 6부터 1까지 모두 더한 값이지만 이 함수는 2씩 줄이므로 홀수와 짝수만 각각 더하게 되어 이 보기는 옳지 않다.

    1. 甲은 재귀 함수의 결과를 예측해 본 학생이다. 인수 그대로 출력된다고 생각했으나 자기 자신을 호출하며 합을 쌓아 가는 구조라 인수와는 다른 값이 나온다는 것을 확인했다. 덧셈으로 쌓이는 구조를 놓친 것이 실수의 원인이었다.

    3. 甲은 1부터 n까지 모두 더하는 식으로 잘못 계산해 십오와 이십일을 얻은 학생이다. 함수가 둘씩 줄어드는 점을 놓쳤다는 것을 조교의 설명으로 깨달았다. 그래서 홀수와 짝수를 따로 더해야 한다는 점을 그림으로 다시 그려 보았다.
    4. 甲은 팩토리얼을 구하는 재귀 함수와 이 함수를 혼동한 학생이다. 곱하는 것이 아니라 더하고 있음을 코드를 다시 읽고 나서야 알았다. 곱하는 함수와 더하는 함수를 구분하는 습관을 들이기로 했다.

    운동발달에 영향을 미치는 사회·문화적 요인은?

    1. 1. 유전
    2. 2. 성역할
    3. 3. 신체의 성장
    4. 4. 체력의 발달

    정답 2번

    🔍 보기별 해설
    1. 유전은 부모로부터 물려받는 선천적·생물학적 요인이며, 관습·교육·성역할 기대처럼 후천적 환경에서 비롯되는 사회·문화적 요인에는 해당하지 않으므로 옳지 않다.
    2. 성역할(gender role)은 사회·문화가 만든 기대·규범으로 운동발달에 영향을 미치는 사회·문화적 요인이다. 옳다(정답).
    3. 신체의 성장은 생물학적(개체발생적) 요인이다. 사회·문화 환경이 아니라 타고난 성숙 과정이므로 사회·문화적 요인을 묻는 답이 아니어서 옳지 않다.
    4. 체력의 발달은 사회나 문화가 빚어낸 것이 아니라 개인의 몸 안에서 이루어지는 생물학적 변화이므로 사회·문화적 요인이 아니다. 옳지 않다.
    🧮 풀이
    1. 연구자가 같은 연령 아이들의 운동 능력 차이를 살핀다. 부모에게서 물려받은 유전 형질은 생물학적 요인이다. 사회가 제공하는 운동 기회와 나누어 분석한다.
    2. 어떤 학교는 특정 운동을 남학생에게만 권하는 분위기가 있다. 여학생의 참여 기회가 줄면 기술을 익힐 경험도 달라질 수 있다. 연구자는 이런 성역할 기대를 사회·문화적 요인으로 분류한다.
    3. 아이의 키와 팔 길이가 자라면서 던지기 동작의 조건이 변한다. 몸의 크기가 커지는 성장은 신체적 요인이다. 연구자는 주변의 역할 기대와 별도 변수로 기록한다.
    4. 체력 훈련 뒤 아이의 지구력과 근력이 좋아진다. 체력의 발달은 신체 기능의 변화에 가깝다. 연구자는 문화적 참여 기회와 실제 수행 능력을 구분한다.

    성역할은 사회가 성별에 따라 기대하는 행동과 기회를 뜻한다. 운동발달에 영향을 주는 사회·문화적 요인인 ②가 옳다.

    운동학습의 피드백 분류에서 숙련자보다 초보자에게 더 유용한 피드백은?

    1. 1. 처방 피드백
    2. 2. 시각 피드백
    3. 3. 기술 피드백
    4. 4. 매개변수 피드백

    정답 1번

    🔍 보기별 해설
    1. 처방 피드백은 무엇을 어떻게 고쳐야 하는지 구체적으로 알려 주어, 오류를 스스로 파악하기 어려운 초보자에게 특히 유용하다. 옳다(정답).
    2. 시각 피드백은 정보가 전달되는 감각 양식(종류)에 따른 구분일 뿐, 문항이 묻는 '숙련자보다 초보자에게 더 유용한 피드백'으로 특정되는 분류가 아니므로 옳지 않다.
    3. 기술 피드백은 동작의 기술적 요소에 관한 정보 유형으로, 문항이 묻는 '숙련자보다 초보자에게 특히 더 유용한 피드백'으로 규정되는 분류에는 해당하지 않으므로 옳지 않다.
    4. 매개변수 피드백은 이미 동작 패턴을 익힌 학습자에게 세부 조정을 위해 유용하므로 초보자보다 숙련자에게 적합하다. 옳지 않다.
    🧮 풀이
    1. 처음 농구 자유투를 배우는 학생이 공을 계속 짧게 던진다. 코치가 팔을 끝까지 펴고 손목을 앞으로 마무리하라고 구체적인 수정 방법을 알려 준다. 학생은 다음 시도에서 바로 적용한다.
    2. 영상으로 자신의 동작을 본 초보자가 무엇을 바꿔야 할지 아직 알지 못한다. 시각 피드백은 동작을 보여 주지만 수정 방향은 별도로 배워야 한다. 코치는 영상과 함께 구체적인 교정 지시를 준다.
    3. 수영 동작에 관한 기술적 정보를 들은 초보자가 여러 오류 중 중요한 것을 고르기 어려워한다. 코치는 당장 바꿀 한 동작을 정해 알려 준다. 단순한 기술 설명과 처방을 구분한다.
    4. 숙련된 선수가 던지는 힘과 시간의 세부값을 조절한다. 매개변수 피드백은 이미 배운 동작의 크기나 속도를 다듬는 데 유용하다. 초보자에게는 기본 동작의 오류 수정이 먼저 필요하다.

    초보자는 오류를 스스로 진단하기 어려워 다음 동작을 어떻게 고칠지 알려 주는 처방 피드백의 도움을 받는다. ①이 옳다.

    〈보기〉에서 연령시기별 운동발달단계가 바르게 연결된 것만을 모두 고른 것은? ㄱ. 영아기 – 초기(초보) 움직임 단계 ㄴ. 유아기 – 기본 움직임 단계 ㄷ. 아동기 – 성장과 세련 단계 ㄹ. 청소년기 – 스포츠 기술 단계

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄷ, ㄹ

    정답 1번

    🔍 보기별 해설
    1. ㄱ. 영아기는 초기(초보) 움직임 단계에 해당한다. 발달 단계와 시기의 연결이 서로 들어맞으므로 바르게 연결된 항목이라 옳다.
    2. ㄴ. 유아기는 걷기·달리기·던지기처럼 기초적인 운동 동작을 두루 익히는 기본 움직임 단계에 해당한다. 옳다.
    3. ㄷ. 아동기는 기본 움직임을 스포츠에 적용하기 시작하는 전문화(스포츠) 움직임 단계로 넘어가는 시기로, '성장과 세련 단계'라는 연결은 정확하지 않다. 옳지 않다.
    4. ㄹ. 스포츠 기술(전문화) 단계는 아동기부터 시작되므로 '청소년기–스포츠 기술 단계'라는 연결은 정확하지 않다. 옳지 않다.
    🧮 풀이
    1. 영아가 앉고 기고 서는 초기 움직임을 익힌다. 연구자는 이 시기를 기본 기술 이전의 초보 움직임 단계로 분류한다. 뒤에 나타나는 스포츠 기술과 구분한다.
    2. 유아가 달리고 뛰고 던지는 기본 움직임을 배우기 시작한다. 여러 놀이를 통해 기본 패턴을 넓힌다. 연구자는 이를 기본 움직임 단계와 연결한다.
    3. 아동기의 운동발달 단계 이름을 연구자의 분류표와 대조한다. 성장과 세련이라는 표현은 해당 발달 단계의 공식 연결로 쓰이지 않는다. 담당자는 연령만 보고 임의로 이름을 붙이지 않는다.
    4. 청소년이 종목별 기술을 익히더라도 발달 단계 명칭을 단순히 스포츠 기술 단계로 바로 대응시키지 않는다. 연구자의 모형에 따라 이전 단계와 전문화 단계를 구분해야 한다. 담당자는 보기의 명칭을 원래 분류와 대조한다.

    정답은 1번이다.

    운동수행의 정확성과 관련하여 〈보기〉가 설명하는 것은? · 피드백 체계의 오류 수정 과정에 근거하여 속도와 정확성의 상쇄현상을 설명한다. · 인간의 움직임은 불연속적인 하위움직임으로 구성되어 있다. · 조준과제를 설명하는 데 한계점이 있다.

    1. 1. 임펄스 가변성 이론(모형)
    2. 2. 최적 하위분절운동 모델
    3. 3. 반복 수정 모델(이론)
    4. 4. 피츠(Fitts)의 법칙

    정답 3번

    🔍 보기별 해설
    1. 임펄스 가변성 이론은 힘(임펄스)의 가변성으로 정확성을 설명하는 것으로, 보기의 '반복적 오류 수정' 설명과 다르다. 옳지 않다.
    2. 최적 하위분절운동 모델은 보기가 설명하는 이론이 아니다. 보기가 말하는 속도·정확성 상쇄는 피츠의 법칙이 다루는 내용이라 이 모델은 답이 아니어서 옳지 않다.
    3. 반복 수정 모델은 피드백에 근거한 오류 수정 과정으로 움직임을 불연속적 하위움직임의 연속으로 보며, 속도-정확성 상쇄를 설명하지만 조준과제 설명에 한계가 있다. 보기와 일치한다. 옳다(정답).
    4. 피츠의 법칙은 목표 거리·크기로 동작 시간을 설명하는 법칙으로, 보기의 '반복 수정 과정' 설명과 다르다. 옳지 않다.
    🧮 풀이
    1. 임펄스 가변성 모형은 힘과 시간 명령의 변동이 동작 정확도에 미치는 영향을 본다. 반복해서 시각 오류를 수정하는 과정이 핵심인 모형과 다르다. 연구자는 두 설명의 오류 원인을 구분한다.
    2. 최적 하위분절운동 모형은 목표에 도달하기 위한 하위 동작을 어떻게 나눌지 다룬다. 제시된 반복적인 오류 수정 기제 자체를 가리키는 이름은 아니다. 연구자는 동작 분절과 피드백 교정을 나누어 본다.
    3. 조준 과제를 수행하는 참가자가 목표를 향해 손을 움직인 뒤 오차를 확인한다. 작은 수정 동작을 여러 번 더해 목표에 가까워진다. 연구자는 빠르게 움직일수록 수정할 시간이 줄어 정확도가 낮아지는 현상을 반복 수정 모형으로 설명한다.
    4. 피츠의 법칙은 목표의 크기와 거리, 수행 시간을 연결한다. 목표가 작고 멀수록 더 오래 걸리는 경향을 수식으로 다룬다. 연구자는 하위 움직임의 오류 교정 모형과 법칙 자체를 구분한다.

    반복 수정 모형은 하위 움직임마다 오류를 확인하고 다시 고치는 과정을 통해 속도와 정확성의 상쇄를 설명한다. ③이 옳다.

    슈미트와 리스버그(Schmidt & Wrisberg, 2000)가 제시한 운동학습의 3단계를 옳게 나열한 것은?

    1. 1. 언어인지 단계 → 연합 단계 → 숙련 단계
    2. 2. 인지 단계 → 협응 단계 → 자동화 단계
    3. 3. 인지 단계 → 제어 단계 → 숙련 단계
    4. 4. 언어인지 단계 → (언어)운동 단계 → 자동화 단계

    정답 4번

    🔍 보기별 해설
    1. '언어인지→연합→숙련'은 제시된 3단계 명칭과 일치하지 않는다. 옳지 않다.
    2. '인지→협응→자동화'는 제시된 명칭과 일치하지 않는다. 옳지 않다.
    3. '인지→제어→숙련'은 제시된 명칭과 일치하지 않는다. 옳지 않다.
    4. 슈미트와 리스버그의 3단계는 언어인지 단계 → (언어)운동 단계 → 자동화 단계이다. 옳다(정답).
    🧮 풀이
    1. 초보 선수가 동작을 말로 이해하고 반복하며 숙련해 간다. 이 흐름은 학습 단계의 일반적 설명과 닮았지만 슈미트와 리스버그가 쓴 세 단계 명칭은 다르다. 연구자는 모형 이름과 단계 용어를 맞춘다.
    2. 학생이 기술의 목적을 이해하고 동작을 조절하며 자동화한다. 인지·협응·자동화라는 말은 다른 분류와 섞일 수 있다. 연구자는 슈미트와 리스버그의 원래 단계 명칭을 확인한다.
    3. 연습자가 실수를 줄이며 동작을 더 잘 제어한다. 제어 단계라는 표현만으로 원 모형의 언어운동 단계를 대신하지 않는다. 연구자는 중간 단계 이름의 차이를 확인한다.
    4. 슈미트와 리스버그는 처음 동작을 언어로 이해하는 시기, 말과 움직임을 연결하는 연습 시기, 수행이 자동화되는 시기를 구분했다. 학생은 각 단계에서 필요한 지도 방법을 바꾼다. 연구자는 이 순서를 학습 과정에 적용한다.

    슈미트와 리스버그의 단계는 언어인지, 언어운동, 자동화 순서로 설명한다. 이를 나열한 ④가 정답이다.

    운동의 협응에 관한 설명으로 옳은 것은?

    1. 1. 질서변수는 제어변수의 변화를 일으킨다.
    2. 2. 임계요동은 상변이(phase transition) 직후에 발생한다.
    3. 3. 상변이는 안정성의 변화로 인해 협응구조의 형태가 변하는 것이며, 선형성의 원리를 따른다.
    4. 4. 켈소(Kelso, 1984)의 양 손가락 협응 실험에서 빠른 움직임의 경우, 같은 위상(in-phase)은 반대 위상(out-phase)에 비해 안정성이 높다.

    정답 4번

    1. 수험생이 건강운동관리사 시험에 합격하겠다고 목표를 세운다. 합격 여부는 시험의 최종 결과로 확인된다. 연구자는 연습 과정의 행동 목표와 나누어 본다.
    2. 사람이 수영장에 등록하고 첫 수업에 참석한다. 운동 참여를 시작하는 행동을 실천했다. 연구자는 대회 순위나 시험 합격 같은 결과목표와 구별한다.
    3. 스쿼트를 할 때 무릎과 허리 자세를 유지하려는 참가자가 있다. 동작 수행 방식에 집중하는 과정목표다. 연구자는 결과 수치와 다른 수준의 목표로 본다.
    4. 선수가 단축마라톤 대회에서 3위 안에 들기를 바란다. 다른 선수들의 기록까지 영향을 주는 최종 순위 목표다. 연구자는 이를 결과목표로 분류한다.

    정답은 1번이다.

    공격(aggression)에 관한 설명으로 옳은 것은?

    1. 1. 수단적 공격은 상대방을 해칠 의도가 있으나, 분노가 수반되지 않는다.
    2. 2. 적대적 공격의 근본적인 목적은 승리나 칭찬과 같은 보상을 획득하는 것이다.
    3. 3. 좌절-공격 가설에 따르면, 인간의 공격적 행동은 선천적으로 타고난 본능에서부터 비롯된다.
    4. 4. 좌절-공격 가설에 따르면, 공격에 성공하게 되면 다른 형태의 공격 행위를 위한 자극이 증가된다.

    정답 1번

    🔍 보기별 해설
    1. 수단적 공격은 승리나 이득 같은 외적 목표를 이루기 위한 수단으로 상대를 해치는 행동이어서, 상대를 해치는 것 자체가 목적인 적대적 공격과 달리 분노 감정이 동반되지 않는다. 옳다(정답).
    2. 승리·보상 획득이 목적인 것은 '수단적' 공격이다. 적대적 공격의 목적은 상대에게 고통을 주는 것이라 틀리다. 옳지 않다.
    3. 좌절-공격 가설은 공격 행동이 선천적 본능이 아니라 목표 달성이 가로막힌 '좌절' 경험에서 비롯된다고 설명하므로, 본능에서 비롯된다는 이 진술은 본능이론과 혼동한 것이어서 틀리다. 옳지 않다.
    4. 좌절-공격(수정) 가설에서 공격이 성공하면 오히려 긴장이 해소(카타르시스)되어 자극이 줄어든다고 본다. '증가'는 틀리다. 옳지 않다.
    🧮 풀이
    1. 선수가 상대의 진로를 강하게 막아 경기상 이익을 얻으려 한다. 상대에게 신체적 해를 줄 가능성을 알면서 행동하지만 감정적 분노가 주목적은 아니다. 연구자는 수단적 공격의 목적을 확인한다.
    2. 화가 난 선수가 상대를 다치게 하는 자체를 목적으로 행동한다. 이는 적대적 공격에 가깝다. 승리나 칭찬을 얻는 도구로 해를 가하는 수단적 공격과 구별한다.
    3. 좌절을 겪은 뒤 선수가 공격적인 반응을 보인다. 좌절-공격 가설은 목표가 막힌 경험과 공격의 관계를 설명한다. 선천적인 공격 본능만을 원인으로 삼는 설명과 다르다.
    4. 좌절-공격 가설에서는 좌절이 공격 반응을 유발할 수 있다고 본다. 공격에 성공하면 다른 공격을 더 자극한다는 주장을 핵심 정의로 두지 않는다. 연구자는 좌절과 공격의 원인 관계를 살핀다.

    수단적 공격은 경기상 이익을 얻으려 상대에게 해를 가할 의도가 있지만 분노가 중심은 아니다. ①이 옳다.

    〈보기〉에 해당하는 강화(reinforcement) 또는 처벌(punishment)은? 운동참여자가 목표한 훈련량을 채웠을 때, 원하지 않는 나머지 힘든 훈련에서 제외시켜 준다.

    1. 1. 정적 강화(positive reinforcement)
    2. 2. 정적 처벌(positive punishment)
    3. 3. 부적 강화(negative reinforcement)
    4. 4. 부적 처벌(negative punishment)

    정답 3번

    🔍 보기별 해설
    1. 정적 강화는 좋아하는 것을 '주어' 행동을 늘리는 것으로, '싫은 것을 빼 주는' 이 사례와 다르다. 옳지 않다.
    2. 정적 처벌(positive punishment)은 싫어하는 자극을 새로 부여해 행동을 줄이는 것인데, 사례는 힘든 훈련을 오히려 없애 주어 바람직한 행동을 늘리는 부적 강화이므로 정적 처벌과는 다르다. 옳지 않다.
    3. 바람직한 행동(목표 훈련량 달성) 뒤에 싫어하는 것(힘든 훈련)을 '제거'해 그 행동을 늘리는 것은 부적 강화다. 옳다(정답).
    4. 부적 처벌(negative punishment)은 좋아하는 것을 빼앗아 행동 빈도를 줄이는 것인데, 사례는 싫어하는 힘든 훈련을 면제해 목표 행동을 늘리는 부적 강화이므로 부적 처벌과는 방향이 다르다. 옳지 않다.
    🧮 풀이
    1. 출석한 참가자에게 칭찬 스티커를 새로 준다. 좋은 자극을 더해 행동을 늘리면 정적 강화다. 사례처럼 힘든 훈련을 없애 주는 방식과 구별한다.
    2. 규칙을 어긴 참가자에게 추가 달리기를 시킨다. 불쾌한 자극을 더해 행동을 줄이는 정적 처벌이다. 목표 훈련 완료 뒤 부담을 없애 주는 상황과 다르다.
    3. 참가자가 목표량을 채우면 남아 있던 힘든 훈련을 면제받는다. 싫은 과제가 사라져 다음에도 목표량을 채우려는 행동이 늘 수 있다. 연구자는 부적 강화의 제거와 행동 증가를 함께 확인한다.
    4. 규칙을 어긴 사람에게 좋아하는 활동 시간을 빼앗는다. 좋은 자극을 제거해 행동을 줄이면 부적 처벌이다. 사례에서는 싫은 과제를 없애 목표 행동을 늘린다.

    목표 훈련량을 채운 뒤 싫어하는 추가 훈련을 없애 주면 목표 행동이 강화된다. 불쾌 자극을 제거하는 부적 강화 ③이 옳다.

    〈보기〉의 괄호 안에 공통으로 들어갈 내용은? · 프리드먼과 로젠먼(M. Friedman & R. Rosenman)은 시간 강박증, 과도한 경쟁성, 적대감을 갖고 있는 성격을 ( ) 행동으로 분류했다. · ( ) 행동은 관상동맥질환을 포함한 심폐질환의 발생 가능성과 높은 연관성이 있다.

    1. 1. A형
    2. 2. B형
    3. 3. AB형
    4. 4. Z형

    정답 1번

    🔍 보기별 해설
    1. 프리드먼과 로젠먼(Friedman & Rosenman)이 시간 강박증, 과도한 경쟁성, 적대감이 강하고 관상동맥질환 위험이 높다고 분류한 성격은 A형 행동이므로, 괄호에 공통으로 들어갈 말로 옳다. 옳다(정답).
    2. B형 행동은 느긋하고 경쟁심이 적어 시간에 쫓기지 않는 유형으로, 이 문항이 가리키는 성격과 정반대다. 옳지 않다.
    3. AB형은 혈액형 구분일 뿐 이 성격 분류 용어가 아니다. 시간 강박·경쟁심·적대감을 지닌 성격은 A형이라 부르므로 AB형은 답이 아니어서 옳지 않다.
    4. 프리드먼과 로젠먼의 성격 유형 분류에는 경쟁적·적대적인 A형과 느긋한 B형만 있을 뿐 'Z형'이라는 유형은 존재하지 않으므로, 괄호에 들어갈 용어가 될 수 없다. 옳지 않다.
    🧮 풀이
    1. 프리드먼과 로젠먼은 시간을 아끼려 서두르고 경쟁에 민감한 사람들의 행동 패턴을 관찰했다. 이 패턴을 A형 행동으로 불렀다. 연구자는 적대감과 관상동맥질환 위험의 관계도 살폈다.
    2. 차분하고 시간 압박에 덜 민감한 사람의 행동을 A형과 비교한다. B형은 제시된 과도한 경쟁성과 적대감을 대표하는 이름이 아니다. 연구자는 두 행동 양식의 차이를 기록한다.
    3. 연구자가 혈액형 AB형과 행동 유형을 혼동하지 않는다. 프리드먼과 로젠먼의 A형·B형은 성격적 행동 양식의 구분이다. 혈액형 검사 결과와는 관련이 없다.
    4. 프리드먼과 로젠먼의 분류를 확인하면 제시된 높은 경쟁성과 시간 압박은 A형에 해당한다. Z형은 이 고전적 두 유형의 표준 이름이 아니다. 연구자는 원 연구의 용어를 사용한다.

    프리드먼과 로젠먼은 시간에 쫓김·경쟁성·적대감이 큰 행동 양식을 A형으로 분류했다. ①이 옳다.

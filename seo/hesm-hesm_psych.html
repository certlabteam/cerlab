    운동발달에 영향을 미치는 사회·문화적 요인은?

    1. 1. 유전
    2. 2. 성역할
    3. 3. 신체의 성장
    4. 4. 체력의 발달

    정답 2번

    🔍 보기별 해설
    1. 유전은 부모로부터 물려받는 선천적·생물학적 요인이며, 관습·교육·성역할 기대처럼 후천적 환경에서 비롯되는 사회·문화적 요인에는 해당하지 않으므로 옳지 않다.
    2. 성역할(gender role)은 사회·문화가 만든 기대·규범으로 운동발달에 영향을 미치는 사회·문화적 요인이다. 옳다(정답).
    3. 신체의 성장은 생물학적(개체발생적) 요인이다. 사회·문화 환경이 아니라 타고난 성숙 과정이므로 사회·문화적 요인을 묻는 답이 아니어서 옳지 않다.
    4. 체력의 발달은 사회나 문화가 빚어낸 것이 아니라 개인의 몸 안에서 이루어지는 생물학적 변화이므로 사회·문화적 요인이 아니다. 옳지 않다.
    🧮 풀이
    1. 부모에게 물려받은 키·체형 같은 유전은 생물학적 요인이다.
    2. '남자아이는 축구, 여자아이는 무용'처럼 사회가 부여하는 성역할이 운동 경험을 좌우한다.
    3. 키가 자라고 몸이 커지는 것은 생물학적 성장 요인이다.
    4. 근력·지구력이 느는 것은 개인의 체력 발달 요인이다.

    성역할은 사회와 문화가 만든 기대·규범으로 운동발달에 영향을 미치는 사회문화적 요인이므로, 정답은 2번이다.

    운동학습의 피드백 분류에서 숙련자보다 초보자에게 더 유용한 피드백은?

    1. 1. 처방 피드백
    2. 2. 시각 피드백
    3. 3. 기술 피드백
    4. 4. 매개변수 피드백

    정답 1번

    🔍 보기별 해설
    1. 처방 피드백은 무엇을 어떻게 고쳐야 하는지 구체적으로 알려 주어, 오류를 스스로 파악하기 어려운 초보자에게 특히 유용하다. 옳다(정답).
    2. 시각 피드백은 정보가 전달되는 감각 양식(종류)에 따른 구분일 뿐, 문항이 묻는 '숙련자보다 초보자에게 더 유용한 피드백'으로 특정되는 분류가 아니므로 옳지 않다.
    3. 기술 피드백은 동작의 기술적 요소에 관한 정보 유형으로, 문항이 묻는 '숙련자보다 초보자에게 특히 더 유용한 피드백'으로 규정되는 분류에는 해당하지 않으므로 옳지 않다.
    4. 매개변수 피드백은 이미 동작 패턴을 익힌 학습자에게 세부 조정을 위해 유용하므로 초보자보다 숙련자에게 적합하다. 옳지 않다.
    🧮 풀이
    1. 甲은 골프를 처음 잡는데 코치가 오른손목을 조금 더 세우라고 동작 하나를 콕 짚어 처방해 주어, 혼자서는 알아채기 힘든 자세 오류를 순서대로 바로잡아 간다.
    2. 시각 피드백은 피드백을 받는 감각 경로에 따른 구분일 뿐이다.
    3. 기술(수행)에 관한 피드백은 숙련자에게도 똑같이 활용되므로, 초보자에게만 유용한 피드백으로 따로 규정되지는 않는다.
    4. 매개변수 피드백은 동작을 이미 익힌 숙련자의 미세 조정에 더 알맞다.

    처방 피드백은 무엇을 어떻게 고쳐야 하는지 알려줘 오류를 스스로 못 찾는 초보자에게 특히 유용하므로, 정답은 1번이다.

    〈보기〉에서 연령시기별 운동발달단계가 바르게 연결된 것만을 모두 고른 것은? ㄱ. 영아기 – 초기(초보) 움직임 단계 ㄴ. 유아기 – 기본 움직임 단계 ㄷ. 아동기 – 성장과 세련 단계 ㄹ. 청소년기 – 스포츠 기술 단계

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄷ, ㄹ

    정답 1번

    🔍 보기별 해설
    1. ㄱ. 영아기는 초기(초보) 움직임 단계에 해당한다. 발달 단계와 시기의 연결이 서로 들어맞으므로 바르게 연결된 항목이라 옳다.
    2. ㄴ. 유아기는 걷기·달리기·던지기처럼 기초적인 운동 동작을 두루 익히는 기본 움직임 단계에 해당한다. 옳다.
    3. ㄷ. 아동기는 기본 움직임을 스포츠에 적용하기 시작하는 전문화(스포츠) 움직임 단계로 넘어가는 시기로, '성장과 세련 단계'라는 연결은 정확하지 않다. 옳지 않다.
    4. ㄹ. 스포츠 기술(전문화) 단계는 아동기부터 시작되므로 '청소년기–스포츠 기술 단계'라는 연결은 정확하지 않다. 옳지 않다.
    🧮 풀이
    1. 돌 무렵 영아는 뒤집기·기기 같은 초보 움직임 단계에 있다.
    2. 유아기에는 걷기·달리기·던지기 같은 기본 움직임을 익힌다.
    3. 甲은 초등학생이 되어 그동안 익힌 기본 던지기와 달리기를 실제 야구 경기 상황에 맞게 쓰기 시작하는데, 아동기가 이렇게 기본 움직임을 스포츠에 적용해 가는 단계다.
    4. 甲은 초등학교에 들어가면서부터 기본 동작을 농구와 축구 같은 종목별 기술로 다듬기 시작했는데, 이런 전문화된 스포츠 기술 단계는 청소년기가 아니라 아동기에 이미 열린다.

    아동기를 성장과 세련 단계, 청소년기를 스포츠 기술 단계로 본 것은 틀리고 영아기·유아기 연결만 맞으므로, 정답은 1번이다.

    운동수행의 정확성과 관련하여 〈보기〉가 설명하는 것은? · 피드백 체계의 오류 수정 과정에 근거하여 속도와 정확성의 상쇄현상을 설명한다. · 인간의 움직임은 불연속적인 하위움직임으로 구성되어 있다. · 조준과제를 설명하는 데 한계점이 있다.

    1. 1. 임펄스 가변성 이론(모형)
    2. 2. 최적 하위분절운동 모델
    3. 3. 반복 수정 모델(이론)
    4. 4. 피츠(Fitts)의 법칙

    정답 3번

    🔍 보기별 해설
    1. 임펄스 가변성 이론은 힘(임펄스)의 가변성으로 정확성을 설명하는 것으로, 보기의 '반복적 오류 수정' 설명과 다르다. 옳지 않다.
    2. 최적 하위분절운동 모델은 보기가 설명하는 이론이 아니다. 보기가 말하는 속도·정확성 상쇄는 피츠의 법칙이 다루는 내용이라 이 모델은 답이 아니어서 옳지 않다.
    3. 반복 수정 모델은 피드백에 근거한 오류 수정 과정으로 움직임을 불연속적 하위움직임의 연속으로 보며, 속도-정확성 상쇄를 설명하지만 조준과제 설명에 한계가 있다. 보기와 일치한다. 옳다(정답).
    4. 피츠의 법칙은 목표 거리·크기로 동작 시간을 설명하는 법칙으로, 보기의 '반복 수정 과정' 설명과 다르다. 옳지 않다.
    🧮 풀이
    1. 임펄스 가변성 이론은 낸 힘의 흔들림으로 오차를 설명한다.
    2. 甲은 다트를 던질 때 처음의 큰 팔 동작으로 과녁 가까이 보낸 뒤 손끝을 조금씩 조정해 마무리하는데, 이렇게 큰 동작과 수정 동작으로 나눠 보는 것이 최적 하위분절운동 모델이다.
    3. 손을 목표로 가져갈 때 여러 번 나눠 조금씩 오차를 고쳐 가는 것으로 보는 것이 반복 수정 모델이다.
    4. 피츠의 법칙은 목표가 멀거나 작을수록 동작 시간이 길어진다는 법칙이다.

    피드백에 근거한 오류 수정과 불연속 하위움직임, 조준과제 설명의 한계를 함께 짚는 것은 반복 수정 모델이므로, 정답은 3번이다.

    슈미트와 리스버그(Schmidt & Wrisberg, 2000)가 제시한 운동학습의 3단계를 옳게 나열한 것은?

    1. 1. 언어인지 단계 → 연합 단계 → 숙련 단계
    2. 2. 인지 단계 → 협응 단계 → 자동화 단계
    3. 3. 인지 단계 → 제어 단계 → 숙련 단계
    4. 4. 언어인지 단계 → (언어)운동 단계 → 자동화 단계

    정답 4번

    🔍 보기별 해설
    1. '언어인지→연합→숙련'은 제시된 3단계 명칭과 일치하지 않는다. 옳지 않다.
    2. '인지→협응→자동화'는 제시된 명칭과 일치하지 않는다. 옳지 않다.
    3. '인지→제어→숙련'은 제시된 명칭과 일치하지 않는다. 옳지 않다.
    4. 슈미트와 리스버그의 3단계는 언어인지 단계 → (언어)운동 단계 → 자동화 단계이다. 옳다(정답).
    🧮 풀이
    1. 이 조합은 3단계 이름과 맞지 않는다.
    2. '협응'이라는 명칭이 이 3단계 구분에 쓰이지 않는다.
    3. 甲은 새 동작을 배울 때 처음엔 말로 원리를 이해하고 다음엔 움직임을 다듬으며 마지막엔 의식하지 않고도 해내는 순서를 거치는데, 이 세 단계는 언어인지와 운동, 자동화로 불린다.
    4. 처음엔 말로 이해하고(언어인지), 동작을 다듬은 뒤((언어)운동), 무의식적으로 수행(자동화)하는 순서다.

    슈미트와 리스버그의 3단계는 언어인지 단계, 언어운동 단계, 자동화 단계 순이므로, 정답은 4번이다.

    운동의 협응에 관한 설명으로 옳은 것은?

    1. 1. 질서변수는 제어변수의 변화를 일으킨다.
    2. 2. 임계요동은 상변이(phase transition) 직후에 발생한다.
    3. 3. 상변이는 안정성의 변화로 인해 협응구조의 형태가 변하는 것이며, 선형성의 원리를 따른다.
    4. 4. 켈소(Kelso, 1984)의 양 손가락 협응 실험에서 빠른 움직임의 경우, 같은 위상(in-phase)은 반대 위상(out-phase)에 비해 안정성이 높다.

    정답 4번

    🔍 보기별 해설
    1. 반대로 제어변수(control parameter)의 변화가 질서변수(order parameter)의 변화를 일으킨다. 옳지 않다.
    2. 임계요동(critical fluctuation)은 협응 패턴이 새 상태로 바뀌는 상변이가 임박했을 때 기존 패턴의 안정성이 떨어지며 커지는 현상으로, 상변이 '직후'가 아니라 '직전'에 크게 나타나므로 옳지 않다.
    3. 상변이는 안정성 변화로 협응 형태가 바뀌는 것이며 '비선형성'의 원리를 따른다. '선형성'은 틀리다. 옳지 않다.
    4. 켈소의 양 손가락 협응 실험에서 움직임이 빨라지면 같은 위상(in-phase)이 반대 위상(out-phase)보다 안정성이 높게 유지된다. 옳다(정답).
    🧮 풀이
    1. 속도 같은 제어변수를 바꾸면 협응 패턴(질서변수)이 바뀌는 것이지 그 반대가 아니다.
    2. 두 손의 협응 패턴이 다른 패턴으로 바뀌기 바로 직전에는 움직임의 흔들림, 곧 임계요동이 평소보다 크게 늘어난다.
    3. 협응에서 상변이는 운동 속도가 서서히 올라가다 어느 순간 움직임 패턴이 갑작스럽게 바뀌어 버리는 비선형적 변화로 나타난다.
    4. 손가락을 빠르게 움직이면 반대로 움직이던 패턴은 무너지고 같은 방향(in-phase) 패턴이 더 안정적으로 유지된다.

    켈소의 실험에서 움직임이 빨라지면 같은 위상이 반대 위상보다 안정성이 높게 유지되므로, 정답은 4번이다.

    운동학적(kinematic) 측정에 가장 적합한 것은?

    1. 1. 지면반력기
    2. 2. 회전판 추적기
    3. 3. 전자식 각도계
    4. 4. 바크만(Bachman) 사다리

    정답 3번

    🔍 보기별 해설

    1. 수행목표 달성에 필요한 양 이상으로 반복 연습하는 것은 과잉학습(overlearning)에 대한 설명이며, 학습자를 물리적·언어적으로 안내·보조하는 가이던스 기법과는 다른 개념이다. 옳지 않다.
    2. 이것은 다양성(가변)연습에 대한 설명이다. 여러 움직임과 환경을 두루 경험하게 하는 방법이라 가이던스 기법을 묻는 답이 아니어서 옳지 않다.

    4. 가이던스는 학습자의 수행 오류·두려움을 줄이고 부상을 막기 위해 신체적·언어적·시각적으로 안내하는 기법이다. 옳다(정답).
    🧮 풀이
    1. 예: 목표에 도달한 뒤에도 더 반복하는 것은 과잉학습이다.
    2. 예: 여러 코스·환경에서 연습해 적응력을 키우는 것이 다양성연습이다.
    3. 예: 몸을 움직이지 않고 머릿속으로 동작을 그려 보는 것이 정신연습이다.
    4. 甲은 처음 다이빙대에 오른 초보자에게 안전벨트를 채워 몸을 잡아 주고 뛰어드는 요령을 말로 일러 주며 시범 영상을 보여 주어 무서움과 부상을 줄이는데, 이런 도움이 가이던스다.

    동작 중 실수나 겁을 줄이고 다치지 않도록 몸으로·말로·눈으로 도와 이끄는 방식이므로, 정답은 4번이다.

    4. 예: '3위 안에 들기'는 경쟁 상대에 따라 달라지는 결과 목표다.

    공격(aggression)에 관한 설명으로 옳은 것은?

    1. 1. 수단적 공격은 상대방을 해칠 의도가 있으나, 분노가 수반되지 않는다.
    2. 2. 적대적 공격의 근본적인 목적은 승리나 칭찬과 같은 보상을 획득하는 것이다.
    3. 3. 좌절-공격 가설에 따르면, 인간의 공격적 행동은 선천적으로 타고난 본능에서부터 비롯된다.
    4. 4. 좌절-공격 가설에 따르면, 공격에 성공하게 되면 다른 형태의 공격 행위를 위한 자극이 증가된다.

    정답 1번

    🔍 보기별 해설
    1. 수단적 공격은 승리나 이득 같은 외적 목표를 이루기 위한 수단으로 상대를 해치는 행동이어서, 상대를 해치는 것 자체가 목적인 적대적 공격과 달리 분노 감정이 동반되지 않는다. 옳다(정답).
    2. 승리·보상 획득이 목적인 것은 '수단적' 공격이다. 적대적 공격의 목적은 상대에게 고통을 주는 것이라 틀리다. 옳지 않다.
    3. 좌절-공격 가설은 공격 행동이 선천적 본능이 아니라 목표 달성이 가로막힌 '좌절' 경험에서 비롯된다고 설명하므로, 본능에서 비롯된다는 이 진술은 본능이론과 혼동한 것이어서 틀리다. 옳지 않다.
    4. 좌절-공격(수정) 가설에서 공격이 성공하면 오히려 긴장이 해소(카타르시스)되어 자극이 줄어든다고 본다. '증가'는 틀리다. 옳지 않다.
    🧮 풀이
    1. 예: 반칙으로 상대를 넘어뜨려 득점을 막는 것은 분노 없는 수단적 공격이다.
    2. 예: 화가 나 상대에게 고통을 주려는 것이 적대적 공격이다.
    3. 예: 좌절-공격 가설은 목표 달성이 막힌 좌절이 공격을 부른다고 설명한다.
    4. 예: 공격이 성공해 좌절이 풀리면 공격 욕구가 오히려 가라앉는다고 본다.

    수단적 공격은 승리 같은 외적 목표를 위한 수단일 뿐 상대를 해치려는 분노가 동반되지 않으므로, 정답은 1번이다.

    〈보기〉에 해당하는 강화(reinforcement) 또는 처벌(punishment)은? 운동참여자가 목표한 훈련량을 채웠을 때, 원하지 않는 나머지 힘든 훈련에서 제외시켜 준다.

    1. 1. 정적 강화(positive reinforcement)
    2. 2. 정적 처벌(positive punishment)
    3. 3. 부적 강화(negative reinforcement)
    4. 4. 부적 처벌(negative punishment)

    정답 3번

    🔍 보기별 해설
    1. 정적 강화는 좋아하는 것을 '주어' 행동을 늘리는 것으로, '싫은 것을 빼 주는' 이 사례와 다르다. 옳지 않다.
    2. 정적 처벌(positive punishment)은 싫어하는 자극을 새로 부여해 행동을 줄이는 것인데, 사례는 힘든 훈련을 오히려 없애 주어 바람직한 행동을 늘리는 부적 강화이므로 정적 처벌과는 다르다. 옳지 않다.
    3. 바람직한 행동(목표 훈련량 달성) 뒤에 싫어하는 것(힘든 훈련)을 '제거'해 그 행동을 늘리는 것은 부적 강화다. 옳다(정답).
    4. 부적 처벌(negative punishment)은 좋아하는 것을 빼앗아 행동 빈도를 줄이는 것인데, 사례는 싫어하는 힘든 훈련을 면제해 목표 행동을 늘리는 부적 강화이므로 부적 처벌과는 방향이 다르다. 옳지 않다.
    🧮 풀이
    1. 예: 잘했을 때 칭찬 스티커를 주는 것이 정적 강화다.
    2. 선수 甲이 훈련에 반복해서 지각하자 코치 乙은 벌점이라는 불쾌한 자극을 새로 부과하였고, 이렇게 하여 甲의 지각 행동이 점점 줄어들도록 만든다.
    3. 예: 목표를 채우면 힘든 추가 훈련을 면제해 줘 그 노력을 더 하게 만드는 것이 부적 강화다.
    4. 예: 규칙을 어기면 좋아하는 자유시간을 빼앗는 것이 부적 처벌이다.

    목표 훈련량을 채웠다고 싫어하는 힘든 훈련을 없애 바람직한 행동을 늘리는 것은 부적 강화이므로, 정답은 3번이다.

    〈보기〉의 괄호 안에 공통으로 들어갈 내용은? · 프리드먼과 로젠먼(M. Friedman & R. Rosenman)은 시간 강박증, 과도한 경쟁성, 적대감을 갖고 있는 성격을 ( ) 행동으로 분류했다. · ( ) 행동은 관상동맥질환을 포함한 심폐질환의 발생 가능성과 높은 연관성이 있다.

    1. 1. A형
    2. 2. B형
    3. 3. AB형
    4. 4. Z형

    정답 1번

    🔍 보기별 해설
    1. 프리드먼과 로젠먼(Friedman & Rosenman)이 시간 강박증, 과도한 경쟁성, 적대감이 강하고 관상동맥질환 위험이 높다고 분류한 성격은 A형 행동이므로, 괄호에 공통으로 들어갈 말로 옳다. 옳다(정답).
    2. B형 행동은 느긋하고 경쟁심이 적어 시간에 쫓기지 않는 유형으로, 이 문항이 가리키는 성격과 정반대다. 옳지 않다.
    3. AB형은 혈액형 구분일 뿐 이 성격 분류 용어가 아니다. 시간 강박·경쟁심·적대감을 지닌 성격은 A형이라 부르므로 AB형은 답이 아니어서 옳지 않다.
    4. 프리드먼과 로젠먼의 성격 유형 분류에는 경쟁적·적대적인 A형과 느긋한 B형만 있을 뿐 'Z형'이라는 유형은 존재하지 않으므로, 괄호에 들어갈 용어가 될 수 없다. 옳지 않다.
    🧮 풀이
    1. 예: 늘 시간에 쫓기고 경쟁적이며 쉽게 화내는 사람이 A형 행동으로, 심장병 위험이 높다.
    2. 예: 서두르지 않고 여유로운 사람이 B형 행동이다.
    3. 甲은 늘 시간에 쫓기고 승부에 예민해 쉽게 화를 내는 편이고 乙은 서두르지 않고 여유로운 편인데, 이 성격 이론이 가르는 유형은 이러한 A형 행동과 B형 행동 두 가지다.
    4. 甲이 프리드먼과 로젠먼의 성격 유형 이론을 교재에서 찾아 훑어보았지만, Z형이라는 유형은 그 이론 어디에도 나오지 않는 용어임을 확인하였다.

    시간 강박증과 과도한 경쟁성, 적대감을 지녀 관상동맥질환 위험이 높은 성격은 A형 행동이므로, 정답은 1번이다.

    응집용 약품주입설비에 관한 설명으로 옳지 않은 것은?

    1. 1. 급속여과방식의 정수처리에서는 약품에 의한 응집이 필수적이다.
    2. 2. 여과지 폐색이 우려되는 완속여과시설에서는 응집용 약품주입설비가 필요없다.
    3. 3. 응집용약품은 응집제, pH조정제, 응집보조제, 가중응집제로 구분된다.
    4. 4. 일반적으로 약품주입률은 자-테스트로 결정한다.

    정답 2번

    🔍 보기별 해설
    1. 급속여과는 미세입자를 약품으로 응집시킨 뒤 여과층에 붙잡히게 한다. 응집이 필수이므로 옳다.
    2. 완속여과지에 들어오는 물이 여과층을 막을 우려가 있으면 응집용 약품설비를 검토한다. 필요 없다는 말은 옳지 않다(정답).
    3. 응집용 약품은 응집제·pH 조정제·응집보조제·가중응집제로 구분한다. 제시한 분류가 맞으므로 옳다.
    4. 자-테스트(jar test)는 약품량별 플록과 상징수질을 비교해 주입률을 고른다. 일반적인 방법이므로 옳다.
    🧮 풀이
    1. 급속여과지로 보내는 저탁도 원수에도 응집제를 넣었다. 미세입자가 플록으로 뭉치자 모래층에 더 잘 붙잡혔다. 운영자는 약품을 뺀 시험수와 처리수 탁도를 비교해 응집 필요성을 확인했다.
    2. 완속여과지의 유입수가 탁해져 모래 표면이 빠르게 막혔다. 운영자는 전처리와 응집용 약품설비를 검토해 막힘을 줄일 방법을 찾았다. 완속여과에는 어떤 경우에도 약품설비가 필요 없다는 초안을 고쳤다.
    3. 원수의 pH가 낮아 응집제만으로는 플록이 잘 자라지 않았다. 담당자는 pH 조정제와 응집보조제, 가중응집제의 역할을 응집제와 나눠 검토했다. 각 약품을 같은 이름으로 뭉뚱그리지 않고 주입 목적별로 기록했다.
    4. 원수 시료 여러 병에 응집제량을 다르게 넣었다. 빠르게 섞고 천천히 저은 뒤 플록 크기와 상징수 탁도를 비교했다. 운영자는 가장 안정된 결과를 낸 병의 주입량을 실제 공정 시험에 적용했다.

    완속여과라도 폐색이 우려되면 응집용 약품설비가 필요하므로 정답은 2번이다.

    응집제 저장설비용량에 관한 설명으로 옳은 것은?

    1. 1. 저장설비의 용량은 계획정수량에 각 약품의 평균주입률을 나누어 산정한다.
    2. 2. 응집제는 10일분 이상으로 한다.
    3. 3. 응집보조제는 일주일분 이상으로 한다.
    4. 4. 알칼리제는 연속 주입할 경우 30일분 이상, 간헐 주입할 경우에는 10일분 이상으로 한다.

    정답 4번

    🔍 보기별 해설
    1. 약품 필요량은 계획정수량에 평균주입률을 곱해 구한다. 주입률로 나눈다는 식은 옳지 않다.
    2. 응집제 저장설비는 30일분 이상이 표준이다. 10일분이라는 설명은 옳지 않다.
    3. 응집보조제는 10일분 이상 저장한다. 일주일분은 그보다 적어 옳지 않다.
    4. 알칼리제는 연속 주입 시 30일분 이상, 간헐 주입 시 10일분 이상 저장한다. 옳다(정답).
    🧮 풀이
    1. 정수장의 하루 계획수량과 약품 평균주입률을 계산서에 적었다. 담당자는 두 값을 곱해야 필요한 약품량이 나온다고 확인했다. 주입률로 나누어 저장탱크를 지나치게 작게 그린 도면을 고쳤다.
    2. 응집제 탱크를 열흘치만 저장하도록 설계했다. 납품이 늦어질 경우 30일분 표준에 못 미쳐 약품이 먼저 바닥날 수 있었다. 설계자는 일 사용량을 다시 구해 탱크 용량을 늘렸다.
    3. 응집보조제 포대를 일주일치만 보관하는 계획을 검토했다. 담당자는 기준인 열흘분보다 적다는 점을 재고표에서 확인했다. 부족한 삼 일분을 추가할 창고 공간을 확보했다.
    4. 알칼리제를 계속 넣는 정수장은 30일분 이상 저장할 탱크를 잡았다. 가끔만 넣는 다른 시설은 10일분 이상으로 계획했다. 담당자는 주입 방식에 따라 필요한 재고가 달라지는 점을 설계서에 표시했다.

    알칼리제는 연속 30일분·간헐 10일분 이상 저장하므로 정답은 4번이다.

    침전지내에서 편류나 밀도류를 발생시키지 않고 플록 제거율을 높이기 위한 시설은?

    1. 1. 호퍼
    2. 2. 위어
    3. 3. 정류벽
    4. 4. 트로프

    정답 3번

    🔍 보기별 해설
    1. 호퍼는 바닥에 가라앉은 슬러지를 모아 배출한다. 유입 편류를 막는 시설로는 옳지 않다.
    2. 위어는 상징수를 일정하게 넘겨 유출시킨다. 유입부의 밀도류를 막는 시설로는 옳지 않다.
    3. 정류벽은 유입수를 횡단면 전체로 분산해 편류·밀도류를 줄인다. 플록 제거율을 높이므로 옳다(정답).
    4. 트로프는 물을 받아 내보내는 홈통이다. 침전지 유입 흐름을 정류하는 벽으로는 옳지 않다.
    🧮 풀이
    1. 침전지 바닥 호퍼에 가라앉은 슬러지가 모였다. 운영자는 배출밸브를 열어 고형물을 빼냈다. 유입수가 한쪽으로 몰리거나 밀도류가 생기는 문제는 바닥 호퍼보다 앞단 정류벽에서 다뤘다.
    2. 침전지 출구의 위어를 따라 맑은 상징수가 고르게 넘쳤다. 담당자는 유출수량을 확인했다. 유입부에서 생기는 편류를 줄이려면 위어만이 아니라 정류벽을 배치해야 했다.
    3. 침전지 입구의 한쪽으로 물이 빠르게 몰렸다. 설계자가 정류벽과 구멍을 설치하자 유입수가 횡단면 전체로 분산됐다. 플록이 가라앉을 시간을 얻어 유출수 탁도가 낮아졌다.
    4. 침전지의 긴 트로프가 처리수를 받아 유출관으로 고르게 보냈다. 운영자는 홈통의 배수 상태와 막힌 구간을 확인했다. 유입부의 밀도류를 막는 정류벽과는 위치와 역할이 달랐다.

    침전지 유입 흐름을 고르게 펴는 시설은 정류벽이므로 정답은 3번이다.

    물역세척방식 전용으로 사용되고 있는 하부집수장치를 모두 고른 것은?

    ㄱ. 휠러블록형

    ㄴ. 티피블록형

    ㄷ. 유공블록형

    ㄹ. 스트레이너 블록형

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄷ, ㄹ

    정답 1번

    🔍 보기별 해설
    1. 휠러블록형은 물을 여재 아래에서 고르게 분배하는 물역세척 전용 블록이다. 옳다.
    2. 티피블록형은 물역세척을 위해 바닥에서 세척수를 분배한다. 전용 형식이므로 옳다.
    3. 유공블록형은 구멍을 통해 물과 공기를 함께 분배할 수 있다. 물 전용이라는 말은 옳지 않다.
    4. 스트레이너 블록형은 스트레이너를 통해 물과 공기를 분배할 수 있다. 물 전용이라는 말은 옳지 않다.
    🧮 풀이
    1. 여과지 바닥에 휠러블록을 놓고 역세척수를 아래에서 올렸다. 물이 블록을 따라 고르게 분배돼 모래층이 균일하게 팽창했다. 담당자는 공기를 함께 보내는 다른 형식과 구분해 물 전용으로 기록했다.
    2. 티피블록형 집수장치를 통해 세척수를 여재 아래로 보냈다. 블록에서 분산된 물이 여과층 전체를 씻었다. 운영자는 물역세척 전용 형식인지 확인하고 세척 유량을 맞췄다.
    3. 유공블록의 구멍을 통해 물과 공기를 함께 공급하는 설비를 검토했다. 담당자는 공기세척 단계에서도 같은 바닥 장치를 쓸 수 있음을 확인했다. 물만 쓰는 전용 형식이라는 분류에서 제외했다.
    4. 스트레이너가 달린 블록 아래에서 물과 공기를 번갈아 올렸다. 두 세척 매체가 여재층에 분배됐다. 담당자는 물역세척만 가능한 휠러블록과 이 구조의 운전 범위를 구분했다.

    물역세척 전용 하부집수장치는 휠러블록형과 티피블록형이다.

    액화염소 저장실에 관한 설명으로 옳지 않은 것은?

    1. 1. 저장조가 설치된 저장실 출입구는 기밀구조로 하고 이중출입문을 설치한다.
    2. 2. 염소주입기실과 통합하고 용기의 반출입이 편리한 위치로서 감시하기 쉬운 곳에 설치한다.
    3. 3. 방액제와 피트를 설치하여 누출된 액화염소의 확산을 방지하는 구조로 한다.
    4. 4. 내진 및 내화성으로 하고 안전한 위치에 설치한다.

    정답 2번

    🔍 보기별 해설
    1. 저장조가 있는 저장실의 출입구는 기밀하게 만들고 이중출입문을 둔다. 누출 확산을 줄여 옳다.
    2. 액화염소 저장실은 염소주입기실과 분리해 설치한다. 통합한다는 설명은 옳지 않다(정답).
    3. 방액제와 피트는 새어 나온 액화염소가 넓게 퍼지는 것을 막는다. 설치 조건으로 옳다.
    4. 저장실은 지진과 화재에 견디며 위험을 줄일 안전한 위치에 둔다. 옳다.
    🧮 풀이
    1. 액화염소 저장실의 출입구에 이중문을 설치했다. 작업자가 한 문을 닫은 뒤 다른 문을 열도록 해 누출가스가 밖으로 퍼지는 길을 줄였다. 담당자는 문틈의 기밀 상태를 정기적으로 점검했다.
    2. 저장용기 반출입이 편리하다는 이유로 저장실과 염소주입기실을 한 공간에 합친 도면이 나왔다. 검수자는 누출 위험을 분리 관리하도록 두 실을 나눠야 한다고 지적했다. 운반 동선은 유지하면서 벽과 출입구를 다시 배치했다.
    3. 액화염소가 저장용기에서 새는 사고를 가정했다. 바닥의 방액제와 피트가 액체가 다른 공간으로 퍼지는 것을 막았다. 운영자는 피트 용량과 누출 감지기 위치를 함께 확인했다.
    4. 저장실의 위치를 고르며 주변 건물과 대피 동선을 살폈다. 설계자는 지진과 화재에도 견디는 구조 재료를 적용했다. 운영자는 안전한 접근과 긴급 차단이 가능한지도 점검했다.

    액화염소 저장실은 염소주입기실과 분리해야 하므로 정답은 2번이다.

    오존발생기실에 관한 설명으로 옳지 않은 것은?

    1. 1. 건물은 내화 및 내식을 고려한다.
    2. 2. 발생기실은 채광, 방음, 환기, 배수 등이 양호해야 한다.
    3. 3. 바닥면적은 발생기 등의 유지관리에 충분한 넓이로 한다.
    4. 4. 발생설비는 가능한 한 주입지점과 멀리 설치한다.

    정답 4번

    🔍 보기별 해설
    1. 오존은 강한 산화제라 설비가 부식될 수 있고 화재에도 대비해야 한다. 내화·내식을 고려하므로 옳다.
    2. 발생기실은 채광·방음·환기·배수가 좋아야 작업과 안전 관리가 쉽다. 옳다.
    3. 발생기를 점검하고 부품을 바꿀 공간이 필요하다. 유지관리 면적을 확보해야 하므로 옳다.
    4. 오존은 이동하는 동안 분해되고 긴 관에서는 손실이 커진다. 주입점에서 멀리 둔다는 말은 옳지 않다(정답).
    🧮 풀이
    1. 오존발생기실의 재료를 고르면서 화재와 산화성 가스에 견디는지 확인했다. 담당자는 벽체와 금속 부품의 내화·내식 사양을 도면에 적었다. 오존이 새는 상황에서도 설비가 쉽게 손상되지 않도록 점검했다.
    2. 발생기실에서 작업할 때 열과 소음이 많이 나고 바닥에 세척수가 흘렀다. 설계자는 채광·방음·환기·배수를 함께 갖췄다. 유지보수자가 공기를 안전하게 마시고 장비에 접근할 수 있는지도 확인했다.
    3. 오존발생기 옆 부품을 교체하려는데 벽과 장치 사이가 너무 좁았다. 설계자는 점검 도구와 작업자가 들어갈 충분한 바닥면적을 확보했다. 운전 중에도 배관과 전기부에 안전하게 접근하는지 살폈다.

    푸드 마일리지(food mileage)와 관련 있는 것을 모두 고른 것은?

    ㄱ. 사회적 책임

    ㄴ. 푸드 마일스(food miles)

    ㄷ. 미국의 사회학자 폴 레이

    ㄹ. 테이크 아웃

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄹ
    3. 3. ㄴ, ㄷ
    4. 4. ㄷ, ㄹ

    정답 1번

    🔍 보기별 해설
    1. 푸드 마일리지를 낮추려면 식품 운송거리와 운송량을 줄여야 한다. 운송에 따른 환경 부담을 고려하는 행동이므로 사회적 책임과 관련이 있다.
    2. 푸드 마일스는 식품의 생산지에서 소비지까지 이동한 거리와 무게를 곱해 비교하는 개념이다. 푸드 마일리지의 직접적인 바탕이므로 관련이 있다.
    3. 사회학자 폴 레이는 건강과 지속가능성을 중시하는 로하스 소비자 연구로 알려져 있다. 식품 운송거리의 산정 개념을 만든 인물로 제시한 것은 관련이 없다.
    4. 테이크 아웃은 음식을 매장 밖으로 가져가 먹는 판매 방식이다. 식품의 생산지에서 소비지까지 이동한 거리를 뜻하지 않으므로 관련이 없다.
    🧮 풀이
    1. 학교 급식 담당자가 멀리서 실어 오던 식재료를 가까운 지역 농산물로 바꿨다. 운송거리가 줄어 푸드 마일리지가 낮아졌고, 운송에서 나오는 탄소도 줄었다. 환경 부담을 줄이려는 사회적 책임 활동이다.
    2. 급식업체가 감자 1t을 200km 떨어진 산지에서 들여오면 푸드 마일스는 200t·km이고, 50km 떨어진 산지에서 들여오면 50t·km다. 같은 무게라도 이동거리가 4배면 푸드 마일스도 4배다.
    3. 한 기업이 폴 레이의 로하스(LOHAS) 소비자 연구를 참고해, 건강과 환경을 중시하는 고객을 겨냥한 친환경 상품을 내놓았다. 식품이 얼마나 멀리서 왔는지를 따지는 푸드 마일리지와는 다른 연구다.
    4. 식당이 포장 판매(테이크 아웃)를 시작해 손님이 음식을 집으로 가져가게 했다. 포장 판매를 해도 식재료가 산지에서 식당까지 온 거리는 그대로라 푸드 마일리지는 달라지지 않는다.

    정답은 1번이다.

    다음 설명에 해당하는 외식업 경영행태는?

    기업의 소유주가 경영노하우를 가지고 있는 제3자에게 회사경영의 일부 또는 전부를 계약기간 동안 양도하여 경영하게 하는 방식

    1. 1. 소유 직영(ownership management)
    2. 2. 프랜차이즈 경영(franchise management)
    3. 3. 위탁 경영(management contract)
    4. 4. 리퍼럴 그룹(referral group)

    정답 3번

    🔍 보기별 해설
    1. 소유 직영은 주인이 직접 직원을 고용해 가게를 운영하는 방식이다. 남에게 맡기는 것이 아니므로 해당하지 않는다.
    2. 프랜차이즈 경영은 본사가 상호와 조리법을 빌려주고 가맹점주가 자기 자본으로 점포를 여는 방식이다. 회사 경영을 넘기는 것이 아니므로 해당하지 않는다.
    3. 주인이 경영 노하우를 가진 다른 사람에게 회사 경영의 일부나 전부를 정해진 기간 동안 넘겨 운영하게 하는 것이 위탁 경영이다. 소유는 그대로 두고 운영하는 일만 넘기는 방식이므로 해당한다(정답).
    4. 리퍼럴 그룹은 독립적으로 운영되는 여행사들이 예약과 홍보를 함께하는 조직이다. 경영을 넘기는 방식이 아니므로 해당하지 않는다.
    🧮 풀이
    1. 개인 식당의 소유주는 요리사와 홀 직원을 직접 채용하고 매출과 비용을 직접 관리했다. 외부 회사에 경영권을 맡기지 않아 직영 방식으로 운영됐다. 매장 수익과 영업 결정도 소유주가 직접 책임졌다.
    2. 프랜차이즈 가맹점주는 본사의 상표와 조리법을 사용하면서 자기 자본으로 매장을 열었다. 본사는 가맹 계약에 따라 교육과 메뉴 기준을 제공했고 점주는 자기 매장을 운영했다. 가맹 본사의 표준 메뉴는 적용됐지만 매장 소유권과 일상 운영 책임은 점주에게 남았다.
    3. 식당 소유주는 소유권을 유지한 채 전문 운영회사와 경영위탁 계약을 맺었다. 운영회사가 계약기간 동안 직원 관리와 매장 운영을 맡아 위탁 경영이 이루어졌다. 계약이 끝난 뒤 운영을 다시 맡길지는 소유주가 결정했다.
    4. 독립 여행사 여러 곳은 서로 고객을 소개하고 예약망을 공유했다. 각 회사의 경영권은 그대로여서 소개 협력은 위탁 경영으로 처리되지 않았다. 고객을 서로 연결한 뒤에도 각 여행사의 인사와 회계는 독립적으로 처리됐다.

    소유는 그대로 두고 경영 노하우를 가진 다른 사람에게 운영하는 일만 맡기는 방식은 위탁 경영이므로, 정답은 3번이다.

    복합리조트(IR)에 관한 설명으로 옳지 않은 것은?

    1. 1. 카지노뿐만 아니라 호텔, 컨벤션, 쇼핑 등이 복합적으로 통합된 리조트를 의미한다.
    2. 2. 라스베이거스에서 시작되었다.
    3. 3. 싱가포르에서는 1개의 복합리조트를 허가하였다.
    4. 4. 마리나베이샌즈는 2010년 개장하였다.

    정답 3번

    🔍 보기별 해설
    1. 복합리조트는 카지노만 두는 것이 아니라 호텔과 컨벤션, 쇼핑까지 한자리에 묶어 놓은 시설을 가리킨다. 개념 설명이 맞으므로 이 진술은 옳다.
    2. 여러 시설을 한데 묶어 사람을 오래 머물게 하는 이 방식은 라스베이거스에서 처음 자리를 잡았다. 이 진술은 그대로 옳다.
    3. 싱가포르는 복합리조트를 하나가 아니라 두 곳 허가하여 마리나베이샌즈와 리조트월드 센토사를 열었다. 하나만 허가했다고 적었으므로 옳지 않다(정답).
    4. 마리나베이샌즈는 2010년에 문을 열어 싱가포르를 대표하는 복합리조트가 되었다. 개장 연도가 맞으므로 이 진술은 옳다.
    🧮 풀이
    1. 싱가포르의 마리나베이샌즈에는 숙박시설과 회의장, 쇼핑시설, 카지노가 함께 들어섰다. 방문객은 한 단지에서 여러 서비스를 이용해 복합리조트의 모습을 확인할 수 있었다. 시설의 결합이 방문객의 숙박과 쇼핑 수요를 함께 받는 결과로 이어졌다.
    2. 라스베이거스에서는 카지노 중심 시설에 호텔과 공연장, 쇼핑시설을 결합한 대규모 단지가 발전했다. 복합리조트의 초기 사례로 관광객의 체류와 소비를 한곳에 모았다. 카지노 외 시설에서 보낸 시간도 체류형 리조트 운영의 일부가 됐다.
    3. 싱가포르 정부는 마리나베이샌즈와 리조트월드 센토사 두 복합리조트에 사업권을 부여했다. 두 사업자는 각각 시설을 건설하고 카지노와 관광시설을 운영했다. 싱가포르에는 허가받은 복합리조트가 2곳 들어섰다.
    4. 마리나베이샌즈는 2010년에 문을 열었다. 싱가포르 관광객은 개장 이후 호텔, 회의장과 쇼핑시설을 한곳에서 이용했다. 개장 뒤 두 복합리조트는 싱가포르의 숙박·회의·쇼핑 관광상품에 함께 포함됐다.

    싱가포르는 복합리조트를 한 곳이 아니라 마리나베이샌즈와 리조트월드 센토사 두 곳을 허가했으므로, 정답은 3번이다.

    호텔의 정보시스템 관련 용어로 옳은 것은?

    1. 1. PMS: property maintenance system
    2. 2. POS: point of sales
    3. 3. HIS: hotel IT system
    4. 4. PABX: property automation branch exchange

    정답 2번

    🔍 보기별 해설
    1. PMS는 Property Management System의 약자로 객실 예약과 투숙 정보를 관리한다. Property Maintenance System으로 확장한 설명은 옳지 않다.
    2. POS는 Point of Sales의 약자로 판매 시점에 거래를 기록하는 시스템이다. 제시된 영문 풀이는 옳다(정답).
    3. HIS는 Hotel Information System으로 호텔의 정보를 관리한다. Hotel IT System으로 확장한 설명은 옳지 않다.
    4. PABX는 Private Automatic Branch Exchange로 구내 자동 전화교환기를 가리킨다. Property Automation Branch Exchange라는 풀이는 옳지 않다.
    🧮 풀이
    1. 호텔 예약부는 PMS에서 객실 배정과 투숙객 요금 내역을 처리했다. 설비 수리 담당자는 별도 관리 절차를 사용해 PMS를 시설보수 시스템으로 해석하지 않았다. 예약·객실 운영 자료와 고장 수리 기록은 담당 부서와 사용 목적이 달랐다.
    2. 호텔 식당은 손님이 계산할 때 POS에 주문 내역을 입력했다. 판매시점의 매출이 객실 청구 내역과 연결되어 정산됐다. 레스토랑 판매액은 주문이 끝난 시점에 바로 전산 기록으로 남았다.
    3. 호텔 직원은 객실과 고객 정보를 HIS에서 조회했다. 정보시스템을 뜻하는 이름이지 Hotel IT System이라는 풀이는 사용하지 않았다. 조회한 자료는 투숙과 객실 운영에 사용됐다.
    4. 호텔 프런트는 PABX로 객실 전화와 외부 전화를 연결했다. 이 설비는 구내 자동 전화교환기여서 건물 자동화 장치로 분류되지 않았다. 객실에서 건 전화는 교환 설비를 거쳐 외부 회선으로 연결됐다.

    물건이 팔리는 자리에서 매출과 재고를 곧바로 기록하는 판매시점관리시스템이 POS이므로, 정답은 2번이다.

    다음 ( )에 들어갈 내용은?

    ( ) 여행사는 여행상품을 만들어 소매여행사에 판매하는 여행사를 말한다.

    1. 1. 홀세일러(wholesaler)
    2. 2. 리테일러(retailer)
    3. 3. 온라인(on-line)
    4. 4. 오프라인(off-line)

    정답 1번

    🔍 보기별 해설
    1. 여행상품을 직접 만들어 소매여행사에 넘기는 곳을 홀세일러라 부른다. 손님에게 바로 팔지 않고 파는 곳에 대는 자리이므로 이 보기가 옳다(정답).
    2. 리테일러는 홀세일러가 만든 상품을 받아 손님에게 직접 파는 소매여행사를 가리킨다. 빈칸에 들어갈 자리와는 반대이므로 옳지 않다.
    3. 온라인은 상품을 파는 통로가 인터넷이라는 뜻일 뿐 상품을 만들어 넘기는 자리를 가리키지는 않는다. 그러므로 이 보기는 옳지 않다.
    4. 오프라인은 매장에서 얼굴을 맞대고 파는 방식을 가리키는 말이다. 상품을 만들어 넘기는 자리와는 다르므로 이 보기는 옳지 않다.
    🧮 풀이
    1. 도매여행사는 항공편과 숙박을 묶은 여행상품을 기획해 여러 소매여행사에 공급했다. 소매여행사들은 공급받은 상품을 고객에게 판매했다. 상품 기획과 최종 소비자 판매가 서로 다른 업체에서 이루어졌다.
    2. 소매여행사는 도매여행사가 만든 패키지를 받아 개인 고객에게 설명하고 예약을 받았다. 상품을 만들어 다른 여행사에 공급하는 역할은 맡지 않았다. 고객 계약과 예약 확인은 소매여행사가 담당했다.
    3. 여행사는 인터넷 예약창에서 여행상품을 판매했다. 온라인은 판매 통로를 나타냈을 뿐 상품을 만들어 소매여행사에 공급하는 회사의 역할을 뜻하지 않았다. 판매 경로가 달라도 여행상품의 도매 공급자는 따로 존재했다.
    4. 여행사는 지점 창구에서 고객과 직접 계약했다. 오프라인은 대면 판매 통로를 뜻했으며 도매 공급자를 가리키지 않았다. 창구 판매 여부는 회사가 도매 상품을 생산하는지 판단하는 근거가 되지 않았다.

    여행상품을 만들어 소매여행사에 넘기는 자리를 가리키는 말은 홀세일러이므로, 정답은 1번이다.

    우리나라가 의료법 개정을 통해 외국인 환자 유치를 허용한 연도는?

    1. 1. 2006년
    2. 2. 2009년
    3. 3. 2012년
    4. 4. 2015년

    정답 2번

    🔍 보기별 해설

    다음에서 설명하는 국제 관광기구는?

    ○ 1951년에 설립된 관민 합동기구

    ○ 아시아 태평양 지역의 관광발전 및 관광객 유치를 위한 공동 선전활동을 목적으로 함

    2. 2. PATA
    3. 3. ASTA
    4. 4. EATA

    🔍 보기별 해설

    2. PATA는 1951년에 세워진 관민 합동기구로 아시아·태평양 지역의 관광 발전과 관광객 유치를 위한 공동 선전을 목적으로 삼는다. 자료 그대로이므로 옳다(정답).

    🧮 풀이
    1. UNWTO는 회원국 정부가 참여하는 국제회의에서 관광 정책을 논의했다. 회원국 대표는 국제 협력 안건을 의결했다. 아시아·태평양의 민관 공동 홍보 업무는 PATA가 맡았다.

    3. ASTA는 미국 여행업계의 단체로 여행사 업무와 소비자 보호를 다뤘다. 아시아·태평양 지역의 민관 공동 홍보 기구로 설명한 자료와 맞지 않았다. 담당자는 ASTA를 해당 답에서 제외했다.

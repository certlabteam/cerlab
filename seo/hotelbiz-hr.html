    직무분석의 절차로 옳은 것은?

    1. 1. 직무분석의 목적설정 → 분석대상직무의 선정 → 자료의 수집 → 분석 및 처리
    2. 2. 직무분석의 목적설정 → 자료의 수집 → 분석대상직무의 선정 → 분석 및 처리
    3. 3. 분석대상직무의 선정 → 직무분석의 목적설정 → 자료의 수집 → 분석 및 처리
    4. 4. 분석대상직무의 선정 → 직무분석의 목적설정 → 분석 및 처리 → 자료의 수집

    정답 1번

    🔍 보기별 해설
    1. 목적설정→분석대상직무 선정→자료수집→분석및처리 순서는 직무분석 절차와 일치하므로 옳다(정답).
    2. 목적설정보다 자료수집이 먼저일 수 없으므로 옳지 않다.
    3. 분석대상직무 선정이 목적설정보다 먼저일 수 없으므로 옳지 않다.
    4. 분석및처리가 자료수집보다 먼저일 수 없으므로 옳지 않다.
    🧮 풀이
    1. A호텔 인사팀은 직무분석의 목적을 먼저 정하고, 분석할 직무를 고른 뒤 자료를 모아 분석했다.
    2. A호텔 인사팀은 자료부터 모으기 시작했다가 목적이 안 정해져 있어 다시 처음으로 돌아갔다.
    3. A호텔 인사팀은 분석할 직무를 먼저 고르려다 목적이 안 정해진 것을 깨닫고 순서를 바꿨다.
    4. A호텔 인사팀은 분석 결과를 먼저 정리하려다 자료가 모자란 것을 깨닫고 자료수집부터 다시 했다.

    직무분석은 목적설정→대상직무선정→자료수집→분석및처리 순서이므로, 정답은 1번이다.

    2. 2. 직무성과 → 기계적·구조적 직무설계 → 경영성과
    3. 3. 기계적·구조적 직무설계 → 직무성과 → 경영성과

    🔍 보기별 해설

    🧮 풀이
    1. A호텔은 직무를 기계적으로 설계한 효과가 경영성과에 먼저 나타난다고 보고했다가 순서가 반대인 것을 확인했다.
    2. A호텔은 직무성과가 설계보다 먼저 나타난다고 보고했다가 순서가 맞지 않는 것을 확인했다.
    3. A호텔은 직무를 기계적·구조적으로 설계한 뒤 직무성과가 오르고, 그 결과 경영성과도 함께 올랐다.
    4. A호텔은 직무성과를 맨 먼저 둔 순서로 보고했다가 설계가 빠진 것을 확인했다.

    전통적 직무설계는 설계→직무성과→경영성과 순으로 영향이 이어지므로, 정답은 3번이다.

    2. 2. 분류법
    3. 3. 점수법
    4. 4. 요소비교법

    정답 4번

    🔍 보기별 해설

    2. 분류법도 대표직무 기준의 복잡한 평가척도를 쓰지 않으므로 옳지 않다.

    4. 요소비교법은 대표직무를 기준으로 여러 평가요소를 비교하는 방법이라 대표직무가 바뀌면 전체 척도를 바꿔야 하므로 옳다(정답).
    🧮 풀이
    1. A호텔은 직무들을 단순히 순서로 매기는 서열법을 썼는데, 대표직무 선정 문제는 없었다.
    2. A호텔은 직무를 몇 개 등급으로 나누는 분류법을 썼는데, 대표직무를 따로 기준으로 삼지 않았다.
    3. A호텔은 직무마다 점수를 매기는 점수법을 썼는데, 대표직무가 바뀌어도 척도 전체를 바꾸지 않았다.
    4. A호텔은 대표직무를 기준으로 다른 직무들을 비교하는 요소비교법을 썼는데, 대표직무 내용이 바뀌자 평가척도 전체를 다시 짜야 했다.

    대표직무를 기준으로 비교하고 대표직무 변경 시 척도를 다시 짜야 하는 방법은 요소비교법이므로, 정답은 4번이다.

    직무분석의 절차로 옳은 것은?

    1. 1. 직무분석의 목적설정 → 분석대상직무의 선정 → 자료의 수집 → 분석 및 처리
    2. 2. 직무분석의 목적설정 → 자료의 수집 → 분석대상직무의 선정 → 분석 및 처리
    3. 3. 분석대상직무의 선정 → 직무분석의 목적설정 → 자료의 수집 → 분석 및 처리
    4. 4. 분석대상직무의 선정 → 직무분석의 목적설정 → 분석 및 처리 → 자료의 수집

    정답 1번

    🔍 보기별 해설
    1. 목적설정→분석대상직무 선정→자료수집→분석및처리 순서는 직무분석 절차와 일치하므로 옳다(정답).
    2. 목적설정보다 자료수집이 먼저일 수 없으므로 옳지 않다.
    3. 분석대상직무 선정이 목적설정보다 먼저일 수 없으므로 옳지 않다.
    4. 분석및처리가 자료수집보다 먼저일 수 없으므로 옳지 않다.
    🧮 풀이
    1. A호텔 인사팀은 직무분석의 목적을 먼저 정하고, 분석할 직무를 고른 뒤 자료를 모아 분석했다.
    2. A호텔 인사팀은 자료부터 모으기 시작했다가 목적이 안 정해져 있어 다시 처음으로 돌아갔다.
    3. A호텔 인사팀은 분석할 직무를 먼저 고르려다 목적이 안 정해진 것을 깨닫고 순서를 바꿨다.
    4. A호텔 인사팀은 분석 결과를 먼저 정리하려다 자료가 모자란 것을 깨닫고 자료수집부터 다시 했다.

    직무분석은 목적설정→대상직무선정→자료수집→분석및처리 순서이므로, 정답은 1번이다.

    최근 노동시장의 외부환경이 아닌 것은?

    1. 1. 저학력화
    2. 2. 고령화
    3. 3. 여성의 경제활동 증가
    4. 4. 비정규직 증가

    정답 1번

    🔍 보기별 해설
    1. 최근 노동시장은 고학력화가 진행되고 있어 저학력화는 실제 외부환경과 반대되므로 옳지 않다(정답).
    2. 고령화는 실제 노동시장 외부환경에 해당하므로 옳다.
    3. 여성의 경제활동 증가도 실제 외부환경에 해당하므로 옳다.
    4. 비정규직 증가도 실제 외부환경에 해당하므로 옳다.
    🧮 풀이
    1. A호텔 인사팀은 신입 지원자들의 평균 학력이 계속 높아지는 것을 확인하고 저학력화 추세는 아니라고 보고했다.
    2. A호텔 인사팀은 정년 연장과 고령 지원자 증가를 노동시장 고령화의 사례로 보고했다.
    3. A호텔 인사팀은 여성 지원자 비율이 꾸준히 늘어난 것을 여성 경제활동 증가의 사례로 보고했다.
    4. A호텔 인사팀은 계약직·파견직 채용이 늘어난 것을 비정규직 증가의 사례로 보고했다.

    최근 노동시장은 고학력화가 진행되고 있어 저학력화가 아니므로, 정답은 1번이다.

    전통적 직무설계의 패러다임으로 옳은 것은?

    1. 1. 기계적·구조적 직무설계 → 경영성과 → 직무성과
    2. 2. 직무성과 → 기계적·구조적 직무설계 → 경영성과
    3. 3. 기계적·구조적 직무설계 → 직무성과 → 경영성과
    4. 4. 직무성과 → 경영성과 → 기계적·구조적 직무설계

    정답 3번

    🔍 보기별 해설
    1. 경영성과가 직무성과보다 먼저 영향받는다고 적어 순서가 반대이므로 옳지 않다.
    2. 직무성과가 직무설계보다 먼저일 수 없으므로 옳지 않다.
    3. 기계적·구조적 직무설계가 직무성과를 거쳐 경영성과로 이어지는 순서이므로 옳다(정답).
    4. 직무성과가 맨 앞에 온다고 적어 순서가 맞지 않으므로 옳지 않다.
    🧮 풀이
    1. A호텔은 직무를 기계적으로 설계한 효과가 경영성과에 먼저 나타난다고 보고했다가 순서가 반대인 것을 확인했다.
    2. A호텔은 직무성과가 설계보다 먼저 나타난다고 보고했다가 순서가 맞지 않는 것을 확인했다.
    3. A호텔은 직무를 기계적·구조적으로 설계한 뒤 직무성과가 오르고, 그 결과 경영성과도 함께 올랐다.
    4. A호텔은 직무성과를 맨 먼저 둔 순서로 보고했다가 설계가 빠진 것을 확인했다.

    전통적 직무설계는 설계→직무성과→경영성과 순으로 영향이 이어지므로, 정답은 3번이다.

    다음의 내용에 해당되는 직무평가방법은? 장점: 평가기준표를 작성할 경우 타 직무 평가에 용이함; 합리적인 방법임; 평가범위에 따라 다양한 직무평가가 용이함. 단점: 대표직무 선정의 정확성이 평가결과에 영향을 미침; 대표직무 내용이 바뀌면 전체 평가척도를 변경해야 함; 평가척도 구성이 복잡해 충분히 이해시키기 곤란함; 많은 시간과 비용이 듦.

    1. 1. 서열법
    2. 2. 분류법
    3. 3. 점수법
    4. 4. 요소비교법

    정답 4번

    🔍 보기별 해설
    1. 서열법은 대표직무 선정 정확성이 평가에 영향을 미치는 복잡한 척도를 쓰지 않으므로 옳지 않다.
    2. 분류법도 대표직무 기준의 복잡한 평가척도를 쓰지 않으므로 옳지 않다.
    3. 점수법도 대표직무 변경에 따라 전체 척도를 바꿔야 하는 방식이 아니므로 옳지 않다.
    4. 요소비교법은 대표직무를 기준으로 여러 평가요소를 비교하는 방법이라 대표직무가 바뀌면 전체 척도를 바꿔야 하므로 옳다(정답).
    🧮 풀이
    1. A호텔은 직무들을 단순히 순서로 매기는 서열법을 썼는데, 대표직무 선정 문제는 없었다.
    2. A호텔은 직무를 몇 개 등급으로 나누는 분류법을 썼는데, 대표직무를 따로 기준으로 삼지 않았다.
    3. A호텔은 직무마다 점수를 매기는 점수법을 썼는데, 대표직무가 바뀌어도 척도 전체를 바꾸지 않았다.
    4. A호텔은 대표직무를 기준으로 다른 직무들을 비교하는 요소비교법을 썼는데, 대표직무 내용이 바뀌자 평가척도 전체를 다시 짜야 했다.

    대표직무를 기준으로 비교하고 대표직무 변경 시 척도를 다시 짜야 하는 방법은 요소비교법이므로, 정답은 4번이다.

    직무상의 업무내용이 유사하고 관련성이 있는 특성별로 분할·결합되는 조직형태는?

    1. 1. 기능별(functional) 조직
    2. 2. 스텝(staff) 조직
    3. 3. 위원회(committee) 조직
    4. 4. 라인(line) 조직

    정답 1번

    🔍 보기별 해설
    1. 업무내용이 유사하고 관련성 있는 특성별로 나누는 조직형태는 기능별 조직이므로 옳다(정답).
    2. 스텝조직은 라인조직을 지원하는 조직으로 업무 유사성에 따른 분화와는 다르므로 옳지 않다.
    3. 위원회조직은 여러 부서가 모여 의사결정을 하는 조직으로 업무 유사성에 따른 분화와는 다르므로 옳지 않다.
    4. 라인조직은 지휘명령 계통에 따른 조직으로 업무 유사성에 따른 분화와는 다르므로 옳지 않다.
    🧮 풀이
    1. A호텔은 객실·식음료·마케팅처럼 업무 성격이 비슷한 부서로 조직을 나눈 기능별 조직을 운영했다.
    2. A호텔의 스텝조직은 현장부서를 돕는 자문 역할만 했다.
    3. A호텔의 위원회조직은 여러 부서장이 모여 중요한 의사결정을 논의하는 자리였다.
    4. A호텔의 라인조직은 지배인부터 현장 직원까지 이어지는 지휘명령 계통으로 구성되었다.

    업무내용이 유사하고 관련성 있는 특성별로 나누는 조직형태는 기능별 조직이므로, 정답은 1번이다.

    직장 내에서 발생할 수 있는 여러 상황을 제시하여 지원자의 대응능력을 평가하는 면접방법은?

    1. 1. 스트레스면접
    2. 2. 구조적면접
    3. 3. 집단토론면접
    4. 4. 상황면접

    정답 4번

    🔍 보기별 해설
    1. 스트레스면접은 압박 상황에서의 반응을 보는 면접이라 여러 상황 제시와는 다르므로 옳지 않다.
    2. 구조적면접은 미리 정한 질문을 순서대로 묻는 면접이라 상황 대응력 평가와는 다르므로 옳지 않다.
    3. 집단토론면접은 여러 지원자가 토론하는 모습을 보는 면접이라 개별 상황 대응력 평가와는 다르므로 옳지 않다.
    4. 직장 내 여러 상황을 제시해 지원자의 대응능력을 평가하는 면접은 상황면접이므로 옳다(정답).
    🧮 풀이
    1. A호텔 면접관은 지원자를 일부러 압박하는 질문으로 스트레스면접을 진행했다.
    2. A호텔 면접관은 모든 지원자에게 같은 질문을 같은 순서로 묻는 구조적면접을 진행했다.
    3. A호텔 면접관은 지원자 여러 명을 한자리에 모아 토론시키는 집단토론면접을 진행했다.
    4. A호텔 면접관은 고객 불만 상황을 가정해 지원자가 어떻게 대응하는지 보는 상황면접을 진행했다.

    직장 내 상황을 제시해 대응능력을 평가하는 면접방법은 상황면접이므로, 정답은 4번이다.

    외부모집에 관한 설명으로 옳지 않은 것은?

    1. 1. 상대적으로 빠른 시간에 기업문화에 적응한다.
    2. 2. 공개적인 광고를 통해 지원자를 모집한다.
    3. 3. 대학 등 교육기관의 추천을 통해 지원자를 모집한다.
    4. 4. 단기적인 평가로 인하여 부적격한 지원자를 채용할 개연성이 있다.

    정답 1번

    🔍 보기별 해설
    1. 외부모집은 조직문화에 적응하는 데 내부모집보다 시간이 더 걸리므로, 빠르게 적응한다고 적은 이 선택지는 옳지 않다(정답).
    2. 공개적인 광고로 지원자를 모은다는 설명은 맞으므로 옳다.
    3. 대학 등 교육기관의 추천으로 지원자를 모은다는 설명은 맞으므로 옳다.
    4. 단기적인 평가로 부적격한 지원자를 채용할 개연성이 있다는 설명은 맞으므로 옳다.
    🧮 풀이
    1. 외부에서 새로 들어온 A호텔 직원은 조직문화에 적응하는 데 내부 승진자보다 시간이 더 걸렸다.
    2. A호텔은 채용 공고를 공개적으로 올려 지원자를 모았다.
    3. A호텔은 호텔경영학과 교수의 추천을 받아 졸업생을 지원자로 받았다.
    4. A호텔은 짧은 면접만으로 지원자를 뽑았다가 부적격자를 채용한 사례가 있었다.

    외부모집은 내부모집보다 조직문화 적응에 시간이 더 걸리므로, 정답은 1번이다.

    인사이동 및 배치관리의 원칙으로 옳지 않은 것은?

    1. 1. 적재적소의 원칙
    2. 2. 연고주의의 원칙
    3. 3. 능력주의의 원칙
    4. 4. 적정인력의 원칙

    정답 2번

    🔍 보기별 해설
    1. 적재적소의 원칙은 인사이동·배치관리의 원칙에 해당하므로 옳다.
    2. 연고주의는 인사이동·배치관리의 원칙이 아니라 오히려 지양해야 할 기준이므로 옳지 않다(정답).
    3. 능력주의의 원칙도 인사이동·배치관리의 원칙에 해당하므로 옳다.
    4. 적정인력의 원칙도 인사이동·배치관리의 원칙에 해당하므로 옳다.
    🧮 풀이
    1. A호텔은 직원을 그 사람에게 맞는 자리에 배치하는 적재적소의 원칙을 지켰다.
    2. A호텔 관리자가 친척이라는 이유로 배치를 결정했다가 연고주의라는 지적을 받았다.
    3. A호텔은 능력이 뛰어난 직원을 더 중요한 자리에 배치하는 능력주의의 원칙을 지켰다.
    4. A호텔은 필요한 인원만큼만 배치하는 적정인력의 원칙을 지켰다.

    연고주의는 인사이동·배치관리의 원칙이 아니라 지양해야 할 기준이므로, 정답은 2번이다.

    대용승진에 관한 설명으로 옳은 것은?

    1. 1. 인사적체와 사기저하를 방지하기 위해 직무내용상의 실질적 변화 없이 직위명칭 또는 자격호칭 등의 승진을 시키는 경우이다.

    3. 특정 직위에 전문가를 승진시켜 임무를 맡기는 방식은 직무내용 변화 없이 명칭만 올리는 대용승진과는 다르므로 옳지 않다.
    4. 능력자를 임명해 업무를 맡기지만 승진시키기 곤란한 경우를 그대로 설명한 것은 대용승진의 정의와 다르므로 옳지 않다.
    🧮 풀이
    1. A호텔은 승진 자리가 부족해 인사적체가 생기자, 직무는 그대로 두고 직위명칭만 올리는 대용승진을 시행했다.
    2. A호텔은 근속연수에 따라 호봉을 올려주는 자격승진제도를 운영했다.
    3. A호텔은 전문 지식을 가진 직원을 특정 전문직위에 승진시켜 임무를 맡겼다.
    4. A호텔은 능력 있는 직원에게 업무를 맡기고 싶었지만 자리가 없어 승진시키지 못한 채 업무만 맡겼다.

    하나의 특성을 기반으로 피고과자에 관한 전반적인 평가에 영향을 미치는 것은?

    2. 2. 중심화경향(central tendency)

    4. 4. 대비효과(contrast effect)

    정답 3번

    🔍 보기별 해설
    1. 관대화경향은 전반적으로 후하게 평가하는 오류라 하나의 특성이 전체평가에 영향을 주는 것과는 다르므로 옳지 않다.

    4. 대비효과는 비교대상과 견주어 평가가 달라지는 오류라 하나의 특성이 전체평가에 영향을 주는 것과는 다르므로 옳지 않다.
    🧮 풀이
    1. A호텔 평가자는 모든 직원에게 후한 점수를 줘 관대화경향이라는 지적을 받았다.
    2. A호텔 평가자는 모든 직원에게 중간 점수만 줘 중심화경향이라는 지적을 받았다.
    3. A호텔 평가자는 한 직원의 인상이 좋다는 이유만으로 업무능력까지 높게 평가해 후광효과라는 지적을 받았다.
    4. A호텔 평가자는 바로 앞 직원과 비교해 점수를 다르게 줘 대비효과라는 지적을 받았다.

    하나의 특성이 전반적 평가에 영향을 미치는 오류는 후광효과이므로, 정답은 3번이다.

    ATP(administrative training program)에 관한 설명으로 옳은 것은?

    1. 1. 직장에서 직속상사가 부하에게 직접적으로 개별지도를 하며, 내용은 직무수행에 필요한 지식, 기능 및 태도에 관한 교육 등이 있다.
    2. 2. 중간관리자를 위한 교육훈련의 전형적인 방식으로, 내용은 관리이론, 작업교육, 작업방법개선 등이 있다.
    3. 3. 경영간부의 능력을 향상하고 시야가 넓은 경영자 양성을 목적으로 하며, 내용은 경영실무, 원가 및 재무관리, 마케팅 등이 있다.
    4. 4. 경영자에 대한 전형적인 교육으로 가장 널리 알려져 있으며, 내용은 기업의 목적 및 방침의 확립, 기능, 조직, 통제 등이 있다.

    정답 4번

    🔍 보기별 해설
    1. 직속상사가 부하에게 직무수행에 필요한 지식·기능·태도를 개별지도하는 방식은 OJT(현장훈련)에 해당하므로, 이 선택지는 ATP 설명으로 옳지 않다.
    2. 관리이론·작업교육·작업방법개선을 다루며 중간관리자를 대상으로 하는 교육은 MTP(관리자훈련프로그램)에 해당하므로, 이 선택지는 ATP 설명으로 옳지 않다.
    3. 경영간부의 능력향상과 경영실무·원가 및 재무관리·마케팅을 다루는 교육은 ATP가 아닌 다른 경영자과정 설명이므로, 이 선택지는 옳지 않다.
    4. 경영자를 대상으로 기업의 목적 및 방침 확립, 기능·조직·통제 등을 다루는 교육이 ATP(경영자훈련프로그램)이므로, 이 선택지는 옳다.
    🧮 풀이
    1. 甲이 신입 직원에게 직무수행에 필요한 지식과 태도를 직속상사로서 직접 개별지도하자, 인사부서는 이를 OJT로 분류해 교육기록에 남겼다.
    2. 乙이 중간관리자들을 모아 관리이론과 작업방법개선을 가르치자, 인사부서는 이 과정을 MTP로 분류해 교육기록에 남겼다.
    3. 丙이 경영간부들에게 경영실무와 원가·재무관리, 마케팅을 가르치자, 인사부서는 이 과정을 ATP가 아닌 별도의 경영자과정으로 분류했다.
    4. 丁이 경영자들에게 기업의 목적 및 방침 확립, 기능·조직·통제를 가르치자, 인사부서는 이 과정을 ATP로 분류해 최고경영자 교육체계에 포함시켰다.

    ATP는 경영자를 대상으로 기업의 목적·방침 확립과 기능·조직·통제 등을 다루는 교육이므로, 정답은 4번이다.

    1. 1. 몰입의 심화
    2. 2. 제한된 합리성
    3. 3. 점진적 의사결정 모형

    정답 2번

    🔍 보기별 해설
    1. 몰입의 심화는 잘못된 결정에 계속 투자하는 현상이라 제한된 정보·대안 속 합리적 선택과는 다르므로 옳지 않다.

    3. 점진적 의사결정 모형은 작은 변화를 반복하는 의사결정 방식이라 이 개념과는 다르므로 옳지 않다.
    4. 직관적 모형은 경험과 느낌에 의존하는 의사결정 방식이라 이 개념과는 다르므로 옳지 않다.
    🧮 풀이
    1. A호텔 경영진이 이미 투자한 사업에 손실이 나도 계속 투자를 늘렸다가 몰입의 심화라는 지적을 받았다.
    2. A호텔 경영진은 제한된 시간과 자료 안에서 그나마 나은 선택을 고르는 방식으로 설비 투자를 결정했다.
    3. A호텔 경영진은 기존 정책을 조금씩 바꿔 나가는 방식으로 가격 정책을 조정했다.
    4. A호텔 경영진은 과거 경험에서 오는 느낌으로 신속하게 채용을 결정했다.

    제한된 정보와 대안 안에서 합리적 선택을 하려는 개념은 제한된 합리성이므로, 정답은 2번이다.

    다음의 내용에 해당되는 리더십 모델은? 효과적인 그룹성과는 리더의 스타일과 리더가 상황을 통제할 수 있는 정도에 따라 달라진다. LPC 설문에서 가장 함께 일하기 싫은 동료에게 높은 점수를 주면 관계중심적, 낮게 주면 업무중심적 리더로 분류한다. 상황과 리더 스타일이 맞지 않을 때는 상황이나 리더를 바꾸어야 한다.

    1. 1. 피들러(Fiedler)의 상황적 리더십
    2. 2. 하우스(House)의 경로-목표이론
    3. 3. 리더-부하 교환(leader-member exchange) 이론
    4. 4. 서번트(servant) 리더십

    정답 1번

    🔍 보기별 해설
    1. 리더의 스타일과 상황 통제 정도에 따라 그룹성과가 달라진다고 보는 이론은 피들러의 상황적 리더십이므로 옳다(정답).
    2. 하우스의 경로-목표이론은 리더가 부하의 목표달성 경로를 돕는 방식을 다루는 이론이라 LPC 설문과는 다르므로 옳지 않다.
    3. 리더-부하 교환이론은 리더가 부하마다 다른 관계를 맺는다고 보는 이론이라 LPC 설문과는 다르므로 옳지 않다.
    4. 서번트 리더십은 리더가 구성원을 섬기는 방식의 리더십이라 LPC 설문과는 다르므로 옳지 않다.
    🧮 풀이
    1. A호텔 총지배인은 LPC 설문에서 낮은 점수를 받아 업무중심적 리더로 분류되었고, 상황 통제력이 낮은 지점으로 발령받아 성과가 떨어졌다.
    2. A호텔 중간관리자는 부하가 목표에 다다르도록 경로를 안내하는 방식으로 팀을 이끌었다.
    3. A호텔 팀장은 부하 직원마다 신뢰 관계를 다르게 맺으며 팀을 운영했다.
    4. A호텔 신임 관리자는 직원들을 섬기는 자세로 팀을 이끄는 서번트 리더십을 보였다.

    LPC 설문으로 리더 스타일을 가르고 상황 통제 정도에 따라 성과가 달라진다고 보는 이론은 피들러의 상황적 리더십이므로, 정답은 1번이다.

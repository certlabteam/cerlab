    비료에 대한 설명으로 옳지 않은 것은?

    1. 1. 비료의 3요소는 인, 질소, 칼륨이다.
    2. 2. 배합비료는 비료 성분을 단순 혼합한 것이다.
    3. 3. 화성비료는 화학반응을 통해 제조할 수 있다.
    4. 4. 비료의 3요소 성분의 함량이 50 % 미만인 것은 저도화성비료로, 50 % 이상인 것은 고도화성비료로 구분한다.

    정답 4번

    🔍 보기별 해설
    1. 비료의 삼요소는 질소와 인산과 칼륨이다. 작물이 많이 쓰면서도 토양에서 모자라기 쉬운 성분들이 맞으므로 옳다.
    2. 배합비료는 이미 만들어진 비료들을 화학 반응 없이 섞기만 한 것이다. 알갱이마다 성분이 다를 수 있다는 점이 맞으므로 옳다.
    3. 화성비료는 원료를 화학 반응시켜 한 알갱이 안에 성분이 고루 들어가게 만든 것이다. 제조 방식을 바르게 적었으므로 옳다.
    4. 고도화성비료와 저도화성비료를 가르는 기준은 삼요소 합계 30퍼센트다. 50퍼센트로 적어 기준을 잘못 옮겼으므로 옳지 않다(정답).
    🧮 풀이
    1. 甲은 비료 포대 뒤의 보증성분 칸을 읽으며 굵게 적힌 성분을 세어 보았다. 세 가지가 나란히 적혀 있는 것을 확인하고 나머지는 부성분 줄에 작게 들어간 것을 표시했다.
    2. 甲은 배합비료 알갱이를 흰 접시에 쏟아 놓고 돋보기로 들여다보았다. 색이 다른 알갱이가 섞여 있는 것을 보고 뿌릴 때 고르게 퍼지는지 따로 확인해 기록해 두었다.
    3. 甲은 화성비료 공장에서 원료가 반응기를 거쳐 한 빛깔 알갱이로 나오는 것을 보았다. 한 알에 성분이 고루 들어간다는 설명을 듣고 공정 단계를 순서대로 옮겨 적었다.
    4. 甲은 창고에 쌓인 비료 포대의 성분 합계를 계산해 30퍼센트를 넘는 것만 따로 모아 보았다. 고도화성으로 분류되는 포대에 표시를 붙이고 기준 수치를 옆에 크게 적었다.

    고도화성비료를 가르는 기준은 세 요소 합계 30퍼센트다. 50퍼센트가 아니다.

    아미노산에 대한 설명으로 옳은 것만을 모두 고르면?

    ㄱ. 단백질은 아미노산이 아마이드결합으로 연결되어 있다.

    ㄴ. 아미노산은 아민기와 카르복실기를 모두 포함하고 있다.

    ㄷ. 단백질을 완전 가수분해하면 아미노산의 혼합물이 되며, 지구상에는 총 20종의 필수 아미노산이 존재한다.

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄷ
    3. 3. ㄴ, ㄷ
    4. 4. ㄱ, ㄴ, ㄷ

    정답 1번

    🔍 보기별 해설
    1. ㄱ은 아미노산끼리 아마이드 결합으로 이어져 단백질이 된다는 것으로 옳고, ㄴ은 한 분자에 아민기와 카르복실기를 함께 가진다는 것으로 옳아 이 묶음이 맞다.
    2. ㄱ과 ㄷ을 고르면 ㄷ이 걸린다. 단백질을 이루는 아미노산이 스무 종이고 그 가운데 몸에서 못 만드는 일부만 필수 아미노산이므로 옳지 않다.
    3. ㄴ과 ㄷ을 고르면 ㄷ이 걸린다. 단백질을 이루는 아미노산이 스무 종이고 그 가운데 몸에서 만들지 못하는 일부만 필수로 꼽으므로 옳지 않다.
    4. 셋을 모두 고르면 ㄷ까지 안게 된다. 앞의 둘은 맞지만 스무 종 전부를 필수 아미노산이라 적은 것이 잘못이므로 옳지 않다.
    🧮 풀이
    1. 甲은 두 아미노산이 이어지는 과정을 그리며 떨어져 나오는 물 분자를 표시했다. 새로 생긴 결합이 단백질에서도 같은 이름으로 불리는 것을 확인하고 그 이름을 적어 넣었다. 그 결합의 이름을 적어 넣어 두었다.
    2. 甲은 아미노산 한 분자의 구조식을 그려 양 끝의 작용기를 각각 동그라미로 묶었다. 한쪽은 염기성이고 다른 쪽은 산성인 것을 확인하고 각 자리에 이름을 달아 두었다. 각 자리에 작용기 이름을 달아 두었다.
    3. 甲은 영양학 자료에서 필수 아미노산 목록을 찾아 이름을 하나씩 세어 보았다. 스무 종에 크게 못 미치는 것을 확인하고 단백질을 이루는 전체 수와 나란히 적어 두었다. 전체 수와 나란히 적어 견주어 보았다.
    4. 甲은 단백질을 산으로 완전히 가수분해한 실험 자료를 읽었다. 여러 아미노산이 섞여 나오는 것을 확인하고 그 가운데 몸에서 만들 수 있는 것에 따로 표시를 남겼다.

    필수 아미노산은 스무 종이 아니다. 단백질을 이루는 것이 스무 종이고 필수는 그중 일부다. 정답은 1번.

    1. 의자 꼴은 결합각 변형이 거의 없고 이웃한 수소도 서로 어긋나 있어 뒤틀린 꼴보다 낮은 에너지를 가지므로 ㄱ만 고른 것은 옳다.
    2. ㄴ은 플루오린이 고리 위아래로 곧게 선 쪽을 더 안정하다고 보았으나 치환기는 옆으로 누울 때 같은 쪽 수소와 부딪히지 않으므로 옳지 않다.
    3. ㄱ은 옳게 보았으나 ㄷ은 메틸기 둘이 모두 고리 위아래로 선 쪽을 더 안정하다고 하여 서로 부딪히는 쪽을 고른 것이므로 옳지 않다.
    4. ㄴ과 ㄷ은 모두 치환기가 고리 위아래로 선 배좌를 더 안정하다고 보아 실제와 반대이므로 셋을 다 고른 것은 옳지 않다.
    🧮 풀이
    1. 甲이 두 배좌의 에너지를 계산해 견주자 고리가 나란히 접힌 쪽이 뒤로 젖혀진 쪽보다 낮게 나왔고, 결합각이 정사면체 각에 가깝고 이웃 수소가 서로 엇갈려 있는 것을 원인으로 적었다.
    2. 甲이 플루오린이 고리 위쪽으로 곧게 선 그림을 더 낮은 에너지 쪽으로 적어 두었다가, 같은 쪽을 향한 수소 둘과 가까워져 서로 밀어내는 것을 모형으로 확인하고 두 칸을 맞바꾸었다.
    3. 甲이 메틸기 둘이 위아래로 선 그림을 골라 적었다가, 고리를 한 번 뒤집어 둘을 모두 옆으로 눕힌 그림의 에너지가 더 낮게 나오자 앞서 적은 순서를 지우고 새로 적어 넣었다.
    4. 甲이 세 항목을 모두 맞다고 적어 제출했다가, 치환기가 옆으로 누울 때 부딪힘이 줄어든다는 것을 두 항목에 똑같이 적용하지 않았다는 지적을 받고 표를 처음부터 다시 만들었다.

    사이클로헥세인은 의자형이 보트형보다 안정하고 치환기는 축방향보다 적도방향일 때 안정하므로 옳은 것은 ㄱ뿐이고 정답은 1번이다.

    외부 자기장이 없는 상태에서 그림과 같은 스핀 배열을 가지는 자성체의 자기적 특성은?

    1. 1. 강자성(ferromagnetic)
    2. 2. 준강자성(ferrimagnetic)
    3. 3. 상자기성(paramagnetic)
    4. 4. 반강자성(antiferromagnetic)

    정답 2번

    🔍 보기별 해설
    1. 강자성은 모든 스핀이 같은 방향으로 나란히 서는 배열인데 그림에는 위아래로 엇갈린 화살표가 줄마다 섞여 있으므로 옳지 않다.
    2. 그림은 길이가 서로 다른 반대 방향 스핀이 번갈아 놓여 상쇄되고도 한쪽 몫이 남는 배열을 보이고 있으므로 옳다(정답).
    3. 상자기성은 외부 자기장이 없을 때 스핀 방향이 제멋대로 흩어져 있어야 하는데 그림은 줄과 칸을 따라 규칙적으로 번갈아 서 있으므로 옳지 않다.
    4. 반강자성은 길이가 같은 반대 스핀이 번갈아 서서 합이 0이 되는 배열인데 그림의 화살표는 길이가 뚜렷이 다르므로 옳지 않다.
    🧮 풀이
    1. 甲이 시료를 자기장 밖에 두고 중성자 회절 무늬를 떠 보니 이웃한 원자들이 서로 반대쪽을 향하고 있어, 모든 원자가 한쪽으로 줄 선 물질에서 얻던 무늬와 전혀 달라 분류표의 첫 줄을 지웠다.
    2. 甲이 외부 자기장을 모두 걷어 낸 뒤에도 시료가 스스로 약한 자기를 띠는 것을 확인하고, 두 격자의 모멘트 크기가 서로 달라 완전히 지워지지 않고 얼마쯤 남는다고 실험 노트에 적어 두었다.
    3. 甲이 같은 시료를 상온에서 흔들어 놓고 자화 곡선을 그렸더니, 바깥 자기장을 끊는 순간 값이 0으로 곤두박질치는 물질의 곡선과 달리 한참 값이 남아 있어 분류를 처음부터 다시 잡았다.
    4. 甲이 두 격자의 모멘트 크기를 따로 재어 보니 한쪽이 다른 쪽보다 뚜렷하게 커서, 크기가 같아 서로 완전히 지워진다고 적어 두었던 앞선 기록을 지우고 새 줄에 다시 적어 넣었다.

    크기가 다른 반대 방향 스핀이 번갈아 놓여 알짜 자기모멘트가 남는 배열은 준강자성이다.

    다음에서 설명하는 박막형성 공정은?

    ○ 단차 피복성이 매우 우수하다.

    ○ 박막 밀도가 높고, 성장 제어가 가능하다.

    ○ 전구체가 순차적으로 공급되어 표면 반응을 통해 박막이 성장한다.

    1. 1. 스퍼터링(sputtering)
    2. 2. 진공기화(vacuum evaporation)
    3. 3. 원자층 증착(atomic layer deposition)
    4. 4. 분자빔 결정성장(molecular beam epitaxy)

    정답 3번

    🔍 보기별 해설
    1. 스퍼터링은 이온을 표적에 때려 튀어나온 원자를 쌓는 방식이라 직진성이 강하다. 깊은 골짜기 옆면까지 고르게 덮기는 어려우므로 옳지 않다.
    2. 진공기화는 재료를 데워 증기로 날린 뒤 기판에 앉히는 방식이다. 역시 직진해 날아가므로 단차 피복성이 좋지 않아 옳지 않다.
    3. 원자층 증착은 전구체를 하나씩 번갈아 넣어 표면에서만 반응시켜 한 층씩 쌓는다. 깊은 골짜기 안쪽까지 고르게 덮이고 두께를 층 수로 조절할 수 있으므로 옳다(정답).
    4. 분자빔 결정성장은 아주 높은 진공에서 분자 다발을 쏘아 결정을 키우는 방식이다. 전구체를 번갈아 공급하는 방식이 아니므로 옳지 않다.
    🧮 풀이
    1. 甲은 깊은 구멍이 파인 시료에 스퍼터링으로 막을 올린 뒤 단면을 잘라 들여다보았다. 입구 쪽만 두껍고 바닥은 얇은 것을 확인하고 위치별 두께를 재어 그래프로 옮겼다.
    2. 甲은 진공기화로 막을 올린 시료의 단면도 앞서와 같은 방식으로 잘라 살펴보았다. 역시 그늘진 옆면이 얇게 덮인 것을 확인하고 앞서 잰 값과 나란히 놓아 두 방식을 견주어 두었다.
    3. 甲은 전구체를 번갈아 넣는 장비에서 주입 횟수를 세어 가며 막 두께를 재어 보았다. 횟수와 두께가 곧은 직선을 그리는 것을 확인하고 한 번에 쌓이는 두께를 계산해 옆에 적었다.
    4. 甲은 반도체 연구실에서 주먹만 한 노즐이 줄지어 달린 장비를 견학하며 설명을 들었다. 원료가 끊김 없이 함께 날아가 결정층을 이룬다는 말에 앞서 본 장비들과 무엇이 다른지 표로 갈랐다.

    전구체를 번갈아 넣어 한 층씩 쌓는 원자층 증착은 단차 피복성이 뛰어나다.

    그림은 유산소성 대사 과정 중 전자전달계를 나타낸 것이다. 〈보기〉의 설명에서 옳은 것만을 모두 고른 것은? ㄱ. NADH는 Ⓐ, Ⓑ, Ⓒ 펌프에, FADH2는 Ⓑ, Ⓒ 펌프에만 영향을 미친다. ㄴ. Ⓐ, Ⓑ, Ⓒ 펌프 모두 전자 2개를 받을 때 H+ 4개를 막 사이 공간으로 배출한다. ㄷ. 산소는 Ⓓ를 산화시키는 최종 전자수용체로서 산화적 인산화가 계속되게 한다. ㄹ. 화학삼투 가설에 의해 기질로 H+이 이동하면서 Ⓓ가 활성화되어 ATP가 합성된다.

    1. 1. ㄱ, ㄷ
    2. 2. ㄱ, ㄹ
    3. 3. ㄷ, ㄹ
    4. 4. ㄴ, ㄷ, ㄹ

    정답 2번

    🔍 보기별 해설
    1. ㄱ. NADH는 복합체 Ⓐ로 들어가 Ⓑ·Ⓒ까지 거쳐 세 펌프 모두에 영향을 주고, FADH2는 Ⓐ를 건너뛰어 Ⓑ·Ⓒ에만 영향을 준다. 옳다.
    2. ㄴ. 세 복합체가 퍼내는 수소이온 수는 서로 달라 '모두 전자 2개당 H+ 4개'라고 할 수 없다. 옳지 않다.
    3. ㄷ. 산소는 마지막 복합체(Ⓒ)에서 전자를 받는 최종 전자수용체이지, ATP 합성효소 Ⓓ를 산화시키는 것이 아니다. 옳지 않다.
    4. ㄹ. 화학삼투 가설대로 막 사이에 쌓인 H+이 Ⓓ(ATP 합성효소)를 통해 기질로 흐르면서 Ⓓ가 작동해 ATP가 합성된다. 옳다.
    🧮 풀이
    1. NADH는 맨 앞 입구로, FADH2는 한 칸 뒤 입구로 들어간다고 보면 된다.
    2. 전자전달계에서 각 복합체 펌프는 전자를 받아 수소이온을 막 사이 공간으로 퍼 올리는데, 그 개수가 복합체마다 서로 달라 일정하지 않다.
    3. 전자전달계의 끝에서 산소는 전달되어 온 전자와 수소이온을 받아 물로 바뀌는 최종 전자수용체, 곧 전자가 흘러가는 마지막 종착지 역할을 한다.
    4. 댐에 가둔 물(H+)이 수문(ATP 합성효소)으로 쏟아지며 발전(ATP)한다.

    H+ 배출량이 세 펌프 모두 같다는 것과 산소가 ATP합성효소를 산화시킨다는 것은 틀리고 ㄱ·ㄹ만 맞으므로, 정답은 2번이다.

    그림은 운동강도에 따른 탄수화물과 지방의 이용 비율을 나타낸다(Ⓐ·Ⓑ 곡선, Ⓒ 교차점). 그림에 관한 설명으로 옳지 않은 것은?

    1. 1. 에피네프린은 Ⓐ의 이용 비율을 증가시킨다.
    2. 2. 속근 섬유의 동원은 Ⓑ의 이용 비율을 증가시킨다.
    3. 3. 교감신경계의 항진은 Ⓒ를 왼쪽으로 이동시킨다.
    4. 4. 장기간 지구성 트레이닝의 효과로 Ⓒ가 오른쪽으로 이동한다.

    정답 1번

    🔍 보기별 해설
    1. 에피네프린(교감신경 호르몬)은 간·근육 글리코겐 분해를 촉진해 탄수화물(Ⓑ) 이용을 늘린다. 지방(Ⓐ) 이용을 늘린다는 설명은 방향이 틀리다. 옳지 않다(정답).
    2. 속근 섬유는 주로 탄수화물(해당작용)에 의존하므로, 속근 동원이 늘면 탄수화물(Ⓑ) 이용 비율이 증가한다. 옳다.
    3. 교감신경계가 항진되면 낮은 운동강도에서도 탄수화물 이용이 지방 이용을 앞질러 교차점이 더 낮은 강도 쪽에서 나타나므로, 교차점(Ⓒ)이 왼쪽으로 이동한다는 설명이 맞다. 옳다.
    4. 지구성 트레이닝은 지방 이용 능력을 키워 더 높은 강도까지 지방을 쓰게 하므로 교차점(Ⓒ)이 오른쪽으로 이동한다. 옳다.
    🧮 풀이
    1. 甲이 갑자기 긴장해 에피네프린이 솟구치면, 이 호르몬이 간과 근육에 쌓인 글리코겐 분해를 재촉해 지방보다 탄수화물을 먼저 꺼내 쓰게 만든다.
    2. 빠르고 강하게 쓰는 속근은 탄수화물을 연료로 삼는다.
    3. 교감신경이 흥분하면 낮은 강도에서도 몸이 탄수화물 위주로 돌아선다.
    4. 훈련이 잘된 사람은 꽤 높은 강도까지도 지방을 잘 태운다.

    에피네프린은 글리코겐 분해를 촉진해 지방이 아니라 탄수화물 이용을 늘리므로, 정답은 1번이다.

    장기간 트레이닝에 의한 신경세포의 변화가 아닌 것은?

    1. 1. 신호 전달 저항 감소
    2. 2. 수초화(myelination) 증가
    3. 3. 절연층(insulating layer) 생성 감소
    4. 4. 랑비에르 결절(node of Ranvier) 도약전도 증가

    정답 3번

    🔍 보기별 해설
    1. 규칙적 트레이닝은 신경 신호 전달을 방해하는 저항을 줄여 신호가 더 효율적으로 전달되게 하므로, 이는 트레이닝으로 실제 나타나는 신경세포 변화에 해당한다. 옳다.
    2. 트레이닝을 하면 축삭을 감싸는 수초가 늘어나는 수초화(myelination)가 촉진되어 신경전도 속도가 빨라지므로, 이는 실제로 나타나는 신경세포 변화에 해당한다. 옳다.
    3. 신경 절연층 역할을 하는 수초는 트레이닝으로 오히려 증가하므로, '절연층 생성 감소'는 실제로 나타나는 변화가 아니어서 트레이닝에 의한 신경세포 변화로 볼 수 없다. 옳지 않다(정답).
    4. 수초화가 늘면 신호가 랑비에르 결절 사이를 건너뛰어 흐르는 도약전도 역시 빨라지고 힘을 얻으므로, 이는 트레이닝으로 실제 나타나는 신경세포 변화에 해당한다. 옳다.
    🧮 풀이
    1. 훈련하면 신경 신호가 더 매끄럽게 전달된다.
    2. 전깃줄의 피복(수초)이 두꺼워지듯 축삭 절연이 좋아진다.
    3. 甲이 몇 달간 꾸준히 근력 운동을 이어 가자, 신경섬유를 감싸는 말이집 같은 절연층이 오히려 두꺼워지고 늘어나 신호 전달이 빨라졌다.
    4. 결절 사이를 뛰어넘는 도약전도가 빨라져 신호가 더 빠르게 간다.

    수초 같은 절연층은 트레이닝으로 오히려 늘어나 감소한다는 것은 실제와 반대이므로, 정답은 3번이다.

    고강도 등척성 운동 시 증가하는 것이 아닌 것은?

    1. 1. 정맥 환류
    2. 2. 수축기 혈압
    3. 3. 말초혈관 저항
    4. 4. 교감신경 활성

    정답 1번

    🔍 보기별 해설
    1. 등척성(정적) 수축은 근육이 혈관을 눌러 정맥 환류를 오히려 방해한다. 고강도 등척성 운동에서 정맥 환류가 증가한다는 것은 맞지 않다. 옳지 않다(정답).
    2. 고강도 등척성 운동 중에는 지속적 근수축이 혈관을 압박하고 교감신경이 활성화되어 수축기 혈압이 크게 상승하므로, 문제에서 찾는 '증가하지 않는 것'에는 해당하지 않는다. 옳다.
    3. 수축한 근육이 혈관을 눌러 말초혈관 저항이 증가한다. 등척성 수축이 혈관을 압박해 혈류를 막으므로 저항이 늘어나는 것이 맞아 옳다.
    4. 힘을 준 채 자세를 버티는 등척성 운동에서는 몸이 이를 스트레스로 받아들여 교감신경계를 강하게 활성화한다. 따라서 그 활성은 늘어나므로 옳다.
    🧮 풀이
    1. 甲이 무거운 역기를 들고 자세를 고정한 채 버티는 등척성 운동을 하면, 수축한 근육이 혈관을 눌러 정맥을 타고 심장으로 되돌아오는 피의 흐름이 오히려 줄어든다.
    2. 甲이 무거운 역기를 든 채 자세를 움직이지 않고 버티는 등척성 운동을 하면 순간적으로 혈압이 급격히 치솟는다.
    3. 甲이 무거운 바벨을 든 채 온몸에 힘을 주고 버티는 동안, 단단히 수축한 근육이 안쪽 혈관을 짓눌러 말초혈관 저항이 크게 올라간다고 트레이너가 옆에서 짚어 주었다.
    4. 버티는 동안 몸은 교감신경을 켜서 대응한다.

    등척성 수축은 근육이 혈관을 눌러 정맥 환류를 오히려 방해하므로, 정답은 1번이다.

    수중 걷기운동을 위해 복장뼈(sternum)까지 잠기는 수온 20℃ 수영장에 입수할 때 일시적으로 증가하지 않는 것은?

    1. 1. 체온조절을 위한 대사율
    2. 2. 흉곽 압박에 의한 호흡수
    3. 3. 하지 정맥 압박에 의한 전부하(preload)
    4. 4. 압력감지수용기(baroreceptor) 반사에 의한 심박수

    정답 4번

    🔍 보기별 해설
    1. 체온(약 37℃)보다 낮은 20℃ 물에 들어가면 몸의 열을 빼앗겨 체온을 유지하려는 열 생산이 필요하므로 대사율이 일시적으로 증가하며, 따라서 '증가하지 않는 것'에는 해당하지 않는다. 옳다.
    2. 복장뼈까지 잠기면 물의 정수압이 흉곽을 압박해 호흡에 드는 부담이 커지고 이를 보상하려 호흡수가 일시적으로 증가할 수 있으므로, '증가하지 않는 것'에는 해당하지 않는다. 옳다.
    3. 물의 정수압이 하지 정맥을 눌러 심장으로 돌아오는 정맥 환류가 늘어나면 심장이 받는 전부하(preload)가 커지므로, 전부하는 일시적으로 증가해 '증가하지 않는 것'에는 해당하지 않는다. 옳다.
    4. 전부하 증가로 심박출량이 늘면 압력감지수용기 반사가 작동해 심박수는 오히려 감소한다. 증가하지 않는다. 옳지 않다(정답).
    🧮 풀이
    1. 미지근하지 않은 물에 들어가면 체온을 지키려 몸이 열을 더 낸다.
    2. 가슴까지 물에 잠기면 물이 눌러 숨쉬기가 힘들어진다.
    3. 甲이 복장뼈까지 잠기는 수영장에 들어서자 물의 압력이 다리 정맥을 눌러 하지에 고여 있던 혈액이 심장 쪽으로 밀려 올라가 정맥회귀량이 늘어난다.
    4. 심장으로 피가 많이 돌아오면 몸은 심박수를 낮춰 균형을 맞춘다.

    정맥 환류 증가로 전부하가 커지면 압력감지수용기 반사가 작동해 심박수는 오히려 줄어드므로, 정답은 4번이다.

    그림은 동일한 근섬유에 가해진 자극과 장력을 나타낸다(Ⓐ·Ⓑ·Ⓒ 구간). 〈보기〉에서 Ⓑ가 Ⓐ보다 장력이 높은 이유로 옳은 것만을 모두 고른 것은? ㄱ. 십자교 생성 증가 ㄴ. 운동단위 발화 비율 증가 ㄷ. 트로포닌과 Ca2+ 결합 증가 ㄹ. 근형질세망(SR)으로 Ca2+ 회수율 증가

    1. 1. ㄱ
    2. 2. ㄱ, ㄴ
    3. 3. ㄱ, ㄴ, ㄷ
    4. 4. ㄱ, ㄴ, ㄷ, ㄹ

    정답 3번

    🔍 보기별 해설
    1. ㄱ. 자극이 반복되어 장력이 가중되는 Ⓑ 구간에서는 액틴과 마이오신이 만드는 십자교(교차결합)가 더 많이 형성되어 발생하는 힘이 커지므로, Ⓑ의 장력이 높은 이유로 맞다. 옳다.
    2. ㄴ. 단위 시간당 자극 빈도, 즉 발화 비율이 높아지면 근섬유가 완전히 이완할 틈 없이 수축이 겹쳐 쌓여 더 큰 장력이 만들어지므로, Ⓑ의 장력이 높은 이유로 맞다. 옳다.
    3. ㄷ. 자극이 반복되며 세포질에 칼슘(Ca2+)이 축적되어 트로포닌과의 결합이 늘면 액틴의 마이오신 결합부위가 더 많이 열려 십자교 형성이 증가하므로 장력이 커진다. 옳다.
    4. ㄹ. 근형질세망으로 칼슘을 회수하는 것은 이완을 촉진하는 과정이라 장력을 낮추는 방향이다. Ⓑ의 높은 장력 이유가 아니다. 옳지 않다.
    🧮 풀이
    1. 자극이 겹치면 힘을 내는 다리(십자교)가 더 많이 붙는다.
    2. 甲이 자신의 팔 근육에 오는 자극 신호가 짧은 간격으로 더 자주 도착할수록 근섬유가 미처 이완하지 못하고 겹쳐 수축하여, 甲은 근육이 그만큼 더 큰 힘으로 세게 당겨지는 것을 느낀다.
    3. 칼슘이 쌓여 액틴의 문이 더 많이 열린다.
    4. 칼슘을 창고로 되가져가는 것은 힘을 빼는(이완) 과정이다.

    칼슘의 근형질세망 회수는 이완을 돕는 과정이라 장력을 낮춰 틀리고 십자교·발화비율·칼슘결합 증가만 맞으므로, 정답은 3번이다.

    그림은 동일한 근섬유에 가해진 자극과 장력을 나타낸다(Ⓐ·Ⓑ·Ⓒ 구간). Ⓒ 구간에 관한 설명으로 옳은 것은?

    1. 1. ATP 고갈로 수축력 급감
    2. 2. 단일 활동전위에 의해 수축 유지

    🔍 보기별 해설
    1. 내피세포유래인자는 산화질소(NO) 등 혈관을 넓히거나 좁히는 물질을 낸다. '조직 대사 증가'와의 직접 연결은 부정확하다. 옳지 않다.
    2. 활동성충혈은 조직 대사가 늘어 대사산물이 쌓이며 혈류가 느는 현상이라 '관류 압력 변화'와의 연결은 부정확하다. 옳지 않다.
    3. 근원성반응은 혈관 벽이 압력 변화에 스스로 수축·이완하는 것이라 '물질 분비'와의 연결은 부정확하다. 옳지 않다.
    4. 반응성충혈(reactive hyperemia)은 조직으로 가는 혈류를 단기간 차단했다가 다시 풀 때 부족했던 산소를 보충하려 혈류가 급증하는 현상이므로, '단기간 조직 혈액 공급 차단'과의 연결이 맞다. 옳다(정답).
    🧮 풀이
    1. 甲이 내피세포가 산화질소 같은 물질을 내보내 혈관을 넓히거나 좁히는 일을 맡는다고 배우면서, 이 기전을 조직 대사가 늘어나는 상황과 곧바로 이어 붙이기는 어렵다고 정리했다.
    2. 운동하는 근육에 대사산물이 쌓이며 피가 확 몰리는 것이 활동성충혈이다.
    3. 甲이 팔을 아래로 축 내렸을 때 혈관 벽이 늘어난 압력을 느껴 스스로 오그라드는 근원성반응을 관찰하고, 이것을 어떤 물질을 분비하는 작용과 이어 붙이기는 맞지 않다고 보았다.
    4. 甲이 혈압계 커프로 위팔을 잠시 세게 조여 피를 막았다가 한꺼번에 풀자 그 아래 피부로 혈류가 왈칵 몰려 벌게지는 반응성충혈이 나타나는 것을 가만히 지켜보았다.

    혈류를 잠시 막았다 풀면 부족한 산소를 채우려 혈류가 급증하는 것이 반응성충혈이므로, 정답은 4번이다.

    3. 3. 근글리코겐이 분해된 후 포도당으로 전환되어 혈액으로 방출된다.
    4. 4. 간에서 아미노산, 젖산, 글리세롤을 이용해 새로운 포도당을 합성한다.

    정답 3번

    🔍 보기별 해설
    1. 혈당이 떨어지려 하면 간은 저장해 둔 글리코겐을 포도당으로 쪼개 혈액으로 내보내 수치를 지탱한다. 실제로 일어나는 반응이므로 옳다.

    3. 근육에는 포도당-6-인산분해효소가 없어 근글리코겐은 포도당으로 전환·혈액 방출이 되지 않는다. 틀린 설명이라 정답이다. 옳지 않다(정답).
    4. 간에서 아미노산·젖산·글리세롤로 새 포도당을 만든다(당신생). 여러 전구물질로 포도당을 새로 합성해 운동 중 혈당을 지키는 작용이라 옳다.
    🧮 풀이
    1. 甲이 중강도로 달리는 동안 간이 저장해 두었던 글리코겐을 포도당으로 분해해 혈액으로 내보내 떨어지려는 혈당을 일정하게 지켜 낸다.
    2. 甲이 중강도 유산소 운동을 오래 이어 갈수록 근육이 쓰는 연료 가운데 지방이 차지하는 비중이 커져 지방을 점점 더 많이 태워 에너지로 쓴다.
    3. 甲이 중강도로 달리는 동안 근육 안에 쌓아 둔 근글리코겐은 그 자리에서 에너지로 쓰일 뿐, 포도당으로 바뀌어 혈액으로 나가지는 못한다.
    4. 장시간 운동 후반에 간이 재료를 모아 포도당을 새로 만든다.

    근육에는 관련 효소가 없어 근글리코겐이 분해돼도 포도당으로 바뀌어 혈액으로 나가지 못하므로, 정답은 3번이다.

    저항성 훈련에 관한 설명으로 옳지 않은 것은?

    1. 1. Type I 근섬유의 단위면적당 힘(특이장력, specific force)이 증가할 수 있다.
    2. 2. 훈련 초기 신경계 변화에 의해 근비대 없이도 근력 향상이 나타난다.
    3. 3. 트레이닝 초기에 훈련받지 않은 반대쪽 팔다리의 근력도 증가한다.
    4. 4. 골지힘줄기관의 근수축 활성 작용을 통하여 근력이 향상한다.

    정답 4번

    🔍 보기별 해설
    1. 저항성 훈련을 하면 Type I 근섬유의 단위면적당 힘(특이장력, specific force)이 향상될 수 있으므로, 이 설명은 사실에 부합하여 문제에서 찾는 '옳지 않은 것'에는 해당하지 않는다. 옳다.
    2. 훈련 초기에는 근비대 전에도 신경 적응으로 근력이 는다. 근육이 커지기 전이라도 운동단위 동원과 협응이 좋아져 힘이 세지므로 옳다.
    3. 초기에 교차교육 효과로 훈련하지 않은 반대쪽 근력도 오른다. 한쪽을 훈련해도 신경계 적응이 반대쪽에 전이돼 근력이 함께 느는 현상이라 옳다.
    4. 골지힘줄기관은 과도한 장력에서 근수축을 억제하는 기관이라 '수축 활성으로 근력 향상'은 틀리다. 옳지 않다(정답).
    🧮 풀이
    1. 甲이 몇 달간 꾸준히 저항성 훈련을 한 뒤 검사를 받아 보니, 지구력에 강한 지근인 Type I 섬유마저 단위면적당 내는 힘, 곧 특이장력이 예전보다 커져 있는 것을 확인했다.
    2. 운동 시작 2~3주는 근육 크기 변화가 없어도 힘이 세진다.
    3. 甲이 깁스한 왼쪽 다리는 쉬게 두고 오른쪽 다리만 몇 주간 근력 운동을 했더니, 훈련하지 않은 왼쪽 다리의 힘까지 교차교육 효과로 조금 늘어 있는 것을 알게 되었다.
    4. 甲이 무거운 바벨을 들다가 힘줄에 지나친 장력이 걸리자, 골지힘줄기관이 오히려 근수축을 억제해 甲의 근력을 순간적으로 풀어 주는 안전장치로 작동했다.

    골지힘줄기관은 과도한 장력에서 수축을 억제하는 기관이라 수축을 활성화해 근력을 키운다는 것은 틀리므로, 정답은 4번이다.

    〈보기〉에서 해수면 수준에서 훈련하던 국가대표 선수의 과달라하라 적응 훈련 과정에서 나타날 수 있는 생리적 변화로 옳은 것만을 모두 고른 것은? [도착 직후] ㄱ. 저산소 자극으로 분당 환기량 증가 ㄴ. 동맥혈산소분압(PaO2) 감소로 호흡성 산증(acidosis) 발생 [순응 과정] ㄷ. 순응 초기 신장을 통한 중탄산염(HCO3-) 배출 증가 ㄹ. 장기 순응 시 적혈구 생성이 과도할 경우 심장의 후부하 증가

    1. 1. ㄱ, ㄴ
    2. 2. ㄱ, ㄷ
    3. 3. ㄱ, ㄷ, ㄹ
    4. 4. ㄴ, ㄷ, ㄹ

    정답 3번

    🔍 보기별 해설
    1. ㄱ. 과달라하라 같은 고지대의 낮은 산소 환경은 말초 화학수용기를 자극해 호흡을 촉진하므로, 도착 직후 저산소 자극에 의해 분당 환기량이 증가한다는 설명이 맞다. 옳다.
    2. ㄴ. 고지대에서 환기가 늘면 이산화탄소가 과도하게 배출되어 혈액이 알칼리 쪽으로 기우는 호흡성 알칼리증이 생기므로, '호흡성 산증이 발생한다'는 설명은 실제와 반대여서 성립하지 않는다. 옳지 않다.
    3. ㄷ. 순응 과정에서는 신장이 중탄산염(HCO3−)을 소변으로 더 배출해 앞서 생긴 호흡성 알칼리증을 보상하므로, 이 설명이 맞다. 옳다.

    2. 숨을 몰아쉬면 이산화탄소가 빠져 혈액이 알칼리 쪽으로 가므로 산증이 아니다.
    3. 콩팥이 염기(중탄산염)를 소변으로 빼서 산-염기 균형을 맞춘다.
    4. 甲이 고지대에서 여러 달 지내며 적혈구가 지나치게 많아지자 혈액이 걸쭉해져 점도가 오르고, 그만큼 심장이 맞서 밀어내야 할 후부하도 함께 커졌다는 것을 배웠다.

    환기가 늘면 산증이 아니라 알칼리증이 생긴다는 것만 실제와 반대라 틀리고 나머지 셋은 맞으므로, 정답은 3번이다.

    과달라하라와 같은 환경에서 운동할 때, 스트레스 반응과 혈당 유지에 관여하는 호르몬은?

    2. 2. 에리트로포이에틴(erythropoietin, EPO)

    3. 코르티솔(cortisol)은 대표적인 스트레스 반응 호르몬으로 간의 당신생을 촉진해 혈당을 끌어올려 유지하므로, 스트레스 반응과 혈당 유지에 관여하는 호르몬으로 맞다. 옳다(정답).
    4. 항이뇨호르몬(antidiuretic hormone, ADH)은 신장에서 수분 재흡수를 늘려 체내 수분·삼투압을 조절하는 호르몬이며 혈당 유지에는 직접 관여하지 않으므로, 이 문항의 답으로 볼 수 없다. 옳지 않다.
    🧮 풀이
    1. 멜라토닌은 밤에 분비되어 잠을 유도한다.
    2. 甲이 고지대에 머무는 동안 신장에서 EPO 분비가 늘어 골수의 적혈구 생성이 촉진되면서 혈액 속 적혈구 수가 점점 많아진다.
    3. 시험·경기 같은 스트레스 상황에서 코르티솔이 혈당을 끌어올려 대응 에너지를 마련한다.
    4. ADH는 콩팥에서 물을 재흡수해 소변을 줄이는 호르몬이라 혈당과는 직접 관련이 없다.

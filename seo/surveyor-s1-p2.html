    배수량 등곡선도에서 제공하는 요소가 아닌 것은?

    1. 1. 부면심
    2. 2. 수선면적
    3. 3. 선박의 무게중심
    4. 4. 중앙 횡단면 계수

    정답 3번

    🔍 보기별 해설
    1. 부면심은 수면 아래 선체 부피의 중심 위치를 나타낸다. 선형과 흘수에 따라 정해져 배수량 등곡선도에서 읽을 수 있으므로 옳다.
    2. 수선면적은 일정 흘수에서 선체가 수면과 만나는 면의 넓이다. 선형과 흘수로 정해져 곡선도에 나타나므로 옳다.
    3. 무게중심은 선박과 적재물의 무게가 어디에 놓였는지에 따라 달라진다. 선형만으로 만든 배수량 등곡선도에서 직접 읽을 수 없으므로 옳지 않다(정답).
    4. 중앙 횡단면 계수는 중앙 단면의 수면 아래 면적비다. 선형과 흘수에 따라 정해지는 값이므로 곡선도에 제시될 수 있어 옳다.
    🧮 풀이
    1. 흘수 8미터에서 물에 잠긴 선체 부피의 중심을 검량사 甲이 곡선도에서 찾았다. 흘수를 바꿔 같은 값을 읽자 부면심의 위치가 달라졌다. 선체 형상과 수면 높이로 정해진 정역학 자료였다.
    2. 선박이 더 깊이 잠기자 검량사 甲이 수선면적의 새 값을 곡선도에서 읽었다. 넓어진 수선면을 이용해 배수량 변화를 계산했다. 적재물의 위치를 몰라도 선형과 흘수만으로 면적을 찾을 수 있었다.
    3. 갑판 위로 무거운 장비를 옮기자 선박의 무게중심이 올라갔다. 검량사 甲은 배수량 등곡선도의 선형 자료는 그대로 두고 새 적재 상태의 무게중심을 따로 계산했다. 복원성 평가값이 바뀌었다.
    4. 중앙 단면의 수면 아래 면적을 검량사 甲이 도면에서 측정했다. 이를 같은 흘수의 직사각형 면적으로 나눠 중앙 횡단면 계수를 구했다. 화물 배치가 달라도 단면의 선형 값은 유지됐다.

    배수량 등곡선도에는 선형과 흘수로 정해지는 정역학 값이 실린다. 적재 상태마다 달라지는 선박의 무게중심은 직접 제공되지 않으므로 3번이 정답이다.

    선박의 횡요주기와 선폭과의 관계로 옳은 것은?

    1. 1. 선폭에 비례한다.
    2. 2. 선폭에 반비례한다.
    3. 3. 선폭의 제곱에 비례한다.
    4. 4. 선폭의 제곱에 반비례한다.

    정답 1번

    🔍 보기별 해설
    1. 횡요주기 식에서 선폭은 분자에 놓인다. 다른 조건이 같을 때 선폭이 커지면 주기가 길어지므로 옳다(정답).
    2. 선폭에 반비례하면 폭이 넓을수록 횡요주기가 짧아진다. 횡요주기 식에서 선폭은 분자에 있으므로 옳지 않다.
    3. 선폭의 제곱에 비례하면 폭이 두 배일 때 주기가 네 배가 된다. 횡요주기 식에는 선폭이 한 번만 들어가므로 옳지 않다.
    4. 선폭의 제곱에 반비례하면 폭이 두 배일 때 주기가 4분의 1이 된다. 실제 식은 선폭에 비례하므로 옳지 않다.
    🧮 풀이
    1. 폭이 20미터인 모형과 30미터인 모형을 시험원 甲이 같은 GM 조건으로 맞췄다. 두 배의 흔들림 주기를 측정하자 폭이 넓은 쪽이 더 오래 걸렸다. 선폭이 분자에 있는 관계와 일치했다.
    2. 선폭을 키우면 더 빨리 흔들린다는 예측을 시험원 甲이 시험했다. GM을 일정하게 두고 선폭만 늘리자 횡요주기는 오히려 길어졌다. 반비례라는 예측과 측정 결과가 반대였다.
    3. 선폭 20미터 모형을 40미터로 바꾼 시험원 甲이 횡요주기 식을 계산했다. 주기는 두 배로 늘었고 네 배가 되지는 않았다. 선폭을 제곱해 적용하는 방식은 시험값과 맞지 않았다.
    4. 선폭을 두 배로 키운 모형에서 주기가 4분의 1이 된다고 실습생 甲이 예측했다. 시험원은 같은 GM에서 주기가 두 배로 늘어난 값을 보여 줬다. 비례 방향과 거듭제곱이 모두 달랐다.

    횡요주기를 구하는 어림식에서 선폭은 분자에 한 번 들어간다. 다른 조건이 같으면 주기는 선폭에 비례하므로 1번이 정답이다.

    해수비중에 관한 설명으로 옳지 않은 것은?

    1. 1. 해수비중이 담수비중보다 크므로 운항하는 선박의 흘수는 작아진다.
    2. 2. 해수비중은 선박의 중앙, 선수, 선미의 각 양현 6개소에서 상, 중, 하층에서 측정한다.
    3. 3. 해수비중은 물의 표면장력에 의해서 약간 올라온 부분의 눈금을 읽어서 측정한다.
    4. 4. 비중이 1.025일 때 물 1 m3에 해당하는 부피의 무게는 1,000 M/T이다.

    정답 4번

    🔍 보기별 해설
    1. 해수는 담수보다 밀도가 커 같은 선박이 더 작은 부피의 물을 밀어내도 뜬다. 해수에서 흘수가 작아지므로 옳다.
    2. 해수비중은 선체 주변 여러 위치와 깊이에서 측정해 편차를 반영한다. 중앙·선수·선미의 양현과 상·중·하층을 측정한다는 설명이므로 옳다.
    3. 비중계는 액면에서 표면장력 때문에 액체가 올라간 부분의 눈금을 기준으로 읽는다. 제시한 측정 방식에 맞으므로 옳다.
    4. 비중 1.025인 물 1세제곱미터는 약 1,025킬로그램, 즉 1.025톤이다. 1,000톤이라는 값은 천 배 가까이 크므로 옳지 않다(정답).
    🧮 풀이
    1. 담수 하구에서 해수로 이동한 선박의 흘수를 검량사 甲이 다시 쟀다. 같은 적재량인데도 더 밀도 높은 해수에서 선체가 조금 떠올랐다. 흘수가 줄어든 값을 배수량 보정에 반영했다.
    2. 선수·중앙·선미의 양현에서 검량사 甲이 물을 채취했다. 각 위치의 상층·중층·하층 시료를 나누어 비중을 쟀다. 장소와 깊이에 따른 차이를 반영한 평균값을 계산했다.
    3. 해수 시료에 비중계를 띄운 검량사 甲이 액면 주변 눈금을 읽었다. 표면장력으로 액체가 비중계 줄기를 따라 조금 올라온 위치를 기준으로 했다. 기록한 값을 해수비중 계산표에 반영했다.
    4. 비중 1.025인 해수 1세제곱미터를 검량사 甲이 단위로 환산했다. 약 1,025킬로그램은 1.025톤이었다. 보고서에 적힌 1,000톤은 같은 부피의 질량과 전혀 맞지 않았다.

    비중 1.025인 해수 1세제곱미터의 질량은 약 1.025톤이다. 1,000톤이라는 4번은 단위가 크게 어긋나 옳지 않다.

    평균흘수가 8.7 m인 선박에 300 톤의 화물을 양화하였다면 하역 후 평균흘수(m)는? (단, Tcm은 30 톤이다.)

    1. 1. 5.6
    2. 2. 6.6
    3. 3. 7.6
    4. 4. 8.6

    정답 4번

    🔍 보기별 해설
    1. 5.6미터는 처음 흘수 8.7미터보다 3.1미터 작다. 300톤을 내릴 때 줄어드는 0.1미터와 다르므로 옳지 않다.
    2. 6.6미터는 처음 흘수보다 2.1미터 작다. Tcm으로 계산한 감소량 0.1미터보다 훨씬 크므로 옳지 않다.
    3. 7.6미터는 처음 흘수보다 1.1미터 작다. 300÷30=10센티미터를 미터로 바꾼 0.1미터와 다르므로 옳지 않다.
    4. 300톤을 Tcm 30톤으로 나누면 흘수 감소량은 10센티미터다. 8.7미터에서 0.1미터를 빼면 8.6미터이므로 옳다(정답).
    🧮 풀이
    1. 화물 300톤을 내린 선박의 흘수가 5.6미터가 됐다는 계산서를 검량사 甲이 받았다. 시작값 8.7미터와 비교하자 3.1미터나 줄어든 셈이었다. Tcm 30톤을 적용한 감소량과 맞지 않아 다시 계산했다.
    2. 하역 뒤 흘수 6.6미터를 적은 실습생의 기록을 검량사 甲이 검토했다. 300톤에 Tcm 30톤을 적용하면 감소량은 10센티미터뿐이었다. 2.1미터가 줄었다는 기록을 바로잡았다.
    3. 흘수 7.6미터를 적은 실습생 甲이 감소량을 다시 계산했다. 300톤을 매 센티미터 30톤으로 나누자 10센티미터였다. 이를 0.1미터로 환산하자 7.6미터라는 답과 차이가 드러났다.
    4. 하역 전 흘수 8.7미터에서 검량사 甲이 화물 300톤을 내렸다. Tcm 30톤으로 나눈 10센티미터를 0.1미터로 바꿔 시작값에서 뺐다. 하역 뒤 평균흘수는 8.6미터가 됐다.

    화물 300톤을 내리면 Tcm 30톤 기준으로 흘수가 10센티미터 줄어든다. 8.7미터에서 0.1미터를 빼면 8.6미터이므로 4번이 정답이다.

    선체구조에 관한 설명으로 ( )에 들어갈 용어는?

    선체의 횡강력을 보강하기 위하여 빔(beam)을 양현 쪽보다 선체의 중심선부근을 높게 하는데 이 높이의 차를 ( )라/이라 하며, 노출갑판의 경우 최대 선폭의 1/50을 표준으로 한다.

    1. 1. 텀블 홈(tumble home)
    2. 2. 플레어(flare)
    3. 3. 캠버(camber)
    4. 4. 현호(sheer)

    정답 3번

    🔍 보기별 해설
    1. 텀블 홈은 선측 윗부분이 안쪽으로 기울어 들어가는 선체 형상이다. 갑판 중앙과 양현의 높이 차가 아니므로 옳지 않다.
    2. 플레어는 선수 쪽 선측이 위로 갈수록 바깥으로 벌어지는 형상이다. 갑판 중앙의 높이 차가 아니므로 옳지 않다.
    3. 캠버는 갑판의 중앙을 양현보다 높게 만드는 가로 방향의 굴곡이다. 발문에서 설명한 높이 차이므로 옳다(정답).
    4. 현호는 선박을 옆에서 볼 때 갑판이 앞뒤로 휘어 올라가는 형상이다. 좌우 방향의 높이 차인 캠버와 다르므로 옳지 않다.
    🧮 풀이
    1. 선측 윗부분이 갑판 가까이에서 안쪽으로 좁아졌다. 설계자 甲은 단면도에 그 안쪽 경사를 표시했다. 선측의 텀블 홈은 갑판 중앙을 양현보다 높이는 캠버와 위치가 달랐다.
    2. 선수 쪽 선측이 위로 갈수록 바깥쪽으로 벌어졌다. 설계자 甲은 그 플레어 형상으로 파도 물보라가 갑판에 덜 올라오는 상황을 검토했다. 갑판 중앙과 양현의 높이 차는 별도로 계산했다.
    3. 갑판 중앙에 떨어진 빗물이 양현으로 흘러갔다. 설계자 甲은 중앙과 양쪽 끝의 높이 차를 도면에서 측정했다. 가로 방향으로 볼록한 캠버가 배수를 돕고 갑판의 횡강성에도 기여했다.
    4. 측면도에서 갑판선이 선수와 선미 쪽으로 올라갔다. 설계자 甲은 배의 길이 방향을 따라 현호의 곡선을 그렸다. 좌우 끝보다 중앙이 높은 캠버와 굴곡 방향이 달랐다.

    캠버는 갑판 중앙을 양현보다 높게 만든 가로 방향의 높이 차다. 빈칸에 해당하므로 3번이 정답이다.

    유체를 한 방향으로만 흐르게 하고 반대 방향의 흐름을 차단시키는 밸브는?

    1. 1. 글로브 밸브
    2. 2. 체크 밸브
    3. 3. 게이트 밸브
    4. 4. 시퀀스 밸브

    정답 2번

    🔍 보기별 해설
    1. 글로브 밸브는 밸브 몸체 안의 디스크 위치를 바꿔 유량을 조절한다. 역류할 때 자동으로 닫히는 체크 밸브가 아니므로 옳지 않다.
    2. 체크 밸브는 한 방향의 유동에서는 열리고 반대 방향에서는 자동으로 닫힌다. 역류를 차단하므로 옳다(정답).
    3. 게이트 밸브는 판을 올리거나 내려 관로를 열고 닫는다. 흐름 방향을 감지해 자동으로 역류를 막는 장치가 아니므로 옳지 않다.
    4. 시퀀스 밸브는 설정 압력에 따라 유압 회로의 다음 동작 순서를 제어한다. 역류 차단용 밸브가 아니므로 옳지 않다.

    1. 관로의 유량이 지나치게 커지자 작업자 甲이 글로브 밸브의 손잡이를 돌렸다. 디스크가 내려오면서 통로가 좁아지고 유량이 줄었다. 역류가 생길 때 저절로 닫히는 기능과는 달랐다.

    4. 선수와 선미 흘수를 모두 크게 바꾼 실습생 甲의 답안을 검량사가 검토했다. 부면심이 중앙이라는 조건에 맞춰 변화량을 절반씩 배분했다. 선수 6.1미터와 선미 7.1미터로 수정됐다.

    트림 변화량은 200×40/400=20센티미터다. 부면심이 중앙이면 선수는 10센티미터 깊어져 6.1미터, 선미는 10센티미터 얕아져 7.1미터이므로 2번이 정답이다.

    배수량 등곡선표(hydrostatic table)에서 제공하는 정보(기호)가 아닌 것은?

    1. 1. CP
    2. 2. CS
    3. 3. LCF
    4. 4. TPC

    정답 2번

    🔍 보기별 해설
    1. CP(Prismatic Coefficient)는 수면 아래 부피를 중앙횡단면적과 길이의 곱으로 나눈 주형계수다. 흘수별 선형 값으로 표에 실리므로 옳다.
    2. CS는 제시된 배수량 등곡선표의 표준 정역학 항목을 나타내는 기호가 아니다. 다른 세 항목과 달리 표에서 제공하는 정보가 아니므로 옳지 않다(정답).
    3. LCF(Longitudinal Centre of Flotation)는 수선면의 부면심이 앞뒤 어디에 있는지 나타낸다. 트림 계산에 쓰이는 흘수별 값이므로 옳다.
    4. TPC(Tonnes per Centimetre Immersion)는 흘수가 1센티미터 바뀔 때의 배수톤수다. 화물 적재량 계산에 쓰이는 표의 값이므로 옳다.
    🧮 풀이
    1. 선체의 수면 아래 부피와 중앙횡단면적을 검량사 甲이 표에서 읽었다. 그 값으로 CP를 계산해 흘수별 선형 차이를 비교했다. 배의 앞뒤가 얼마나 가늘어지는지 수치가 달라졌다.
    2. 배수량 등곡선표의 기호 목록을 검량사 甲이 하나씩 확인했다. CP와 LCF, TPC는 찾았지만 CS 항목은 없었다. 해당 기호의 뜻을 다른 자료에서 확인하고 이 표의 값으로 사용하지 않았다.
    3. 화물을 옮긴 뒤 트림을 계산하려고 검량사 甲이 LCF 값을 읽었다. 수선면의 앞뒤 중심 위치를 기준으로 선수와 선미 흘수 변화를 나눴다. 새 적재 상태의 트림을 계산했다.
    4. 화물 300톤을 더 실을 계획을 검량사 甲이 세웠다. 곡선표의 TPC 값을 읽고 화물 중량을 나눠 예상 흘수 증가량을 구했다. 그 값으로 만재선 여유를 다시 확인했다.

    CP·LCF·TPC는 배수량 등곡선표의 정역학 항목으로 쓰인다. CS는 이 표의 통상적인 기호가 아니므로 2번이 정답이다.

    원심 펌프의 송출 유량을 조절하는 방법 중 선박 기관실에서 주로 사용하는 것으로 옳은 것은?

    1. 1. 펌프의 회전수를 조절하는 방법
    2. 2. 전동기의 회전수를 조절하는 방법
    3. 3. 펌프의 흡입 밸브의 개도를 조절하는 방법
    4. 4. 펌프의 송출 밸브의 개도를 조절하는 방법

    정답 4번

    🔍 보기별 해설
    1. 펌프 회전수를 바꾸면 원심 펌프의 유량도 달라진다. 별도 제어 장치가 필요해 송출측 밸브 조절보다 일반적인 기관실 방식이 아니므로 옳지 않다.
    2. 전동기 회전수 조절은 구동 속도를 바꿔 유량을 조절한다. 가변속 장치가 필요해 발문이 찾는 주된 간단 조절법이 아니므로 옳지 않다.
    3. 흡입 밸브를 조이면 펌프 입구의 압력이 낮아져 공동현상 위험이 커진다. 통상적인 유량 조절법으로 쓰기 어려우므로 옳지 않다.
    4. 송출 밸브의 개도를 줄이면 원심 펌프에서 나가는 유량을 조절할 수 있다. 기관실에서 쉽게 적용하는 방법이므로 옳다(정답).
    🧮 풀이
    1. 원심 펌프의 회전수를 낮추려던 기관사 甲이 제어 장치의 설치 상태를 확인했다. 기존 장비에는 속도 조절기가 없어 바로 바꾸지 못했다. 송출측 밸브로 유량을 조절하는 방법을 택했다.
    2. 전동기 속도를 바꾸는 장치를 기관사 甲이 기관실 도면에서 찾았다. 해당 펌프에는 가변속 제어기가 설치되지 않았다. 전동기 회전수를 조절하는 방안 대신 송출 밸브를 사용했다.
    3. 흡입 밸브를 조이자 펌프 입구에서 기포가 생기고 소음이 커졌다. 기관사 甲은 밸브를 다시 열어 흡입 압력을 회복했다. 공동현상 위험을 피하려고 송출측에서 유량을 조절했다.
    4. 송출측 밸브를 조금 닫자 유량계의 수치가 내려갔다. 기관사 甲은 목표 유량에 맞춰 개도를 조정하고 펌프 상태를 점검했다. 별도 속도 제어 장치 없이 필요한 유량을 맞췄다.

    원심 펌프의 송출측 밸브 개도를 바꾸면 별도 회전수 장치 없이 유량을 조절할 수 있다. 기관실에서 주로 쓰는 방식이므로 4번이 정답이다.

    아래 표시된 기호의 의미는?

    1. 1. 스톱 밸브
    2. 2. 체크 밸브
    3. 3. 릴리프 밸브
    4. 4. 유량 조절 밸브

    정답 2번

    🔍 보기별 해설
    1. 스톱 밸브는 조작으로 관로를 열고 닫는 밸브다. 그림처럼 역류 때 자동으로 닫히는 원판 기호가 아니므로 옳지 않다.
    2. 체크 밸브는 유체가 정방향으로 흐를 때 열리고 역류하면 원판이 시트에 닿아 닫힌다. 그림의 기호와 맞으므로 옳다(정답).
    3. 릴리프 밸브는 설정 압력을 넘으면 열려 압력을 낮춘다. 그림의 역류 차단 기호와 기능이 다르므로 옳지 않다.
    4. 유량 조절 밸브는 개도를 바꿔 관로의 흐름량을 조절한다. 그림의 자동 역류 차단 기호가 아니므로 옳지 않다.
    🧮 풀이
    1. 관로를 정비하려고 작업자 甲이 스톱 밸브를 손으로 닫았다. 관로의 유체 흐름이 완전히 멈췄다. 역류가 생길 때 원판이 스스로 내려와 닫히는 그림의 장치와 구분됐다.
    2. 펌프가 멈추자 관 안의 물이 역방향으로 움직이려 했다. 작업자 甲은 체크 밸브의 원판이 시트에 닿아 통로를 막는 것을 확인했다. 배출한 물이 펌프 쪽으로 되돌아오지 않았다.
    3. 배관 압력이 설정값을 넘자 릴리프 밸브가 열렸다. 기관사 甲은 배출 경로로 빠져나간 유체 덕분에 압력이 내려간 것을 확인했다. 압력 보호와 역류 방지는 다른 기능이었다.
    4. 유량이 목표보다 높아지자 작업자 甲이 유량 조절 밸브의 개도를 줄였다. 관로의 흐름량이 내려갔다. 역류할 때 자동으로 닫히는 체크 밸브와 조작 목적이 분명히 달랐다.

    그림의 원판이 한쪽 흐름에서 열리고 역류 때 자리에 닿아 닫히는 기호는 체크 밸브다. 따라서 2번이 정답이다.

    곡류표면고정방법의 인정기준상 산적화물선에서 곡류표면의 고박장치로 옳지 않은 것은?

    1. 1. wire mesh
    2. 2. lashing wire
    3. 3. steel strap
    4. 4. lashing bridge

    정답 4번

    🔍 보기별 해설
    1. wire mesh는 곡류 표면을 덮어 낟알이 옆으로 이동하지 않게 하는 철망이다. 곡류 고박장치에 해당하므로 옳다.
    2. lashing wire는 곡류 표면을 가로질러 당겨 묶는 와이어다. 표면 이동을 제한하므로 옳다.
    3. steel strap은 곡류 표면을 띠로 눌러 고정하는 강철 밴드다. 표면 이동을 제한하므로 옳다.
    4. lashing bridge는 컨테이너선 갑판에 세워 컨테이너 고박을 돕는 구조물이다. 산적 곡류의 표면 고박장치가 아니므로 옳지 않다(정답).
    🧮 풀이
    1. 곡물 표면 위에 wire mesh를 펼친 선원 甲이 가장자리를 단단히 고정했다. 선박이 기울어도 철망이 표면의 낟알을 눌렀다. 곡류가 한쪽으로 흘러가는 양이 줄었다.
    2. 곡류 표면을 가로지르는 lashing wire를 선원 甲이 양쪽 고리에 묶었다. 장력을 맞춰 표면을 단단히 눌렀다. 항해 중 흔들림에도 윗부분의 낟알이 크게 움직이지 않았다.
    3. steel strap을 곡물 위에 여러 줄 걸고 선원 甲이 조임 장치로 당겼다. 띠가 표면을 가로질러 곡류를 눌렀다. 선박이 좌우로 움직여도 표면 이동이 제한됐다.
    4. 컨테이너선 갑판의 lashing bridge에 작업자 甲이 올라가 상자 고박 장치를 걸었다. 브리지가 높이 쌓은 컨테이너의 고박 위치를 제공했다. 산적 곡류의 표면에는 이 구조물을 놓지 않았다.

    와이어 메시·래싱 와이어·스틸 스트랩은 곡류 표면을 고정한다. 래싱 브리지는 컨테이너 고박 구조물이므로 4번이 옳지 않다.

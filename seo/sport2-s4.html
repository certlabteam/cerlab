    성인의 1 MET가 의미하는 것은?

    1. 1. V̇CO₂
    2. 2. V̇O₂ rest
    3. 3. V̇O₂ max
    4. 4. V̇O₂ peak

    정답 2번

    🔍 보기별 해설
    1. V̇CO₂는 호흡으로 내보낸 이산화탄소의 양을 나타내며 산소 소비량은 알려주지 않는다. 1 MET의 기준은 안정 시 산소 섭취량이므로 옳지 않다.
    2. V̇O₂ rest는 쉬고 있을 때 몸이 소비하는 산소량이며 분당 값으로 나타낸다. 이것을 기준으로 운동 강도를 MET로 나타내므로 옳다(정답).
    3. V̇O₂ max는 강도를 높여도 더 늘지 않는 최대 산소 섭취량이며 운동 능력 평가에 쓴다. 안정 상태를 나타내는 1 MET와 다르므로 옳지 않다.
    4. V̇O₂ peak는 검사 중 실제로 측정된 가장 높은 산소 섭취량이며 종료 시점의 기록이다. 안정 시 산소 소비를 뜻하지 않으므로 옳지 않다.
    🧮 풀이
    1. 경사로를 오른 甲은 내쉬는 공기 속 이산화탄소량을 재었다. 그 값은 몸에서 밖으로 나온 기체량으로 기록되었다. 운동 강도의 바탕이 되는 안정 시 산소 섭취량과 구별되는 이산화탄소 배출량이다.
    2. 의자에 앉아 甲이 쉬는 동안 체중 1kg당 분당 약 3.5mL의 산소를 소비했다. 이후 걷기 운동의 산소 섭취량을 이 수치와 비교했다. 이렇게 쉬는 동안 소비한 산소를 기준으로 삼는 값이 1 MET다.
    3. 러닝머신을 달린 甲은 속도와 경사를 계속 높였다. 어느 순간 산소 섭취량은 더 올라가지 않았다. 운동 강도를 더 높여도 증가하지 않은 산소 섭취의 최고 수준이 최대산소섭취량이다.
    4. 자전거 검사를 받은 甲은 마지막 구간에서 가장 높은 산소 섭취량을 기록했다. 검사 종료 뒤에는 그 값보다 더 높은 수치를 확인하지 못했다. 실제 검사에서 관찰한 최고값을 가리키는 최대 관찰 산소 섭취량이다.

    1 MET는 성인이 가만히 쉴 때의 산소 섭취량을 뜻한다. 체중 1kg당 분당 약 3.5mL를 기준으로 하므로 정답은 2번이다.

    〈보기〉에서 설명하는 것은? 쾌적한 환경(온도 21℃, 습도 50%)에서 일정한 강도(50% V̇O₂ max)로 60분 동안 운동 시 35~45분 후에 체온은 고원(plateau)에 도달하여 일정하게 유지된다.

    1. 1. 항정상태(steady state)
    2. 2. 항상성(homeostasis)
    3. 3. 정적 피드백(positive feedback)
    4. 4. 부적 피드백(negative feedback)

    정답 1번

    🔍 보기별 해설
    1. 항정상태는 같은 운동 강도를 유지할 때 생리적 값이 큰 변화 없이 이어지는 상태다. 체온이 35~45분 뒤 고원에 머물렀으므로 옳다(정답).
    2. 항상성은 몸의 내부 환경을 일정 범위로 유지하려는 넓은 조절 능력이다. 보기에서 한 운동 조건의 체온이 고원에 이른 상태는 항정상태이므로 옳지 않다.
    3. 정적 피드백은 처음 생긴 변화를 더 크게 증폭하는 조절 방식이다. 체온이 더 오르지 않고 일정하게 유지된 결과와 맞지 않으므로 옳지 않다.
    4. 부적 피드백은 기준에서 벗어난 변화를 줄이는 조절 과정이다. 보기에서 묻는 체온 고원의 결과 상태는 항정상태이므로 옳지 않다.
    🧮 풀이
    1. 트레드밀에서 甲이 같은 속도로 40분을 달렸다. 땀과 피부 혈류가 늘면서 운동 초기에 나타난 체온 상승이 멈췄다. 운동 강도는 그대로인데 체온이 한 수준에 머무른 상태가 항정상태다.
    2. 휴식 중인 甲은 더운 실내에 들어가자 땀을 흘렸다. 시원한 곳으로 나오자 몸은 땀 분비를 다시 줄이며 체온을 조절했다. 여러 환경에서 내부 온도를 일정 범위로 지키려는 몸의 기능은 항상성이다.
    3. 상처를 입은 甲이 피를 흘리자 혈액 응고 반응이 연달아 커졌다. 앞선 반응이 다음 반응을 더 강하게 밀어 응고가 빠르게 이어졌다. 변화가 스스로 증폭되는 흐름이 정적 피드백이다.
    4. 더운 길을 따라 甲이 걸으며 체온이 올라가자 땀이 평소보다 많이 났다. 땀이 피부에서 증발하면서 올라간 체온이 다시 낮아졌다. 처음의 변화를 되돌리도록 반응하는 조절 과정이 부적 피드백이다.

    운동 중 열 생산과 방출이 균형을 이루면 체온이 일정해진다. 한 운동 조건에서 값이 고원에 머물렀으므로 정답은 1번이다.

    인체 내 포도당신생합성(gluconeogenesis)의 주요 기질(substrate)이 아닌 것은?

    1. 1. 염소(chlorine)
    2. 2. 젖산염(lactate)
    3. 3. 알라닌(alanine)
    4. 4. 글리세롤(glycerol)

    정답 1번

    🔍 보기별 해설
    1. 염소는 무기 원소여서 포도당을 만들 탄소 골격이 없다. 간에서 포도당신생합성의 주요 재료로 쓰이지 않으므로 옳지 않다(정답).
    2. 젖산염은 운동한 근육에서 만들어져 혈액을 타고 간으로 이동한다. 간에서 탄소 골격을 이용해 다시 포도당으로 바뀔 수 있는 주요 기질이므로 옳다.
    3. 알라닌은 근육에서 간으로 운반될 수 있는 아미노산이며 운동 중 질소도 함께 나른다. 간에서 그 탄소 골격이 포도당 생성에 쓰이므로 옳다.
    4. 글리세롤은 저장 지방인 중성지방이 분해될 때 지방산과 함께 나온다. 간에서 포도당을 새로 만드는 데 쓸 수 있는 재료가 되므로 옳다.
    🧮 풀이
    1. 공복에 甲이 걸을 때 몸에는 염소 이온이 혈액과 세포액에 들어 있었다. 하지만 그 무기 이온만으로 포도당의 탄소 뼈대를 만들 수 없었다. 새로운 포도당을 만드는 주요 재료 목록에서 제외되는 염소다.
    2. 운동장에서 甲이 빠르게 달리자 근육에서 젖산염이 생겼다. 혈액을 따라 간에 도착한 젖산염은 포도당으로 다시 만들어졌다. 운동 중 나온 물질을 재활용하는 포도당신생합성의 젖산염 기질이다.
    3. 긴 운동을 마친 甲이 쉬는 동안 근육의 알라닌이 혈액을 타고 간으로 보내졌다. 간은 알라닌에서 얻은 탄소 골격으로 필요한 포도당을 새로 만들었다. 근육과 간을 잇는 포도당신생합성의 알라닌 기질이다.
    4. 식사 전 甲이 달릴 때 지방 조직에서 저장된 중성지방이 분해되었다. 나온 글리세롤이 혈액을 따라 간으로 이동해 포도당 합성에 쓰였다. 지방 분해와 포도당 공급을 잇는 글리세롤 기질이다.

    젖산염·알라닌·글리세롤은 포도당을 다시 만드는 재료가 된다. 염소는 탄소 골격을 제공하지 않으므로 정답은 1번이다.

    그림은 골격근 섬유의 특징을 보여주고 있다. ㉠에 들어갈 변인으로 옳지 않은 것은?

    1. 1. ATPase 활성도
    2. 2. 최대 특이장력(specific tension)
    3. 3. 최대 수축 속도
    4. 4. 미토콘드리아 수

    정답 4번

    🔍 보기별 해설
    1. Type IIx 섬유는 빠른 수축에 맞춰 미오신 ATPase 활성이 높다. Type I보다 높은 특성으로 제시할 수 있으므로 옳다.
    2. 최대 특이장력은 근섬유 단면적을 고려해 비교한 최대 힘을 뜻한다. 순간적으로 큰 힘을 내는 Type IIx가 Type I보다 높은 쪽으로 비교되므로 옳다.
    3. Type IIx 섬유는 짧은 시간에 빠르게 힘을 내도록 발달한 빠른 근섬유다. 최대 수축 속도가 지구성 Type I보다 높으므로 옳다.
    4. 미토콘드리아는 산소를 이용해 ATP를 만드는 세포 소기관이다. 지구성인 Type I에 더 많으므로 Type IIx가 높다는 설명은 옳지 않다(정답).
    🧮 풀이
    1. 단거리 트랙에서 甲은 전력으로 달렸고 Type IIx 섬유가 빠르게 수축했다. 미오신 머리에서 ATP를 분해하는 반응이 활발했다. 빠른 수축을 뒷받침하는 높은 미오신 ATPase 활성도다.
    2. 무거운 중량을 든 甲은 빠른 섬유에서 순간적으로 큰 힘을 냈다. 같은 단면적을 놓고 느린 섬유와 힘을 비교해도 큰 값이 나왔다. 빠른 섬유에서 더 높게 나타나는 최대 특이장력이다.
    3. 출발 신호에 맞춰 甲이 짧은 거리를 빠르게 뛰었다. Type IIx 섬유가 Type I보다 빠르게 짧아져 순간적인 움직임을 만들었다. 빠른 섬유를 구별하는 높은 최대 수축 속도다.
    4. 장거리 달리기를 이어 간 甲은 Type I 섬유로 산소를 써 ATP를 꾸준히 만들었다. 세포 안에는 그 일을 맡는 미토콘드리아가 많이 자리했다. Type IIx보다 Type I에서 더 두드러지는 미토콘드리아 수다.

    Type IIx는 빠른 수축에 강하고 Type I은 산화 능력에 강하다. 미토콘드리아는 Type I에 더 많으므로 정답은 4번이다.

    근육 세포에서 크레아틴 카이네이즈(Creatine Kinase, CK)의 활성도를 증가시키는 것은?

    1. 1. ATP 증가
    2. 2. NAD 감소
    3. 3. ADP 증가
    4. 4. 젖산 감소

    정답 3번

    🔍 보기별 해설
    1. ATP가 충분하면 근육 세포가 당장 ATP를 다시 만들어야 할 요구가 상대적으로 작다. ADP 증가와 달리 CK 반응을 촉진하는 직접적인 변화가 아니므로 옳지 않다.
    2. NAD 감소는 여러 산화환원 반응에 영향을 줄 수 있다. 크레아틴 카이네이즈를 직접 활성화하는 핵심 신호는 아니므로 옳지 않다.
    3. ADP가 늘면 크레아틴인산의 인산기를 ADP에 옮겨 ATP를 재생하는 반응이 커진다. 이를 촉매하는 CK의 작용이 늘어나므로 옳다(정답).
    4. 젖산 감소는 해당과정에서 생긴 물질의 변화를 보여준다. 크레아틴 카이네이즈 활성 증가의 직접 원인으로 보기 어려우므로 옳지 않다.
    🧮 풀이
    1. 짧은 운동을 멈춘 甲은 근육에 ATP가 충분한 상태였다. 급히 ATP를 보충할 필요가 줄어 크레아틴인산 반응의 요구도 작았다. CK 활성 증가의 신호로 보기 어려운 ATP 증가다.
    2. 체육관에서 甲은 근력 운동을 하며 세포의 NAD 양이 변했다. 그 변화만으로 크레아틴인산이 ADP에 인산기를 건네는 반응이 직접 켜지지는 않았다. CK를 움직이는 핵심 자극과 구별되는 NAD 감소다.
    3. 전력으로 甲이 달리자 근육에서 ATP가 쓰이며 ADP가 늘었다. 크레아틴인산이 ADP에 인산기를 건네 ATP를 빠르게 다시 만들었다. 이 전달 반응을 촉매하는 CK의 활성이 커지는 상황이다.
    4. 속도를 낮춘 甲은 근육에서 젖산 생성이 줄어들었다. 젖산 변화만으로 크레아틴인산과 ADP 사이의 인산기 전달을 설명할 수는 없었다. CK 활성의 직접 신호와 다른 젖산 감소다.

    ATP가 쓰이면 ADP가 늘고 크레아틴인산이 ATP 재합성에 동원된다. 이 반응을 돕는 CK 활성은 ADP 증가와 연결되므로 정답은 3번이다.

    〈보기〉에서 설명하는 것은? • 빛에 의한 분비 억제 • 수면 유도 및 수면 주기 조절 • 솔방울샘(송과체, pineal gland)에서 분비되는 호르몬

    1. 1. 인슐린
    2. 2. 글루카곤
    3. 3. 코티졸
    4. 4. 멜라토닌

    정답 4번

    🔍 보기별 해설
    1. 인슐린은 췌장 베타세포에서 나와 근육과 지방의 포도당 이용을 돕고 혈당을 낮춘다. 솔방울샘에서 나오는 수면 조절 호르몬이 아니므로 옳지 않다.
    2. 글루카곤은 췌장 알파세포에서 나와 혈당을 높이는 호르몬이다. 빛에 의해 분비가 억제되는 솔방울샘 호르몬이 아니므로 옳지 않다.
    3. 코티졸은 부신피질에서 분비되어 스트레스와 에너지 대사에 관여하는 호르몬이다. 보기에서 제시한 솔방울샘 분비 장소와 맞지 않으므로 옳지 않다.

    3. 마이오글로빈은 근육 안에서 산소를 붙잡아 필요할 때 공급한다. 적혈구용적률이 늘면 혈액 점성은 감소하지 않고 커지므로 옳지 않다.

    1. 달리기를 한 甲은 혈액의 적혈구 안 헤모글로빈으로 산소를 운반했다. 근육 안에서는 마이오글로빈이 그 산소를 붙잡았고 적혈구가 늘면 혈액은 더 진해졌다. 혈액 산소 운반을 맡는 헤모글로빈과 점성 변화다.
    2. 긴 거리를 걸은 甲은 적혈구 안의 헤모글로빈으로 근육까지 산소를 보냈다. 적혈구 비율이 높으면 혈액은 더 끈끈해졌지만 근육 안 저장 단백질은 별개였다. 혈액 속 산소 운반 단백질인 헤모글로빈이다.
    3. 자전거를 탄 甲은 근섬유의 마이오글로빈에 산소를 잠시 붙잡아 뒀다. 적혈구 비율도 커졌다면 혈액은 묽어지지 않고 점성이 올라갔다. 근육의 산소 저장과 구별되는 적혈구용적률의 점성 증가다.
    4. 오르막을 오른 甲은 근육 속 마이오글로빈에서 산소를 사용했다. 적혈구가 차지하는 비율이 커지자 혈액의 흐름 저항도 높아졌다. 근육의 산소 저장과 혈액 점성 증가를 연결하는 마이오글로빈·적혈구용적률이다.

    근육 안에서 산소를 붙잡는 단백질은 마이오글로빈이고 적혈구 비율이 오르면 혈액 점성도 커진다. 두 빈칸을 맞게 채웠으므로 정답은 4번이다.

    펄스부호변조(PCM, pulse code modulation)의 입출력 신호와 과정을 순서대로 바르게 나열한 것은?

    (가) 아날로그 신호 (나) 부호화 (다) 양자화 (라) 표본화 (마) 디지털 신호

    1. 1. (가) － (나) － (다) － (라) － (마)
    2. 2. (가) － (라) － (다) － (나) － (마)
    3. 3. (마) － (다) － (라) － (나) － (가)
    4. 4. (마) － (라) － (나) － (다) － (가)

    정답 2번

    🔍 보기별 해설
    1. (가)－(나)－(다)－(라)－(마)는 부호화된 값과 중간 처리를 먼저 두는 순서다. 표본화 뒤 양자화·부호화가 이어져야 하므로 옳지 않다.
    2. (가)－(라)－(다)－(나)－(마)는 아날로그 입력 뒤 표본화·양자화·부호화를 거쳐 디지털 출력으로 간다. PCM 처리 순서이므로 옳다(정답).
    3. (마)에서 시작하는 배열은 디지털 출력을 입력으로 둔다. 송신측 PCM 변환의 진행 방향과 반대이므로 옳지 않다.
    4. (마)에서 시작하고 (가)로 끝나는 배열은 출력에서 입력으로 거슬러 간다. 아날로그 입력의 부호화 순서가 아니므로 옳지 않다.
    🧮 풀이
    1. 마이크의 연속 전압을 일정한 시간 간격으로 읽으면 표본들이 생긴다. 아직 값이 연속적인 표본을 단계별 전압으로 반올림해야 양자화가 끝난다. 이 과정을 건너뛰고 부호화를 앞세울 수 없다.
    2. 마이크가 내는 연속 전압 (가)를 표본화 장치 (라)가 일정 간격으로 읽는다. 양자화 (다)가 각 표본을 정해진 단계로 바꾸고 부호화 (나)가 비트열을 만든다. 마지막에 디지털 신호 (마)가 출력된다.
    3. PCM 송신기의 출력 비트열 (마)을 먼저 놓고 입력 신호를 뒤에 적으면 처리 방향이 뒤집힌다. 수신기가 비트열을 복원하는 방향은 별도다. 여기서는 아날로그 입력에서 디지털 출력으로 진행한다.
    4. 디지털 출력 (마)에서 출발해 아날로그 입력 (가)으로 끝나는 화살표를 그린다. 이 흐름은 송신측 표본화·양자화·부호화의 정방향과 반대다. 입력 파형을 먼저 읽는 (가)에서 시작해야 한다.

    PCM(Pulse Code Modulation)은 아날로그 입력을 표본화·양자화·부호화해 디지털 출력으로 만든다. 이 순서를 표시한 2번이 정답이다.

    안테나에 대한 설명으로 옳지 않은 것은?

    1. 1. 등방성 안테나의 지향성은 1보다 크다.
    2. 2. 다이폴(dipole) 안테나는 일반적으로 전방향성 빔 패턴을 갖는다.
    3. 3. 기하학적 모양에 따라 도선 안테나, 개구면 안테나, 평면형 안테나 등으로 분류된다.
    4. 4. 등방성 안테나로부터 수신되는 신호의 전력밀도는 이론적으로 안테나로부터 거리의 제곱에 반비례한다.

    정답 1번

    🔍 보기별 해설
    1. 등방성 안테나의 지향성은 최대 방사 세기를 평균 방사 세기로 나눈 값 1이다. 1보다 크다는 설명은 옳지 않다(정답).
    2. 반파장 다이폴 안테나는 축 주위의 수평 방향으로 비슷하게 방사한다. 전방향성 빔의 대표적인 예이므로 옳다.
    3. 도선·개구면·평면형은 안테나의 기하학적 구조에 따른 분류다. 형태에 따른 구분이므로 옳다.
    4. 등방성 안테나의 전력은 거리 r에서 구면 4πr²에 퍼진다. 전력밀도가 거리의 제곱에 반비례하므로 옳다.
    🧮 풀이
    1. 이상적인 등방성 안테나에서 방사 구면의 모든 방향을 같은 세기로 잡는다. 가장 강한 방향과 평균 방향의 세기가 같아 비율이 1이다. 특정 방향으로 전력을 모으는 실제 안테나의 지향성과 기준점을 구별한다.
    2. 수직으로 세운 반파장 다이폴의 수평면 방사 패턴을 그리면 중심축 주위를 둥글게 둘러싼다. 축 방향 위아래로는 약하지만 수평 방향 어디서나 신호를 받을 수 있다. 이런 면에서 전방향성이라고 부른다.
    3. 간단한 금속 막대는 도선 안테나에, 파라볼라 반사경의 입구는 개구면 안테나에 넣는다. 회로 기판 위에 붙인 패치 구조는 평면형 안테나의 사례다. 세 분류는 외형 구조를 기준으로 구분한다.
    4. 등방성 안테나에서 1 m 떨어진 구면과 2 m 떨어진 구면을 비교한다. 반지름이 두 배면 면적이 네 배이므로 같은 송신 전력이 네 배 넓게 퍼진다. 단위 면적당 받는 전력은 4분의 1이다.

    등방성 안테나는 모든 방향으로 같은 세기로 방사하므로 지향성이 정의상 1이다. 1보다 크다고 한 1번이 옳지 않다.

    20 [dB] 증폭된 신호전력이 2.4 [W]일 때, 증폭되기 전의 신호전력 [mW]은?

    1. 1. 1.2
    2. 2. 2.4
    3. 3. 12
    4. 4. 24

    정답 4번

    🔍 보기별 해설
    1. 출력 2.4 W는 2400 mW이고 전력 배율은 100이다. 입력은 2400/100=24 mW이므로 옳다(정답).
    🧮 풀이
    1. ① 증폭 뒤 전력 2.4 W를 답 단위 mW로 바꾼다. 1 W가 1000 mW이므로 2.4 W는 2400 mW다.
    2. → P_out=2400 mW
    3. ↓
    4. ② 전력 이득 20 dB를 선형 비율로 바꾼다. 전력의 dB에는 10log를 쓰므로 배율은 10^(20/10)=100이다.
    5. → P_out/P_in=100
    6. ↓
    7. ③ 출력 전력을 배율로 나눠 입력을 구한다. 24 mW를 100배 하면 2400 mW로 돌아간다.
    8. → P_in=2400/100=24 mW

    20 dB 전력 이득은 100배다. 출력 2400 mW를 100으로 나누면 입력은 24 mW다.

    대역폭이 B [Hz]인 AWGN 채널을 통해 수신된 신호의 신호대 잡음비를 SNR 이라고 할 때, 이 전송 채널을 통해 오류 없이 수신될 수 있는 섀넌(Shannon)의 최대 채널 용량[bps]은?

    1. 1. B log_2 (1 + SNR)
    2. 2. {1 / B} log_2 (1 + SNR)
    3. 3. B log_2 (1 + {1 / SNR})
    4. 4. {1 / B} log_2 (1 + {1 / SNR})

    정답 1번

    🔍 보기별 해설
    1. C=B log₂(1+SNR)은 AWGN(Additive White Gaussian Noise) 채널의 섀넌(Shannon) 용량식이다. 대역폭과 신호대잡음비를 올리면 용량이 늘어 옳다(정답).
    2. 대역폭 B를 분모에 두면 B가 넓어질수록 용량이 줄어든다. 대역폭에 비례하는 채널 용량식과 반대여서 옳지 않다.
    3. 1/SNR을 쓰면 신호가 강해질수록 로그항이 작아진다. 신호대잡음비가 클수록 용량이 증가해야 하므로 옳지 않다.
    4. 대역폭을 분모에 두고 1/SNR을 쓰면 두 관계가 모두 뒤집힌다. 섀넌 용량식의 비례 관계와 맞지 않아 옳지 않다.
    🧮 풀이
    1. 대역폭 1 MHz의 잡음 채널에서 수신 전력과 잡음 전력을 재어 선형 신호대잡음비를 구한다. 이 값을 1에 더해 밑 2 로그를 취한다. 결과에 1 MHz를 곱하면 비트/초 단위의 이론적 최대 전송률이 나온다.
    2. 같은 신호대잡음비를 유지하고 채널 폭을 1 MHz에서 2 MHz로 넓힌다. 사용 가능한 주파수 자원이 두 배가 되어 이론적 채널 용량도 두 배가 된다. 1/B를 곱하면 이 물리적 관계를 거꾸로 나타낸다.
    3. 잡음은 그대로 두고 수신 신호 전력을 네 배로 키운다. 신호대잡음비가 커져 안정적으로 구별할 수 있는 신호 상태가 많아진다. 1/SNR을 넣으면 오히려 계산된 용량이 낮아진다.
    4. 통신 시스템의 채널 폭과 수신 신호 전력을 함께 늘려 본다. 두 조치는 모두 이론적 용량을 키운다. B를 분모에 놓고 SNR의 역수를 쓰는 식은 두 조치 모두에 반대 결과를 낸다.

    섀넌의 AWGN 채널 용량은 대역폭 B에 log₂(1+SNR)을 곱한 값이다. 정답은 1번이다.

    OFDM(orthogonal frequency division multiplexing)에 대한 설명으로 옳지 않은 것은?

    1. 1. 단일 반송파 전송 방식보다 등화기 구조가 간단하다.
    2. 2. CP(cyclic prefix)의 길이가 길어질수록 심볼 전송률이 증가한다.
    3. 3. CP의 길이를 최대 지연 시간보다 길게 설정하면 부반송파들 간의 직교성이 깨지는 현상을 방지할 수 있다.
    4. 4. 심볼에 보호구간을 삽입하여 다중경로 채널에 의해 발생하는 인접 심볼 간 간섭 문제를 해결할 수 있다.

    정답 2번

    🔍 보기별 해설
    1. OFDM(Orthogonal Frequency Division Multiplexing)은 다수 부반송파에 데이터를 나눠 실어 각 부반송파의 등화를 단순화한다. 단일 반송파보다 간단한 등화기가 가능하므로 옳다.
    2. CP(Cyclic Prefix)가 길어지면 한 심벌의 전체 전송시간이 길어져 같은 시간에 보내는 유효 심벌 수가 줄어든다. 전송률이 증가한다는 설명은 옳지 않다(정답).
    3. CP를 최대 지연시간보다 길게 잡으면 앞 심벌의 잔향이 유효 구간에 들어오지 않는다. 부반송파의 직교성 유지에 도움이 되므로 옳다.
    4. 심벌 앞의 보호구간은 이전 심벌에서 늦게 온 다중경로 성분을 흡수한다. 인접 심벌 간 간섭을 줄이므로 옳다.
    🧮 풀이
    1. 넓은 전송 대역을 여러 좁은 부반송파로 나누면 각 부반송파가 겪는 채널 변화가 완만해진다. 수신기는 부반송파마다 단순한 계수 하나로 보정할 수 있다. 같은 넓은 대역을 한 반송파로 보내는 경우보다 등화 구조가 쉬워진다.
    2. 유효 심벌 시간이 100 μs이고 CP가 10 μs이면 전체 심벌은 110 μs다. CP를 30 μs로 늘리면 전체가 130 μs가 된다. 초당 보낼 수 있는 유효 심벌 수는 줄어든다.
    3. 실내 반사파의 최대 지연이 5 μs인 채널에서 CP를 6 μs로 둔다. 이전 심벌의 늦은 반사파가 보호구간 안에서 끝난다. 유효 심벌 구간에 들어가 부반송파 직교성을 흐트러뜨릴 가능성이 줄어든다.
    4. 앞 OFDM 심벌이 벽에 반사되어 다음 심벌 시각에 늦게 도착한다. 다음 심벌 앞의 CP 구간이 그 잔향을 받아낸다. 수신기는 보호구간을 버리고 간섭이 줄어든 유효 구간만 복조한다.

    OFDM의 CP는 보호구간이라 길어질수록 유효 심벌이 차지하는 시간 비율이 줄어든다. 심벌 전송률이 증가한다는 2번이 옳지 않다.

    다음 설명에 해당하는 소규모 페이딩은?

    이동국이 기지국으로부터 수신하는 신호의 심볼 주기(symbol period)가 이동통신 채널의 지연확산(delay spread)보다 매우 작고, 이동국의 코히런스 시간(coherence time)보다 매우 크다.

    1. 1. 주파수 선택적 빠른 페이딩
    2. 2. 주파수 선택적 느린 페이딩
    3. 3. 주파수 비선택적 빠른 페이딩
    4. 4. 주파수 비선택적 느린 페이딩

    정답 1번

    🔍 보기별 해설
    1. 지연확산 때문에 심벌 안에 서로 다른 경로가 겹치고, 채널도 심벌 동안 빠르게 변한다. 주파수 선택적 빠른 페이딩이므로 옳다(정답).
    2. 지연확산에 따른 주파수 선택성은 맞다. 심벌 시간보다 코히런스 시간이 짧아 느린 페이딩이라는 부분은 옳지 않다.
    3. 빠른 페이딩은 맞지만 지연확산이 심벌보다 길면 주파수별 채널 응답이 달라진다. 주파수 비선택적이라는 부분은 옳지 않다.
    4. 심벌보다 큰 지연확산과 짧은 코히런스 시간은 각각 선택성과 빠른 변화를 뜻한다. 둘 다 비선택적·느림이라는 분류는 옳지 않다.
    🧮 풀이
    1. 심벌 길이가 1 μs인데 반사파들의 도착 차이가 3 μs인 실내 채널을 쓴다. 심벌의 주파수 성분들이 서로 다른 감쇠를 받아 주파수 선택성이 생긴다. 단말이 움직여 채널이 1 μs 안에도 변하면 빠른 페이딩까지 겪는다.

    2. DSB-TC(Double Sideband Transmitted Carrier)는 반송파와 두 측파대를 전송한다. 점유 대역폭은 약 2B여서 가장 좁지 않으므로 옳지 않다.
    3. SSB(Single Sideband)는 상측파대나 하측파대 하나만 보낸다. 메시지 대역폭 B만 차지해 보기 중 가장 좁으므로 옳다(정답).
    4. 협대역 FM(Frequency Modulation)은 작은 변조지수에서 주된 측파대가 반송파 양쪽에 생긴다. 점유 폭은 대략 2B여서 SSB보다 넓으므로 옳지 않다.
    🧮 풀이
    1. 음성 신호가 0~3 kHz의 대역을 차지한다고 놓는다. DSB-SC 송신기의 반송파를 억압해도 위쪽 3 kHz와 아래쪽 3 kHz의 측파대는 남는다. 전체 점유 폭은 약 6 kHz다.
    2. 같은 0~3 kHz 음성을 DSB-TC로 송신한다. 중심의 반송파와 양쪽에 펼쳐진 측파대가 함께 나온다. 반송파를 더해도 측파대 끝 사이 폭은 약 6 kHz다.
    3. 같은 음성의 상측파대만 필터로 남기고 하측파대를 제거한다. 반송파 위쪽의 3 kHz 구간에 정보가 담긴다. 한쪽 측파대만 써 점유 폭이 3 kHz로 줄어든다.
    4. 작은 변조지수로 음성을 FM 변조하면 반송파 가까이에 양쪽 측파대가 생긴다. 0~3 kHz 음성의 주된 성분은 중심 양편으로 퍼진다. 대략 6 kHz의 폭을 보며 한쪽만 남긴 SSB와 비교한다.

    SSB는 메시지의 한쪽 측파대만 남겨 대역폭 B를 쓴다. 양측파대를 쓰는 방식보다 좁아 3번이 정답이다.

    3. UHF(Ultra High Frequency)는 전리층을 통과해 위성이나 지상 가시거리 통신에 쓰인다. 단파의 전리층 반사 경로와 달라 옳지 않다.
    4. SHF(Super High Frequency)는 마이크로파 위성·레이더 등에 쓰이는 높은 대역이다. 전리층에 반사되는 단파 통신의 대역이 아니므로 옳지 않다.

    3. 위성 수신기가 UHF 신호를 지상에서 받아 궤도까지 이어지는 경로를 쓴다. 신호가 전리층을 지나야 위성에 닿는다. HF의 지상 귀환 경로를 적용하면 위성 링크가 성립하기 어렵다.

    지구국과 위성 간 통신시스템의 특성으로 옳지 않은 것은?

    1. 1. 저궤도 위성은 정지궤도 위성보다 도플러 편이가 크다.
    2. 2. 정지궤도 위성은 저궤도 위성보다 전송 지연이 길다.
    3. 3. 태양, 지구, 위성의 정렬 상태에 따라 통신품질이 변할 수 있다.
    4. 4. 일정한 통신품질 제공을 위하여 정지궤도 위성은 하루에 2회 지구를 공전한다.

    정답 4번

    🔍 보기별 해설
    1. 저궤도 위성은 지상국에 대한 상대 이동이 빨라 수신 주파수의 도플러 편이가 크다. 정지궤도와 비교한 설명이므로 옳다.
    2. 정지궤도 위성은 저궤도보다 멀리 있어 전파가 왕복하는 시간이 길다. 전송 지연이 더 크므로 옳다.
    3. 태양이 지상국의 위성 방향과 겹치면 태양 잡음이 수신기에 강하게 들어올 수 있다. 정렬 상태가 품질에 영향을 주므로 옳다.
    4. 정지궤도 위성은 하루에 한 번 지구를 돌아 지상에서 거의 고정돼 보인다. 하루 두 번 돈다는 설명은 옳지 않다(정답).
    🧮 풀이
    1. 저궤도 위성이 지상국 하늘을 빠르게 가로지른다. 접근할 때와 멀어질 때 수신 주파수가 서로 다른 방향으로 이동한다. 같은 곳에 보이는 정지궤도 위성보다 도플러 보정이 많이 필요하다.
    2. 지상국에서 낮은 궤도 위성과 적도 상공 약 36000 km의 정지궤도 위성에 각각 신호를 보낸다. 먼 위성까지 전파가 가고 돌아오는 시간이 더 길다. 음성 통신에서는 그 차이가 지연으로 느껴진다.
    3. 태양과 위성과 지상국 안테나가 비슷한 방향으로 나란히 놓인다. 안테나가 위성 신호와 함께 태양의 강한 잡음도 받아 신호대잡음비가 떨어진다. 정렬이 풀리면 수신 상태가 회복된다.
    4. 정지궤도 위성이 지구 자전 방향으로 하루 동안 한 바퀴 공전한다. 지구 표면의 관측자도 함께 한 바퀴 돌아 위성이 하늘의 같은 방향에 보인다. 하루 두 바퀴라면 지상에서 위치가 고정되지 않는다.

    정지궤도 위성은 지구 자전과 같은 주기로 하루에 한 번 공전한다. 두 번 공전한다는 4번이 옳지 않다.

    펄스파 레이더에 대한 설명으로 옳지 않은 것은?

    1. 1. 안테나의 이득이 클수록 최대 탐지거리가 증가한다.
    2. 2. 최대 탐지거리는 송신 펄스의 주기에 반비례한다.
    3. 3. 목표물의 유효 반사면적이 클수록 최대 탐지거리가 증가한다.
    4. 4. 표적으로부터 반사된 신호를 이용하여 표적과의 거리를 계산한다.

    정답 2번

    🔍 보기별 해설
    1. 안테나 이득이 커지면 표적 방향 송신과 반사파 수신이 강해진다. 최대 탐지거리가 늘 수 있으므로 옳다.
    2. 송신 펄스 주기는 모호하지 않게 재는 거리 범위에 영향을 준다. 최대 탐지거리가 그 주기에 단순 반비례한다는 설명은 옳지 않다(정답).
    3. 표적의 유효 반사면적이 크면 레이더 방향으로 돌아오는 반사파가 강해진다. 더 먼 표적도 탐지할 수 있어 옳다.
    4. 레이더는 송신 펄스가 표적에서 반사돼 돌아오는 시간을 잰다. 전파속도와 왕복 시간을 이용해 거리를 계산하므로 옳다.
    🧮 풀이
    1. 기존 접시 안테나 대신 같은 출력의 더 높은 이득 안테나를 표적 방향으로 조준한다. 목표물에 더 강한 전파가 닿고 돌아온 신호도 더 잘 받는다. 수신 문턱을 넘는 탐지 거리가 늘 수 있다.
    2. 펄스 사이 간격을 길게 하면 먼 표적의 반사파가 다음 펄스 전에 돌아올 여유가 커진다. 이 변화는 어느 펄스에서 온 반사파인지 구분하는 비모호 거리에 관계한다. 수신 감도와 반사 전력으로 정하는 탐지 한계와는 별도다.
    3. 같은 거리의 작은 드론과 큰 항공기를 레이더로 관측한다. 큰 항공기가 더 넓은 유효 반사면적을 가지면 보통 더 강한 반사파가 돌아온다. 수신 문턱에 걸리는 먼 거리에서도 탐지될 가능성이 높다.
    4. 레이더가 펄스를 발사하고 200 μs 뒤 같은 펄스의 반사 신호를 받는다. 전파속도에 왕복 시간을 곱한 다음 2로 나눠 표적까지의 편도 거리를 구한다. 반사파의 도착 시간이 거리 정보가 된다.

    펄스 레이더의 최대 탐지거리는 송신전력·안테나 이득·표적 반사면적 등에 영향을 받는다. 송신 펄스 주기에 반비례한다는 2번이 옳지 않다.

    이동통신시스템에 적용되는 기술에 대한 설명으로 옳지 않은 것은?

    1. 1. 다중 안테나를 이용한 공간다중화기법으로 전송률을 높일 수 있다.
    2. 2. 다중 안테나를 이용하여 송신 다이버시티 이득을 얻기 위해서는 송신 안테나 간 상관도가 클수록 효과적이다.
    3. 3. OFDMA(orthogonal frequency division multiple access) 신호는 PAPR(peak-to-average-power ratio)이 큰 특성을 갖는다.
    4. 4. SC-FDMA(single carrier-frequency division multiple access)는 OFDMA에 비해 PAPR이 작기 때문에 상향링크에 적합한 방식이다.

    정답 2번

    🔍 보기별 해설
    1. 공간다중화는 여러 안테나로 서로 다른 데이터 흐름을 동시에 보낸다. 조건이 맞으면 전송률을 높일 수 있어 옳다.
    2. 송신 다이버시티는 안테나 경로가 서로 다르게 페이딩할수록 효과가 크다. 상관도가 클수록 효과적이라는 설명은 옳지 않다(정답).
    3. OFDMA(Orthogonal Frequency Division Multiple Access)는 많은 부반송파가 합쳐질 때 순간 진폭이 커질 수 있다. PAPR(Peak-to-Average Power Ratio)이 크므로 옳다.
    4. SC-FDMA(Single Carrier Frequency Division Multiple Access)는 단일 반송파 특성으로 OFDMA보다 낮은 PAPR을 얻기 쉽다. 송신 전력 증폭기 부담을 줄인다는 설명이므로 옳다.
    🧮 풀이
    1. 두 송신 안테나가 각각 다른 데이터 흐름을 동시에 같은 시간대에 보낸다. 수신기의 여러 안테나가 공간적으로 다른 채널을 이용해 두 흐름을 분리한다. 한 흐름만 보내는 경우보다 전송률이 높아질 수 있다.
    2. 두 안테나가 거의 같은 채널 페이딩을 겪으면 한 안테나 신호가 약해질 때 다른 쪽도 함께 약해진다. 두 경로의 상관을 낮추면 한쪽이 약한 순간 다른 쪽이 보완할 가능성이 커진다. 송신 다이버시티의 이득이 커진다.
    3. OFDMA 송신기의 여러 부반송파가 같은 위상으로 겹치는 순간을 관찰한다. 평균 전력에 비해 큰 순간 첨두 전력이 생긴다. 증폭기는 이 첨두를 찌그러뜨리지 않도록 충분한 여유가 필요하다.
    4. 이동 단말의 상향 송신기에 SC-FDMA를 적용한다. OFDMA에 비해 순간 첨두와 평균 전력의 차이를 낮추기 쉽다. 단말의 전력 증폭기를 더 효율적으로 운용하는 데 도움이 된다.

    송신 다이버시티는 안테나 채널의 상관이 낮을수록 독립적인 경로 이득을 얻기 쉽다. 상관이 클수록 좋다는 2번이 옳지 않다.

    WPAN 통신 규격에 대한 설명으로 옳은 것은?

    1. 1. IEEE 802.15.1은 UWB(ultra wideband) 표준이며, 스펙트럼밀도가 낮다.
    2. 2. IEEE 802.15.1은 UWB 표준이며, 스펙트럼밀도가 높다.
    3. 3. IEEE 802.15.3a는 UWB 표준이며, 스펙트럼밀도가 낮다.
    4. 4. IEEE 802.15.3a는 UWB 표준이며, 스펙트럼밀도가 높다.

    정답 3번

    🔍 보기별 해설
    1. IEEE 802.15.1은 블루투스 계열 규격이다. UWB(Ultra Wideband) 표준이라고 한 부분이 옳지 않다.
    2. IEEE 802.15.1은 블루투스 계열이고 UWB 표준이 아니다. 높은 스펙트럼 밀도라는 설명도 UWB의 특징과 어긋나 옳지 않다.
    3. IEEE 802.15.3a는 UWB 기술을 다루며 에너지를 넓은 주파수 대역에 퍼뜨린다. 단위 주파수당 전력이 낮아 옳다(정답).
    4. IEEE 802.15.3a와 UWB의 연결은 맞다. 넓은 대역에 전력이 퍼져 스펙트럼 밀도가 낮으므로 높다는 부분은 옳지 않다.
    🧮 풀이
    1. 블루투스 이어폰이 휴대전화와 짧은 거리에서 연결된다. 이 계열의 WPAN 규격을 IEEE 802.15.1로 분류한다. 넓은 대역 전체에 낮은 밀도로 전력을 퍼뜨리는 UWB와 구별한다.
    2. 블루투스 기기가 작은 개인 영역 안에서 데이터를 주고받는다. IEEE 802.15.1의 예로 볼 수 있다. UWB의 넓은 주파수 확산과 낮은 단위 대역 전력이라는 특징을 여기에 붙이지 않는다.
    3. 근거리 위치 측정 장치가 UWB 펄스를 매우 넓은 대역에 걸쳐 송신한다. 전체 전력은 넓은 주파수 폭으로 분산돼 주파수 1 Hz당 전력은 낮다. IEEE 802.15.3a와 연결된 UWB의 특징이다.
    4. UWB 송신기의 총 전력을 그대로 두고 신호를 더 넓은 주파수 대역에 퍼뜨린다. 스펙트럼 분석기의 단위 대역당 전력은 낮아진다. IEEE 802.15.3a의 대역을 높은 전력 밀도라고 부르지 않는다.

    IEEE 802.15.3a는 UWB 기술과 연결되며 넓은 대역에 전력을 펼쳐 스펙트럼 밀도가 낮다. 정답은 3번이다.

    "7개 포대가 약간 습기 찼음"에 대한 일반화물의 적요로 옳은 것은?

    1. 1. 7 MODERATELY WET BURLAPS.
    2. 2. 7 SLIGHTLY MOIST BAGS.
    3. 3. 7 SLIGHTLY WET BALES.
    4. 4. 7 HEAVILY MOIST BAGS.

    정답 2번

    🔍 보기별 해설
    1. moderately(웬만큼)는 약간보다 센 정도를 가리키고 wet(젖음)은 습기 찬 것보다 심한 상태이며 burlaps(마대)는 포대와 다른 자루다. 세 군데가 다 어긋나므로 옳지 않다.
    2. slightly(약간)와 moist(습기 참), bags(포대)가 원문의 정도와 상태, 짐 이름에 그대로 맞으므로 옳다(정답).
    3. wet(젖음)은 습기 찬 것보다 심한 상태이고 bales(꾸러미)는 포대와 다른 짐이다. 정도는 맞지만 상태와 짐 이름이 어긋나므로 옳지 않다.
    4. heavily(심하게)는 약간보다 훨씬 세게 젖은 정도를 가리키는 말이다. 상태와 짐 이름은 맞지만 정도가 어긋나므로 옳지 않다.
    🧮 풀이
    1. 甲은 습기가 약간 찬 포대 일곱 개를 적요에 적으며 웬만큼 젖은 마대라고 썼다가 반장에게 정도와 짐 이름이 다 틀렸다는 말을 들었다. 젖은 것과 습기 찬 것은 다른 상태였고 마대와 포대도 다른 짐이었다. 세 군데가 한꺼번에 어긋나 있었다.
    2. 甲은 습기가 약간 찬 포대 일곱 개를 살펴보고 적요에 그대로 옮겨 적었다. 정도와 상태, 짐 이름이 원문과 하나도 어긋나지 않았다. 반장은 표를 훑어보고 그대로 결재해 다음 칸으로 넘어갔다.
    3. 甲은 포대 일곱 개의 상태를 적으며 약간이라는 정도는 맞게 썼지만 짐 이름을 꾸러미로 잘못 적었다. 반장은 포대와 꾸러미는 다른 짐이라고 짚어 주었다. 상태말은 맞아도 짐 이름이 어긋나 있었다.
    4. 甲은 포대 일곱 개의 습기를 심하게 찼다고 적요에 적었다가 반장에게 실제보다 정도를 부풀렸다는 말을 들었다. 실제로 짐이 젖은 정도는 약간에 그쳤을 뿐이었다. 정도말 하나가 실제보다 세게 적혀 있었다.

    습기가 약간 찬 포대라는 원문에 정도·상태·짐 이름이 다 맞는 말을 고르는 것인데 slightly moist bags만 그대로 맞으므로, 정답은 2번이다.

    문장의 번역으로 옳은 것은?

    1. 1. Who is duty officer? - 당직사관은 누구입니까?
    2. 2. I want to meet your chief officer. - 나는 이등항해사를 만나고 싶습니다.
    3. 3. I think this is old damage. - 나는 이것이 노후 비용이라고 생각합니다.
    4. 4. Are you looking for foreman? - 당신은 앞의 남자를 닮았습니까?

    정답 1번

    🔍 보기별 해설
    1. duty officer(당직사관)를 그대로 옮겼다. 지금 당직을 서는 사람이 누구인지 묻는 원문의 뜻이 그대로 맞으므로 옳다(정답).
    2. chief officer(일등항해사)를 이등항해사로 옮겼다. 일등항해사와 이등항해사는 배에서 맡는 자리가 다른 사람이므로 옳지 않다.
    3. old damage(오래된 손상)를 노후 비용으로 옮겼다. 짐이 상한 상태를 가리키는 말을 비용이라는 돈 이야기로 바꿔 옮겼으므로 옳지 않다.
    4. looking for foreman(작업반장을 찾다)을 앞의 남자를 닮았느냐는 전혀 다른 물음으로 옮겼다. 사람을 찾는 물음이 생김새를 묻는 물음으로 바뀌었으므로 옳지 않다.
    🧮 풀이
    1. 甲은 당직사관이 누구냐는 손님의 물음을 그대로 옮겨 갑판의 당직 선원에게 전했다. 선원은 지금은 자기가 당직이라고 곧바로 나서서 답했다. 원문의 뜻이 그대로 전해져 물음과 답이 딱 맞아떨어졌다.
    2. 甲은 일등항해사를 만나고 싶다는 손님의 말을 이등항해사를 찾는 것으로 옮겨 전했다. 불려 온 이등항해사는 자기가 아니라고 손을 저으며 난처해했다. 부르는 자리가 뒤바뀌어 엉뚱한 사람이 나왔다.
    3. 甲은 이것이 오래된 손상이라는 감정사의 말을 노후 비용이라는 뜻으로 옮겨 전했다. 담당자는 무슨 비용이냐며 서류를 다시 펼쳐 되물었다. 짐의 상태를 말한 것이 돈 이야기로 바뀌어 전해졌다.
    4. 甲은 작업반장을 찾느냐는 물음을 앞에 있는 남자를 닮았느냐는 물음으로 옮겨 전했다. 상대는 무슨 소리냐며 눈을 크게 뜨고 어리둥절해했다. 엉뚱한 뜻이 전해져 대화가 한참을 헛돌다 겨우 바로잡혔다.

    원문을 그대로 옮긴 번역을 고르는 것인데 당직사관은 누구입니까만 뜻이 그대로 맞으므로, 정답은 1번이다.

    강재화물(Iron plate)의 명칭으로 옳은 것은?

    1. 1. Semifinished steel: 완제품
    2. 2. Flat bar: 평강
    3. 3. Round bar: 각재
    4. 4. Half round bar: 반각재

    정답 2번

    🔍 보기별 해설
    1. Semifinished steel(반제품)을 완제품으로 옮겼다. 아직 다 만들어지지 않은 중간 단계 강재를 다 만들어진 것으로 뒤바꿨으므로 옳지 않다.
    2. Flat bar(평강)는 단면이 납작한 강재를 가리키는 이름이다. 원어와 우리말 짝이 강재의 생김새 그대로 맞으므로 옳다(정답).
    3. Round bar(환봉)를 각재로 옮겼다. 단면이 둥근 강재의 이름을 단면이 모난 강재의 이름으로 뒤바꿔 옮겼으므로 옳지 않다.
    4. Half round bar(반원형강)를 반각재로 옮겼다. 반원 모양 단면과 각진 모양 단면은 서로 다른 생김새이므로 옳지 않다.
    🧮 풀이
    1. 甲은 아직 다듬지 않은 중간 단계의 강재를 완제품이라고 적요에 적었다가 감독관에게 지적을 받았다. 그 강재는 나중에 한 번 더 손을 봐야 나가는 물건이었다. 중간 단계의 짐을 다 된 물건으로 잘못 적어 둔 것이었다.
    2. 甲은 단면이 납작한 강재 묶음을 보고 적요에 평강이라고 적었다. 화주가 보낸 명세서의 이름과 한 글자도 다르지 않았다. 납작한 생김새가 이름 그대로 적요에 옮겨져 표가 매끄럽게 다 채워졌다.
    3. 甲은 단면이 둥근 강재 다발을 각재라고 적요에 적었다가 다시 살펴보고는 둥근 것과 모난 것은 다른 강재라는 것을 알아챘다. 다발의 단면은 분명히 원 모양이었다. 생김새를 가리키는 말이 뒤바뀌어 있었다.
    4. 甲은 반원 모양 단면의 강재를 반각재라고 적요에 적었다가 반원과 각진 모양은 서로 다른 생김새라는 것을 뒤늦게 알아챘다. 강재의 단면은 둥근 쪽을 반으로 자른 모양이었다. 이름과 실제 생김새가 어긋나 있었다.

    강재의 원어와 우리말 이름이 맞게 짝지어진 것을 고르는 것인데 Flat bar와 평강만 그대로 맞으므로, 정답은 2번이다.

    위험물 검수에 관한 다음 내용에서 ( )에 해당하지 않는 것은?

    If you find any trouble while checking, you should inform to the ( ) of the problem. And then, you should take a step on the matters in their presence.

    1. 1. chief officer
    2. 2. consignor
    3. 3. customs
    4. 4. terminal

    정답 3번

    🔍 보기별 해설
    1. chief officer(일등항해사)는 위험물에 문제가 생겼을 때 즉시 알려야 하는 선박 쪽 책임자다. 발문이 알리라고 한 대상에 들므로 해당한다.
    2. consignor(송하인)도 위험물에 문제가 생겼을 때 알려야 하는 화주 쪽 당사자다. 발문이 알리라고 한 대상에 들므로 해당한다.
    3. customs(세관)는 통관을 맡는 기관이라 현장에서 생긴 위험물 문제를 그 자리에서 알리는 대상은 아니다. 발문이 알리라고 한 대상에 들지 않으므로 해당하지 않는다(정답).
    4. terminal(터미널)도 현장에서 문제가 생기면 곧바로 알려야 하는 운영 쪽 책임자다. 발문이 알리라고 한 대상에 들므로 해당한다.
    🧮 풀이
    1. 甲은 위험물 컨테이너에서 새는 자국을 발견하고 곧바로 일등항해사에게 알렸다. 항해사는 그 자리로 와서 상태를 함께 살피며 필요한 조치를 지시했다. 문제를 알려야 할 첫 자리가 배 쪽 책임자였다.
    2. 甲은 위험물 표찰이 떨어진 것을 보고 송하인 쪽 담당자에게 곧바로 연락해 알렸다. 담당자는 곧 새 표찰을 들고 현장에 나타나 제자리에 다시 붙였다. 짐의 주인 쪽에도 알려야 할 몫이 있었다.
    3. 甲은 위험물에 이상이 생기자 세관에 먼저 알리려다가 통관을 맡는 곳이지 현장 문제를 처리하는 곳이 아니라는 것을 반장에게 들었다. 정작 알려야 할 곳은 따로 있었던 것이다. 엉뚱한 곳에 먼저 연락할 뻔했다.
    4. 甲은 위험물 적재 구역에서 이상 냄새를 맡고 터미널 운영 담당자에게 바로 알렸다. 담당자는 인력을 데리고 현장으로 바삐 달려와 구역을 살폈다. 터미널 쪽도 알려야 하는 자리 가운데 하나였다.

    위험물 문제를 알려야 하는 대상을 고르는 것인데 세관은 통관 기관이라 현장 문제를 알리는 자리가 아니므로, 정답은 3번이다.

    하역장비에 관한 다음 설명에서 ( )에 적합한 것은?

    ( ) is an acceptable working tonnage used for a weight-bearing item of equipment.

    1. 1. Safety working load
    2. 2. Maximum pay load
    3. 3. Breaking load
    4. 4. Test load

    정답 1번

    🔍 보기별 해설
    1. Safety working load(안전 사용 하중)는 장비가 짐을 버티며 안전하게 쓸 수 있는 톤수를 가리키는 말과 그대로 맞으므로 적절하다(정답).
    2. Maximum pay load(최대 적재 중량)는 장비가 실을 수 있는 가장 큰 짐의 무게를 가리키는 말이라 안전하게 쓸 수 있는 톤수와는 뜻이 다르므로 적절하지 않다.
    3. Breaking load(파괴 하중)는 장비가 부서지는 지점의 무게를 가리키는 말이라 안전하게 쓸 수 있는 톤수와는 반대되는 뜻이므로 적절하지 않다.
    4. Test load(시험 하중)는 장비를 시험할 때 거는 무게를 가리키는 말이라 평소에 안전하게 쓸 수 있는 톤수와는 다른 뜻이므로 적절하지 않다.
    🧮 풀이
    1. 甲은 크레인에 붙은 표찰에서 안전 사용 하중이 적힌 숫자를 확인하고 그 무게를 넘지 않도록 짐을 나눠 실었다. 표찰의 숫자는 장비가 버티며 쓸 수 있는 한계였다. 그 한계 안에서 하루 작업이 무사히 끝났다.
    2. 甲은 장비에 적힌 최대 적재 중량을 안전하게 쓸 수 있는 톤수로 착각해 그 무게까지 짐을 실으려 했다. 반장은 그 숫자는 한계에 가까운 값이지 평소에 쓰는 값이 아니라고 짚어 주었다. 두 톤수의 뜻이 뒤섞여 있었다.
    3. 甲은 장비에 적힌 파괴 하중을 안전하게 쓸 수 있는 톤수로 잘못 읽고 그 무게까지 짐을 실으려다 반장에게 제지당했다. 그 숫자는 장비가 부서지는 지점이었다. 안전과 파괴가 정반대의 뜻으로 뒤바뀌어 있었다.
    4. 甲은 장비에 적힌 시험 하중을 평소에 안전하게 쓸 수 있는 톤수로 여기고 짐을 실으려 했다. 반장은 그 숫자는 시험할 때만 거는 값이라고 알려 주었다. 시험용 숫자와 평소용 숫자가 헷갈려 있었다.

    장비가 안전하게 버티며 쓸 수 있는 톤수를 가리키는 말을 고르는 것인데 Safety working load만 그 뜻과 맞으므로, 정답은 1번이다.

    Select the best one which represents following sentences.

    This is defined as the volume occupied by unit weight of cargo. Usually expressed as cubic meters per tonne or cubic feet per tonne.

    1. 1. Deadweight
    2. 2. Cargo space
    3. 3. Stowage factor
    4. 4. Subdivision factor

    정답 3번

    🔍 보기별 해설
    1. Deadweight(재화중량톤수)는 배가 실을 수 있는 무게의 총량을 가리키는 말이라 짐 한 단위가 차지하는 부피를 가리키는 뜻과는 다르므로 해당하지 않는다.
    2. Cargo space(화물창 용적)는 짐을 싣는 공간 자체의 크기를 가리키는 말이라 무게 한 단위당 부피를 가리키는 뜻과는 다르므로 해당하지 않는다.
    3. Stowage factor(적재계수)는 짐 무게 한 단위가 차지하는 부피를 톤당 세제곱미터 등으로 나타내는 말과 그대로 맞으므로 해당한다(정답).
    4. Subdivision factor(구획지수)는 배의 침수 구획을 나누는 기준을 가리키는 말이라 짐의 부피와는 뜻이 다르므로 해당하지 않는다.

    1. 甲은 짐 한 톤이 차지하는 부피를 묻는 화주의 물음에 재화중량톤수를 답으로 내밀었다가 반장에게 그 값은 배가 실을 수 있는 무게의 총량이라는 말을 들었다. 물음은 무게가 아니라 부피에 관한 것이었다. 엉뚱한 톤수가 답으로 나갈 뻔했다.

    3. 甲은 다른 짐에서 새어 나온 액체에 물든 화물을 자세히 살펴보고 적요에 Contaminated라고 적었다. 오염된 상태와 용어의 뜻이 하나도 어긋나지 않았다. 표는 그대로 다음 검사 칸으로 넘어갔다.
    4. 甲은 습기에 녹아 완전히 풀어진 짐을 유심히 살펴보고 적요에 Dissolved라고 적었다. 녹은 상태와 용어의 뜻이 그대로 맞아떨어졌다. 감독관도 별다른 말 없이 표를 그대로 받아 넘겼다.

    일반화물 현재적요 해석이 옳지 않은 것을 고르는 것인데 Broken, contents intact만 뜻이 정반대로 뒤집혔으므로, 정답은 2번이다.

    다음 내용이 설명하는 장비는?

    컨테이너 터미널에서 사용하는 장비로서 컨테이너를 양각 사이에 끼우고 적재와 운반 기능을 수행할 수 있는 기동성이 뛰어난 대형 운전기계이다.

    1. 1. Chassis
    2. 2. Straddle carrier
    3. 3. Yard tractor
    4. 4. Spreader

    정답 2번

    🔍 보기별 해설
    1. Chassis(샤시)는 컨테이너를 얹어 도로로 옮기는 트레일러 골격을 가리키는 말이라 양각 사이에 끼우는 장비와는 뜻이 다르므로 해당하지 않는다.
    2. Straddle carrier(스트래들 캐리어)는 컨테이너를 양각 사이에 끼워 적재·운반하는 기동성 있는 대형 장비라는 뜻과 그대로 맞으므로 해당한다(정답).
    3. Yard tractor(야드 트랙터)는 컨테이너가 실린 샤시를 끄는 견인 장비를 가리키는 말이라 양각으로 끼우는 장비와는 뜻이 다르므로 해당하지 않는다.
    4. Spreader(스프레더)는 컨테이너 상단을 붙잡는 크레인의 부속 장치를 가리키는 말이라 대형 운전기계 자체와는 뜻이 다르므로 해당하지 않는다.
    🧮 풀이
    1. 甲은 컨테이너를 실은 샤시를 양각으로 끼우는 장비로 착각해 표에 적으려다가 그것은 트레일러의 골격일 뿐이라는 것을 알아챘다. 양각으로 끼우는 장비는 따로 있었다. 엉뚱한 장비 이름을 적을 뻔했다.
    2. 甲은 터미널 마당에서 컨테이너를 양각 사이에 끼우고 성큼성큼 옮기는 스트래들 캐리어를 지켜보며 작업 순서를 표에 적었다. 그 장비가 그날 야드 이송의 중심이었다. 큰 다리를 벌린 장비가 컨테이너를 잇달아 실어 날랐다.
    3. 甲은 샤시를 끌고 다니는 야드 트랙터를 양각으로 끼우는 장비로 잘못 적으려다가 그것은 끄는 장비일 뿐이라는 것을 반장에게 들었다. 끼우는 장비와 끄는 장비는 하는 일이 달랐다. 표를 고쳐 다시 적었다.
    4. 甲은 크레인 끝에 달린 스프레더를 대형 운전기계로 적으려다가 그것은 컨테이너 상단을 붙잡는 부속 장치일 뿐이라는 것을 알아챘다. 장비 전체와 부속 장치는 서로 다른 것이었다. 이름을 다시 살펴 고쳐 적었다.

    컨테이너를 양각 사이에 끼우는 장비를 설명하는 말을 고르는 것인데 Straddle carrier만 그 뜻과 맞으므로, 정답은 2번이다.

    주의표시(Care mark)의 설명으로 옳은 것을 모두 고른 것은?

    ㄱ. Length ways: 길이로 눕혀 실을 것

    ㄴ. Glass with care: 유리제품 취급주의

    ㄷ. Stow level: 수평 적재

    ㄹ. Guard wetness: 수직 적재

    1. 1. ㄱ, ㄴ, ㄷ
    2. 2. ㄱ, ㄴ, ㄹ
    3. 3. ㄱ, ㄷ, ㄹ
    4. 4. ㄴ, ㄷ, ㄹ

    정답 1번

    🔍 보기별 해설
    1. Length ways(길이로 눕혀 실을 것)는 화물을 눕혀 놓는 방향을 가리키는 뜻과 그대로 맞으므로 옳다.
    2. Glass with care(유리제품 취급주의)는 유리 화물을 조심해서 다루라는 뜻과 그대로 맞으므로 옳다.
    3. Stow level(수평 적재)은 화물을 기울이지 않고 평평하게 눕혀 쌓으라는 뜻이며, 표시가 그 뜻을 그대로 옮겼으므로 옳다.
    4. Guard wetness(습기 조심)를 수직 적재로 옮겼다. 물기를 막으라는 말과 세워 쌓으라는 말은 다른 뜻이므로 옳지 않다.
    🧮 풀이
    1. 甲은 긴 파이프 화물에 붙은 Length ways 표시를 보고 눕혀서 길이 방향으로 실었다. 표시가 가리키는 방향과 그대로 맞았다. 파이프는 흔들림 없이 실렸다.
    2. 甲은 Glass with care 표시가 붙은 상자를 두 손으로 조심스레 옮겼다. 유리 화물이니 조심하라는 뜻과 그대로 맞았다. 상자는 깨지지 않고 창고에 놓였다.
    3. 쌓아 올린 상자 더미가 한쪽으로 기울자, 반장은 Stow level 표시를 짚으며 바닥부터 다시 가지런히 눕혀 쌓으라고 지시했다. 화물이 다시 평평하게 자리를 잡을 때까지 작업은 이어졌다.
    4. 甲은 Guard wetness 표시가 붙은 상자를 수직으로 세워 두면 되는 줄 알고 그대로 세워 놓았다. 반장은 그 표시는 세우라는 뜻이 아니라 물기를 막으라는 뜻이라고 알려 주었다. 甲은 상자를 비 안 드는 자리로 옮겼다.

    주의표시의 뜻이 다 맞는 조합을 고르는 것인데 ㄹ은 습기 조심인데 수직 적재로 잘못 짝지어져 ㄱㄴㄷ만 맞으므로, 정답은 1번이다.

    Followings are classes of dangerous substances and articles under IMDG Code.

    Which one is correct?

    1. 1. Class 1 - Compressed gas
    2. 2. Class 3 - Flammable solids
    3. 3. Class 7 - Radioactive material
    4. 4. Class 8 - Miscellaneous dangerous substances & articles

    정답 3번

    🔍 보기별 해설
    1. Class 1(폭발물)을 Compressed gas(압축가스)로 짝지었다. 압축가스는 Class 2에 드는 물질이므로 옳지 않다.
    2. Class 3(인화성 액체)을 Flammable solids(가연성 고체)로 짝지었다. 가연성 고체는 Class 4에 드는 물질이므로 옳지 않다.
    3. Class 7(방사성물질)을 Radioactive material로 짝지었다. IMDG 분류의 등급과 물질이 그대로 맞으므로 옳다(정답).
    4. Class 8(부식성 물질)을 Miscellaneous dangerous substances(기타위험물)로 짝지었다. 기타위험물은 Class 9에 드는 물질이므로 옳지 않다.
    🧮 풀이
    1. 甲은 위험물 반입 서류에서 압축가스를 폭발물 등급인 Class 1로 옮겨 적으려던 순간 손을 멈칫했다. 압축가스는 그 옆 칸인 Class 2에 드는 물질이었다. 서류를 다시 살펴 올바른 등급 칸에 옮겨 적었다.
    2. 甲은 가연성 고체가 든 상자에 Class 3 표찰을 붙이려다가 동료가 다가와 손을 잡는 바람에 멈췄다. 그 물질은 인화성 액체와는 다른 Class 4에 드는 것이었다. 표찰을 떼어 내고 알맞은 등급으로 다시 붙였다.
    3. 甲은 방사능 경고문이 붙은 컨테이너 서류에 Class 7이라고 적어 넣었다. 문서에 적힌 등급과 실제 실린 물질의 성질이 조금도 어긋나지 않았다. 옆에서 지켜보던 선임도 별다른 말 없이 서명을 보탰다.
    4. 甲은 부식성 물질을 기타위험물이라 여겨 Class 8 서류철에 끼워 넣으려 했다. 알고 보니 그 물질은 따로 묶이는 Class 9 서류철 몫이었다. 서류철을 바꿔 제자리에 다시 끼워 넣었다.

    IMDG 분류의 등급과 물질이 맞게 짝지어진 것을 고르는 것인데 Class 7과 방사성물질만 그대로 맞으므로, 정답은 3번이다.

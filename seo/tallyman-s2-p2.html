    "7개 포대가 약간 습기 찼음"에 대한 일반화물의 적요로 옳은 것은?

    1. 1. 7 MODERATELY WET BURLAPS.
    2. 2. 7 SLIGHTLY MOIST BAGS.
    3. 3. 7 SLIGHTLY WET BALES.
    4. 4. 7 HEAVILY MOIST BAGS.

    정답 2번

    🔍 보기별 해설
    1. moderately(웬만큼)는 약간보다 센 정도를 가리키고 wet(젖음)은 습기 찬 것보다 심한 상태이며 burlaps(마대)는 포대와 다른 자루다. 세 군데가 다 어긋나므로 옳지 않다.
    2. ‘7 SLIGHTLY MOIST BAGS.’는 포대 일곱 개가 약간 습기를 머금었다는 뜻이다. 수량·포장 단위·젖음 정도가 모두 맞으므로 옳다(정답).
    3. wet(젖음)은 습기 찬 것보다 심한 상태이고 bales(꾸러미)는 포대와 다른 짐이다. 정도는 맞지만 상태와 짐 이름이 어긋나므로 옳지 않다.
    4. heavily(심하게)는 약간보다 훨씬 세게 젖은 정도를 가리키는 말이다. 상태와 짐 이름은 맞지만 정도가 어긋나므로 옳지 않다.
    🧮 풀이
    1. 포대 일곱 개가 중간 정도로 젖자 검수사 甲은 7 MODERATELY WET BURLAPS.라고 초안을 썼다. 甲은 실제 물기가 약하고 포장 단위가 포대임을 다시 확인했다. 젖음 정도와 명칭을 고쳐 최종 검수표에 반영했다.
    2. 일곱 포대에 약한 습기가 남아 검수사 甲은 7 SLIGHTLY MOIST BAGS.라고 적었다. 甲은 포대마다 젖은 부위를 확인하고 사진을 붙였다. 수하인은 인수 시 일곱 포대의 습기 상태를 대조할 수 있었다.
    3. 베일 포장 일곱 개를 맡은 검수사 甲은 7 SLIGHTLY WET BALES.라고 적었다. 甲은 베일과 포대의 포장 단위를 구분했다. 발문의 포대 손상 기록에는 베일 명칭을 쓰지 않았다.
    4. 포대 일곱 개가 심하게 젖자 검수사 甲은 7 HEAVILY MOIST BAGS.라고 적었다. 甲은 물이 스며든 범위를 재고 별도로 보관했다. 약간 습기가 찬 포대의 기록과 젖음 정도를 구분했다.

    습기가 약간 찬 포대라는 원문에 정도·상태·짐 이름이 다 맞는 말을 고르는 것인데 slightly moist bags만 그대로 맞으므로, 정답은 2번이다.

    문장의 번역으로 옳은 것은?

    1. 1. Who is duty officer? - 당직사관은 누구입니까?
    2. 2. I want to meet your chief officer. - 나는 이등항해사를 만나고 싶습니다.
    3. 3. I think this is old damage. - 나는 이것이 노후 비용이라고 생각합니다.
    4. 4. Are you looking for foreman? - 당신은 앞의 남자를 닮았습니까?

    정답 1번

    🔍 보기별 해설
    1. ‘Who is duty officer?’는 지금 당직을 맡은 사관이 누구인지 묻는다. ‘당직사관은 누구입니까?’라는 번역과 일치하므로 옳다(정답).
    2. chief officer(일등항해사)를 이등항해사로 옮겼다. 일등항해사와 이등항해사는 배에서 맡는 자리가 다른 사람이므로 옳지 않다.
    3. old damage(오래된 손상)를 노후 비용으로 옮겼다. 짐이 상한 상태를 가리키는 말을 비용이라는 돈 이야기로 바꿔 옮겼으므로 옳지 않다.
    4. looking for foreman(작업반장을 찾다)을 앞의 남자를 닮았느냐는 전혀 다른 물음으로 옮겼다. 사람을 찾는 물음이 생김새를 묻는 물음으로 바뀌었으므로 옳지 않다.
    🧮 풀이
    1. 당직사관을 찾는 검수사 甲은 ‘Who is duty officer?’라고 물었다. 선원은 근무 중인 사관의 이름을 알려 주었다. 甲은 그 사관에게 화물 손상 보고서를 전달했다.
    2. 수석항해사를 찾는 검수사 甲은 ‘I want to meet your chief officer.’라고 말했다. 선원은 일항사가 근무하는 사무실을 안내했다. 이등항해사에게 보고서가 잘못 전달되지 않았다.
    3. 오래전 생긴 손상을 본 검수사 甲은 ‘I think this is old damage.’라고 기록했다. 甲은 기존 사진과 현재 상태를 대조해 손상 시점을 조사했다. 비용 항목으로 오역하지 않아 사고 보고 내용이 분명해졌다.
    4. 하역반장을 찾는 검수사 甲은 ‘Are you looking for foreman?’이라는 질문을 들었다. 甲은 담당 반장의 위치를 묻고 작업 지시를 전달했다. 앞에 서 있는 남자의 외모를 묻는 말로 해석하지 않았다.

    원문을 그대로 옮긴 번역을 고르는 것인데 당직사관은 누구입니까만 뜻이 그대로 맞으므로, 정답은 1번이다.

    강재화물(Iron plate)의 명칭으로 옳은 것은?

    1. 1. Semifinished steel: 완제품
    2. 2. Flat bar: 평강
    3. 3. Round bar: 각재
    4. 4. Half round bar: 반각재

    정답 2번

    🔍 보기별 해설
    1. Semifinished steel(반제품)을 완제품으로 옮겼다. 아직 다 만들어지지 않은 중간 단계 강재를 다 만들어진 것으로 뒤바꿨으므로 옳지 않다.
    2. Flat bar는 납작한 막대 형태의 강재인 평강을 뜻한다. 영문 명칭과 한국어 뜻이 일치하므로 옳다(정답).
    3. Round bar(환봉)를 각재로 옮겼다. 단면이 둥근 강재의 이름을 단면이 모난 강재의 이름으로 뒤바꿔 옮겼으므로 옳지 않다.
    4. Half round bar(반원형강)를 반각재로 옮겼다. 반원 모양 단면과 각진 모양 단면은 서로 다른 생김새이므로 옳지 않다.
    🧮 풀이
    1. 반제품 강재를 검수사 甲이 인수했다. 甲은 Semifinished steel 표기를 보고 추가 압연 공정이 필요한 상태로 기록했다. 완제품 창고에 보내지 않아 공정별 재고가 구분됐다.
    2. 평평한 막대 모양의 강재를 검수사 甲이 셌다. 甲은 치수와 수량을 재고 Flat bar, 곧 평강으로 기록했다. 원형 막대와 섞이지 않도록 별도 적치 구역을 지정했다.
    3. 둥근 단면의 강재 묶음을 검수사 甲이 받았다. 甲은 직경과 길이를 측정하고 Round bar로 기록했다. 각재와 다른 형태라 입고 목록의 분류를 정정하고 지정된 강재 구역에 쌓았다.
    4. 반원형 단면의 강재를 검수사 甲이 조사했다. 甲은 단면 사진과 길이를 기록해 Half round bar로 분류했다. 반각재라는 표기가 잘못되어 재고 명칭을 고쳤다.

    강재의 원어와 우리말 이름이 맞게 짝지어진 것을 고르는 것인데 Flat bar와 평강만 그대로 맞으므로, 정답은 2번이다.

    위험물 검수에 관한 다음 내용에서 ( )에 해당하지 않는 것은?

    If you find any trouble while checking, you should inform to the ( ) of the problem. And then, you should take a step on the matters in their presence.

    1. 1. chief officer
    2. 2. consignor
    3. 3. customs
    4. 4. terminal

    정답 3번

    🔍 보기별 해설
    1. Chief officer는 선박의 화물과 위험물 안전을 맡는 수석항해사다. 문제 발생 시 보고할 대상이므로 옳다.
    2. Consignor는 화물을 맡긴 송하인이다. 위험물에 문제가 생겼을 때 알려야 하는 당사자이므로 옳다.
    3. Customs는 세관을 뜻하며 통관·감독 업무를 맡는다. 이 문맥의 선박·화주·터미널 안전 보고 대상과 구분되므로 옳지 않다(정답).
    4. Terminal은 하역 현장을 운영하는 터미널 측 담당자다. 현장의 위험물 문제를 알려야 하므로 옳다.
    🧮 풀이
    1. 위험물 포장에서 누출을 발견한 검수사 甲은 chief officer에게 현장 상태를 알렸다. 일항사는 선박의 안전 조치를 지시하고 위험 구역을 통제했다. 甲은 누출 수량과 조치 시간을 검수표에 남겼다.
    2. 화주의 위험물 표시가 서류와 다르자 검수사 甲은 consignor에게 확인을 요청했다. 화주는 올바른 물질명과 포장 정보를 보냈다. 甲은 수정된 서류와 실제 표지를 대조해 선적 목록을 정정했다.
    3. 위험물의 포장이 손상되자 검수사 甲은 customs를 검수 현장 보고 대상 목록에서 구분했다. 甲은 먼저 선박과 터미널의 안전 담당자에게 알려 현장을 격리했다. 통관 조사는 별도 절차에 따라 필요한 자료를 제출했다.
    4. 야드에서 위험물 용기 하나가 새자 검수사 甲은 terminal 담당자에게 연락했다. 터미널은 작업 구역을 막고 대응팀을 배치했다. 甲은 손상 용기 번호를 기록해 조치 결과와 연결했다.

    위험물 문제를 알려야 하는 대상을 고르는 것인데 세관은 통관 기관이라 현장 문제를 알리는 자리가 아니므로, 정답은 3번이다.

    하역장비에 관한 다음 설명에서 ( )에 적합한 것은?

    ( ) is an acceptable working tonnage used for a weight-bearing item of equipment.

    1. 1. Safety working load
    2. 2. Maximum pay load
    3. 3. Breaking load
    4. 4. Test load

    정답 1번

    🔍 보기별 해설
    1. Safety working load는 하역 장비가 정상 작업에서 안전하게 지탱할 수 있는 허용 하중이다. 발문의 정의와 일치하므로 옳다(정답).
    2. Maximum pay load는 적재 가능한 최대 화물 중량을 뜻한다. 양중 장비의 안전 작업 하중이라는 정의와 다르므로 옳지 않다.
    3. Breaking load는 장비가 파괴되는 한계 하중이다. 정상 작업의 허용 하중과 다르므로 옳지 않다.
    4. Test load는 장비 성능을 시험할 때 가하는 하중이다. 일상 작업의 안전 허용 하중이 아니므로 옳지 않다.
    🧮 풀이
    1. 크레인에 걸 화물 무게를 확인한 작업자 甲은 Safety working load를 읽었다. 甲은 장비의 허용 작업 하중보다 가벼운 화물만 들어 올렸다. 장비가 정해진 범위에서 작동해 하역을 마쳤다.
    2. 컨테이너 적재량을 계산하던 담당자 甲은 Maximum pay load를 확인했다. 甲은 컨테이너에 실을 수 있는 화물의 상한을 적재 계획에 반영했다. 크레인 장비의 안전 작업 하중과는 수치를 구분했다.
    3. 와이어가 끊어지는 한계 시험을 맡은 담당자 甲은 Breaking load를 기록했다. 甲은 실제 하역 때 그 한계까지 화물을 싣지 않도록 작업 기준을 낮췄다. 일상 작업의 허용 하중은 별도로 표시했다.
    4. 하역 장비의 검사를 맡은 기술자 甲은 Test load를 이용해 성능을 시험했다. 甲은 시험 후 장비의 상태를 검사 기록에 남겼다. 실제 작업에서 허용되는 안전 하중은 별도 표지를 기준으로 삼았다.

    장비가 안전하게 버티며 쓸 수 있는 톤수를 가리키는 말을 고르는 것인데 Safety working load만 그 뜻과 맞으므로, 정답은 1번이다.

    Select the best one which represents following sentences.

    This is defined as the volume occupied by unit weight of cargo. Usually expressed as cubic meters per tonne or cubic feet per tonne.

    1. 1. Deadweight
    2. 2. Cargo space
    3. 3. Stowage factor
    4. 4. Subdivision factor

    정답 3번

    🔍 보기별 해설
    1. Deadweight는 선박이 실을 수 있는 총중량을 나타낸다. 화물 단위 중량당 용적의 뜻이 아니므로 옳지 않다.
    2. Cargo space는 화물을 실을 수 있는 공간의 전체 용적이다. 단위 중량당 화물 용적과 구분되므로 옳지 않다.
    3. Stowage factor는 화물의 단위 중량이 차지하는 용적을 뜻한다. 발문의 정의와 일치하므로 옳다(정답).
    4. Subdivision factor는 선박 구획과 침수 안전에 관한 계수다. 화물의 단위 중량당 용적을 뜻하지 않으므로 옳지 않다.
    🧮 풀이
    1. 선박의 적재 한도를 계산한 담당자 甲은 Deadweight를 확인했다. 甲은 화물과 연료 등 실을 수 있는 총중량을 적재표에 적었다. 단위 중량 화물이 차지하는 용적은 별도로 계산했다.
    2. 선창을 배정하던 담당자 甲은 Cargo space의 전체 용적을 측정했다. 甲은 실제 화물을 넣을 수 있는 공간을 적부 계획에 반영했다. 화물 한 톤이 차지하는 부피와는 다른 수치로 기록했다.
    3. 곡물 한 톤이 선창에서 차지하는 부피를 검량사 甲이 계산했다. 甲은 단위 중량당 용적을 Stowage factor로 기록했다. 그 값으로 선창 공간에 실을 수 있는 곡물의 양을 산정했다.
    4. 선박 내부 구획을 검토한 기술자 甲은 Subdivision factor를 설계표에 적었다. 甲은 구획별 침수 가능성과 안전 기준을 검토했다. 곡물 한 톤의 적재 용적 계산에는 그 계수를 쓰지 않았다.

    짐 한 단위가 차지하는 부피를 가리키는 말을 고르는 것인데 Stowage factor만 그 뜻과 맞으므로, 정답은 3번이다.

    항만 관련 약어의 의미가 옳지 않은 것은?

    1. 1. CY: Container Yawing
    2. 2. CFS: Container Freight Station
    3. 3. EDI: Electronic Data Interchange
    4. 4. CIQ: Customs, Immigration, Quarantine

    정답 1번

    🔍 보기별 해설
    1. CY의 정식 이름은 Container Yard, 곧 컨테이너 야드다. Container Yawing이라는 풀이는 틀렸으므로 옳지 않다(정답).

    3. 3. Parcel: 포
    4. 4. Sack: 덩어리

    정답 4번

    🔍 보기별 해설
    1. Bar(막대기)는 길고 가는 막대 모양으로 단단히 묶어 다듬은 짐의 포장 형태를 가리키는 말이라 그 뜻이 그대로 맞으므로 옳다.
    2. Cage(우리)는 살아있는 짐승이나 부피 큰 짐을 넣어 나르는 철제 틀 모양의 포장 형태를 가리키는 말이라 뜻이 그대로 맞으므로 옳다.
    3. Parcel(포)은 종이나 천으로 겹겹이 싸서 단단히 묶은 꾸러미 모양 포장을 가리키는 말이라 그 뜻이 그대로 맞으므로 옳다.
    4. Sack은 포대나 자루를 뜻한다. 덩어리라는 번역은 포장 형태와 맞지 않으므로 옳지 않다(정답).
    🧮 풀이
    1. 막대 모양 강재를 검수사 甲이 Bar로 기록했다. 甲은 길이와 개수를 재어 강재 검수표에 적었다. 우리나 포대와 구분해 막대 형태의 적치 위치를 따로 정하고 선적팀에 전달했다.
    2. 살아 있는 동물을 실은 우리를 검수사 甲이 Cage로 적었다. 甲은 우리의 수와 잠금 상태를 확인했다. 동물이 빠져나오지 않도록 문을 고정하고 선창의 지정 위치로 운반했다.
    3. 소포 형태의 화물을 검수사 甲이 Parcel로 분류했다. 甲은 포장의 수량과 수하인을 각각 기록했다. 덩어리 화물과 구분해 개별 인도가 가능하도록 화주별 적치 칸에 놓았다.
    4. 포대 자루를 검수사 甲이 Sack으로 기록했다. 甲은 자루마다 기호와 내용물 수량을 대조했다. 덩어리라는 뜻으로 옮기지 않아 포장 단위가 명확해지고 인수 수량이 맞았다.

    포장형태 영문 해석이 옳지 않은 것을 고르는 것인데 Sack만 자루를 덩어리로 잘못 옮겼으므로, 정답은 4번이다.

    다음 내용이 설명하는 것은?

    A charted plan of vessel's cargo-carrying spaces which illustrates the type, tonnage and description of goods for designated discharge in the various intended ports of call for the voyage.

    2. 2. Tally sheet
    3. 3. Rigging plan
    4. 4. Hatch list

    정답 1번

    🔍 보기별 해설
    1. Stowage plan은 선박의 화물 적재 공간에 종류·톤수·위치별 화물을 표시한 배치도다. 발문의 설명과 일치하므로 옳다(정답).
    2. Tally sheet는 검수 중 화물 수량과 손상을 기록하는 표다. 본선 적재 구역별 도면이 아니므로 옳지 않다.

    2. 화물 수량을 세던 검수사 甲은 Tally sheet에 결과를 적었다. 甲은 손상 수량과 포장 기호를 함께 기록했다. 본선 전체 공간의 적재 배치를 나타내는 도면과는 다른 자료였다.
    3. 하역 장비를 설치하던 작업자 甲은 Rigging plan을 확인했다. 甲은 와이어와 슬링의 배치를 도면대로 맞췄다. 선창별 화물 종류와 적재 위치는 별도의 화물배치도에서 확인했다.
    4. 해치별 작업 순서를 짜는 담당자 甲은 Hatch list를 열었다. 甲은 해치 번호와 개방 순서를 작업팀에 전달했다. 화물의 톤수와 전체 적재 위치를 그린 도면은 따로 사용했다.

    화물 배치를 나타내는 도표를 설명하는 말을 고르는 것인데 Stowage plan만 그 뜻과 맞으므로, 정답은 1번이다.

    일반화물의 현재적요(Conditional remark)에 관한 해석으로 옳지 않은 것은?

    1. 1. Bags torn: 포장이 터진 것
    2. 2. Broken contents intact: 내외부가 모두 파손된 것
    3. 3. Contaminated: 오염된 것
    4. 4. Dissolved: 녹은 것

    정답 2번

    🔍 보기별 해설
    1. Bags torn(포장이 터진 것)은 포대 겉면이 힘없이 찢어져 크게 벌어진 상태를 가리키는 말과 뜻이 그대로 맞으므로 옳다.
    2. Broken contents intact는 포장은 깨졌지만 안의 내용물은 온전하다는 뜻이다. 내외부가 모두 파손됐다는 번역은 옳지 않다(정답).
    3. Contaminated(오염된 것)는 다른 물질이 새어 나와 묻거나 섞여 짐 전체가 물든 상태를 가리키는 말과 그대로 맞으므로 옳다.
    4. Dissolved(녹은 것)는 짐이 물기나 열기에 녹아 액체 상태로 완전히 풀어진 것을 가리키는 말과 뜻이 그대로 맞으므로 옳다.
    🧮 풀이
    1. 포대가 찢어진 것을 검수사 甲이 발견했다. 甲은 Bags torn이라고 적고 찢어진 위치와 포대 수량을 사진에 남겼다. 내용물이 빠지기 전에 별도 포장으로 옮겨 인수했다.
    2. 상자의 겉포장이 깨졌지만 안의 기계는 온전했다. 검수사 甲은 Broken contents intact라고 적어 내품 손상이 없음을 표시했다. 내외부가 모두 파손됐다는 번역을 쓰지 않아 사고 범위가 바로 전달됐다.
    3. 화학액이 상자 외면에 묻자 검수사 甲은 Contaminated라고 기록했다. 甲은 오염 범위를 표시하고 정상 상자와 거리를 두었다. 인수 기록에 오염 수량이 남아 별도 처리가 진행됐다.
    4. 가루 화물의 일부가 액체에 녹자 검수사 甲은 Dissolved라고 적었다. 甲은 녹은 부분의 중량과 포장 상태를 기록했다. 오염이나 파손과 구분한 손해 항목으로 수하인에게 전달했다.

    일반화물 현재적요 해석이 옳지 않은 것을 고르는 것인데 Broken, contents intact만 뜻이 정반대로 뒤집혔으므로, 정답은 2번이다.

    주의표시(Care mark)의 설명으로 옳은 것을 모두 고른 것은?

    ㄱ. Length ways: 길이로 눕혀 실을 것

    ㄴ. Glass with care: 유리제품 취급주의

    1. 1. ㄱ, ㄴ, ㄷ
    2. 2. ㄱ, ㄴ, ㄹ
    3. 3. ㄱ, ㄷ, ㄹ
    4. 4. ㄴ, ㄷ, ㄹ

    🔍 보기별 해설

    2. Glass with care는 유리제품을 조심해 다루라는 뜻이다. 제시된 풀이가 옳다.
    3. Stow level은 수평을 유지해 적재하라는 뜻이다. 제시된 풀이가 옳다.

    정답은 1번이다.

    Followings are classes of dangerous substances and articles under IMDG Code.

    Which one is correct?

    1. 1. Class 1 - Compressed gas
    2. 2. Class 3 - Flammable solids
    3. 3. Class 7 - Radioactive material
    4. 4. Class 8 - Miscellaneous dangerous substances & articles

    정답 3번

    🔍 보기별 해설
    1. Class 1(폭발물)을 Compressed gas(압축가스)로 짝지었다. 압축가스는 Class 2에 드는 물질이므로 옳지 않다.
    2. Class 3(인화성 액체)을 Flammable solids(가연성 고체)로 짝지었다. 가연성 고체는 Class 4에 드는 물질이므로 옳지 않다.
    3. Class 7은 방사성 물질(Radioactive material)의 위험물 등급이다. 국제해상위험물규칙(IMDG)의 분류와 맞으므로 옳다(정답).
    4. Class 8(부식성 물질)을 Miscellaneous dangerous substances(기타위험물)로 짝지었다. 기타위험물은 Class 9에 드는 물질이므로 옳지 않다.
    🧮 풀이
    1. 위험물 명세서를 받은 검수사 甲은 Class 1 표지를 폭발물로 대조했다. 甲은 압축가스 용기의 Class 2와 구분해 보관 위치를 지정했다. 잘못된 등급 표시를 수정해 안전 구역을 나눴다.
    2. 가연성 고체를 맡은 검수사 甲은 Class 3으로 적힌 초안을 확인했다. 甲은 실제 표지의 Class 4와 대조해 등급을 고쳤다. 액체 인화물과 다른 구역에 적재됐다.
    3. 방사성 물질 포장을 검수사 甲이 인수했다. 甲은 Class 7 - Radioactive material 표지를 읽고 격리 기준을 적용했다. 포장 번호와 표지 수량을 기록해 지정 구역에 보관했다.
    4. 부식성 물질 드럼을 맡은 검수사 甲은 Class 8 표지를 기록했다. 甲은 기타 위험물과 구분해 누출 방지 받침대에 놓았다. Miscellaneous dangerous substances & articles는 별도 등급으로 정정했다.

    IMDG 분류의 등급과 물질이 맞게 짝지어진 것을 고르는 것인데 Class 7과 방사성물질만 그대로 맞으므로, 정답은 3번이다.

    2. 청소년교류시설은 교류 목적 시설을 가리킨다. 모든 영역의 상위 명칭이 아니므로 옳지 않다.
    3. 청소년시설은 활동·복지·보호에 제공되는 시설을 통틀어 말한다. 기본법 제3조에 맞으므로 옳다(정답).

    5. 청소년보호시설은 보호 중심 시설을 뜻한다. 활동·복지를 포함하는 정의와 달라 옳지 않다.

    2. 2. 행글라이딩
    3. 3. 산악스키
    4. 4. 5km 도보이동
    5. 5. 스킨스쿠버

    정답 4번

    🔍 보기별 해설
    1. 고무보트 활동은 수상 위험활동에 속한다. 의무 인증 대상이므로 옳다.
    2. 행글라이딩은 항공 위험활동이다. 의무 인증 대상이므로 옳다.
    3. 산악스키는 산악 위험활동이다. 의무 인증 대상이므로 옳다.
    4. 시행규칙 별표 7은 10km 이상 도보이동을 위험활동으로 정한다. 5km를 의무 인증 대상이라고 하여 옳지 않다(정답).
    5. 스킨스쿠버는 수중 위험활동이다. 의무 인증 대상이므로 옳다.
    🧮 풀이
    1. 참가자 A는 강에서 고무보트를 탔다. 지도자 B는 안전장비와 인증 절차를 확인했다. 수상 위험활동이다.
    2. 비행참가자 A는 행글라이딩을 신청했다. 운영자 B는 인증 대상 여부를 살폈다. 항공 위험활동이다.
    3. 산악캠프참가자 A는 겨울 산악스키를 계획했다. 지도자 B는 위험활동 기준을 확인했다. 산악 위험활동이다.
    4. 참가자 A는 평지에서 5km를 걸었다. 지도자 B는 다른 위험활동이 포함됐는지 따로 확인했다. 단순 도보이동이다.
    5. 청소년 A는 바다에서 스킨스쿠버를 배웠다. 운영자 B는 인증과 구조계획을 확인했다. 수중 위험활동이다.

    학교 밖 청소년 지원에 관한 법률에 명시된 상담지원에 관한 내용이다. ( )에 들어갈 내용으로 옳은 것은?

    국가와 지방자치단체는 학교 밖 청소년에 대하여 효율적이고 적합한 지원을 할 수 있도록 심리상담, 진로상담, ( ）등 상담을 제공할 수 있다.

    1. 1. 가족상담
    2. 2. 대면상담
    3. 3. 자립상담
    4. 4. 교육상담
    5. 5. 건강상담

    정답 1번

    🔍 보기별 해설
    1. 가족상담은 심리·진로상담과 함께 법에 명시된다. 제8조의 열거에 맞으므로 옳다(정답).
    2. 대면상담은 상담의 방식이다. 제8조가 묻는 상담 분야가 아니므로 옳지 않다.
    3. 자립상담은 지원 과정에서 할 수 있는 상담이다. 해당 열거의 빈칸이 아니므로 옳지 않다.
    4. 교육상담은 학업지원과 연결될 수 있다. 해당 법조의 열거 항목이 아니므로 옳지 않다.
    5. 건강상담은 건강지원과 연결될 수 있다. 해당 법조의 빈칸과 달라 옳지 않다.
    🧮 풀이
    1. 지원받는 밖 청소년 A는 부모와 진로 문제로 다퉜다. 상담사 B는 가족이 함께 참여하는 상담을 마련했다. 가족상담이다.
    2. 청소년 A는 상담실에서 상담사 B를 만났다. B는 온라인 상담과 구분해 대면으로 진행했다. 상담 방식의 구별이다.
    3. 자립준비 A는 자립 계획을 세우고 싶었다. 상담사 B는 주거와 취업 문제를 들었다. 자립을 주제로 한 상담이다.
    4. 검정고시준비 A는 검정고시를 준비했다. 상담사 B는 학습 지원기관을 연결했다. 교육 분야 상담이다.
    5. 청소년 A는 건강검진 결과가 걱정됐다. 상담사 B는 의료기관을 안내했다. 건강 관련 상담이다.

    학교 밖 청소년 지원법 제8조의 상담지원에는 심리·진로·가족상담이 열거된다. 빈칸의 법정 항목은 가족상담이므로 정답은 1번이다.

    1. 1. 300만원 이하의 과태료
    2. 2. 500만원 이하의 벌금
    3. 3. 1년 이하의 징역 또는 1천만원 이하의 벌금
    4. 4. 1년 이하의 징역 또는 2천만원 이하의 벌금
    5. 5. 2년 이하의 징역 또는 2천만원 이하의 벌금

    🔍 보기별 해설
    1. 300만원 이하 과태료는 제22조의 형사처벌과 다르다. 비밀누설 제재를 낮춰 옳지 않다.
    2. 500만원 이하 벌금만 적었다. 징역형과 벌금 상한을 빠뜨려 옳지 않다.
    3. 1년 이하 징역 또는 1천만원 이하 벌금이다. 제22조의 형량에 맞으므로 옳다(정답).
    4. 벌금 상한을 2천만원으로 높였다. 법의 1천만원과 달라 옳지 않다.
    5. 징역 상한을 2년으로 높였다. 법의 1년과 달라 옳지 않다.

    1. 직원 A는 피해학생의 상담 내용을 외부에 전했다. 수사관 B는 과태료가 아닌 벌칙 조항을 확인했다. 비밀누설 제재다.
    2. 교사 A는 신고자 정보를 누설했다. 담당자 B는 벌금만 규정된 것인지 검토했다. 징역형도 있는 벌칙이다.
    3. 심의위원 A는 피해학생 정보를 누설했다. 수사관 B는 1년 이하 징역 또는 1천만원 이하 벌금을 적용했다. 법정 형량이다.
    4. 학교 직원 A가 사건 자료를 외부에 보냈다. 검토자 B는 벌금 상한이 2천만원은 아니라고 확인했다. 벌금 상한의 구별이다.
    5. 위원 A는 비밀을 공개했다. 검토자 B는 징역 상한이 1년이라고 확인했다. 징역형 상한의 구별이다.

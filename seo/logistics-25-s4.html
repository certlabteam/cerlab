    피킹 방식에 관한 설명으로 옳지 않은 것은?

    1. 1. 디지털 피킹(Digital Picking): 피킹 물품을 전표없이 피킹하는 방식으로 다품종 소량, 다빈도 피킹작업에 효과적이다.
    2. 2. 차량탑승피킹: 파렛트 단위로 피킹하는 유닛로드시스템(Unit Load System)이며, 피킹트럭에 탑승하여 피킹함으로써 보관시설의 공간활용도가 낮다.
    3. 3. 존 피킹(Zone Picking): 여러 피커가 피킹 작업범위를 정해두고, 본인 담당구역의 물품을 골라서 피킹하는 방식이다.
    4. 4. 일괄피킹: 여러 건의 주문을 모아서 일괄적으로 피킹하는 방식이다.
    5. 5. 릴레이 피킹(Relay Picking): 피킹 전표에서 해당 피커가 담당하는 품목만을 피킹하고, 다음 피커에게 넘겨주는 방식이다.

    자동분류시스템에 관한 설명으로 옳지 않은 것은?

    1. 1. 다이버터(Diverter) 방식은 팝업 방식에 비하여 구조가 상대적으로 복잡하다.
    2. 2. 팝업(Pop-up) 방식은 여러 개의 롤러(Roller)나 휠(Wheel) 등을 이용하여 물품이 컨베이어의 특정 위치를 지나갈 때 그 물품을 들어 올려서 방향을 바꾸는 방식 이다.
    3. 3. 다이버터(Diverter) 방식은 다이버터를 사용하여 물품이 이동할 때 가로막아 방향을 바꾸는 방식이다.
    4. 4. 트레이(Tray) 방식은 분류해야 할 물품이 담긴 트레이를 기울여서 물품의 위치를 아래로 떨어트리는 방식이다.
    5. 5. 슬라이딩슈(Sliding Shoe) 방식은 트레이 방식에 비하여 물품의 전환 흐름이 부드러워 상대적으로 물품의 손상 가능성이 낮다.

    자동창고(AS/RS)에 관한 설명으로 옳은 것은?

    1. 1. 스태커 크레인(Stacker Crane): 창고의 통로 공간을 수평 방향으로만 움직이는 저장/반출 기기이다.
    2. 2. 단일명령(Single Command) 방식: 1회 운행으로 저장과 반출 작업을 동시에 수행하는 방식이다.
    3. 3. 이중명령(Dual Command) 방식: 2회 운행으로 저장과 반출 작업을 순차적으로 모두 수행하는 방식이다.
    4. 4. 임의위치저장(Randomized Storage) 방식: 물품의 입출고 빈도에 상관없이 저장위치를 임의로 결정하는 방식이다.
    5. 5. 지정위치저장(Dedicated Storage) 방식: 물품의 입출고 빈도를 기준으로 저장위치를 등급(Class)으로 나누고 등급별로 저장위치를 결정하는 방식이다.

    5. 5. 플로우랙(Flow Rack): 적입과 인출이 반대 방향에서 이루어지는 선입선출이 효율적인 랙이다.

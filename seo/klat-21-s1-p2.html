    동의 경쟁의 결과로 옳은 것은?

    1. 1. 한자어와 고유어의 경쟁에서는 항상 한자어가 생존한다.
    2. 2. 두 단어가 의미 영역을 분담하여 공존하는 경우도 있다.
    3. 3. 경쟁 결과 의미 변화는 일어나지 않고 사용 빈도만 달라진다.
    4. 4. 경쟁하는 단어 중 동음이의어가 있는 쪽이 생존 가능성이 높다.

    정답 2번

    🔍 보기별 해설
    1. 한자어와 고유어가 경쟁할 때 어느 쪽이 살아남는지는 단어마다 다르다. 한자어가 항상 생존한다는 설명은 옳지 않다.
    2. 비슷한 뜻의 두 단어가 쓰임을 나누면 서로 다른 의미 영역에서 함께 남을 수 있다. 경쟁 결과로 공존도 가능하다는 설명은 옳다(정답).
    3. 동의 경쟁은 한 단어의 뜻이 넓어지거나 좁아지는 변화로 이어질 수 있다. 사용 빈도만 바뀐다는 설명은 옳지 않다.
    4. 동음이의어가 있으면 문맥에 따라 뜻을 헷갈릴 수도 있다. 동음이의어가 있는 쪽의 생존 가능성이 높다는 설명은 옳지 않다.
    🧮 풀이
    1. 수지는 오래된 글에서 같은 대상을 가리키던 고유어와 한자어를 찾아 현재 쓰임과 비교했다. 어떤 낱말에서는 고유어가 계속 쓰이고 다른 낱말에서는 한자어가 더 널리 쓰였다. 단어마다 결과가 달라 어느 한 계통의 말이 반드시 이긴다고 할 수 없었다.
    2. 예전에는 비슷한 뜻으로 쓰이던 두 단어가 시간이 지나 각기 다른 자리에서 쓰이기도 한다. 일상 대화에는 한쪽을 쓰고 전문 분야에서는 다른 쪽을 쓰면 두 말이 모두 남는다. 경쟁 끝에 의미 영역을 나누어 공존한 경우다.
    3. 민수는 옛 사전과 현재 사전의 뜻풀이를 비교했다. 한 단어는 예전보다 좁은 뜻으로 쓰이고 경쟁하던 다른 단어가 나머지 뜻을 맡았다. 사용 횟수만 달라진 것이 아니라 단어 자체의 의미 범위도 변했다.
    4. 같은 소리로 읽히지만 뜻이 다른 두 말이 있으면 듣는 사람은 앞뒤 문맥을 살펴야 한다. 수지가 한 말의 뜻을 민수가 다른 뜻으로 알아들어 다시 물은 적도 있었다. 이런 혼동 가능성만으로 그 단어가 경쟁에서 유리해진다고 할 수 없다.

    뜻이 비슷한 말들이 경쟁한 뒤 서로 다른 의미 영역을 맡아 함께 남을 수도 있다. 정답은 2번이다.

    혼종어로 옳은 것은?

    1. 1. 양말
    2. 2. 미나리
    3. 3. 떡케이크
    4. 4. 시나리오

    정답 3번

    🔍 보기별 해설
    1. ‘양말’은 한자어 요소 ‘양(洋)’과 ‘말(襪)’이 결합한 말이다. 서로 다른 어종이 섞인 혼종어라는 판정은 옳지 않다.
    2. ‘미나리’는 식물 이름을 나타내는 고유어 한 단어다. 외래어·한자어 요소가 고유어와 결합한 혼종어라는 판정은 옳지 않다.
    3. ‘떡케이크’는 고유어 ‘떡’과 외래어 ‘케이크’를 결합한 낱말이다. 서로 다른 어종이 섞인 혼종어라는 판정은 옳다(정답).
    4. ‘시나리오’는 외국에서 들어온 하나의 외래어다. 서로 다른 어종의 요소를 결합한 혼종어라는 판정은 옳지 않다.
    🧮 풀이
    1. 민수는 추운 날 양말을 두 켤레 신었다. ‘양말’의 ‘양’은 서양을 뜻하는 한자이고 ‘말’도 버선을 뜻하는 한자에서 왔다. 두 부분의 출처가 같으므로 고유어와 외래어가 섞인 떡케이크와 구조가 다르다.
    2. 수지는 시장에서 미나리 한 단을 사서 국에 넣었다. ‘미나리’라는 이름은 고유어로 전해진 낱말이다. 한자어 성분이나 외래어 성분을 떼어 낼 수 없으므로 서로 다른 어종이 결합한 말로 보지 않는다.
    3. 제과점은 쌀떡으로 만든 케이크를 ‘떡케이크’라고 팔았다. 이름 앞의 ‘떡’은 고유어이고 뒤의 ‘케이크’는 영어에서 들어온 외래어다. 서로 다른 어종의 말이 한 낱말 안에서 만난 혼종어다.
    4. 영화 제작자는 새 작품의 시나리오를 배우들에게 나누어 주었다. ‘시나리오’는 외국어에서 들어온 말이 통째로 쓰인다. 낱말 안에서 고유어와 한자어 같은 서로 다른 어종이 결합한 사례는 아니다.

    ‘떡케이크’에는 고유어 ‘떡’과 외래어 ‘케이크’가 함께 들어 있다. 정답은 3번이다.

    상보 반의어의 특징으로 옳지 않은 것은?

    1. 1. 두 단어를 동시에 긍정하거나 부정하면 모순이 된다.
    2. 2. 정도 부사의 수식을 받을 수 없고, 비교 표현으로도 사용되지 않는다.
    3. 3. 판단 대상에 관계없이 동일한 기준이 적용되는 절대적 개념으로 사용된다.
    4. 4. 한쪽 단어의 단언과 다른 쪽 단어의 부정 사이에 일방함의 관계가 성립한다.

    정답 4번

    🔍 보기별 해설
    1. 상보 반의어는 두 상태가 서로를 배제하고 중간 상태를 두지 않는다. 같은 대상에 두 말을 함께 긍정하거나 부정하면 모순이라는 설명은 옳다.
    2. 상보 반의어는 정도의 중간 단계를 나타내지 않는다. ‘조금’ 같은 정도 부사나 ‘더’ 같은 비교 표현을 일반적으로 쓰지 못한다는 설명은 옳다.
    3. 상보 관계는 대상의 크기나 상황에 따라 경계가 달라지는 정도 대립과 다르다. 둘 중 한 상태로 나눈다는 설명은 옳다.
    4. 상보 관계에서는 한쪽이 참이면 다른 쪽이 거짓이고 한쪽이 거짓이면 다른 쪽이 참이다. 함의가 일방적이라는 설명은 옳지 않다(정답).
    🧮 풀이
    1. 의사는 환자가 살아 있는지 사망했는지 확인해 기록했다. 같은 시점의 한 사람을 두고 두 상태가 모두 참이라고 적을 수 없다. 둘 다 거짓이라고 적어 제삼의 중간 상태를 두는 것도 이 대립의 뜻과 맞지 않는다.
    2. 수지는 경기 기록을 보고 누군가가 다른 사람보다 ‘더 사망했다’고 적지 않았다. ‘조금 사망했다’는 식으로 정도를 나누는 표현도 쓰지 않았다. 생존과 사망을 중간 단계로 배열하는 말이 아니기 때문이다.
    3. 병원은 두 사람의 생사 여부를 각각 확인했다. 키가 큰지 작은지를 비교할 때처럼 사람마다 다른 높이 기준을 정하지 않았다. 생존 여부라는 두 갈래로 상태를 판단하는 대립이기 때문이다.
    4. 민수는 ‘이 사람은 살아 있다’라는 말을 들으면 ‘죽어 있지 않다’고 추론했다. 반대로 ‘살아 있지 않다’는 말을 들으면 ‘죽어 있다’고 추론했다. 이 상보 관계에서는 긍정과 상대말의 부정이 서로 이어진다.

    상보 반의어는 한쪽의 긍정과 다른 쪽의 부정이 서로를 뜻하므로 함의가 한 방향에만 머물지 않는다. 정답은 4번이다.

    고유어가 포함되지 않은 것은?

    1. 1. 책값
    2. 2. 시누이
    3. 3. 사진첩
    4. 4. 외할머니

    정답 3번

    🔍 보기별 해설
    1. ‘책값’의 ‘책’은 한자어이고 가격을 뜻하는 ‘값’은 고유어다. 고유어가 포함되지 않았다는 판정은 옳지 않다.
    2. ‘시누이’는 남편의 자매를 가리키는 고유어 낱말이다. 말 전체가 고유어이므로 포함되지 않았다는 판정은 옳지 않다.
    3. ‘사진첩’은 한자어 ‘사진’과 사진을 모아 두는 책을 뜻하는 한자어 ‘첩’이 결합한 낱말이다. 고유어 요소가 없다는 판정은 옳다(정답).
    4. ‘외할머니’는 한자어 요소 ‘외’와 고유어 ‘할머니’가 결합한 말이다. 고유어가 포함되지 않았다는 판정은 옳지 않다.
    🧮 풀이
    1. 서점에서 민수는 책값을 계산했다. 영수증의 ‘책값’을 ‘책’과 ‘값’으로 나누면 앞은 한자어이고 뒤는 고유어다. 두 요소 중 하나가 고유어이므로 고유어가 없는 낱말로 분류할 수 없다.
    2. 수지는 가족에게 남편의 누이를 소개하면서 ‘시누이’라고 말했다. 이 말 자체가 고유어로 쓰인다. 한자어만 모아 놓은 낱말 목록에 시누이를 넣으면 고유어가 포함된 사례를 잘못 분류하게 된다.
    3. 할머니는 오래된 가족사진을 사진첩에 보관했다. ‘사진’도 ‘첩’도 한자에서 온 요소다. 사진을 붙여 두는 물건의 이름을 두 부분으로 나누어 보아도 고유어 요소가 나타나지 않는다.
    4. 수지는 이번 주말에 외할머니 댁을 찾기로 했다. ‘외할머니’의 앞부분 ‘외’는 한자어 요소이고 뒤의 ‘할머니’는 고유어다. 낱말 안에 고유어가 들어 있으므로 사진첩과 어종 구성이 다르다.

    ‘사진첩’의 사진과 첩은 모두 한자어 요소다. 고유어가 들어 있지 않은 것은 3번이다.

    외래어로만 묶인 것은?

    ㄱ. 우동

    ㄴ. 로망

    ㄷ. 메뉴판

    ㄹ. 호프집

    ㅁ. 아지트

    1. 1. ㄱ, ㄷ
    2. 2. ㄱ, ㄴ, ㅁ
    3. 3. ㄴ, ㄹ, ㅁ
    4. 4. ㄴ, ㄷ, ㄹ, ㅁ

    정답 2번

    🔍 보기별 해설
    1. 우동은 일본어에서 들어와 한국어에서 쓰이는 음식 이름이다. 다른 어종의 요소가 결합하지 않은 외래어이므로 옳다.
    2. 로망은 프랑스어에서 들어와 한국어 어휘로 자리 잡은 동경의 뜻을 가진 말이다. 다른 어종의 요소가 붙지 않은 외래어 하나이므로 옳다.
    3. 메뉴판은 외래어 메뉴와 한자어 판이 결합해 식당에서 쓰이는 물건의 이름이 됐다. 한 어종으로만 된 외래어가 아니므로 옳지 않다.
    4. 호프집은 외래어 호프와 고유어 집이 결합해 술집을 가리키는 말이 됐다. 서로 다른 어종이 섞인 혼종어이므로 옳지 않다.
    5. 아지트는 러시아어에서 들어와 사람들이 모이는 장소를 가리키는 한국어 어휘로 쓰인다. 한 낱말 전체가 들어온 외래어이므로 옳다.
    🧮 풀이
    1. 식당에서 손님이 뜨거운 우동 한 그릇을 주문했다. ‘우동’이라는 음식 이름은 일본어에서 들어와 한국어에서 그대로 쓰인다. 이름 안에 한국 고유어나 한자어 요소가 따로 붙어 있지 않다.
    2. 수지는 여행 작가가 되겠다는 로망을 이야기했다. ‘로망’은 프랑스어에서 들어와 바라는 일이나 낭만적인 동경을 가리킬 때 쓰인다. 이 낱말 자체에 다른 어종의 요소가 결합하지 않았다.
    3. 식당 직원은 새 메뉴판에 음식 이름과 가격을 적었다. ‘메뉴’는 외국어에서 들어온 말이고 ‘판’은 한자어 요소다. 물건 하나를 가리키지만 이름의 두 부분은 서로 다른 어종에서 왔다.
    4. 퇴근한 동료들이 골목의 호프집에서 만났다. 가게 이름의 ‘호프’는 외래어이고 뒤의 ‘집’은 한국 고유어다. 두 요소가 한 낱말에 함께 있으므로 외래어만 모은 묶음에 넣지 않는다.
    5. 동호회 사람들은 매주 모이는 작은 방을 아지트라고 불렀다. ‘아지트’는 러시아어에서 들어온 말로 모임의 근거지라는 뜻으로 쓰인다. 낱말 안에 별도의 고유어 요소나 한자어 요소가 붙어 있지 않다.

    정답은 2번이다.

    우리나라에서 만든 한자어가 아닌 것은?

    1. 1. 부모(父母)
    2. 2. 식구(食口)
    3. 3. 감기(感氣)
    4. 4. 전답(田畓)

    정답 1번

    🔍 보기별 해설
    1. ‘부모(父母)’는 중국의 오래된 문헌에도 쓰인 한자어다. 우리나라에서 새로 만든 말이라는 판정은 옳지 않다(정답).
    2. ‘식구(食口)’는 한집에서 함께 먹고 사는 사람을 가리키도록 우리나라에서 만든 한자어다. 한국식 한자어라는 판정은 옳다.
    3. ‘감기(感氣)’는 감기에 걸린 상태를 뜻하도록 우리나라에서 만들어 쓴 한자어다. 한국식 한자어라는 판정은 옳다.
    4. ‘전답(田畓)’은 밭을 뜻하는 ‘田’과 논을 뜻하는 ‘畓’을 결합한 말이다. 한국에서 만든 한자 ‘畓’이 들어 있으므로 옳다.
    🧮 풀이
    1. 수지는 오래된 중국 문헌에서 아버지와 어머니를 함께 가리키는 ‘父母’를 보았다. 오늘날 한국어의 ‘부모’와 같은 한자와 뜻이다. 한국에서 처음 조합해 만든 말로 볼 수 없는 근거가 된다.

    3. ‘짜장면’과 ‘자장면’은 중국식 볶음 국수인 같은 음식을 가리키는 두 표준어다. 둘을 복수 표준어로 묶은 설명은 옳다.
    4. ‘품새’와 ‘품세’는 태권도의 정해진 공격·방어 동작 형식을 가리키는 두 표준어다. 복수 표준어라는 설명은 옳다.
    🧮 풀이
    1. 시장 상인은 채소를 광주리에 담아 팔았다. 손님이 이름을 ‘광우리’라고 적자 상인은 표준어 표기를 ‘광주리’로 확인했다. 두 형태가 같은 뜻의 복수 표준어로 함께 인정된 것은 아니다.
    2. 체육관은 전통 무예 체험 행사의 이름에 ‘택견’을 썼다. 소개 글에는 같은 무예를 가리키는 ‘태껸’도 함께 적었다. 두 이름은 모두 표준어로 인정되어 같은 종목을 부르는 데 쓸 수 있다.
    3. 중국 음식점은 차림표에 ‘자장면’을 적어 두었다. 손님이 ‘짜장면’이라고 주문해도 같은 음식을 내왔다. 두 표기가 모두 표준어이므로 차림표와 일상 대화에 각각 나타날 수 있다.
    4. 태권도 사범은 수련생에게 새 품새를 가르쳤다. 안내문에서는 같은 동작 형식을 ‘품세’라고 적었다. 사범은 두 이름을 모두 사용하며 정해진 공격과 방어 동작을 차례로 시범 보였다.

    ‘광주리’는 표준어지만 ‘광우리’는 복수 표준어로 인정되지 않는다. 정답은 1번이다.

    외래어 표기가 옳은 것을 모두 고른 것은?

    ㄱ. fighting(화이팅)

    ㄴ. thank you(땡큐)

    ㄷ. accessory(액세서리)

    ㄹ. symposium(심포지엄)

    ㅁ. carol(캐롤)

    ㅂ. color(칼라)

    1. 1. ㄱ, ㄴ
    2. 2. ㄷ, ㄹ
    3. 3. ㄱ, ㄹ, ㅁ
    4. 4. ㄴ, ㄷ, ㅂ

    정답 2번

    🔍 보기별 해설
    1. 영어 fighting은 외래어 표기법에 따라 첫소리를 ㅍ으로 옮겨 파이팅으로 적는다. 화이팅을 맞는 표기로 제시했으므로 옳지 않다.
    2. 국립국어원은 thank you에 대해 심의된 외래어 표기가 없다고 밝힌다. 땡큐를 확정된 표준 표기로 제시할 근거가 없으므로 옳지 않다.
    3. 영어 accessory는 한국어에서 액세서리로 적고 악세사리처럼 첫 음절을 바꾸지 않는다. 제시된 표기가 표준 표기에 맞으므로 옳다.
    4. 영어 symposium은 학술 모임의 이름으로 한국어에서 심포지엄으로 적는다. 제시된 표기가 표준 표기에 맞으므로 옳다.
    5. 영어 carol은 한국어에서 캐럴로 적으며 끝부분의 모음을 ㅓ로 옮긴다. 캐롤은 표준 표기가 아니므로 옳지 않다.
    6. 영어 color는 한국어에서 컬러로 적으며 첫 음절의 모음을 ㅓ로 옮긴다. 칼라는 표준 표기가 아니므로 옳지 않다.
    🧮 풀이
    1. 응원단장 A는 경기장에 걸 현수막 초안에 화이팅이라고 썼다. 홍보 담당자는 표준 표기를 찾아 파이팅으로 문구를 고쳤다. 응원단은 고친 현수막을 인쇄해 관중이 보는 경기장 입구에 걸었다.
    2. 번역자 B는 영어 인사말 thank you를 자막에 땡큐라고 적었다. 교열자는 해당 표현에 심의된 외래어 표기가 없다는 국립국어원의 안내를 확인했다. 제작진은 땡큐를 확정된 표준 표기라고 설명하던 자막 주석을 삭제했다.
    3. 온라인 판매자 C는 accessory 상품의 이름을 입력하며 악세사리와 액세서리 중 하나를 골라야 했다. 표준 표기를 대조한 뒤 상품명에 액세서리를 적었다. 검색 목록과 상품 상세 페이지의 표기도 액세서리로 통일됐다.
    4. 학술회의 담당자 D는 symposium을 한국어 행사명으로 옮겼다. 외래어 표기 자료에서 심포지엄을 확인해 포스터와 신청서에 같은 이름을 적었다. 참석자에게 배포한 일정표에도 심포지엄이라는 표기가 실렸다.
    5. 음악회 기획자 E는 행사 안내문의 캐롤을 교열자에게 보냈다. 교열자는 carol의 표준 표기가 캐럴임을 확인해 안내문을 수정했다. 인쇄된 프로그램과 온라인 예매 화면에 캐럴이 같은 형태로 표시됐다.
    6. 디자이너 F는 상품 설명에 칼라라는 낱말을 넣었다. 교열자는 영어 color의 표준 표기를 확인하고 컬러로 고쳤다. 수정한 상품 설명이 포장지와 판매 페이지에 함께 실렸다.

    정답은 2번이다.

    동의 경쟁의 결과로 옳은 것은?

    1. 1. 한자어와 고유어의 경쟁에서는 항상 한자어가 생존한다.
    2. 2. 두 단어가 의미 영역을 분담하여 공존하는 경우도 있다.
    3. 3. 경쟁 결과 의미 변화는 일어나지 않고 사용 빈도만 달라진다.
    4. 4. 경쟁하는 단어 중 동음이의어가 있는 쪽이 생존 가능성이 높다.

    정답 2번

    🔍 보기별 해설
    1. 한자어와 고유어가 같은 뜻으로 겨루더라도 어느 한쪽이 언제나 살아남는 법칙은 없고 실제 결과도 단어마다 다르므로 옳지 않다.
    2. 비슷한 뜻의 두 말이 경쟁한 뒤 각각 쓰이는 의미 범위를 나누어 맡으면서 모두 살아남아 함께 사용되는 경우도 있으므로 옳다(정답).
    3. 같은 뜻을 지닌 말들이 경쟁하는 과정에서는 사용 빈도뿐 아니라 뜻의 범위가 좁아지거나 달라지는 의미 변화도 생길 수 있으므로 옳지 않다.
    4. 다른 뜻의 같은 소리를 가진 말이 이미 있으면 의미 전달에서 혼동이 생길 수 있어 오히려 경쟁에서 불리하게 작용할 수 있으므로 옳지 않다.
    🧮 풀이
    1. 甲은 옛 문헌과 현대 신문에서 같은 뜻을 나타내던 고유어와 한자어의 사용 빈도를 시대별로 조사했다. 어떤 말은 고유어가 남고 다른 말은 한자어가 널리 쓰이는 결과를 확인하여 단어별 변화 양상을 표로 정리했다.
    2. 甲은 처음에는 비슷한 뜻으로 쓰이던 두 낱말이 시간이 흐른 뒤 서로 다른 상황에서 선택되는 자료를 모았다. 하나는 일상적인 뜻을, 다른 하나는 전문적인 뜻을 맡아 함께 살아남은 모습을 용례별로 구분해 적었다.
    3. 甲은 오래된 사전과 현대 사전에서 경쟁 관계에 있던 두 낱말의 뜻풀이를 비교했다. 사용 횟수만 달라진 것이 아니라 한 낱말의 의미 범위가 좁아진 사례를 찾아 시대별 의미 영역을 원으로 그려 보았다.
    4. 甲은 소리가 같지만 뜻이 다른 낱말이 여러 개 있는 자료를 읽다가 문맥 없이는 뜻을 가리기 어려운 사례를 발견했다. 이런 혼동이 낱말의 생존에 반드시 유리한 조건은 아니라는 점을 실제 문장으로 확인했다.

    동의 경쟁에서는 한 말이 사라질 수도 있고 두 말이 의미 영역을 나누어 공존하거나 의미가 달라질 수도 있다.

    혼종어로 옳은 것은?

    1. 1. 양말
    2. 2. 미나리
    3. 3. 떡케이크
    4. 4. 시나리오

    정답 3번

    🔍 보기별 해설
    1. ‘양말’은 ‘서양 양’과 ‘버선 말’이라는 한자어 요소끼리 결합해 만들어진 말이므로 서로 다른 언어 계통의 요소가 섞인 혼종어는 아니어서 옳지 않다.
    2. ‘미나리’는 다른 언어에서 들어온 요소와 고유어 요소가 결합한 말이 아니라 본래부터 사용해 온 고유어 하나이므로 혼종어라는 판단은 옳지 않다.
    3. ‘떡케이크’는 고유어 ‘떡’과 영어에서 들어온 외래어 ‘케이크’가 결합하여 서로 다른 계통의 요소로 이루어진 혼종어이므로 옳다(정답).
    4. ‘시나리오’는 외국어에서 들어온 하나의 외래어로서 고유어·한자어 등 서로 다른 계통의 요소가 내부에서 결합한 말이 아니므로 옳지 않다.
    🧮 풀이
    1. 甲은 ‘양말’을 두 부분으로 나누고 각 요소의 어원을 사전에서 확인했다. 두 조각이 모두 한자에서 유래했다는 사실을 확인한 뒤 서로 다른 언어 계통이 섞인 사례와 구별하여 어원별 분류표에 적었다.
    2. 甲은 시장에서 미나리를 산 뒤 이름의 유래가 궁금해 국어사전을 찾아보았다. 외래어 요소가 붙어 만들어진 말이 아니라 고유어로 전해진 낱말임을 확인하고 혼종어 목록에서 따로 떼어 표시했다.
    3. 甲은 카페 진열대에서 ‘떡케이크’라는 이름을 보고 앞부분과 뒷부분의 출처를 나누어 살폈다. 고유어와 영어에서 들어온 말이 하나의 낱말 안에서 결합한 것을 확인하고 혼종어 사례로 공책에 기록했다.
    4. 甲은 영화 수업에서 ‘시나리오’라는 낱말을 적은 뒤 내부를 고유어와 외래어 요소로 나눌 수 있는지 살폈다. 하나의 외래어가 통째로 받아들여진 말임을 확인하고 혼종어와 외래어를 다른 칸에 분류했다.

    ‘떡케이크’는 고유어 ‘떡’과 외래어 ‘케이크’가 결합하여 만들어진 혼종어이다.

    상보 반의어의 특징으로 옳지 않은 것은?

    1. 1. 두 단어를 동시에 긍정하거나 부정하면 모순이 된다.
    2. 2. 정도 부사의 수식을 받을 수 없고, 비교 표현으로도 사용되지 않는다.
    3. 3. 판단 대상에 관계없이 동일한 기준이 적용되는 절대적 개념으로 사용된다.
    4. 4. 한쪽 단어의 단언과 다른 쪽 단어의 부정 사이에 일방함의 관계가 성립한다.

    정답 4번

    🔍 보기별 해설
    1. ‘살다－죽다’ 같은 상보 반의 관계에서는 어느 대상을 두 상태라고 함께 긍정하거나 어느 쪽도 아니라고 함께 부정하면 논리적 모순이 생기므로 옳다.
    2. 상보 반의어는 중간 정도를 인정하지 않는 이분적인 관계이므로 ‘매우’ 같은 정도 표현이나 ‘더’와 같은 비교 표현을 일반적으로 허용하지 않으므로 옳다.
    3. 상보 관계는 중간 단계를 두지 않고 어느 한쪽이면 다른 쪽이 아닌 절대적 대립으로 파악하므로 대상마다 기준이 달라지는 등급 반의어와 구별되어 옳다.
    4. 상보 반의어에서는 한쪽을 긍정하면 다른 쪽을 부정하고, 한쪽을 부정해도 다른 쪽을 긍정하므로 함의가 한 방향에만 성립한다는 설명은 옳지 않다(정답).
    🧮 풀이
    1. 甲은 한 사람이 동시에 살아 있으면서 죽어 있다고 말하는 문장과 둘 다 아니라고 말하는 문장을 만들어 보았다. 두 상태 사이에 제3의 선택을 두기 어려워 문장 자체가 모순되는 것을 확인하고 대립 관계를 표시했다.
    2. 甲은 ‘살다’와 ‘죽다’ 앞에 ‘매우’와 ‘조금’을 붙이고 두 사람을 두고 어느 쪽이 더 죽었다고 비교하는 문장도 만들어 보았다. 자연스럽지 않은 표현들을 확인하며 정도의 중간값을 허용하지 않는 성질을 정리했다.
    3. 甲은 여러 사람의 생사 여부를 판정하는 표를 만들면서 키나 온도처럼 사람마다 달라지는 경계값을 따로 정하지 않았다. 살아 있지 않으면 죽은 것으로 나뉘는 이분적인 기준을 적용하여 각 사례를 두 칸에 배치했다.
    4. 甲은 ‘살아 있다’와 ‘죽어 있다’를 이용해 긍정과 부정의 관계를 화살표로 그렸다. 살아 있으면 죽지 않았고 살아 있지 않으면 죽었다는 두 방향의 추론이 모두 성립하는 모습을 확인해 양쪽 화살표를 표시했다.

    상보 반의어는 중간항 없이 양쪽이 서로를 배제하므로 긍정과 상대편 부정 사이의 함의가 양방향으로 성립한다.

    고유어가 포함되지 않은 것은?

    1. 1. 책값
    2. 2. 시누이
    3. 3. 사진첩
    4. 4. 외할머니

    정답 3번

    🔍 보기별 해설
    1. ‘책값’은 한자어 ‘책’과 고유어 ‘값’이 결합한 말이므로 구성 요소 가운데 고유어가 들어 있어 고유어가 없는 사례라는 판단은 옳지 않다.
    2. ‘시누이’는 남편의 자매를 가리키는 고유어이므로 낱말 자체에 고유어 요소가 분명히 있어 고유어가 없는 사례라는 판단은 옳지 않다.
    3. ‘사진첩’은 한자어 ‘사진’과 한자어 ‘첩’이 결합하여 이루어진 말로서 고유어 요소가 들어 있지 않으므로 옳다(정답).
    4. ‘외할머니’는 한자어 요소인 ‘외’와 고유어인 ‘할머니’가 결합한 말이므로 구성 가운데 고유어가 들어 있어 고유어가 없는 사례는 아니므로 옳지 않다.
    🧮 풀이
    1. 甲은 서점에서 책의 가격표를 보며 ‘책값’이라는 말을 두 부분으로 나누었다. ‘책’은 한자에서 온 말이고 ‘값’은 고유어라는 것을 사전에서 확인한 뒤 서로 다른 계통의 요소가 결합한 사례로 표시했다.
    2. 甲은 가족 관계도를 그리며 아버지의 누이와 남편의 누이를 가리키는 말을 각각 적어 보았다. 그중 ‘시누이’가 외국어나 한자어에서 빌려 온 말이 아니라 고유어라는 것을 확인해 어종 칸에 기록했다.
    3. 甲은 오래된 가족사진을 보관할 앨범을 찾다가 ‘사진첩’이라는 낱말을 분석했다. ‘사진’과 ‘첩’이 모두 한자에서 온 요소임을 확인하고 고유어가 하나도 들어 있지 않은 사례로 분류표에 표시했다.
    4. 甲은 가족 소개문을 쓰며 ‘외할머니’를 구성 요소별로 나누어 보았다. 앞의 ‘외’는 한자어 요소이고 뒤의 ‘할머니’는 고유어라는 사실을 확인한 뒤 두 계통이 결합한 낱말로 정리했다.

    ‘사진첩’은 한자어 요소끼리 이루어진 말이고 ‘책값·시누이·외할머니’에는 고유어가 들어 있다.

    외래어로만 묶인 것은?

    ㄱ. 우동

    ㄴ. 로망

    ㄷ. 메뉴판

    ㄹ. 호프집

    ㅁ. 아지트

    1. 1. ㄱ, ㄷ
    2. 2. ㄱ, ㄴ, ㅁ
    3. 3. ㄴ, ㄹ, ㅁ
    4. 4. ㄴ, ㄷ, ㄹ, ㅁ

    정답 2번

    🔍 보기별 해설
    1. ‘우동’은 일본어에서 들어온 외래어이지만 ‘메뉴판’은 외래어 ‘메뉴’와 한자어 ‘판’이 결합한 혼종어이므로 둘 모두 외래어라는 분류는 옳지 않다.
    2. ‘우동’은 일본어, ‘로망’은 프랑스어, ‘아지트’는 러시아어에서 들어와 한국어 어휘 체계에 자리 잡은 말들이므로 모두 외래어라서 옳다.
    3. ‘로망’과 ‘아지트’는 외래어이지만 ‘호프집’은 외래어 ‘호프’와 고유어 ‘집’이 결합한 혼종어이므로 세 낱말 모두 외래어라는 분류는 옳지 않다.
    4. ‘로망’과 ‘아지트’는 외래어이나 ‘메뉴판’과 ‘호프집’은 서로 다른 어종이 결합하여 만들어진 혼종어이므로 네 말 모두 외래어라는 분류는 옳지 않다.
    🧮 풀이
    1. 甲이 음식점 차림표에서 ‘우동’과 ‘메뉴판’을 찾아 어종을 분석했다. ‘우동’은 통째로 일본어에서 들어왔지만 ‘메뉴판’은 외래 요소와 한자 요소가 합쳐졌음을 표에 따로 표시했다.
    2. 甲이 외래어 사전을 펼쳐 ‘우동’, ‘로망’, ‘아지트’의 유래를 차례로 확인했다. 각각 일본어·프랑스어·러시아어에서 들어온 말임을 확인하고 세 낱말을 같은 외래어 칸에 적었다.
    3. 甲이 소설을 읽다가 ‘로망’과 ‘아지트’를 표시한 뒤 거리의 ‘호프집’ 간판도 함께 분석했다. 앞의 두 말과 달리 ‘호프집’에는 고유어 ‘집’이 결합했다는 차이를 공책에 적었다.
    4. 甲이 ‘메뉴판’의 ‘판’과 ‘호프집’의 ‘집’을 각각 떼어 보고 ‘로망’, ‘아지트’와 비교했다. 서로 다른 어종이 섞인 두 말과 통째로 들어온 외래어를 두 무리로 나누어 정리했다.

    우동·로망·아지트만 외래어이고 메뉴판·호프집은 혼종어이므로 ㄱ, ㄴ, ㅁ을 고른 정답은 2번이다.

    우리나라에서 만든 한자어가 아닌 것은?

    1. 1. 부모(父母)
    2. 2. 식구(食口)
    3. 3. 감기(感氣)
    4. 4. 전답(田畓)

    정답 1번

    🔍 보기별 해설
    1. ‘부모’는 중국의 고전 문헌에서도 오래전부터 쓰여 온 한자어로 한국에서 새롭게 만들어 낸 한자어가 아니므로 해당하지 않는다(정답).
    2. ‘식구’는 한자 ‘食口’를 이용해 우리나라에서 만들어 쓰기 시작한 한자어로, 한집에서 함께 생활하는 사람들을 가리키므로 해당한다.
    3. ‘감기’는 ‘感氣’라는 한자를 바탕으로 우리나라에서 만들어져 오늘날 호흡기 질환을 가리키는 말로 굳어진 한자어이므로 해당한다.

    표준 발음으로 옳지 않은 것은?

    1. 1. 맑다[막따]
    2. 2. 없다[업ː따]
    3. 3. 젊다[점ː따]
    4. 4. 짧다[짭따]

    정답 4번

    🔍 보기별 해설
    1. ‘맑다’는 어말의 겹받침 ‘ㄺ’에서 ‘ㄹ’이 탈락하고 ‘ㄱ’이 남으며 뒤의 ‘ㄷ’도 된소리로 나므로 [막따]라는 발음은 옳다.
    2. ‘없다’는 겹받침 ‘ㅄ’에서 ‘ㅅ’이 탈락하여 받침이 [ㅂ]으로 실현되고 뒤따르는 ‘ㄷ’은 된소리가 되므로 [업ː따]라는 발음은 옳다.
    3. ‘젊다’는 겹받침 ‘ㄻ’에서 ‘ㄹ’이 탈락하고 ‘ㅁ’이 받침으로 실현되며 뒤의 ‘ㄷ’이 된소리로 바뀌므로 [점ː따]라는 발음은 옳다.
    4. ‘짧다’의 겹받침 ‘ㄼ’은 자음 앞에서 ‘ㄹ’로 발음되어 [짤따]가 되므로, ‘ㅂ’을 받침으로 실현한 [짭따]라는 발음은 옳지 않다(정답).
    🧮 풀이
    1. 甲은 ‘날씨가 맑다’를 소리 내어 읽으면서 ‘ㄺ’의 두 자음을 모두 내지 않았다. [막따]라고 발음한 뒤 받침에서는 ‘ㄱ’만 남고 뒤의 ‘ㄷ’이 된소리로 바뀌는 과정을 칠판에 적었다.
    2. 甲은 낭독 시간에 ‘시간이 없다’를 [시간이 업ː따]라고 읽었다. ‘없다’의 겹받침 가운데 ‘ㅂ’만 받침으로 소리 나고 뒤의 ‘ㄷ’이 [ㄸ]으로 바뀌는 것을 발음표에 표시했다.
    3. 甲은 “그 사람은 아직 젊다.”를 천천히 읽으면서 [점ː따]라고 발음했다. ‘ㄻ’ 가운데 ‘ㅁ’이 종성으로 남고 이어지는 ‘ㄷ’이 된소리가 되는 과정을 음절별로 나누어 확인했다.
    4. 甲은 “끈이 너무 짧다.”를 처음에 [짭따]라고 읽었다가 표준 발음 자료를 확인했다. 겹받침 ‘ㄼ’에서 ‘ㄹ’이 남는 경우임을 확인하고 [짤따]로 다시 읽어 녹음했다.

    ‘짧다’는 겹받침 ‘ㄼ’에서 ‘ㄹ’이 발음되고 뒤의 ‘ㄷ’이 된소리가 되어 표준 발음은 [짤따]이다.

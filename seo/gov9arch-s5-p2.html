    그림과 같은 2방향 직사각형 독립 기초판의 단변방향으로 배근할 전체 철근량이 15,000 mm2이면, 유효폭 내에 배근해야 하는 단변방향 철근량[mm2]은?

    1. 1. 10,000
    2. 2. 12,000
    3. 3. 12,500
    4. 4. 13,500

    정답 2번

    🔍 보기별 해설
    1. 집중배근비를 잘못 적용해 전체 철근량의 3분의 2 정도만 남기면 10,000이 나올 수 있으나 실제 계산값과는 다르므로 옳지 않다.
    2. 장변과 단변의 비 β=6/4=1.5를 γ=2/(β+1) 공식에 넣어 구하면 γ=0.8이 되고, 전체 철근량 15,000에 곱하면 12,000이 되어 실제 계산값과 그대로 맞으므로 옳다(정답).
    3. 비율을 소수점에서 반올림해 조금 다르게 잡으면 12,500이 나올 수 있으나 공식대로 정확히 구한 실제 계산값과는 다르므로 옳지 않다.
    4. 집중배근비를 실제보다 크게 잡으면 13,500이 나올 수 있으나 β=1.5를 정확히 대입해 구한 실제 계산값과는 다르므로 옳지 않다.
    🧮 풀이
    1. 甲은 전체 철근량의 3분의 2 정도만 유효폭에 넣으면 된다고 어림잡아 계산했다가 공식과 다른 값이 나오는 것을 발견했다. 정확한 공식으로 처음부터 다시 계산해 고쳤다.
    2. 甲은 기초판의 장변 6 m와 단변 4 m 비율을 공식에 대입해 집중배근비 0.8을 구해 보았다. 전체 철근량 15,000에 그 비율을 곱해 12,000이라는 값을 얻었다.
    3. 甲은 집중배근비 계산 도중 소수점을 반올림해 값을 살짝 다르게 잡았다가 결과가 어긋나는 것을 알아챘다. 반올림하지 않은 정확한 값으로 처음부터 다시 계산해 고쳤다.
    4. 甲은 집중배근비를 실제보다 넉넉하게 잡아 철근량을 계산했다가 검산 단계에서 값이 너무 크다는 것을 뒤늦게 발견했다. 공식에 정확한 비율을 대입해 값을 고쳐 제출했다.

    장변·단변 비로 구한 집중배근비 0.8을 곱하면 유효폭 철근량은 12,000 mm²다.

    다음 그림은 철근콘크리트 기둥의 P－M 상관도에 기둥의 세장비에 따른 파괴양상을 표현하였다. (가) ～ (다)에 들어갈 말을 바르게 연결한 것은?

    (가) (나) (다)

    1. 1. 재료파괴 재료파괴 좌굴파괴
    2. 2. 재료파괴 좌굴파괴 좌굴파괴
    3. 3. 좌굴파괴 재료파괴 재료파괴
    4. 4. 좌굴파괴 좌굴파괴 재료파괴

    정답 1번

    🔍 보기별 해설
    1. (가)와 (나) 모두 재료파괴, (다)만 좌굴파괴로 놓으면 실제 P－M 상관도에서 세장비가 커질수록 안쪽 곡선으로 옮겨 가는 순서와 그대로 맞으므로 옳다(정답).
    2. (나)까지 좌굴파괴로 넣으면 원래 상관곡선에 가까운 (나)가 재료 강도 한계까지 도달해 파괴되는 실제 거동과 어긋나 옳지 않다.
    3. (가)를 좌굴파괴로 놓으면 가장 바깥쪽 원래 곡선 위에서 재료 강도 한계까지 도달해 파괴되는 실제 거동과 어긋나 옳지 않다.
    4. (가)와 (나)를 모두 좌굴파괴로 놓으면 세장비가 작아 재료 강도까지 버티는 (가)·(나)의 실제 거동과 어긋나 옳지 않다.
    🧮 풀이
    1. 甲은 세장비가 작은 짧은 기둥의 P－M 곡선을 그려 놓고 하중이 원래 곡선 끝까지 다다르는 지점을 (가)로 표시했다. 재료 강도 한계에 닿아 끝난다는 설명을 옆에 적었다.
    2. 甲은 중간 세장비의 기둥을 시험대에 올려 (나)에 해당하는 파괴점을 하나하나 꼼꼼히 확인해 보았다. 원래 곡선에서 크게 벗어나지 않은 채 끝나는 것을 그래프에 표시해 남겼다.
    3. 甲은 가장 가느다란 기둥을 시험해 (다)에서 하중이 가장 안쪽 곡선을 따라 꺾이며 끝나는 것을 확인했다. 좌굴이 재료 강도보다 먼저 일어난다는 설명을 옆에 적어 두었다.
    4. 甲은 세 기둥의 세장비를 나란히 견주며 곡선이 안쪽으로 옮겨 갈수록 좌굴 영향이 커지는 흐름을 표로 정리했다. (가)에서 (다)로 갈수록 파괴 유형이 달라지는 것을 확인했다.

    세장비가 작은 (가)·(나)는 재료파괴, 가장 세장한 (다)는 좌굴파괴다.

    강구조 설계에서 용접에 대한 설명으로 옳지 않은 것은?

    1. 1. 필릿용접의 유효면적은 유효길이에 유효목두께를 곱한 것으로 한다.
    2. 2. 필릿용접의 유효길이는 필릿용접의 총길이에서 용접치수의 2배를 공제한 값으로 한다.
    3. 3. 플러그용접과 슬롯용접의 유효길이는 목두께의 중심을 잇는 용접중심선의 길이로 한다.
    4. 4. 강도를 기반으로 하여 설계되는 필릿용접의 최소길이는 공칭용접치수의 3배 이상으로 하여야 한다.

    정답 4번

    🔍 보기별 해설
    1. 필릿용접의 유효면적을 유효길이와 유효목두께의 곱으로 정의한 설명이 실제 정의와 그대로 맞으므로 옳지 않은 것을 찾는 이 문항에서는 옳다.
    2. 필릿용접의 유효길이를 총길이에서 용접치수의 2배를 뺀 값으로 정의한 설명이 실제 정의와 그대로 맞으므로 옳지 않은 것을 찾는 이 문항에서는 옳다.
    3. 플러그용접과 슬롯용접의 유효길이를 목두께 중심을 잇는 용접중심선의 길이로 정의한 설명이 실제 정의와 그대로 맞으므로 옳지 않은 것을 찾는 이 문항에서는 옳다.
    4. 강도를 기반으로 설계되는 필릿용접의 최소길이를 공칭용접치수의 3배 이상이라 적었는데 실제 기준은 4배 이상이라 배수가 실제와 어긋나 옳지 않다(정답).
    🧮 풀이
    1. 甲은 필릿용접 부위의 유효길이와 유효목두께를 각각 자로 재어 곱해 유효면적을 손수 구해 보았다. 그렇게 구한 값을 강도 계산서에 그대로 옮겨 적고 상사의 결재를 받았다.
    2. 甲은 필릿용접의 총길이에서 용접치수의 2배를 뺀 값을 유효길이로 다시 천천히 계산해 보았다. 시작과 끝부분을 뺀 나머지만 강도에 반영된다는 설명을 옆에 자세히 적어 두었다.
    3. 甲은 플러그용접 구멍의 목두께 중심을 이은 선의 길이를 자로 재어 유효길이로 하나씩 적어 넣었다. 슬롯용접에도 같은 방식을 그대로 적용해 계산서를 마저 채우고 검토를 마쳤다.
    4. 甲은 필릿용접의 길이를 공칭치수의 3배로 설계했다가 기준서를 다시 확인하고서 4배에 못 미친다는 것을 뒤늦게 발견했다. 용접 길이를 넉넉히 늘려 도면을 다시 그려 제출했다.

    필릿용접의 최소길이는 공칭용접치수의 3배가 아니라 4배 이상이어야 한다.

    일반적으로 강재는 저온 상태가 되면 (가) 와/과 (나) 이 급격히 감소하여 (다) 와 같은 현상이 발생하기 쉽다. (가) (나) (다)

    1. 1. 인장강도 전단강성 취성파괴
    2. 2. 인장강도 단면수축률 연성파괴

    4. 4. 연신율 단면수축률 취성파괴

    4. 저온이 되면 연신율과 단면수축률이 급격히 줄어 취성파괴가 나기 쉽다는 짝짓기가 실제 저온취성 현상과 그대로 맞으므로 옳다(정답).

    3. 甲은 저온에서 시편이 늘어나지 않고 갑자기 뚝 끊어지는 파단면을 사진으로 찍어 남겨 두었다. 매끈하지 않고 거칠게 갈라진 단면을 보고 취성파괴라고 보고서에 적었다.

    강구조 설계에 대한 용어 설명으로 옳은 것은?

    1. 1. 자유돌출판은 하중의 방향과 평행하게 양면이 직각방향의 판요소에 의해 연속된 압축을 받는 평판요소이다.
    2. 2. 스켈럽은 용접선의 단부에 붙인 보조판으로 용접의 시작부나 종단부에서 용착금속의 결함 방지를 위하여 사용한다.
    3. 3. 블록전단파단은 접합부에서, 한쪽 방향으로는 인장파단, 다른 방향으로는 전단항복 혹은 전단파단이 발생하는 한계상태이다.
    4. 4. 인장역작용은 하중점과 볼트, 접합된 부재의 반력 사이에서 지렛대와 같은 거동에 의해 볼트에 작용하는 인장력이 증폭되는 작용이다.

    정답 3번

    🔍 보기별 해설
    1. 자유돌출판을 하중 방향과 평행하게 양면 모두 직각방향 판요소로 연속 지지된 평판요소라 설명하면 그것은 오히려 구속판요소를 가리키는 설명이라 옳지 않다.
    2. 스켈럽을 용접선 단부에 붙여 용착금속 결함을 막는 보조판이라 설명하면 그것은 오히려 엔드탭을 가리키는 설명이라 옳지 않다.
    3. 접합부에서 한쪽 방향으로는 인장파단이, 다른 방향으로는 전단항복 또는 전단파단이 함께 일어나는 한계상태를 블록전단파단이라 부르는 설명이 실제 정의와 그대로 맞으므로 옳다(정답).
    4. 인장역작용을 하중점과 볼트, 부재 반력 사이의 지렛대 거동으로 볼트 인장력이 커지는 작용이라 설명하면 그것은 오히려 지렛대작용을 가리키는 설명이라 옳지 않다.
    🧮 풀이
    1. 甲은 한쪽 가장자리만 판에 붙고 나머지 세 변은 뚫려 있는 앵글 부재의 단면 모양을 꼼꼼히 스케치했다. 그 부재를 자유돌출판이라 이름 붙이고 도면 여백에 자세히 표시했다.
    2. 甲은 용접 시작과 끝부분에 덧댄 작은 보조판이 무엇인지 몰라 그 이름을 한참 헷갈려 하며 스켈럽이라 적었다가 나중에 용어집을 다시 찾아보고 엔드탭으로 고쳐 적었다.
    3. 甲은 볼트 접합부 파단면을 살피며 한쪽은 인장으로, 다른 쪽은 전단으로 찢어진 것을 발견하고 놀랐다. 그 파괴 양상을 블록전단파단이라 적고 사진을 붙여 보고했다.
    4. 甲은 하중을 받은 볼트가 지렛대처럼 휘며 인장력이 커지는 접합부 실험을 오래도록 지켜보았다. 그 현상의 이름을 인장역작용이라 적었다가 지렛대작용으로 고쳐 적었다.

    블록전단파단은 한쪽은 인장파단, 다른 쪽은 전단항복·파단이 함께 일어나는 한계상태다.

    강구조 하중저항계수 설계법의 용어에 대한 설명으로 옳지 않은 것은?

    🧮 풀이

    3. 甲은 서로 직각으로 맞닿은 두 강판 사이에 삼각형 단면이 생기도록 용접봉을 움직여 필릿용접을 떠 보았다. 완성된 용접부 단면을 잘라 삼각형 모양이 그대로 나온 것을 확인하고 검사표에 적었다.
    4. 甲은 가새 없이 보와 기둥 접합부만으로 지어진 골조 모형에 수평힘을 걸어 접합부가 휘며 버티는 모습을 지켜보았다. 그 골조를 비가새골조라 부른다는 것을 구조계산서 용어 설명란에 적어 두었다.

    그림과 같이 내민보에 등분포하중 10 kN/m가 작용할 때, A 지점의 수직반력[kN]은? (단, 보의 자중은 무시한다)

    2. 2. 40
    3. 3. 60
    4. 4. 80

    🔍 보기별 해설

    🧮 풀이
    1. 甲은 B점을 기준으로 모멘트평형식을 세워 전체하중 120킬로뉴턴과 그 작용점 사이 거리를 곱한 값으로 B지점 반력부터 90킬로뉴턴으로 구해 보았다. 전체하중에서 그 값을 뺀 30킬로뉴턴을 A지점 수직반력으로 계산서에 적어 넣었다.
    2. 甲은 내민 구간 4미터에 걸린 하중을 빼놓은 채 AB구간 8미터에 실린 하중만으로 반력을 절반씩 나누어 40킬로뉴턴을 얻어 보았다. 검산 과정에서 내민보 전체의 평형이 맞지 않는 것을 발견하고 계산을 처음부터 다시 했다.
    3. 甲은 전체하중 120킬로뉴턴을 두 지지점에 똑같이 절반씩 나누어 60킬로뉴턴이라는 값을 계산기로 뽑아 보았다. 지지점 사이 간격과 하중 작용 위치를 무시한 계산이라는 것을 뒤늦게 알아차리고 모멘트식을 다시 세웠다.
    4. 甲은 모멘트식의 거리 항을 도면과 다르게 어림잡아 넣어 80킬로뉴턴이라는 반력 값을 얻어 보았다. 치수를 도면과 하나하나 다시 대조하다 거리를 잘못 넣은 것을 발견하고 계산을 고쳐 다시 냈다.

    지구성 훈련에 의한 지근섬유(Type I)의 생리적 변화로 옳지 않은 것은?

    1. 1. 모세혈관 밀도 증가
    2. 2. 마이오글로빈 함유량 감소
    3. 3. 미토콘드리아의 수와 크기 증가
    4. 4. 절대 운동강도에서의 젖산 농도 감소

    정답 2번

    🔍 보기별 해설
    1. 모세혈관은 근섬유로 산소와 연료를 보내는 작은 혈관이다. 지구성 훈련 뒤 근육 주변의 모세혈관 밀도가 높아질 수 있으므로 옳다.
    2. 마이오글로빈은 근섬유 안에서 산소를 붙잡아 미토콘드리아에 공급한다. 지구성 훈련으로 함유량이 늘 수 있는데 감소한다고 했으므로 옳지 않다(정답).
    3. 미토콘드리아는 산소를 이용해 근육이 쓸 ATP를 만드는 세포 안의 장소다. 지구성 훈련 뒤 그 수와 크기가 늘어 산화 능력이 좋아지므로 옳다.
    4. 지구성 훈련으로 산소를 쓰는 능력이 좋아지면 운동 중 젖산이 쌓이는 정도가 줄 수 있다. 같은 속도일 때 혈중 젖산이 전보다 적어질 수 있으므로 옳다.
    🧮 풀이
    1. 오래 달린 甲은 다리 근육 주변에 작은 혈관이 촘촘해졌다. 혈액이 활동하는 근섬유 가까이 산소를 더 잘 전달해 같은 속도의 달리기를 오래 이어 갔다. 산소 공급 통로가 늘어나는 모세혈관 밀도 증가다.
    2. 수영 훈련을 이어 간 甲은 지근섬유에 산소를 붙잡는 단백질이 늘었다. 근육 안으로 들어온 산소가 미토콘드리아에 쓰일 때까지 마이오글로빈이 보관을 도왔다. 지구성 훈련으로 증가하는 마이오글로빈 함유량이다.
    3. 자전거를 꾸준히 탄 甲은 근육 안에서 산소를 쓰는 미토콘드리아가 늘었다. 한 번에 만들 수 있는 ATP가 커져 같은 강도의 페달을 더 오래 밟을 수 있었다. 산화 대사 장소가 많아지는 미토콘드리아 적응이다.
    4. 같은 속도로 달린 甲은 훈련 뒤 혈중 젖산 농도가 전보다 낮았다. 근육의 산소 이용 능력이 좋아져 같은 부담을 더 많은 유산소 대사로 감당했다. 고정된 운동강도에서 나타나는 젖산 반응 감소다.

    지구성 훈련을 하면 지근섬유의 산소 공급과 사용 능력이 좋아진다. 마이오글로빈은 감소하지 않고 늘어나므로 정답은 2번이다.

  • 2

    유산소성 트레이닝을 통한 근육 내 미토콘드리아 변화와 관련된 설명으로 옳지 않은 것은?

    1. 1. 근원섬유 사이의 미토콘드리아 밀도 증가
    2. 2. 근육 내 젖산과 수소 이온(H⁺) 생성 감소
    3. 3. 손상된 미토콘드리아 분해 및 제거율 감소
    4. 4. 근육 내 크레아틴인산(phosphocreatine) 소모량 감소

    정답 3번

    🔍 보기별 해설
    1. 근원섬유 사이의 미토콘드리아는 수축에 필요한 ATP를 가까운 곳에서 만든다. 유산소 훈련 뒤 그 밀도가 높아질 수 있으므로 옳다.
    2. 유산소 능력이 좋아지면 같은 운동강도에서 산화 대사가 더 많은 ATP를 공급한다. 젖산과 수소 이온의 축적이 줄 수 있으므로 옳다.
    3. 손상된 미토콘드리아는 세포의 품질 관리 과정에서 분해되고 새 미토콘드리아로 교체된다. 훈련으로 그 제거율이 감소한다고 단정했으므로 옳지 않다(정답).
    4. 같은 운동강도에서 산소를 쓰는 ATP 생산이 늘면 크레아틴인산에 의존하는 정도가 줄 수 있다. 근육 내 크레아틴인산 소모 감소가 가능하므로 옳다.
    🧮 풀이
    1. 계단을 오르던 甲은 훈련 뒤 근섬유의 수축 부위 곁에 미토콘드리아가 더 많아졌다. 산소를 이용한 ATP 공급이 수축 단백질 가까이에서 이어졌다. 근원섬유 사이 미토콘드리아 밀도 증가다.
    2. 일정한 속도로 달린 甲은 훈련 전보다 다리의 타는 느낌이 늦게 왔다. 미토콘드리아가 산소를 써서 에너지를 더 만들자 젖산과 수소 이온이 덜 쌓였다. 같은 강도에서 나타나는 대사 부산물 감소다.
    3. 오래 자전거를 탄 甲은 근육의 고장 난 미토콘드리아를 분해하고 새것을 만들었다. 손상된 것을 계속 남겨 두면 산소를 쓰는 능력이 떨어지므로 교체가 이어졌다. 미토콘드리아의 분해·제거와 신생을 포함한 품질 관리다.
    4. 완만한 언덕을 오른 甲은 훈련 뒤 같은 속도에서 산소 대사로 ATP를 더 많이 만들었다. 급한 에너지 보충에 쓰는 크레아틴인산의 감소량은 전보다 작았다. 일정 강도에서의 크레아틴인산 의존도 감소다.

    유산소 훈련은 미토콘드리아를 늘리고 손상된 미토콘드리아의 교체도 촉진한다. 손상된 것의 제거율이 감소한다는 설명이 틀리므로 정답은 3번이다.

    운동 중 지방분해를 촉진하는 요인으로 옳지 않은 것은?

    1. 1. 인슐린 증가
    2. 2. 글루카곤 증가
    3. 3. 에피네프린 증가
    4. 4. 순환성(cyclic) AMP 증가

    정답 1번

    🔍 보기별 해설
    1. 인슐린은 지방세포에 저장된 중성지방을 분해하는 효소의 활동을 억제한다. 인슐린 증가를 지방분해 촉진 요인으로 든 것은 옳지 않다(정답).
    2. 글루카곤은 에너지가 필요할 때 몸에 저장된 연료의 동원을 돕는 호르몬이다. 지방조직의 지방분해를 촉진하는 방향으로 작용하므로 옳다.
    3. 에피네프린은 운동 중 교감신경 반응과 함께 지방세포의 수용체에 작용한다. 지방세포에 저장된 중성지방의 분해를 촉진할 수 있으므로 옳다.
    4. 순환성 AMP(cyclic AMP)는 호르몬 신호를 세포 안으로 전달하는 물질이다. 지방분해효소를 활성화하는 신호 과정에 참여하므로 옳다.
    🧮 풀이
    1. 식사 직후 가볍게 걸은 甲은 혈중 인슐린이 높아 저장 지방을 쉽게 꺼내 쓰지 않았다. 지방세포의 분해효소가 억제되어 중성지방의 분해가 줄었다. 지방 저장을 돕고 지방분해를 누르는 인슐린 작용이다.
    2. 공복에 오래 걸은 甲은 혈당을 유지하며 지방을 연료로 썼다. 글루카곤 신호가 저장 연료를 꺼내는 방향으로 작용해 지방산 공급을 도왔다. 에너지 동원에 참여하는 글루카곤 증가다.
    3. 빠른 달리기를 시작한 甲은 교감신경 반응으로 에피네프린을 더 분비했다. 지방세포가 신호를 받아 중성지방을 지방산으로 분해해 혈액에 내보냈다. 운동 중 지방 동원을 높이는 에피네프린 반응이다.
    4. 자전거를 탄 甲은 지방세포의 호르몬 수용체에 운동 신호를 받았다. 세포 안 순환성 AMP가 늘면서 분해효소의 활성화가 뒤따랐다. 호르몬과 지방분해효소를 잇는 순환성 AMP 신호다.

    운동 중 지방분해는 글루카곤·에피네프린과 순환성 AMP의 신호로 촉진된다. 인슐린은 지방분해를 억제하는 쪽이므로 정답은 1번이다.

    운동에 대한 심혈관 반응에 관한 설명으로 옳은 것은?

    1. 1. 점증 부하 운동 시 심근산소소비량 감소
    2. 2. 고강도 운동 시 내장 기관으로의 혈류 분배 비율 증가
    3. 3. 일정한 부하의 장시간 운동 시 시간 경과에 따른 심박수 감소
    4. 4. 고강도 운동 시 활동근의 세동맥(arterioles) 확장을 통한 혈류량 증가

    정답 4번

    🔍 보기별 해설
    1. 운동 부하가 커지면 심장은 더 빠르고 강하게 일해 산소를 더 쓴다. 점증 부하 운동에서 심근산소소비량이 감소한다고 했으므로 옳지 않다.
    2. 고강도 운동 중에는 혈류가 활동근과 심장 쪽으로 더 배분된다. 내장 기관으로 가는 혈류의 비율이 증가한다는 설명은 옳지 않다.
    3. 일정 부하로 오래 운동하면 체온 상승과 혈장량 감소 등으로 심박수가 점차 오를 수 있다. 시간이 지날수록 감소한다고 했으므로 옳지 않다.
    4. 활동근의 세동맥은 운동 중 생긴 대사 신호에 반응해 확장된다. 고강도 운동에서 활동근으로 들어가는 혈류량이 늘므로 옳다(정답).
    🧮 풀이
    1. 트레드밀 속도를 단계별로 올린 甲은 심장이 더 자주 뛰고 수축도 강해졌다. 심장근육에 필요한 산소가 늘어 관상혈류도 더 많이 필요해졌다. 부하 상승에 따르는 심근산소소비량 증가다.
    2. 전력으로 달린 甲은 계속 수축하는 다리 근육에 혈액을 많이 보냈다. 쉬고 있을 때보다 소화기관에 돌아가는 혈류의 몫은 작아졌다. 활동근 쪽으로 혈액을 재분배하는 운동 반응이다.
    3. 고정된 속도로 오래 달린 甲은 뒤로 갈수록 맥박이 조금씩 빨라졌다. 체온이 오르고 땀으로 혈장량이 줄자 같은 운동량을 유지하려고 심장이 더 자주 뛰었다. 장시간 일정 부하 운동의 심혈관 표류다.
    4. 언덕을 빠르게 오른 甲은 다리 근육에서 산소와 저장 연료를 많이 썼다. 활동근의 세동맥이 넓어져 그 부위로 들어가는 혈액이 늘었다. 활동근 혈류를 높이는 국소 혈관 확장이다.

    운동 강도가 높아지면 활동근은 세동맥을 넓혀 혈액을 더 받는다. 고강도 운동 때 활동근 혈류가 증가하는 설명이므로 정답은 4번이다.

    〈보기〉의 ㉠, ㉡에 들어갈 용어가 바르게 나열된 것은? • 심장의 부담을 나타내는 심근산소소비량은 심박수와 ( ㉠ )을 곱하여 산출한다. • 산소섭취량이 동일한 운동 시 다리 운동이 팔 운동에 비해 심근산소소비량이 더 ( ㉡ ) 나타난다.

    1. 1. ㉠ 1회 박출량, ㉡ 높게
    2. 2. ㉠ 1회 박출량, ㉡ 낮게
    3. 3. ㉠ 수축기 혈압, ㉡ 높게
    4. 4. ㉠ 수축기 혈압, ㉡ 낮게

    정답 4번

    🔍 보기별 해설
    1. ㉠은 심박수와 곱해 심근 부담을 나타내는 수축기 혈압이다. ㉡은 같은 산소섭취량에서 다리 운동의 심근산소소비량이 팔 운동보다 낮게 나타나는 것이다.

    ㉠은 수축기 혈압, ㉡은 낮게이므로 정답은 4번이다.

    골격근의 수축 특성을 결정하는 요인에 대한 설명 중 〈보기〉의 ㉠, ㉡에 들어갈 용어가 바르게 연결된 것은? • 특이장력 = 근력 / ( ㉠ ) • 근파워 = 힘 × ( ㉡ )

    1. 1. ㉠ 근횡단면적, ㉡ 수축속도
    2. 2. ㉠ 근횡단면적, ㉡ 수축시간
    3. 3. ㉠ 근파워, ㉡ 수축속도
    4. 4. ㉠ 근파워, ㉡ 수축시간

    정답 1번

    🔍 보기별 해설
    1. ㉠은 근력을 나누어 특이장력을 구하는 근횡단면적이다. ㉡은 힘에 곱해 근파워를 구하는 수축속도다.

    ㉠은 근횡단면적, ㉡은 수축속도이므로 정답은 1번이다.

    〈보기〉의 ㉠~㉢에 들어갈 용어가 바르게 나열된 것은?

    수용기역할근방추( ㉠ ) 정보 전달골지건기관( ㉡ ) 정보 전달근육의 화학수용기( ㉢ ) 정보 전달

    1. 1. ㉠ 근육의 길이, ㉡ 근육 대사량, ㉢ 힘 생성량
    2. 2. ㉠ 근육 대사량, ㉡ 힘 생성량, ㉢ 근육의 길이
    3. 3. ㉠ 근육 대사량, ㉡ 근육의 길이, ㉢ 힘 생성량
    4. 4. ㉠ 근육의 길이, ㉡ 힘 생성량, ㉢ 근육 대사량

    1. 팔꿈치를 굽힌 甲은 상완이두근에 수축 신호를 보냈다. 근형질세망에서 나온 칼슘이 수축 단백질의 결합을 돕자 팔이 움직였다. 근수축에 쓸 칼슘을 저장하고 방출하는 근형질세망이다.

    ATP를 합성하는 데 사용되는 에너지원이 아닌 것은?

    2. 2. ② 비타민C

    🔍 보기별 해설

    2. 큰 힘을 내는 Type IIx 섬유는 보통 낮은 강도의 활동에서 첫 순서가 아니다. Type IIx·Type IIa를 앞에 놓고 Type I을 끝에 둔 배열이므로 옳지 않다.

    2. 평지에서 걷기 시작한 甲은 큰 힘이 필요한 질주를 하지 않았다. Type I 섬유가 먼저 쓰였고 속도를 높인 뒤에야 빠른 섬유의 참여가 늘었다. Type IIx를 출발점에 둔 배열과 다른 크기 원리다.
    3. 甲은 천천히 계단을 오르다가 점점 빠르게 뛰어올랐다. 처음에는 Type I이 주로 참여했고 힘 요구가 커지자 Type IIa와 IIx가 차례로 더 동원됐다. 작은 운동단위부터 동원하는 Type I·IIa·IIx 순서다.
    4. 무게를 조금씩 올린 甲은 다리 근육에서 더 큰 힘을 냈다. 낮은 강도의 Type I 다음에 Type IIa가 참여했고 더 큰 부담에서 Type IIx가 늘었다. IIx를 IIa보다 먼저 놓지 않는 운동단위 동원 순서다.

    1. 1. Basic Constraints: 인증 주체가 CA인지를 식별한다.
    2. 2. Authority Key Identifier: 인증서를 서명하는 데 사용하는 공개 키를 식별한다.
    3. 3. Key Usage: 인증서에 있는 암호화, 서명, 인증서 서명과 같은 키의 목적을 정의한다.
    4. 4. Subject Alternative Name: 인증서의 발급자에 대한 다양한 대체 이름을 제공하는 역할을 한다.

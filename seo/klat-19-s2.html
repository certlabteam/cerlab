    어휘쌍이 이루는 의미 관계에 관한 설명으로 옳지 않은 것은?

    2. 2. ‘틈’-‘겨를’ : ‘틈’과 ‘겨를’은 모든 문맥에서 서로 교체할 수 있는 절대적 동의어이다.

    4. 4. ‘손’-‘손가락’ : ‘손가락’은 ‘손’의 부분을 이루고 있어서 ‘손’의 부분어이다.

    언어 이해와 산출에 관한 설명 또는 예로 옳지 않은 것은?

    1. 1. 의미적 점화: ‘의사’라는 단어는 이전에 의미적으로 관련이 있는 ‘병원’이라는 단어를 처리한 이후 더 빠르게 처리된다.
    2. 2. 통사적 점화: 학습자에게 능동문을 반복하게 한 후 그림 묘사 실험을 수행한 경우에 학습자는 능동문으로 그림을 묘사한다.
    3. 3. 교환: 말실수의 한 유형으로 ‘치즈 피자’ 대신에 ‘피즈 피자’라고 말하는 것을 들 수 있다.
    4. 4. 가든 패스(garden path) 모형: 중의성이 있는 문장을 어느 한 방향으로 분석하고 나중에 이의 잘못을 파악하여 재분석하는 통사 처리 모형이다.

    사회언어학의 개념에 관한 설명으로 옳지 않은 것은?

    1. 1. 피진(pidgin)은 어휘의 수가 적고 복잡한 문법 규칙도 없어 매우 단순화된 언어 형태를 띤다.
    2. 2. 크레올(creole)은 피진보다 언어 체계가 더 안정되고 어휘가 확장된 언어로서, 톡 피신어(Tok Pisin)가 대표적이다.
    3. 3. 양층 언어 현상(diglossia)은 한 언어 공동체에서 두 개의 언어나 방언이 특정 영역에서 체계적으로 구별되어 사용되는 상황이다.
    4. 4. 링구아 프랑카(lingua franca)는 여러 언어를 사용하는 사람들 간의 의사소통을 위한 공동 언어로서, 영어가 대표적이다.

    학습자 언어에 관한 설명으로 옳지 않은 것은?

    1. 1. 목표어다운 사용: 학습자가 목표어를 사용할 때 필수적으로 사용해야 하는 특정 문법 자질을 문맥에서 정확하게 사용하는 것
    2. 2. 체계적 변이: 학습자가 목표어의 특정 자질의 한 형태를 특정한 경우에만 사용하고 다른 형태는 다른 특정한 경우에만 사용하는 규칙성을 보이는 것
    3. 3. 재구조화: 통제된 노력이 요구되던 절차들이 자동화됨에 따라 언어 지식뿐만 아니라 언어 기술 사용 전략에도 질적 변화가 발생하는 것
    4. 4. 안정화: 학습자의 중간 언어 발달이 일시적으로 중지된 상태

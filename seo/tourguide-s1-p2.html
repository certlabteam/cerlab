    다음 설명에 해당하는 것은?

    기병인 신기군, 보병인 신보군, 승병인 항마군으로 편성된 특수 부대이다.

    1. 1. 별기군
    2. 2. 별무반
    3. 3. 삼별초
    4. 4. 훈련도감

    정답 2번

    🔍 보기별 해설
    1. 별기군은 개항 뒤 일본인 교관을 두고 신식 훈련을 시킨 군대로 임오군란의 빌미가 되었다. 그러므로 해당하지 않는다.
    2. 별무반은 윤관이 여진 정벌을 위해 만든 군대다. 그러므로 해당한다(정답).
    3. 삼별초는 최씨 정권의 야별초에서 비롯한 군대다. 그러므로 해당하지 않는다.
    4. 훈련도감은 임진왜란 중에 포수·사수·살수의 삼수병으로 짠 조선의 상비군이다. 그러므로 해당하지 않는다.
    🧮 풀이
    1. 개항 뒤 조선 정부는 일본인 교관의 지도로 신식 군대인 별기군을 훈련시켰다. 기존 군인이 차별에 반발해 임오군란이 일어났다. 윤관의 군대와 다르다.
    2. 윤관은 여진의 기병에 맞서 신기군·신보군·항마군을 조직했다. 기병과 보병, 승병을 함께 써 여진을 공격했다. 별무반의 세 부대다.
    3. 최우가 도둑을 잡을 야별초를 만들었다. 훗날 좌·우별초와 신의군이 삼별초로 이어졌다. 윤관의 여진 정벌보다 뒤에 나타난 조직이다.
    4. 임진왜란 중 조선은 총을 쏘는 포수, 활을 쏘는 사수, 칼을 쓰는 살수를 묶어 훈련도감을 두었다. 고려의 신기군·신보군·항마군과 다르다.

    신기군·신보군·항마군으로 짠 부대는 윤관이 여진을 치려 만든 별무반이다. 그러므로 정답은 2번이다.

    다음 설명에 해당하는 인물은?

    ○ 국청사를 창건하여 천태종을 창시하였다.

    ○ 교단 통합 운동을 펼쳤으며 교관겸수를 제창하였다.

    1. 1. 요세
    2. 2. 의천
    3. 3. 지눌
    4. 4. 혜심

    정답 2번

    🔍 보기별 해설
    1. 요세는 강진 만덕사에서 백련결사를 일으켜 참회와 염불로 극락왕생을 구하자고 한 승려다. 그러므로 해당하지 않는다.
    2. 의천은 국청사를 세워 천태종을 열고 교관겸수를 주장했다. 그러므로 해당한다(정답).
    3. 지눌은 수선사 결사에서 정혜쌍수를 주장했다. 그러므로 해당하지 않는다.
    4. 혜심은 지눌 뒤에 수선사 결사를 이었다. 그러므로 해당하지 않는다.
    🧮 풀이
    1. 요세는 강진 만덕사에서 백련결사를 이끌었다. 승려와 신도에게 참회와 염불을 권했다. 국청사를 세운 왕자 출신 승려의 활동과는 다르다.
    2. 문종의 아들 의천은 승려가 되어 송에 다녀왔다. 국청사를 세우고 천태종을 열어 교리 공부와 참선을 함께 하자고 했다. 교단을 합치려는 움직임이었다.
    3. 지눌은 송광사를 중심으로 수선사 결사를 이끌었다. 승려들은 참선과 지혜를 함께 닦았다. 의천의 천태종과 다른 불교 개혁이다.
    4. 고려의 승려 혜심은 여러 선사의 말을 모아 선문염송집을 엮었다. 수행자들은 이 책으로 화두와 선의 가르침을 익혔다. 천태종을 연 의천의 활동과는 다르다.

    국청사를 세워 천태종을 열고 교관겸수를 내세운 이는 의천이다. 그러므로 정답은 2번이다.

    조선 통신사에 관한 설명으로 옳지 않은 것은?

    1. 1. 조선 초기부터 정기적으로 중국에 파견되었다.
    2. 2. 외교 사절로 일본에서는 국빈으로 예우받았다.
    3. 3. 조선의 선진 학문과 기술을 전파하는 역할을 하였다.
    4. 4. 도쿠가와 막부의 장군이 바뀔 때 권위를 국제적으로 인정받기 위해 파견을 요청받았다.

    정답 1번

    🔍 보기별 해설
    1. 통신사는 일본에 보낸 사절이고 중국에는 조천사와 연행사를 보냈다. 그러므로 옳지 않다(정답).
    2. 통신사 일행이 지나는 길목마다 다이묘가 나서서 맞이하고 숙소와 음식을 갖추어 국빈으로 대접했다. 그러므로 옳다.
    3. 통신사에는 문인과 화원, 의원이 함께 가 시와 글씨를 남기고 의술을 나누어 조선의 학문과 기술을 전했다. 그러므로 옳다.
    4. 도쿠가와 막부는 장군이 새로 자리에 오를 때마다 조선에 사절을 청해 그 권위를 안팎에 드러내려 했다. 그러므로 옳다.
    🧮 풀이
    1. 조선의 사신이 배를 타고 바다를 건너 일본 막부로 갔다. 통신사는 일본과 외교 문서를 주고받았다. 중국에 정기적으로 보낸 사절단의 이름과 다르다.
    2. 에도의 관리가 조선 통신사를 국빈으로 맞았다. 일행은 막부 장군을 만나 외교 예를 갖췄다. 두 나라 사이의 공식 사절이었다.
    3. 조선 통신사와 함께 간 화가와 의원이 일본 사람과 만나 그림과 의학 지식을 나눴다. 외교뿐 아니라 문화 교류도 이루어졌다.
    4. 도쿠가와 막부에 새 장군이 들어서자 일본은 조선에 통신사를 요청했다. 조선의 사절이 에도에 도착해 새 장군과 외교 예를 나눴다.

    통신사는 중국이 아니라 일본에 보낸 사절이다. 그러므로 정답은 1번이다.

    조선 후기 과학 기술의 발달에 관한 설명으로 옳은 것은?

    1. 1. 흥덕사에서 직지심체요절을 간행하였다.
    2. 2. 금속활자로 상정고금예문을 인쇄하였다.
    3. 3. 기기도설을 참고하여 거중기를 만들었다.
    4. 4. 고구려 천문도를 바탕으로 천상열차분야지도를 돌에 새겼다.

    정답 3번

    🔍 보기별 해설
    1. 직지심체요절은 고려 우왕 때 청주 흥덕사에서 찍은 현존 최고의 금속활자본이다. 그러므로 옳지 않다.
    2. 상정고금예문을 금속활자로 찍었다는 기록은 고려 강화 천도 시기의 것으로 이규보의 글에 전한다. 그러므로 옳지 않다.
    3. 정약용은 기기도설을 참고해 거중기를 만들고 화성 축조에 썼다. 그러므로 옳다(정답).
    4. 천상열차분야지도는 조선 태조 때 고구려의 천문도를 바탕으로 돌에 새긴 별자리 지도다. 그러므로 옳지 않다.
    🧮 풀이
    1. 고려의 승려들은 흥덕사에서 금속활자로 직지심체요절을 찍었다. 책이 1377년에 간행됐다. 정조의 화성 축조보다 훨씬 앞선 기술이다.
    2. 고려 조정은 금속활자로 상정고금예문을 인쇄했다. 책은 전하지 않지만 기록이 남았다. 조선 후기 거중기 제작보다 앞선 일이다.
    3. 정약용은 기기도설을 살피고 거중기를 설계했다. 수원 화성 축성 현장에서 큰 돌을 들어 올리는 데 이 장치가 쓰였다. 정조 때의 기술이다.
    4. 권근은 별자리 지도에 붙일 글을 지어 새 왕조의 천문 사업을 설명했다. 석공이 하늘의 별을 새긴 돌을 세우자 천문 지식이 후대까지 남았다. 조선 건국 무렵의 일이다.

    정약용이 기기도설을 참고해 거중기를 만들어 수원 화성을 쌓는 데 썼다. 그러므로 정답은 3번이다.

    조선 중종 대에 관한 설명으로 옳은 것은?

    1. 1. 현량과를 실시하였다.
    2. 2. 대전통편을 편찬하였다.
    3. 3. 식목도감을 설치하였다.
    4. 4. 전민변정도감을 설치하였다.

    정답 1번

    🔍 보기별 해설
    1. 중종은 조광조를 불러 쓰며 학문과 덕행이 뛰어난 이를 추천으로 뽑는 현량과를 두었다. 그러므로 옳다(정답).
    2. 대전통편은 정조가 경국대전과 속대전을 아울러 정리한 법전이다. 그러므로 옳지 않다.
    3. 식목도감은 고려에서 법과 격식을 의논해 정하던 재신·추신의 회의 기구다. 그러므로 옳지 않다.
    4. 전민변정도감은 고려 공민왕 때 빼앗긴 땅과 노비를 되찾으려 둔 기구다. 그러므로 옳지 않다.
    🧮 풀이
    1. 중종은 조광조의 건의로 학문과 품행을 갖춘 사람을 천거받았다. 현량과로 뽑힌 이들이 관리가 됐다. 중종 시기 사림의 개혁이다.
    2. 정조는 조정의 법령을 모아 대전통편을 편찬했다. 법전이 행정의 기준이 됐다. 중종과는 두 세기 넘게 시기가 다르다.
    3. 고려는 법과 제도를 논의할 식목도감을 두었다. 고려의 관청이므로 조선 중종이 만든 기구가 아니다.
    4. 공민왕은 전민변정도감을 두어 권세가가 빼앗은 땅과 사람을 되찾으려 했다. 고려 말 개혁이므로 중종 때와 다르다.

    중종은 조광조를 등용해 천거로 인재를 뽑는 현량과를 시행했다. 그러므로 정답은 1번이다.

    ( )에 해당하는 인물은?

    ( )는/은 서양의 여러 나라를 돌아보면서 듣고 본 역사, 지리, 산업, 정치, 풍속 등을 기록한 을 저술하였다. 국한문 혼용체를 사용하였으며 1895년에 간행되었다.

    1. 1. 김옥균
    2. 2. 박영효
    3. 3. 유길준
    4. 4. 윤치호

    정답 3번

    🔍 보기별 해설
    1. 김옥균은 급진 개화파를 이끌고 갑신정변을 일으켰다가 일본으로 망명한 인물이다. 그러므로 해당하지 않는다.
    2. 박영효는 갑신정변에 함께한 개화파로 태극기를 처음 만들어 쓴 인물로도 알려져 있다. 그러므로 해당하지 않는다.
    3. 유길준은 서양 여행 뒤 국한문 혼용체로 서유견문을 썼다. 그러므로 해당한다(정답).
    4. 윤치호는 독립협회에서 활동하며 독립신문 발행에도 관여한 인물이다. 그러므로 해당하지 않는다.
    🧮 풀이
    1. 김옥균은 개화파 동지들과 갑신정변을 일으켰다. 사흘 만에 실패하자 일본으로 망명했다. 서유견문을 쓴 개화 사상가와는 다른 행적이다.
    2. 박영효는 갑신정변에 참여하고 일본을 오가며 개화를 추진했다. 태극기를 사용한 일로도 알려졌다. 서유견문의 저자는 아니다.
    3. 유길준은 미국과 유럽을 둘러보며 제도와 풍속을 살폈다. 돌아와 본 것을 국한문 혼용 문체의 서유견문에 담았다. 1895년에 책이 간행됐다.
    4. 윤치호는 독립협회 활동에 참여하며 개화와 독립을 주장했다. 독립신문에도 관여했다. 서유견문을 간행한 유길준과는 다른 인물이다.

    서유견문을 국한문 혼용체로 써서 1895년에 펴낸 이는 유길준이다. 그러므로 정답은 3번이다.

    주먹도끼가 처음 만들어진 시대의 생활 모습으로 옳은 것은?

    1. 1. 고인돌을 만들었다.
    2. 2. 비파형 동검을 제작하였다.
    3. 3. 주로 동굴이나 막집에서 살았다.
    4. 4. 무천이라는 제천 행사를 열었다.

    정답 3번

    🔍 보기별 해설

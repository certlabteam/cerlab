    컨테이너 구조에서 컨테이너를 다단적 할 때 그 하중을 전달하는 수직방향의 골재는?

    1. 1. Corner post
    2. 2. End rail
    3. 3. Side rail
    4. 4. Base

    정답 1번

    🔍 보기별 해설
    1. Corner post는 컨테이너 네 모서리의 수직 프레임이다. 다단 적재 때 위 컨테이너의 하중을 아래로 전달하므로 옳다(정답).
    2. End rail은 컨테이너 양 끝의 수평 골재다. 다단 적재 하중을 수직으로 전달하는 Corner post와 달라 옳지 않다.
    3. Side rail은 컨테이너 옆면의 길이 방향 골재다. 수직으로 하중을 전달하는 기둥이 아니므로 옳지 않다.
    4. Base는 컨테이너의 바닥 부분이다. 네 귀퉁이에서 다단 적재 하중을 받는 수직 골재가 아니므로 옳지 않다.
    🧮 풀이
    1. 컨테이너를 여러 단 쌓은 甲은 네 모서리의 Corner post를 점검했다. 위 상자의 무게가 수직 기둥을 따라 아래로 전달되었다. 프레임이 찌그러지지 않은 것을 기록했다.
    2. 컨테이너 끝단의 End rail을 조사한 甲은 가로 방향 부재를 확인했다. 위에서 내려오는 적재하중을 직접 전달하는 수직 기둥과 달랐다. 구조도에 위치를 구분했다.
    3. 옆면의 Side rail을 검사한 甲은 길이 방향으로 이어지는 프레임을 확인했다. 모서리 기둥의 수직 하중 전달 역할과 구분했다. 레일의 휨을 수리 목록에 적었다.
    4. 컨테이너 바닥 Base를 점검한 甲은 바닥재의 손상 부위를 찾았다. 화물이 직접 놓이는 부분이었다. 다단 적재하중을 위아래로 잇는 기둥은 Corner post로 기록했다.

    컨테이너를 다단적 할 때 하중을 전달하는 수직 골재를 고르는 것인데 Corner post만 그 뜻과 맞으므로, 정답은 1번이다.

    컨테이너 번호 체계에 관한 설명으로 옳지 않은 것은?

    1. 1. 영문자와 아라비아 숫자를 조합하여 11자리로 구성된다.
    2. 2. BIC Code 상의 컨테이너 소유자 표기는 3개의 영문자로 한다.
    3. 3. 컨테이너 일련번호는 아라비아 숫자 6개로 표기된다.
    4. 4. 체크 디지트(check digit)는 오류 검산을 위해 아라비아 숫자 2개로 구성된다.

    정답 4번

    🔍 보기별 해설
    1. 영문자와 숫자를 합쳐 11자리로 구성된다는 것은 소유자부호 3·장비구분 1·일련번호 6·체크디지트 1을 더한 자릿수와 맞는 설명이므로 옳다.
    2. BIC Code 상 소유자 표기가 영문자 3개로 이뤄진다는 것은 열한 자리 가운데 앞자리 몫을 맞게 짚은 설명이므로 옳다.
    3. 일련번호가 아라비아 숫자 6개로 표기된다는 것은 열한 자리 가운데 가운데 자리 몫을 맞게 짚은 설명이므로 옳다.
    4. 컨테이너 번호의 체크 디지트는 앞자리의 오류를 검산하는 숫자 한 자리다. 두 자리라는 설명은 옳지 않다(정답).
    🧮 풀이
    1. 컨테이너 번호를 옮겨 적는 甲은 영문자와 아라비아 숫자를 한 자리씩 세었다. 소유자 코드와 장비 코드, 일련번호와 검산 숫자를 합해 열한 자리였다. 반입 기록에서 누락된 문자를 보완한 뒤 전산 번호를 다시 조회했다.
    2. BIC Code의 소유자 표기를 확인한 甲은 번호 앞의 영문자 세 개를 조회했다. 코드에 등록된 회사가 실제 상자 소유자인지 운송 계약과 대조했다. 운송 서류의 소유자란을 일치시키고 장비 식별 문자는 별도로 적었다.
    3. 컨테이너 번호의 숫자 여섯 자리를 읽은 甲은 이를 일련번호로 기록했다. 같은 소유자 코드를 가진 다른 상자들의 번호와 비교해 중복 여부를 확인했다. 추적 시스템에서 해당 상자의 입출항 이력을 찾아냈다.
    4. 번호 끝의 체크 디지트를 세던 甲은 검산용 숫자가 한 자리임을 확인했다. 두 자리라고 적힌 초안은 전체 번호의 길이와도 맞지 않았다. 앞 열 자리로 계산한 검산값을 대조하여 기록을 고쳤다.

    컨테이너 번호 체계 설명 가운데 옳지 않은 것을 고르는 것인데 체크 디지트 자릿수만 틀리므로, 정답은 4번이다.

    컨테이너 외부 표시(marking)에서 확인할 수 없는 것은?

    1. 1. 컨테이너의 자체 중량
    2. 2. 컨테이너의 최대 적재 중량
    3. 3. 컨테이너의 자체 용적
    4. 4. 컨테이너의 운임

    정답 4번

    🔍 보기별 해설
    1. Tare는 빈 컨테이너 자체의 중량으로 외부 표시에 적힌다. 표시에서 확인할 수 있으므로 옳다.
    2. 컨테이너의 최대 적재 중량은 외부 표시판에 수치로 적힌다. 표시에서 확인할 수 있으므로 옳다.
    3. 컨테이너의 자체 용적은 외부 제원 표시에 세제곱미터 단위로 적힌다. 표시에서 확인할 수 있으므로 옳다.
    4. 컨테이너 외부 표시는 자체 중량과 허용 중량 등 물리적 제원을 나타낸다. 계약에 따라 정해지는 운임은 표시하지 않으므로 옳지 않다(정답).
    🧮 풀이
    1. 컨테이너 문짝의 Tare 표기를 읽은 甲은 빈 상자의 자체 중량을 확인했다. 저울에서 잰 컨테이너와 화물의 총중량에서 그 값을 뺐다. 계산한 화물 순중량을 선적 서류의 별도 칸에 기록했다.
    2. 컨테이너 문짝의 최대 적재중량 표시를 읽은 甲은 포대별 무게와 포장재 무게를 합쳤다. 한도를 넘긴 포대는 다른 컨테이너로 옮겨 다시 저울에 달았다. 수정한 총중량이 표시된 허용 범위에 들어 선적 계획을 확정했다.
    3. 상자 외부의 용적 표시를 확인한 甲은 내부 제원표와 수치를 대조했다. 적입할 포장 화물의 외곽 용적을 합쳐 남는 공간을 계산했다. 적화 계획에 용적값을 반영해 상자 안의 배치를 조정했다.
    4. 운임 금액을 찾던 甲은 컨테이너 바깥의 표찰과 번호를 조사했다. 외부에는 무게와 용적 같은 제원이 있었지만 계약에 따라 정해지는 운임은 없었다. 운송 계약서에서 금액을 확인해 청구서에 적었다.

    컨테이너 외부 표시에서 확인할 수 없는 것을 고르는 것인데 운임만 그 표시에 들지 않으므로, 정답은 4번이다.

    ISO Code 6346 규정상 컨테이너 기호 ‘22G0’에 비중 2인 화물을 가득 적재한 경우 화물의 중량은 약 몇 Metric ton 인가? (단, 컨테이너 철판의 두께는 무시한다.)

    1. 1. 37.8
    2. 2. 76.7
    3. 3. 154.0
    4. 4. 163.1

    정답 2번

    🔍 보기별 해설
    1. 22G0 컨테이너의 내용적 약 38.35㎥에 비중 2를 곱하면 약 76.7톤이다. 37.8톤은 절반 수준이므로 옳지 않다.
    2. 22G0 컨테이너의 용적은 약 38.35㎥다. 여기에 비중 2를 곱한 화물 중량이 약 76.7미터톤이므로 옳다(정답).
    3. 38.35㎥에 비중 2를 곱한 화물 중량은 약 76.7톤이다. 154.0톤은 다시 두 배를 적용한 값이라 옳지 않다.
    4. 22G0 컨테이너의 내용적과 비중으로 구한 값은 약 76.7톤이다. 163.1톤은 계산 결과와 달라 옳지 않다.
    🧮 풀이
    1. 20피트 표준 컨테이너의 용적을 찾은 甲은 37.8세제곱미터라는 수치를 확인했다. 비중 2인 화물은 그 용적의 두 배 중량이 된다. 단순 용적 수치를 답으로 적지 않았다.
    2. 기호 22G0의 컨테이너를 측정한 甲은 약 38.35세제곱미터의 적재 용적을 계산했다. 비중 2를 곱해 약 76.7미터톤을 얻었다. 계산 결과를 화물 중량란에 기입했다.
    3. 적재 화물의 중량을 154톤으로 적은 甲은 컨테이너 용적과 비중을 다시 곱했다. 20피트 상자의 실제 용적보다 큰 값을 사용한 오류였다. 중량을 약 76.7톤으로 고쳤다.
    4. 163.1톤을 계산한 甲은 사용한 컨테이너 길이 코드를 재검토했다. 22G0은 20피트 표준형으로 그만한 용적이 나오지 않았다. 올바른 용적에 비중 2를 적용해 값을 수정했다.

    22G0 컨테이너에 비중 2인 화물을 가득 채웠을 때 중량을 구하는 것인데 내용적(약 38.5 m3)에 비중을 곱하면 약 76.7톤이 나오므로, 정답은 2번이다.

    컨테이너 전용선의 구조적 특징이 아닌 것은?

    1. 1. Top side wing tank
    2. 2. Cell guide system
    3. 3. Lashing bridge
    4. 4. Container stanchion

    정답 1번

    🔍 보기별 해설
    1. Top side wing tank는 컨테이너 전용선의 대표적인 적재 구조가 아니다. 제시된 구조적 특징에 해당하지 않으므로 옳지 않다(정답).
    2. Cell guide system은 선창에서 컨테이너의 수직 이동을 안내한다. 컨테이너 전용선의 구조적 특징이므로 옳다.
    3. Lashing bridge는 갑판적 컨테이너를 고박하는 작업 발판이다. 컨테이너 전용선의 구조적 특징이므로 옳다.
    4. Container stanchion은 갑판적 컨테이너를 옆에서 지지한다. 컨테이너 전용선의 구조적 특징이므로 옳다.
    🧮 풀이
    1. Top side wing tank를 선체 도면에서 찾은 甲은 벌크선의 상부 측면 탱크 구조와 비교했다. 컨테이너 전용선의 일반 구조적 특징으로 보기 어려웠다. 제원표에서 해당 항목을 제외했다.
    2. 화물창의 Cell guide를 검사한 甲은 컨테이너가 내려갈 수직 통로를 확인했다. 크레인이 상자를 내리자 가이드가 위치를 잡아 주었다. 선적도가 실제 적재 위치와 맞았다.
    3. Lashing bridge에 오른 甲은 높은 단의 컨테이너 결속봉을 점검했다. 작업자가 안전하게 결속 위치에 접근했다. 갑판 위 상자가 항해 중 흔들리지 않게 고정되었다.
    4. Container stanchion을 확인한 甲은 컨테이너를 지지하는 기둥의 체결 상태를 검사했다. 적재 구조가 필요한 하중을 받는지 확인했다. 구조 점검표에 지지 위치를 기록했다.

    컨테이너 전용선의 구조적 특징이 아닌 것을 고르는 것인데 벌크선에 쓰이는 Top side wing tank만 갈래가 다르므로, 정답은 1번이다.

    위험화물의 컨테이너 적입에 관한 설명으로 옳지 않은 것은?

    1. 1. 적입 전 컨테이너에 부착된 불필요한 명찰, 표찰 등은 제거한다.
    2. 2. 포장화물 검사 시 손상 및 누유가 발견된 경우 컨테이너에 적입하면 안 된다.
    3. 3. 주관청의 승인이 없는 한 드럼은 눕혀서 적입하여야 한다.
    4. 4. 서로 격리하도록 규정된 위험물은 동일한 컨테이너에 적입하면 안 된다.

    정답 3번

    🔍 보기별 해설
    1. 적입 전 컨테이너에 붙은 불필요한 명찰·표찰을 제거한다는 것은 앞선 화물의 흔적이 섞여 혼동을 부르지 않게 막는 실무 순서를 맞게 짚은 설명이므로 옳다.
    2. 손상·누유가 발견된 포장화물은 적입하면 안 된다는 것은 위험을 막는 실무 원칙을 맞게 짚은 설명이므로 옳다.
    3. 드럼은 원칙적으로 세워 적입하며 별도의 승인이 있을 때 예외를 검토한다. 승인 없이 눕혀 적입해야 한다는 설명은 옳지 않다(정답).
    4. 서로 격리하도록 정해진 위험물은 같은 컨테이너에 적입하면 안 된다는 것은 격리 규정을 맞게 짚은 설명이므로 옳다.
    🧮 풀이
    1. 위험화물 적입 전에 甲은 컨테이너에 남은 이전 화물의 명찰과 표찰을 모두 떼었다. 현재 싣는 화물의 위험등급만 표시하고 운송 서류와 대조했다. 외부에서 잘못된 위험 정보를 읽는 일이 없게 되었다.
    2. 위험물 포장에 누유가 있는 것을 발견한 甲은 컨테이너 적입을 즉시 중단했다. 손상된 용기를 격리해 새 용기에 다시 담고 표면을 닦았다. 누출 시험을 통과한 뒤에만 화물을 선적했다.

    2. 승인기관의 별도 명판을 본 甲은 세관승인표찰에 필요한 항목과 구분했다. 승인번호와 제조업자 번호를 우선 확인했다. 명판을 필수 기재사항으로 잘못 추가하지 않았다.
    3. 화물 적재 용적을 계산하던 甲은 컨테이너 제원표에서 내부 용적을 찾았다. 세관승인표찰의 필수 기재사항에는 그 값이 없었다. 적화 계획서의 용적란에 별도로 기록해 통관 표찰과 구분했다.
    4. 컨테이너 제조일자를 조회한 甲은 안전검사 일정과 재검사 기한을 계산했다. 이 문항의 세관승인표찰에 필요한 기재사항과는 별개의 날짜였다. 관리대장에 날짜를 남기되 필수 표찰 항목으로 잘못 추가하지 않았다.
    5. 상자의 형태를 확인한 甲은 세관승인표찰의 형식 표기를 읽었다. 실제 컨테이너 구조와 운송 서류의 종류를 대조했다. 형식이 맞아 통관 자료에 같은 명칭을 기재했다.
    6. 제조업자 식별 번호를 확인한 甲은 생산 기록의 업체 코드와 세관승인표찰을 대조했다. 같은 제작자가 만든 컨테이너임을 확인하고 불일치가 없는지 검사했다. 승인 자료에 제조 주체와 번호를 기록했다.

    정답은 2번이다.

    컨테이너의 종류에 관한 설명으로 옳지 않은 것은?

    1. 1. 오픈 탑 컨테이너는 컨테이너 표준을 초과한 화물 적재에 적합하다.
    2. 2. 냉동 컨테이너는 온도 조절이 필요한 화물 적재에 적합하다.
    3. 3. 탱크 컨테이너는 유류, 화학제품과 같은 액체화물 운송에 적합하다.
    4. 4. 하이 큐브 컨테이너는 ISO 규격 컨테이너보다 1 피트 높다.

    정답 1번

    🔍 보기별 해설
    1. 오픈 탑 컨테이너는 지붕을 열어 높은 화물을 실을 수 있지만 모든 표준 초과 화물에 적합한 것은 아니다. 단정한 설명은 옳지 않다(정답).
    2. 냉동 컨테이너는 온도 조절이 필요한 화물 적재에 적합하다는 설명은 이 컨테이너의 쓰임을 다룬 원문의 뜻과 그대로 맞으므로 옳다.
    3. 탱크 컨테이너는 유류·화학제품과 같은 액체화물 운송에 적합하다는 설명도 이 컨테이너의 쓰임을 다룬 원문의 뜻과 그대로 맞으므로 옳다.
    4. 하이 큐브 컨테이너는 ISO 규격 컨테이너보다 1피트 높다는 설명도 이 컨테이너의 치수를 다룬 원문의 뜻과 그대로 맞으므로 옳다.
    🧮 풀이
    1. 오픈 탑 컨테이너의 열린 지붕으로 甲은 높이가 큰 기계를 크레인으로 내렸다. 기계의 돌출 높이와 항로의 적재 제한을 따로 측정했다. 모든 표준 초과 치수를 자동으로 허용한다는 계획을 수정하고 허용 범위 안에서 기계를 고정했다.
    2. 냉동 컨테이너를 받은 甲은 냉각 장치의 전원을 연결했다. 화물에 필요한 설정 온도를 입력하고 일정 시간 운전 상태를 시험했다. 항해 중 온도 기록이 유지되도록 담당자에게 점검 주기를 전달했다.
    3. 유류를 싣는 甲은 탱크 컨테이너의 밸브와 탱크 외벽을 점검했다. 액체가 새지 않도록 연결부를 밀봉하고 누출 시험을 진행했다. 화학제품 운송 서류에 탱크 형식과 검사 결과를 표시했다.
    4. 하이 큐브 컨테이너를 측정한 甲은 일반 표준형보다 약 1피트 높은 외형을 기록했다. 선박 셀과 갑판의 허용 적재 높이와 대조했다. 상자를 맞는 위치에 배치하고 높이 제한을 선적도에 적었다.

    컨테이너 종류 설명으로 옳지 않은 것을 고르는 것인데 오픈 탑 컨테이너 설명만 어긋나므로, 정답은 1번이다.

    화물이 적재되지 않은 빈 컨테이너의 무게를 나타내는 것은?

    1. 1. PAYLOAD
    2. 2. MAX.GROSS
    3. 3. NET
    4. 4. TARE

    정답 4번

    🔍 보기별 해설
    1. PAYLOAD는 컨테이너에 실을 수 있는 화물의 중량이다. 빈 컨테이너 자체 중량이 아니므로 옳지 않다.
    2. MAX.GROSS는 컨테이너와 화물을 합한 허용 총중량이다. 빈 컨테이너 무게와 달라 옳지 않다.
    3. NET은 컨테이너를 제외한 화물의 순중량이다. 컨테이너 자체 무게가 아니므로 옳지 않다.
    4. TARE는 화물을 싣지 않은 빈 컨테이너의 자체 중량이다. 발문의 무게를 나타내므로 옳다(정답).
    🧮 풀이
    1. 컨테이너의 PAYLOAD 표기를 읽은 甲은 실을 수 있는 화물의 최대 무게를 확인했다. 빈 상자 자체 무게와는 달랐다. 화물 적재 계획의 허용 중량란에 기록했다.
    2. MAX.GROSS 수치를 확인한 甲은 빈 상자와 화물을 합한 최대 총중량으로 읽었다. 저울에서 잰 합계와 대조했다. 제한값을 넘는 화물을 다른 컨테이너로 옮겼다.
    3. NET 수치를 읽은 甲은 화물의 순중량과 컨테이너 자체 중량의 차이를 확인했다. 빈 상자의 구조물 무게만 나타내는 항목은 아니었다. 제원표에서 TARE 값을 따로 찾아 중량 기록을 구분했다.
    4. 빈 컨테이너를 저울에 올린 甲은 화물을 싣지 않은 상태의 무게를 측정했다. 외부에 표시된 TARE 값과 저울 수치를 대조해 차이가 없는지 확인했다. 검량 결과를 빈 상자 중량 항목에 기록했다.

    화물이 적재되지 않은 빈 컨테이너의 무게를 나타내는 것을 고르는 것인데 TARE만 그 뜻과 맞으므로, 정답은 4번이다.

    항만하역장비의 제원에 관한 설명으로 옳지 않은 것은?

    1. 1. 양정은 스프레더로 들어 올릴 수 있는 권상 최대능력을 말한다.
    2. 2. 스팬은 레일 궤도를 주행하는 경우에 레일간 거리를 말한다.
    3. 3. 안벽 크레인의 주행속도는 무부하시 속도로 표시한다.
    4. 4. 권상속도는 스프레더가 들어 올리는 최고 속도로 부하시와 무부하시로 나누어 표시한다.

    정답 1번

    🔍 보기별 해설
    1. 양정은 스프레더가 들어 올릴 수 있는 수직 높이를 뜻한다. 최대 권상중량이라는 설명은 옳지 않다(정답).
    2. 스팬은 레일 궤도를 주행하는 경우에 레일간 거리를 말한다는 설명은 장비 제원의 정의를 다룬 원문의 뜻과 그대로 맞으므로 옳다.
    3. 안벽 크레인의 주행속도는 무부하시 속도로 표시한다는 설명도 이 장비의 표시 기준을 다룬 원문의 뜻과 그대로 맞으므로 옳다.
    4. 권상속도는 스프레더가 들어 올리는 최고 속도를 부하시와 무부하시로 나누어 표시한다는 설명도, 그 속도를 재는 두 조건이 원문의 뜻과 그대로 맞으므로 옳다.
    🧮 풀이
    1. 안벽 크레인의 양정을 확인한 甲은 스프레더가 수직으로 올라갈 수 있는 높이를 쟀다. 들어 올릴 수 있는 최대 중량인 권상능력과 달랐다. 제원표의 두 항목을 분리해 기록했다.
    2. 레일 위 크레인의 두 주행 궤도 사이를 잰 甲은 스팬 길이를 기록했다. 구조도와 대조해 기초 공사 치수가 맞는지 확인했다. 크레인이 레일 안에서 안정적으로 움직였다.
    3. 무부하 상태의 안벽 크레인을 운전한 甲은 정해진 레일 구간을 이동하는 데 걸린 시간을 쟀다. 거리를 시간으로 나누어 주행속도를 구하고 제원표와 비교했다. 장비가 표시된 무부하 속도에 맞게 움직였다.
    4. 권상장비의 부하 상태에서 甲은 크레인 속도를 쟀다. 빈 스프레더를 들어 올리는 무부하 속도도 별도로 측정했다. 두 값을 제원표의 다른 칸에 기록해 운전 기준을 확정했다.

    항만하역장비 제원 설명으로 옳지 않은 것을 고르는 것인데 양정 설명만 어긋나므로, 정답은 1번이다.

    드럼(Drum)과 롤(Roll) 화물을 컨테이너에 적입할 때의 주의사항으로 옳지 않은 것은?

    1. 1. 롤 화물은 변형 또는 파손 방지를 위해 세워서 적재한다.
    2. 2. 롤 화물은 화물사이에 틈이 없도록 깔개나 완충재를 사용한다.
    3. 3. 드럼 화물은 마개를 아래쪽으로 향하도록 적재한다.
    4. 4. 드럼 화물의 겹침 적재 시는 깔개를 끼워 하중의 균형과 안전을 도모한다.

    정답 3번

    🔍 보기별 해설
    1. 변형되거나 부서지지 않도록 롤 화물을 곧게 세워 싣는다는 설명은 이 화물의 적입 방법을 다룬 원문의 뜻과 그대로 맞으므로 옳다.
    2. 롤 화물끼리 틈이 벌어지지 않도록 깔개나 완충재로 채운다는 설명도 적입 시 보호 방법을 다룬 원문의 뜻과 그대로 맞으므로 옳다.
    3. 드럼은 마개가 위쪽을 향하도록 세워 적입해야 누유 위험을 줄일 수 있다. 아래쪽으로 놓으라는 설명은 옳지 않다(정답).
    4. 드럼 화물을 겹쳐 쌓을 때는 사이사이에 깔개를 끼워 무게가 한쪽으로 쏠리지 않게 한다는 설명도 원문의 뜻과 그대로 맞으므로 옳다.
    🧮 풀이
    1. 롤 화물을 컨테이너에 넣는 甲은 원형이 눌려 변형되지 않도록 세워 배치했다. 화물의 바닥에 받침을 놓고 상단에 무거운 짐이 쏠리지 않게 고정했다. 도착지에서 포장을 풀어도 롤의 원형이 유지되었다.
    2. 여러 롤 사이에 남은 빈 공간을 확인한 甲은 깔개와 완충재를 넣었다. 항해 중 화물이 옆으로 움직이지 않도록 결속띠의 장력을 조절했다. 도착항에서 화물끼리 부딪혀 포장이 찢어진 흔적이 없었다.
    3. 드럼의 마개가 아래를 향하도록 놓으라는 작업서를 본 甲은 누유 위험을 확인했다. 마개는 위쪽으로 두고 드럼을 세워야 했다. 배치를 고쳐 적입 중 기름이 새지 않았다.
    4. 드럼을 두 단으로 쌓은 甲은 단 사이에 깔개를 넣었다. 윗단의 하중이 아랫단에 고르게 전달되도록 위치를 맞췄다. 적재가 끝난 뒤 기울어진 드럼이 없는지 점검했다.

    드럼·롤 화물 적입 주의사항으로 옳지 않은 것을 고르는 것인데 마개를 아래로 향한다는 설명만 거꾸로이므로, 정답은 3번이다.

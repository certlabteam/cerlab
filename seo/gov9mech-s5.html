    크리프(creep) 현상에 대한 설명으로 옳지 않은 것은?

    1. 1. 크리프 곡선의 제1기 크리프에서는 변형률 속도가 증가한다.
    2. 2. 크리프 곡선의 제2기 크리프에서는 변형률 속도가 거의 일정하게 나타난다.
    3. 3. 가스터빈, 제트엔진, 로켓 등 고온에 노출되는 부품은 크리프 특성이 중요시 된다.
    4. 4. 일정한 하중이 작용하는 경우 온도가 높아지면 파단에 이르는 시간이 짧아진다.

    정답 1번

    🔍 보기별 해설
    1. 제1기(천이) 크리프는 시간이 지날수록 변형률 속도가 점점 줄어드는 구간이다. 가공경화가 회복보다 앞서기 때문인데 속도가 증가한다고 했으므로 옳지 않다(정답).
    2. 제2기(정상) 크리프는 가공경화와 회복이 균형을 이뤄 변형률 속도가 거의 일정한 직선 구간이다. 곡선에서 가장 길게 이어지는 구간이므로 맞다.
    3. 가스터빈 블레이드나 제트엔진, 로켓 노즐은 고온과 하중을 오래 함께 받는다. 그래서 재료를 고를 때 크리프 저항을 먼저 따지는 부품이므로 맞다.
    4. 하중이 같아도 온도가 오르면 원자 확산이 빨라져 변형이 더 빠르게 쌓인다. 그 결과 파단에 이르는 시간이 짧아진다는 설명이므로 맞다.
    🧮 풀이
    1. 고온에서 일정한 하중을 받은 금속 시편을 처음부터 측정했다. 초기에는 빠르게 늘어나다가 변형 속도가 점점 느려졌다. 변형률 속도가 감소하는 제1기 크리프의 모습이었다.
    2. 고온 하중 시험을 계속하자 시편 길이가 거의 일정한 속도로 늘었다. 변형률 곡선의 중간 구간이 비슷한 기울기를 유지했다. 이 정상 상태 구간을 제2기 크리프라고 불렀다.
    3. 가스터빈 블레이드는 높은 온도에서 오랫동안 회전력을 받았다. 작은 크리프 변형도 쌓이면 날개와 케이싱 사이 간격이 달라질 수 있었다. 재료를 고를 때 장시간 고온 강도가 중요했다.
    4. 같은 하중을 건 시편 두 개를 서로 다른 온도에서 시험했다. 더 뜨거운 시편의 변형과 손상이 빨리 누적됐다. 파단까지 걸리는 시간이 짧아져 고온 설계에 온도 조건을 반영했다.

    제1기 크리프는 변형률 속도가 시간이 갈수록 감소한다. 속도가 증가한다는 1번은 제3기 크리프의 특징을 붙인 것이다.

    평행하지도 교차하지도 않는 두 축 사이에 동력을 전달하기 위해 사용하는 기어는?

    1. 1. 스퍼 기어
    2. 2. 베벨 기어
    3. 3. 크라운 기어
    4. 4. 하이포이드 기어

    정답 4번

    🔍 보기별 해설
    1. 스퍼 기어는 평행한 두 축 사이에 동력을 옮기는 원통형 기어이다. 두 축이 서로 나란해야 물리므로 평행하지도 교차하지도 않는 축에는 쓸 수 없어 옳지 않다.
    2. 베벨 기어는 원추 모양으로 두 축의 중심선이 한 점에서 만나는 교차축용이다. 축이 교차하는 배치에 쓰이므로 교차하지도 않는 축을 잇는 데는 옳지 않다.
    3. 크라운 기어는 피치면이 평면인 기어로 베벨 기어의 특수한 경우에 속한다. 맞물리는 축도 서로 교차하므로 어긋난 축용이 아니어서 옳지 않다.
    4. 하이포이드 기어는 스파이럴 베벨과 닮았지만 두 축이 서로 어긋나게 놓인다. 축이 교차하지도 평행하지도 않은 위치에서 동력을 전하므로 옳다(정답).
    🧮 풀이
    1. 서로 평행한 두 축에 곧은 이의 스퍼 기어를 각각 달았다. 두 기어가 같은 평면에서 맞물려 회전을 전달했다. 축 중심선이 어긋나 교차하지 않는 배치는 아니었다.
    2. 서로 직각으로 만나는 두 축에 베벨 기어를 놓았다. 원뿔 모양의 이가 맞물리며 회전 방향을 바꿨다. 축이 실제로 교차하므로 어긋난 축용 하이포이드 기어와 달랐다.
    3. 원판의 평평한 면에 이가 난 크라운 기어를 맞물렸다. 다른 기어와 직각에 가까운 축 배치에서 회전을 전달했다. 두 중심선이 어긋난 비평행·비교차 축 전용 기어는 아니었다.
    4. 자동차의 구동축과 차축이 직각 방향이지만 중심선은 서로 어긋났다. 하이포이드 기어가 두 축 사이에 동력을 전달했다. 차축 위치를 낮춰 차량 구동계 배치를 조정할 수 있었다.

    두 축이 평행하지 않고 서로 교차하지도 않는 어긋난 축이라면 하이포이드 기어를 쓴다. 스퍼·베벨·크라운 기어의 축 배치와 구별한다.

    배관에서 조립 플랜지와 파이프를 이음하는 방식으로 옳지 않은 것은?

    1. 1. 나사 플랜지
    2. 2. 주조 플랜지
    3. 3. 리벳이음 플랜지
    4. 4. 용접이음 플랜지

    정답 2번

    🔍 보기별 해설
    1. 나사 플랜지는 파이프 끝에 나사를 내어 플랜지를 돌려 끼우는 조립식 방식이다. 용접이 어려운 곳에서 쓰는 조립 플랜지의 한 방식이므로 맞다.
    2. 주조 플랜지는 관과 플랜지를 한 덩어리로 주조해 일체로 만드는 형식이다. 따로 조립해 이음하는 방식이 아니므로 조립 플랜지의 이음에 해당하지 않아 옳지 않다(정답).
    3. 리벳이음 플랜지는 파이프에 플랜지를 얹고 리벳을 쳐서 붙이는 방식이다. 조립 플랜지를 파이프에 고정하는 방법 가운데 하나이므로 맞다.
    4. 용접이음 플랜지는 플랜지를 파이프 끝에 용접해 붙이는 방식이다. 고압 배관에 흔히 쓰이는 조립 플랜지의 이음이므로 맞다.
    🧮 풀이
    1. 작은 배관 끝에 나사를 정확히 가공하고 나사식 플랜지를 돌려 끼웠다. 파이프와 플랜지가 나사산에서 결합됐다. 해체할 때도 플랜지를 다시 돌려 빼는 연결 방식이었다.
    2. 용탕을 주형에 부어 플랜지 몸체를 주조했다. 만들어진 플랜지는 아직 파이프에 붙어 있지 않았다. 이후 나사나 용접 같은 별도 이음이 필요해 주조 자체는 연결 방식이 아니었다.
    3. 강판으로 만든 플랜지와 파이프의 겹친 자리에 구멍을 맞췄다. 리벳을 끼우고 끝을 눌러 두 부품을 고정했다. 구멍과 리벳으로 기계적 결합을 만드는 이음 방식이었다.
    4. 파이프 끝과 플랜지를 정확히 맞댄 뒤 전체 둘레를 연속으로 용접했다. 녹은 금속이 식으면서 두 부품이 붙고 누설 경로도 막혔다. 배관에서 쓰는 용접이음 플랜지였다.

    배관 플랜지는 나사·리벳·용접 등의 방식으로 파이프에 연결할 수 있다. 주조는 플랜지를 만드는 방법이며 파이프와 잇는 방식이 아니다.

    상온에서 초기응력 없이 양단이 고정되어 있는 강관에 고온의 유체가 흐를 때 발생하는 현상 및 그 특징으로 옳지 않은 것은?

    1. 1. 강관에 발생하는 길이 방향 하중은 압축력이다.
    2. 2. 강관에 발생하는 길이 방향 응력은 온도변화에 비례한다.
    3. 3. 강관에 발생하는 길이 방향 하중은 종탄성계수에 비례한다.
    4. 4. 강관에 발생하는 길이 방향 응력은 관 길이의 제곱에 비례한다.

    정답 4번

    🔍 보기별 해설
    1. 양단이 고정된 관이 열로 늘어나려 해도 벽이 막고 있어 밀어내는 힘이 생긴다. 늘어남을 억제하는 하중이므로 압축력이라는 설명은 맞다.
    2. 열응력은 탄성계수와 선팽창계수에 온도 변화를 곱해 얻어 온도 변화에 정비례한다. 온도차가 두 배면 응력도 두 배가 되므로 맞다.
    3. 구속된 관의 하중은 탄성계수·단면적·팽창계수·온도 변화를 곱한 값이다. 그래서 종탄성계수에 비례한다고 한 설명은 맞다.
    4. 열응력은 늘어나려는 양과 막힌 양이 같은 비율로 커져 길이가 식에서 지워진다. 응력은 관 길이와 무관한데 길이의 제곱에 비례한다고 했으므로 옳지 않다(정답).
    🧮 풀이
    1. 긴 강관 양끝을 단단히 고정하고 뜨거운 유체를 계속 흘렸다. 관은 온도가 올라 길어지려 했지만 두 고정점이 이동을 막았다. 관 내부에는 길이 방향의 큰 압축력이 생겼다.
    2. 같은 강관의 온도 상승량을 두 배로 높였다. 자유롭게 늘어나려는 열팽창도 두 배가 됐고 고정된 관의 압축응력도 비례해 커졌다. 허용응력 검토에 온도차를 직접 반영했다.
    3. 열팽창계수와 온도차가 같은 두 강관 재료를 양끝에서 고정했다. 종탄성계수가 큰 재료는 같은 열변형을 더 강하게 저항했다. 발생하는 압축 하중과 응력이 더 커졌다.
    4. 길이가 다른 강관 두 개의 양끝을 각각 고정하고 같은 온도만큼 데웠다. 자유 팽창량은 길이에 비례했지만 고정으로 생기는 변형률은 같았다. 열응력은 길이 제곱과 무관했다.

    양끝이 고정된 관을 가열하면 자유 팽창이 막혀 압축 응력이 생긴다. 응력은 EαΔT로 길이와 무관하므로 길이 제곱에 비례한다는 4번이 옳지 않다.

    기준치수가 동일한 구멍과 축에서 구멍의 공차역이 H7일 때, 헐거운 끼워맞춤에 해당하는 축의 공차역은?

    1. 1. g6
    2. 2. js6
    3. 3. k6
    4. 4. m6

    정답 1번

    🔍 보기별 해설
    1. H7 구멍에 g6 축은 축 공차역이 기준선보다 아래에 놓여 항상 틈새가 남는다. 미끄럼 끼워맞춤에 가까운 헐거운 끼워맞춤이므로 옳다(정답).
    2. js6은 공차역이 기준선 위아래로 대칭이어서 H7 구멍과 짝지으면 틈새나 죔새가 어느 쪽으로도 날 수 있다. 헐거운 쪽으로만 확정되지 않는 중간 끼워맞춤이므로 옳지 않다.
    3. k6은 공차역이 기준선 위쪽에 걸쳐 H7 구멍과 짝지으면 대체로 조금의 죔새 쪽으로 기운다. 헐거운 끼워맞춤이라기보다 중간 끼워맞춤이므로 옳지 않다.
    4. m6은 k6보다 공차역이 더 위쪽에 있어 H7 구멍과 끼우면 죔새가 생기는 경우가 더 많다. 중간 끼워맞춤 가운데서도 조이는 쪽이라 헐거운 끼워맞춤이 아니므로 옳지 않다.
    🧮 풀이
    1. 도면의 H7 구멍과 g6 축을 각각 가공해 끼웠다. 축 공차역 전체가 구멍 기준선 아래에 있어 가장 큰 축도 가장 작은 구멍보다 작았다. 조립 뒤 항상 회전 가능한 틈이 남았다.
    2. H7 구멍에 js6 축을 넣는 도면을 검토했다. 축 공차역이 기준 치수 양쪽에 걸쳐 가공 결과에 따라 틈 또는 조임이 생길 수 있었다. 최대·최소 치수를 비교하면 항상 틈을 보장하는 g6와 달랐다.
    3. H7 구멍과 k6 축의 최대·최소 치수를 비교했다. 일부 조합에서는 축이 구멍에 빡빡하게 들어가 중간 끼워맞춤이 됐다. 어느 조합에서나 틈이 남는 헐거운 끼워맞춤은 아니었다.
    4. H7 구멍보다 치수가 큰 쪽으로 치우친 m6 축을 준비했다. 축을 넣으려면 별도의 압입력이 필요할 수 있었다. 자유롭게 미끄러지는 g6 축과 공차역 위치가 뚜렷하게 달랐다.

    구멍 기준 H7에 축 g6를 맞추면 축의 최대 치수가 구멍 최소 치수보다 작아 항상 틈이 생긴다. 헐거운 끼워맞춤이다.

    다음 중 사이클로이드 치형의 특징이 아닌 것은?

    1. 1. 압력각이 변화한다.
    2. 2. 전위기어를 사용할 수 없다.
    3. 3. 언더컷이 발생하고 인벌류트 치형에 비해 소음이 크다.
    4. 4. 접촉면의 미끄럼률이 일정하며 치면의 마모가 균일하다.

    정답 3번

    1. 1. 200
    2. 2. 250
    3. 3. 300
    4. 4. 350

    정답 1번

    🔍 보기별 해설
    1. 외접 기어 중심거리는 m(z₁+z₂)/2다. 5×80/2=200mm이므로 옳다(정답).
    🧮 풀이
    1. ① 잇수의 합을 확인한다
    2. 두 기어의 잇수 합은 80개다. 각속도비 1:3이므로 잇수는 반대 비인 3:1이다. 따라서 두 잇수는 60개와 20개지만 중심거리에는 합 80만 있으면 된다.
    3. → z₁+z₂=80
    4. ↓
    5. ② 피치원 지름을 나타낸다
    6. 평기어의 모듈은 피치원 지름을 잇수로 나눈 값이다. 모듈이 5mm이므로 두 피치원 지름의 합은 모듈과 잇수 합의 곱이다. 각 기어에 같은 모듈을 쓴다.
    7. → d₁+d₂=m(z₁+z₂)=400mm
    8. ↓
    9. ③ 외접 중심거리를 구한다
    10. 두 기어가 바깥에서 맞물리므로 중심 사이는 피치원 반지름 둘을 더한 값이다. 지름 합 400mm를 2로 나누면 중심거리는 200mm다.
    11. → a=(d₁+d₂)/2=200mm
    12. ↓
    13. ④ 속도비로 검산한다
    14. 잇수 60과 20에 모듈 5를 곱하면 피치원 지름은 300mm와 100mm다. 반지름 150mm와 50mm를 더하면 200mm로 앞의 계산과 같다.

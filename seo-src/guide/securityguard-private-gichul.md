# 민간경비론 기출문제, 자주 나오는 개념부터

경비지도사 1차 민간경비론은 회마다 40문항입니다. 이 글은 서트랩에 올라간 민간경비론 기출 5개년(2021년 제23회 ~ 2025년 제27회, 200문항)에서 여러 문항에 걸쳐 나온 개념 10가지를 골랐습니다.

개념 옆 링크를 누르면 그 개념이 나온 기출 문제를 바로 풀고 보기별 해설을 볼 수 있습니다. 1차 두 과목을 같이 정리한 글은 [경비지도사 1차 기출문제 정리](https://certlab.ai.kr/seo/guide-securityguard-1cha-gichul.html)에 있습니다.

## 1. 기계경비의 장단점

기계경비는 장점과 단점을 따로 묻고, 인력경비와 나란히 놓고도 묻습니다. 장점과 단점을 한 표에 같이 적어 두면 「옳지 않은 것」 문제에서 헷갈리지 않습니다.

- 기계경비의 장점에 관한 설명으로 옳지 않은 것 → [2021 기출](https://certlab.ai.kr/?q=securityguard/gs2021_private_016)
- 기계경비의 단점에 관한 설명으로 옳지 않은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_011)
- 인력경비와 기계경비에 관한 설명으로 옳은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_019)

## 2. 자체경비와 계약경비

거의 해마다 나오는 짝 개념입니다. 한쪽의 장점이 다른 쪽의 단점인 경우가 많아서, 보기를 반대로 바꿔 내는 문제가 자주 보입니다.

- 자체경비와 계약경비의 장단점으로 옳지 않은 것 → [2021 기출](https://certlab.ai.kr/?q=securityguard/gs2021_private_017)
- 계약경비와 자체경비에 관한 설명으로 옳은 것 → [2023 기출](https://certlab.ai.kr/?q=securityguard/gs2023_private_016)
- 자체경비와 계약경비에 관한 설명으로 옳지 않은 것 → [2024 기출](https://certlab.ai.kr/?q=securityguard/gs2024_private_013)

## 3. 민간경비와 공경비

둘의 차이와 둘의 관계를 따로 묻습니다. 누구를 위해, 무엇을 목적으로, 어떤 권한으로 일하는지를 기준으로 나눠 보세요.

- 민간경비와 공경비에 관한 설명으로 옳지 않은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_002)
- 민간경비와 공경비의 관계에 관한 설명으로 옳지 않은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_010)

## 4. 민간경비원의 법적 지위와 권한

민간경비원이 할 수 있는 일과 할 수 없는 일을 묻습니다. 보기마다 「이건 경찰 권한인가, 민간경비원도 되는가」를 따져 보면 풀립니다.

- 우리나라 민간경비원의 법적 권한으로 옳지 않은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_036)
- 민간경비원의 법적 지위와 권한으로 옳지 않은 것 → [2024 기출](https://certlab.ai.kr/?q=securityguard/gs2024_private_018)

## 5. CPTED(환경설계를 통한 범죄예방)

CPTED의 원리마다 예를 하나씩 붙여 외워 두면 보기를 빨리 고를 수 있습니다.

- CPTED에 관한 설명으로 옳지 않은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_004)
- 환경설계를 통한 범죄예방에 관한 설명으로 옳은 것 → [2024 기출](https://certlab.ai.kr/?q=securityguard/gs2024_private_030)

## 6. 경비계획 수립의 원칙

- 경비계획 수립의 기본 원칙으로 옳지 않은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_021)
- 경비계획을 세울 때 고려할 사항으로 옳지 않은 것 → [2023 기출](https://certlab.ai.kr/?q=securityguard/gs2023_private_023)

## 7. 외곽경비

울타리, 출입구, 조명처럼 건물 밖을 지키는 방법을 묻습니다. 경비계획 문제와 같이 풀어 두면 좋습니다.

- 외곽경비에 관한 설명으로 옳지 않은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_022)
- 외곽경비에 관한 설명으로 옳은 것 → [2023 기출](https://certlab.ai.kr/?q=securityguard/gs2023_private_025)

## 8. 민간경비의 실질적·형식적 개념

- 민간경비의 개념에 관한 설명으로 옳지 않은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_001)

## 9. 공동화이론

민간경비가 왜 생겨났는지를 설명하는 이론 가운데 하나입니다. 다른 이론과 이름이 비슷하니 이론마다 핵심 한 줄을 적어 두세요.

- 공동화이론에 관한 설명으로 옳은 것 → [2024 기출](https://certlab.ai.kr/?q=securityguard/gs2024_private_003)

## 10. 한국 민간경비의 역사

- 한국 민간경비의 역사적 발전 과정으로 옳지 않은 것 → [2021 기출](https://certlab.ai.kr/?q=securityguard/gs2021_private_008)
- 우리나라 민간경비 제도에 관한 설명으로 옳지 않은 것 → [2021 기출](https://certlab.ai.kr/?q=securityguard/gs2021_private_012)

## 더 보면 좋은 것 — 치안 여건의 변화

- 우리나라 치안 여건의 변화로 옳지 않은 것 → [2021 기출](https://certlab.ai.kr/?q=securityguard/gs2021_private_014)
- 우리나라 치안 환경에 관한 설명으로 옳은 것 → [2022 기출](https://certlab.ai.kr/?q=securityguard/gs2022_private_014)

## 시험 전까지 푸는 순서

1. 위 1~10번 순서대로 개념마다 기출을 풉니다. 여러 해에 걸쳐 나온 개념부터 잡는 방법입니다.
2. 틀린 문제는 정답 해설만 보지 말고 보기별 해설을 다 읽습니다.
3. 자체경비와 계약경비, 민간경비와 공경비, 기계경비와 인력경비처럼 짝으로 나오는 개념은 표로 나란히 적어 두고 시험 전날 다시 봅니다.
4. 마지막으로 최근 회차(2025 → 2021) 순서로 한 회씩 40문항을 다 풀어 봅니다.
